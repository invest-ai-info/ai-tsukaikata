# 「みんながAIで何をしたいか」の調査（2026-08-10）

オーナー指示「いまみんながAIを使ってやりたいことを大規模にリサーチして、まとめて保存」。
目的は**レシピの題材を、勘ではなく需要から決めること**。

## 何を測ったのか（先に限界を書く）

🚨 **「みんながやりたいこと」は直接測れない。**取れるのは全部**代理指標**で、それぞれ偏る。

| 使った | 分かること | 偏り |
|---|---|---|
| **Google サジェスト**（今回の主力） | 実際に打たれている語。日本語・現在 | 検索する人だけ。**回数は分からない** |
| Search Console | **このサイトに来た検索語** | ⭐ 最強だが**未登録**（運営者の宿題） |
| Q&Aサイト・Reddit | 詰まっている具体的な場面 | 困った人だけ。成功例は出ない |
| 公的調査（情報通信白書等） | 利用率・属性 | 半年〜1年遅れ。粒度が粗い |

⚠️ **WebSearch はツール側の仕様で US 限定**なので、日本語圏の需要には使えなかった。

🔑 **いちばん重要な限界: サジェストに件数は付いてこない。**下の「語数」は
**言い回しの種類の多さ**であって検索回数ではない。順位の目安にはなるが、
「230語だから213語より需要が大きい」とは言えない。**ノイズも混ざる**
（「ai 翻訳 ひで」「哀 例文」のような無関係な一致が実際にあった）。

## 方法（再現できる形で）

種30語 × 語尾32種 = **930クエリ**を Google サジェストに投げ、**5,104語**を集めた。

```python
import json, time, urllib.parse, urllib.request
def suggest(q):
    url = ("https://suggestqueries.google.com/complete/search?client=firefox&hl=ja&"
           + urllib.parse.urlencode({"q": q}))
    req = urllib.request.Request(url, headers={"User-Agent": "Mozilla/5.0"})
    with urllib.request.urlopen(req, timeout=15) as r:
        return json.loads(r.read().decode("utf-8"))[1]
```

種＝ツール名（ChatGPT/Claude/Gemini/生成AI/AI）× 作業（文章・資料・エクセル・メール・
議事録・要約・翻訳・画像・勉強・家事・家計）× 文脈（仕事・効率化・自動化・副業）。
語尾＝ひらがな28種＋「方法/コツ/例/やり方」。

情報収集・商用・無関係を落として（とは/料金/口コミ/求人/資格/株/危険/規制 など）
**4,239語**を「やりたいこと」として扱い、17テーマに束ねて既存22記事と突き合わせた。

| **資料・スライドを作らせる** | 38 | **ゼロ** | **ゼロ** |

⚠️ **「あり」判定は雑**（記事本文にその語が出るかを見ただけ）。**「ゼロ」のほうは
全文検索で確かめてあるので信用してよいが、「あり」は薄い扱いかもしれない。**

## 判断: 書かなかったもの

- **画像生成（66語）** — 需要はあるが、このサイトの読者像（非エンジニアの会社員が
  仕事を自動化する）から外れる。既存記事もある
- **コードを書かせる（20語）** — 読者定義と正面から矛盾する（「プログラミング不要」）
- **「AIに仕事を奪われるか」系** — 検索は多いが**このサイトが答えるべき問いではない**。
  ノイズとして落とした
