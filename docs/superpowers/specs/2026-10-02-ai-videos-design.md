# AI動画まとめ（/videos/）設計

2026-10-02 オーナー承認。「YouTubeでAI関係の動画を集めて、要約して紹介するページ。
AI技術系・AIで稼ぐ系・AI最新情報系の3つで分ける」。

## オーナーが決めたこと

| 論点 | 決定 |
|---|---|
| 言語 | 日本語中心＋海外の有名どころ（要約はすべて日本語） |
| 稼ぐ系 | **注意書きを付けて載せる**（外さない） |
| 要約 | **Gemini に動画そのものを見せる**（登録済みの `GEMINI_API_KEY`） |
| チャンネル | おまかせ＝候補21本を調べて一覧を見せ、承認済み（`videos/channels.yml`） |

## 仕組み

トラッカー（`tracker/`）には相乗りしない。メール通知の仕組みを巻き込まないため、別パッケージ `videos/`。

1. **集める**（`videos/feed.py`）＝チャンネルの RSS（`/feeds/videos.xml?channel_id=`・鍵不要）。
   - 🚨 **正しい ID でも 404/500 を繰り返す**（2026-10-02 調査で最大30回）。再試行し、1回の 404 を「ID違い」と扱わない
   - リンクが `/shorts/` の動画は除く
2. **要約する**（`videos/gemini.py`）＝公開動画のURLを Gemini に渡す（interactions API。失敗したら generateContent）。
   - 無料枠＝YouTube 動画は1日8時間ぶん。**1回4本・最初の30分だけ**（`end_offset` 1800秒）・6時間おき＝1日最大16本×30分
   - 返事は JSON。分類（tech / earn / news）・要約3行・こんな人向け・注意書き・AIと関係あるか
   - 動画に出てこない数字を足さない。稼ぐ系の金額は「本人の主張」と書く
3. **貯める**（`videos/store.py`）＝`data/videos/videos.json`。**要約済みは期限なしで残す**（2026-10-06〜。
   それまでは公開から45日で消していた）。載らない動画（skipped/failed）は45日で消す。要約待ちは14日で諦める。
   3回失敗した動画は `failed`
4. **載せる**（`src/videos.py`）＝要約ができた動画だけ。入口・分類・月の3段（下の「画面」）

## 失敗したとき

- 要約が作れない動画は**載せない**（タイトルと説明文から要約を作らない＝作り話を出さない）
- 配信が取れないチャンネルはその回だけ飛ばす。前回までのデータで表示を続ける
- ファイルが無い・要約済みが0本＝ページもボタンも出さない（`/ainews/` と同じ）
- ファイルが壊れている＝ビルドを止める
- ワークフローの要約ステップは失敗しても後続のコミットを止めない

## 画面

- ~~`/videos/` 1ページに3分類を全部並べる~~ → 2026-10-06 に3段へ分けた（次の節）
- カード＝サムネイル（`i.ytimg.com`）・題・チャンネル名・公開日・要約3行・こんな人向け・⚠️注意書き
- 動画は埋め込まない（重くならない・視聴者が YouTube に追跡されない）。クリックで YouTube を開く
- 稼ぐ系の冒頭に「動画内の金額は出演者の主張で、このサイトは確かめていません」
- プライバシーポリシーに「サムネイル画像は YouTube のサーバーから読み込む」を足す

## 入口・分類・月の3段に分けた（2026-10-06）

オーナー指摘「ページが長くなって見づらい。隠すか別のページに誘導を。過去の動画も見れるようにしたい」。
2案（①分類ごとに別ページ ②1ページのまま畳む）から **①をオーナーが選んだ**。
②は作りが軽いが、ページの中身（読み込む量）が動画が増えるほど重くなり続けるため。

| ページ | 中身 | テンプレート |
|---|---|---|
| `/videos/` | 分類ごとに最新6本（題・サムネ・チャンネル・日付だけ。要約は出さない）＋「要約つきで見る」 | `videos.html` |
| `/videos/<分類>/` | 最新20本（要約つき）＋「月ごとに見る」 | `videos_list.html`（`month=None`） |
| `/videos/<分類>/<年-月>/` | その月の動画を全部（要約つき） | `videos_list.html` |

- 分類のページを「今月」ではなく**最新20本**にした（「今月」だと月初めにほぼ空になる）
- 月は**日本時間**で数える（UTC の 9/30 16:00 は 10月の動画）
- 入口の6本と検索結果の行き先は**分類のページ**（`/videos/<分類>/#v-<動画ID>`）。6本・検索対象の20本は必ずそこに並ぶ
- **検索に入るのは分類のページの最新20本だけ**。過去の月は月のページでたどる（全部入れると索引が1年で数百KB増える）
- 動画が0本の分類はページを作らず、ボタンもリンクも出さない
- 稼ぐ系の注意書きは**入口・分類・月のどのページにも**出す
- スマホのカードはサムネを全幅→120px で題の横に置いた。要約は下に全幅
- 実測（375px幅・46本の時点）: 旧 `/videos/` 31,746px → 入口 3,422px・分類のページ（20本）10,422px
- データ量＝要約済み1本 約1.3KB・1日7本ほど＝1年 約3MB（`videos.json` は6時間おきにコミットされる）。
  重くなったら、終わった月を `data/videos/archive/<年-月>.json` に切り出す（いまは不要）
