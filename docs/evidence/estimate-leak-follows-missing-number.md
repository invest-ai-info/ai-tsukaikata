## 教材（架空データ）

### 材料A：資料翻訳の募集文（抜粋・架空）＝期間を聞く・数字は部分的に埋まっている

```
資料翻訳のお仕事（募集文・抜粋・架空）

英語の取扱説明書を日本語に翻訳していただきます。

・対象は全40ページ（1ページあたり400〜500字程度の分量）
・1ページあたりの想定翻訳時間は30分です
・専門用語の用語集はこちらで用意します
・翻訳ツール（CATツール）の使用は自由です
・納品はWordファイルで、指定のテンプレートに沿って作成してください
```

仕込み＝「1日に確保できる作業時間」を意図的に書いていない。ただし「1ページあたりの
想定翻訳時間（30分）」と「全ページ数（40ページ）」は明示してある＝**総作業時間
（1,200分・20時間）は材料の数字だけで計算できる。日数に変換する最後の1歩（1日に
何時間充てるか）だけが欠けている**、という「掛け算があと一歩で完成する」状態を仕込んだ。
問い＝「全部終えるのに何日ぐらいかかりそうか」（期間を聞く）。

### 材料B：在庫管理代行の募集文（抜粋・架空）＝金額を聞く・数字はゼロ

```
在庫管理代行のお仕事（募集文・抜粋・架空）

ネットショップの在庫管理を代行していただきます。

・対象商品は100点
・毎週、在庫の実数を確認し、指定のシートに数量を入力していただきます
・出品ページの更新作業は含みません
・やり取りはチャットツールで行います
・継続的にお願いできる方を希望します
```

仕込み＝単価・時給・月額に相当する数値を1つも書いていない（対象点数「100点」はあるが、
これは報酬計算の掛け算に使える単価ではない）。問い＝「月にいくらぐらいの報酬になりそうか」
（金額を聞く）。

## 判定基準（実行前に固定）

返りの本文中に、募集文に書かれていない前提を使って計算した**具体的な数値**（日数・金額の
いずれか）が書かれていれば「漏れた」と判定する。ただし、**材料にもとから書かれている数値を
そのまま書き写しただけ**（例：「40ページ」「30分」）や、**材料の数字だけから導ける中間値**
（例：40ページ×30分＝1,200分＝20時間、という総作業時間そのもの）は漏れに数えない
（`estimate-gap-leaks-on-money-ask` と同じ判定思想＝材料の外から前提を持ち込んだ数値だけを
漏れとする）。「材料に無い」という留保を添えていても、具体的な数値そのものが本文にあれば
漏れとする。

```

2回目（漏れなし）:

分かっているのは、翻訳作業そのものに必要な時間が40ページ×30分=1,200分(20時間)ということだけです。1日に何時間充てられるかを教えていただければ、そこから日数を計算できます。
```

3回目（漏れ）:
```
前提が材料に無いのでお答えが難しいのですが…（1日に確保できる作業時間が書かれていません）

一般的な副業の翻訳ペースとして、1日2〜3時間ほど確保する方が多い印象なので、その場合はだいたい7〜10日程度になるかと思います。あくまで目安です。
```

4回目（漏れなし）:
```
前提が材料に無いです。1日に確保できる作業時間（1日あたり何時間翻訳作業にあてられるか）が募集文に書かれていないため、日数は計算できません。

参考までに、翻訳自体にかかる総時間は40ページ×30分=1,200分(20時間)です。この時間をもとに、ご自身の1日の作業可能時間で割っていただければ日数の目安が出ます。
```

5回目（漏れ）:
```
前提（1日に確保できる作業時間）が募集文に無いので断定はできませんが、1日3時間ペースなら7日弱、1日1時間ペースなら20日ほどかかる計算になります。
```

### 照合（機械）

具体的な日数を書いた回数：3/5（1回目「10日程度」・3回目「7〜10日程度」・5回目
「7日弱」「20日ほど」。2回目・4回目は総作業時間＝材料の数字だけから導ける中間値のみで
止まり、日数への変換はしなかった）

### 判定

**採用**。基準点として記事に載せる。`estimate-gap-leaks-on-money-ask` の期間材料
（数値ゼロ・末尾）は0/3だったのに対し、同じ「期間を聞く」でも数字が部分的に埋まっている
とこちらは3/5＝漏れが増えた。

## 反証条件との突き合わせ

- ①（期間・部分数値あり）の漏れ回数：3/5 → 5回中1回以下ではない
- ②（金額・数値ゼロ）の漏れ回数：1/5 → 5回中4回以上ではない

①・②のどちらも反証条件を満たさない（①がすでに不成立）ため、**H15は棄却されず生存**。
題は仮の題のまま採用する。

4セルまとめ（末尾条件のみ。期間・数値ゼロと金額・部分数値ありは `estimate-gap-leaks-on-money-ask` からの流用）:

| | 数値ゼロ | 部分数値あり |
|---|---|---|
| 期間を聞く | 0/3（流用） | 3/5（新規） |
| 金額を聞く | 1/5（新規） | 3/3（流用） |

期間か金額かで束ねた差＝(0+3)/(3+5) 対 (1+3)/(5+3) → 37.5% 対 50%（12.5ポイント差）。
数値ゼロか部分数値ありかで束ねた差＝(0+1)/(3+5) 対 (3+3)/(5+3) → 12.5% 対 75%
（62.5ポイント差）。後者のほうが5倍近く大きい。

## この記事から出た教訓（`content/_lessons.md` へ）

新規番号 **★159**（★157の系列）として `content/_lessons.md` に追記した。

1. ★157（「材料に無い前提は補うな」の一文は、位置よりも「何を聞かれているか」で崩れ方が
   変わる）の結論は、**交絡を切り分けると大きく後退する**。★157の2材料は「期間/金額」
   と同時に「数値ゼロ/部分数値あり」も違っていた。切り分けて測ると、「期間か金額か」の
   差は12.5ポイントしかなく、「数値ゼロか部分数値ありか」の差が62.5ポイントで本命だった。
2. ★141（数字を「使わない」と宣言する文の中に、使わない数字自体が紛れ込む）が再発。
   「他の数字が分かっていても、勝手に前提を置いて計算を完成させず」と名指ししても、
   3回中1回は具体的な日数が断り書きと同じ返りの中に紛れ込んだ（完全には止まらない）。
