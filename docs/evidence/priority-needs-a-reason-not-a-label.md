# 試した証拠 — priority-needs-a-reason-not-a-label

## 教材（架空データ）

架空のタスク一覧を2種類（材料A＝総務・経理の担当者、材料B＝ネットショップ運営者）用意した。
各20件で、うち4件は「締切が1〜3日後と近いが、遅れても実害がない」と本文に書いた仕事（trapA）、
別の4件は「締切は20日以上先だが、遅れると重大な影響が出る」と本文に書いた仕事（trapB）。
残り12件は締切・重要度とも中間的な仕事（filler）で埋めた。今日の日付は2026年9月24日として扱った。

**仕込み（先に宣言）**: trapA（TA1〜TA4／SA1〜SA4）の締切は1〜3日後・重要度は最低ランク。
trapB（TB1〜TB4／SB1〜SB4）の締切は18〜31日後・重要度は最高ランク。
「優先順位をつけて並べ替えて」だけの指示でも「重要度も踏まえて」と足した指示でも、
本文に理由が書いてあれば trapB が trapA より必ず上位に来る、という仮説を立てて試した。

## この記事から出た教訓（`content/_lessons.md` へ）

1. **AIに優先順位を決めさせるとき、指示文に「重要度も踏まえて」と足しても結果は動かない。
   決め手は材料の説明文に「なぜ重要か」の理由が書かれているかどうかだった。**
   理由の一文がある材料では、指示の言い方に関わらず8回・128組の比較で逆転ゼロ。
   理由を消して「重要度：高・中・低」のラベルだけにすると、同じ2つの指示の言い方で
   4回・64組の比較すべてで向きが完全に逆転した（締切の近さが勝った）。
   これは `urgent-wording-does-not-catch-more`（★156・念押しは検出数を動かさず、
   動いたのは材料の作り方だった）と同じ家族の現象——**指示文の強さより、
   材料の書き方（理由の有無）が結果を決める**、という構図が別の題材でも再発した。
