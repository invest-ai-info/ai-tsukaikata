**真値（Pythonでの検算）:**

```
>>> note_office = 800 * 0.05
>>> note_platform = (800 - note_office) * 0.10
>>> note_net = 800 - note_office - note_platform
(40.0, 76.0, 684.0)   # note: 事務手数料40円・利用料76円・手取り684円。売上800円<1,000円で振込不可

>>> kindle_net = 0.35 * (700 / 1.1)
222.72727272727272    # Kindle: KDPセレクト未登録なので35%（配信コストは引かない）

>>> youtube_net = 9000 * 0.45
4050.0                # YouTube: Shortsなので45%。8,000円未満で繰り越し
```

⚠️ 仕込み＝(1) note の売上800円は「1,000円以上」の振込条件を**下回る**、
(2) Kindle はKDPセレクト**未登録**なので35%(70%ではない)、
(3) YouTube はShorts**なので45%**(長尺の55%ではない)。この3点を取り違えずに
計算・判定できるかを見た。あわせて、Kindleの振込条件（最低額・締め日）は
どちらの教材にも**書いていない**——書かれていない情報を、実在のKDPについて

## この記事から出た教訓（`content/_lessons.md` へ）

1. 実在プラットフォーム名について、材料に書いていない情報（振込条件・支払いサイクル）を
   尋ねると、AIは実在サービスの一般的な運用として作り話を補う。単独で名指しするほど
   発生率が上がり（まとめた版で2/3、単独版で3/3）、しかも補った数字が回によって食い違う
   （「約2か月後」「約60日後」「約2ヶ月後」）。これは★144/★162/★163（実在固有名詞は
   書かれていない規約・料率を自分から語らせる）の再発で、対象が「規約の中身」から
   「支払いタイミングの数字」に広がった。
2. 「示されていない情報は、実際のサービスの一般的な運用で補わないでください」の一文は、
   複数プラットフォームをまとめた版でも、単独の版でも、作り話の発生を止めた（2/3→0/3、
   3/3→0/2）。組み合わせ方に関係なく効く一文として使える。
