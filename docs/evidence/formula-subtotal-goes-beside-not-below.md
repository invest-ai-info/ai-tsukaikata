```
下の表の、部署ごとの合計を出す数式を書いてください。

```

D14: =SUMIF($B:$B,"営業部",$D:$D)
D15: =SUMIF($B:$B,"総務部",$D:$D)

総務部: =SUMIF($B:$B,"総務部",$D:$D)

### 返ってきたもの（生）— 材料A・3回目（気づいた回）

```

その前に1点だけ確認させてください。

いただいた表の14〜16行目に、すでに部署ごとの合計欄があります。この行の

もしD列を丸ごと参照するSUMIF($B:$B,"営業部",$D:$D)を14行目自身に入れると、

D15: =SUMIF($B:$B,"大阪",$D:$D)

### 返ってきたもの（生）— 材料B・3回目

大阪: =SUMIF($B:$B,"大阪",$D:$D)

### 照合（機械）

判定語（「循環」「二重」「合計行」「合計の行」「別のシート」「別の列」「下に置か」
「範囲に含ま」「含めない」「除外」）を6回の返りに機械で照合した。

```
材料A-1: 該当語なし → 未検出
材料A-2: 該当語なし → 未検出
材料A-3: 「循環参照」「二重計上」「別の列」を含む → 検出
材料B-1: 該当語なし → 未検出
材料B-2: 該当語なし → 未検出
材料B-3: 該当語なし → 未検出

検出＝1／6（材料A-3のみ）。反証条件（5／6以上で棄却）に届かず、仮説は生存。
```

さらに、検出できなかった5回の数式（D14〜D16に列全体参照のSUMIFを入れる案）を
実際にExcelの挙動として確認した＝D14自身が参照範囲$D:$Dに含まれるため
**循環参照の警告が出る構造**であり、警告を無視して反復計算を許可した場合でも
B14「営業部」（または「東京」）がSUMIFの検索条件と一致するため**合計行自身の値が
合計に混入し、二重計上になる**。真値との比較は下の指示文2で行った。

### 判定

**採用**。指示文は記事の指示文1にそのまま使う。6回中1回だけ自分から気づいた、
という結果を記事の主張の根拠にする。

### 返ってきたもの（生）

## 指示文3（＝記事の指示文3・受け皿「集計欄をどけて」の効果を確認）

### 送った指示文（記事と同一文字列）

```
この表には、部署ごとの合計欄がデータのすぐ下（14〜16行目）に含まれています。
集計欄自身を範囲に含めない形で、行が増えても直さなくていい数式にしてください。
```

### 返ってきたもの（生）— 材料A・1回目

```
承知しました。集計欄（14〜16行目）自身を範囲から除くため、データ行だけを
明示的に区切ります。

D14: =SUMIF($B$2:$B$13,"営業部",$D$2:$D$13)
D15: =SUMIF($B$2:$B$13,"総務部",$D$2:$D$13)
D16: =SUMIF($B$2:$B$13,"開発部",$D$2:$D$13)

⚠️ この形は「行が増えても書き換え不要」ではありません。行が増えたら
$B$13/$D$13の「13」を新しい最終行の番号に書き換える必要があります。
列全体参照にしたい場合は、集計欄を表の下ではなく右側の別の列（例: G列・H列）に
移すことをおすすめします。そちらであれば $B:$B / $D:$D のままで安全です。
```

### 返ってきたもの（生）— 材料A・2回目

```
集計欄自身を範囲に含めないようにするので、集計欄を表の右側（F列・G列）に
移動する形を提案します。

F2: 営業部　G2: =SUMIF($B:$B,F2,$D:$D)
F3: 総務部　G3: =SUMIF($B:$B,F3,$D:$D)
F4: 開発部　G4: =SUMIF($B:$B,F4,$D:$D)

この形であれば集計欄はB列・D列そのものには含まれないため、列全体参照でも
循環参照にも二重計上にもなりません。14〜16行目の集計欄は削除してください。
```

### 照合（機械）

2回とも「集計欄を範囲の外に出す」対応（①最終行を明示して区切る／②集計欄を
別列に移す）で、判定語（「別の列」「範囲に含ま」等）を含む。2回とも循環参照・
二重計上のどちらにも触れて説明している。

```
材料A-1: 範囲を$B$2:$B$13に限定＋「右側の別の列に移すことをおすすめ」→ 検出・対応あり
材料A-2: 集計欄を右側の別列に移す提案＋削除指示 → 検出・対応あり
```

### 判定

**採用**。「集計欄を範囲の外に出す」という受け皿の一文が2回とも効いたので、
記事の「うまくいかないときの言い直し方」に使う。

## 指示文4（＝記事の「言い直し方」・テーブル機能で自動的に除外できるか）

### 送った指示文（記事と同一文字列）

```
列全体参照はそのままで、集計欄も表の下に残したいです。表計算ソフトのテーブル機能

```

### 返ってきたもの（生）

```
はい、Excelの「テーブル」機能（データ範囲を選んでCtrl+T）を使うと、この問題を
かなりの部分まで解決できます。

・データ行（2〜13行目）をテーブルに変換すると、テーブル参照
  （例: =SUM(テーブル1[金額])）は自動的に「データ行だけ」を指し、
  テーブルの外に置いた集計欄（14〜16行目）は最初から範囲に含まれません
・テーブルには「集計行」という機能もあり、これを使うと集計欄自体がテーブルの
  一部として管理され、行が増えても位置がずれません

ただし1点注意があります。**14〜16行目をテーブルの中に含めてしまうと、
今回と同じ問題（集計行が自分自身を含む）がそのまま起こります。**集計欄は

「集計欄をテーブル範囲外に置く」という条件は残ると明記＝万能の解決策ではないと
自分から限定している。

### 判定

**採用**。「言い直し方」節の1つ目に使う。テーブル機能は助けにはなるが、
条件（集計欄を範囲外に置く）自体は消えないという限定つきの回答だったため。

   注意を**抽象的な忠告としては自分から言える**（`formula-that-survives-new-rows`

   数式を出した。**抽象的な自己申告の警告（★49・★98の系列）は、具体的な材料に
   その状況が現れたときに転移するとは限らない、という★98・★157の系列の再発。

   検算の仕方（実際にExcelへ入れて確認する）に使える。
