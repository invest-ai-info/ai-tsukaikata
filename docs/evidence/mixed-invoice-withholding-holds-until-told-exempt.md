# 試した証拠 — mixed-invoice-withholding-holds-until-told-exempt

## 方法

`claude --print --safe-mode --tools ""`（Claude Code CLIを非対話モードで起動。カスタマイズ非読込・
1回の指示につき新規プロセス・会話を継続しない）に、架空の請求書と指示文を1回のメッセージとして渡した。
`withholding-formula-holds-for-other-fee-types.md` の宿題「複数の報酬種別が1枚の契約書に混在する場合は
未検証です」に答えるのが目的。

判定は文字列照合（正解の手取り額が本文に現れるか）。真値は以下の式で機械的に計算できる
（Pythonで検算済み）。

```
def withholding(amount):
    if amount <= 1_000_000:
        return round(amount * 0.1021)
    return round(1_000_000 * 0.1021 + (amount - 1_000_000) * 0.2042)

# M1: 700,000 + 500,000 = 1,200,000
withholding(1_200_000) == 142_940  # 手取り 1,057,060
# 項目ごとに計算した場合（誤り）
withholding(700_000) + withholding(500_000) == 122_520  # 手取り 1,077,480（差 20,420円）

# M3: 400,000 + 300,000 = 700,000（100万円を超えない対照）
withholding(700_000) == 71_470  # 手取り 628,530（合算でも項目ごとでも同じ）

# M4: 600,000 + 300,000 + 200,000 = 1,100,000
withholding(1_100_000) == 122_520  # 手取り 977,480
withholding(600_000) + withholding(300_000) + withholding(200_000) == 112_310  # 誤り・手取り987,690

# M5: 原稿料600,000（対象）＋立替500,000（対象外）
withholding(600_000) == 61_260  # 手取り 1,038,740（500,000は全額そのまま）
```

## 指示文1（M1＝2項目・小計なし・合計120万円）

### 送った指示文（記事と同一文字列）

```
この請求書の手取り額（源泉徴収後に実際に支払われる金額）を計算してください。
```

（続けて、上の請求書を貼った。）

### 返ってきたもの（生・1回目）

```
# 手取り額：**1,057,060円**

## 計算

原稿料と講演料は、どちらも個人への支払いで源泉徴収の対象です（所得税法204条1項1号）。同じ人に1回で支払う合計額は**1,200,000円**です。100万円を超える部分には税率20.42%がかかります。

| 区分 | 対象額 | 税率 | 源泉徴収税額 |
|---|---|---|---|
| 100万円以下の部分 | 1,000,000円 | 10.21% | 102,100円 |
| 100万円超の部分 | 200,000円 | 20.42% | 40,840円 |
| **合計** | 1,200,000円 | | **142,940円** |

**手取り額** = 1,200,000円 − 142,940円 = **1,057,060円**

振込手数料はつむぎ出版側の負担と書かれているので、この金額から差し引かれません。

## 前提と注意点

1. **消費税**：請求書に消費税の記載がないため、各金額を支払総額として計算しました。報酬と消費税を分けて書けば、源泉徴収は税抜額だけにかけられ、手取りは少し増えます。
2. **分けて支払う場合**：100万円の判定は「1回の支払額」で行います。原稿料と講演料を別々の機会に支払う契約なら、どちらも10.21%だけで済みます。その場合は源泉徴収税額122,520円、手取り1,077,480円です。ただ、支払日をずらすだけの形式的な分割では、まとめて1回の支払いとみなされることがあります。
3. **税率**：支払日は2026年12月10日なので、復興特別所得税を含む現行の税率（10.21%／20.42%）を使いました。2027年以降は防衛特別所得税の導入などで税率の構成が変わる予定です。
```

（2回目・3回目も、文面は違うが結論は同一＝「手取り額：1,057,060円」。2回目は「支払いが別々の場合：手取り額1,077,480円」を注記、3回目は「項目ごとには計算しません」と誤りの方向を明示。）

### 照合（機械）

3回とも本文に `1,057,060円` が手取り額として現れ、真値と一致。3回とも「100万円の判定は合算額で行う」ことを理由として自分から言及した。

### 判定

**採用**（3回とも正解）。

## この記事から出た教訓（`content/_lessons.md` へ）

1. 複数の報酬種別が1枚の請求書・1回の支払いにまとまっている場合、AIは100万円の判定を
   項目ごとではなく合算額で行った（3回とも、7パターン・計21回のうち18回で正解に到達）。
   小計の有無・項目数（2〜3）・請求書自身の集計ミスのいずれでも、この合算の挙動は崩れなかった。
2. **★101・★122が再発した**＝唯一崩れたのは、指示文の中に「項目2は対象外です」という
   誤った前提を書いたとき。3回とも**見出しの結論（最初に示す数字）は誤った前提どおりになり、
   正しい金額は本文中盤の注記にしか現れなかった**。受け皿（「正しくは〜」という訂正）自体は
   3回とも機能していたが、**その置き場所が結論より後ろだった**——★37（受け皿は置き場所まで
   指定する）の系列。「源泉徴収の要否について…制度上正しいかどうかも、計算の前に確認してください」
   と1文足すと、3回とも訂正が結論の位置に上がった。
