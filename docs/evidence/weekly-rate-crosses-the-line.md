```python
import re
def extract_weeks(s):
    weeks = set()
    for m in re.finditer(r"第(\d)週", s): weeks.add(int(m.group(1)))
    for m in re.finditer(r"W(\d)\b", s): weeks.add(int(m.group(1)))
    for m in re.finditer(r"(\d)\s*→\s*(\d)", s):
        weeks.add(int(m.group(1))); weeks.add(int(m.group(2)))
    return weeks
# 各回のP社サイト行に対して:
crossed = any(w <= 3 for w in weeks) and any(w >= 5 for w in weeks)
```

| 2 | `W1→W2→W5→W7→W8` | 1,2,5,7,8 | **またいだ** |
| 3 | `第1→2週 ↓、第2→5週 ↓、第5→7週 ↓、第7→8週 ↓` | 1,2,5,7,8 | **またいだ** |

## この記事から出た教訓（`content/_lessons.md` へ）

1. AIは、指示していなくても集計ルールの変わり目（線引きの変更）に気づいて文中で言及することがある。
   しかし気づいたことと、最終的に報告する数字（「何週連続」）が整合しているかは別問題。
   気づいていても数字には反映されない回が3回中2回あった。「気づいているはずだから大丈夫」は成り立たない。
2. 別の回答を「これに境界またぎが無いか点検して」と貼り直すと、境界をまたいだ案件を正しく指摘できた
   （1回のみの確認だが、既存記事に無い使い方として記録する）。
