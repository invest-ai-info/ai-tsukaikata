## Phase5. 参考データをもとに、仕入れ値・手数料・配送料込みの利益を計算させる ― 2回

### 送った指示文（記事と同一文字列。Phase3・1回目の続きとして送った）

```

```

- 配送料: 380円
- 手数料と配送料を引いた受取額: 2,200円 − 220円 − 380円 = 1,600円
- 仕入れ値3,000円との差額: 1,600円 − 3,000円 = −1,400円（1,400円の損失）

配送料: 380円

**採用。** 2回とも計算は正しく、渡していない費用を勝手に追加することもなかった。

### 照合（機械）

```
金額（円を表す数値表現）が含まれているか: 1回目=なし 2回目=なし
合計: 0/2 で金額が出た（Phase4では2回中1回、求めていない金額5,000〜15,000円が出ていた）
```

### 判定

**採用。** Phase4の文面に「このデータに無い商品については、一般的な相場の推測も含めて、金額を一切言わないでください」を加えると、2回とも金額は0件になった。Phase4で1回だけ出ていた「求めていない一般知識の金額」の漏れが、この1文で塞がった。

## この記事から出た教訓（`content/_lessons.md` へ）

1. 「わからなければ具体的な金額を言わずに」という受け皿を足すと、金額の作り話は4回中4回で0件になった。ただし受け皿の外（金額以外の根拠のない定性的な断定）は1回だけ漏れた（★1の系統の再発）。
2. 根拠のないデータ（渡していない商品）について聞かれても、渡した参考データが別カテゴリだと正しく認識し、その数字を誤って転用した回は0件だった（2/2）。一方で、求めていない一般知識の金額を自発的に追加する動きは、データの有無や関連性と関係なく残った。
3. 「推測か実データかを先に明記して」という指示は、金額そのものを止めずに出どころを可視化する効果があった（2/2）。Phase2（金額を止める）と使い分けられる。
