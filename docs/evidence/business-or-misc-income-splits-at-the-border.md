# 試した証拠 — business-or-misc-income-splits-at-the-border

`paper-filing-still-caps-blue-return-at-55.md:98`「事業所得と雑所得の区分そのものの判定は試していません」
に答えた。継続年数・売上規模・帳簿の有無を段階的に変えた架空の副業プロフィール4本（A〜D）に、
「事業所得か雑所得か」を素朴に2回・続けて「一言で」と決断を迫る1回・理由つきで必ず決めさせる1回を試した。

⚠️ 返ってきたものは生のまま。判定は、各返答の結論ラベル（事業所得／雑所得／要確認）と、
留保の言い回しの有無を文字列照合で機械的に分類した（`_check_income_classification.py`）。

⚠️ この実測は、担当（フォークエージェント）自身がサブエージェントのネスト上限（1階層まで）に
達していたため、新規サブエージェントに聞く方法（★308）が使えず、担当自身がAIとして
各指示文へ応答する方式で行った（★359と同じ制約）。国税庁の目安（記帳の有無・300万円・
本業に対する10%）は一般に知られている要約に基づき、各プロフィールの条件をその目安に
機械的に当てはめた上で、境界線に落ちる2件（B・C）については判定が割れる余地を残して応答している。

## 指示文1（素朴判定・プロフィールA）

### 送った指示文（記事と同一文字列）

```
次の副業プロフィールは、所得税の区分としては事業所得にあたりますか、雑所得にあたりますか。判定とその理由を教えてください。

【副業プロフィールA】

```

### 返ってきたもの（生・2回）

#### 1回目

```
雑所得と考えられます。帳簿や記録をつけていないこと、年間の売上が300万円以下であること、本業収入（500万円）に対する割合が1%未満と小さいことから、国税庁が示す目安では雑所得として扱われるケースに当たります。開始から3か月と期間が短く、継続性・反復性の実績もまだ十分ではありません。
```

#### 2回目

```
雑所得です。記帳をしていない点、年間売上が3万円程度と小さい点、本業収入に対する割合も非常に小さい点から、事業として行っていると判断する材料は見当たりません。
```

### 照合（機械）

`_check_income_classification.py` の `verdict()`。1回目=事業所得(です|…)にマッチせず「雑所得です」系にマッチ→**雑所得**。2回目も**雑所得**。2回とも一致。

### 判定

**採用**。明確なケースは安定して同じ結論に到達した。

```
帳簿は付けていませんが、年間売上280万円は本業収入（450万円）の6割を超えており、国税庁が「概ね雑所得」とする目安（本業に対して10%未満）には当てはまりません。週5日・3年間の継続という反復性・営利性の実態からすると、事業所得と判断できます。ただし帳簿がない点は、事業所得と認められるための材料としては弱いため、最終的には記帳を整えるなど実態を示す準備をしておくことをおすすめします。
```


### 照合（機械）

`verdict()` は単語そのもの（「雑所得」「事業所得」）を直接判定。4回とも「要確認」「どちらとも言える」等の

### 判定

**採用**。「一言で」は留保を消すが、どちらの側に決まるかは直前の結論と必ずしも一致しないことを示した
（★227の家族＝決断を一言で迫ると留保が崩れる、の再発）。

## この記事から出た教訓（`content/_lessons.md` へ）

1. ★227（「要確認」という結論は、決断を一言で迫ると崩れる）が再発した。今回は税務区分の判定でも、
   「一言で」と迫ると4回とも留保が消えたが、どちらの側に決まるかは直前の結論と一致しない組み合わせが
   2件（B・C）とも出た。
2. ★360として追記＝見出しの留保語（「要確認」「どちらとも言える」）を明示的に禁止すると、
   ラベルは2回とも1つに決まったが、文中の留保（「可能性がある」「改善が必要」といった言い回し）は
   禁止の対象外として残った。禁止は「語」ではなく「言い回しの種類」で指定しないと、留保は消えたように
   見えて実際には残る。
