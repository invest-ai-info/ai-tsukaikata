## 100行の生成コード（`gen.py`。材料A・Bの全文はこのコードの出力として再現できる）

```python
import datetime

clients_a = ["C社", "D社", "E社", "F社", "G社"]
tasks_a = ["記事の下書き", "打ち合わせメモ起こし", "修正対応", "請求書の作成", "資料のチェック", "取材メモの整理"]
durations_a = [30, 45, 60, 75, 90, 120]

shops_b = ["スーパーやまと", "ドラッグストアみどり", "書店きたむら", "コンビニひまわり", "八百屋さくら"]
items_b = ["食料品", "日用品", "書籍", "雑貨", "野菜"]
amounts_b = [860, 1280, 1650, 2140, 980, 3200]

def gen_rows(n, end_date, clients, tasks, durs):
    rows = []
    start = end_date - datetime.timedelta(days=n - 1)
    for i in range(n):
        d = start + datetime.timedelta(days=i)
        c = clients[i % len(clients)]
        t = tasks[(i * 2 + 1) % len(tasks)]
        dur = durs[(i * 3 + 2) % len(durs)]
        rows.append(f"{d.isoformat()} / {c} / {t} / {dur}分")
    return rows

def gen_rows_b(n, end_date, shops, items, amts):
    rows = []
    start = end_date - datetime.timedelta(days=n - 1)
    for i in range(n):
        d = start + datetime.timedelta(days=i)
        s = shops[i % len(shops)]
        it = items[(i * 2 + 1) % len(items)]
        amt = amts[(i * 3 + 2) % len(amts)]
        rows.append(f"{d.isoformat()} / {s} / {it} / {amt}円")
    return rows

end = datetime.date(2026, 7, 31)
rows_a = gen_rows(100, end, clients_a, tasks_a, durations_a)
rows_b = gen_rows_b(100, end, shops_b, items_b, amounts_b)
# アノマリー版は rows[-2]（2026-07-30）だけをカンマ区切りへ差し替える
```

## この記事から出た教訓（`content/_lessons.md` へ）

1. ★31系列の再発＝1日目にそろう／そろわないが決まると、2日目はその結果を自分から踏襲する
   （材料も指示文も変えていないのに、1日目の運だけで2日目の運命が決まる。4系列中4系列で再現）。
2. 新規＝**見本の行数を増やしても的中率は上がらない。むしろ下がりうる**。元記事（daily-append-same-shape）
   の「お手本1行・書式無指定」は12回中12回だったが、見本を100行に増やした同条件は4回中3回だった。
   `dummy-row-holds-real-row-breaks` が見つけた「副業の作業記録＋実データ見本1行だけ4回中0回」の
   崩れ方と、材料A・無指定という条件が重なっている（同じ材料が繰り返し崩れやすい）。
3. 新規＝**1行だけ形の違う行を履歴に混ぜると、的中率はさらに下がる**（4本中1本）。ただしAIが
   その乱れた行の形（カンマ区切り）を新しい行にコピーすることは1回も無かった（4回とも、
   多数派の形に従うか、素の走り書きのまま貼るかのどちらかだった）。
4. 新規＝**点検専用の別会話に「形がそろっていない行を挙げて」と頼む検査は、100行規模のファイルでも
   機能した**（3系列・正解6件・誤検知0件）。崩れを自動で直させるのではなく、人に戻す設計として有効。
