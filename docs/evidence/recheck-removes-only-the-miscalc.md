## 指示文C（検算・出力形式を「確定した号だけの一覧」に変える）— 誤検知ありの指摘結果に対して

### 送った指示文（記事と同一文字列）

```
以下は、下書き一覧の内容確認で指摘された結果です。指摘した号だけを対象に、金額や日付の計算をもう一度やり直して確認してください。計算が合っていた号（＝指摘が正しかった号）だけを、番号をカンマ区切りで1行にまとめて出力してください。それ以外は書かないでください。
```

（教材Aの12件と、2回目の指摘結果5件＝No.1の誤検知を含む、を添えて送った）

### 返ってきたもの（生）

```
4,8
```

### 照合（機械）

```
誤検知(No.1): 一覧に含まれない＝正しく除去。
本物の欠陥{4,8,11}: 出力は{4,8}のみ。No.11が理由なく脱落（2/3のみ生存）。
No.6（スタイル指摘・本物の欠陥ではない）も出力に含まれず。
```

### 判定

**採用（言い直し方の材料として）。**号ごとに「正しい・誤り」を書かせた指示文A・Bでは11号は残ったが、
「計算が合っていた号だけを一覧で」という出力形式に変えたところ、計算ではなく文言確認だった11号が
暗黙のうちに対象外にされた。**検算そのものではなく、出力させる形によって結果が変わることを示す証拠。**
記事の「うまくいかないときの言い直し方」と「応用・次の一手」に、この結果をそのまま使う。

## この記事から出た教訓（`content/_lessons.md` へ）

1. AIの指摘（誤検知の疑いがあるもの）に対して「指摘した号だけ、計算をもう一度やり直して確認して」
   と検算を頼むと、この材料・4回では、本物の欠陥（計算で白黒つくもの）は1件も消えず、
   計算ミスによる誤検知だけを正しく取り下げられた。念押しの強さ（「計算をやり直して」の有無）
   による差は、この4回では出なかった。
2. ただし検算の出力形式を「号ごとに正しい・誤りを書く」から「確定した号だけの一覧を出す」に
   変えると、計算とは呼べない種類の指摘（文言の不一致）が、理由なく一覧から消えた。
   **検算という対策が効くかどうかは、対策そのものだけでなく、出力させる形にも左右される。**
