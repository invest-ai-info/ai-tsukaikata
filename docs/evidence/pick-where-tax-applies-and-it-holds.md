## 教材（架空データ）

**仕込み＝**前作と同一の2材料（契約額92,000円は共通・税抜税抜きは明示しない）。

- 材料1（段階制・クラウドワークス型）：システム利用料は契約金額10万円以下の部分に20%、
  10万円超20万円以下の部分に10%
- 材料2（一律・ランサーズ型）：システム利用料は契約金額（税込）に対して一律16.5%

## 📌 正解の算出（Pythonで先に計算。本文の判定基準）

2つの指定の意味を、次のとおり定義してコードで計算した。

```python
def fee_tiered(base):
    """段階制：10万円以下20%・10万円超20万円以下10%"""
    if base <= 100000:
        return base * 0.20
    return 100000 * 0.20 + (base - 100000) * 0.10

contract = 92000
tax = 0.10

# 指定A＝消費税は契約額全体にかけて、そのあとで手数料率を当てはめる
gross = contract * (1 + tax)                 # 税抜き起点＝契約額全体に税を足してから手数料を当てはめる
feeA_from_gross = fee_tiered(gross)
takeA_from_gross = gross - feeA_from_gross    # = 81,080円（材料1）／84,502円（材料2・率16.5%）
feeA_from_contract = fee_tiered(contract)
takeA_from_contract = contract - feeA_from_contract  # = 73,600円（材料1）／76,820円（材料2）

# 指定B＝消費税は手数料自体にだけかける（契約額には触れない＝常に92,000が基準）
fee_base = fee_tiered(contract)
fee_with_tax = fee_base * (1 + tax)
takeB_with_tax = contract - fee_with_tax      # = 71,760円（材料1）
takeB_without_tax = contract - fee_base       # = 73,600円（材料1）
```

| | 材料1（段階制） | 材料2（一律16.5%） |
|---|---|---|
| 指定A・契約額全体に税を足した側 | **81,080円** | **84,502円** |
| 指定A・足さない側 | **73,600円** | **76,820円** |
| 指定B・手数料に税を足した側 | **71,760円** | 75,302円（後述のとおり材料2は揺れた） |
| 指定B・足さない側 | **73,600円** | 75,302円（同上） |

⚠️ **この「正解」は、2つの指定文をこう読んだ場合の定義であって、唯一の読み方ではない。**
下の指示文2（材料2・指定B）では、AI自身がこの定義と異なる、もう一つの自然な読み方
（税抜きの場合は契約額自体も1.1倍して101,200円を基準にする）を一貫して採用した。
**判定は「この正解と一致したか」ではなく、「主回答が5回とも同じ2つの金額・同じ組み合わせで
安定したか」と「指示していない金額が追加で出てきたか」の2本に分けた**（理由は後述）。

### 返ってきたもの（生）— turn2_1（全文）

```
はい、かけました。②（税抜の場合）で、92,000円に10%をかけて101,200円にしています。

**理由**
手数料は「契約金額（税込）」に対して16.5%かかる、という条件でした。92,000円が税抜なら、手数料の基準になる税込額が必要です。そのため、手数料の基準額を作る目的でだけ92,000円に消費税を加算しました。

**ご指示との食い違い**
「消費税は手数料自体にだけかけてください」という指示とは食い違っている可能性があります。さらに、②の手取りも税込額の101,200円から手数料を引いて出しているので、契約金額への消費税が結果に入り込んでいます。

**訂正**
前回の補足で、契約にかかる消費税を「10,000円」と書きましたが、正しくは9,200円です。納税分9,200円を差し引くとすると、②の手取りは73,633円になります。

**92,000円に消費税をかけない場合**
92,000円をそのまま手数料の基準にすると、手数料は15,180円、その消費税は1,518円で、合計16,698円です。手取りは75,302円になり、①と同じ結果です。

どちらの解釈が意図に近いか教えてください。それに合わせて整理し直します。
```

## この記事から出た教訓（`content/_lessons.md` へ）

1. 新しい観察＝「消費税をどこにかけるか」を1つ指定すると、前作（`take-home-repeat-no-split`）で
   1回の返りに3種類の金額が混ざっていた段階制の材料が、**20回中20回とも、主回答が同じ2つの金額に
   完全に収まった。**しかも段階制（材料1）は10回とも、指示していない代替の読みや納税後の金額が
   1つも付かなかった。
2. ★26番の系列が再発した（一律16.5%・材料2）。主回答自体は10回とも安定したのに、**10回中7回は
   「16.5%がすでに税込み料率だったら」「納税後の実質手取りは」という、聞いていない代替の数字が
   追加で出た。**材料1では0回だった現象が、対照のつもりで置いた材料2だけで繰り返し起きた。
   安定しているかどうかと、聞いていない数字が付いてこないかどうかは別の軸として確かめる必要がある。
3. 新しい観察＝指定文（指定B）は「消費税は手数料自体にだけかける」としか言っていなかったため、
   「税抜きの場合に契約額自体を1.1倍するかどうか」という、担当も指定文も触れていない当てはめ先が
   残っていた。AIは材料2でこの未指定の部分を、5回とも同じやり方（契約額も1.1倍する）で埋めたが、
   担当が最初に立てた「正解」の定義とは異なっていた。**1つ指定しても、指定文が触れていない隣の
   当てはめ先にまだ曖昧さが残ることがある。**
4. 新しい観察＝その食い違いを直接聞くと、3回とも「かけました」「指示と食い違っています」と
   自分から正確に言語化し、指定文どおりに読んだ場合の計算（両ケースとも同額になる）まで示した。
   ただし、この気づきは最初の回答には一度も出てこない（指示文4・5の計8回で、自分から食い違いを
   指摘した回は0回）。**指定した内容が意図どおりに読まれたかは、黙って信用せず、別の質問で
   確認する必要がある。**
