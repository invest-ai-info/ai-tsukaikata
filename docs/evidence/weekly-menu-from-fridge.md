### 照合（Python）

```
手持ちの使用: 9/15品  ★残 にんじん 玉ねぎ ピーマン 牛乳 ミックスベジタブル 食パン
えびアレルギー: ★違反（水曜にえびのチリソース）

予算3,000円への言及: ★なし

使わなかったものの明示: ★なし
在庫の残量表: ★なし

```

### 判定
**記事の出発点にした。**発見は3つ。

1. 🚨 **えびアレルギーが守られなかった。**条件として渡してあるのに、水曜に
   えびのチリソースが入った。**献立そのものは読んでもおかしくない**ので、
   自分で条件と照らし合わせるまで気づけない
2. **手持ち15品のうち6品が使われずに残る**（牛乳のような日持ちしないものを含む）
3. **買い足し13品目に金額がゼロ。**「3,000円以内」と伝えてあるのに、
   予算内かどうかを判断する材料が返ってこない

📌 **消費期限だけは偶然守られていた**（豚こまが2日目）。**今回は守られたというだけ**で、
指示していないので次も守られる保証はない。記事では「守られた」とは書かず、
期限を明示的に指定する指示文（§6）を載せた。

## 指示文C〜P

記事§8（1日分だけ先に作らせる）・「言い直し方」5件・「応用」2件は同じ教材で順に実行し、
意図どおり動いたため**採用**。特記事項は2つ。

- **家にない調味料**（「言い直し方」1つ目）＝あるものを列挙しただけでは「これしかない」と
  伝わらない。オイスターソースなど渡していない調味料が当然のように出た。
  **「勝手に『家にあるはず』と仮定しないでください」**まで書いて止まった
- **却下されたぶんの作り直し**（「言い直し方」5つ目）＝「月曜と木曜を変えて」だけだと
  **7日分すべてが作り直され、在庫の計算も変わった**。「残りの5日はそのままで、
  在庫の計算だけやり直して」と**変えない範囲を明示**して直った

## この記事から出た教訓（`content/_lessons.md` へ）

1. **★1（禁止は受け皿と対で）が再発。**「20分以内」だけだと守れない日も20分と書かれる。
   「収まらない日は、なぜ収まらないかを書いて」を足すと**本当の40分**が返った
2. **2番（範囲は種類の一覧で）が再発。**「条件」を文章で渡すと埋もれる。
   **箇条書きで復唱させてから作らせる**と守られる
3. **新規＝作らせる前に「まだ作らないでください」で条件確認を挟む。**
   これが無いと確認工程そのものが飛ばされる（AIは成果物を先に出したがる）
4. **新規＝安全に関わる条件（アレルギー等）は、他の条件と並べない。**
   並べると同じ重みで扱われる。「他のどの条件よりも優先」と単独で渡す
5. **5番（単一条件で抜かせると隣接が落ちる）の親戚**＝「あるもので作って」は
   使えるものを選ぶだけで、**使わなかったものは報告されない**。
   在庫の残量表を出させると初めて見える
