## 真値（国税庁の制度に基づく）

青色申告特別控除は3段階。

- **10万円**＝正規の簿記の原則（複式簿記）でなくてもよい場合（簡易簿記・単式簿記）
- **55万円**＝①複式簿記で記帳 ②損益計算書・貸借対照表を添付 ③法定期限内に申告
- **65万円**＝55万円の3条件に加えて、**④e-Taxによる電子申告 または 優良な電子帳簿保存（事前の届出必須）のいずれか一方を満たす**

④が無いと、①②③だけでは**55万円で止まる**。「パソコンに会計データを保存している」ことは
④の「優良な電子帳簿保存」とは別物（届出・訂正削除履歴の確保等の追加要件がある）。

## 指示文5（罠2＝会計ソフトでパソコンに保存＝電子帳簿保存と取り違えないか）

罠1より一段意地悪な条件。「データをパソコンに保存している」という、電子化しているように
聞こえる記述を足して、優良な電子帳簿保存（事前届出・訂正削除履歴の確保等の要件）と


### 返ってきたもの（生・3回とも要旨）

1回目: 「いいえ、その条件だけでは65万円にはならず、55万円になります」。「単に『データをパソコンに保存している』だけでは不十分（届出や訂正履歴機能などの追加要件が別途必要）」と明記。
2回目: 「いいえ、65万円には**なりません**」。「単にクラウドや会計ソフトでデータ保存しているだけでは自動的には認められません」と明記。

### 照合（機械）

```

```

### 判定

**採用**。「電子化っぽい記述（パソコンに保存）」を足しても、3回とも「優良な電子帳簿保存」の
