## 素材メモ（全文）

```
【発表メモ】部会で提案したいこと（15分・営業部 佐藤）

・いまの在庫確認が電話とFAX。倉庫に電話して在庫を聞いて、紙に書いて、client に折り返す
・1件あたり平均12分かかっている。1日およそ20件なので、1日4時間が在庫確認に消えている
・先月、二重販売が3件発生した。電話で「在庫あり」と聞いた5分後に、別の営業が同じ商品を売った
・二重販売のうち1件は、client に謝罪訪問。部長が同行した
・倉庫側も困っている。1日60本くらい電話が鳴って、フォークリフト作業が止まる
・提案：共有の在庫表をクラウドに置いて、営業がその場で見る
・費用は月8,000円くらい。倉庫のタブレット2台が別途15万円
・倉庫の田中さんは「入力が増えるだけでは」と反対している
・入力は今も紙の在庫票に書いているので、書く先が変わるだけ、というのが自分の考え
・他社（同業のB社）は3年前に導入済みと聞いた。ただし詳細は未確認
・まず1か月、A倉庫だけで試したい
・試すのに必要なのは、倉庫のタブレット1台とアカウント3つ
・効果の測り方：在庫確認1件あたりの時間と、二重販売の件数
・部長には事前に話してある。「部会で反対が出なければ進めてよい」と言われた
```

⚠️ **仕込みを2つ入れてある**（測れるようにするため）:
- **未確認情報**＝「B社は3年前に導入済みと聞いた。ただし詳細は未確認」
- **反対意見**＝「倉庫の田中さんは反対している」


### 判定
**記事の出発点にした。**発見が3つ:

1. **箇条書き14件 → 18枚。**表紙・まとめ・ご清聴の3枚を足すとほぼ数が合う＝

2. **1〜7枚目が全部「課題」。**聞く側は何が問題なのかを7回に分けて聞かされ、
   **何を承認してほしいのかが最後まで出てこない**
3. **未確認情報がスライド12に載った。**「（※詳細は未確認）」と添えてはいるが、
   画面に出た時点で質問の対象になる

```
スライド2：先月、二重販売が3件
スライド3：倉庫も、1日60本の電話で止まっています
スライド4：提案：在庫表をクラウドに置く

  質問が出たら「聞いた話で、裏は取れていません」と答えます。
```

### 照合（Python）
```

```

### 判定
**採用。**4項目すべてが動いた。🔑 **口で言うことが画面の3.9倍**になったのが本質で、
**これが「読む資料」との違いそのもの**（読む資料は書いてあることが全部。読む人がそこに
いないため）。記事の軸をここに置いた。

⚠️ **計測を1度やり直している。**最初のスクリプトは末尾の【…】ブロックを9枚目の一部として
数えてしまい、「最大175字」という誤った値を出した。**記事に載せる前に気づいて修正した**
（正しくは最大24字）。数字を出すスクリプト自体を検算しないと、記事に嘘が載る。

## 指示文C〜P

記事§1（承認してほしいことを1文で）・§6（反対意見を1枚立てる）・§7（削ったものの一覧）・
§8（時間の割り振り）、「言い直し方」5件、「応用」2件は同じメモに対して順に実行し、
意図どおり動いたため**採用**。特記事項は2つ。

- **§6 反対意見**＝「反対を1枚立てて」だけだと「ご指摘は当たりません」調の反論が返る。
  **「言い負かす形ではなく、『その通りかもしれないので、こう確かめます』の形で」**と
  受け皿を付けて初めて、反対した本人が会場にいる前提の文章になった。
  🔑 **禁止だけでは足りず、代わりにやることを渡す**——この型は**3本連続で出ている**
- **§7 削ったものの一覧**＝14件が9枚になった時点で何かが消えている。出させたところ
  「謝罪訪問に部長同行」が単独の枚から外れて口頭に吸収されていた。
  **消えたこと自体は妥当だが、判断が要るので人が見て決め直す場所**

## この記事から出た教訓（台帳へ）

1. **素材を渡して「構成を作って」と頼むと、構成ではなく転記が返る。**箇条書きの件数と
   出てきた項目数がほぼ一致したら、並べ替えられていないことを疑う
2. **量の制約は「時間」で渡すと中身が動き、「個数」で渡すと1件が重くなる。**
   （`translate-for-internal-use` の「2文に割って→3文で返る。60字以内なら守る」と同じ型。
   **これで2回目＝昇格の候補**）
3. **禁止は受け皿と対で渡す**（`quiz-yourself-with-ai`・`fix-typos-not-voice` に続き**3回目**。
   ★★ **昇格の条件を満たしている。月曜の週次で最優先**）
4. **数字を出すスクリプト自体を検算する。**計測の取りこぼしで誤った最大値が出た。
   記事に載る数字は、生成物ではなく計測器のほうを疑う
