## 核となる集計（Python・IDの集合演算）

```
p2final（書き戻し忘れ）材料A: 手動処理済み5件のうち再び対象に含まれた件数 = [5, 5, 5]（真値0）
p2final（書き戻し忘れ）材料B: 手動処理済み5件のうち再び対象に含まれた件数 = [5, 5, 5]（真値0）
```

## この記事から出た教訓（`content/_lessons.md` へ）

1. **12番が再発した（3回目・カンマ区切りの体裁）。** 「IDだけを、届いた順に並べてください」
   という指示文は改行を明示していないため、AIが改行区切りではなくカンマ区切りの1行で
   返すことがある。判定コードは「1行＝ID単独」だけでなく「行をカンマ・読点・空白で
   割って全部IDなら採用」まで広げないと、正しい返りを0件と誤判定する。
2. **12番が再発した（4回目・「次回ID」の行に含まれるIDの誤カウント）。** 新着が0件の
   ときの返りは「次回のための最新処理ID: Q-24」のように、一覧の中身とは無関係な文脈で
   IDが単独行として出ることがある（`次回のための最新処理ID:\nH-24` のように改行される
   ケースを含む）。ID正規表現を本文全体に当てると、この行のIDまで「一覧に含まれた」と
   誤カウントする。「一覧→最後に次回ID」という指示文の構造に合わせ、最初に「次回」
   「最新」を含む行より後のID単独行は除外する形に直した。
