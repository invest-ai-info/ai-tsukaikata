# 試した証拠 — second-thirty-not-new

2026-09-03 に実施。教材＝**架空の発注書2本**（★32＝材料を変えて2本）。
既存記事 `count-copy-ideas-that-pass` の勤怠アプリ・温泉旅館は**使っていない**。

**実測環境**＝担当のセッションとは別に、`claude --safe-mode --tools "" -p` を空のディレクトリで起動。
2ターン目・3ターン目は `--session-id <uuid>` で発行して `--resume` で続けた
（`--safe-mode` は CLAUDE.md・skills・過去の会話を読まない＝台帳★91／★20）。

**回数**＝
- 本編＝材料2本 × 2巡目の言い方5版 × 各2回＝**20回**（1回につき2ターン送信）
- 追加の指示文（記事§5・§6）＝材料2本 × 各2回＝**8回**（3ターン目）
- 言い直し（記事の「うまくいかないときの言い直し方」「応用」）＝**7回**（3ターン目）
- 案の総数は1・2巡目だけで**1,200案**

⚠️ 判定はすべて Python。目視では判定していない（`judge.py`＝抽出と4条件の○×、
`analyze.py`＝集計、`difflib` の類似度で「近い案」）。
🚨 **仕込み（真値）を作るコードも計測器**（台帳★24）なので、走らせる前に
「通るはずの例／落ちるはずの例」を assert で確かめてある。

## 計測器のほうを2回直している（台帳12番）

🚨 **1回目**＝案の行を「行頭に番号か記号が付いているか」で拾う作りにしたところ、
**番号も記号も付けずに30行返した回**（40ファイル中4ファイル）が**まるごと0案**と表示された。
「印があるか」ではなく「地の文でないか」で決める形に直した。

🚨 **2回目**＝太字の見出し行が、先頭の `*` を箇条書きの記号と誤認して**案として1件数えられた**
（該当2ファイルで31案と表示）。太字記号を先に外し、見出しらしい語
（「キャッチコピー」「◯案」で終わる行）を落とす形に直した。

→ 直したあと、**40ファイルすべてがちょうど30案**になった（この一致自体が計測器の検算になっている）。
どちらの誤りも `judge.py` の assert に足してある。
