2026-08-17 実施。**架空の「私ができること7件」と「私がもう決めていること3件」**を材料に、
引き受ける範囲の表を作らせた。材料は**種類の違うものを2本**（A＝Webライティング、
B＝資料作成の代行）用意し、指示文1〜4と7は**材料2本 × 各2回＝4回**、
指示文5・6は**材料2本 × 各1回＝2回**。合わせて **24回**。

- 実測用のセッションはすべて新規のエージェント。⚠️ 台帳★20 のとおり「事前知識なし」ではないので、
  結論は**機械照合できる結果だけ**に置いた＝材料に無い数量の出現、〔私が決める〕の印の数、
  除外の項目行の数、判定列の値。

### 補足を2つだけ

**公開ボタンを自分で押さない**のは、意図してそうしています。押した瞬間に「公開されたページの責任」が自分側に寄ってくるためです。入稿までを自分の仕事、公開の判断を発注側の仕事、と分けておくと、内容の当たり外れの話に巻き込まれにくくなります。

**写真の4番が一番あぶない**項目です。素材の商用利用可否を確認する責任が誰にあるかを書いていないと、後から権利の話になったときに、選んだ人＝自分に来ます。「無料素材サイトと支給素材のみ」と範囲を狭く書いておくのは、手を抜くためではなく、確認できる範囲だけを引き受けるためです。
```
### 返ってきたもの（生）— P1_A_r2
```
7つとも「できること」として挙がっているので、**やる/やらない**ではなく **「基本料金に含む」/「別料金のオプション」** で分けました。全部を同じ料金に入れると、写真と図と入稿で時間を持っていかれて時給が崩れます。

## すでに決めている3つに、但し書きを足しておく

決めた数字そのままだと、あとで解釈がずれます。足すのは一文ずつです。

- **納期7日** → 起点は「発注日」ではなく **「テーマ・文字数・参考情報が揃った日」の翌日から7日**。材料待ちの日数を自分の納期から引かれないため。
- **修正2回** → 1回＝**まとめて届いた指摘のかたまり**。日をまたいで小分けに来たら、それぞれ1回と数える。3回目以降は1回いくら、と先に書く。
- **納品後7日以内に振込** → 「納品」が何を指すかを決める。**下書き保存を終えて完了報告を送った時点**を納品にする。相手が公開するまで待つ形にすると、先方の都合で入金が止まります。

## 表に入れていないが、必ず聞かれること

7項目のどこにも入っていないので、先に決めておくと楽です。

- **写真の権利**：素材サイトの規約に沿って選ぶところまでが自分の責任。掲載後に権利の問題が起きたときの補償はしない、と書いておく。
- **WordPressの権限**：預かるアカウントは「投稿者」まで。管理者権限は受け取らない（サイト全体の不具合まで疑われる立場にならないため）。
- **記事の著作権と実績公開**：納品時に著作権を渡すのか、ポートフォリオに「この記事を書きました」と載せてよいのか。

表はそのまま提案書に貼れる形にしてあります。オプション3つ（写真・入稿・図）の金額を入れれば見積もりになります。
```
### 返ってきたもの（生）— P1_B_r1
```
いただいた7項目と3つの条件で、そのまま先方に見せられる形の表にしました。

範囲の表は「やること」だけ書くと必ずもめるので、**各項目に「含まない」を並べて**あります。ここが実際の防波堤になります。

## 3. 表に足しておくと事故が減るところ

決まっていない前提で、こちらで文案を置いています。合わないところだけ差し替えてください。

**「修正1回」の数え方**
> 修正のご指摘は**まとめて1通**でお送りください。いただいた1通ぶんを「1回」と数えます。修正後に届いた追加のご指摘は2回目として扱います。

これが無いと、思いつくたびに1行ずつ届いて実質無制限になります。**回数を決めるより、数え方を決めるほうが効きます。**

**支給していただくもの**
> 手書き下書き、グラフの元データ、指定の素材（ロゴ・写真）、社内のフォーマットがあればその資料。

7日の納期は材料が揃ってからの7日です。**支給待ちの日数は納期に含めない**と書いておかないと、待たされたぶんが自分の遅れになります。

**範囲外と明記しておくもの**
> 内容の企画・調査、文章の執筆、数値の集計と検証、印刷の手配、当日の運営、緊急対応（3日以内の納品）。

1〜7を見ると、**すべて「材料はもらう、形にするのが自分の仕事」**で揃っています。この線引きがきれいなので、「中身を考える仕事は受けない」と一言添えると全体の説明になります。

**まだ空欄なところ**
料金と、その料金が「1件」なのか「スライド1枚」なのかの単位が入っていません。ここは範囲の表と同じ紙に載せておくと、後から「この作業は料金に入っていたのか」の話にならずに済みます。
```
### 返ってきたもの（生）— P1_B_r2
```
いただいた7項目を、作業の流れ順に3区分でまとめました。

## 依頼者側に用意してもらうもの

範囲表とセットで先に伝えておくと、納期の遅れが自分のせいにならなくなります。

- 手書きの下書き
- グラフの元になる数値（表計算ファイルなど）

## このままだと揉めやすい5点

材料の中で、境界が決まっていない箇所です。決め方の案も入れてあります。

**1. 7番と「修正2回」の関係**
発表後の修正が2回に含まれるのかが読み取れません。→ 納品前の修正2回とは別枠にして、発表後の修正は1回・納品から14日以内、と分けるのが分かりやすいです。

**2. 納期7日の起点**
