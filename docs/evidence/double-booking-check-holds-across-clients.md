## 真値（算数で確認）

### 材料1（クライアントA・B・C、2026-11-10）

既存: A 10:00-11:00／B 13:00-14:30／C 15:00-15:30

```python
def overlap(a_start, a_end, b_start, b_end):
    return a_start < b_end and b_start < a_end

existing = [("A", 600, 660), ("B", 780, 870), ("C", 900, 930)]  # 分（0:00基準）
candidates = {1: (540, 600), 2: (630, 690), 3: (810, 840), 4: (870, 900), 5: (960, 1020)}
for i, (s, e) in candidates.items():
    hits = [name for name, es, ee in existing if overlap(s, e, es, ee)]
    print(i, hits)
# 1 []  2 ['A']  3 ['B']  4 []  5 []
```

正解: **開いている = 候補1・候補4・候補5／重複 = 候補2(A)・候補3(B)**

### 材料2（クライアントD・E・F、2026-11-12・境界をまたぐ候補あり）

既存: D 09:00-09:30／E 11:00-12:00／F 12:00-13:00（EとFが隙間なく連続）

```python
existing2 = [("D", 540, 570), ("E", 660, 720), ("F", 720, 780)]
candidates2 = {1: (510, 540), 2: (570, 600), 3: (645, 675), 4: (705, 735), 5: (780, 810)}
for i, (s, e) in candidates2.items():
    hits = [name for name, es, ee in existing2 if overlap(s, e, es, ee)]
    print(i, hits)
# 1 []  2 []  3 ['E']  4 ['E', 'F']  5 []
```

正解: **開いている = 候補1・候補2・候補5／重複 = 候補3(E)・候補4(EとFの両方)**

### 材料1＋後出しのクライアントD（2026-11-10・候補5が追記で変わる）

材料1に「クライアントD: 16:00-16:30」を追記すると、候補5(16:00-17:00)が新たに重複になる。

正解: **開いている = 候補1・候補4のみ／重複 = 候補2(A)・候補3(B)・候補5(D・追記分)**

## 指示文6（材料1・生成形＝候補を渡さず、AI自身に空き時間を提案させる）

ここまでは「渡した候補が空いているか」を判定させていた。ここでは逆に、候補を渡さず、
AI自身に1時間の空き時間帯を3つ提案させ、提案そのものが既存の予定と重複していないかを確かめた。

### 送った指示文（記事と同一文字列）

```
下記は3名のクライアントの、2026年11月10日（火）の既存の予定です。

クライアントA: 10:00-11:00 会議
クライアントB: 13:00-14:30 会議
クライアントC: 15:00-15:30 会議

既存の予定を避けて、来客対応に使える1時間の空き時間帯を、営業時間9:00-18:00の中から3つ提案してください。
```

### 返ってきたもの（生・3回とも要旨）

1回目: 「9:00-10:00」「11:00-12:00」「16:00-17:00」を提案。根拠として空き区間（9-10・11-13・15:30-18）も明記。
2回目: 「9:00-10:00」「11:00-12:00」「16:00-17:00」を提案。同じ空き区間の根拠を明記。
3回目: 「9:00-10:00」「11:30-12:30」「16:00-17:00」を提案（2件目だけ時間帯が異なる）。

### 照合（機械）

```python
existing = [(600, 660), (780, 870), (900, 930)]
def is_free(s, e):
    return all(not (s < ee and es < e) for es, ee in existing)
# 1回目・2回目: 9:00-10:00(540,600)=free / 11:00-12:00(660,720)=free / 16:00-17:00(960,1020)=free
# 3回目: 9:00-10:00=free / 11:30-12:30(690,750)=free / 16:00-17:00=free
```

```
真値: 提案した3件とも、既存3件の予定と重複していないこと
1回目: 3件とも重複なし → 一致
2回目: 3件とも重複なし → 一致
3回目: 3件とも重複なし → 一致
判定: 3/3（提案した枠が既存の予定と重複した回は0件）
```

### 判定

**採用**。候補を渡さずAI自身に考えさせる生成形でも、提案した3件とも既存の予定と重複しなかった。
2回目と3回目で2件目の時間帯（11:00-12:00 と 11:30-12:30）が違ったが、どちらも空き区間
（11:00-13:00）の範囲内で、間違いではない。
