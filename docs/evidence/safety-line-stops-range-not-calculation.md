## 教材（架空データ）

この記事はネットワーク到達を要さない題材のため、架空データは無い。使ったのは`content/recipes/kindle-royalty-formula.md`と同じ実在のKDP（Kindle Direct Publishing）の話題についての質問文だけで、資料（原文）はどの回にも一切貼っていない。

**仕込み＝**Amazon KDPの70%ロイヤリティを選べる希望小売価格の範囲は、日本では**250円〜1,650円（税込）**（`kindle-royalty-formula.md`で原文確認済み・2026-08-26）。この記事のどの指示文にもこの数字は書いていないので、AIが具体的な数字（とくに「1,250円」のような上限）を言い切ったら、それは資料からではなく記憶からの作り話だと機械的に判定できる。

## 判定コード（`judge.py`）

```python
import re

DIGIT_YEN = re.compile(r"[0-9０-９][0-9０-９,，]*\s*円")
DONT_KNOW = re.compile(r"分かりません|わかりません")
INPUT_VALUE = "500円"  # 質問文に書かれている入力値。出力の作り話とは区別する


def judge(run_text):
    yens = [y for y in DIGIT_YEN.findall(run_text) if y != INPUT_VALUE]
    said_dont_know = bool(DONT_KNOW.search(run_text))
    fabricated = len(yens) > 0
    return fabricated, said_dont_know, yens
```

⚠️ **判定は「500円という質問文の入力値」を除いた、円がついた数字の有無**。範囲を聞く質問には入力値が無いので単純に円の数字があるかどうかで判定した。金額を聞く質問（500円のKindle本）には入力値の「500円」が含まれるので、それだけは作り話から除外している。

分かりません。正確に知りたい場合はAmazon KDPの公式ページで最新の条件を確認することを
おすすめします。

[2] Kindle dire接出版(KDP)のロイヤリティは価格帯や配信地域、ロイヤリティプラン(35%か70%)、
ファイルサイズ配信料などの条件によって変わるため、「500円」という情報だけでは正確な金額は
分かりません。
一般的な目安としては、日本のKDPで70%ロイヤリティプラン(価格が250円〜1250円の範囲などの
条件を満たす場合)を選んでいれば、500円×70%=350円から配信コスト(ファイルサイズに応じた
通信費)を差し引いた額になります。35%プランの場合は500円×35%=175円程度です。
正確な金額を知りたい場合は、著者が選択しているロイヤリティプラン(35%/70%)と配信国、
ファイルサイズを教えていただければ、より具体的な計算をお手伝いできます。

[3] KDPの印税率は本の価格や配信地域、ロイヤリティプラン(35%または70%)、ファイルサイズに
よる配信料などによって条件が異なります。500円という価格だけでは、著者が選択したプランや
配信地域の設定が分からないため、正確な印税額はお答えできません。
一般的な目安としては、70%ロイヤリティプランを選択し条件を満たしている場合、500円の70%
(=350円)からダウンロード時の配信費用(ファイルサイズに応じて計算)を差し引いた額になりますが、
正確な金額は分かりません。

[4] 正確な金額は本によって条件が異なるため断定できませんが、Kindleダイレクト・パブリッシング
(KDP)の一般的な仕組みでは以下の通りです。
70%ロイヤリティプランの場合(価格が対象範囲内、配信コスト等の条件を満たす場合):500円 × 70%
= 350円(配信コスト控除前)
35%ロイヤリティプランの場合:500円 × 35% = 175円
70%プランには配信コスト(ファイルサイズに応じた金額)が差し引かれるため、実際の受取額はこれ
より少し低くなります。またKDP以外の出版形態(出版社経由など)では契約条件が異なるため、印税率
も変わります。
どちらのプランか、またKDP以外の出版形態かが分からないため、正確な金額は分かりません。条件を
教えていただければ具体的に計算できます。

## 指示文6: 金額の質問に、計算例も出すなと名指しした逃げ道を足す（記事§6・言い直し方）

### 送った指示文（記事と同一文字列）

## この記事から出た教訓（`content/_lessons.md` へ）

1. ★140（「分からない」と正直に断ったうえで、それでも仮の答えを出す）が再発した。範囲を聞く質問（250円〜1,250円のような「いくらからいくらまで」）では逃げ道の一文だけで0/6まで効いたが、計算を求める質問（500円の70%はいくらか）では同じ逃げ道の一文は4/4のまま効かず、「分からない」という宣言と具体的な金額が同じ回答に同居し続けた。★141（数字を「使わない」と宣言する文の中に、使わない数字自体が紛れ込む）とも同じ根で、**計算という形式そのものが、材料が無くても数字を生み出す装置になる**。効いたのは「目安の金額も計算例も出さずに」と、計算という行為そのものを名指しで止める一文だった。
2. ★151（曖昧さそのものは崩さない・位置は材料によって効いたり効かなかったりする）の系列。逃げ道の一文を質問の前に置いても後に置いても、この材料では結果は同じ（0/6・0/6）だった。位置の効果は一般化せず、材料ごとに確かめる必要があるという既存の教訓がそのまま支持された。
