# 試した証拠 — simultaneous-stop-both-get-named

キュー：`content/_recipe_queue.md`「自動化・ループ優先」節「複数の処理が同時に止まったら、それぞれの
基準で両方とも名指しできるか」（2026-11-03補充）。根拠は、公開済み `four-process-log-keeps-each-own-
baseline.md` が自分で残した未測定事項「停止したのは常に1本だけです。**2本以上が同時に止まる場合は
試していません**」。実測日 2026-11-04。

実測に使ったAI＝`claude --print --safe-mode --tools ""`（Claude Code CLIを非対話モードで起動）。
`--safe-mode` は CLAUDE.md・skills・plugins・履歴を全部無効化する。1回の指示につき1つの新規
プロセスとして起動し、会話を継続しなかった（前の回の返りが次の回の判断に影響しないようにするため）。
材料（ログ本文＋指示文）は標準入力で渡した。

先行記事 `four-process-log-keeps-each-own-baseline`（2026-10-31公開）は、P1〜P4の4本を1本のログに
混ぜても「処理ごとに計算して」と頼めば、どの1本が止まっても見つかることを確かめた。ただし条件は
「止まるのは常に1本だけ」。この記事は、2本が**同時に**止まる場合に、既存の指示文のまま両方とも
漏れなく名指しできるか、片方だけ合算（のような扱い）に埋もれて見逃されないかを測る。

### ログの生成方法

日別実行回数を生成）で、21日分（2026-09-01〜09-21）の日別実行回数から、1日の中でだいたい等間隔に
