# 試した証拠 — client-reply-without-softening

発注者・取引先への返事の文面をAIに書かせたとき、**自分が先に決めた条件**がどう扱われるかを実測した記録。

⚠️ 判定はすべて Python の文字列照合。計測コードは末尾に全文を貼った。
⚠️ 台帳★20 のとおり、実測した環境はこのサイトの文脈から切り離されていない。
根拠は**機械照合できるものだけ**にした＝先に決めた文字列が文面に出るか・
先に決めたぼかし語が何件出るか・引用が原文に実在するか。

---

## この記事から出た教訓（`content/_lessons.md` へ）

1. **★38（新規）**＝**文面を整える工程で、こちらが決めた条件のほうが緩む。**

   「これより早くはできない」が「早められるよう進めてまいります」になった。
   **条件を渡した本人が読んでも、自分の条件が変わったことに気づきにくい。**
3. **12番が再発した（10本目）**＝判定記号の出現回数を全文から数えたため、
   **まとめの一行そのもの**を1件として数え、★22の再発と誤って表示した。
   **返りを疑う前に、数えたコードを読み直す。**
4. **★1の系列（新しい形）**＝受け皿を「条件の中だけ」に縛ると、
   **代案が作れない希望が残る**（4件中2件）。作れなかった2件が、
   **自分がまだ決めていないこと**の在りか。**空振りが情報になる形。**

5. **★25が再発した（2本目・新しい場所）**＝条件の部分を1文字も変えずに
   「あいさつと結びだけ柔らかく」と頼んだら、結びに
   **「公開に間に合うよう、しっかり進めてまいります」**が入った。
