## 実測のやり方

- 指示文は**すべて別々の新しいセッション**に渡した。各セッションには
  「架空の走り書き14行（＋検査するときは台本）＋指示文」だけを渡している。
- 各セッションには「答えの全文をそのままファイルに書き出してください」という
  **運搬のための一文**を足してある。これは記事に載せる指示文の一部ではない。
- 🚨 **実測環境の汚染を1つ見つけた（台帳★20の新しい形）。**
  実測用のセッションは**プログラムを実行できる環境**だったため、
  指示文2の1回目は、台詞を別ファイルに書き出して Python で数えていた（道具を14回使っている）。
  **手元のチャットAIには、ふつうその道具が無い。**そこで指示文2と5は、
  運搬側に「プログラムを書いたり実行したりしないでください。ふつうのチャットとして
  頭の中だけで答えてください」を足した回（`out2b` / `out5b`）を別に取り、両方を残した。
  ⚠️ **結果は両方とも申告字数＝実測字数だった**ので、記事では
  「字数はAIには数えられない」とは書いていない。
- **判定は機械照合できるものだけに限った**＝台詞の字数、1文の長さ、
  禁止した語の出現数、秒数の合計、走り書きに無い数字、抜き出しがもとの台本に実在するか。
  照合コードは `check.py`、出力は末尾に貼る。

## ブロック4（2:15〜3:15）しんどかったこと

**ひとつめ、夏。**シャツが汗で背中に貼りつきます。これはもう、どうにもならない。僕は途中から、会社に着替えを置くようにしました。これで解決しました。逆に言うと、着替えを置ける環境がないと、夏はけっこうきついと思います。

## ブロック5（3:15〜3:55）期待はずれだったこと

## ブロック6（3:55〜4:35）続いた理由

> ト書き：ここがこの動画の山です。声のトーンを少し落として、ゆっくり。カメラをまっすぐ見る。

じゃあ、なんで続いたのか。

お金が浮いたから、でもないです。健康のため、でもないです。痩せてないので。

続いている理由は、**電車の乗り換えが嫌いだったからです。**

これだけです。

あの、ホームで待って、人をよけて、階段を上がって、また待って、っていうのが、ずっと嫌でした。自転車は、家を出たら会社まで一本です。乗り換えがない。それだけのために続いています。

これ、1年やって一番分かったことなんですけど、**続くかどうかは、「良いこと」があるかじゃなくて、「今、嫌なこと」が消えるかどうかなんだと思います。**

健康にいいから、とか、節約になるから、っていう理由は、雨の日の朝には勝てないです。でも「乗り換えしたくない」は、毎朝ちゃんと効きます。

## 1. 用意しておくもの

### 数字まわり

走り書きの中身はほぼ数字です。ひとりで話して編集しないなら、数字は言い間違えた時点でそのテイクが終わります。

- **数字だけを大きく書いた紙**を、三脚のスマホのすぐ後ろ、目線がほとんど動かない位置に貼る。
  - 7.2km / 23分 / 去年4月 / 198日 / 電車28分 / 定期 月9,800円 / 整備 年18,400円 / パンク2回 / 雨 月4日 / 駐輪場 月3,000円
- **単位を数字とセットで書く**。特に「月9,800円」「年18,400円」「月3,000円」は、月と年が入り混じっています。ここを言い間違えると金額の話が丸ごと逆の意味になります。カンペには金額だけでなく「月／年」まで大書きしてください。
- **撮る前に一度、裏を取る。**
  - 198日を何で数えたのか（その元データを手元に出しておく）
  - 18,400円の内訳（点検とタイヤ交換の記録・レシート）
  - 定期9,800円の記録
  - 撮り終えてから「実は違った」と気づくのが、いちばん高くつく撮り直しです。

### 撮影の機材まわり

- スマホの**空き容量**と**バッテリー**（5分をワンテイクで、しかも何回か撮る前提で）
- **通知・着信をすべて切る**。5分回している最中の1回の通知で、そのテイクは捨てになります。
- **経過時間が自分から見える時計かタイマー**。5分に収めたいのに編集しないなら、話しながら残り時間が見えないと、確実に伸びます。
- **画角の確認手段**。ひとりなので、自分がフレームに入っているかを撮影中に確認できません。10秒だけ試し撮りして再生する、を毎回の位置決めのたびにやる前提で時間を見ておいてください。

### 映すなら、手元に要るもの

編集をほとんどしないということは、**後から画を足せない**ということです。何かを映すなら、撮影中に手が届く場所に置いておく必要があります。走り書きに出てくる実物は次の4つです。

- クロスバイク本体（4番）
- 会社に置いている着替え（8番）— 会社にあると書いてあるので、映すなら持ち帰りが要ります
- 冬のグローブ（9番）— 季節物なので、しまい込んでいると探す時間がかかります
- 駐輪場（12番）— 場所を映すのかどうか

映さないなら不要です。ただ「撮り始めてから、やっぱり見せたい」と思っても、その時点では取りに行くしかありません。ここは撮影前に決めておくところです。

## 2. 撮り直しになりそうな箇所

### 数字の言い間違い（可能性が最も高い）

- **月と年の取り違え**：9,800円（月）、3,000円（月）、18,400円（年）。この3つが一度に出てくる場面が必ずあります。
- **7.2kmと23分、28分**：自転車23分／電車28分は差が5分しかなく、口が滑ると逆になります。逆になると話の前提が崩れます。

### 話しながら自分で詰まる箇所

走り書きに書かれていないせいで、口に出した瞬間に「あれ、これどうなるんだ」と自分で気づいて止まる、というタイプの箇所です。事前に扱いを決めておかないと、ほぼ確実にここでテイクが切れます。

- **雨の日の電車代（7番と3番の間）**：定期はもう買っていない、でも月4日は電車に乗っている。その4日分がいくらかは走り書きにありません。お金の話をした直後にこれを言うと、自分でも視聴者でも「じゃあその分は？」となります。
- **これから始める人の初期費用（4番）**：自転車は前から持っていた、と言った瞬間に、迷っている会社員が最も知りたい「で、いくらかかるの」が宙に浮きます。走り書きに購入費はありません。話している最中に気づいて、その場で当てずっぽうを言い始めると、そこから戻れなくなります。
- **198日の分母（2番）**：198日と言えば「1年の通勤日のうち何日？」が即座に浮かびますが、分母は書かれていません。
- **「1年」がいつまでか（2番）**：去年4月に始めて1年、とだけあります。締めがいつか、そして今も続けているのかは書かれていません。ここが決まっていないと語尾（「でした」か「です」か）が毎回ぶれます。
- **パンク2回のあと（6番）**：どちらも帰り道だった、と言うと、その日どうやって帰ったかが自然に続きますが、走り書きにありません。
- **会社に駐輪場がない話（12番）**：自分の会社の事情を話したあと、「みなさんの会社も」と一般化しに行こうとして、根拠がないので止まる、という形になりやすい箇所です。

### 話の立ち位置が揺れる箇所

- **10番・11番（体重は変わらない／よく眠れる気はするが測っていない）**：健康効果を期待している視聴者に対して、片方は否定、片方は根拠なしの主観です。ここで言い訳を足しにかかると長くなり、時間も足りなくなります。どこまで言うかを決めておかないと、言い直しが増えます。
- **13番（事故は無い／路肩の車がこわい）**：安全の話は言葉を選ぼうとして詰まる典型です。勧めるのか勧めないのかの立ち位置が決まっていないと、ここで急に慎重な口調になり、前後とトーンがつながらなくなります。
- **14番（続いている理由は乗り換えが嫌いだから。健康のためではない）**：これは実質的な結論です。最初に言うか最後に言うかを決めていないと、話の途中でうっかり先に言ってしまい、終盤が繰り返しになります。

### 尺

- 項目が14個、尺が5分。単純に割ると1項目20秒です。**最初のテイクはまず間違いなく5分を超えます**。超えたと気づいてから後半を早口で詰めると、そのテイクは使えません。何を落とすかを先に決めていないと、この撮り直しは何度でも起きます。
- **冒頭の入り**（誰に向けた何の話か）は、毎回撮り直しの筆頭になる場所です。ここだけ何回か試してから通しに入るほうが早いです。
