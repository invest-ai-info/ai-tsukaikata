# 試した証拠 — hourly-rate-from-your-own-log

副業の作業記録から時給と偏りを出すとき、AIに何をやらせて何をやらせないかを実測した記録。

⚠️ 判定はすべて Python。**真値は記録から計算した**（手で書いていない＝台帳12番・★24）。
⚠️ 台帳★20 のとおり、実測した環境はこのサイトの文脈から切り離されていない。
根拠は**機械照合できるものだけ**にした＝真値との一致・行の被覆・2回転の突き合わせ。

---

## 指示文1

### 送った指示文（記事と同一文字列）

```
副業の作業記録と、案件ごとの報酬を貼ります。この記録から、案件ごとの時給を出してください。
```

### 返ってきたもの（生）

```
作業記録をもとに、案件ごとの時給を算出しました。

| 案件 | 報酬 | 作業時間 | 時給 |
|---|---|---|---|
| A社サイト | 48,000円 | 800分（13時間20分） | 3,600円 |
| B社バナー | 12,000円 | 155分（2時間35分） | 4,645円 |
| C社ロゴ | 30,000円 | 715分（11時間55分） | 2,517円 |
| D社 | 0円 | 130分（2時間10分） | 0円 |
| E社記事 | 8,000円 | 205分（3時間25分） | 2,341円 |

全体では、報酬98,000円 ÷ 2,005分（33時間25分）＝ 時給 約2,933円 です。

■ 気づいた点
・B社バナーの時給がもっとも高く（4,645円）、E社記事がもっとも低い（2,341円）結果になりました。
・C社ロゴは修正に290分（130＋85＋75）かかっており、制作200＋165分と合わせると715分です。修正の割合が大きい案件です。
・D社は提案に130分かけて報酬が発生していないため、時給は0円となります。
・E社記事は単価に対して制作時間が長く、今後同種の案件を受ける際は単価の見直しを検討されるとよいかもしれません。

なお「（案件なし）」の事務作業75分は、特定の案件に紐づかないため上表には含めていません。
```

### 照合（機械）

```

A社サイト        800        800     ○     3,600      3,600     ○
B社バナー        155        155     ○     4,645      4,645     ○
C社ロゴ         715        715     ○     2,517      2,517     ○
D社           130        130     ○         0          0     ○

返事の全体行: ['全体では、報酬98,000円 ÷ 2,005分（33時間25分）＝ 時給 約2,933円 です。']

案件なしの事務: 真 75分 ／ 返事に書かれた分数: ['75']

線引き（何を含めたか）を返事が書いているか: ★書いていない
```

### 判定

**採用**（記事の起点）。🚨 **計算は5案件とも真値と完全一致**（分数も時給も全体も）。
台帳6番（AIの計数は当てにならない）は**再発しなかった**。
🚨 **合っていないのは「何を含めたか」のほう**＝どの種類の作業を案件の時間に入れたかが、
どこにも書かれていない。実際は6種類すべてを入れている（＝いちばん低く出る線引き）。
読む側は、それが選ばれた1つの答えだと思って受け取る。
