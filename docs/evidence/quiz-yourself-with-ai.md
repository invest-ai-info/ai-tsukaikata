# 試した証拠 — quiz-yourself-with-ai

2026-08-11 に実施。教材＝架空の「経費精算規程（2026年4月1日改定）」全7条。
条ごとに数値を持たせ、**5,000円を第2条（領収書の線）と第3条（会議費の上限）の
2か所に置いて**、混同が起きるかを見られるようにした。

⚠️ 返りは生のまま。判定に使った照合は Python で行い、結果も併記する。

## 教材（全文）

```
第1条（申請期限）支出日から30日以内。超過時は所属長の理由書を添えて60日以内まで。
第2条（領収書）5,000円以上の支出は原本。5,000円未満は画像可。
             交通系ICの利用履歴を提出する場合、金額にかかわらず領収書は不要。
第3条（会議費）参加者1人あたり5,000円を上限。超える場合は事前に部長の承認。
             いずれの場合も参加者名簿を添付。
第4条（出張日当）日帰り1日2,000円、宿泊を伴う場合1日3,500円。領収書不要。
第5条（前払金）支出見込額10万円以上に限る。支出予定日の7営業日前までに請求。
第6条（差戻し）通知日から14日以内に再申請。超過すると精算の対象外。
第7条（私的利用）私的な支出が混在していた場合、当該申請は全額却下。
             私的部分のみを除いた再申請は認めない。
```

## 指示文6（記事§5・いちばん見つけにくかったもの）

### 送った指示文（直す前）
間違えやすいところを狙って、ひっかけ問題を作ってください。

### 返ってきたもの（生）
```
Q. 参加者3人の会議で、会議費として1人あたり6,000円、合計18,000円を支出した。
   部長の事前承認は得ている。領収書は画像の提出でよいか。
A. よくない。1人あたり6,000円は5,000円以上なので、領収書の原本が必要。
```

### 照合（Python・5,000円の出現箇所）
```
L8:  5,000円以上の支出は、領収書の原本を提出すること。5,000円未満は、
L13: 会議費は、参加者1人あたり5,000円を上限とする。上限を超える場合は、
-> 第2条の主語は「支出」。この設問の支出は18,000円であって6,000円ではない
```
**結論は正しいが根拠が誤り。**「1人あたり5,000円」は第3条（会議費の上限）の話で、
領収書の判定には関係しない。5,000円が2か所にある罠に、出題した側が引っかかっている。

### 送った指示文（直したもの・記事に載せた版）
正解の根拠として、資料の該当する一文をそのまま引用してください。

### 返ってきたもの（生）
```
A. よくない。原本が必要。
   根拠：「5,000円以上の支出は、領収書の原本を提出すること。」
   （この規程では支出額で判定する。本件の支出は18,000円）
```

### 照合（Python・引用が原文に完全一致するか）
```
引用: 5,000円以上の支出は、領収書の原本を提出すること。
原文に完全一致: あり
```

### 判定
**直した。**引用させると、①引用文を資料検索でその場で確かめられる ②引用の主語が
「支出」だと読めるので、1人あたりの話でないと自分で分かる。
🔑 **この型は答えが合っているので、読んだだけでは絶対に気づけない。**

## この記事から出た教訓（台帳へ）

1. **数を指定すると前から埋まり、後ろが落ちる。**範囲（どこから）で指定する。
   `mail-needs-reply` の「単一条件だと隣接カテゴリが静かに落ちる」と同じ型
2. **「〜するな」より「〜が正解になる問題にしろ」。**禁止だけだと出力の幅ごと狭まる。
   禁止と、禁止した先の受け皿を対で渡す
3. **結論が合っていて根拠が違う、が起きる。**引用を強制すると初めて見える。
   同じ数字が資料の2か所にあるときに起きやすい
