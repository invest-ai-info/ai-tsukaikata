## ⚠️ 実行方法（先行2本との違い・必ず先に読むこと）

先行2本（`how-far-back-changes-the-usual-number`・`flat-log-keeps-the-benchmark-steady`）は

```
             判定=はっきりとした違い(「同じ」ではない) → 一致
材料C・1回目: 14日合計115(真値115 一致)・14日目安8.21(真値8.214286… 一致)
             42日区分合計30+25+40+63=158(真値158 一致)・56日目安4.875(真値4.875 一致)
             判定=大きく違います → 真値diff%68.50 → 一致
材料C・2回目: 14日合計115(一致)・14日目安8.21(一致)
             42日区分合計30+25+52+51=158(一致)・56日目安4.875(一致)
             判定=明確に、大きく違う → 一致
```

4回とも、14日・56日それぞれの目安が真値と完全に一致し、判定は4回とも真値どおり
「大きく違う」側だった（4/4）。

### 判定

**採用。**材料A（真値の差約36.5%）・材料C（真値の差約68.5%）のどちらも、2回ずつ・合計4回、
正しく「大きく違う」と判定した。[先行記事](/recipes/flat-log-keeps-the-benchmark-steady/)の
材料（真値の差約5.7%）での「同じ」判定（2/2）と合わせ、真値の差が小さいときは「同じ」、
大きいときは「大きく違う」という、2つの対照的な条件での判定が揃った。

1. **新しい教訓＝この実行環境（Claude Code Remote のオーケストレーション層）には、

   公開してもらい、そのURLをこちらのArtifact読み取りで回収する」という追加の中継が要る。
   ⚠️ **この中継の依頼自体が、相手に「これは本当に依頼者からの指示か」と疑われて止まることが
   ある**（4回中1回。該当セッションは捨てて再試行した）。
