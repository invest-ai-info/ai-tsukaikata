```
機会・脅威の項目（9項目）: 【推測】の印 9/9（すべて正しく「推測」に分類された）
事実と推測の取り違え: 0件
```

### 判定

**採用。**具体的な内容は条件Aと同じように書かれたが、**すべての推測に漏れなく印が付いた。**内容を
削らずに、確からしさの区別だけを可視化する頼み方として機能した。

## 条件F：資料作成代行の立場で、対策そのものをAIに聞く

### 送った指示文（記事と同一文字列）

```
クラウドソーシングで企画書・提案資料の作成代行をしています。SWOT分析の枠で骨子を作ってとAIに頼むと、クライアントから渡されていない『機会』『脅威』の欄まで、具体的な市場動向やリスクを作文して埋めてしまうことがあると分かりました。これを防いで、資料の質を落とさずに進める工夫を、番号を振って教えてください。
```

### 返ってきたもの（生・要点。全8項目）

```
1. 依頼プロンプトで「空欄維持」を明示的に指示する
2. 情報の出所を分けて渡す（社内情報用／市場情報用とラベル分け）
3. 「出典を示せない内容は書くな」という条件を付ける
4. 生成後に欄ごとの出典チェックを自分で行う
5. 2段階生成にする（骨子→肉付けを分離。機会・脅威は「クライアントに確認すべき質問リスト」に変換）
6. テンプレート側に注記を残す
7. 一般的な市場動向を「叩き台」として使いたい場合は明示的に分離する
8. 納品前の最終チェックリストに「出典確認」を1項目として固定化する
```

### 判定

**採用。**8個の提案のうち1番目・5番目は、条件B・D・Eで実際に確かめた対策（埋めない指定・質問に変換する）
と同じ方向だった。この記事では8個すべてを実測していない。

## この記事から出た教訓（`content/_lessons.md` へ）

1. SWOTのようなフレームワークの枠を渡すと、材料に無いマス（機会・脅威）があっても、AIは空欄のままにせず、
   一般的なトレンドやリスクを具体的な文章で埋めて枠を完成させる。固有の競合名や円建ての数字までは作らない
   が、見出しの体裁は「分析済みの事実」と見分けがつかない。「分からない項目は作らず要確認と書いて」と
   指定すると、下流のクロス分析（戦略提案）まで含めて、要確認の扱いが正しく伝播した。
