# 試した証拠 — handoff-summary-adds-what-you-never-said

すべて **この環境にプリインストールされている `claude` CLI を `--safe-mode --tools ""` で新規サブプロセス起動**し、送ったのは指示文＋教材の文字列だけ（この会話の文脈は一切渡していない＝答える側は真値を知らない。台帳★91の直し方＝`claude --safe-mode --tools "" -p "<指示文>"`）。

材料2本（それぞれ架空の申込み一覧2セット＝1回目の会話用と、2回目の会話用）×3版（a/b/c）×2試行＝**のべ12回**。さらに「言い直し方」で1版（d）を追加検証（のべ2回、材料は主実験と共通）。

**版の対応**：a＝会話を切らずにそのまま続ける／b＝「ここまでの前提と決めごとを、次の会話に渡せる形でまとめて」と頼み、その返り（引き継ぎメモ）だけを新しい会話に貼る／c＝対照版。8ルールの原文をそのまま新しい会話に貼りなおす／d＝bの改良版。「個人情報や雑談を含めないでください」という一文を足す。

1つの会話の流れ＝①8ルール＋1回目の材料を渡して日報化させる →②日報作成とは無関係な雑談を4往復はさんで会話を長くする →③ここで a/b/c/d に分岐し、2回目の材料を日報化させる。

## 指示文6（言い直し方＝版d）の判定

**採用（一部）**。個人情報・雑談を含めないでください、という一文を足した2回で、
引き継ぎメモへの実在情報の混入は2回とも0件——このかぎりでは効いた。
ただし**別の崩れに2回とも遭遇した**：1回目の会話の時点で、AIが「前日ぶんのはずが
複数日にまたがっている」ことをルール⑧の「矛盾」と拡大解釈し、情報に欠落も矛盾もない
行まで〔保留〕へ回してしまった（材料1回目：本来20行とも保留不要なのに10行を保留化。
材料2回目：同じ現象）。この拡大解釈は主実験（12回）の1回目の会話では一度も起きて
いない（4/4とも正しく「保留該当なし」）ので、版dに固有の問題ではなく、**ルール⑧の
文言（「情報が足りない・矛盾している行」）が、まれに「前日という条件と矛盾する日付」
にまで拡大解釈されうる**という、独立した崩れ方として言い直し方に採用した。
n=2と少ないため、「言い直し方」では実測件数を明記し、一般化しない。

## この記事から出た教訓（`content/_lessons.md` へ）

1. ★26系が新しい形で出た（本人のメールアドレス）＝「聞いていないことが足される」ことは、
   これまで金額や計算結果として観測されていた（★26・★29）が、今回は**実在する個人情報**
   という別の重さで出た。引き継ぎメモを作らせる（＝会話を振り返って要約させる）指示は、
   通常の一問一答よりも「聞いていないことを埋める」余地が広いと考えられる。
2. ルール⑧の文言「情報が足りない・矛盾している行」は、まれに（今回はのべ6回の
   1回目会話のうち2回＝供試体が別のdriverだが同一プロンプト・同一材料設計）
   「前日ぶんという条件と日付が矛盾する」という、こちらが意図していない解釈まで
   拾ってしまった。**「矛盾」という言葉は、書いた側が想定していない対象にまで
   及ぶことがある**——縛りの言葉を選ぶときは、対象を狭める一文（例：「行の中の情報どうしの
   矛盾に限る」）を足すほうが安全そうだという、新しい観察。
3. 会話を続けた版（a）と、要約して引き継いだ版（b）は、どちらも「合計」の後に
   聞いていない確認・質問を足す率が、対照版（c＝ルールを貼りなおすだけ）より高かった
   （a=1/4・b=3/4・c=0/4）。**会話の履歴を長く持ち越すほど、指示していない
   「気の利かせ方」が増える**という傾向は、既存の教訓には無い新しい観察。
