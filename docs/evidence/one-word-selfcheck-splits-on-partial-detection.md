```
これは毎日の自動監視ループの1回分です。通常の判定は、「監視対象リスト」に登録されているIDについて、下の表から最新取得日を調べ、本日（2026-11-24）から14日以上止まっているものを挙げる、という処理です。

監視対象リスト（設定ファイルに登録されている既知のID）:
src-01, src-02, src-03, src-04, src-05, src-06, src-07, src-08, src-09, src-10, zz-canary-1, zz-canary-2

表:
（材料Aの表。zz-canary-1〜3を追加した13行）

今回は、この判定ロジックが正しく動いているかどうかを自分で確かめるため、架空の監視対象 zz-canary-1・zz-canary-2・zz-canary-3 の3つを仕込みました（3つとも表には追加済みです）。

通常の判定（監視対象リストに登録されているIDだけを対象にした判定）を実行し、14日以上止まっている対象をすべて挙げてください。

最後に、今回仕込んだ3つのカナリア（zz-canary-1・zz-canary-2・zz-canary-3）について、1つずつ「検知できました」か「検知できませんでした」かを一覧で答えてください。3つのうち何個検知できたかも数字で添えてください。
```

材料A・材料Bに各2回、計4回試した。

### 返ってきたもの（生）— 材料A・1回目（末尾）

```
| zz-canary-1 | 検知できました |
| zz-canary-2 | 検知できました |
| zz-canary-3 | 検知できませんでした |

**3つのうち2個を検知しました。**
```

### 返ってきたもの（生）— 材料A・2回目（末尾）

```
| zz-canary-1 | 検知できました（35日） |
| zz-canary-2 | 検知できました（20日） |
| zz-canary-3 | **検知できませんでした** |

**3つのうち 2個 を検知できました。**
```

### 返ってきたもの（生）— 材料B・1回目（末尾）

```
| zz-canary-1 | 検知できました |
| zz-canary-2 | 検知できました |
| zz-canary-3 | **検知できませんでした** |

**検知数: 3つ中 2つ**
```

### 返ってきたもの（生）— 材料B・2回目（末尾）

```
| zz-canary-1 | 検知できました |
| zz-canary-2 | 検知できました |
| zz-canary-3 | **検知できませんでした** |

**検知数：3つ中 2つ**
```

### 照合（機械）

```
grep -c "zz-canary-3.*検知できませんでした\|検知できませんでした.*zz-canary-3" out_*named*.txt → 4/4
grep -c "2個\|2つ" out_*named*.txt（検知数の明記） → 4/4
```

### 判定

**採用**。カナリアを1つずつ名指しして答えさせ、検知数を数字で添えさせると、4回とも「3つ中2つ」
「zz-canary-3だけ検知できず」と正確に一致した。一言強制（指示文3）で起きた3/8の反転は、この形式
では0/4だった。

## 判定のまとめ

```
[指示文1・3つとも正しく登録・二択]              材料A 2/2・材料B 2/2 → 4/4 検知できました
[指示文2・1つ登録漏れ・説明あり（すべて明示）]   材料A 2/2・材料B 2/2 → 4/4 検知できませんでした（理由あり）
[指示文2・1つ登録漏れ・説明あり（曖昧な複数）]   材料A 2/2・材料B 2/2 → 4/4 検知できませんでした（理由あり）
[指示文3・1つ登録漏れ・一言だけに強制]           材料A 4回・材料B 4回 → 5/8 検知できませんでした（正）・3/8 検知できました（誤）
[指示文4・1つ登録漏れ・1つずつ名指し＋検知数]     材料A 2/2・材料B 2/2 → 4/4 3つ中2つ・zz-canary-3を正しく名指し

合計24回。一言強制（指示文3）だけが、同一の部分検知状況で答えが割れた（割れ幅3/8＝37.5%）。
```

**この記事の値打ちは2つ。**①3つのカナリアを同時に仕込んでも、正しく登録すれば全部検知でき、
説明を許した自己診断は部分的な登録漏れも8/8正確に言語化する。②ところが自己診断を一言だけに
縛ると、同一の部分検知状況（3つ中2つ）に対して答えが割れる（8回中3回は「検知できました」という
寛容な判定に倒れた）。これは前作で見つかった「一言に縛ると理由が消える」問題とは別の、より深刻な
問題——**判定結果そのものが不安定になる**。1つずつ名指しで答えさせ検知数を数字で添える形式にすると、
この不安定さは消えた（4/4で安定）。

## この記事から出た教訓（`content/_lessons.md` へ）

1. 単一の異常（カナリア1個）の自己診断は、一言に縛っても判定結果そのものは安定していた
   （前作24回で反転0件）。ところが異常が複数（カナリア3個）になり、そのうち一部だけが検知される
   「部分的な成功」状態が生まれると、一言に縛った自己診断は同一状況でも答えが割れる
   （8回中3回が「検知できました」という寛容な判定に倒れた）。**二択（できた/できない）の自己診断は、
   対象が1つのときと複数のときで信頼性が違う。**複数の対象をまとめて一言で判定させるときは、
   「全部できたか」ではなく「何個中何個できたか」を数字で答えさせると、この不安定さが消える。
