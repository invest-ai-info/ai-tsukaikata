## 指示文6（2回ぶんを比べて「重複」を数えさせる）

### 送った指示文（記事と同一文字列）

```
下の【1回目】と【2回目】は、同じテーマで別々に出したタイトル案50件ずつです。2回を比べて、発想がどれだけ重複しているか、実質何種類の発想があるかを数字で教えてください。

```

### 返ってきたもの（生・要点）

```
型(構成パターン)の一致率は100%(5種類×10件が両回で完全に同じ配分・同じ順序)。
具体的な発想・主張の一致率は約35%前後(especially二択型と逆説型で重複が濃い)。
100件のタイトルを「別の発想」として数えるなら、実質60〜65種類程度に圧縮されます。
```

### 照合（機械）

```
1回目のクラスタ数: 29　2回目のクラスタ数: 41　重複クラスタ数: 12
combined 100件の全体クラスタ数: 58
```

自己申告「60〜65種類」と機械判定「58件」の差は**2〜7件（3〜12%）**。

### 判定

**採用（ただし別の聞き方よりはるかに正確）**。指示文5（1回ぶんの見直し）は88%過少だったが、
**「2回を比べて」という聞き方では、機械判定との差が1桁小さくなった**。同じ「実質何種類か」
という問いでも、**比較対象を明示すると、与えられた構造に寄りかかりにくくなる**らしい。
⚠️ **それでも機械判定の裏取りは必須**（この回は近かったが、必ず当たるとは限らない）。
