# 試した証拠 — writing-style-sample-matches-the-ratio

記事「見本の文章を渡すと文体は再現できる——言葉だけだと接続詞が1.6倍に増える」の実測記録。

Agentツール `general-purpose`（共有コンテキストの無い新規サブエージェントを毎回1回だけ呼び出し。
「ツールを使わず、ユーザーの依頼にそのまま応答し、出力はレビュー文だけにしてください」という
前置きを付けて、記事と同じ指示文をそのまま渡した）。2材料×3条件（見本なし2回・見本あり4回・
言葉だけ4回）＝計20回。

- 材料A（くだけた文体）＝猫の爪とぎレビュー（見本）→犬の散歩バッグ（新しい話題）
- 材料B（硬い文体）＝シャープペンシルレビュー（見本）→万年筆（新しい話題）

## 見本の実測値（判定の基準）

```
Material A: 文数=9 平均字数=25.1 んですよね系文末=7/9 ちなみに=2回
Material B: 文数=7 平均字数=39.1 である調(非敬体)=7/7 そもそも=2回
```

判定コード（`sentences()` で「。」区切り、文末パターン・接続詞の出現回数・平均字数を数える）:

```python
import re

def sentences(text):
    return [p for p in re.split(r"。", text) if p.strip()]

def stats_a(text):
    sents = sentences(text)
    n = len(sents)
    avg = sum(len(s) for s in sents) / n
    target_end = sum(1 for s in sents if s.endswith("んですよね") or s.endswith("んです"))
    chinamini = text.count("ちなみに")
    return dict(n=n, avg=round(avg,1), target_end=target_end, chinamini=chinamini)

KEITAI_RE = re.compile(r"(です|ます|ません|でした|ました)$")
def stats_b(text):
    sents = sentences(text)
    n = len(sents)
    avg = sum(len(s) for s in sents) / n
    plain = sum(1 for s in sents if not KEITAI_RE.search(s))
    sosomo = text.count("そもそも")
    return dict(n=n, avg=round(avg,1), plain=plain, sosomo=sosomo)
```

## この記事から出た教訓（`content/_lessons.md` へ）

1. 見本（実例）を渡すと、AIは文体の「二値的な特徴」（使うか使わないか）だけでなく、
   「量的な特徴」（頻度・文の長さ）まで実物に近い配合比率で再現する。一方、言葉だけで特徴を
   説明すると、二値的な特徴は同じ精度で再現できるが、量的な特徴は指示した語（「多用」「よく使う」）
   を文字どおり全部の文・より多い回数に適用してしまい、実物より強く出る（1.6倍・78%→100%）。
2. 言葉だけの指示でも、比率を具体的な数字（「8文中6〜7文」）で指定すると、見本を渡した場合に
   近い値（74%、実物は78%）まで戻せる。曖昧な「多用して」ではなく数えられる形で指定すること。
3. 4回のうち1回だけ誤字（「このの万年筆」）が出たが、判定（そもそもの回数・敬体の有無）には
   影響しなかった。生ログはそのまま残し、記事では言及しない（判定に関係ない瑕疵）。
