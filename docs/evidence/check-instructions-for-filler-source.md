# 試した証拠 ― check-instructions-for-filler-source

2026-08-25 実施。**架空の「保存指示文」を3本**（A＝毎朝の受信箱仕分け／B＝毎朝の表の点検／C＝毎日の記録の要約）作り、それぞれに**下限を強制する指定8個**（危険）と**上限だけの安全な指定8個**を1個ずつ仕込んだ。

**3つの頼み方（そのまま開いて聞く／下限だけ挙げて／＋書くことが無い日に何が出るか）× 材料3本 × 各2回 ＝ 18回**を基本に、さらに次の3種を追加で試した。

- **もう一度全部見直して**（材料ごと1回・最初に開いて聞いた会話に重ねて質問）＝3回
- **一度に「全部見直して」まで含めて頼む**（材料ごと1回・新規の会話）＝3回
- **逃げ道が本当にその項目にかかっているか確認して**（材料ごと1回・重ねて質問）＝3回

**合計27回**の返りを取った。判定は仕込みの一意な文字列で機械的に照合できるものは `grade.py` で、文脈込みの判定（逃げ道の有無・矛盾の指摘など）は生の返りを人が読んで確定させた。

### 返ってきたもの（生） ― 材料A・1回目

```
この指示文には、材料が無くても何かを書かせてしまう箇所が複数あります。

**1. 「今日中に返信すべきものを、必ず3つ挙げてください」**
最も強い問題箇所です。上限（5個まで）は決めているのに下限を「必ず3つ」と固定しているため、緊急の返信が実際には1件や0件の日でも、数合わせで重要度の低いメールを繰り上げて埋めることになります。
→ 直し方: 「今日中に返信すべきものを、最大5個まで挙げてください（無ければ0件と書く）」のように、上限のみを定め、下限の縛りを外す。

**2. 「添付ファイルがあるメールは、良い点と悪い点を同数で挙げてください」**
実際には悪い点が1つしか無い、あるいは無い場合でも「同数」を満たすために良い点を水増しする（または悪い点を無理に絞り出す）ことになります。件数を対にする指定自体が無理を生みます。
→ 直し方: 「気づいた良い点・悪い点をそれぞれ挙げてください（無ければ『特になし』と書く）」とし、同数の縛りを外す。すぐ下の「気になる点が思い当たらないときは空欄でよい」というただし書きと矛盾している点も合わせて解消できます。

**3. 「表の点検欄」の「表の全欄を埋めてください」**
情報が無い項目（例えば緊急度の判断材料が無い会社）でも、表の形式を保つために無理に値を入れることになりかねません。
→ 直し方: 「情報が無い欄は『不明』または『該当なし』と書いてよい」と明記する。

**4. 「届いていないメールが疑われるときは、原因を3つ書いてください」**
「心当たりが無ければ『見つかりませんでした』とだけ書く」という逃げ道はありますが、「疑われるとき」に該当した場合は原因の数を3つに固定しているため、実際には1つか2つしか思い当たらなくても数合わせで埋めることになります。
→ 直し方: 「思い当たる原因を、あれば最大3つまで書いてください」と上限指定に変える。

**5. 「対応の候補が複数あるときは、候補から必ず1つ選んでください」**
候補同士に優劣をつける根拠が無い場合でも、強制的に1つを選ばせる形になっています。決め手が無いのに選ばせると、もっともらしい理由の後付けを誘発します。
→ 直し方: 「決め手がある場合のみ1つ選び、無ければ『決め手なし』と書いてください」とする。

**6. 「まとめは180字以内でまとめてください」＋「最大3行」の二重指定**
文字数指定自体は上限なので直接の問題ではありませんが、「材料が足りないときはそう答えてください」という逃げ道と、「180字以内で"まとめて"ください」という書き方が両立しにくく、材料が薄い日でも180字に近づけようと水増しする恐れがあります。
→ 直し方: 「材料が少ない日は無理に字数を埋めず、短くてよい」と一言添える。

**総評**
「不明」「空欄可」「見つかりませんでした」といった逃げ道は随所に用意されており設計思想は良いのですが、下限指定（必ず3つ／同数／全欄／3つの原因／必ず1つ選ぶ）だけが逃げ道と衝突しています。下限を課している5箇所（1・2・3・4・5）を「上限のみ」「無ければその旨を書く」という表現に統一すれば、書くことが無いのに埋めさせる構造は解消されます。
```

### 照合（機械＋人の読み合わせ）

見つけた8個中5個（D1・D2・D6・D7・D8）。**D3（各項目に一言添えて）・D4（◯行でまとめて）・D5（5段階で点数を）は挙がらなかった。**安全な8個（S1〜S8）を危険と誤って挙げた箇所は無し（S1・S2の組みは「文字数指定自体は上限なので直接の問題ではありません」と自分で除外している）。

### 返ってきたもの（生） ― 材料B

```
ご依頼のとおり、実行はせず、指示文というテキストそのものを分析しました。

まず「書くことが無くても埋めさせてしまう指定」を確認すると、■表記ゆれの節にあります。

> 「表記ゆれの候補が3つ未満のときは、必ず3つ挙げてください。近い候補まで含めて構いません。」

これは他の節（原因が無ければ「見つかりませんでした」、該当0件は明記、気になる行が無ければその旨を書く）が一貫して「無ければ無いと書く」設計になっているのに対し、唯一「無くても数を満たすまで（近い候補まで含めて）挙げさせる」という下限強制の指定です。表記ゆれの候補が実際には2個や0個しか無い場合でも、無理に3個に届かせる書き方を求めており、水増し・こじつけを誘発します。

この観点で、数や分量を指定している行を最初から最後まで全部洗い出し、下限強制の有無を判定した一覧は以下のとおりです。

1. 「原因を3つ書いてください」— 上限的な指定だが、直後に「心当たりが無ければ『見つかりませんでした』とだけ」という逃げ道が明記されている。下限強制ではない。
2. 「該当が0件のときは0件と明記してください」— 数の指定ではなく、0件をそのまま書けという指示。下限強制ではない。
3. 「該当する種類が無い場合はその旨を書いてください」— 同上、無ければ無いと書く指示。下限強制ではない。
4. 「表全体の使いやすさを、5段階で点数をつけてください」— 評価尺度の指定であり、書く分量の下限ではない。
5. 「表の全欄を埋めてください。空欄が残っている行は仕上げてください。」— 一見すると強制的だが、直後の6で明確に打ち消されている。
6. 「ただし根拠に自信が持てない欄は、無理に埋めず空欄のままにしてください。」— 5の下限指定を明示的に解除する逃げ道。下限強制ではない。
7. 「各項目に一言添えてください」— 項目数に対応した分量指定で、内容が無くても書けというものではない。
8. 「気になる行が複数あるときは、候補から必ず1つ選んでください」— 複数ある場合の絞り込み指示であり、無い場合まで作らせるものではない。
9. 「気になる行が無いときは、その旨を書いてください」— 無ければ無いと書く指示。下限強制ではない。
10. 「表記ゆれが疑わしい語は、良い点と悪い点を同数で挙げてください」— 同数という体裁の指定。件数の下限そのものではないが、次の11と組み合わさると水増しの土台になりうる。
11. 「表記ゆれの候補が3つ未満のときは、必ず3つ挙げてください。近い候補まで含めて構いません。」— **下限を強制している指定**。材料が無くても（近い候補まで含めて）3つに届かせよという、書くことが無くても埋めさせる唯一の箇所。
12. 「最後に3行でまとめてください」／「まとめは最大3行までにしてください」— 上限指定であり下限ではない。
13. 「まとめは180字以内でまとめてください」— 上限指定であり下限ではない。
14. 「材料が足りないときはそう答えてください」— 足りなければそう書けという逃げ道。下限強制ではない。
15. 「集計に使った数字の上限は5個までとし、それ以下でもかまいません」— 明示的に上限のみで、下限は「それ以下でもかまわない」と否定されている。
16. 「分からない項目は『不明』と書いてください」— 分からなければ不明と書く指示。下限強制ではない。

結論として、下限を強制している箇所は11番の「表記ゆれの候補が3つ未満のときは、必ず3つ挙げてください」の1点のみです。他の数・分量に関する指定はすべて上限指定であるか、「無ければ無いと書く／自信が無ければ空欄にする」という逃げ道が明記されており、内容が無いのに埋めさせる強制にはなっていません。
```

### 照合（機械＋人の読み合わせ）

3回（材料A・B・C）で最終的に挙げた個数は **3・1・3**（合計7/24）。**「もれなく見直して」と1回の指示に詰め込んでも、実際にはむしろ丁寧な除外理由をつけて項目を落とす方向に働いた。**材料Bでは、この回答自身が根拠として並べた「4. 5段階で点数を」を、最後の結論では見送っている（同じ返答の中で、見つけた候補を自分で棄却している）。

## この記事から出た教訓（`content/_lessons.md` へ）

1. **「下限だけ挙げて」と絞っても、精度は上がらない。**むしろ回によるばらつきが大きくなる（1個〜7個）。絞り込みの指示は、検出漏れを減らすとは限らない。
2. **「もう一度全部見直して」を、一度に詰め込んでも効かない。**新規の会話で最初から「見て→全部見直して→一覧で」と1文にまとめると、むしろ丁寧な理由をつけて項目を除外する方向に働いた（3回で合計7/24）。**同じ会話に、あとから2手目として重ねて聞く**方が確実に効いた（3/3）。
3. **近くにある「逃げ道」の一文は、隣の項目にかかっていることがある。**「5段階で点数をつけてください」の2行後に「無理に埋めず空欄のままにしてください」があっても、その逃げ道は実は直前の別の指定（表の全欄を埋めて）にかかっていて、5段階評価自体には届いていない。逃げ道は「近くにあるか」ではなく「同じ主題の文の中にあるか」で確認する必要がある。
