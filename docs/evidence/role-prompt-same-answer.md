# 試した証拠 — role-prompt-same-answer

「よく言われる『AIには役割を与えよ（あなたは◯◯の専門家です）』を、実際に試す」の実測記録。

⚠️ 返ってきたものは生のまま。判定はすべて機械（Pythonの文字列一致・件数の数え上げ）で行い、目視の「良くなった」判定はしていない。

実測は Agent ツール（`general-purpose`、会話の文脈を一切引き継がない独立回答）を使用。材料を作った担当と同じ知識空間にはあるため、サブエージェントに渡したのは依頼文＋材料だけで、正解・仕込みの答えは渡していない。

⚠️ 下の「送った指示文」は記事の `<div class="prompt">` と同一文字列。実際にサブエージェントへ送った文面は、この末尾に「ツールは使わず、この場で直接日本語で回答してください。前置きの挨拶は不要です。」を追加してある（Agentツールが余計な下調べを始めないための、実測作業だけの注記で、記事の指示文には含めていない）。

第6条（残業時の食事）
22時以降まで残業した場合、1食あたり1,000円までの食事代を実費精算する。
