## 真値の検算（★24）

```python
def withhold(amount):
    if amount <= 1_000_000:
        tax = amount * 0.1021
    else:
        tax = 1_000_000 * 0.1021 + (amount - 1_000_000) * 0.2042
    return round(tax), amount - round(tax)

print(withhold(300_000))    # => (30630, 269370)
print(withhold(1_300_000))  # => (163360, 1136640)
print(withhold(1_000_000))  # => (102100, 897900)
```

実行結果：300,000円→源泉徴収30,630円・手取り269,370円。1,300,000円→源泉徴収163,360円・
手取り1,136,640円。1,000,000円ちょうど→境界ぎりぎりで全額10.21%・源泉徴収102,100円・
手取り897,900円。この3値を正解として機械照合した。
