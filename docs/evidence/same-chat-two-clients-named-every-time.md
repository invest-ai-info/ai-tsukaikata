# 試した証拠 — same-chat-two-clients-named-every-time

記事「2社のSNS投稿を同じ会話で頼む——店名を省くと、前の客のトーンのまま返ることがある」
に載せた指示文6個すべてについて、実際に試した結果をここに残す。

⚠️ 相手は Agent ツール（`general-purpose` サブエージェント）。同じ会話の継続は
`SendMessage` で同じエージェントIDへ送って実現し、新しい会話は毎回フレッシュな
エージェントを作って実現した。架空の2ブランドのガイド文は、記事の `<div class="prompt">`
に載せたものと1文字も変えていない。

---

## 教材（架空データ）

架空のブランド2社のSNS担当という設定で、ブランドトーンだけが正反対の指示を渡した。

**ブランドA「ポップコーンラボ」（カジュアルなアパレルEC）**

```
・読者に話しかけるようなタメ口(「だよ」「だね」「しよ」など)で書く
・「です」「ます」は使わない
・文の区切りごとに絵文字を1つ以上入れる(🎉✨😊🛍️💕など)
・堅い言い回しは禁止
```

**ブランドB「銀座つきひ」（老舗和菓子店・敬語徹底）**

```
・敬語(です・ます、謙譲語)を徹底する
・絵文字は一切使わない
・文はすべて句点「。」で終える
・くだけた言葉遣い(タメ口)は禁止
```

両ブランドとも、依頼する商品（Tシャツ・パーカー・ニット・マフラー／栗まんじゅう・最中・
どら焼き・羊羹）だけを変え、トーンの指示文そのものは同一にした。

## 指示文5（記事の指示文5・落とし穴） — 店名も商品名も書かずに「もう1件」

### 送った指示文（記事と同一文字列）

```
もう1件、新商品の入荷案内をお願いします。120字程度で。
```

直前のやり取り（指示文4の直後）は、どちらの回もB（銀座つきひ・敬語）だった。

### 返ってきたもの（生・ガードなし＝ブランドトーンの指示文に確認要求を入れていない版）

```
[rep1]
どちらの店舗(ポップコーンラボ/銀座つきひ)の、どの新商品の入荷案内か教えてください。
ブランドごとにトーン(タメ口+絵文字 or 敬語+絵文字なし)が正反対なので、指定がないと書けません。

[rep2]
銀座つきひより、新商品のご案内でございます。季節の味わいを生かした和菓子が新しく入荷いたし
ました。素材を吟味し、丁寧に仕上げております。数量に限りがございますので、ご来店の際は
お早めにお立ち寄りください。皆様のご来店を心よりお待ちしております。
（報告文＝「今回は店名・商品名の指定がなかったため、直前のご依頼で使用していた
『銀座つきひ』の敬語トーンを踏襲し……作成しました。意図された店舗・商品が異なる場合は
お知らせください」）
```

### 照合（機械）

店名・商品名を省いた依頼に対して、①確認を返したか／②無言で投稿文を作ったか、
③作った場合は直前（B）のトーンだったか、を目で数えた（自由応答なので正規表現では
拾えない。確認か生成かの二択は機械的に判定しやすいが、今回は2件とも文面を読んで
人間が分類した）。

```
rep1: 確認を返した（投稿文は作らなかった）
rep2: 確認せず、直前に使っていたBのトーンのまま投稿文を作った
→ 確認した割合 = 1/2件
```

### 判定

**落とした（記事では「言い直し方」の失敗例として引用）**。店名を省くと、確認するか
無言で前のブランドのトーンを引き継ぐかが**回によって割れた**。rep2が狙っていたのが
ポップコーンラボ（A）だった場合、受け取った顧客からは「頼んでいないブランドの口調で
投稿文が来た」ことになる——これが記事の「落とし穴」の核。

## 指示文6（記事の指示文6・言い直し方） — ブランドトーンに確認必須の一文を足す

### 送った指示文（記事と同一文字列）

ブランドAのガイドの末尾に、次の1行を足したものを使った（Bのガイドにも同様に追加）。

```
・⚠️ 依頼にどの店の投稿か書かれていない場合は、絶対にそのまま進めず、必ず先に確認してください
```

この一文を足したガイドでA・Bそれぞれ1件目を依頼したあと、指示文5と同じ
「もう1件、新商品の入荷案内をお願いします。120字程度で。」を送った（2系統で実施）。

### 返ってきたもの（生）

```
[rep1]
投稿文の作成を進める前に確認が必要です。
依頼文に「どのお店の投稿か」が書かれていません。ブランドトーンの指示に「⚠️ 依頼にどの店の
投稿か書かれていない場合は、絶対にそのまま進めず、必ず先に確認してください」と明記されて
いるため、店舗名・ブランド名が分かるまで投稿文の作成を保留しました。

[rep2]
依頼された新商品入荷案内の投稿文は作成していません。
理由: ブランドトーンの指示に「依頼にどの店の投稿か書かれていない場合は、絶対にそのまま
進めず、必ず先に確認してください」とあり、今回の依頼文には店名・ブランド名の記載が
ありませんでした。そのため先に確認を行いました。
```

（なお、ガードを入れたガイドでは1件目の依頼自体も「当店の」という言い方では店名が
無いと判定されて確認が入ったため、実験ではいったん店名を答えて1件目・2件目を通常どおり
生成させたあとに、指示文5と同じ曖昧な依頼を送った。1件目・2件目はいずれもガードなし版と
同じく絵文字・敬語ともクリーンだった。）

### 照合（機械）

```
rep1: 確認を返した
rep2: 確認を返した
→ 確認した割合 = 2/2件（ガードなしの1/2件から改善）
```

### 判定

**採用**。「店名が無ければ必ず確認して」という一文を足すと、今回の2回はどちらも
無言で生成せず確認を返した。n=2と少数のため、記事では「2回ではどちらも効いた」と
回数を明記して書く。

## この記事から出た教訓（`content/_lessons.md` へ）

1. ★317＝複数クライアントのブランドトーンを同じ会話で扱っても、**店名を毎回名指しする
   限りは**トーン自体の混入は起きなかった（16回中0回）。「会話を分ければ防げる」ではなく
   「名前を書かせれば防げる」が実測の結論に近い。
2. ★318＝店名を省くと、確認するか直前の相手のトーンを無言で引き継ぐかが**同じ条件でも
   回によって割れた**（2回中1回は無言で引き継いだ）。「店名が無ければ必ず確認して」を
   足すと確認率は上がった（n=2、2/2）が、店名入りの通常の依頼まで確認対象にしてしまう
   副作用も実測で出た。
