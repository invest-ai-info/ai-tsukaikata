## 指示文7（個人か法人かの判断根拠を聞き直す＝言い直し方の節で紹介する指示文）

### 送った指示文（記事と同一文字列）

```
個人事業主と法人、どちらだと判断してその金額を出しましたか。判断の根拠も教えてください。
```

### 返ってきたもの（生）

1回目（agentId: ab3bd2cc9212c1074）:
```
個人事業主だと判断して179,580円を出しました。根拠は以下の3点です。

1. 契約書の受注者欄の表記: 「蒼空法人工房　鈴木次郎」という書き方は、屋号（蒼空法人工房）の後に個人名（鈴木次郎）を併記する形式で、これは個人事業主が屋号を使う際の典型的なパターンです。法人であれば通常「株式会社蒼空法人工房　代表取締役　鈴木次郎」のように会社形態と役職が明記されます。

```

**採用。**条件分岐で濁っていた前の回答と違い、この聞き方を向けると「個人事業主と判断した」

## この記事から出た教訓（`content/_lessons.md` へ）

1. **仕込みに想定外の手がかりを混ぜると、測りたい効果ではなく、その手がかりの効果を
   測ってしまう。**最初の指示文1・3の1回目は、契約文に「個人事業主」という明示ラベルを
   付けたまま実行してしまい、屋号の紛らわしさとは無関係に、ラベルを読むだけで正解に
   到達していた（ラベルがヒントを与えてしまう）。ラベルを一切外した契約文で全条件を
   再実施し、記事本文にはその再実測版だけを採用した。
2. **「自分で試す」は、担当自身が応答を作文するのではなく、まったく新しい文脈の
   サブエージェントに契約書と質問だけを渡して得る方が、仮説を知らない側の判断として
   信頼できる。**今回は `Agent` ツールで毎回独立したサブエージェントを呼び、
   このリポジトリの検証意図を一切知らない状態での応答を記録した。
