## 判定コード（`judge.py`）

```python
import re

SEP_RE = re.compile(r"^-{3,}\s*$", re.MULTILINE)


def extract_body(text):
    seps = list(SEP_RE.finditer(text))
    if len(seps) >= 2:
        return text[seps[0].end():seps[-1].start()]
    if len(seps) == 1:
        return text[seps[0].end():]
    return text


# 「これまで／従来／現行／以前」等のあとに出てくる時刻・時間量が、
# 新しい値と異なる場合だけを「変更前の値を捏造した」と数える。
BEFORE_CONTEXT = re.compile(
    r"(これまで|従来|現行|以前|閉店時刻（|開店時刻（)[^。]{0,20}?(\d{1,2}(?::\d{2})?\s*時間?|24時間)"
)


def find_fabricated_values(text, new_values):
    body = extract_body(text)
    found = set()
    for m in BEFORE_CONTEXT.finditer(body):
        val = m.group(2)
        if val not in new_values:
            found.add(val)
    return found
```

⚠️ **判定の当て方を2通りで確かめた（★51）。**上のキーワード近接方式に加えて、返り全文から「N時」「N時間」に一致する語をすべて拾い、新しい値（23時・20時・22時・8時）を引いた残りが何件あるかも数えた（`grep`相当）。**2つの当て方で、2か所条件の結果（0/20）は完全に一致した**（2か所条件のテキストには、新しい値以外の時刻・時間量が1件も出現しない）。1か所条件は、キーワード近接方式で7/10・全語抽出方式でも同じ7件（「24時間」×2・「20時」×5。「2時間」は「2時間延長」という所要時間の言及で、変更前の値ではないため両方式とも数えていない）。

## この記事から出た教訓（`content/_lessons.md` へ）

1. 新規。★131の系列が再発（材料を組み直す前の段階で気づいた点）＝価格改定という業種では、そもそもPREP法が「変更前の値」を捏造しなかった（0/10）。前提が成立しない材料で反証条件を判定するところだった。
2. 新規。比較対象が増えると、返りの形が「プローズで具体的な旧値を語る」形から「箇条書き＋ラベル（変更前より短縮／現行より変更）」という**定型の型**に変わり、型そのものが具体的な旧数値を書かせなくする方向に働いた。★158（効きそうな一文を積み増しても、素朴な指示文がすでにできていた部分は変わらない）や★192（材料の量ではなく書式の指定が結果を左右する）と同じ「量ではなく書式が効く」という系列の、新しい実例。
