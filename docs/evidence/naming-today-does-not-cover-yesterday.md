# 試した証拠 — naming-today-does-not-cover-yesterday

[追記の形は50回でも崩れない——「本日」は壁時計の日付に化ける](https://ai-tsukaikata.com/recipes/append-rounds-date-drift/)
の末尾に残っていた宿題「走り書きの言い方を『今日』『昨日』『さっき』などに増やしたとき、
同じ事故が同じ形で起きるか」に答える実測（2026-10-22）。

⚠️ 実測の仕方は `increasing-log-judgment-comes-out-right.md` と同じ形＝「材料を作った本人とは
別の、答えを知らない側に答えさせる」。この記事では、Agent（general-purpose・毎回新規・前の回の
文脈を共有しない独立呼び出し）に、チャット応答のみを求める依頼として同じ文面を渡した。各エージェント
には「これはコード/ファイル操作ではなく、チャット画面での1回の会話応答である。ツールは使わず、
ユーザーへの返答のみを出力する」という前置きを付け、「認識している今日の日付」も自己申告させた。

## 教材（架空データ）

### 材料A（副業の作業記録）

```
# 副業の作業記録
2026-08-01 / クライアントA社 / 記事構成の相談 / 30分
2026-08-02 / B社 / 見積りの修正 / 20分
2026-08-03 / C社 / 納品物の確認 / 15分
```

ファイルの続きとして正しい次の行の日付は **2026-08-04**。「昨日」の正しい日付は、その前日の
**2026-08-03**（＝最後の既存行C社と同じ日付。1日に複数の仕事があってもおかしくないので、
これは重複ではなく正しい値）。

### 材料B（家計の買い物メモ）

```

2026-08-01 / スーパー / 食材 / 2,400円
2026-08-02 / ドラッグストア / 日用品 / 1,200円
2026-08-03 / コンビニ / 飲み物 / 350円
```

同じく続きとして正しい次の行の日付は2026-08-04、「昨日」の正しい日付は2026-08-03。

### 走り書き（3語・日付の表記を含まない）

- 今日: 「今日D社向けに資料を修正、所要40分でした。」／「今日ドラッグストアで日用品を買った、1,500円。」
- 昨日: 「昨日E社と電話で打ち合わせ、所要25分でした。」／「昨日本屋で参考書を買った、1,800円。」
- さっき: 「さっきF社とチャットで相談、所要10分でした。」／「さっきコンビニでアイスを買った、280円。」

実測日（system-reminderが示す今日の日付）は **2026-10-22**。「昨日」の壁時計基準の値は
**2026-10-21**。

## この記事から出た教訓（`content/_lessons.md` へ）

1. 走り書きの相対日付語（今日・昨日・さっき）は、いずれも「本日」と同じ壁時計化けを起こす
   （12回中12回）。事故は「本日」という1語固有のものではなく、現在時刻を基準にした相対表現
   そのものの性質だった。
2. 「本日」「今日」としか名指ししていない直し方は、名指ししていない語にも一般化することが
   あるが、保証ではない。「さっき」には2/2で一般化されたが、「昨日」には4回中1回、一般化が
   外れて元の事故（壁時計の日付）に戻った。確実にするには、効くかもしれない語に賭けず、
   効かせたい語をすべて指示文の中で列挙する（content/_lessons.md ★121・家族2の実測を補強。
   新しい番号として★285とした）。
