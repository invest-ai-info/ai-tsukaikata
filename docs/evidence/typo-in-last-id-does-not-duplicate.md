## 判定コード（照合に使ったPython・要約）

```python
import re

def check_material_a(text):
    found = {f"Q-{n}" for n in set(re.findall(r"Q-(\d{2})", text))}
    truth_new = {f"Q-{n:02d}" for n in range(9, 25)}
    truth_old = {f"Q-{n:02d}" for n in range(1, 9)}
    missing = truth_new - found
    extra = found & truth_old
    return len(found), sorted(missing), sorted(extra)

def check_material_b(text):
    nums = set(int(n) for n in re.findall(r"(?<!\d)(\d{1,2})(?!\d)", text))
    truth_new, truth_old = set(range(9, 21)), set(range(1, 9))
    found = nums & (truth_new | truth_old)
    return len(found), sorted(truth_new - found), sorted(found & truth_old)

def classify_nonexistent(text):
    asks = ("教えて" in text or "確認させて" in text or "ご確認" in text or "?" in text or "？" in text)
    has_error_line = bool(re.search(r"エラー[:：]\s*前回位置", text))
    outputs_most_ids = len(set(re.findall(r"Q-(\d{2})", text))) >= 20
    return asks, has_error_line, outputs_most_ids
```

「拾えた新着」「取りこぼし」「誤検出」は`check_material_a`／`check_material_b`の出力、
「確認を求めた」「エラー行あり」「大半のIDを出力」は`classify_nonexistent`の出力をそのまま使った。

   本当に存在しないときで、その対応は指示文の書き方によって割れる。特に「これは自動処理
   なので質問はできません」と念を押すと、2回に1回は済んでいるはずの分まで含めて全件を
   処理し直した（新規の教訓＝★147として追加）。

   ある正しいIDまで「見つかりません」と誤って止めてしまう。表記ゆれの許容と存在確認を
   分けて書き、さらに「判断の途中経過や説明は書かず、最終的な出力だけを出力して」を
   加えると、自己修正の文言が混ざる出力ゆれも消えた（新規の教訓＝★148として追加）。
