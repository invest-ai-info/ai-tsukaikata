```
- 支払のタイミング:検収完了後、翌月末日までに支払う
つまり契約書は「納品 → 検収完了(納品から最大7営業日後) → 翌月末」という2段階の計算で、支払基準日は検収完了日です。

個別発注書の基準
- 納品日:2026年9月28日(月)
- 支払条件:納品月の翌月末お支払い
発注書は検収というステップを経ず、納品日そのものを基準に「納品月の翌月末」と書いています。

一致していない点
1. 基準点が違う
契約書は「検収完了日」を基準にしているのに対し、発注書は「納品日」を基準にしています。検収には最大7営業日かかる可能性があるので、両者は本来ズレうる基準です。
2. 今回のケースで実際に結果がズレるかどうか
納品日が2026年9月28日(月)なので、検収完了までの7営業日は9月29日(火)〜10月7日(水)ごろ(土日を除く)になります。
- 発注書の基準(納品月=9月の翌月末)→ 2026年10月31日(土)
- 契約書の基準(検収完了月の翌月末)→ 検収完了が9月中(9/28〜9/30)なら契約書も「9月の翌月末」=10月31日で一致。しかし検収完了が10月に入ってから(10/1以降にずれ込んだ場合)は、契約書上は「検収完了月=10月」の翌月末、つまり11月末になってしまいます。
今回のケースでは検収期限の7営業日が月をまたぐかどうかがちょうど境界線上にあり、検収がいつ完了したかによって支払月が9月基準か10月基準かで1か月変わりうる構造上のリスクがあります。

指摘すべきポイント
- 発注書は検収完了を待たずに「納品月」を基準にしており、契約書の「検収完了を基準にする」という原則と文言上一致していません。
- 検収が遅れて月をまたぐと、発注書の解釈では10月末払い、契約書の解釈では11月末払いという1か月のズレが生じ得ます。
- 発注書の「納品月の翌月末」が「検収完了を前提とした簡略表記」なのか、「納品日を基準に契約書の規定を上書きする特則」なのかを、発注者に確認しておくことを強くお勧めします。
```

### 照合（機械）

```
基準点の違い（検収完了日 vs 納品日）の明示: あり
月境界が「ちょうど境界線上」という仕込みの核心への言及: あり（「検収期限の7営業日が月をまたぐかどうかがちょうど境界線上にあり」）
```

### 判定

**採用**。1回だけの結果だが、仕込みの核心（検収期限が月境界をまたぐかどうかで支払月が変わる構造）まで言い当てた。
