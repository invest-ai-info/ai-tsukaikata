## 材料D（差10.0%）・round1

### 返ってきたもの（生）

```
直近14日分(10/14〜10/27)の合計を計算します。

4, 6, 5, 6, 5, 5, 5, 5, 6, 7, 5, 5, 7, 6

これを足すと77件。14日で割ると、

77 ÷ 14 = 5.5件/日

次に56日分(9/2〜10/27)の合計を計算します。10日ずつのブロックに分けて足します。

- 9/2〜9/11(10日): 3+4+3+3+5+3+4+5+5+6 = 41
- 9/12〜9/21(10日): 4+6+6+6+5+6+5+5+5+5 = 53
- 9/22〜10/1(10日): 4+5+4+6+6+5+5+4+4+6 = 49
- 10/2〜10/11(10日): 5+5+6+5+6+5+4+6+4+5 = 51
- 10/12〜10/21(10日): 4+5+4+6+5+6+5+5+5+5 = 50
- 10/22〜10/27(6日): 6+7+5+5+7+6 = 36

合計 = 41+53+49+51+50+36 = 280件

280 ÷ 56 = 5.0件/日

【結果】
- 直近14日の目安: 5.5件/日
- 56日全体の目安: 5.0件/日
- 差: 0.5件/日(56日平均に対して約10%)

【判定】実務上は「ほぼ同じ」とみなせる範囲内の差です。大きなズレではありません。

理由は、この0.5件という差が、もともとこの記録が持っている1日あたりの自然なブレの大きさと比べて小さいことです。56日分の値は3件〜7件の間で動いていて、ならしてみると平均(5件)からのズレの大きさはだいたい±0.9〜1件程度(標準偏差に相当する目安)です。直近14日の平均が0.5件高いというのは、このブレのおよそ半分程度の大きさしかなく、「毎日の増減の範囲内」に収まっています。

ただし方向としては、直近14日のほうが一貫してやや高め(7件という日が10/23・10/26の2回出ている一方、古い42日間には7件の日が一度もない)という傾向もうかがえます。なので「件数が急に跳ね上がった」とまでは言えませんが、「ここ2週間はわずかに多め(5件強)、それ以前を含めた全体ではちょうど5件前後」という、緩やかな上振れ傾向として捉えるのが実務上妥当です。問い合わせ対応の人員計画などでは、どちらの数字を使っても「1日あたりおよそ5件」という見積もりで実質同じ結論になります。
```

返り: sum14=77 mean14=5.5 / sum56=280（41+53+49+51+50+36の内訳も全て一致） mean56=5.0 / diff≒10%
→ 完全一致。判定＝「ほぼ同じ（実務上同じとみなせる範囲）」

## この記事から出た教訓（`content/_lessons.md` へ）

1. 境界に近い差（10%〜30%）でも、AIが出す「直近14日の目安」「56日全体の目安」という数値そのものは
   6回中5回が真値と完全一致した。ズレたのは1回（材料F・round1の56日合計が+2件）だけで、
   この回でも最終判定（大きく違う）の方向は真値と一致していた。★24（計測器が間違っていることがある）
   の逆側＝**判定が合っていても、根拠の数字は別に照合しないと誤りを見逃す**、という形で再発した。
2. 「同じ／大きく違う」の判定が切り替わる境界は、1回の実測で1点には絞れない。今回は
   10.0%で「同じ」、20.0%で「大きく違う」と分かったが、**その間の15%や18%がどちらに
   転ぶかは分からないまま**。境界を扱う記事は「ここまで狭まった」で止め、「ここで切り替わる」
   と言い切らないこと。
