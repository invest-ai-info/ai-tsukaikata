事前に Python で検算した必要件数・成功確率：

```python
from math import comb
def binom_at_least(n, p, k):
    return sum(comb(n, i) * p**i * (1-p)**(n-i) for i in range(k, n+1))

# 材料A: 受注率1/3のまま、提案n件で受注4件以上になる確率
binom_at_least(12, 1/3, 4)  # => 0.607
binom_at_least(15, 1/3, 4)  # => 0.791

# 材料B: 成約率0.25のまま、出品n件で販売7件以上になる確率
binom_at_least(28, 0.25, 7)  # => 0.572
binom_at_least(32, 0.25, 7)  # => 0.722
binom_at_least(36, 0.25, 7)  # => 0.832
```

## この記事から出た教訓（`content/_lessons.md` へ）

1. ★361の系列＝目標額が届きやすい倍率（1.2倍・1.29倍）でも、「前向きに」は条件付きの「難しい」を同じように消した。倍率の大きさは崩れ方を変えなかった。
2. 新規＝言い回しを変えると崩れる場所が違う。「前向きに」は成功確率の計算を落とさなかったが、「希望を持てる言い方で」は4回中3回、確率の計算まで落とした。
3. 新規＝「難しい」という言葉を名指しで指示文に書き込んでも、確実には戻らない（4回中1回は戻らなかった）。受け皿の一文は「足せば必ず効く」ものではなく、足した後に実際に出てきたかを確認する必要がある。
