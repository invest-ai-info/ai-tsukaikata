# 試した証拠 — date-only-sender-slips-at-twenty（20社でも検出漏れは直せる）

実施方法: Claude Code の Agent（サブエージェント・`claude` 型・ツール未使用）に、「一般的なチャットAIとして、
渡した文章にそのまま応答する」役を演じさせ、独立した会話（前の回のことは一切知らない）で毎回新規に走らせた。
担当（このセッション）は架空データを作り、正解（どの取引先の何番目が真の緊急かの固定リスト）を先に決めてから
実施した。判定は正解データとの機械照合（Python の集合演算）。

⚠️ **土台は既存記事**＝[複数の相手の緊急度を仕分ける](/recipes/one-rule-does-not-fit-every-sender/)
（`docs/evidence/one-rule-does-not-fit-every-sender.md`）の5社×5件・4パターン（件名明記・本文のみ・日付のみ・
慣習語）＋対照群1つ。この記事は、その5パターンの型をそのまま**10社・20社に増やして再現**する。
5社（材料A・25件・真の緊急8件）での実測は元記事にあるものをそのまま使い、この記事では新たに実施していない。

⚠️ **教材は手書きではなく生成コードで作った**（本ファイル末尾の `gen_materials.py`）。5パターンを1サイクルとして
サイクルを繰り返し、サイクルごとに言い回しのセット（0〜3）を変えて同一文面の反復を避けた。正解（真の緊急）は
コード側で固定してから一覧テキストを生成しているので、目視の後付けではない。

        cycle = i // 5
        ptype = PROFILE_CYCLE[i % 5]
        variant = cycle % 4
        company = f"取引先{i+1:02d}"
        letters = scenario(variant, ptype, company)
        lines.append(f"【{company}】")
        for j, (subject, body, urgent) in enumerate(letters, start=1):
            lines.append(f"{j}. 件名: {subject}")
            lines.append(f"本文: {body}")
            if urgent:
                truth.append((company, j))
        lines.append("")
    return "\n".join(lines).rstrip() + "\n", truth
