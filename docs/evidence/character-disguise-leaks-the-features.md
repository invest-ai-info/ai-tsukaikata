1. 固有名詞が本当に全部消えているか
　作品名・キャラクター名・企業名・ブランド名が、言い換え後の文章に一切残っていないか確認します。「◯◯のような」のような婉曲表現に変わっただけで、固有名詞がそのまま残っているケースがあるので要注意です。

2. 特徴の組み合わせが「特定の一作品」を指していないか
　髪型・服装・色の組み合わせ・持ち物などを個別には一般的な言葉にしていても、全部を足し合わせると誰が見てもあの作品だと分かってしまう場合があります。言い換え後の文章を他人に読ませて「何を思い浮かべるか」を聞いてみるのも有効です。

　プロンプトが安全でも、AIが学習データの影響で特定キャラクターに酷似した絵を出すことがあります。プロンプトの文章だけでなく、必ず生成結果の画像を見て「既存のキャラクターに似すぎていないか」を確認します。

4. 「特定の実在アーティストの画風で」という言い方になっていないか
　作品名はぼかせても、実在する漫画家・イラストレーター個人の名前やタッチを指定する言い方が残っていると、著作権とは別に本人のスタイルを無断で商用利用する問題になり得ます。個人名は固有名詞と同様に消えているか確認します。

5. ロゴ・マーク・企業デザインが紛れ込んでいないか
　キャラクターの服や持ち物に、実在企業のロゴや商標的なマークが描かれていないか確認します。これは著作権というより商標・パロディの問題として別途リスクになります。

6. 実在の人物に似せていないか
　「◯◯（芸能人・著名人）みたいな顔で」という依頼だった場合、著作権だけでなく肖像権・パブリシティ権の問題になります。言い換え後も「実在の特定の人物」を連想させる特徴が残っていないか確認します。

7. お客さんの本当の意図とズレていないか
