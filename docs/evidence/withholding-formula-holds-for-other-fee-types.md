```python
def withhold(amount):
    base = min(amount, 1_000_000)
    over = max(amount - 1_000_000, 0)
    tax = round(base * 0.1021) + round(over * 0.2042)
    return tax, amount - tax

assert withhold(450_000) == (45945, 404055)
assert withhold(1_200_000) == (142940, 1057060)
assert withhold(280_000) == (28588, 251412)
```

```
法人から直接、講演料・翻訳料・著作権使用料などを受け取る契約が増えてきました。契約ごとに源泉徴収の対象かどうかと、正しい手取り額を毎回確認したいです。プログラミングはできません。私が契約のたびに確認することを、番号を振って箇条書きで教えてください。
```

### 返ってきたもの（生）

**1回目（10項目）**
```
1. 支払う相手が「法人」かどうかを確認する
2. 報酬の種類が源泉徴収の対象リストに当たるか確認する
3. 消費税が区分されているか確認する
4. 1回の支払金額が100万円を超えるかどうかを確認する
5. 源泉徴収税額を自分で計算してみる
6. 契約書・請求書に源泉徴収額と手取り額を明記してもらう（または自分で明記する）
7. 実際の入金額が、自分で計算した手取り額と一致するか確認する
8. 支払調書（または支払通知書）を受け取り、記載内容を照合する
9. 全契約の記録を一覧で残しておく
10. 判断に迷うケースは契約の都度、税理士またはその年の最新の国税庁資料で再確認する
```

**2回目（11項目）**
```
1. 受け取る名義の確認
2. 支払名目の確認
3. 雇用契約ではないことの確認
4. 消費税の区分記載の確認
5. 実費（旅費・宿泊費など）が別立てになっているかの確認
6. 1回あたりの支払金額の確認（100万円の壁）
7. 源泉徴収税額を自分で計算する
8. 相手から来る支払通知書・支払調書と照合する
9. 手取り額を計算して実際の入金額と照合する
10. 証拠を保存する
11. 支払者が海外法人でないかの確認
```

### 照合（機械）

項目数10・11（回によって違う）。ただし次の骨格は2回とも共通していた＝①報酬の種類・名目が
源泉徴収の対象かを確認②消費税の区分記載を確認③100万円の壁で税率を自分で計算④入金額と
照合⑤記録・支払調書を保存。

### 判定

**採用**。本数そのものは回ごとに違うので記事には「次の骨格は共通していた」として
2回の結果を併記する。

## この記事から出た教訓（`content/_lessons.md` へ）

1. `direct-contract-withholding-survives-the-million-yen-line` が実測した204条1項1号の
   源泉徴収ルール（10.21%／20.42%・100万円の境目）は、原稿料・デザイン料だけでなく、
   講演料・翻訳料・著作権使用料という同じ号の他の業務にも、ラベルを明記しなくても
   正しく一般化した（各3回・計12回・12回とも正解額）。
2. 新しい観察＝204条の対象外の業務（システム開発）を同じ聞き方で試すと、3回とも
   「源泉徴収は不要」と正しく踏みとどまり、個人への業務委託だからという理由だけで
   源泉徴収を過剰適用する誤りは起きなかった。既存台帳に同種の番号は無いので、
   次回2回目が出たら新しい番号で立てる。
3. エージェントの最終報告が、ユーザーへの回答本文そのものではなく「要約」の形で返ることが
   複数回あった（指示文3の3回目・指示文4の3回目）。数字は本文中に明記されていたため
   判定には影響しなかったが、生の文面を記事に引用する際はこの回を避けた。
