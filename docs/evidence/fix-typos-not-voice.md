### 返ってきたもの（生・AIの申告）
```

入替えいたしまた → 入れ替えいたします
お願い致しす → お願いいたします
して下さい → してください
ご一報くだい → ご連絡ください
約15分程度 → 約15分
```
（7件）

### 照合（Python・申告 vs 実際の差分）
```
AIが「直した」と申告した件数: 7
実際に本文で変わっていた箇所: 13

申告に載っていないのに本文では変わっていたもの（6件）:
  ★ 行って下さい
  ★ 本件
  ★ 別紙
  ★ 稟議
  ★ 期限厳守。
  ★ お問い合わせいただけますよう
```

### 判定
**記事の中心にした。**🔑 **一覧に出るのは「直した」と自覚したものだけ。**
稟議→社内承認は、AIにとっては誤りの訂正ではなく「分かりやすくした改善」なので、
直した箇所として数えられていない。**守りたかった4件が、そっくりそのまま無申告側にあった。**

→ 対処は2つに1つ。①本文を返させない（一覧しか無ければ、一覧に無い変更は起こりえない）
②本文を受け取るなら自分で差分を取る。「一覧に無い変更は本文にも入れないで」を足すと
漏れは減るが**ゼロにはならない**ので、記事にもそう書いた。

## この記事から出た教訓（台帳へ）

1. **範囲は「名前」ではなく「種類の一覧」で渡す。**「校正」「整理」「改善」のような
   名前の範囲は相手が決める。AIは広いほうで取る
2. **禁止は、受け皿と対で渡す。**「変えるな」だけだと、変えてほしいものまで止まる
   （`quiz-yourself-with-ai` の「〜するな より 〜が正解になる問題にしろ」と同じ型。
   **2回出た＝昇格の候補**）
3. **AIの自己申告は、本人が自覚した範囲しか含まない。**件数も箇所も、原文との
   差分で検算する。良かれと思ってやった変更ほど申告に出ない
