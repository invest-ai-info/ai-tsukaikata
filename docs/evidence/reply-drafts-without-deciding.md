# 試した証拠 — reply-drafts-without-deciding

問い合わせへの一次返信の下書きを、まとめて作らせたときの記録。
測ったのは丁寧さではなく、**自分が決めていないことが文面の中で決まるかどうか**。

⚠️ 判定はすべて Python。**答えられる6通／答えられない6通は、走らせる前に決めて、
その手がかりが条件表8行に1つも無いことをコードで確かめた**（★24）。
⚠️ 台帳★20 のとおり、実測した環境はこのサイトの文脈から完全には切り離せない。
根拠は**機械照合できるものだけ**にした＝印の数・条件表に無い決めごとの件数・約束語の照合。

📌 **実測のやり方**＝指示文は、このセッションとは別の新しいチャットに送った。
返りは**そのまま**貼ってある。

📌 **試行回数**＝指示文1・2・3は各2回、指示文4・5・6は各1回。
記事の本文にも同じ回数を書いた。

🚨 **数えるのは、相手に貼る本文だけ。**返りの末尾に付く「置いた前提」のような注記は
数えていない。理由は記事の主張そのもの＝**貼るのは本文だから。**
