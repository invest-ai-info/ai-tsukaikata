# 試した証拠 — rewrite-clears-sentence-ending-repeats

キュー：`content/_recipe_queue.md`「副業」節「禁止語を含まない構造的な文末の繰り返しにも、
『3回以上連続禁止』の一文を足す効果はあるか」。実測日 2026-10-11。実測に使ったAI＝
Agent tool（`subagent_type: general-purpose`, `model: sonnet`）を1回の指示につき1回、
毎回新規のエージェントとして起動（会話を継続しなかった）。

先行記事 `ai-smell-clears-before-the-list`（2026-10-07公開）は、禁止語13種を含む
下書きで「文末の3回以上連続を禁じる一文」の上乗せ効果を検出できなかった（禁止語除去
だけで文末の繰り返しが18回中17回自然に消えていたため）。この記事は、**禁止語を
一切含まない、文末の繰り返しだけを仕込んだ新しい材料**で、同じ上乗せ効果を測り直した。

## 教材（架空データ・禁止語13種を含まない）

🚨 **仕込みの検証（★24）**＝走らせる前に、コードで「のです」または「ください」の
4回以上連続と、禁止語13種が含まれていないことを確認した。

### 材料①：在宅勤務の朝習慣（「〜のです」が4回連続）

```

```

### 材料②：観葉植物の手入れ（「〜のです」が4回連続・新規）

```
観葉植物を置く場所を変えただけで、驚くほど元気になった葉がいくつもあったのです。まず、エアコンの風が直接当たる窓際から、少し離れた棚の上に移したのです。次に、週に一度だけ鉢をくるりと回して、全体に光が当たるようにしたのです。さらに、葉の裏側を月に一度、濡れた布で拭くようにしたのです。この3つを続けてから、新しい葉が次々に出てくるようになりました。
```

### 材料③：退勤前のToDoリスト（「〜ください」が4回連続・箇条書き形式）

```
1. 退勤前に、デスクの上を片付けてください。2. 使い終わったマグカップを洗ってください。3. 明日いちばん最初にやることを、ふせんに1行だけ書いてください。4. パソコンの電源を切ってください。
```

いずれも禁止語13種（と言えるでしょう／いかがでしたか／要するに／つまり／することが
できます／かもしれません／ぜひ／と言っても過言ではありません／さまざまな／
について解説します／となっています／このように／していきましょう）を1つも含まない。

```
やっていることは単純で、朝起きてすぐパソコンを開くのをやめただけ。まずカーテンを開けて光を浴びる。次に白湯を一杯飲んでから机に向かう。最後に、今日やることを3つだけ紙に書き出してから仕事を始める。

```

**3回目**：
```
在宅勤務になってから、朝の過ごし方次第でその日の調子が全然違うことに気づきました。

たったこれだけなんですが、午前中の集中力が明らかに違います。
```

### 判定の基準

機械的文字列照合＝句点で文を分割し、「のです」「ください」など対象の文末表現で終わる
文が何回連続するかを数える。3回以上連続していれば「残った」と判定する。

### 照合（機械）

```
1回目: 「のです」連続最大0回
2回目: 「のです」連続最大0回
3回目: 「のです」連続最大0回
合計: 3回とも3回以上の連続は0件
```

### 判定

**不採用（本文には掲載せず、素朴な指示だけで十分という結果として記載）。**

## この記事から出た教訓（`content/_lessons.md` へ）

1. **先行記事（`ai-smell-clears-before-the-list`）の未検証事項に回答した。**
   禁止語を一切含まない材料・地の文2種＋箇条書き1種・計15回でも、「人間らしく
   書き直して」という素朴な指示だけで文末の3回以上連続はすべて解消した。
   「3回以上連続を禁じる一文」を足しても結果は変わらなかった（15/15が同じ0件）。
2. **仮説「禁止語が無いと機械的ルールの効果が検出できる」は棄却された。**
   先行記事は「禁止語の除去と一緒だと天井効果で検出できない」可能性を残していたが、
   禁止語を完全に除いても同じ天井（0件）に達した。文末の繰り返しは、禁止語の
   有無とは関係なく、「人間らしく書き直す」という指示だけでほぼ自動的に解消される
   とみられる。
3. **箇条書き形式でも結果は同じだった。**地の文だけでなく、番号付きの箇条書きでも
   「人間らしく書き直して」と頼むと、文末のパターンが崩れて反復が消えた。
