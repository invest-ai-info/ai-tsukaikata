# 試した証拠 — two-days-back-stops-correctly-but-wording-shifts

[新しい相対語も一般化で直る](/recipes/relative-word-generalizes-but-yesterday-slips/)が本文末尾に残した未測定事項を実測した。
「2日前・3日前を指す語（一昨日など）や、同じ走り書きに複数の相対語が混ざる場合も試していません」。
同記事はその節で、先に受け皿の一文を提案していた。
「出てくる可能性があるなら、『前日より前を指す語が出た場合は、作業を止めて人に確認してください』という受け皿を先に足してください」。

この受け皿を実際に指示文へ足し、2つの観点を実測した。

1. 「一昨日」「おととい」のような**前日より前を指す語**が出たとき、受け皿は実際に止まるか
2. 同じ1行に**別の相対語が混ざっても**、誤って止まらずに済むか（今日型・前日型の意味区別が、新しい言い回しにも広がるか）

実行は、文脈を持たない新規のClaude（Agent機能・subagent_type: general-purpose）に、指示文と教材だけを渡し、
「一般的なチャットAIとして自然に返答する」よう頼んで得た。本実験の仮説は実行役には伝えていない。

判定は目視ではなく、各回の出力から「止まったか／続けたか」「書かれた日付」「追記された本文が入力と一致するか」を

一方、続けた8回のうち3回は追記した本文が入力と一致しなかった。これは指示文が「すでにある行は1文字も
変えないでください」とだけ約束していて、**新しく追記する行の本文については一字一句の保持を約束していない**
ため、違反ではないが、読者が自動化で使うときに気づきにくい副作用として記事に明記する。

## この記事から出た教訓（`content/_lessons.md` へ）

1. 🆕 「前日より前を指す語が出たら止めて確認」という受け皿は、「一昨日」「おととい」という
   2つの言い回しの違いにまたがって4/4回とも正しく機能した。
2. 🆕 受け皿を足しても、別の相対語（今日・昨日・本日・前日）が同じ行に混ざるだけでは誤って
   止まらなかった（6/6回）。「本日」「前日」という、指示文に例として挙げていない言い換えにも
   意味の区別はそのまま広がった（前作★の「意味で分けた一般化」の系列の再発）。
3. 🆕 指示文が保証していない部分（追記する本文そのものの一字一句）は、8回中3回、入力と違う
   文面に書き換えられた。日付の判定（何の日付にするか）は毎回正しかったが、本文の保持は
   別の約束が要る。自動化で元の走り書きをそのまま記録に残したいなら、「追記する文章は
   入力された文章をそのまま使ってください」という一文を別途加える必要がある。
