```
1か月あたりの金額として扱ってよいかは出品者の意図次第のため） 9.月額 10.月額

2回目: 1.別物 2.別物 3.別物 4.月額 5.別物 6.月額 7.別物 8.要確認（一括支払いの3ヶ月パックで、
単純に1か月分と同じ扱いにできるか判断が難しい） 9.月額 10.月額
```

### 照合（機械）

```
8番を「月額」と断定した回: 0/2（2回とも「要確認」）
8番を「別物」と断定した回: 0/2
合計: 「要確認」2/2。誤って「月額」と断定した回は0件だが、Phase4のように明確に「別物」とも
言い切っていない
```

### 判定

**採用。** 「迷うものは要確認に」を足すと、8番を誤って「月額」と断定する回は0件になった。ただしPhase4（1か月あたりに直す）のように「別物」と確定はせず、「要確認」という中間の答えになる。断定の誤りを防ぐ効果はあるが、答えそのものは出ない。

## Phase6. 8番だけを取り出して、単独で判定させる ― 2回

### 送った指示文（記事と同一文字列）

```
ココナラのインスタ運用代行の出品で、価格30,000円、出品ページの説明が「運用代行3ヶ月パック（一括支払い・月あたり10,000円相当）」というものがあります。この30,000円は、そのまま1か月分の運用代金ですか。
```

### 返ってきたもの（生・2回）

```
1回目: いいえ、そのまま1か月分の運用代金ではありません。「3ヶ月パック」「一括支払い」と
明記されているとおり、30,000円は3か月分の合計です。1か月あたりに直すと10,000円になります。

2回目: 違います。30,000円は3ヶ月ぶんをまとめて支払う価格で、1か月の運用代金としては
10,000円相当です。
```

### 照合（機械）

```
単独で聞いたとき、「1か月分ではない」と正しく判定した回: 2/2
```

### 判定

**採用。** 10件の中に混ぜて聞くと3回中1回（Phase1+2合計で2/6）誤判定した同じ項目を、単独で取り出して聞くと2回とも正しく判定した。他の9件と並べて聞くことが、この項目の判定を崩す一因になっている可能性がある。

## この記事から出た教訓（`content/_lessons.md` へ）

1. 前作（instagram-agency-rate-sticker-price-trap）の「本文を渡せば判定は崩れない」という結果は、件数を5件→10件に増やしても大枠では再現した（29/30・29/30）。
2. 新規＝複数月ぶんの価格を一括表示した項目（3ヶ月パック・30,000円）だけが、10件中ほかの9件と違って崩れた（6回中2回、月額と誤判定）。「1か月あたりに直して」と一文を足すと2/2で直り、単独で聞くと2/2で直ったが、「迷うものは要確認に」では「要確認」止まりで断定の答えは出なかった。
