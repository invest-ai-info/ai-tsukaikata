## 教材：架空の社内手順書（全文）

```
月次請求書の保管と経理連絡

対象：総務課の担当者
実施：毎月1日〜5日

1. 前月分の請求書をメールから集める。
2. 請求書を共有フォルダに保存する。
3. ファイル名を「取引先名_年月.pdf」に変更する。
4. 金額を確認する。不備があれば差し戻す。
5. 作成した請求明細表を添付して、経理に連絡する。
6. 経理から承認を受ける。
7. 請求書一覧を上長に提出する。
8. 保管完了の記録を残す。
```

```
【手順1】前月分の請求書をメールから集める
```

```
8/8   仕込んだ穴を全部見つけた
```

**記事の中心にした。**②との差は**実行させたことではなく、「止まってよい」と伝えたこと。**
指示文の後半3文が全部効いている。

- 「そこで止まって」＝止まる許可
- 「何が分からないから進めないのか」＝止まった先の受け皿（台帳1番）
- 「分からないことを自分で決めて先へ進まないでください」＝②で起きたことの名指し

⚠️ **3つのうち最後が特に要る。**②の返答が示すとおり、
**AIの既定は「決めて進む」**なので、止まる許可だけでは決めるほうが優先される。

```
違いが出るのは、次の点です。
```

## 指示文⑥（2通りに読める箇所と、結果の違い）

### 送った指示文（記事と同一文字列）

```
手順書の文のうち、2通り以上に読めるところを挙げてください。それぞれの読み方で実行した場合に、結果がどう変わるかも書いてください。
```

### 返ってきたもの（生・全文）

```
2通り以上に読める箇所を挙げます。

1. 手順2「請求書を共有フォルダに保存する」
　読み方A：手順1で集めた全ファイルをまとめて保存する
　読み方B：1件ずつ確認しながら保存する
　→ 手順3のファイル名変更をいつ行うかが変わります。Aなら保存後に一括、Bなら1件ずつ。件数が多い月は作業時間が変わります。

2. 手順4「金額を確認する」
　読み方A：請求書に書かれた合計金額と明細の合計が合っているかを見る（請求書の中で完結する確認）
　読み方B：発注内容や契約金額と突き合わせる（外部の資料が必要な確認）
　→ Aなら数分で終わり、Bには発注データが要ります。手順書はどちらか決めていないため、担当者が替わると確認の中身が変わります。

3. 手順4「不備があれば差し戻す」
　読み方A：不備のあった1社だけを差し戻し、残りは手順5へ進む
　読み方B：全社そろうまで手順5へ進まない
　→ Aなら経理への連絡が2回に分かれます。Bなら締切に間に合わない月が出ます。どちらで運用するかで、経理側の受け取り方も変わります。

4. 手順5「請求明細表」と手順7「請求書一覧」
　読み方A：同じ資料の呼び名違い
　読み方B：別の資料（明細表は金額の内訳、一覧は保管したファイルの目録）
　→ Aなら作る資料は1つ、Bなら2つです。作る手順はどちらも書かれていません。

5. 手順8「保管完了の記録を残す」
```

## この記事から出た教訓（`content/_lessons.md` へ）

1. **★新規：AIの既定は「決めて進む」。実行させるだけでは、穴は1件も出ない。**
   同じ手順書を「やってみて」と頼むと、**8手順とも完了・止まった報告0・
   自分で決めた値14件**で終わる。**穴のあった場所ほど丁寧に埋められる**
   （明細表を作る手順が無い所では、列まで決めて作ったことにした）。
   → **「できないところで止まって」＋「分からないことを自分で決めて先へ進まないで」**
   の2文で 0/8 → 8/8。**読ませて批評させた場合（5/8）より広い。**
2. **★新規：手順書は、書いた本人にとっては足りている。**
   「初めてやる人」と「毎月やっている人」で分けさせると、
   **初回にだけ必要な準備（権限・窓口・様式）が初回側に固まって出る。**
   手順書を書くのは毎月やっている人なので、ここが構造的に抜ける。
3. **台帳4番が再発（3本目）**＝あとから「自分で決めたことを挙げて」と聞くと、
   実際の14件のうち12件しか出ない。**漏れた2件は、値を書かずに黙って進んだ判断。**
   → **決めさせてから聞くのではなく、決めるその場で「仮置き」と印を付けさせる**と
   本文の印と一覧が12件で一致した。
4. **台帳1番が再発**＝「止まってよい」の許可だけでは足りず、
   **止まった先に何を書くか**（何が分からないから進めないのか）まで要る。
5. **台帳6番が再発**＝止まった理由が「情報が不足しています」だと直せない。
   **手順書の語を引用させる**と、直す場所が語の単位で決まる。
6. **台帳12番が再発（2本目・同じ晩）**＝1回目の計測で判定語を素の文字列でしか
   見ておらず、3件取りこぼした（「「不備」の基準」がかぎ括弧で分断されていた等）。
   **正規表現に直し、一致した実文字列を印字して目で確かめる形にした。**
