# 不足のある契約

**ひまわり保育園**
- 基本月額27,000円 / 入金0円 → **不足27,000円**
- 備考なし。全額未入金。

**月光印刷**
- 基本月額48,000円、備考では「年末休業オプション（3,000円）をキャンセル・返金対応済み」とのこと
- であれば請求額は 48,000 − 3,000 = **45,000円** になるはずですが、入金は41,000円
- → **不足4,000円**（備考の説明と入金額が一致していません。要確認）

# 参考：整合性OKのケース
**北斗自動車**は、備考で「多言語対応12,000円キャンセルにより請求額を40,000円に修正」とあり、実際に52,000−12,000=40,000円の入金があるため、説明と入金額は一致しており不足なしです。

他の契約（山田商会、さくら工房、高橋設計事務所、みなと食品、緑風堂、大地興業、青空クリニック、富士フーズ、虹の会計事務所）はすべて基本月額通りの入金で不足はありません。
