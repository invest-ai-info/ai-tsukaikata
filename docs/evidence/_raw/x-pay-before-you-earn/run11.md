結論から言うと、Basic（ベーシック）プランのままでは申請できません。

X の広告収益配分（クリエイター広告収益配分）やサブスクリプションといった収益化機能は、Premium または Premium+、あるいは Verified Organizations（認証済み組織）の加入者に限定されています。Basic は対象外で、収益化メニューを開いても「対象のプランではない」という趣旨の表示になり、申請ボタン自体が押せない状態になります。

## なぜ Basic だと弾かれるのか

Basic は「投稿の編集」「長文投稿」「ブックマークフォルダ」など、投稿まわりの機能だけを安く使うための入門プランという位置づけです。認証バッジ（チェックマーク）が付かず、返信の優先表示や収益化の解放も含まれません。

収益配分は「課金実績があり、バッジが付いているアカウント」に絞って支払う設計になっているため、バッジのない Basic は入口の時点で対象外になります。ここは裏技的な抜け道はなく、プランを上げるしかありません。

## 申請に必要な条件（Premium 以上にした上で）

- X Premium または Premium+ に加入している（または Verified Organizations）
- フォロワー 500人以上
- 直近3か月の投稿インプレッションが累計 500万以上
- 18歳以上
- 支払い受け取り用の Stripe アカウントを作れること（対応国に居住し、本人確認が通ること）
- クリエイター収益化基準および X のルールに違反していないこと

フォロワー 500人はそれほど高い壁ではありませんが、実質的にきついのはインプレッションのほうです。3か月で累計500万というのは、日々そこそこ伸びる投稿を継続していないと届かない水準だと考えておいたほうがいいです。

## 実際の流れ

1. サイドバーまたは設定の「Premium」から、プランを Premium 以上に変更する（Basic からのアップグレードは差額精算になります）
2. 認証バッジが付くのを待つ（審査に数日かかることがあります）
3. サイドバーの「収益化」→「広告収益配分」を開き、条件を満たしていれば申請する
4. Stripe に登録する（本人確認書類と銀行口座が必要）
5. 承認されると、累計が最低支払額（10ドル程度）を超えた時点で振り込まれる

## 先に知っておいたほうがいいこと

**Premium に入っただけでは1円も入りません。** 課金は「申請できる資格を得る」だけの意味しかなく、実際の支払いはフォロワー数とインプレッションの条件をクリアして初めて始まります。収益化目当てで先に課金したものの、条件に届かず月額だけ払い続ける、というのはよくあるパターンです。まず Basic のまま、あるいは無料のまま投稿を続けて、自分のインプレッションが3か月で500万に届きそうかを X アナリティクスで確認してから課金判断をするほうが安全です。

**配分の算定方法は何度も変わっています。** 当初は広告インプレッション基準でしたが、その後「Premium 加入者からのエンゲージメント」を軸にした算定に変更されるなど、ルールの改定が頻繁です。金額の期待値も、以前ネットで話題になった時期の数字はあてになりません。

**条件そのものも変わります。** フォロワー数やインプレッションの基準、対象プラン、対応国は変更されることがあるので、申し込む直前に X のヘルプセンターとアプリ内の Premium 画面で最新の条件を確認してください。上に書いた数字も、あくまで一般的に案内されている内容です。

なお、収益が発生した場合は日本では課税対象になり、給与所得者でも一定額を超えると確定申告が必要になります。金額が見えてきたら早めに税務署か税理士に確認しておくと安心です。
