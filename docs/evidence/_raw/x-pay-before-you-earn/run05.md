結論から言うと、自分から払う必要があるのは基本的に「X Premium の月額料金」だけです。応募料・登録料・審査料のようなものはありません。

**必ずかかるもの**

- **X Premium への加入**：クリエイター広告収益配分（およびサブスク機能）の対象になるのは Premium / Premium+ の加入者で、いちばん安い Basic プランは対象外という扱いです。つまり「青バッジが付くプラン」に入る必要があります。
- **日本の料金の目安**：Premium が Web 決済で月1,380円前後、iOS / Android のアプリ内課金だと月1,900円台と割高になります。年払いにすると1〜2割ほど安くなります。Premium+（月数千円〜）は受け取り開始の必須条件ではありません。

**無料のもの**

- Stripe アカウントの作成と本人確認（身分証の提出）
- 電話番号認証
- 銀行口座の登録

**実質かかるかもしれないもの**

- 受け取りは Stripe 経由で、X 側の手数料は基本的にありませんが、USD → JPY の為替・着金の過程で数%程度が目減りすることがあります。
- 稼いだ分は日本では雑所得（規模によっては事業所得）として申告対象になります。これは「先に払うお金」ではありませんが、手取りを考えるときには効いてきます。

**なので持ち出し額は「条件を満たすまでの月数 × 月額」で決まります**

- 3か月で条件クリア → 約4,000円
- 半年 → 約8,000円
- 1年 → 約1.7万円

ここが一番のポイントで、条件が地味に重いです。フォロワー500人以上に加えて、直近3か月で500万インプレッション（その後「Premium 会員からのエンゲージメント」を基準にする方式へ変更されています）、さらに累計収益が最低支払額（$10〜$50程度、時期によって変わっています）に届いて初めて振り込まれます。条件に届かないまま加入し続けると、月額だけが出ていく状態になります。「まず月1,380円を何か月払えるか」という予算の問題として考えるのが現実的です。

**注意**：料金も条件も X はかなり頻繁に変えています。上の数字は私の記憶ベースなので、契約前に X 公式ヘルプの資格要件ページと、実際の申込画面に出る料金表示で最新を確認してください。特に iOS アプリから入ると自動的に高いほうの価格になるので、**Web ブラウザから登録する**のが定番の節約ポイントです。
