結論から言うと、Basicプランでは申請できません。

Xの収益配分（クリエイター広告収益配分／Creator Revenue Sharing）は、応募条件そのものに「X Premium または Premium+ に加入していること（組織アカウントなら Verified Organizations）」が含まれています。Basic は Premium シリーズの一番安いプランですが、認証バッジも収益化機能も付かない位置づけで、収益配分の対象外です。

## Basic に含まれないもの（主なもの）

- 青い認証バッジ
- 広告収益配分
- クリエイターサブスクリプション（フォロワーからの有料サブスク受付）
- 返信の優先表示（ブースト）の強い版

Basic で使えるのは、投稿の編集、長文投稿、ブックマークフォルダといった「機能寄り」の部分です。収益化はひとつ上のプランからと考えてください。

## 収益配分の申請条件（Premium加入以外に必要なもの）

- 18歳以上
- フォロワー500人以上
- 直近3か月の投稿インプレッション合計500万以上
- Stripe が使える国に居住していて、本人確認と受取口座を登録できること
- X のルールと収益化基準（Monetization Standards）を満たしていること

これらは「全部そろって初めて申請できる」タイプの条件です。Basic のままだと、そもそも申請の導線が出ないか、プラン条件で弾かれます。

## 見落としやすい点

支払額の計算は「表示回数の多さ」ではなく「Premium 加入者からのエンゲージメント（返信など）」を基準にする方式に変わっています。バズっても、反応しているのが非課金ユーザーばかりだと金額は伸びません。フォロワー数やインプレッションはあくまで入口の条件で、稼げる額を保証するものではない、という点は先に知っておいたほうがいいです。

つまり「Basic → Premium にアップグレードすれば自動的に収入になる」のではなく、アップグレードは応募資格を得るための最低条件にすぎません。月額を払っても条件（500フォロワー・500万インプレッション）に届かなければ申請自体ができず、支出だけが先に出ます。

## 自分のアカウントで確認する手順

1. Xのサイドバー →「プレミアム」を開き、いま Basic / Premium / Premium+ のどれに入っているか確認する
2. サイドバー →「収益化」→「広告収益配分（収益分配）」を開く。ここに現在の条件と、自分がどれを満たしていないかが表示されます
3. 項目が出ない・グレーアウトしている場合は、プランか条件を満たしていないサインです
4. 最新の条件は X ヘルプセンターの収益配分のページで確認する

## 注意

プラン名・価格・条件は変更が多い領域です。ここに書いたのは私が把握している時点の内容なので、実際に申し込む前に、必ず上の手順2（アプリ内の収益化タブ）と手順4（ヘルプセンター）で現在の条件を確認してください。もし今の画面で Basic のまま収益化タブが出ているようなら、条件が変わっている可能性があります。その場合は画面の表示のほうを信じてください。
