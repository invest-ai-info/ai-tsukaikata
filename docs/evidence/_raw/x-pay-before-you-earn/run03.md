X（旧Twitter）で稼ぐには、「Xが直接払ってくれるお金」と「Xを入口にして外で稼ぐお金」の2系統があります。前者は条件が厳しいわりに単価が低いので、実際にまとまった額になっている人のほとんどは後者です。両方を分けて説明します。

## 1. X公式の収益化に必要な条件

**広告収益分配（クリエイター向けの収益シェア）**
- X Premium（有料サブスク）に加入していること
- フォロワー500人以上
- 直近3か月の累計インプレッションが500万以上
- 18歳以上
- Stripeアカウントを作れること（本人確認書類＋本人名義の銀行口座）
- 規約違反・スパム判定・センシティブ設定がないこと

**サブスクリプション（自分のアカウントを月額課金にする）**
- X Premium加入、フォロワー500人以上、直近で継続的に活動していること、18歳以上
- 受け取りは同じくStripe経由

なお、金額条件と分配ロジックは頻繁に変わります（当初は「返信欄に表示された広告」ベース、その後「認証ユーザーからのエンゲージメント」ベースへ変更されました）。実際に申し込む直前に、公式ヘルプで最新の条件を確認してください。

## 2. 金額の現実

広告分配の単価はかなり低く、月100万インプレッションでも数百円〜数千円というオーダーになることが多いです。ここを主目的にすると、パクリ・釣り・大喜利リプに寄っていき、インプレッションは増えてもフォロワーの質が落ち、後述の外部収益がゼロになる——という一番まずい形になりがちです。公式収益化は「おまけ」と割り切るのが現実的です。

## 3. 本命は「Xの外で稼ぐ」

- アフィリエイト（ASP案件、Amazon・楽天など）
- 自分の商品（note、教材、テンプレート、ツール、月額コミュニティ）
- 自分のサービス（コンサル、受託、代行、制作）
- 企業案件（PR投稿、レビュー、アンバサダー）
- 他媒体への送客（ブログのAdSense、YouTube、メルマガ／LINE）

ここで必要なのは、「誰の、どんな悩みを、どう解決するアカウントか」が一文で言えることです。ここが曖昧なままフォロワーだけ増やしても換金できません。逆に、この一文が明確なら、フォロワー1,000人でも月数万円は十分に射程に入ります。

## 4. 運用の実務として必要なもの

- ニッチの決定（自分が半年以上飽きずに書ける × お金が動く領域）
- プロフィール・固定ポスト・ヘッダーで「何の人か」と「次にどこへ行くか」を明示
- 毎日投稿できる仕組み（ネタのストック、型のテンプレ化、予約投稿）
- 伸びている中〜大アカウントへの早いリプライ（初期の露出源はほぼこれ）
- 数字を見る習慣（インプレッション／プロフィールクリック／フォロー転換率／リンククリック）
- 最終的にリスト化（メルマガ・LINE・自サイト）。Xの外へ資産を逃がす

## 5. 落とし穴

- **凍結リスク**：X単体依存だと一夜で収入ゼロ。必ず外部の受け皿を先に作る
- **ステマ規制**（景表法、2023年10月〜）：広告・PRは「PR」等の明示が必須
- **税金**：副業なら年20万円超で確定申告が必要（20万円以下でも住民税の申告は必要）。専業なら基礎控除48万円が目安。最終的な判断は税務署か税理士に確認を
- 金融・医療・法律など規制のある分野は、断定的な助言や資格の要る行為に踏み込まない
- 規約とアルゴリズムの変更が速い。1つの収益源に賭けない

## 6. 現実的な順番

1. ニッチと「最終的に何を売るか」を先に決める
2. プロフィールと固定ポストを整え、導線を作る
3. 90日、毎日投稿＋リプライで、フォロワー500人と自分の型を作る
4. X Premiumに加入し、Stripeを登録（ここで初めて公式収益化が視野に入る）
5. 広告分配はおまけと割り切り、アフィリエイト／自分の商品／案件で単価を上げる
6. メルマガ・LINE・自サイトへ逃がして、凍結耐性を作る

一言でまとめると、必要なのは「Premium課金＋フォロワー500人＋500万インプレッション＋Stripe」という**入場券**と、それとは別に「何を売るか」という**設計**です。入場券だけ揃えても、月数百円で終わります。
