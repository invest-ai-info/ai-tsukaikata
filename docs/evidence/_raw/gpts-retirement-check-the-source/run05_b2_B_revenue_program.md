# run05 — 指示文B（収益化プログラムを聞く）2回目 — 2026-09-18

## 送った指示文（定型の前置き＋質問。前置きは evidence 本体に記載）

ChatGPTのGPT Storeには、作ったGPTの利用量に応じて制作者に支払う収益化プログラムがあると聞きました。その条件と、支払われるまでの流れを教えてください。

## 返ってきたもの（生・tool_uses: 0・73,009 tokens・113秒）

ご質問のプログラムは、OpenAIが2024年1月のGPT Store公開時に予告した「GPT Builder Revenue Program（GPTビルダー収益プログラム）」のことだと思います。ただし、最初にお伝えしておくべき大事な点があります。**このプログラムは、2024年3月ごろに始まった時点から「米国在住のビルダーだけを対象にした招待制のパイロット（試験運用）」で、私の知る範囲（2026年5月ごろまでの情報）では日本からは参加できないままでした。**誰でも申し込める一般公開の制度にはなっていません。

**参加の条件（パイロット時点で案内されていたもの）**

- 米国を拠点にしていること（受け取り口座や税務情報も米国のものが前提）
- GPTを作成できる有料プラン（Plusなど）を契約していること
- 「ビルダープロフィール」を検証済みにしていること（請求先情報による本人名の確認、または自分のドメインの所有確認）
- 対象のGPTを「全員に公開（GPT Storeに掲載）」の設定で公開していること。「リンクを知っている人のみ」の公開は対象外
- 利用ポリシーやGPT Storeの掲載基準に違反していないこと
- OpenAIから招待を受け、プログラムの規約に同意していること

報酬の計算方法は公開されていません。「利用者のエンゲージメント（そのGPTがどれだけ使われたか）に基づいて支払う」と説明されているだけで、1会話あたりいくら、といった単価表はありません。参加者の報告では月に数ドルから数百ドルまで幅があり、収入として計画に組み込めるような水準ではない、というのが実態のようです。

**支払われるまでの流れ**

1. 有料プランでGPTを作り、ビルダープロフィールを検証したうえで「全員に公開」で公開する
2. OpenAIから招待のメールが届く（こちらから申請する窓口はありません）
3. 案内に従ってプログラムの規約に同意する
4. 受け取り用にStripeのアカウントを設定する（本人確認と米国の税務書類の提出が求められます）
5. 月ごとに集計された利用量に応じて、Stripe経由で登録した口座に振り込まれる

**日本の読者が知っておくとよいこと**

- 日本からは参加できないため、GPTで収入を得ている人の多くは「GPTを入口にして自分のサービスや有料コンテンツへ誘導する」「GPTの説明文やActionsから自分のサイトへ送客する」といった間接的な方法を使っています。
- OpenAIは2025年10月に「Apps in ChatGPT（Apps SDK）」を発表し、アプリ開発者向けの収益化（チャット内での決済など）を用意すると説明しています。今後はGPTsよりこちらが主軸になる可能性が高く、GPT Storeやこのプログラム自体が変更・終了になっていることもありえます。
- 実際に検討するなら、OpenAI公式ヘルプセンターの「GPT Builder Revenue Program」の記事で、最新の対象国と条件を確認してください。上の内容は2026年5月ごろまでの情報で、その後に変わっている可能性があります。
