## 1. 動くモデルが入れ替わった

- 2025年8月にGPT-5が既定モデルになり、GPTsもGPT-5系で動くようになりました。
- 2026年2月13日に、ChatGPT上のGPT-4o・GPT-4.1・o4-miniが提供終了になりました（API側では継続）。GPT-4oの口調や挙動を前提に作り込んだGPTは、同じ指示文でも返答の調子が変わっている可能性があります。GPT自体は消えませんが「以前どおり動く」保証はないので、使っているGPTは一度動作を確かめ直すことをおすすめします。
- 2025年にGPTの設定でモデルを指定できる仕組みが入りましたが、指定先のモデルが終了すれば別モデルに置き換わります。

## 2. 開発者向けの主軸が「Apps in ChatGPT」に移りつつある

- 2025年10月のDevDayで、MCPを土台にした「Apps SDK」と「Apps in ChatGPT」が発表され、その後アプリの公開申請とディレクトリも順次始まっています。画面付きの部品を出す、外部サービスと深く連携する、といった用途はこちらが本命になっています。
