ただし「今後もずっと今のまま」と言い切れる材料もありません。理由は3つあります。

第一に、OpenAIは2025年10月の開発者向けイベント（DevDay）で「Apps in ChatGPT」と、その開発キット「Apps SDK」（MCPという共通規格をベースにした仕組み）を発表し、同年12月にはChatGPTの中にアプリのディレクトリを開設しました。これは外部サービスをChatGPTに組み込む手段として、GPTsの「Actions」より高機能な、事実上の後継の位置づけです。GPTストアとアプリのディレクトリが将来統合される、あるいはGPTsの比重が下がっていく可能性は十分あります。ただ、私の知る限りでは、具体的な移行スケジュールや「GPTsを何年何月に終了する」という告知はありませんでした。

第二に、GPTsの中身が変わらなくても、それを動かしているモデルのほうが入れ替わります。GPTsは基本的にChatGPTの既定モデルで動くため、GPT-5への切り替え（2025年8月）や、GPT-4oなど旧モデルのChatGPTからの引退（2026年2月）のようなタイミングで、同じ指示文でも答え方や口調が変わることがあります。「使えなくなる」のではなく「挙動が変わる」という形の変更は、今後も定期的に起きると考えておくほうが安全です。

第三に、個人で使う用途では、ChatGPTの「プロジェクト」機能（指示文やファイルを紐づけて会話をまとめる機能）がGPTsと役割が重なっており、OpenAIはこちらを無料ユーザーにも広げています。自分ひとりで使うカスタムGPTなら、いずれプロジェクトに寄せるほうが自然になる流れです。

なお、私の知識には期限があり、それ以降にOpenAIが方針を発表していれば反映できていません。この種の話題は変化が速いので、判断の前にOpenAI公式のヘルプセンター（GPTsに関する記事）、ChatGPTのリリースノート、開発者向けの発表ページを直接確認することを強くおすすめします。特に「廃止時期」のような具体的な日付は、AIの回答を鵜呑みにせず、必ず公式の一次情報で裏を取ってください。
