## 送った指示文（定型の前置き＋質問。前置きは evidence 本体に記載）

ChatGPTのGPT Storeには、作ったGPTの利用量に応じて制作者に支払う収益化プログラムがあると聞きました。その条件と、支払われるまでの流れを教えてください。

## 返ってきたもの（生・tool_uses: 0・71,660 tokens・98秒）

結論から言うと、「作ったGPTの利用量に応じて制作者に支払う仕組み」はOpenAIが発表はしたものの、誰でも参加できる正式なプログラムとしては公開されていません。私の知る範囲（2026年春ごろまでの情報）では、米国の一部制作者だけを招待した試験運用にとどまっており、日本在住の制作者が申し込める窓口はありません。以下、経緯・条件・流れの順に整理します。

**経緯**

2024年1月10日にGPT Storeが公開された際、OpenAIは「2024年第1四半期にGPTビルダー収益プログラムを開始する。第一歩として、米国の制作者に対し、GPTへのユーザーのエンゲージメント（どれだけ使われたか）に基づいて支払う」と発表しました。同年3月、少数の米国制作者を招待する形でパイロット（試験運用）が始まりましたが、その後一般公開へ拡大されることはなく、公式ヘルプの記述も「限定的なパイロット中。詳細は拡大時に共有する」という趣旨のまま止まっています。2025年10月のDevDayではChatGPT内で動く「アプリ」（Apps SDK）が発表され、収益化の仕組み（Agentic Commerce Protocolへの対応など）はそちらで後日案内すると表明されました。つまりOpenAIの重心はGPTsからアプリへ移っており、GPTsの位置づけ自体も今後変わる可能性があります。

**条件（公表・報道されている範囲）**

- 米国在住で、米国の銀行口座と税務情報を登録できること（18歳以上）
- ビルダープロフィールの認証（氏名またはドメインの検証）を済ませ、GPTを「全員に公開」でストアに掲載していること
- OpenAIの利用ポリシーおよびGPT Storeのポリシーに違反していないこと
- 支払い受け取り用にStripeのアカウントを設定すること
- 支払いの基準は「エンゲージメント」で、GPTに値段を付けて売る仕組みではありません。単価や計算式は公表されていません
- 招待制で、自分から応募する手段はありません

**支払われるまでの流れ（パイロット参加者の報告に基づく）**

1. OpenAIから招待の連絡が届く
2. プログラム規約に同意し、Stripeで受け取り口座と税務書類を登録する
3. 一定期間（月単位と報告されています）のエンゲージメントがOpenAI側で集計される
4. Stripe経由で米ドルで振り込まれる

**現実的な注意点**

日本からは参加できず、米国内でも招待されなければ参加できません。したがって「GPTの利用量そのもので稼ぐ」ことを前提に作るのはおすすめしません。実際にGPTで収益を上げている人は、GPTを集客の入口にして自分のサービス・教材・アフィリエイトへ誘導する、あるいはActions機能で自前のAPIやウェブサービスに接続し、その先で課金する、といった間接的な方法を取っています。

なお、私の情報には時点の限界があります。最新の状況はOpenAIのヘルプセンターで「GPT builder revenue program」や、ChatGPTアプリの収益化に関する案内を確認してください。
