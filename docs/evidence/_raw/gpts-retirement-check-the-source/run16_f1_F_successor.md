まず言葉の整理をしておきます。OpenAIがGPTsの後継として案内しているのは、2025年10月のDevDayで発表された「Apps SDK」で作る「ChatGPTの中で動くアプリ（apps in ChatGPT）」です。土台はMCP（Model Context Protocol）で、開発者が自分のサーバーを用意し、ChatGPTの会話の中にアプリの画面を出せる仕組みです。なお「プラグイン」という名前は2023年の別の機能で、2024年にGPTsへ置き換えられて終了しています。ご質問はこの「アプリ」のことだと理解して答えます。

収益化について私が知っている経過は次のとおりです。発表時（2025年10月）、OpenAIは「年内にアプリの提出受付とディレクトリ（一覧ページ）を始め、開発者が収益化する方法は後日案内する。ChatGPT内で決済を完結させるInstant Checkoutを支えるAgentic Commerce Protocol（ACP）への対応を含む」と説明しました。2025年12月ごろにアプリの提出受付とディレクトリが始まりましたが、この時点でも収益化は「2026年に案内する」という予告にとどまっていたと記憶しています。そのACP／Instant Checkoutは、EtsyやShopifyの加盟店などが商品をChatGPT内で販売し、完了した購入ごとに販売者側が手数料を払う仕組みで、当初は米国の利用者向けでした。これは「商品の販売」の仕組みであって、「アプリ自体の利用料を取る」仕組みではありません。手数料率も公表されていなかったと思います。

つまり、私の知識の範囲で個人が収入につなげる現実的な道は二つで、ひとつはアプリ自体は無料で公開し、自分のサービス側で課金する（自サイトの有料プランにログインさせて使わせる等）こと、もうひとつは物販をしているなら加盟店としてInstant Checkoutを使うことです。「ChatGPTのアプリ一覧で値段を付けて売り、OpenAIから振り込まれる」形は確認できていません。
