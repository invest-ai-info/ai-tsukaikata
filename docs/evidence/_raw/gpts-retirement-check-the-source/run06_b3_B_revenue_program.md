## 送った指示文（定型の前置き＋質問。前置きは evidence 本体に記載）

ChatGPTのGPT Storeには、作ったGPTの利用量に応じて制作者に支払う収益化プログラムがあると聞きました。その条件と、支払われるまでの流れを教えてください。

## 返ってきたもの（生・tool_uses: 0・70,854 tokens・87秒）

結論から言うと、そのプログラムは「発表され、米国の少数の制作者で試験運用された」段階で止まっており、誰でも参加できる条件表や支払い規定は（私の知る範囲では）公開されていません。「利用量に応じて支払われる」という前提でGPTを作ると期待外れになるので、まずそこを押さえてください。

## これまでの経緯

- **2024年1月10日（GPT Store公開時）**: OpenAIが「第1四半期にGPTビルダー収益プログラムを開始する。まず米国のビルダーを対象に、GPTへのユーザーのエンゲージメントに基づいて支払う。支払い基準の詳細は追って案内する」と発表。
- **2024年3月末**: 「米国の少数のビルダーと、利用量に基づく収益の試験を始めた」と告知。招待制で、選ばれた人にだけメールで案内が届きました。自分から申し込む窓口はありませんでした。
- **それ以降**: 対象国の拡大や、単価・計算式（1会話あたりいくら、など）の公開は行われていません。招待されなかった多くの制作者にとっては「存在はするが入れない」状態が続いています。
- **2025年10月以降**: OpenAIは「ChatGPT内アプリ（Apps SDK）」を発表し、開発者の収益化はアプリ側（Agentic Commerce Protocolによる決済など）で進める方針を示しています。GPT単体の利用量課金プログラムを広く開放する見通しは示されていません。

## 分かっている参加条件（試験運用の時点）

1. **米国在住の個人または事業者であること**。日本からは対象外です。
2. **OpenAIからの招待を受けること**。公募・申請制ではありません。
3. **ビルダープロフィールが認証済みであること**。氏名認証（有料プランの請求名で確認）か、ドメイン認証（自分のサイトのDNSにTXTレコードを置く）のどちらか。
4. **GPTを「全員」に公開してGPT Storeに掲載されていること**。利用ポリシーとブランドガイドラインに違反していないこと。
5. **支払いは「エンゲージメント（利用量）」に基づく**。ただし、何を1単位と数えるか、単価はいくらか、は非公開です。

## 支払われるまでの流れ（試験運用の参加者の場合）

1. OpenAIから招待メールが届き、プログラムの規約に同意する。
2. 支払い口座を設定する（Stripe経由と報告されています）。米国の税務書類の提出も必要。
3. OpenAIが一定期間のGPT利用量を集計する。
4. 集計に基づいて支払われる。頻度や最低支払額は公開されていません。

参加者からの報告も少なく、金額は小さかったという声が目立ちます。「月に何万円」といった具体的な数字を載せている記事は、公式発表に基づかない推測である可能性が高いです。

## 日本の制作者にとっての現実

- 現状、GPT Storeから直接お金が入る仕組みはありません。
- 実際に使われているのは、GPTを「入口」にして自分のサービス・note・教材・アフィリエイト先へ案内する形、またはActions（外部連携）で自前の有料サービスにつなぐ形です。GPTそのものではなく、その先で収益を作る発想が必要です。
