1. 結論:精算できる
根拠:第2条(宿泊費) 上限12,000円以内(11,000円)のため。

2. 結論:精算できない
根拠:第3条(会食費) 上限は「一人当たり」5,000円であり、合計額ではなく一人当たり単価(5,600円)が基準を超えているため。

3. 結論:精算できない
根拠:第6条(申請期限) 支出日から30日以内の申請が必要であり、35日後の申請は「30日を超えた申請は原則却下」に該当するため。

4. 結論:規程に記載なし
本規程には駐車場代に関する条文がありません。第1条は電車・バス・新幹線、第4条はタクシーのみを対象としており、駐車場代は明記されていないため、この規程だけでは判断できません。上長にご確認ください。

5. 結論:精算できない
根拠:第7条(私的な支出) 自宅の電気代は業務専用の支出と切り分けられない私的支出に該当し、精算対象外と考えられるため。
※なお、在宅勤務手当等の別制度がある場合はそちらの規程による可能性があるため、制度の有無について上長にご確認いただくことをお勧めします。

6. 結論:規程に記載なし
第5条は「3万円未満は課長決裁、3万円以上は部長決裁」と定めており、決裁不要で自己判断購入できる金額の定めはありません。決裁を経ずに購入できる範囲について本規程からは判断できないため、上長にご確認ください。
