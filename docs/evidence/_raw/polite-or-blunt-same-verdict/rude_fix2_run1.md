# 経費精算 判定結果

**1**
結論:精算できる
根拠:第2条(宿泊費)。宿泊費の上限は1泊12,000円(税込)。今回は11,000円で上限以下のため精算対象。

**2**
結論:精算できない
根拠:第3条(会食費)。取引先との会食は一人当たり上限5,000円。実際は一人当たり5,600円で上限を超えており、申請どおりの全額精算はできない。

**3**
結論:精算できない
根拠:第6条(申請期限)。支出日から30日以内の申請が原則で、30日を超えた申請は原則却下。今回は35日後の申請であり、原則に従えば却下対象。
※ただし条文が「原則却下」という表現になっており、例外扱いの余地が規程上残っているため、条文をそのまま機械的に当てはめきれない部分があります。上司に確認してください。

**4**
結論:規程に記載なし
根拠:駐車場代を対象とした条文が規程内に存在しない(第1条は電車・バス・新幹線、第4条はタクシーのみを規定)。出張関連費用として類推適用できるかは規程からは判断できない。上司に確認してください。

**5**
結論:規程に記載なし
根拠:在宅勤務の光熱費(電気代)を対象とした条文が規程内に存在しない。第7条は「業務に関係しない支出は対象外」と定めるのみで、業務按分できる光熱費の取り扱いには触れていないため、規程からは判断できない。上司に確認してください。

**6**
結論:規程に記載なし
根拠:第5条(備品購入)は「3万円未満は課長決裁、3万円以上は部長決裁」としており、金額の大小にかかわらず必ず決裁が必要と読める。決裁不要で自己判断購入できる金額の定めは規程上存在しない。上司に確認してください。
