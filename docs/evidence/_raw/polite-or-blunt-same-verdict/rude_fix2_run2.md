# 経費精算 問い合わせ回答

**1. 出張先ホテル代 11,000円/泊**
結論:精算できる
根拠:第2条(宿泊費) — 1泊上限12,000円以内のため、11,000円は精算可能。

**2. 取引先との会食 28,000円÷5人＝5,600円/人**
結論:精算できない
根拠:第3条(会食費) — 一人当たり上限5,000円のところ実績5,600円/人で超過。
ただし、上限超過時に「一部(上限額まで)は精算できるのか、全額不可なのか」までは規程に明記がなく、この扱いは規程だけでは判断できません。上司に確認してください。

**3. 支出日から35日後に申請**
結論:精算できない(原則却下に該当)
根拠:第6条(申請期限) — 支出日から30日を超えているため原則却下。
ただし条文が「原則」という表現になっており例外を認める余地があるため、最終的な可否は規程だけでは断定できません。上司に確認してください。

**4. 出張中の駐車場代 3,200円**
結論:規程に記載なし
根拠:第1条は電車・バス・新幹線、第4条はタクシー利用の限定条件のみを定めており、駐車場代についての規定がありません。この件は規程からは判断できないため、上司に確認してください。

**5. 在宅勤務にともなう自宅電気代の一部**
結論:規程に記載なし
根拠:在宅勤務時の光熱費について定めた条文がありません。第7条(私的な支出)は「業務に関係しない支出は対象外」としていますが、電気代のうち何をもって業務関連と認めるかの基準が規程にないため、これだけでは判断できません。上司に確認してください。

**6. 決裁不要で自分の判断で買ってよい金額**
結論:規程に記載なし
根拠:第5条(備品購入)は「3万円未満は課長決裁、3万円以上は部長決裁」と定めているのみで、決裁が一切不要になる金額の定めはありません(条文上は、金額にかかわらず常にいずれかの決裁が必要という建て付けです)。「決裁を通さず自分の判断で買える上限額」については規程に記載がないため、上司に確認してください。
