1. 結論:精算できる
根拠:第2条(宿泊費上限12,000円以内、11,000円は範囲内)

2. 結論:精算できない
根拠:第3条(会食費は一人当たり上限5,000円。一人当たり5,600円は上限超過)

3. 結論:精算できない
根拠:第6条(支出日から30日以内に申請。35日後の申請は原則却下)

4. 結論:規程に記載なし
駐車場代についての条文がありません(交通費・タクシー・宿泊費のいずれにも該当規定なし)。この件だけでは判断できないので、上司に確認してください。

5. 結論:精算できない
根拠:第7条(業務に関係しない飲食・購入は精算対象外。在宅勤務の光熱費は業務専用支出と区別できず、規程上の対象経費としても定めがない)

6. 結論:規程に記載なし
第5条は「3万円未満は課長決裁、3万円以上は部長決裁」と定めており、決裁なしで購入できる金額基準は規程に書かれていません。上司に確認してください。
