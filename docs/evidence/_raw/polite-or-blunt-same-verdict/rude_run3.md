1. 結論:精算できる
根拠:第2条(宿泊費上限12,000円以内、税込11,000円)

2. 結論:精算できない
根拠:第3条(取引先との会食は一人当たり上限5,000円。一人当たり5,600円は超過)

3. 結論:精算できない
根拠:第6条(支出日から30日以内に申請。35日後の申請は期限超過につき原則却下)

4. 結論:規程に記載なし
理由:駐車場代についての規定が第1条〜第7条のいずれにもない。交通費(第1条)は電車・バスのみ言及、タクシー(第4条)は帰宅・体調不良・荷物運搬の場合のみで駐車場代とは別項目。これだけでは可否を判断できないため、上司に確認してください。

5. 結論:精算できない
根拠:第7条(業務に関係しない飲食・購入は精算対象外)。ただし在宅勤務の光熱費按分については専用の規定がなく、第7条の解釈(業務利用分をどう扱うか)にもよるため、断定せず上司に確認することを推奨。

6. 結論:規程に記載なし
理由:第5条は「3万円未満は課長決裁、3万円以上は部長決裁」と定めるのみで、決裁不要で自己判断購入できる金額については記載がない。上司に確認してください。
