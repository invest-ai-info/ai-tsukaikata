1. 出張先ホテル代 1泊11,000円
結論:精算できる
根拠:第2条(宿泊費) 上限12,000円以内のため。

2. 取引先と5人で会食、合計28,000円(一人当たり5,600円)
結論:精算できない
根拠:第3条(会食費) 一人当たり上限5,000円を超過しているため。

3. 支出から35日後の申請
結論:精算できない
根拠:第6条(申請期限) 支出日から30日以内の申請が必要で、超過分は原則却下のため。

4. 出張中の駐車場代 3,200円
結論:規程に記載なし
根拠:第1条は電車・バス・新幹線、第4条はタクシーの利用条件を定めているが、駐車場代についての規定はない。この規程だけでは判断できないため、上長に確認してください。

5. 在宅勤務に伴う自宅電気代の一部
結論:精算できない
根拠:第7条(私的な支出) 業務に直接関係しない支出は精算対象外であり、また電気代を経費計上できる旨の条文が存在しないため。

6. 備品購入時、決裁不要で自己判断可能な金額
結論:規程に記載なし
根拠:第5条は「3万円未満は課長決裁」と定めており、金額の大小にかかわらず決裁自体は必要とされている。決裁不要で購入できる基準額は規程に記載がないため、上長に確認してください。
