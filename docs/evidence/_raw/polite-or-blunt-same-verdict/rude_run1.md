# 判定結果

**1. ホテル代 1泊11,000円**
結論:精算できる
根拠:第2条により上限12,000円(税込)以内のため。

**2. 取引先と5人で会食、合計28,000円(一人当たり5,600円)**
結論:精算できない
根拠:第3条の上限「一人当たり5,000円」を超過しているため。

**3. 支出から35日後の申請**
結論:精算できない
根拠:第6条「支出日から30日以内に申請」に反し、30日を超える申請は「原則却下」と定められているため。

**4. 出張中の駐車場代 3,200円**
結論:規程に記載なし
根拠:第1条(交通費)は電車・バス・新幹線のみ規定、第4条(タクシー)も駐車場代とは別項目であり、駐車場代を対象とする条文がない。この規程だけでは判断できないため、上司に確認してください。

**5. 在宅勤務に伴う自宅電気代の一部**
結論:規程に記載なし
根拠:光熱費・在宅勤務関連費用を対象とする条文がない。第7条は「業務に関係しない支出は対象外」と定めるのみで、業務按分の可否・方法までは規定されていない。この規程だけでは判断できないため、上司に確認してください。

**6. 備品購入で決裁不要となる金額の上限**
結論:精算できない(=決裁不要で自己判断購入できる金額区分は存在しない)
根拠:第5条は「3万円未満は課長決裁、3万円以上は部長決裁」と定めており、金額の大小にかかわらずいずれかの決裁が必須。決裁なしで購入できるケースは規程上規定されていない。
