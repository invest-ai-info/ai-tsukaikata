# D3 (agent a11527fd) — 部門別経費表 (SUBTOTAL方式)
結論：SUBTOTAL関数（=SUBTOTAL(9, 範囲)）を使うのが一番きれいに解決します。SUBTOTALには「自分が合計する範囲の中に、別のSUBTOTALの結果（＝下位の小計）が混ざっていても、それを無視して二重に数えない」という性質があります。

**①担当者ごとの小計**
例：F7（営業部担当01小計）
=SUBTOTAL(9,F2:F6)
どの担当者も「自分の1〜5行上を合計」という同じパターンなので、F7に入れたらそのままコピーして他の小計行（F13、F19、F25…）すべてに貼り付ければ正しい範囲になる。

**②部署の中計**
例：F92（営業部中計）
=SUBTOTAL(9,F2:F91)
どの部署も「担当者15人×6行＝90行」で構成が揃っているので、「自分の90行上から1行上まで」という同じパターンになる。F92に入れた数式はそのままF184（総務部中計）・F275（人事部中計）・F366（経理部中計）にコピーして使える。

**③事業部の大計**
フロント事業部大計（F93）：
=SUBTOTAL(9,F2:F92)
（フロント事業部は営業部1つだけなので、最初のデータ行から中計行までが範囲）

バックオフィス事業部大計（F367）：
=SUBTOTAL(9,F94:F366)
（総務部・人事部・経理部の3部署分、最初のデータ行から経理部中計行までが範囲）

大計は配下の部署数が事業部によって違うので、この2つだけは個別入力になります（コピーでは揃いません）。

**④総合計**
F368：
=SUBTOTAL(9,F2:F367)

【行を増やすときに1つだけ守ってほしいこと】
新しい担当者や新しい部署を追加するときは、既存の小計・中計・大計行の「真上」に行を挿入してください。
