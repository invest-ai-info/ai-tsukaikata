# D5 (agent ad16b5aa) — 部門別経費表
それぞれの集計欄には、固定の範囲を指定する SUM ではなく、D列の文字を手がかりにする SUMIFS を使う。集計欄自身のD列の文字列は、それぞれの検索条件に引っかからないので、range から除外する操作をしなくても勝手に自分を除外できる。

**①担当者の小計**（例: F10セル、営業部担当01小計の行）
=SUMIFS($F:$F,$A:$A,A10,$B:$B,B10,$C:$C,C10,$D:$D,"経費")

**②部署の中計**（例: F95セル、営業部中計の行）
=SUMIFS($F:$F,$A:$A,A95,$B:$B,B95,$D:$D,"*小計")

**③事業部の大計**（例: F96セル、フロント事業部大計の行）
=SUMIFS($F:$F,$A:$A,A96,$D:$D,"*中計")

**④総合計**（F368セル）
=SUMIFS($F:$F,$D:$D,"*大計")
