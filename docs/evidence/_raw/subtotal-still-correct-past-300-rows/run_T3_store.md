# T3 (agent a0bb29be) — 店舗別売上表
この構成なら、SUMIFSを使い、D列="売上"の行だけを対象にA/B/C列で絞り込む4パターンの数式（店舗小計・エリア中計・地域大計・総合計）を提示する。自分自身を含まず行追加にも対応できる理由を説明する。

①店舗小計（例：9行目「関東01店小計」のF9）
=SUMIFS($F:$F,$C:$C,C9,$D:$D,"売上")
②エリア中計（例：82行目「関東中計」のF82）
=SUMIFS($F:$F,$B:$B,B82,$D:$D,"*小計")
③地域ブロック大計（例：83行目「東日本大計」のF83）
=SUMIFS($F:$F,$A:$A,A83,$D:$D,"*中計")
④総合計（328行目のF328）
=SUMIF($D:$D,"*大計",$F:$F)
