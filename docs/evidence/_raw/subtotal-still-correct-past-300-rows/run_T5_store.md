# T5 (agent a787a341) — 店舗別売上表 (SUBTOTAL方式)
使う関数は SUBTOTAL 一つで解決できます。

【カギになる性質】
SUBTOTAL(9, 範囲) は合計(SUM相当)を返しますが、範囲の中に他のSUBTOTAL式の結果が混ざっていると、その行は自動で無視して集計します。つまり「小計・中計・大計を二重に数えないように手で除外する」必要がなく、範囲を広めに取って丸ごとSUBTOTALで囲むだけで、中に入っている下位の小計たちは自動で除外され、生の売上行だけが足されます。

【実際の式(頂いた表の行番号で。1行目=見出し、2行目から売上開始)】

店小計:
F9 (関東01店小計) = SUBTOTAL(9,F2:F8)
F17 (関東02店小計) = SUBTOTAL(9,F10:F16)
F25 (関東03店小計) = SUBTOTAL(9,F18:F24)
同じエリア内は8行ごとに同じパターンなので、F9の式をコピーして貼るだけで相対参照が自動でずれて正しい範囲になる(エリアが変わる最初の店だけ開始行が変わるので1回だけ手で合わせる)。

中計(そのエリアの最初の売上行〜自分の1行上):
F82 (関東中計) = SUBTOTAL(9,F2:F81)
F164 (関西中計) = SUBTOTAL(9,F84:F163)
F245 (中部中計) = SUBTOTAL(9,F165:F244)
F326 (九州中計) = SUBTOTAL(9,F246:F325)

大計(そのブロックの最初の売上行〜自分の1行上):
F83 (東日本大計) = SUBTOTAL(9,F2:F82)
F327 (西日本大計) = SUBTOTAL(9,F84:F326)

総合計:
F328 (総合計) = SUBTOTAL(9,F2:F327)

【注意点】
- 範囲の開始位置は「同じかそれより上の階層の、直前の区切り行の次の行」にすること。常にF2からにしてしまうと、他のエリア・ブロックの生データまで混ざって二重集計になる。
- 行を増やすときは、そのセクションの内側に挿入する。既存のブロックの中に差し込む形にするのが安全。
