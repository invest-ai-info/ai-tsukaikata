# T1 (agent aa10f19b) — 店舗別売上表
Excelの表、拝見しました。要点は「区分（D列）の文字列パターン」と「上位列（A〜C）の一致」を組み合わせたSUMIFSで、階層ごとに「ひとつ下の階層の集計行だけ」を拾う、という考え方です。こうすると自分自身は絶対に含まれず、行が増えても範囲をいじる必要がありません。

具体的には、こんな式になります。

**① 店舗小計（例：9行目「関東01店小計」のF9）**
```
=SUMIFS($F:$F,$C:$C,C9,$D:$D,"売上")
```
→ 同じ店舗名（C列が自分と同じ）かつ区分が「売上」の行だけを合計します。他の店舗の行はC列が違うので絶対に混ざりません。これを全店舗の小計行（F17、F25、F33…）に同じ形でコピーすればOKです。

**② エリア中計（例：82行目「関東中計」のF82）**
```
=SUMIFS($F:$F,$B:$B,B82,$D:$D,"*小計")
```
→ 同じエリア名（B列が自分と同じ「関東」）かつ区分が「〇〇店小計」で終わる行だけを合計します。生の売上行（区分が「売上」）は条件に合わないので無視され、二重集計になりません。これを中部中計（F245）、九州中計（F326）などにも同じ形でコピーできます。

**③ 地域ブロック大計（例：83行目「東日本大計」のF83）**
```
=SUMIFS($F:$F,$A:$A,A83,$D:$D,"*中計")
```
→ 同じ地域ブロック（A列が自分と同じ「東日本」）かつ区分が「〇〇中計」で終わる行だけを合計します。西日本大計（F327）も同じ形でコピーできます。

**④ 総合計（328行目のF328）**
```
=SUMIF($D:$D,"*大計",$F:$F)
```
→ 区分が「〇〇大計」で終わる行（東日本大計・西日本大計…）だけを全シートから合計します。

**なぜこれで安全なのか**
- 各式は「列全体（$F:$Fなど）」を見ているので、店舗が増えても中部に11店目が増えても、新しい行が自動的に集計対象に入ります。行番号を書き換える必要はありません。
- 自分自身は「区分」の文字列が集計対象のパターン（売上／〇〇小計／〇〇中計／〇〇大計）に一致しないので、自動的に除外されます。
- 下の階層の「すでに合計済みの行」だけを拾う作りなので、生データと小計を両方足してしまう二重集計も起きません。

あとは、各小計・中計・大計・総合計のF列セルに、上と同じ考え方（自分の行の該当列の値を基準にする）で式を入れて、必要な行にコピーしていただければ、行の増減があっても式を直さずに運用できます。
