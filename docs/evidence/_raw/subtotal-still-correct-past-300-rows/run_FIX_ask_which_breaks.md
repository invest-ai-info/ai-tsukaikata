# 追加確認：どこが崩れるかを先に聞く（1回・部門別経費表）
ユーザーからの質問「この表で、同じ数式をコピーするだけでは正しく集計できない階層はありますか。塊の個数が他と違う場所を教えてください。」への回答。

回答の要旨:
- 表の階層は「小計（担当者単位・経費5行+小計1行の6行構成）」「中計（部署単位・担当者15人分=15ブロック集計）」「大計（事業部単位・部署の中計を集計）」「総合計（大計2件を集計）」の4層。
- 小計層と中計層は、どのブロックも同じ個数（5行／15人）で揃っているため、同じ形の数式をそのままコピーして問題ない。
- ただし大計層だけブロック数が不揃い：フロント事業部大計は配下の部署が営業部1つ（中計1ブロックのみ集計）なのに対し、バックオフィス事業部大計は配下が総務部・人事部・経理部の3部署（中計3ブロックを集計）。
- このため、固定の行オフセットやブロック数を前提にした数式をそのままコピーすると、フロント事業部大計側で範囲がずれる（バックオフィス側の値を巻き込む、または範囲不足になる）。
- 対策として、大計の数式だけはD列の文字（「◯◯中計」や事業部名など）を目印にした動的な範囲判定（SUMIFなど）にすることを推奨し、小計・中計はそのままコピーで問題ない旨を伝えた。

判定：真の不均等階層（事業部大計）と完全に一致。正しく言語化できた。
