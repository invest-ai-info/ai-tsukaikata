# T2 (agent a090633b) — 店舗別売上表
この構成なら、SUMIFSを「自分の行の1行上まで」に限定しつつ、キー列（店舗名・エリア名・地域ブロック名）で一致させる形にすると、自分自身を含めずに、行が増えても直さなくていい数式になります。

ポイントは2つです。
- 単純に `SUMIFS(F:F, …)` のように列全体を参照すると、集計行自身もその列（F列）に含まれるため、循環参照の警告が出ます（条件で除外されていても、Excelは「自分の列全体を参照している」という構造だけで循環と判定します）。
- そこで範囲の終わりを `INDEX(F:F,ROW()-1)` にして「自分の1行上まで」に固定します。ROW()は数式を置いた行で自動的に変わるので、行を挿入しても手直し不要です。

① 店舗小計（例：F9セル「関東01店小計」）
=SUMIFS(F$2:INDEX(F:F,ROW()-1), C$2:INDEX(C:C,ROW()-1), C9, D$2:INDEX(D:D,ROW()-1), "売上")
C列（店舗名）が自分と同じ行で、D列が「売上」の行だけを合計します。これを他の全ての「○○店小計」行にコピーすればOKです（各行のC・ROW()が自動で変わります）。

② エリア中計（例：F82セル「関東中計」）
=SUMIFS(F$2:INDEX(F:F,ROW()-1), B$2:INDEX(B:B,ROW()-1), B82, D$2:INDEX(D:D,ROW()-1), "*小計")
B列（エリア名）が同じで、D列が「〜小計」で終わる行（＝各店舗の小計行）だけを合計します。他の「○○中計」行にもコピーしてください。

③ 地域ブロック大計（例：F83セル「東日本大計」）
=SUMIFS(F$2:INDEX(F:F,ROW()-1), A$2:INDEX(A:A,ROW()-1), A83, D$2:INDEX(D:D,ROW()-1), "*中計")
A列（地域ブロック名）が同じで、D列が「〜中計」で終わる行だけを合計します。

④ 総合計（F328セル「総合計」）
=SUMIFS(F$2:INDEX(F:F,ROW()-1), D$2:INDEX(D:D,ROW()-1), "*大計")
D列が「〜大計」で終わる行（＝東日本大計・西日本大計）だけを合計します。

この4つをそれぞれ1回だけ入力して、同じ種類の行（他の小計行・他の中計行…）に下にコピーすれば完成です。店舗や日付の行を後から挿入しても、
- 範囲の終わりは ROW()-1 で自動的にその行の1つ上まで伸びる
- 合計する対象は「名前が一致」「区分の末尾が一致」という条件だけで決まる

ので、数式を一切直さずに正しい値が出ます。
