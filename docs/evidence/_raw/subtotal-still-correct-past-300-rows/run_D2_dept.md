# D2 (agent ae33f8f6) — 部門別経費表
各小計・中計・大計・総合計のF列（金額）には、次のようなSUMIFS数式を入れると、行が増減しても直す必要がありません。範囲を固定せず「列全体＋条件」で集計するのがポイントです。

**①各担当者の小計**（例：7行目「営業部担当01小計」のF7）
=SUMIFS($F:$F,$C:$C,$C10,$D:$D,"経費")
（※回答では例の行として「7行目」と書きつつ式中は C10 を使用）

**②部署の中計**（例：92行目「営業部中計」のF92）
=SUMIFS($F:$F,$A:$A,$A92,$B:$B,$B92,$D:$D,"*小計")

**③事業部の大計**（例：93行目「フロント事業部大計」のF93）
=SUMIFS($F:$F,$A:$A,$A93,$D:$D,"*中計")

**④総合計**（368行目）
=SUMIFS($F:$F,$D:$D,"*大計")
