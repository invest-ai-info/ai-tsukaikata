# T4 (agent a14d080f) — 店舗別売上表
F列の小計・中計・大計・総合計は、すべて同じ考え方（SUMIFSで「区分」列を手がかりに該当行だけを拾う）で組めば、行が何行増えても直す必要がなくなります。ポイントは、集計対象を「行番号の範囲」ではなく「列全体＋条件」で指定することです。範囲参照（例: F2:F8）だと、挿入位置によっては自動で広がらないことがありますが、列全体参照＋SUMIFSなら挿入位置を気にせず常に正しく拾えます。

①店舗小計（例: 9行目「関東01店小計」のF列）
=SUMIFS($F:$F,$C:$C,C9,$D:$D,"売上")
C列（店舗名）が自分と同じで、D列（区分）が「売上」の行だけを合計します。小計行自身のD列は「関東01店小計」で「売上」ではないので、自動的に自分を含みません。
この式を他の店舗小計の行（17行目、25行目…）にそのままコピペすれば、C9の部分は自動でC17、C25…に変わるので、店舗が増えてもこの式を直す必要はありません。

②エリア中計（例: 82行目「関東中計」のF列）
=SUMIFS($F:$F,$B:$B,B82,$D:$D,"*店小計")
B列（エリア名）が自分と同じで、D列が「〜店小計」で終わる行（＝そのエリア内の各店舗小計）だけを合計します。店舗が何店増えても、D列に「◯◯店小計」という文字列が入っている限り自動で拾われます。中計行自身のD列は「関東中計」で「店小計」で終わらないので自分は含まれません。

③地域ブロック大計（例: 83行目「東日本大計」のF列）
=SUMIFS($F:$F,$A:$A,A83,$D:$D,"*中計")
A列（地域ブロック名）が自分と同じで、D列が「〜中計」で終わる行（＝そのブロック内の各エリア中計）だけを合計します。エリアが増えても同様に自動対応します。

④総合計（328行目）
=SUMIFS($F:$F,$D:$D,"*大計")
D列が「〜大計」で終わる行（＝各地域ブロックの大計）をすべて合計します。「総合計」という文字列自体は「大計」で終わらないので自分は含まれません。
