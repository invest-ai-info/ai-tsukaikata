# D1 (agent adfedb62) — 部門別経費表
F列の数式は、どの集計行も「列全体」を見て『D列が“経費”の行だけを拾う』という形にすると、自分自身を含まない・行が増えても直さなくていい、の両方が一度に満たせます。

**①担当者小計（例：F10 "営業部担当01小計"）**
=SUMIFS($F:$F, $C:$C, C10, $D:$D, "経費")
→ C列（担当者）がこの行と同じで、かつD列が「経費」の行だけを合計します。

**②部署中計（例：F95 "営業部中計"）**
=SUMIFS($F:$F, $B:$B, B95, $D:$D, "経費")
→ B列（部署）がこの行と同じで、D列が「経費」の行だけを合計。

**③事業部大計（例：F96 "フロント事業部大計"）**
=SUMIFS($F:$F, $A:$A, A96, $D:$D, "経費")
→ A列（事業部）がこの行と同じで、D列が「経費」の行だけを合計します。

**④総合計（F368）**
=SUMIF($D:$D, "経費", $F:$F)
→ 事業部・部署・担当者に関係なく、D列が「経費」の全行を合計します。
