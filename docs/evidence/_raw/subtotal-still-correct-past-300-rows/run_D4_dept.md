# D4 (agent aba54131) — 部門別経費表 (SUBTOTAL方式)
SUM ではなく =SUBTOTAL(9, 範囲) を使う。SUBTOTALは範囲内に他のSUBTOTAL結果（＝下位の小計・中計）が含まれていても自動で無視して二重計算しないため、下位集計を避けて範囲を切る必要がない。

実際の式（ユーザーの表の行番号どおり）：
小計（F7=SUBTOTAL(9,F2:F6) など、6行単位で全30件コピー可）
中計（F92, F184, F275, F366）
大計（F93=SUBTOTAL(9,F2:F92), F367=SUBTOTAL(9,F94:F366)）
総合計（F368=SUBTOTAL(9,F2:F367)）

行追加に強い理由：既存の参照範囲の内側に行を挿入すればExcelが自動で範囲を広げるため数式を書き直さなくてよい（新ブロックを丸ごと追加する場合はそのブロック自身の小計だけ新規作成すればよい）。末尾（総合計の下）への追記だけは範囲外になるので避けるよう注記。
