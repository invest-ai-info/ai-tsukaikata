## 返ってきたもの（生・tool_uses: 0・72,223 tokens・116秒）

noteのメンバーシップは「売上が立つ → 手数料が引かれる → 売上金として貯まる → 振込申請して口座に入る」という流れなので、その流れの順に公式ヘルプを追うと抜けが出にくいです。見る場所は基本的に、noteヘルプセンター（note画面のフッターやメニューの「ヘルプ」から入るのが確実。「メンバーシップ」「有料販売・売上」「振込」あたりのカテゴリ）、利用規約とメンバーシップに関する特約、そして「お知らせ」（改定告知）の三か所です。ヘルプは「クリエイター向け」と「読者向け」に分かれているので、基本はクリエイター向けを読み、解約・返金の項だけ読者向けも見ると、自分の会員に何が起きるかが分かります。

**1. まず「自分が開設できるか」**
- メンバーシップの開設条件（本人確認の要否、アカウントの状態、年齢、個人と法人で手続きが違うか）
- 銀行口座の登録が開設時に必要か、振込申請のときでよいか
- 法人向けの note pro と通常アカウントで、条件や手数料が違うか（自分がどちらに当たるか）

**2. プラン設計の制約**
- 月額の下限と上限、プランをいくつ作れるか
- 無料プランや初月無料の設定ができるか、その場合の手数料の扱い
- 価格を後から変えたとき、既存メンバーにどう適用されるか（値上げ・値下げ・プラン閉鎖）
- ここで決めた月額に手数料がかかるので、次の項目と往復して読む

**3. 手数料の内訳と「引かれる順番」**
- 手数料が何段階あるか（決済手数料 → プラットフォーム利用料 → 振込手数料、という層の分け方になっているか）
- それぞれが「売上そのもの」に対してかかるのか、「前の手数料を引いた残り」に対してかかるのか。計算例が載っているページを探して、その式をそのまま控える
- いま表示されている率がキャンペーン中の値でないか（期間と、終了後に戻る率）
- メンバーシップの手数料が、有料記事・有料マガジンと同じか別か

**4. 決済手段ごとの違い**
- クレジットカード、携帯キャリア決済、コード決済、アプリ内課金（iOS / Android）で手数料が違うか
- とくにアプリ内課金は、読者に見える価格と自分の取り分が別建てになっていないか
- 読者がどの決済手段を使うかは自分で選べないので、「いちばん不利な手段」を前提に取り分を見ておく

**5. 売上が確定するタイミング**
- 売上が「決済された日」で立つのか、月締めなのか
- 売上金がダッシュボードに反映される時期
- 売上金に有効期限があるか（申請しないまま放置すると失効するのか）

**6. 振込の条件**
- 振込申請できる最低金額（それに届かない月は繰り越しになるか）
- 申請の締め日と、実際に振り込まれる日
- 振込のたびにかかる振込手数料と、誰が負担するか
- 申請制か自動振込か、申請にあたって本人確認が要るか
- 振込先口座の条件（本人名義限定か、ネット銀行やゆうちょ銀行の可否）

**7. 解約・返金・決済失敗の扱い**
- メンバーが月の途中で退会したときの日割りや返金の有無
- 決済失敗（カード期限切れなど）のとき自動で退会になるのか、猶予があるのか
- 返金やチャージバックが起きたとき、引かれた手数料が戻るのか

**8. 税金と書類**
- 売上明細・支払明細をどこからダウンロードできるか（確定申告用）
- インボイス制度への対応（noteが適格請求書を出すのか、自分が課税事業者の場合の手続き）
- 源泉徴収の有無、表示価格が税込か税抜か
- 支払調書の発行有無

**9. 規約と禁止事項**
- メンバーシップの利用規約・特約（禁止コンテンツ、外部サービスへの誘導の制限、アカウント停止時の売上金の扱い）
- 自分がメンバーシップを閉じるときの条件（会員への告知、閉鎖後の返金）

**10. 最後に「いつの情報か」を確かめる**
- 各ヘルプページの更新日
- 「お知らせ」にある手数料改定・規約改定の告知と、その発効日
- 開設後、最初の売上が立ったらダッシュボードの明細とヘルプの説明を突き合わせる。食い違ったら明細のほうが実態です

控えるときは、項目ごとに「ページのタイトル・URL・確認した日・書いてあった内容」をメモにしておくと、あとで「変わったかどうか」を同じ場所で見比べられます。ヘルプ内の検索は「メンバーシップ 手数料」「売上金 振込」「振込申請」「有効期限」「アプリ内課金」「インボイス」あたりの語で引くと、上の項目にそれぞれ対応するページが出てきます。
