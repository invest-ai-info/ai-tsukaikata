手順書「会議の文字起こしから、決定事項を3行にまとめる」
1. ChatGPTを開き、新しいチャットを始める。
2. 会議の文字起こしファイルを用意する。
3. 文字起こしの本文をチャットに貼り付ける。
4. 貼った本文の下に「この会議の決定事項を3行で書いてください」と入力して送る。
5. 返ってきた3行を読み、決定事項として正しいか確認する。
6. 3行を報告用の形に整えて、上司に送る。

**手順1「ChatGPTを開き、新しいチャットを始める」 → 実行できる（条件付き）**
ログイン済みのアカウントがあれば「新しいチャット」を押すだけなので実行できます。ただし、どこで開くのか（ブラウザのURLかアプリか）、アカウントが必要か、無料版でよいか、は書かれていません。ChatGPTを一度も使ったことがない人は、登録・ログインの手順が無いのでここで止まります。

**手順2「会議の文字起こしファイルを用意する」 → 情報が足りず止まる**
足りないもの:
- どの会議か（日付・会議名）
- ファイルがどこにあるか（フォルダ、共有ドライブ、誰が持っているか）
- ファイルの形式（テキスト、Word、Googleドキュメント など）
- 「用意する」が「既にあるものを手元に置く」なのか「録音から文字起こしを作る」なのか。作るのだとしたら、その方法が一切書かれていない

**手順3「文字起こしの本文をチャットに貼り付ける」 → 止まる（手順2が完了していないため）**
仮にファイルが手元にあったとしても、次が書かれていません。
- 「本文」の範囲。発言者名・タイムスタンプ・冒頭の雑談も含めて全部貼るのか
- 長すぎて1回で貼れないときにどうするか（分割するのか、一部だけにするのか）
- 社内の会議内容を外部サービスに貼ってよいのか。初めての人は許可の有無が分からず、ここで手が止まります

**手順4「貼った本文の下に『この会議の決定事項を3行で書いてください』と入力して送る」 → 実行できる**
入力する文言が一字一句書かれており、「送る」も迷いません。細かい点として、「下に」と言われてもChatGPTではEnterを押すと送信されてしまうので、改行の仕方（Shift+Enter）が書かれていないと戸惑う可能性はありますが、貼った直後に続けて入力しても意味は変わらないので、止まるほどではありません。

**手順5「返ってきた3行を読み、決定事項として正しいか確認する」 → 「読む」は実行できるが「正しいか確認する」で止まる**
足りないもの:
- 何と照らし合わせて「正しい」と判断するのか（文字起こしの原文と突き合わせるのか、自分の記憶か）。会議に出ていない人には照合材料が文字起こししか無いのに、それと比べろとも書かれていない
- 「決定事項」の定義。決まったことと、検討中・持ち帰り・宿題を、どう区別するか
- 正しくなかったときにどうするか（言い直させる、自分で書き直す、誰かに聞く）
- 3行で返ってこなかったとき、あるいは決定事項が3つ無かった・4つ以上あったときにどうするか

**手順6「3行を報告用の形に整えて、上司に送る」 → 情報が足りず止まる**
足りないもの:

- 「上司」が誰か（宛先）
- 送る手段（メール、Slack、Teams、口頭）
- いつまでに送るか
- AIで要約した旨を書くのか、文字起こしの原文を添えるのか
