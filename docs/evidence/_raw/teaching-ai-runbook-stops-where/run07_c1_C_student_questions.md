## 送った指示文（定型の前置き＋質問。前置きは evidence 本体に記載）

次の手順書で講座をするとき、受講者から出そうな質問を、手順の番号ごとに挙げてください。手順書に答えが書かれていない質問だけを挙げてください。

手順書「会議の文字起こしから、決定事項を3行にまとめる」
1. ChatGPTを開き、新しいチャットを始める。
2. 会議の文字起こしファイルを用意する。
3. 文字起こしの本文をチャットに貼り付ける。
4. 貼った本文の下に「この会議の決定事項を3行で書いてください」と入力して送る。
5. 返ってきた3行を読み、決定事項として正しいか確認する。
6. 3行を報告用の形に整えて、上司に送る。

## 返ってきたもの（生・tool_uses: 0・72,660 tokens・112秒）

**手順1 ChatGPTを開き、新しいチャットを始める**

- 無料版でよいのか、有料版が必要なのか。
- アカウントを持っていない場合はどうするのか。会社のアカウントと個人のアカウント、どちらを使うべきか。
- 会社のPCで、会社の会議内容をChatGPTに入れてよいのか（社内ルール・情報セキュリティ上の扱い）。
- ブラウザ版とスマホアプリ版、どちらでもよいのか。
- なぜ「新しいチャット」にする必要があるのか。前回の会議のチャットの続きでやると何が困るのか。
- モデルを選ぶ欄が出るが、どれを選べばよいのか。
- 入力した内容が学習に使われない設定にすべきか。その設定はどこにあるのか。
- ChatGPT以外（Copilot・Gemini・Claudeなど）でも同じ手順でできるのか。

**手順2 会議の文字起こしファイルを用意する**

- 文字起こしはどうやって作るのか（Teams/Zoomの自動文字起こし、録音アプリ、手打ち）。
- ファイル形式は何でもよいのか（.txt / .docx / .vtt など）。
- 録音や文字起こしをするのに、会議の参加者の許可は必要か。
- 誤変換や聞き間違いが多い文字起こしでも、そのまま使ってよいのか。先に直すべきか。
- 発言者の名前は入っていた方がよいのか。
- 2時間の会議など、文字起こしが非常に長い場合はどうするのか。
- 社外秘や個人情報が含まれている場合はどうするのか（伏せ字にするのか、そもそも使わないのか）。
- 録音はあるが文字起こしがない場合はどうするのか。

**手順3 文字起こしの本文をチャットに貼り付ける**

- 一度に貼れる文字数に上限はあるか。超えたら分割して貼ればよいのか。
- 貼り付けではなく、ファイルをそのままアップロードしてもよいのか。どちらが結果がよいのか。
- 貼り付けの途中でEnterを押すと送信されてしまう。改行はどうすればよいのか。
- 貼り付けると改行や体裁が崩れるが、結果に影響するのか。
- タイムスタンプや「[笑い]」「えーと」などは消してから貼るべきか。
- 貼り付けた内容はChatGPT側に残るのか。あとで削除できるのか。
- 貼る前に社名・人名・金額を伏せ字にすべきか。伏せると精度は落ちるのか。

**手順4 指示文を入力して送る**

- 指示文を本文の上に書いてはいけないのか。順番で結果は変わるのか。
- 「3行」とは、文が3つという意味か、箇条書き3つという意味か。
- 4行や5行で返ってきたらどうするのか。
- 決定事項が3つより多い会議、または1つも無い会議ではどうするのか。
- 「決定事項」に宿題（誰がいつまでに）や保留事項は含めてよいのか。分けて出させたいときはどう頼むのか。
- 決めた人・期限・理由も一緒に出させたいときはどう頼むのか。
- 出力の形（箇条書き・敬語・文字数）を指定したいときはどう書くのか。
- 毎回同じ指示文を打つのは面倒だが、保存しておく方法はあるか。
- 「決定事項は見当たりません」のように返ってきたらどうするのか。
- 返答が途中で止まった、またはエラーになったらどうするのか。
- 英語の会議でも日本語で書いてもらえるのか。

**手順5 返ってきた3行を読み、正しいか確認する**

- 「正しいか」は具体的に何を見て判断すればよいのか。確認の観点はあるのか。
- 自分が出ていない会議の場合、何と照らし合わせて確認すればよいのか。
- 決定ではないもの（提案・意見・検討中）が決定事項として書かれていたらどうするのか。
- 文字起こしに無いことが書き足されていた場合はどうするのか。そういうことは起きるのか。
- 本当は決まったことが3行に入っていない（抜け）は、どうやって見つけるのか。
- 間違いがあったとき、自分で直すのか、ChatGPTに直させるのか。直させるなら何と言えばよいのか。
- 3行のうち1行だけ違うとき、その1行だけ直してもらえるのか。
- 3行の元になった発言箇所を示させることはできるのか。
- 同じ文字起こしをもう一度送ったら別の3行が返ってきた。どちらが正しいのか。
- 日付や数字が元の発言と微妙に違うときはどうするのか。
- 確認に時間がかかって、自分で書いたほうが早いと感じたらどうするのか。

**手順6 報告用の形に整えて上司に送る**

- 「報告用の形」とは具体的に何か。決まったテンプレートや見本はあるのか。
- メール・チャットツール・議事録ファイルのどれで送るのか。
- 3行のほかに何を付けるべきか（会議名・日時・参加者・次回予定・宿題）。
- 整える作業（メール文面づくり）もChatGPTにやらせてよいのか。
- AIで作ったことを上司に伝える必要はあるのか。
- 上司に「これは誰が言ったの」と聞かれたときのために、元の文字起こしも添付すべきか。
- 上司以外（会議の参加者）にも送ってよいのか。送る前に会議の主催者の確認は要るのか。
- 送ったあとで間違いに気づいたらどうするのか。
- どうしても3行に収まらないとき、行数を増やしてよいのか。
- 毎週同じ会議で繰り返すなら、この手順を自動化できるのか。

このうち「会社の会議内容を外部のAIに入れてよいのか」は手順1〜3のどこでも出るうえ、手順書に一言も触れられていないので、講座の冒頭で答えを用意しておくと後の質問が減ります。
