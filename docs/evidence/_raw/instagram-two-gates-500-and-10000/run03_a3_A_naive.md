# run03 — 指示文A（素朴に聞く）3回目 — 2026-09-18

## 送った指示文（定型の前置き＋質問。前置きは evidence 本体に記載）

Instagramで収益化して収入を得るには、どんな条件を満たせばいいですか。フォロワー数の条件と、お金が実際に入るまでの流れを教えてください。

## 返ってきたもの（生・tool_uses: 0・73,541 tokens・140秒）

Instagramは、YouTubeのように「再生数に応じて広告収入が自動で入る」仕組みが基本的にありません。収入源は大きく分けて、①Instagram（Meta）公式の収益化機能、②企業からのPR案件、③アフィリエイト、④自分の商品・サービスの販売、の4つです。それぞれ条件と、お金が入るまでの流れが違います。

## 1. 公式の収益化機能（Metaから支払われるもの）

日本で使える主なものは「サブスクリプション（月額課金）」「ギフト（リール視聴者からの投げ銭）」「バッジ（ライブ配信中の投げ銭）」です。共通の条件は次のとおりです。

- プロアカウント（クリエイターまたはビジネス）であること
- 18歳以上であること
- Metaの「パートナー収益化ポリシー」「コンテンツ収益化ポリシー」を守っていること（著作権違反、フォロワー購入、誤解を招く投稿などがあると対象外）
- 対象の国・地域に住んでいること

フォロワー数の目安は、サブスクリプションが1万人以上とされることが多く、ギフトやバッジは数千人規模の条件が設定されている時期があります。ただし、この数字は地域や時期で変わっており、同じフォロワー数でも使える人と使えない人がいます。確実なのは、プロアカウントに切り替えたあと「プロフェッショナルダッシュボード」の収益化の項目を見ることで、自分のアカウントで今使える機能と、足りない条件がそこに表示されます。

なお「ボーナス（リール再生数に応じた報奨金）」は招待制で、恒常的な収入源として当てにできるものではありません。

お金が入るまでの流れは、おおむね次のとおりです。

1. 設定からプロアカウントに切り替える
2. プロフェッショナルダッシュボードで対象機能を申請し、ポリシーに同意する
3. 支払い情報を登録する（氏名・住所・生年月日・銀行口座・税務情報。日本在住なら米国外居住者としての税務申告フォームを入力）
4. 視聴者が課金・投げ銭をすると、ダッシュボードに収益として貯まる
5. 月単位で締められ、残高が最低支払額（25米ドル相当が目安）に達すると、翌月中に登録した銀行口座へ振り込まれる

注意点として、アプリ内課金にはApple・Googleの手数料（最大30%程度）がかかるため、視聴者が払った額がそのまま入るわけではありません。

## 2. 企業からのPR案件（タイアップ投稿）

フォロワー数の公式な条件はありません。実際には、1,000〜3,000人程度でも「商品提供のみ」や少額の案件は来ることがあり、現金報酬がまとまってくるのは1万人前後からが一つの目安です。報酬の相場は「フォロワー数×1〜3円程度／1投稿」といわれますが、ジャンル（美容・育児・投資・ガジェットなど）や、いいね・保存・コメントの率で大きく変わります。フォロワーが少なくても反応率が高ければ選ばれます。

流れは次のとおりです。

1. 企業や広告代理店からDM・メールで依頼が来る（またはインフルエンサーのマッチングサービスに登録して案件に応募する。1,000人程度から登録できるものもあります）
2. 投稿内容・本数・納期・報酬・投稿の二次利用の範囲を確認し、合意する（メールでも契約として残す）
3. 商品を受け取り、投稿する。このとき「PR」「広告」「タイアップ」などの表記が必須です（2023年10月からのステマ規制で、表記がないと広告主が法令違反になります）
4. 企業側が投稿を確認したら請求書を送る
5. 「月末締め・翌月末払い」のような条件で、投稿から1〜2か月後に振込

「商品提供のみ」の案件は現金にならないので、報酬の有無を最初に確認しておくことが大切です。

## 3. アフィリエイト

フォロワー数の条件はほぼありません。ストーリーズのリンクスタンプもプロフィールのリンクも、今はフォロワー数に関係なく使えます。A8.net、もしもアフィリエイト、楽天アフィリエイト（楽天ROOM）などはInstagramアカウントで登録できます。Amazonアソシエイトは登録時にSNSのフォロワー数（数百人規模）が見られ、一定期間内に売上実績がないと本審査に通りません。

流れは次のとおりです。

1. ASP（アフィリエイトサービス）に登録し、審査を通す
2. 紹介したい商品の広告主と提携する
3. プロフィールのリンクやストーリーズのリンクスタンプに紹介リンクを置く（複数のリンクをまとめる無料ツールを使う人が多い）
4. 読者がリンク経由で購入すると「未確定」の報酬が記録される
5. 広告主が承認すると「確定」になる（1〜2か月かかる）
6. 確定額が最低支払額（1,000円程度が多い）を超えると、翌月または翌々月に振込

こちらもPR・広告である旨の表記が必要です。

## 4. 自分の商品・サービス

ハンドメイド品、デジタル素材、レシピ集、講座、有料noteなどを自分で売る方法です。フォロワー条件はなく、販売サイトの規約に従うだけで、入金はそれぞれのサービスの締め日・振込日に従います。フォロワーが数千人でも、ジャンルが絞れていれば最も単価が高くなりやすい方法です。

## 全体を通しての注意点

- 収益化の条件は頻繁に変わります。フォロワー数の数字は「目安」として捉え、実際の可否はプロフェッショナルダッシュボードと公式ヘルプで確認してください
- フォロワーの購入は規約違反で、公式機能の対象外になるうえ、企業側にも見抜かれます
- 会社員の副業なら、副業以外の所得が年間20万円を超えると確定申告が必要です（住民税は20万円以下でも申告が要ります）。勤め先の副業規定も先に確認してください
- 現実的には、まったくのゼロから1万人に届くまで半年〜1年以上かかることが多く、最初の収入は「アフィリエイト」か「小さなPR案件」から始まるのが一般的です

まとめると、「公式機能はおおむね1万人前後が壁、企業案件は1,000〜1万人で始まり1万人超えで本格化、アフィリエイトと自分の商品はフォロワー数に関係なく今日から始められる」という整理になります。
