行が増えても崩れないよう、SUMIF を「表全体（十分大きい範囲）」に対して使い、集計行自体はそもそも「合計」という文字列なので二重集計の心配がない形にするのがポイントです。

**C13（渋谷教室 合計）**
```
=SUMIF($A$2:$A$100,$A13,$C$2:$C$100)
```

**C14（新宿教室 合計）**
```
=SUMIF($A$2:$A$100,$A14,$C$2:$C$100)
```

**C15（池袋教室 合計）**
```
=SUMIF($A$2:$A$100,$A15,$C$2:$C$100)
```

**C16（全教室 合計）**
```
=SUMIF($A$2:$A$100,"合計",$C$2:$C$100)... ではなく
=SUM(C13:C15)
```
とすると行数増加時にずれるので、代わりに以下を推奨します。

```
=SUM($C$2:$C$100)-SUM(C13:C15)... も複雑になるため、最もシンプルなのは:
=SUM($C$2:$C$100)/2
```
は不自然なので、**総合計は単純に生徒データ全体を合計**するのが最も安全です。

**C16（全教室 合計・推奨版）**
```
=SUM($C$2:$C$100)
```

### ポイント解説
- `$A$2:$A$100` `$C$2:$C$100` のように**データ行より十分大きい固定範囲**を絶対参照で指定します。生徒が増えて13行目以降にデータがはみ出さない限り、集計欄（「合計」という文字列が入っているだけの行）は `SUMIF` の条件（教室名との一致）に引っかからないので、自己参照にはなりません。
- 100行目は余裕を持たせた仮の値です。実際の想定最大行数に合わせて調整してください（例: 生徒が最大500人なら `$A$500` など）。
- C16はSUMIFではなく生徒データ全体の単純合計にすることで、C13〜C15の並びや行数に依存せず崩れません。

**まとめ（数式一覧）**

| セル | 数式 |
|---|---|
| C13 | `=SUMIF($A$2:$A$100,$A13,$C$2:$C$100)` |
| C14 | `=SUMIF($A$2:$A$100,$A14,$C$2:$C$100)` |
| C15 | `=SUMIF($A$2:$A$100,$A15,$C$2:$C$100)` |
| C16 | `=SUM($C$2:$C$100)` |

これで行を挿入して生徒データが増えても、範囲を手直しする必要はありません（100行目を超えない限り）。
