行が増えても直す必要がないように、SUMIF関数で教室名を条件に集計します。

**C13(渋谷教室 合計):**
```
=SUMIF(A:A,A13,C:C)
```

**C14(新宿教室 合計):**
```
=SUMIF(A:A,A14,C:C)
```

**C15(池袋教室 合計):**
```
=SUMIF(A:A,A15,C:C)
```

**C16(全教室 合計):**
```
=SUM(C13:C15)
```

**ポイント**
- `SUMIF(A:A, A13, C:C)` は「A列が『渋谷教室』のときC列を合計」という意味です。範囲を列全体(`A:A`, `C:C`)にしているため、2行目〜12行目のデータ部分に何行追加・削除しても数式を書き換える必要がありません。
- 集計行自身(13〜15行目)は教室名が「渋谷教室」などではなく生徒名欄が「合計」なので、条件に一致せず自己参照(循環参照)は起きません。
- 全教室合計(C16)は3つの教室合計を足すだけなので `SUM(C13:C15)` で十分です。こちらも教室が増えて行が下にずれる場合は範囲を合わせて調整してください。

なお、範囲を列全体にする代わりに「データ範囲が絶対に2〜12行を超えない」ことが分かっている場合は `=SUMIF($A$2:$A$12,A13,$C$2:$C$12)` のように絶対参照で固定する方法もありますが、その場合はデータ行が増えたときに範囲を手動で広げる必要があります。行が増えても直さずに済ませたいなら、列全体参照(`A:A`, `C:C`)を使う今回の方法が最も安全です。
