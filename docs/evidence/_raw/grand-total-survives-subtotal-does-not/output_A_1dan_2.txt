行が増えても直さなくていいように、SUMIF で「A列が自分の教室名」の月謝を集計する形にします。集計行自体（13〜15行目）はA・B列に「合計」等が入りC列は空欄なので、条件付き集計なら自動的に自分自身を除外できます。

13行目（渋谷教室 合計、C13）に入れる数式：

```
=SUMIF($A$2:$A$12,A13,$C$2:$C$12)
```

これを14行目・15行目にもコピーすればOKです（A14が「新宿教室」、A15が「池袋教室」になっている前提）。

ポイント：
- `$A$2:$A$12` / `$C$2:$C$12` は絶対参照にして、データ範囲を固定します。
- 条件はA13の「渋谷教室」なので、渋谷教室の行だけを自動で拾います。
- 集計行（A13〜A15）はC列が空欄なので、SUMIF範囲が万一少し広がっても実害はありません。

**行が増えた場合の対応**
質問文の「行が増えても直さなくていい」は、データ範囲（2〜12行目）に生徒が増えるケースを指すことが多いです。その場合に備えるなら、範囲を大きめに確保しておく方法が簡単です。

```
=SUMIF($A$2:$A$1000,A13,$C$2:$C$1000)
```

- 空白行はSUMIFが無視するので、範囲を広げても合計はずれません。
- 生徒行を1000行目までの間に挿入するだけで、数式を一切変更せずに済みます。

**より厳密にしたい場合（表オブジェクト化）**
Excel の「テーブル」機能でデータ範囲（A1:C12）をテーブル化すると、行追加時に自動で範囲が拡張されるため、SUMIF の範囲指定すら気にしなくて済みます。

```
=SUMIF(教室[教室],A13,教室[月謝(円)])
```
（テーブル名を「教室」とした例）

まずはシンプルな `SUMIF($A$2:$A$12,A13,$C$2:$C$12)` から始めて、行数の変動が多いようならテーブル化を検討するのがおすすめです。
