SUMIFで、集計欄自身を含めずに範囲を書く方法です。行が増えても直す必要がないように、範囲の開始・終了ともに固定行にせず「データ開始行〜合計行の1つ上」を広めに取り、SUMIF条件でカテゴリを絞るようにします。

## 各カテゴリ合計（13〜15行目）

C13（豆・茶葉の合計）:
```
=SUMIF(A$2:A12,A13,C$2:C12)
```

C14（乳製品の合計）:
```
=SUMIF(A$2:A13,A14,C$2:C13)
```

C15（食材(パン・スイーツ用)の合計）:
```
=SUMIF(A$2:A14,A15,C$2:C14)
```

**ポイント**
- 範囲の終端を「自分の行の1つ上（相対参照）」にしているので、下にコピー（オートフィル）すればそのまま次のカテゴリ行に対応します。
- 範囲の開始は `A$2` / `C$2` に絶対固定しているので、常にデータの先頭からになります。
- SUMIFの条件（`A13`など）はそのカテゴリ名なので、範囲内に他カテゴリの合計行が混ざっていても影響しません（万一、後で合計行より下に集計行を増やしても対象外になります）。
- データ行が増えても、合計欄の行自体が下にずれるだけで、この数式は「自分の1つ上まで」を見るので直す必要がありません。

## 総合計欄（16行目）

C16:
```
=SUM(C13:C15)
```
または
```
=SUMIF(B2:B12,"合計",C2:C12)
```
のように「合計」という品目を条件にする方法もありますが、単純に各カテゴリ合計を足す `=SUM(C13:C15)` が分かりやすく、行が増えてカテゴリ数が変わらない限りそのまま使えます。

---

もしカテゴリの並び順が変わったり、途中に新しいカテゴリが挿入される可能性がある場合は、SUMIFの範囲を「表全体（例:C2:C1000など十分大きい固定範囲）」にしてしまう方法もあります。その場合は集計行のB列に「合計」と入っている行もカテゴリが一致してしまうと二重集計になるため、B列が空でない行だけを対象にする工夫（SUMIFS + 条件追加）が必要になります。今の使い方（各合計欄をすぐ下に置く前提）であれば、上記の「1つ上までを参照する」方式が最もシンプルです。
