行が増減してもずれない、SUMIF系の数式にするのがポイントです。範囲は「表全体」を指定し、集計行自身を含めても数式上は問題ありません（同じ値を拾わないよう、集計欄の値は空白のままにしておけばOK）。

## 各カテゴリの合計欄（C13〜C15）

C13（豆・茶葉 合計）:
```
=SUMIF(A2:A15,A13,C2:C15)
```

C14（乳製品 合計）:
```
=SUMIF(A2:A15,A14,C2:C15)
```

C15（食材(パン・スイーツ用) 合計）:
```
=SUMIF(A2:A15,A15,C2:C15)
```

## 総合計欄（C16）

```
=SUM(C2:C11)
```

または、データ行の増減にも対応させたいなら、カテゴリごとの合計を足し上げる形でも構いません。
```
=SUM(C13:C15)
```

## ポイント解説

- **`SUMIF(A2:A15, A13, C2:C15)`** は「A列がA13(=豆・茶葉)と一致する行のC列を合計する」という意味です。
- 範囲をデータ行だけ（A2:A11など）に絞らず、集計行を含む **A2:A15** のように広めに取っておけば、将来データが16行目、17行目…と増えても、範囲を書き換える必要がありません（集計行自身のC列は空欄なので合計に影響しません）。
- 条件（`A13`など）もセル参照にしておくことで、「豆・茶葉」という文字列を数式に直接書かずに済み、カテゴリ名の変更にも強くなります。
- 総合計は、データ範囲が伸びても対応できるよう `SUM(C13:C15)`（カテゴリ小計の合計）にしておくと、カテゴリが増えた場合も範囲を1箇所広げるだけで済みます。
