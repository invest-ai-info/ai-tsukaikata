行が増えても直す必要がないよう、SUMIF で「教室名が一致し、かつ月謝が数値のデータ」だけを合計する形にするのが確実です（合計行自体は月謝欄が空欄なのでISNUMBER条件で自然に除外されます）。

13行目（渋谷教室・合計）に入れる数式：

```
=SUMPRODUCT(($A$2:$A$100=A13)*ISNUMBER($C$2:$C$100)*$C$2:$C$100)
```

これを14行目、15行目にもそのままコピーすればOKです（A列参照が各行のA14, A15に自動で変わります）。

**ポイント**
- 範囲を `$A$2:$A$100` のように十分広めの固定範囲にしておくことで、データが増えて13行目以降にずれても、集計欄自身（月謝が空欄）は `ISNUMBER` 条件で自動的に除外され、常に「その教室の数値が入っている月謝」だけが合計されます。
- 単純に `SUMIF($A$2:$A$100,A13,$C$2:$C$100)` でも同じ結果になります（空欄はSUMIFでも自動的に0扱いなので無視されます）。こちらの方がシンプルです：

```
=SUMIF($A$2:$A$100,A13,$C$2:$C$100)
```

どちらの式でも、集計行自体をSUM範囲に含めていても「教室名が一致する行」の中で月謝が空欄の行（＝合計行自身）は単に0として加算されるだけなので、循環参照にもならず、行が増えても式を直す必要はありません。

**おすすめ**: `SUMIF` の方がシンプルで意図も明確なので、こちらを使うことをお勧めします。
