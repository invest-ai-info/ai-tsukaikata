行が増えても集計範囲を自動で捉えられるよう、SUMIFを使うのがおすすめです。集計欄自身（13〜15行目）を範囲に含めないよう、データ範囲を広めに（例えば2〜100行など）指定しておけば、後でデータ行が増えても数式を直す必要がありません。

C13（渋谷教室 合計）:
```
=SUMIF(A2:A100,A13,C2:C100)
```

C14（新宿教室 合計）:
```
=SUMIF(A2:A100,A14,C2:C100)
```

C15（池袋教室 合計）:
```
=SUMIF(A2:A100,A15,C2:C100)
```

C16（全教室 合計）:
```
=SUM(C13:C15)
```

**ポイント**
- `SUMIF(A2:A100, A13, C2:C100)` は「A列が『渋谷教室』の行の月謝を合計」という意味です。範囲を2〜100行のように広く取っておけば、13〜15行目の集計行（教室名は同じでも月謝が空欄）を巻き込んでも、そこはC列が空なので合計に影響しません。
- 教室が追加された場合も、データ行を増やすだけで数式の範囲内に収まります（100行を超える場合のみ範囲を広げてください）。
- C16は各教室の小計を足すだけなので、教室が増えてもC13:C15の範囲を教室数分広げれば対応できます。
