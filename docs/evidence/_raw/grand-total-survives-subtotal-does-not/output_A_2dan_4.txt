行数が増えても直す必要がないよう、SUMIF で「合計欄を含まない広い範囲」を指定する形にします。

**C13（渋谷教室 合計）**
```
=SUMIF(A:A,A13,C:C)
```

**C14（新宿教室 合計）**
```
=SUMIF(A:A,A14,C:C)
```

**C15（池袋教室 合計）**
```
=SUMIF(A:A,A15,C:C)
```

**C16（全教室 合計）**
```
=SUM(C13:C15)
```

ポイント:
- `SUMIF(A:A, A13, C:C)` は列全体を対象にしているので、データ行が増減しても数式を書き換える必要がありません。
- 集計行自体（C13〜C15）のC列は空欄なので、SUMIFが自分自身を含めても影響しません（空セルは0として無視される）。ただし「集計欄自身を範囲に含めない」ことを明確にしたい場合は、データ範囲を明示的に絞る方法もあります。

もしデータ範囲を明示的に「集計欄を含まない」形にしたい場合は、テーブル機能（Excelの「テーブルとして書式設定」）を使うのが最も安全です。テーブル化すると、行が増えてもテーブル範囲が自動拡張され、集計欄は別領域に置けるので、`SUMIF(教室,,生徒名]="渋谷教室",...)` のような構造化参照が使え、集計欄を誤って含める心配がなくなります。
