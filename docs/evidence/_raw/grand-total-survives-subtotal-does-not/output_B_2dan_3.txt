SUMIF系で「範囲固定・条件一致」にすれば、行が増えてもカテゴリ合計欄自身を範囲に含めずに済みます。

## 各カテゴリ合計欄（C13:C15）

C13（豆・茶葉 合計）:
```
=SUMIF($A$2:$A$12,A13,$C$2:$C$12)
```

C14（乳製品 合計）:
```
=SUMIF($A$2:$A$12,A14,$C$2:$C$12)
```

C15（食材(パン・スイーツ用) 合計）:
```
=SUMIF($A$2:$A$12,A15,$C$2:$C$12)
```

※ すべて範囲は `$A$2:$A$12` / `$C$2:$C$12`（データ行のみ、13〜15行目は含まない）に固定しているので、行を貼り付け・コピーしても崩れません。

## 総合計欄（C16）

```
=SUM($C$2:$C$12)
```

こちらもデータ範囲のみを直接合計するので、集計欄（13〜15行目）を二重に含めません。

**ポイント**
- カテゴリ名が増減しても、データ行にカテゴリを追加し、対応する合計行にも同じ数式（絶対参照 `$A$2:$A$12` を貼るだけ、条件セルは相対参照でOK）を入れれば動きます。
- もしデータ行数自体が増える（12行目より下に追加される）場合は、範囲をテーブル化（Excelの「テーブル」機能）しておくと `$A$2:$A$12` を都度直す必要がなくなり、さらに堅牢になります。希望があればテーブル化した数式例も出します。
