行が増えても直す必要がないよう、SUMIF関数でカテゴリ名を条件に集計する形にするのがおすすめです。範囲はデータ行だけでなく、集計欄より上の全体（2行目〜集計欄の直前）を指定しつつ、SUMIFなら集計行自体（値が空欄）を含めても影響しないので安全です。

**カテゴリ別合計（C13〜C15）**

C13（豆・茶葉の合計）:
```
=SUMIF(A:A,A13,C:C)
```

C14（乳製品の合計）:
```
=SUMIF(A:A,A14,C:C)
```

C15（食材(パン・スイーツ用)の合計）:
```
=SUMIF(A:A,A15,C:C)
```

**総合計（C16）**

```
=SUM(C2:C11)
```
これは元データ行のみを直接指定するため、集計欄を二重加算しません。ただし行数が増える場合は範囲拡張が必要になります。もし総合計も「行が増えても直さなくていい」形にしたいなら、代わりに各カテゴリ合計を足す形にできます。

```
=SUM(C13:C15)
```

### ポイント
- `SUMIF(A:A, A13, C:C)` は列全体を条件検索するので、新しい仕入れ行を2〜12行目の間に挿入しても自動的に集計対象に含まれます。
- 集計行（13〜15行目）自体はC列が空欄のため、`SUMIF`で合計しても影響しません（A列にカテゴリ名が入っていても、C列の値が空なので加算されない）。
- 総合計はC13〜C15を単純に足す`=SUM(C13:C15)`にしておけば、カテゴリが増減しない限り行挿入の影響を受けません。
