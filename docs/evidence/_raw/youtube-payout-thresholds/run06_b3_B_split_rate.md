YouTubeの広告収益分配は、基本的に **クリエイター55% : YouTube(Google)45%** という比率で分けられます。

## 基本ルール

- **動画広告(長尺動画)**: YPP(YouTubeパートナープログラム)に参加しているクリエイターが、その動画にひもづく広告収益の **55%** を受け取り、残り **45%** をYouTubeが取得します。
- **Shorts(ショート動画)**: 2023年2月以降、長尺動画と同じ「55:45」の分配方式に統一されました。それ以前は「Shorts Fund」という別枠のボーナスプール方式でしたが、現在は広告収益プールを視聴データに応じて分配し、その中からクリエイター取り分が55%となる仕組みです(音楽使用料などが差し引かれる分、実際の受取額は長尺動画よりやや複雑です)。

## その他の収益源での割合

| 収益源 | クリエイター取り分 |
|---|---|
| 動画広告(長尺) | 55% |
| Shorts広告 | 55%(音楽ライセンス費控除後) |
| チャンネルメンバーシップ | 70% |
| Super Chat / Super Sticker | 70% |
| YouTube Premium視聴分の収益 | 視聴時間に応じて配分(概ね広告と同様の考え方) |

## 補足
- この分配はGoogle AdSense/YPPの規約に基づくもので、Googleが公式に長年公表している標準的な数値です。
- 手数料や税金、決済手数料などは別途差し引かれる場合があります。
- 数値は地域やプログラムの変更によって将来変わる可能性があるため、正確な最新情報はYouTube公式ヘルプページ(YouTubeパートナープログラムの収益分配)で確認するのが確実です。
