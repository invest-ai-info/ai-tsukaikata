YouTubeの広告収益分配は、YouTubeパートナープログラム(YPP)に参加しているクリエイターの場合、一般的に以下の割合とされています。

## 基本の分配比率

**クリエイター: 55% / YouTube(運営): 45%**

- これは主に動画再生前後・途中に流れる「ディスプレイ広告」「オーバーレイ広告」「スキップ可能/不可能な動画広告」などの収益に適用される比率です。
- Googleが長年公表している標準的な数字で、YouTube公式ヘルプでも明記されています。

## 補足:収益源によって仕組みが異なる

| 収益源 | 分配の仕組み |
|---|---|
| 通常の動画広告 | クリエイター55% / YouTube45% |
| YouTube Premiumの視聴料 | 会員の視聴時間に応じて按分され、その中からクリエイターに分配(比率はおおむね広告と同様の考え方) |
| YouTube Shorts | 広告収益をまず音楽使用料などを差し引いた上で「Shortsクリエイターの取り分プール」として算出し、各クリエイターの視聴シェアに応じて配分。最終的にクリエイター側の取り分は45%程度(残りをYouTubeが得る)という、通常動画とは逆の比率になっている点が特徴 |
| スーパーチャット/メンバーシップ等 | 広告とは別枠で、こちらもおおむねクリエイター70% / プラットフォーム30%程度(地域・決済手数料により変動) |

## 注意点

- この55/45という比率は、あくまで**広告主が支払った金額そのままではなく**、Googleの広告システム手数料などが差し引かれた「純広告収益」に対する分配率です。
- 実際にクリエイターが受け取る額は、視聴者の地域、広告の種類(スキップ可/不可、バンパー広告など)、広告主の入札額(CPM)、視聴維持率などによって大きく変動します。
- 収益化には「YouTubeパートナープログラム」への参加(登録者数・総再生時間などの条件)が必要です。

必要であれば、Shorts収益の計算方法やCPM/RPMの目安についても詳しくご説明できます。
