YouTubeで広告収入を得るには、大きく分けて「①YPP(YouTubeパートナープログラム)への参加条件を満たす」→「②審査に通る」→「③収益が発生・確定し、実際に振込まれる」という流れになります。

## 1. YPP参加の最低条件(すべて満たす必要あり)

| 項目 | 条件 |
|---|---|
| チャンネル登録者数 | 500人以上 |
| 公開動画本数 | 過去90日間に3本以上投稿 |
| 再生時間の実績(いずれか) | 過去365日間の総再生時間3,000時間以上、**または**過去90日間のShorts視聴回数300万回以上 |
| ガイドライン遵守 | コミュニティガイドライン違反がないこと |
| 居住国 | チャンネルの拠点国がYPP提供国であること |
| 2段階認証 | Googleアカウントで有効化していること |
| 関連付けAdSenseアカウント | 保有(なければ申請時に作成) |

※これは「YPPに参加できる」最低ライン(登録者500人)です。以前の1,000人基準より緩和されています。ただしこの段階では、投げ銭・グッズ販売など一部機能のみで、**広告収益を得るにはさらに上のライン**が必要です。

## 2. 広告収益を得るためのフル基準

| 項目 | 条件 |
|---|---|
| 登録者数 | 1,000人以上 |
| 再生時間実績(いずれか) | 過去365日間で4,000時間以上、**または**過去90日間のShorts視聴回数1,000万回以上 |

これを満たすと、動画広告(インストリーム広告)・Shorts広告収益・チャンネルメンバーシップ・スーパーチャットなど、収益化機能がフルで使えるようになります。

## 3. 実際にお金が入るまでの流れ

1. **条件達成の確認**
 YouTube Studio の「収益化」タブが、条件達成に伴い自動的に「申請可能」状態になります。

2. **YPPへの申請**
 Studioから申請→ポリシーの同意→Google AdSenseアカウントの作成・紐付け(住所や税務情報の入力含む)。

3. **審査**
 YouTube側で自動+人手による審査が行われます(過去動画の著作権・コミュニティガイドライン適合性などをチェック)。数日〜1ヶ月程度かかることがあります。

4. **承認・広告表示開始**
 承認されると動画に広告が表示され始め、収益がAdSense上でカウントされます。

5. **収益の確定(月次)**
 その月の収益は、無効なクリック等のフィルタリングを経て**翌月初め頃に確定**します(例:8月分の収益は9月上旬に確定)。

6. **支払い条件のクリア**
 - AdSenseの支払い基準額(日本の場合は8,000円)に到達していること
 - 銀行口座情報・税務情報(米国税務フォーム等)の登録が完了していること
 - 初回のみ、AdSenseから住所確認のためのPIN郵送物が届き、それをオンラインで入力する本人確認が必要な場合あり

7. **実際の振込**
 上記すべてクリアしていれば、確定した収益が**毎月21〜26日頃**に登録銀行口座へ振り込まれます(基準額未達の月は繰り越され、翌月以降にまとめて支払われます)。

## 補足:収益源は広告だけではない

広告収益(YPP)以外にも、条件を満たせば次のような収益源が使えます。いずれも別途条件があります。
- チャンネルメンバーシップ
- スーパーチャット/スーパーサンクス
- YouTubeショッピング
- Shorts視聴報酬(共有広告収益プール)

必要であれば、ご自身のチャンネルの現状(登録者数・再生時間など)を踏まえた個別のロードマップも整理できます。
