# YouTubeで広告収入を得るための条件と流れ

## 1. YouTubeパートナープログラム(YPP)の参加条件

広告収入を得るには、まず「YouTubeパートナープログラム(YPP)」に参加する必要があります。主な条件は以下の通りです。

### 基本要件(すべて満たす必要あり)
| 項目 | 条件 |
|---|---|
| 登録者数 | **1,000人以上** |
| 視聴時間 | 過去365日で**総再生時間4,000時間以上**(長尺動画) **または** 過去90日で**ショート動画の視聴回数1,000万回以上**(どちらか一方を満たせばOK) |
| 居住地 | YPPが提供されている国・地域に居住 |
| チャンネルの状態 | コミュニティガイドライン違反による有効な停止措置がない |
| セキュリティ | 2段階認証(2FA)をGoogleアカウントで有効化済み |
| リンクされたAdSenseアカウント | Google AdSenseアカウントを保持(未作成なら審査過程で作成) |
| 規約への同意 | YouTube利用規約・パートナープログラムポリシー・収益化ポリシーに同意 |
| コンテンツ内容 | 「広告主に適したコンテンツガイドライン」を満たしている(暴力・アダルト・著作権侵害等がない) |

※2023年以降、ショート動画単体でも収益化できるルートが追加されています。

## 2. 実際にお金が入るまでの流れ

```
① 条件を達成
   ↓
② YouTube Studio から YPP に申し込み
   ↓
③ 審査(自動チェック+人によるチャンネル全体の審査)
   ※数日〜数週間かかることが多い
   ↓
④ 承認 → 収益化ON
   Google AdSenseアカウントをチャンネルにリンク(初めてなら新規作成)
   ↓
⑤ 動画に広告が表示され始める
   ・各動画ごとに広告の種類・表示を設定可能
   ↓
⑥ 収益がAdSenseアカウントに日々蓄積・集計される
   （広告視聴数・単価=CPM/RPMにより変動）
   ↓
⑦ 月末締めで収益が確定（前月分が翌月上旬〜中旬に確定・反映）
   ↓
⑧ AdSenseの支払い条件を満たすと振込
   ・支払いしきい値到達（日本は8,000円）
   ・住所確認（初回、郵送のPINコード入力が必要）
   ・税務情報（米国税務フォーム等）の登録完了
   ・支払い方法（銀行振込等）の設定完了
   ↓
⑨ 毎月21〜26日頃、登録した銀行口座に振込
   （前月分が、その翌月に支払われるイメージ）
```

## 補足ポイント

- **審査に落ちた場合**、30日後に再申請できます。
- **収益源は広告だけでなく**、YPPに参加すると「チャンネルメンバーシップ」「スーパーチャット」「YouTubeショッピング」なども利用可能になります。
- **収益額の目安**は動画ジャンルや視聴者の地域によって大きく変動し、CPM(広告1,000回表示あたりの単価)はジャンルにより数十円〜数千円と幅があります。
- 初回支払い時は住所確認のため、郵便でPINコードが届くまで待つ必要があり、ここが一番時間がかかるポイントになりがちです。

不明点(たとえばショート動画収益化の詳細や、実際のCPM相場、税務申告の話など)があれば、さらに深掘りして説明できます。
