# 材料5点のうち1点だけ抜けているとき、抜けを名指しできるか

対象: **gemini-3-1-pro**　／　課題: single-gap（6件）

⚠️ **1件につき「新しいチャット」を開く。**同じチャットで続けて貼ると、2件目からは
「材料の抜けを探す課題だ」と気づいてしまい、以降が全部当たる。測るものが変わってしまう。

## やること

1. チャット画面で**新しいチャット**を開く。できれば「一時チャット」
   （ChatGPT＝一時的なチャット / Gemini＝一時的なチャット）＝記憶を持ち込まない設定にする
2. `1_A_数値表.prompt.txt` を開き、**中身をそのまま全部**貼って送る
   - ⚠️ 「これを評価して」などを**足さない**。1文字でも足すと課題が変わる
   - ⚠️ 検索・ファイル添付・カスタム指示は**使わない**
3. 返ってきた**本文だけ**を `1_A_数値表.reply.txt` という名前で同じフォルダに保存する
   - 考え中の表示・引用元の一覧・自分の感想は入れない
4. 1〜3を残り5件くり返す（毎回、新しいチャット）
5. 全部そろったら採点する:

```
python tools/model_bench.py --score docs/evidence/_raw/bench/single-gap_gemini-3-1-pro_20260907-110827
```

## 貼る順番（ファイル名のとおり）

1. `1_A_数値表.prompt.txt` → `1_A_数値表.reply.txt`
2. `2_A_来週の予定.prompt.txt` → `2_A_来週の予定.reply.txt`
3. `3_A_備考.prompt.txt` → `3_A_備考.reply.txt`
4. `4_B_単価表.prompt.txt` → `4_B_単価表.reply.txt`
5. `5_B_割引条件.prompt.txt` → `5_B_割引条件.reply.txt`
6. `6_B_条件.prompt.txt` → `6_B_条件.reply.txt`

## 記事に書くときの但し書き（必須）

- どのモデルを、**いつ・どの画面で**測ったか（チャット画面の中身は黙って変わる）
- **点数ではなく、何を落としたか**を書く
- 測ったのは「製品」であって「素のモデルの賢さ」ではない
