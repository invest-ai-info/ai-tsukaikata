# ChatGPT に「材料が1点欠けた依頼」を6通り出した記録

- 測定日: **2026-09-10**
- 相手: **ChatGPT（Plusプラン・一時チャット・思考=中程度）**
- 課題: 材料5点のうち1点だけ抜いて渡し、**抜けを名指しできるか**を見る（6通り）
- 結果: **抜けを名指しした 4/6 ／ 黙って埋めた 2/6**（`summary.json`）

`*.prompt.txt` が出した依頼、`*.reply.txt` が返ってきた本文。
測り方と、測っている最中に踏んだ罠は `測定条件.md`。

## ⚠️ 使い方の制限

**モデル比較には使えない。**チャット画面にモデルの選択欄が無く、
どのモデルが答えたか分からない（これが理由で自前の性能比較は打ち切った）。

**使えるのは、モデル名の要らない主張だけ。**たとえば
「チャット画面に材料を1つ欠いて渡すと、6回中2回は黙って埋める」。

黙って埋めた2件:
- `3_A_備考`＝「備考」という語が**一度も出てこない**まま特記事項を書いた
- `6_B_条件`＝「納期・条件」の見出しの下に納期と修正対応だけ書き、
  【条件】にあった振込手数料・着手金を落とした
