## 🚨 モデル名は名乗れない

**画面にモデル選択欄が無い**（Chat / Work の切り替えと「中程度」だけ）。
どのモデルが答えたかは利用者から見えないので、**「GPT-6 Astra を測った」とは書けない。**
名乗れるのは **「ChatGPT（Plus・一時チャット・思考=中程度）2026-09-10 時点」**まで。

## 出力の形が API と違う

回答は**キャンバス（文書エディタ）**に出る。しかも**仮想化**されていて、
画面に出ている部分しかDOMに無い。
- コピーボタンが写すのは**キャンバスの中身だけ**
- 抜けの指摘は**キャンバスの外**（前置き・後書き）にあることが多い
- → `.reply.txt` は「前置き＋キャンバス本文＋後書き」をつないだもの

⚠️ **コピーボタンだけで保存すると、抜けの指摘が丸ごと落ちる。**

## 自動操作で踏んだ罠（次にやる人へ）

| やったこと | 結果 |
|---|---|
| クリップボードから Ctrl+V | ❌ 合成キー操作では貼れない |
| `navigator.clipboard` の読み書き | ❌ 応答が返らない（権限） |
| `document.execCommand('copy')` | ❌ `false` |
| 文字入力（`type`） | 🚨 **文字を落とす。**「下の5点」が「下の点」になった |
| 改行を含む `type` | ⚠️ 改行で**送信されてしまう** |
| JS で paste イベントを起こす | ⭕️ 確実。**これを使う** |
| Enter / 送信ボタンの座標クリック | ❌ 送信されない |
| JS から `sendButton.click()` | ⭕️ 送信される |
| コピーボタンをいきなりクリック | ❌ **ホバーするまでDOMに出ない** |
| ホバー → クリック | ⭕️ クリップボードに入る |

📌 **必ずやること（どれも実際に事故ったもの）**

1. **送信前に、入力欄の `innerText` を課題ファイルと文字数＋チェックサムで照合する。**
   合わなければ送らない。⚠️ `children` の textContent をつなぐ方法は**使えない**
   （「1. 」が箇条書きに自動変換されて番号が消えるため）。`innerText` なら元に戻る
2. **コピーを押す前にクリップボードを空にする。**空振りしたとき、前の回の本文が
   残ったまま別の回として保存される。中身はもっともらしい文書なので目では気づけない
3. **採点前に、6件の本文が全部違うことを確かめる**（`score_dir` が自動で止める）
