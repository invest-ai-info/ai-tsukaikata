# 測定条件（2026-09-07・実測して分かったこと）

## どこで測ったか

- ChatGPT（**Plus**プラン）・`https://chatgpt.com/?temporary-chat=true`
- 一時チャット＝「メモリ、プラグイン、カスタム指示は無視され、履歴には表示されません」
- 思考の深さ＝**中程度**（既定のまま。全件で揃える）
- 操作＝Claude in Chrome で自動。1件ごとに一時チャットを開き直す

## 🚨 モデル名は名乗れない

**画面にモデル選択欄が無かった**（Chat / Work の切り替えと「中程度」だけ）。
どのモデルが答えたかは**利用者から見えない**ので、
**「GPT-6 Astra を測った」とは書けない。**

記事に書ける名乗りは
**「ChatGPT（Plus・一時チャット・思考=中程度）2026-09-07 時点」**まで。

## 出力の形が API と違う

ChatGPT は本文を**キャンバス（文書エディタ）**に出した。
- コピーボタンが写すのは**キャンバスの中身だけ**
- 「数値表は記載がなかったため」という**抜けの指摘は、キャンバスの外**の
  前置きの一文にある
- → 保存した `.reply.txt` は「前置き＋キャンバス本文＋後書き」をつないだもの

⚠️ **コピーボタンだけで保存すると、抜けの指摘が丸ごと落ちる。**
手でやる場合もここに注意。

## 自動操作で分かった制約

| やったこと | 結果 |
|---|---|
| クリップボードから Ctrl+V | ❌ 合成キー操作では貼れない |
| `navigator.clipboard.readText/writeText` | ❌ 応答が返らない（権限） |
| `document.execCommand('copy')` | ❌ `false`（利用者の操作が要る） |
| コピーボタンを実際にクリック | ⭕️ 通る（クリップボードに入る） |
| 文字入力（改行を含む） | ⚠️ 改行で**送信されてしまう** |
| 1行ずつ入力＋Shift+Enter | ⭕️ 通る |

📌 **入力後に必ず照合すること。**送信前に、入力欄の中身と課題ファイルを
文字数とチェックサムで突き合わせた（365文字・3672579357 で一致）。
1行ずつ打つ以上、打ち間違いは起こりうる。
