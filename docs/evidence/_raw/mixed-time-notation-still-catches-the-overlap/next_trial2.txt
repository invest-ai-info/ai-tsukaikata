# 準備するもの

1. **全クライアントの予定一覧**: コピペしたテキスト、表、カレンダーの書き出しのどれでも構いません。時刻の書き方がバラバラのままで大丈夫です。
2. **各予定に入れておく情報**: クライアント名、日付、開始時刻、終了時刻(または所要時間)。
3. **タイムゾーン**: クライアントごとに違う場合は、「Aさん=日本時間、Bさん=ニューヨーク時間」のように書きます。書かれていない場合は、AIに日本時間と仮定させず質問させます。
4. **新しい来客対応の依頼**: 日付、開始時刻、終了時刻(または所要時間)、場所(オンラインか対面か)、依頼元のクライアント名。

# 頼み方の手順

1. 最初に予定一覧を貼り、次のように頼みます。
   「以下は複数クライアントの予定です。時刻の表記がバラバラなので、まず全部を24時間表記・日本時間に統一した表にしてください。意味があいまいなもの(午前午後が不明、終了時刻がない、日付が読み取れない等)は推測で決めず、リストアップして私に質問してください。」
2. AIが作った統一表と質問を確認し、答えます。ここで間違いを直しておくと、あとの確認が正確になります。
3. 表が正しいと確認できたら、新しい依頼を貼ります。
   「次の来客対応が、上の全クライアントの予定と重なっていないか確認してください。1分でも重なれば『重複あり』としてください。」
4. 前後の移動時間や準備時間を考慮したい場合は、「前後30分の余裕も含めて確認してください」のように条件を足します。
5. 結果は次の形で出してもらいます。
   「結果は、①重複あり/なし、②重なる予定(クライアント名・時刻)、③前後30分以内で近接している予定、の順で出してください。」
6. 重複があった場合は、「空いている近い時間帯の候補を3つ出してください」と続けて頼みます。
7. 依頼が来るたびに、更新した予定一覧(または前回の統一表に追加分)を貼り直し、手順3〜6を繰り返します。同じ会話の中なら一覧を貼り直す必要はありませんが、会話が長くなったら貼り直すほうが安全です。

# 注意点

- 「12時」「午前0時」「午後12時」は間違いやすいので、AIが質問してきたら必ず答えてください。
- 最終判断は、結果の「重なる予定」の時刻を元の予定表と見比べて確認してください。
- 予定に個人情報や機密が含まれる場合は、クライアントとの契約や守秘義務の範囲でAIに渡してよいか確認し、必要なら「Aさん」「会議1」のように伏せてください。
