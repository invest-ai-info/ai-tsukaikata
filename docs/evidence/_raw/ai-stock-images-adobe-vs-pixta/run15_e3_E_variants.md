# run15 — 指示文E（派生の量産は規約上どう扱われるか）3回目 — 2026-09-18

## 送った指示文（定型の前置き＋質問。前置きは evidence 本体に記載）

AIで生成した画像をストック素材サイトに出品するとき、同じプロンプトから色や構図を少しずつ変えた派生を何十枚も作って出品するのは、サイトの規約上どう扱われますか。

## 返ってきたもの（生・tool_uses: 0・75,067 tokens・150秒）

結論から言うと、「同じプロンプトから色や構図を少し変えた派生を何十枚も出す」のは、ほとんどのストックサイトで**類似・重複コンテンツ（similar / duplicate）**として審査で落とされ、それを繰り返すと**スパム行為**として警告・投稿制限・アカウント停止の対象になります。これはAI画像のために新しくできた決まりではなく、写真やイラストの時代からある基本ルールで、AI画像にはそのうえに「AI生成の申告」などの条件が上乗せされている、と理解するのが正確です。

まず前提として、AI画像を受け付けるかどうか自体がサイトによって違います。私の知る範囲（規約は頻繁に変わるので、必ず最新版を確認してください）では、Adobe Stock・Dreamstime・123RF・Freepik・Vecteezy・Wirestock などは申告付きで受け付けており、Getty Images / iStock と Shutterstock はコントリビューターからのAI画像を受け付けていません。日本の PIXTA も生成AI素材の投稿を認めていなかったはずで、写真AC・イラストACなど国内の他サイトも扱いが分かれます。受け付けないサイトでは派生の枚数以前に、AI画像であること自体が規約違反になります。

受け付けるサイトでの「派生の大量出品」の扱いは、おおむね次のとおりです。

- 色だけ違う、シード値だけ違う、ポーズや小物がわずかに違う、といった画像は、審査上は「同じ画像」とみなされます。Adobe Stock なら「Similar content」、Shutterstock なら「Similar Content／Spam」、Freepik なら「Similar resources」のような却下理由で、最初の1〜数枚以外は落ちます。理由は単純で、検索結果が同じ絵で埋まると買い手が離れるからです。サイト側は自動の類似判定と人の目の両方で見ています。
- Adobe Stock は生成AIのガイドラインで、似た画像を大量に送らず最良のものだけを出すよう明示しています。AI画像の流入で審査待ちが長期化しており、承認率の高い投稿者を優先して審査するとされているので、落ちる前提の大量投稿は自分の審査を遅くする方向に働きます。
- 単発の却下にペナルティはありませんが、同じことを続けるとスパムと判断され、警告、投稿数の制限、最悪はアカウント閉鎖になります。契約書には「ガイドライン違反で解約できる」条項が入っているのが普通で、似たAI画像の大量投稿とキーワードの詰め込みを組み合わせた投稿者がアカウントを閉鎖されたという報告もあります。承認済みの画像が後からまとめて削除されることもあります。

AI固有の条件も忘れないでください。Adobe Stock では「生成AIで作成」のチェックを入れ、写真ではなくイラストとして登録し、タイトルやキーワードにツール名・実在の人物・作家名・ブランド名を入れないことが求められます。申告なしで出すと、それ自体が違反で削除やアカウント停止の理由になります。

線引きの目安としては、1つのアイデアにつき2〜5枚、しかも「買い手がどちらかを選ぶ理由がある」違い（横位置と縦位置、寄りと引き、昼と夜、人物の有無、用途の違い）があるものだけを出す、というのが多くの投稿者が守っている水準です。色違いをどうしても出したいなら、1枚の画像の中にバリエーションを並べた「セット」にすると、1ファイルとして通りやすくなります。

まとめると、規約の文言は「重複・類似の禁止」「スパムの禁止」「AI生成の申告義務」の3つで、数十枚の派生は最初の数枚以外が落ちるだけでなく、続けるとアカウントそのものに響く、という扱いです。
