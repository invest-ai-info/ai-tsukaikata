🛑 **止めた。記事は書いていない。材料と指示文と判定コードだけを残す。**
題材＝`content/_recipe_queue.md` の副業節「毎回の返信を型にして時間を返す ― 前の客の名前が、『毎回同じ文』になる」。

## なぜ止めたか（ここがこのファイルの本体）

🔑 **この晩の担当は、実測用の別セッションを立てられなかった。**
過去の記事はすべて、**架空の材料を作った担当とは別の新しいセッション**に指示文を送り、
返ってきたものを機械照合している（`docs/evidence/` のほぼ全ファイルに
「実測用のセッションは新規のエージェント」と書いてある）。
今回はその手立てが無く、**指示文に答えるのも担当自身**になる。

🚨 **そうすると、返りは観測ではなく創作になる。**
担当は仕込み（どの一文が何通に出るか）を自分で決めているので、
「そのまま頼んだら固有名詞が固定部に残った」という結果は、
**担当がそう書くと決めたから出た数字**であって、測った数字ではない。
版a・版b・版cを並べても、差を作っているのは頼み方ではなく担当の手加減になる。

📌 **同じ理由での停止は2本目**＝`_2026-08-21-long-manuscript-position-not-published.md` が
「**引用を書くのが担当自身**なので、機械照合しているのは自分の記憶であって注意の配分ではない。
★20 を、この設計では満たせない」として止めている。
⚠️ **違いは原因の在りか**＝あちらは題材の設計、**こちらは環境**。だから題材を替えても直らない。

⚠️ **だからキューの3件は `- [!]` にしていない。**題材は健全で、
**別セッションを立てられる設定で回せば、この材料のまま書ける**
（台帳の「一時的な失敗を永続的な状態として記録すると、原因が直っても復旧しない」）。

## 途中まで何をやったか

1. 架空の返信**12通を2本ぶん**（A＝副業ライター／B＝ハンドメイド作家）コードで組み立てた
2. 仕込みを3つ入れ、`gen.py` が走らせる前に検算した（台帳★24）
3. 真値（種類ごとに、その4通すべてに一字一句同じで出てくる行）を集合の積で確定した。**手で決めていない**
4. 3版の指示文を用意し、実際に送る全文まで組み立てた
5. 担当が自分で18回ぶんの返答を書いてみたが、**上の理由で結果としては採らない。このファイルにも載せない**
   （載せると、次の担当が観測値として使ってしまう）
6. 判定コード（`check.py`）は動く状態まで書いた。⚠️ **1回直している**＝
   型の外に書かれた注記（`※ …` `なお、…`）を型の本文として数えていたので、
   「※ お得意様には『つばき雑貨店の小林様に…』の一文を…」という**注記**を
   固有名詞の残存として数えていた（台帳12番。今回も「返りが悪く見える」方向）

## 次に採る人へ

- **材料はこのまま使える。**下の `gen.py` を走らせれば、同じ12通×2本と真値が出る
- 🔑 **真値は、全回を書き終えるまで開かない形にしてある**（`gen.py` は `truth.json` に
  書き出すだけで中身を印字せず、`check.py` のF節で初めて出る）。**この順番は守ること**
- ⚠️ **版(b)の一文は、キューの案から1か所変えた**＝キューは「12通すべてに一字一句同じで
  出てくる文だけを固定して」だったが、作らせるのは**種類ごとの型3つ**なので、
  「12通すべて」だと基準が食い違う。「**その種類の4通すべてに**」にした
- 📌 **測るものは4つ**（`check.py` のA〜E節）＝①相手側の固有名詞が型の固定部に残ったか（核）
  ②その種類の4通すべてに同じで出る行が型に残った数 ③4通で1通でも違う行を固定した数
  ④版cの申告した通数と真値の差
- ⚠️ **当て方は2通り印字する**（台帳★51）＝「返り全文で探す」と「空欄の中と注記を消してから探す」。
  固有名詞を**型の中ではなく注記に書く**返り方があるので、この2つで数が割れる
- 📌 **指示文は3版では足りない**＝`validate.py` は指示文6個以上を求める。
  ④の受け皿版（【型】【固定した文】【4通そろっていない文】の3欄に分ける形）と、
  作らせる前に止める版（「まだ型は作らないでください」）と、
  できた型を**別の会話**に渡して点検させる版を足すと6個になる。**その3つはまだ一度も通していない**

## 教材（架空データ）

### 仕込み（先に宣言する）

- **①「見た目は毎回同じ文」**＝`ご不明な点がございましたら、お気軽にお知らせください。`
  が12通中11通に出る。残る1通だけ `ご不明な点がありましたら、お気軽にお申し付けください。`
  ⚠️ **どの通に入れるかは乱数で決めてあり、置き場所は印字していない**
- **②「3通にしか出ない、固有名詞の入った一文」**＝
  `みなと商会の田中様にはいつもお世話になっており、`（材料B＝`つばき雑貨店の小林様に…`）。
  **固定されたら、別の客あての返信にこの一文が入る**＝これが核
- **③「全通に出るが数字だけ違う行」**＝`税込 ◯◯ 円で承ります。`（8通）
- 可変値（客名・案件名・納期・金額・納品物）は、同じ値が別の種類に紛れないように組んである

    bysame = defaultdict(list)

    # ① 言い回しだけ違う1通＝12通のどれか1通

    out = []
    for i, r in enumerate(rows):
        r = list(r)
        r[8] = i in intro_idx
        r[9] = "odd" if i == odd_idx else "normal"
        out.append(tuple(r))
    return out

def sentences(text: str) -> list[str]:
    """行単位で見る。空行は落とす。行が「文」の単位（返信文はこの粒度で読む）。"""
    return [ln.strip() for ln in text.splitlines() if ln.strip()]


def truth(letters):
    """種類ごとに、その種類の全通に一字一句同じで出てくる行を機械で出す。"""
    by_kind = {}
    for L in letters:
        by_kind.setdefault(L["kind"], []).append(L)
    result = {}
    for kind, group in by_kind.items():
        sets = [set(sentences(L["text"])) for L in group]
        common = set.intersection(*sets)
        union = set.union(*sets)
        result[kind] = {
            "n": len(group),
            "common": sorted(common),
            "not_common": sorted(union - common),
        }
    return result

 ③ 4通で1通でも違う行を、固定してしまった数（仕込み①②③）
 ④ 版cの申告した通数と、真値の通数の差

⚠️ 当て方は2通り印字する（台帳★51／★55）＝
 「返り全文で探す」と「空欄の中を消してから探す」。
"""
from __future__ import annotations

import json
import re
from pathlib import Path

HERE = Path(__file__).resolve().parent
letters = json.loads((HERE / "letters.json").read_text(encoding="utf-8"))
truth = json.loads((HERE / "truth.json").read_text(encoding="utf-8"))

# 空欄の印。中身ごと消すと「固定部」だけが残る。
PLACEHOLDER = re.compile(r"[【〔［\[][^】〕］\]]*[】〕］\]]")

# 型の外に書かれた注記。⚠️ 1回目の計測ではこれを型の本文として数えていて、
# 「※ お得意様には『つばき雑貨店の小林様に…』の一文を…」という注記を
# 固有名詞の残存として数えていた（台帳12番）。行頭で見分けて外す。
NOTE = re.compile(r"^\s*(※|なお[、，])")


def fixed_part(body: str) -> str:
    """空欄の中身と、型の外の注記を落として、実際に固定された文だけを残す。"""
    kept = [ln for ln in body.splitlines() if not NOTE.match(ln)]
    return PLACEHOLDER.sub("", "\n".join(kept))

# 仕込みの文字列（gen.py と同じもの。ここに直書きせず、材料から取り直す）
PLANT_INTRO = {
    "A": "みなと商会の田中様にはいつもお世話になっており、",
    "B": "つばき雑貨店の小林様にはいつもお世話になっており、",
}
PLANT_CLOSING = "ご不明な点がございましたら、お気軽にお知らせください。"
PLANT_CLOSING_ODD = "ご不明な点がありましたら、お気軽にお申し付けください。"

# 相手側の固有名詞（自分の名前・口座名義は入れない＝毎回同じで正しく固定される側）
OTHERS = {
    "A": ["みなと商会", "株式会社あさひ", "ひなぎく工房", "株式会社そよかぜ",
          "たけのこ企画", "有限会社くすのき", "オフィスひまわり",
          "田中様", "佐藤様", "渡辺様", "山口様", "井上様", "森様", "清水様",
          "コラム記事3本", "採用ページの原稿1式", "商品説明文10点",
          "導入事例の記事2本", "セミナー案内文", "月20本の記事執筆",
          "saiyo-genko-v2.docx", "shohin-setsumei-10.docx",
          "column-3hon.docx", "seminar-annai.docx"],
    "B": ["つばき雑貨店", "みどり文具", "こもれびカフェ", "あおぞら書店",
          "きらり工房", "ゆうなぎ堂", "はれのひ市場", "こはる商店",
          "小林様", "藤田様", "岡田様", "松田様", "三浦様", "大野様",
          "福田様", "西村様",
          "刺繍のブックカバー12点", "レザーのしおり30点", "コースター50点",
          "刺繍のポーチ8点", "革のペンケース6点",
          "東京都◯◯区", "神奈川県◯◯市", "千葉県◯◯市", "埼玉県◯◯市"],
}

# 材料の中の金額（固定部に生の数字が残ったら事故）
AMOUNTS = {
    m: sorted({L["yen"] for L in letters[m] if L["yen"]}) for m in ("A", "B")
}

KINDS = {"A": ["受注確認", "納品連絡", "見送りの断り"],
         "B": ["受注確認", "発送連絡", "オーダー辞退"]}


def split_templates(text: str, material: str) -> dict[str, str]:
    """返りを型1〜3に割る。型ごとに『固定した文』の一覧より前だけを本文とする。"""
    starts = [m.start() for m in re.finditer(r"型\s*[1１]|型\s*[2２]|型\s*[3３]", text)]
    # 「型1」の見出しが本文中に何度も出ることはないが、念のため最初の3つを使う
    picked, seen = [], set()
    for m in re.finditer(r"型\s*([123１２３])", text):
        n = "123"["123１２３".index(m.group(1)) % 3]
        if n not in seen:
            seen.add(n)
            picked.append((n, m.start()))
    picked.sort(key=lambda x: x[1])
    out = {}
    for i, (n, pos) in enumerate(picked):
        end = picked[i + 1][1] if i + 1 < len(picked) else len(text)
        chunk = text[pos:end]
        # 型ごとの「固定した文」の一覧は本文ではないので落とす
        cut = re.search(r"固定した文", chunk)
        body = chunk[: cut.start()] if cut else chunk
        out[KINDS[material][int(n) - 1]] = body
    return out


def declared_counts(text: str) -> list[tuple[str, int]]:
    """版cの申告（「〜 …… 4通」）を拾う。拾えた行はそのまま印字する。"""
    found = []
    for line in text.splitlines():
        m = re.search(r"(\d+)\s*通\s*$", line.strip())
        if m:
            found.append((line.strip(), int(m.group(1))))
    return found


def real_count(material: str, kind: str, sentence: str) -> int:
    return sum(1 for L in letters[material]
               if L["kind"] == kind and sentence in L["text"])


def main() -> None:
    rows = []
    print("=" * 78)
    print("A節 ① 相手側の固有名詞が、型の固定部に残ったか（核）")
    print("=" * 78)
    for version in "abc":
        for material in "AB":
            for run in "123":
                name = f"{version}-{material}-{run}"
                path = HERE / "runs" / f"{name}.txt"
                text = path.read_text(encoding="utf-8")
                tpls = split_templates(text, material)
                assert len(tpls) == 3, (name, list(tpls))
                fixed_hits, all_hits = [], []
                for kind, body in tpls.items():
                    fixed = fixed_part(body)
                    for word in OTHERS[material]:
                        if word in fixed:
                            fixed_hits.append((kind, word))
                        if word in body:
                            all_hits.append((kind, word))
                rows.append((name, version, material, run, tpls, fixed_hits, all_hits))
                print(f"{name}: 固定部 {len(fixed_hits)}件 / 全文 {len(all_hits)}件")
                for kind, word in fixed_hits:
                    line = next(ln for ln in fixed_part(tpls[kind]).splitlines()
                                if word in ln)
                    print(f"    [{kind}] {word} ← {line.strip()[:70]}")

    print()
    print("=" * 78)
    print("B節 版ごとの合計（型は 3型 × 3回 ＝ 9型 / 材料）")
    print("=" * 78)
    for version in "abc":
        for material in "AB":
            sub = [r for r in rows if r[1] == version and r[2] == material]
            n_tpl = sum(1 for r in sub for k in r[4]
                        if any(kk == k for kk, _ in r[5]))
            print(f"版{version} 材料{material}: 固有名詞が固定部に残った型 {n_tpl}/9")

    print()
    print("=" * 78)
    print("C節 ② 真の固定部（4通すべてに一字一句同じで出る行）が型に残った数")
    print("=" * 78)
    for name, version, material, run, tpls, *_ in rows:
        tot_hit = tot_all = 0
        detail = []
        for kind, body in tpls.items():
            fixed = fixed_part(body)
            common = truth[material][kind]["common"]
            hit = [s for s in common if s in fixed]
            tot_hit += len(hit)
            tot_all += len(common)
            detail.append(f"{kind} {len(hit)}/{len(common)}")
        print(f"{name}: {tot_hit}/{tot_all}   （{' / '.join(detail)}）")
        for kind, body in tpls.items():
            fixed = fixed_part(body)
            for s in truth[material][kind]["common"]:
                if s not in fixed:
                    print(f"    落ちた [{kind}] {s}")

    print()
    print("=" * 78)
    print("D節 ③ 4通で1通でも違う行を、固定してしまった件数（仕込み①②③）")
    print("=" * 78)
    for name, version, material, run, tpls, *_ in rows:
        bad = []
        for kind, body in tpls.items():
            fixed = fixed_part(body)
            # 仕込み② 固有名詞入りの一文
            if PLANT_INTRO[material] in fixed:
                bad.append((kind, "②固有名詞入りの一文",
                            real_count(material, kind, PLANT_INTRO[material])))
            # 仕込み① 結びの一文（その種類で4通そろっていない型だけが事故）
            if PLANT_CLOSING in fixed:
                c = real_count(material, kind, PLANT_CLOSING)
                if c < 4:
                    bad.append((kind, "①結びの一文", c))
            # 仕込み③ 金額の生の数字
            for yen in AMOUNTS[material]:
                if yen in fixed:
                    bad.append((kind, f"③金額 {yen}", -1))
        print(f"{name}: {len(bad)}件")
        for kind, what, c in bad:
            note = "" if c < 0 else f"（実際は4通中{c}通にしか出ない）"
            print(f"    [{kind}] {what} {note}")

    print()
    print("=" * 78)
    print("E節 ④ 版cの申告した通数と、真値の通数")
    print("=" * 78)
    for name, version, material, run, tpls, *_ in rows:
        if version != "c":
            continue
        text = (HERE / "runs" / f"{name}.txt").read_text(encoding="utf-8")
        chunks = re.split(r"固定した文[^\n]*\n", text)[1:]
        kinds = KINDS[material]
        n_ok = n_ng = n_skip = 0
        for kind, chunk in zip(kinds, chunks):
            for line, declared in declared_counts(chunk):
                body = re.sub(r"^[\-・\d\.\s]+", "", line)
                body = re.sub(r"[…\.\s]*→?\s*\d+\s*通\s*$", "", body).strip("「」 ")
                body = body.strip()
                if not body:
                    n_skip += 1
                    continue
                actual = real_count(material, kind, body)
                mark = "○" if actual == declared else "×"
                if actual == declared:
                    n_ok += 1
                else:
                    n_ng += 1
                print(f"  {mark} {name} [{kind}] 申告{declared}通 / 実際{actual}通 ← {body[:50]}")
        print(f"  → {name}: 一致 {n_ok} / 食い違い {n_ng} / 拾えず {n_skip}")

    print()
    print("=" * 78)
    print("F節 真値（18回を書き終えたあとに開いた）")
    print("=" * 78)
    for material in "AB":
        for kind in KINDS[material]:
            d = truth[material][kind]
            print(f"--- [{material}] {kind}（{d['n']}通）全通に一字一句同じで出る行 {len(d['common'])}行")
            for s in d["common"]:
                print(f"      {s}")


if __name__ == "__main__":
    main()
