# 試した証拠 — critique-not-rewrite

2026-08-12 に実施。教材＝架空の社内メールの下書き（283字・本文8段落）。
様式は `docs/evidence/TEMPLATE.md`。判定はすべて Python（文字列照合）。

⚠️ **仕込み＝欠陥を10件、2種類に分けて入れた。**

- **B群（5件）＝下書きの文の中にある欠陥。**指さす対象の文が存在する
- **A群（5件）＝下書きに一度も書かれていない欠陥。**指さす対象が存在しない

この2群に分けたのは、**批評が「書いてある文への注釈」に偏るかどうか**を
機械で判定するため。仕込みを先に決めてあるので、後から数えられる。

| 記号 | 仕込んだ欠陥 | 群 |
|---|---|---|
| B1 | 「大幅にコストが下がります」に数字が無い | 文の中 |
| B2 | 「PJ-Kの二次展開」を説明せずに使っている | 文の中 |
| B3 | 導入理由が「同業他社もやっている」になっている | 文の中 |
| B4 | 「試験導入」と「全社展開」が続けて書かれ、どちらの依頼か決まらない | 文の中 |
| B5 | 困っているのが差出人の課だけで、読み手の問題として書かれていない | 文の中 |
| A1 | 期限が一度も書かれていない | 書かれていない |
| A2 | 相手が何をすればよいかが書かれていない | 書かれていない |
| A3 | 連絡先・窓口が書かれていない | 書かれていない |
| A4 | なぜ総務部に頼むのか（主管がどこか）が書かれていない | 書かれていない |
| A5 | 協力にかかる時間の見込みが書かれていない | 書かれていない |

⚠️ **実行の順番について。**①〜⑧のうち、比較に使った①②③④⑤⑥⑦は
**それぞれ会話の1手目として、下書きだけを渡して実行した**（前の返答を見た状態では、
後の指示文が有利になるため）。⑧⑨と言い直し節・応用節の指示文は、記事の中で
「続けて頼む」形にしてあるものなので、続きとして実行した。

## 指示文①（素朴版・記事の「効かない例」）

### 送った指示文（記事と同一文字列）

```
この下書きを批評してください。
```

### 返ってきたもの（生・全文）

```
拝見しました。全体として丁寧な文面ですが、社内文書としていくつか改善の余地があります。

【良い点】
・宛先と差出人が明記されており、書き出しが簡潔です
・検討段階であることが率直に書かれています

【気になる点】

1. 結論が最後に来ています
社内メールでは、依頼事項を冒頭に置くほうが読み手の負担が減ります。「ご協力のお願い」を最初に持ってくることをおすすめします。

2. 「大幅にコストが下がります」の根拠が示されていません
どの程度下がるのか、何と比べての話なのかが分かりません。試算値があれば添えたほうが説得力が出ます。

3. 「PJ-Kの二次展開」が唐突です
総務部の方がこのプロジェクト名をご存じとは限りません。一言補足があると親切です。

4. 「試験導入」と「全社展開」が混在しています
どちらの話をしているのかが読み取りにくくなっています。段階を分けて書くと整理されます。

5. 他社動向を導入理由にしています
「同業他社でもすでに導入が進んでおり」は補強材料にはなりますが、これ自体を理由にすると論拠として弱く見えます。自社にとっての必要性を先に書くほうがよいでしょう。

6. 依頼内容が抽象的です
「ご協力をお願いできれば」だけでは、相手が何をすればよいか分かりません。

【文章表現について】
・「お疲れさまです」は社内であれば問題ありません
・「〜と考えております」「〜と思います」が続くので、一方を言い切りにすると締まります
・一文が長い箇所があるので、二文に分けると読みやすくなります

必要でしたら、上記を反映した修正版をお作りしますが、いかがいたしましょうか。
```

### 照合（機械）

```
B（文の中にある欠陥） 4/5   指摘なし: B5
A（書かれていない欠陥） 1/5   指摘なし: A1 A3 A4 A5
```

### 判定

**記事の「効かない例」として採用。**指摘は6件出ていて、読むと十分な批評に見える。
だが**書かれていない欠陥は5件中1件しか出ていない**（唯一出た A2 は、
「ご協力をお願いできれば」という**指さす文があった**もの）。
期限・連絡先・主管・工数は、**指さす文が無いので一度も話題にならない。**

📌 かわりに出てきたのは「結論が最後」「一文が長い」といった**文章術の一般論**で、
これは仕込みではない（下書きが誰に何を頼む文書かに関係なく言える指摘）。

### 判定

**記事の中心の1つにした。**発見は3つ。

1. 🚨 **根拠のない断定は、指摘ではなく削除で処理された。**「大幅にコストが下がります」は

2. 🚨 **原文に根拠のない記述が5件混ざった。**そのまま送れば、山田が決めていない内容を

## 指示文③

### 送った指示文（記事と同一文字列）

```
この下書きを、直さずに批評してください。

書き直した文や修正案は書かないでください。代わりに、下書きのどこが、読む人にどう伝わってしまうかを書いてください。
```

### 返ってきたもの（生・全文）

```
書き直しはせず、読み手にどう伝わるかだけを書きます。

1.「現在、当社ではPJ-Kの二次展開として、」
　→ PJ-Kを知らない人は、この一文で「自分に関係のある話かどうか」を判断できません。読み飛ばされるか、最後まで他人事のまま読まれます。

2.「現行のシステムは操作が煩雑で、当課にも問い合わせが多く寄せられており、対応に時間を取られています。」
　→ 困っているのは業務改善推進課である、と読めます。総務部の読み手は「そちらの負担軽減のために、こちらが動くのか」と受け取ります。

3.「新システムを導入すれば、大幅にコストが下がります。」
　→ 数字がないため、読み手はこの一文を判断材料にできません。信じるか信じないかの話になり、慎重な読み手ほど文章全体の信頼度を下げます。

4.「同業他社でもすでに導入が進んでおり、当社としても対応が必要な状況です。」
　→ 他社がやっているから、という理由に読めます。「うちの事情は違う」と一言返されると、それ以上進みません。

5.「つきましては、まずは試験導入という形で進めたいと考えております。」と「全社展開にあたっては、総務部の皆さまにご協力をお願いできればと思います。」
　→ 2文が続いているため、いま頼まれているのが試験導入への協力なのか、全社展開への協力なのかが決まりません。読み手は大きいほう（全社展開）で受け取り、身構えます。

6.「ご協力をお願いできればと思います。」
　→ 何をすればよいかが書かれていないため、読み手は「承知しました」と返す以外にできることがありません。返事は来ますが、作業は始まりません。

7. 全体について
　→ 期限が一度も出てこないため、読み手は「急ぎではない」と判断します。後回しにされても、催促する根拠がこの文面にはありません。
```

### 照合（機械）

```
B 5/5   （素朴版で落ちていた B5 が出た）
A 2/5   指摘なし: A3 A4 A5
書き直した文: 0件（修正案は1つも混ざらなかった）
```

### 判定

**採用。**「直さないでください」だけでなく**「代わりに、どう伝わってしまうかを書いて」**と
受け皿を付けている（台帳1番）。受け皿があると、指摘の粒度が
「良くない」ではなく「読み手がこう受け取る」になり、**直す側が何を足せばいいかを決められる。**

⚠️ **書かれていない欠陥は 1/5 → 2/5 にしか動かない。**ここが次の指示文の理由。

## 指示文④

### 送った指示文（記事と同一文字列）

```
この下書きに書かれていないことを挙げてください。書かれている内容への指摘は要りません。
```

### 返ってきたもの（生・全文）

```
書かれていないことを挙げます。

・期限（いつまでに返事がほしいか、いつから試験導入を始めるか）
・依頼の具体的な内容（総務部に何をしてほしいのか）
・試験導入の対象範囲（どの部署・何人・どの期間か）
・コスト削減額の根拠となる数字

・導入候補のシステム名や、比較検討の状況
・予算の規模と、その承認状況
・問い合わせ先（差出人以外に窓口があるか、内線番号など）
・総務部以外に協力を依頼している部署があるか
・現行システムをいつ止めるのか（併用期間の有無）
```

### 照合（機械）

```
A 3/5   指摘なし: A4（なぜ総務部か） A5（協力にかかる時間の見込み）
B 1/5   （B1 が「コスト削減額の根拠となる数字」として出た）
```

### 判定

**採用。**書かれていないことだけを聞くと **A が 1/5 → 3/5** に上がる。
⚠️ ただし**足りない2件に癖がある**＝A4「なぜ自分に来たのか」と A5「自分が何時間取られるのか」は、
**下書きを外から眺めている限り出てこない。**読み手の席に座らないと生まれない問いだから。

## 指示文⑤

### 送った指示文（記事と同一文字列）

```
この下書きを、直さずに批評してください。

指摘ごとに、下書きの中の一文をそのまま引用してから書いてください。下書きの中に引用できる文が無い指摘は、「下書きに該当箇所なし」と書いてください。
```

### 返ってきたもの（生・全文）

```
指摘ごとに、下書きの一文を引用してから書きます。

1. 引用：「現在、当社ではPJ-Kの二次展開として、新しい経費精算システムの導入を検討しています。」
　→ PJ-Kが何かの説明が続かないため、読み手はここで話の位置づけを見失います。

2. 引用：「現行のシステムは操作が煩雑で、当課にも問い合わせが多く寄せられており、対応に時間を取られています。」
　→ 困っている主体が差出人側になっています。読み手にとっての利点は、この文からは読み取れません。

3. 引用：「新システムを導入すれば、大幅にコストが下がります。」
　→ 「大幅」の中身が数字で示されていません。

4. 引用：「同業他社でもすでに導入が進んでおり、当社としても対応が必要な状況です。」
　→ 他社の動向が導入の理由になっています。

5. 引用：「つきましては、まずは試験導入という形で進めたいと考えております。」
　→ 直後の文が全社展開の話になるため、どちらへの協力依頼かが定まりません。

6. 引用：「ご協力をお願いできればと思います。」
　→ 依頼の中身が書かれておらず、相手の次の動作が決まりません。

7. 下書きに該当箇所なし
　→ 期限が一度も書かれていません。いつまでに返事がほしいのかが分かりません。

8. 下書きに該当箇所なし
　→ 試験導入の時期と対象範囲が書かれていません。

9. 下書きに該当箇所なし
　→ 連絡先が書かれていません。差出人の所属と名前だけです。
```

### 照合（機械）

```
引用 6件中 6件が原文に一致（1文字も違わない）
「下書きに該当箇所なし」= 3件

B 5/5
A 3/5   指摘なし: A4 A5
```

### 判定

**採用。**効き目は2つ。

1. **引用が全件、原文と1文字も違わなかった**＝指摘を自分で検索して確かめられる。
   AIの言い換えを経由しないので、**指摘が本当にその文についてのものか**を照合できる（台帳6番）
2. **「該当箇所なし」という行き先を1つ作ると、書かれていない欠陥がそこに溜まる**（台帳5番）。
   受け皿を作っただけで A が 2/5 → 3/5 に増えた

## 指示文⑥

### 送った指示文（記事と同一文字列）

```
この下書きを読む人は、経費精算システムを実際に運用している総務部の担当者です。この人はPJ-Kに関わっていません。

この読み手が、この下書きを最後まで読んだあとに、何が分からないまま残るかを挙げてください。下書きは直さないでください。
```

### 返ってきたもの（生・全文）

```
この読み手に残る「分からないこと」を挙げます。

1. なぜ自分（総務部）に来たのかが分かりません
　経費精算の運用は総務部がしているので当然、という前提が書かれていません。読み手は「主管はうちなのに、なぜ業務改善推進課が決めているのか」と受け取る可能性もあります。

2. 何をすればよいのかが分かりません
　「ご協力」の中身が書かれていません。会議に出るのか、現行フローの資料を出すのか、テストで実際に申請してみるのかで、必要な時間がまったく違います。

3. いつまでに何をするのかが分かりません
　期限も、試験導入の開始時期も書かれていません。今週の話なのか来期の話なのかが決まりません。

4. どれくらい時間を取られるのかが分かりません
　1時間の打ち合わせ1回なのか、数か月にわたる並行運用なのかで、返事が変わります。

5. 誰に聞けばよいのかが分かりません
　差出人の名前はありますが、連絡先も、この件の窓口が山田さん本人なのかも書かれていません。

6. 現行システムの何が問題なのかが分かりません
　「操作が煩雑」としか書かれていないため、運用している側から見て心当たりのある問題なのかどうかを判断できません。

7. 試験導入の範囲が分かりません
　どの部署が対象で、そのあいだ現行システムはどうなるのか（併用か、切り替えか）が書かれていません。
```

### 照合（機械）

```
A 5/5   ★ 8通りの指示文の中で、A4（なぜ総務部か）を拾ったのはこれだけ
B 0/5   ★ 逆に、文の中にある欠陥は1件も出なかった
```

### 判定

**採用。記事のいちばん大きい発見。**
**読み手を名指しして、その人の席から聞くと、書かれていない欠陥が 5/5 になる。**
特に **A4「なぜ自分に来たのか」は、8通り試して、この指示文でしか出なかった。**

🚨 **ただし引き換えに、文の中にある欠陥（B群）は 0/5 になった。**
読み手の席から見ると「分からないこと」しか見えないので、
「書いてあるが根拠が無い」「書いてあるが理由になっていない」は視界に入らない。

→ **③（または⑤）と⑥は、どちらか一方では足りない。2回に分けて聞く。**

## 指示文⑦

```
この下書きを受け取った人が、返信で最初に聞いてくるであろう質問を5つ、聞かれる順に書いてください。答えは書かないでください。
```

### 送った指示文（記事と同一文字列）

```
いま挙げた指摘を、「これが無いと相手が動けない」順に並べ直してください。

順位ごとに、その指摘に対応しなかった場合に何が起きるかを1行で書いてください。
```

### 返ってきたもの（生・抜粋。順位と帰結の1行）

```
1位｜依頼と期限が書かれていない
> ご検討のほど、よろしくお願いいたします。
未対応なら：全員が「とりあえず読んだ」で終わり、返信がゼロ件のまま止まります。

2位｜宛先が「各位」で、動く人が特定されていない
> 総務部 各位
未対応なら：誰かがやるだろうと互いに見合い、責任者不在で放置されます。

3位｜試験導入の範囲・期間・費用・決裁者が空
未対応なら：受け手が自部署の工数を見積もれず、判断を保留して差し戻されます。

4位｜依頼する「協力」の中身が書かれておらず、前段とも矛盾する
未対応なら：引き受ける範囲が読めないため警戒され、「まず詳細を」と条件闘争に入ります。

5位｜提案の土台であるコスト削減に根拠がない
未対応なら：上申の場で数字を求められ、その場で回答できず持ち帰りになります。

6位｜困っているのが送り手側だけで、受け手の利害が書かれていない
7位｜冒頭の社内略語が説明されていない
8位｜他社動向から結論への飛躍
9位｜件名が用件の種類を示していない

上位4件（1〜4位）は情報が無いと物理的に行動を選べない不足、5位以降は行動を選べても
納得や決裁が通らない不足、という切れ目になっています。
```

### 照合（機械）

```
指摘9件がすべて順位付けされた（9/9・件数の欠落なし）
各順位に「未対応なら：」の1行が付いた（9/9）
引用は原文のまま（書き直しの混入なし）
📌 頼んでいないのに「上位4件と5位以降の切れ目」を自分で言語化した
```

### 判定

**採用。**並べ替えを頼むと、指摘が消えずに全部残ったまま順序だけが変わった
（4番＝申告の欠落が起きやすい型なので、件数の保存を機械で確認した）。

## この記事から出た教訓（`content/_lessons.md` へ）

1. **★新規：批評は「指させる文」がある欠陥に偏る。**素朴に批評させると、
   文の中にある欠陥は 4/5 拾うのに、書かれていない欠陥は 1/5 しか出ない。
   **書かれていないものは指させないので、話題にすらならない。**
   → 「書かれていないこと」を独立して1回聞く。さらに**読み手を名指しして
   その席から聞く**と 5/5 になる（引き換えに、文の中の欠陥は 0/5 に落ちる）。
   **視点を1つに決めると、もう一方が見えなくなる**ので2回に分けて聞く。
2. **★新規：「添削して」は、間違いを指摘ではなく削除で処理する。**
   根拠のない断定「大幅にコストが下がります」は、申告にも出ず本文からも消えた。
   **書いた本人は、自分の断定に根拠が無かったことを知らないまま、
   その一文だけ落ちた文面を受け取る。**さらに原文に根拠のない記述が5件混ざった。
3. **台帳4番が再発**＝添削版の申告は3件だが、原文10行のうち残ったのは2行。
4. **台帳5番が再発**＝「該当箇所なし」「なし」という行き先を作ると落ちたものが見える
   （A 2/5 → 3/5、段落は8/8が返った）。
5. **台帳7番が再発**＝「書き直さないで」と約束させた**次の返答**で修正案が1件混ざった。
   ⚠️ 形が少し違い、**「書き直しはしません」と宣言しながら書き換え文を出す。**
6. **台帳12番が再発**＝1回目の計測で、添削版の「書き直した本文」ごと数えていた。
   本文に原文の語が残っているので、指摘していないのに指摘したことになっていた。
