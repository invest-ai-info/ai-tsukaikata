# 試した証拠 — &lt;slug&gt;（この行を書き換える）

記事に載せる指示文**すべて**についてこの形式で残す。

⚠️ **返ってきたものは生のまま。**要約すると「書いてあることを消す」ことがある
（2026-08-05 の教訓＝確認をAIに要約させたら「その行は無い」という嘘の確認結果が返り、
正しい数字を消してしまった）。長すぎる返りは、先頭と、判定に使った部分を残して
`…（中略）…` でよい。**判定に使った箇所だけは、必ず生のまま残す。**

⚠️ **判定は機械でやる**（文字列照合・`difflib`・件数の数え上げ）。目視で「良くなった」と
書かない。⚠️ **その計測コード自体を1回読み直す**（台帳12番＝計測器のほうが間違っていることがある）。

⚠️ このファイルは `content/` の中に置かない。ビルド除外は**ファイル名**の `_` 判定
（`src/content.py` の `path.name.startswith("_")`）なので、`content/` 配下だと記事として拾われる。
