## この記事から出た教訓（`content/_lessons.md` へ）

1. 単数形で1つに絞る聞き方は、常に1つだけ答えるという性質自体は崩れないが、**どの1つを選ぶかは
   「止まった処理の中でどれが目立つか」ではなく「ログ全体の中で相対的に目立つものがどれか」に
   寄ることがある。**止まった処理が複数あり、残る正常な処理が1本だけだと、その正常な処理の
   相対的な割合が一時的に増え、**止まっていない処理そのものを「異常」と名指しすることがある。**
   複数形（「処理ごとに」）は最初から比較の単位を処理名で区切っているため、この崩れ方をしない。
2. 単数形の崩れは「省略せずに」のような言い方では直らない（質問が単数のままだから）。
   「実際に止まっている処理の中から選び、複数該当する場合は全部挙げる」という、**選ぶ対象の
   母集団そのものを先に絞る**一文が必要。
