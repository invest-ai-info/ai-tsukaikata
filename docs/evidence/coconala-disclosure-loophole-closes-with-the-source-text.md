## この記事から出た教訓（`content/_lessons.md` へ）

1. `crowdworks-copyright-stays-with-you`・`platform-name-guesses-the-rule-backwards`が確かめた「規約原文を貼ると誤りが直る」は、**別のプラットフォーム（ココナラ）・別の質問文でも、同じ方向に効いた**。ただし今回は、想定していた「禁止されていない」という逆方向の誤りではなく、「開示すれば足りる」という弱める方向の誤りが素朴な聞き方で再現した（6/6）。質問文の言い回しを変えると、同じ規約・同じカテゴリでも出てくる誤りの型が変わる。
2. 原文を貼っても、**弱める方向の誤りは1/10で残った**。「規約原文を貼れば誤りは0になる」と一般化しないこと。`crowdworks-copyright-stays-with-you`の4/4・`job-ai-policy-check`の8/8のような「貼れば0件」は、今回は再現しなかった（9/10への改善止まり）。
3. 新しい観察。**素朴に聞いた場合、結論の方向（避けるべき）自体は6/6で正しかった。**理由を見なければ「規約を分かっている」ように見えるが、6/6とも規約原文を引用せず、6/6とも原文に無い救済策（開示すれば足りる）を提案していた。**結論の方向だけを見て「当たっていた」と判定すると、根拠が作り話であることを見逃す。**判定は結論ではなく、根拠（原文の引用の有無・救済策の有無）まで見る必要がある。
