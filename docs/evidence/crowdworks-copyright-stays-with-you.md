# 試した証拠 — crowdworks-copyright-stays-with-you

キュー：`content/_recipe_queue.md`「納品物の著作権は誰のものか、規約原文で確かめる」
（副業節・2026-10-11補充・源①Explore agent発）。

真値の出典＝クラウドワークス利用規約 第18条（本取引の成果物等に関する知的財産権及びその利用）
（<https://crowdworks.jp/pages/agreement>・2026-10-17 WebFetch で取得・HTTP 200）。

```
第1項：ワーカーがクライアントに対して納品した成果物に関する著作権等の知的財産権は、
本取引によって譲渡がなされない限り、作成した会員自身に帰属するものとします。なお、
本取引の中において別途取決めがある場合は、同取決めが優先されるものとします。
第2項：第三者の保有する知的財産権を成果物に利用する場合、ワーカーは当該第三者の
事前の許可を得るものとし（略）
第3項：ワーカーは、本取引によって知的財産権をクライアントに譲渡した成果物につき、
クライアント又はクライアントの取引先に対し、著作者人格権を行使しないものとします。
```

**要点＝既定（デフォルト）は非譲渡。** 著作権はワーカー（作業した人）に残り、クライアントへ
移るのは「本取引によって譲渡がなされた」場合（別途の取決め）だけ。

⚠️ **ランサーズの一次情報には今回到達できなかった**（2026-10-17・`www.lancers.jp` への
WebFetch・curl とも、複数パスで `429 Too Many Requests` が返った。短い待機を挟んで3回
再試行しても変化なし）。ブログ等の二次情報では「支払確定と同時に著作権が譲渡される」という
記述が複数見つかったが、原文未確認のため記事本文には使わず、クラウドワークス単独の実測に
絞った。

実測日 2026-10-17。実測に使ったAI＝Agentツール `general-purpose`（同一セッション内の新規
サブエージェント。記憶の共有なし。依頼文の先頭に「ツールは使わず、検索もせず、あなたが
知っている知識だけで、今すぐ答えてください」を添えた）。毎回独立に起動した。

## 指示文6（応用・毎回確認する手順を作らせる・指示文3の試行2の会話を継続）

### 送った指示文（記事と同一文字列）

```
クラウドワークスやランサーズなどで案件を受けるとき、応募する前に毎回、著作権の扱いを確認する手順にしたいです。プログラミングはできません。私が案件ごとに確認することを、番号を振って箇条書きで教えてください。
```

（実際にAgentへ送った文面は、上の文章の前に「ありがとうございます。」を付けた。）

### 返ってきたもの（生・1回）

```
1. 募集要項(案件の説明文)を全部読み、「著作権」「知的財産権」「譲渡」という言葉を探す。
   なければ原則としてワーカーに著作権が残る可能性が高い(クラウドワークス規約第18条第1項)。
2. 「著作権は譲渡する/帰属する」と明記されていないか確認する。
3. 譲渡の「範囲」(納品物一式か、公開部分だけか)と「タイミング」(納品時か支払い完了後か)を確認する。
4. 二次利用・転載・改変についての記載がないか確認する(範囲が広い譲渡かどうかの判断材料)。
5. 「著作者人格権を行使しない」という一文があるか確認する(譲渡時の普通の付随条件で、特別不利ではない)。
6. 何も書かれていない案件は、応募前にメッセージ機能でクライアントに著作権の扱いを質問し、回答を保存する。
7. 契約金額と著作権譲渡の有無を見比べて、割に合うか判断する。
8. 応募前の募集要項をスクリーンショットで保存し、後日の文言変更に備える。
9. 契約成立後は、個別契約の条件欄でも同じ文言があるか再確認する(募集要項と個別契約が食い違う場合、個別契約が優先)。
10. 迷ったら「譲渡の記載なし」の案件を優先する。
```

### 照合（人による）

募集要項から「著作権」「譲渡」の語を探す→範囲とタイミングを確認する→何も書かれていなければ
発注者に直接質問する、という骨格。規約の既定（譲渡されない限りワーカー帰属）と矛盾する手順は
無し。

### 判定

**採用。**

## この記事から出た教訓（`content/_lessons.md` へ）

1. 新規＝★273として追記した。AIは、著作権法の一般原則（確度が高い）と、個別プラットフォームの
   規約の具体的な中身（未確認の推測）を、同じ文体・同じ自信で続けて書く。あとから「確認済みか
   推測か」と聞き直せば自分から区別できるが、最初の回答にはその境目が無い。
