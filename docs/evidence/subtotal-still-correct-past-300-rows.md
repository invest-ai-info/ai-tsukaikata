### 送った指示文

```

```

ただし大計層だけブロック数が不揃い：フロント事業部大計は配下の部署が営業部1つ（中計1ブロックのみ集計）なのに対し、

対策として、大計の数式だけはD列の文字（「◯◯中計」や事業部名など）を目印にした動的な範囲判定（SUMIFSなど）にすることを推奨。
