## 評価スクリプト（本ファイルの全照合に使用）

```python
import re

TRUTH = {"三日月印刷": 4000, "白樺クリニック": 2500}
HEALTHY = ["青葉自動車", "大地工務店"]

CONCLUSION_RE = re.compile(r"結論:\s*([^\s　]+)\s*([\d,]{3,7})円")
NO_ISSUE_RE = re.compile(r"結論:\s*([^\s　]+)\s*不足なし")

def extract_conclusions(text: str) -> dict:
    result = {}
    for name, amount in CONCLUSION_RE.findall(text):
        result[name] = int(amount.replace(",", ""))
    for name in NO_ISSUE_RE.findall(text):
        result[name] = 0
    return result

def judge(text: str, target: str) -> bool:
    found = extract_conclusions(text)
    false_positive = any(found.get(h, 0) not in (0, None) for h in HEALTHY)
    return found.get(target) == TRUTH[target] and not false_positive
```

⚠️ **最初の実装バグ（台帳12番の再発、2回目）**＝自然文の中から「会社名に近い金額」を拾う
作りにしたところ、会社名の直後に出てくる基本月額などの別の数字を誤って拾ってしまい、
正しく計算できている回答まで「不正解」と判定した。**回答の末尾に必ず「結論: 会社名 金額円」
という機械判定しやすい決まった書式でまとめさせる**方式に直してから、正しく判定できるように
なった。
