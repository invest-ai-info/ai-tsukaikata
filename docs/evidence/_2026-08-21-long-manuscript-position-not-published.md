## 止めた理由

### 1. 🚨 測る対象が「担当自身が気づいたか」になる（★20が効かない）

この設計の核は「仕込んだ18件のうち、位置ごとに何件を**指摘したか**」である。ところが**仕込みを置くのも、指摘するのも、同じ担当**になる。

同じ晩に公開した2本は、ここが違った＝`formula-that-survives-new-rows` は**返した数式の参照範囲の形**を、`take-home-from-the-contract-amount` は**返した金額**を、どちらも**成果物そのものを機械で判定**している。担当が何に気づいたかは判定に入らない。

こちらは「仕込んだ原文が指摘の中に引用されているか」を照合する設計だが、**引用を書くのが担当自身**なので、機械照合しているのは自分の記憶であって注意の配分ではない。★20（実測用のセッションは事前知識なしではない／記事の根拠は機械照合できる結果だけにする）を、この設計では満たせない。

### 2. 🚨 出るはずの結論が、現象ではなく測り方から出る（★62・★62bの型）

仕込みの位置を知っている側が読めば、前も中も後も総なめになる。**「位置では変わらなかった」という結論は出る。**しかしそれは、注意が位置で偏らなかったという観測ではなく、**偏りようのない読み方をしたという事実**でしかない。

★62 は「誤検出を数える実測は、計測器のほうが先に誤検出する」、★62b は「数える規則が結論を逆向きにひっくり返す」。ここでは規則ではなく**読み手の立場**が結論を決めてしまう。

### 3. ⚠️ 材料の長さが、キューの前提（1万字前後）に届かなかった

章5つ・段落46本で組んで **2,796字**（下の `truth.json`）。キューがこの題材を採った理由は「うちの検品系の実測材料が、いちばん長いもので **2,192字** しかない」というものだった。**2,796字では、その穴は埋まらない。**1万字にするには素の段落をあと3倍書く必要があるが、上の1・2が解けないまま長さだけ足しても、測れないものが長くなるだけになる。

📌 **仕込みの3等分も、組んだ時点でそろっていない**（狙い 6/6/6 に対し実際は **7/5/6**）。位置ごとの真値をそろえるには差し込み位置の計算を作り直す必要がある。これは直せる粗だが、1・2が解けない限り直す意味が無いので直していない。

## 次にこの題材を採る人へ

🔑 **切り口を捨てる必要は無い。**「何が落ちるか」ではなく「どこにあると落ちるか」は、うちの62本が1本も測っていない（キューの grep＝`中ほど` 0件・`長い材料` 0件・`何回に分け` 0件）。**測れる形に組み替えれば残る。**

組み替えの当てを2つ書いておく。

1. **仕込みを置く人と読む人を分ける。**仕込みの位置と内容を `gen.py` だけが持ち、**読む側には仕込みの一覧を一切渡さない**形にする。この環境で本当に分けられるか（同じ担当が両方をやらずに済むか）を先に確かめること。

2. **位置ではなく、成果物の側に機械で見える差を作る。**たとえば「**指摘に付けさせた行番号・引用元の位置**」を返させて、**その分布**を数える。分布はこちらが書くものではないので、判定が読み手の記憶から離れる。

⚠️ **どちらも、先に「差が出たかどうかを、担当の記憶に依らずに数えられるか」を1文で書けること。**書けないなら、また同じところで止まる。

def build():

    # 仕込みを、指定の章の決まった位置に差し込む（差し込み位置も計算で決める）

        para = chapters[ch]
        at = 1 + (i * 3) % max(1, len(para) - 1)
        para.insert(at, text)

    titles = {
        1: "第1章　区切りを動作で作る",
        2: "第2章　道具は毎日触るものにだけ",
        3: "第3章　連絡は手段に割り当てる",
        4: "第4章　記録は翌日の自分のために",
        5: "第5章　続けるために削る",
    }
    out = ["在宅の仕事を続けるための決めごと（架空の実用書・原稿）", ""]
    for n in sorted(chapters):
        out.append(titles[n])
        out.append("")
        for p in chapters[n]:
            out.append(p)
            out.append("")
    return "\n".join(out)


def thirds(text: str):
    """字数で3等分し、各ブロックの範囲を返す。"""
    n = len(text)
    return [(0, n // 3), (n // 3, 2 * n // 3), (2 * n // 3, n)]
