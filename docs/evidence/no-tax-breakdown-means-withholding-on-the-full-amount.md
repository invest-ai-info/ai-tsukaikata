## 教材（架空データ）

実在しない業務委託契約書2種を使った。委託者・受託者・業務内容・請求総額（333,000円）は
共通で、消費税の書き方だけを変えた。

契約①（消費税「別」記載）:
```
業務委託契約書（抜粋）

委託者: 株式会社あやめ商事
受託者: 高梨 直人（個人事業主・ライター）
業務内容: 月次のオウンドメディア記事執筆（原稿料）
契約金額: 月額300,000円（消費税別）
消費税: 別途、消費税及び地方消費税33,000円を加算して請求する
支払期日: 当月末締め、翌月20日払い
```

契約②（消費税「込み」・総額のみ記載・区分なし）:
```
業務委託契約書（抜粋）

委託者: 株式会社あやめ商事
受託者: 高梨 直人（個人事業主・ライター）
業務内容: 月次のオウンドメディア記事執筆（原稿料）
契約金額: 月額333,000円（消費税込み）
支払期日: 当月末締め、翌月20日払い
```

**仕込み（先に宣言）**＝正解は国税庁「インボイス制度開始後の報酬・料金等に対する源泉徴収」
（令和3年12月9日付・<https://www.nta.go.jp/law/tsutatsu/kobetsu/shotoku/gensen/111209/01.htm>、
2026-10-26確認）に基づき、Pythonで事前に計算してある（1円未満切り捨て）。

```python
import math
def withhold(base):
    return math.floor(base * 0.1021)

# 契約①: 区分記載があるので報酬額300,000円のみが対象
wh1 = withhold(300000)            # 30,630円
net1 = 333000 - wh1               # 302,370円 ← 正解

# 契約②: 区分記載が無いので、国税庁の通達どおり消費税込みの総額333,000円が対象
wh2 = withhold(333000)            # 33,999円
net2 = 333000 - wh2               # 299,001円 ← 正解

# ありがちな誤り: 消費税込みの金額だから、と税抜額へ逆算してから源泉徴収する
pretax_guess = round(333000 / 1.1)  # 302,727円
wh2_wrong = withhold(pretax_guess)  # 30,908円
net2_wrong = 333000 - wh2_wrong     # 302,092円 ← 本来より2,907円多い（源泉徴収の不足）
```

出力: `302370` `299001` `302092`。本ファイルの全判定はこの3つの数字を正解・比較対象として使う。

**採用。**消費税が区分して記載されている契約は、2回とも正しく302,370円に到達した。

### 送った指示文（記事と同一文字列）

### 返ってきたもの（生）

1回目:
```
消費税込みの金額なので、まず税抜の報酬額を算出します。333,000円÷1.1=302,727円（1円未満四捨五入）。この302,727円に10.21%を掛けると30,908円。手取り額は333,000円−30,908円=302,092円です。
```

2回目:
```
消費税込み333,000円から本体価格を逆算すると302,727円になります（333,000÷1.1、1円未満四捨五入）。源泉徴収税額は302,727円×10.21%=30,908円。手取りは333,000円−30,908円=302,092円と計算できます。
```

3回目:
```
この契約書には消費税額の区分記載がありません。国税庁の取扱いでは、請求書等に報酬額と消費税額の区分記載が無い場合、原則どおり消費税込みの金額全体が源泉徴収の対象になります。333,000円×10.21%=33,999円（1円未満切り捨て）。手取り額は333,000円−33,999円=299,001円です。
```

### 照合（機械）

```
②込み・引用なし 1  got=302092  truth=299001  correct=False
②込み・引用なし 2  got=302092  truth=299001  correct=False
②込み・引用なし 3  got=299001  truth=299001  correct=True
②込み・引用なし: 1/3 正解
```

### 判定

**採用。**同じ指示文・同じ請求総額なのに、3回中2回は消費税込みの金額を税抜へ逆算してから
源泉徴収をかけ、本来より2,907円多い手取り額（302,092円）を出した。国税庁の通達は
「区分記載が無ければ消費税込みの金額全体が対象」としているので、この2回は**源泉徴収が
不足する方向の誤り**だった。1回だけ、区分記載の有無に自分で気づいて正しく計算した。

## 評価スクリプト（本ファイルの全照合に使用）

```python
import re

CORRECT_1 = 302370
CORRECT_2 = 299001

def extract_final_amount(text: str):
    matches = re.findall(r"([\d,]{4,7})円", text)
    if not matches:
        return None
    return int(matches[-1].replace(",", ""))

def judge(text: str, contract: int) -> bool:
    truth = CORRECT_1 if contract == 1 else CORRECT_2
    return extract_final_amount(text) == truth

FLAG_WORDS = ["区分記載", "誤り", "正しくは", "やり直す"]

def flags_the_real_issue(text: str) -> bool:
    return any(w in text for w in FLAG_WORDS)
```

⚠️ **最初の実装バグ**＝`extract_final_amount()` を「『手取り額は』の直後の数字」で
拾う作りにしたところ、「手取り額は333,000円−30,630円=302,370円です」のような引き算の式で
**引かれる数（333,000円）を誤って最終結果として拾ってしまった**。すべてのトライアルで、
文中最後に出てくる金額が実際の結論と一致することを手動で確認したうえで、「文中最後の
金額」を拾う方式に直した（台帳12番の再発）。
