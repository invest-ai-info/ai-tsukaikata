# 試した証拠 — estimate-hours-from-your-own-log

「この作業は何時間かかりますか」と聞いたときに何が返るかを、架空の案件と架空の作業記録で実測した記録。

⚠️ 判定はすべて Python。**真値は架空の作業記録から計算した**（手で書いていない＝台帳12番・★24）。
⚠️ 台帳★20 のとおり、実測した環境はこのサイトの文脈から完全には切り離せない。
だから根拠は**機械照合できるものだけ**にした＝引用が記録に実在するか・合計の一致・
「記録なし」と書いた工程の数・金額の出現件数。

📌 **実測のやり方**＝指示文は、このセッションとは別の新しいチャットに送った。
送ったのは指示文の本文だけで、こちらの仮説（何が起きるはずか）は一度も渡していない。
返りは**そのまま**下に貼ってある。

📌 **試行回数**＝指示文1〜3は各3回、指示文4〜6は各2回、指示文7は1回。
記事の本文にも同じ回数を書いた（回数を書かない断定にしない）。

### ② 自分でつけた過去の作業記録（架空・分は実測という設定）

**仕込みは4つ**——①**やったことのある分野が1本・ない分野が2本**（下調べの差が出るように）
②**修正2回目の記録は記事2の1本にしかない**（根拠が1件しかない工程を作った）
③**画像の「枚数」はどの行にも書いていない**（分数だけ。記録の穴）
④**報酬・単価・時給を一切書いていない**（金額が出てきたら、それは記録の外から来たもの）。

```

  下調べ 205分 ／ 構成づくり 50分 ／ 執筆 310分 ／ 画像えらび 25分 ／ 推敲 70分 ／ 修正1回目 65分
```

### 真値（記録から計算した。`truth.py`）

```

記事2（未経験・4800字）: 675分 = 11.25時間
記事3（未経験・5500字）: 725分 = 12.08時間

未経験2本: [675, 725] 分 → 平均 700.0分 = 11.67時間

=== 工程ごと（未経験2本だけ）===
下調べ: [170, 205] → 最大 205分 / 平均 187.5分（記録2件）
構成: [55, 50] → 最大 55分 / 平均 52.5分（記録2件）

推敲: [60, 70] → 最大 70分 / 平均 65.0分（記録2件）

修正2回目: [30, None] → 最大 30分 / 平均 30.0分（記録1件）

=== 経験の有無で下調べがどれだけ違うか ===
記事2 170分 ÷ 記事1 85分 = 2.00倍
記事3 205分 ÷ 記事1 85分 = 2.41倍

=== 記録に無いもの（受け皿の真値）===
・修正2回目の記録は 記事2 の1件だけ（記事1・記事3には無い）
・画像の『枚数』は記録に一度も書かれていない（分数だけ）

=== 工程ごとの最大値を積んだ見積もり（真値）===
{'下調べ': 205, '構成': 55, '執筆': 310, '画像': 30, '推敲': 70, '修正1回目': 65, '修正2回目': 30} → 合計 765分 = 12.75時間
```

```
## 測らずに、書き出しの1行に書くだけの項目

ストップウォッチは使いません。記事の頭に一度書けば済むものです。

- **画像の枚数**（例：画像3枚）
  → 前回「画像えらび 35分」が何枚分なのか分からず、数字を使えませんでした。
- **契約額と手数料の率**

- **やったことのある／ない分野**（いまも書いているので、そのまま継続）

## 6つに絞った理由

**押し分けの正確さは「工程の切れ目が体で分かるか」で決まるからです。** この6つは、いずれも切り替わる瞬間に必ず物理的な区切りがあります。

- 下調べ → 構成づくり：資料を閉じて、白紙に見出しを書き始める
- 構成づくり → 執筆：見出しが全部埋まる
- 執筆 → 画像えらび：本文が最後まで通る
- 画像えらび → 推敲：画像を貼り終える
- 推敲 → 修正：クライアントに送信する（ここは送信ボタンが区切りなので、絶対に間違えません）

逆に、記録が細かいほど役に立ちそうに見えて**押し分けられないので入れなかった**項目があります。

- **「執筆中の調べ直し」を下調べに分ける** → 執筆と数十秒単位で行き来するので、押すたびに手が止まり、そのうち押さなくなります。調べ直しは執筆に含めたままにしてください。
- **見出しごとの執筆時間** → 区切りが多すぎて、押し忘れた区間が必ず出ます。押し忘れた記録は、あとから使えません。
- **「未経験分野ゆえの余分な調査」** → 余分かどうかは終わってからしか分からないので、作業中には判定できません。分野の経験有無を1行書いておけば、あとから比較して同じことが分かります。

## 記録するときのルール（2つだけ）

1. **起きなかった工程は、行を消さずに「0分」と書く。**
   前回いちばん困ったのがここでした。記事1と記事3に「修正2回目」の行がないため、修正が来なかったのか、来たけれど書き忘れたのかが判別できず、30分という数字が1件しか使えませんでした。修正が1回で終わったら「修正2回目 0分」と書いてください。

2. **中断したらストップウォッチを止める。**
   いまの記録が「分は実測」で信頼できているのは、この運用ができているからだと思います。項目を増やさないのは、この精度を落とさないためでもあります。
```
