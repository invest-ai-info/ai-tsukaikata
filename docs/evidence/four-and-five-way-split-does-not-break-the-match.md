## 指示文6（応用・自動化の手順を聞く）

### 送った指示文（記事と同一文字列）

```
毎月、着手金・中間金1・中間金2・残金の4回に分けて入金される契約と、5回に分けて入金される契約が混ざります。件数は月によって10件のときも40件のときもあります。入金明細と契約一覧を毎月同じ形で突き合わせたいです。プログラミングはできません。私が毎月やることを、番号を振って箇条書きで教えてください。
```

### 返ってきたもの（生・2回）

**1回目**：10ステップ。契約一覧に契約番号を振る→契約番号・分割回数の列を用意→入金明細専用シート
（入金日・振込名義・入金額・契約番号・回目）を作る→契約1件1行の照合シート（着手金〜残金＋差額）→
毎月、明細を貼り足し契約番号と回目を入力→SUMIFSで各回の列に入金額を集計→差額がゼロでない行を
フィルターで抽出→差額の符号で原因を分ける→契約番号が空欄の入金行が無いか確認→月ごとに別名保存。

**2回目**：9ステップ。契約一覧（1契約1行・契約番号／分割回数）→回ごとの予定表（4回契約は4行・
5回契約は5行）→「契約番号＋回」のキー列を作る→明細側にも同じキーを付ける→毎月明細を貼り、
キー列をコピー→SUMIFSで入金済み額を集計→差額を確認しフィルター→明細側の「予定表に無い入金」も
COUNTIFで検出→ズレの原因を備考に記録→条件付き書式で色分け→月ごとに別名保存。

### 照合（機械）

両回とも共通する骨格：①契約に固有の番号を振る ②回ごとに列（または行）を分けて予定と実績を
持たせる ③SUMIFS等の関数で入金額を自動集計する ④差額で未入金・不明入金を洗い出す ⑤4回契約と
5回契約は行数が違うだけで同じ仕組みで扱えると明記 ⑥月ごとに別名保存して翌月に引き継ぐ。
手順の数（10 vs 9）は違うが、骨格は2回とも一致した。

### 判定

**採用**。応用の参考として、骨格が一致した部分を記事に反映。
