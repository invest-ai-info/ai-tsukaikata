## この記事から出た教訓（`content/_lessons.md` へ）

1. **新しい観察＝「一言で」の強制は、プロジェクト方式でも肯定へ倒す（0/5→4/5）。**
   H33（コンペ方式・1/5→5/5）とほぼ同じ方向だが、1回少ない（4/5）。方式を変えても
   「一言で」の効き方自体は再現したが、強さは完全には一致しない。
2. **新しい観察＝「一言で」の言い回しを変えると、肯定へ倒れる前に話題そのものが脱線することがある。**
   「AIを」という語を含めずに短く言い換えた3回は、2回が「AIを使ってよいか」ではなく
   「この案件に応募すべきか」という別の質問に答えた。「わからなければわからないと言ってください」
   という保険の一文を足した3回は、3回とも同じように脱線した。**肯定に倒れる（偽って『使ってOK』と
   言う）ことだけを心配していると、もっと分かりにくい失敗（別の質問に答えている）を見逃す。**
   読者が「一言で」の答えを見るときは、まず「その一言は本当にAIの話に答えているか」を確認する
   必要がある。
3. **新しい観察＝「原文をそのまま抜き出してから一言で迫る」という二段構えは、肯定への倒れを防いだ
   （4/5→0/3）。**H33は抜き出し単体（一言強制なし）でしか試していなかったが、一言強制と組み合わせても
   効き方は変わらなかった。**言い直し方は、強制の文言を変えるより、強制の前に一段階挟むほうが安定する。**
