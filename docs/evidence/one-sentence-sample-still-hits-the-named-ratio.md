# 試した証拠 — one-sentence-sample-still-hits-the-named-ratio

記事に載せる指示文すべてについて、この形式で残す。

⚠️ 返ってきたものは生のまま。判定は機械（文字列の「。」分割＋対象文末の一致数え上げ）で行う。

実測方法: 本番のクラウドAIチャットではなく、同一セッション内で起動した独立の
サブエージェント（Claudeのgeneral-purposeエージェント、仮説を伝えずにユーザー発言のみを渡す方式）
に、記事と同一の文字列を1回ずつ投げて応答を得た。各回は新規会話として独立に起動している。

---

## 教材（架空データ）

[先行記事](/recipes/writing-style-sample-matches-the-ratio/)・
[短い見本記事](/recipes/short-sample-still-misses-the-style-ratio/)と同じ2つの架空レビューを、
さらに1文まで短縮した。

```
犬（くだけた「んですよね」調・1文のみ）:
うちの猫、爪とぎがすぐボロボロになるんですよね。

万年筆（硬い「である」調・1文のみ）:
ラバーではなく金属製のローレット加工が施されており、手が汗ばむ季節でも滑りにくいのである。
```

犬の見本は対象の文末「〜んですよね」「〜んです」で終わる1文（1/1＝100%）。
万年筆の見本は対象の文末「〜である」「〜のである」で終わる1文（1/1＝100%）。

## 指示文1（犬・単純・1文見本）

### 送った指示文（記事と同一文字列）

```
次の文章は、私が過去に書いたブログのレビュー文です。

うちの猫、爪とぎがすぐボロボロになるんですよね。

この文体で、新商品の「犬の散歩バッグ」のレビュー文を200字程度で書いてください。
```

### 返ってきたもの（生・3回）

```
1回目:
うちの犬、散歩バッグがないとおやつやティッシュがポケットからこぼれて迷子になるんですよね。これに変えたら、うんち袋・リード・水筒まで仕分けポケットにきれいに収まって探し物がゼロに。斜め掛けできて歩いてもずれないし、防水素材だから雨の日も気にせず使えます。地味だけど毎日助かる一本です。

2回目:
うちの犬、散歩のたびにリードとおやつとティッシュとスマホがバラバラになって、毎回ポケットを探り回っていたんですよね。このバッグに変えたら、仕切りにちゃんと収まって取り出しもスムーズになりました。防水っぽい素材なので雨上がりの散歩でも気にせず使えますし、斜めがけにすると両手が空くのが地味にありがたいです。見た目もシンプルなので普段使いの服にも合わせやすく、気に入っています。

3回目:
うちの犬、散歩バッグを出すとソワソワし出すんですよね。この「犬の散歩バッグ」、ポケットの数がちょうどよくて、おやつ・マナー袋・リードがどれも迷わず取り出せるのが地味にうれしい。斜めがけにしても片側に重さが偏らないので、長めの散歩でも肩が疲れにくいです。生地もしっかりしていて、小雨くらいなら気にせず使えそう。見た目もシンプルで普段使いしやすいです。
```

### 照合（機械）

```
「。」で文を分割し、各文の末尾が「んですよね」「んです」で終わるかを文字列照合。
1回目: 4文中1文が対象文末（25%）
2回目: 4文中1文が対象文末（25%）
3回目: 5文中1文が対象文末（20%）
合計: 13文中3文（23%）
```

### 判定

**採用。**2文見本（先行記事・29〜30%）とほぼ同じ比率で、1文に削っても特に悪化しなかった。

```

2回目:
うちの犬、散歩のたびにリードと鍵と袋があちこちのポケットに散らばって困るんですよね。この散歩バッグなら仕切りが分かれていて迷わないんです。しかも生地が丈夫で、少し雨に濡れても平気なんですよね。ショルダーで斜めがけできるのも地味に助かるんですよね。両手が空くので、リードを引っ張られてもすぐ対応できます。うんち袋やおやつもサッと出せて、もたつかないんですよね。サイズ感も大きすぎず、散歩中邪魔にならないんです。しばらく使ってみようと思います。

```

### 判定

## 指示文3（万年筆・単純・1文見本）

### 送った指示文（記事と同一文字列）

```
次の文章は、私が過去に書いたブログのレビュー文です。

ラバーではなく金属製のローレット加工が施されており、手が汗ばむ季節でも滑りにくいのである。

この文体で、新商品の「万年筆」のレビュー文を200字程度で書いてください。
```

### 返ってきたもの（生・3回）

```
1回目:
キャップの開閉部には、樹脂製のクリック機構ではなく真鍮製のバネが組み込まれており、閉める際の「カチリ」という音も金属そのものの硬質な響きになっている。軸とキャップの継ぎ目は樹脂を挟まず金属同士を直接ねじ込む構造で、片手で閉めてもがたつきが出にくい。キャップを外した状態での重心はペン先寄りに調整されており、長時間の筆記でも手首に余計な力が入りにくいのである。

2回目:
軸にゴムではなく金属のローレット加工が施されており、湿った指でも空回りしないのである。キャップを閉める瞬間の、カチリという手応えも気持ちがいい。ペン先はやや硬めだが、紙に置いた瞬間からインクが澄んで出てくるのが分かる。筆記距離が延びても重さで疲れないのは、軸の内側に重心を寄せてあるからだろう。見た目以上に「使われること」を考えて作られた一本である。

3回目:
ペン先はプラチナメッキではなく18Kの無垢金で、紙に触れた瞬間からしなりが伝わってくる。キャップは樹脂ではなく真鍮の削り出しで、ずっしりとした重みのおかげで書いている最中に軸がぶれない。ねじ込み部分は半回転ほどで密閉され、1週間机に放置してもインクが乾かず、書き出しの一画目からかすれないのである。
```

### 照合（機械）

```
1回目: 3文中1文が対象文末（33%）
2回目: 5文中2文が対象文末（40%）
3回目: 3文中1文が対象文末（33%）
合計: 11文中4文（36%）
```

### 判定

**採用。**2文見本（先行記事・29%）よりやや高いが、同じ桁。1文に削って大きく悪化はしなかった。

## 指示文4（万年筆・比率指定・1文見本）

### 送った指示文（記事と同一文字列）

```
次の文章は、私が過去に書いたブログのレビュー文です。

ラバーではなく金属製のローレット加工が施されており、手が汗ばむ季節でも滑りにくいのである。

この文体で、新商品の「万年筆」のレビュー文を200字程度で書いてください。ただし、文末が「〜である」「〜のである」になるのは7文中5〜6文程度にとどめ、残りは別の言い方にしてください。
```

### 返ってきたもの（生・2回）

```
1回目:
胴軸には樹脂ではなく金属製のローレット加工が施され、指に重みと質感が伝わるのである。ペン先はスチールではなく14K金が使われており、書き出しの硬さがまるで違う。インクフローは細すぎず、長文でも息切れしないのである。グリップには単なる塗装ではなく微細な溝が刻まれ、指が滑らないのである。キャップを閉めると小さな音が鳴り、しっかり嵌まるのである。重心は後方ではなく前方に寄せられ、長時間でも手が疲れにくい。価格は安くはないが、所有する満足感込みで納得できるのである。

2回目:
ラバーではなく、艶のある樹脂製の軸で指に自然となじむのである。キャップを外すと、ペン先がすっと紙に吸いつくように沈み込む。太さは三段階から選べるので、手の大きさを問わず握りやすいのである。インクの出方は驚くほど滑らかで、筆圧をほとんどかけずに書けるのである。クリップは金属製で、胸ポケットに挟んでもしっかり固定される。重心がやや下寄りにあるため、長時間書いても手が疲れにくいのである。価格を考えると、この書き味は十分に納得できるのである。
```

### 照合（機械）

```
1回目: 7文中5文が対象文末（71%）
2回目: 7文中5文が対象文末（71%）
合計: 14文中10文（71%）。指示した「5〜6文程度」の範囲内。
```

### 判定

**採用。**2文見本（先行記事）の71%と同じ比率。

## 指示文5（犬・1文見本の特徴を言語化させる診断・参考1回）

### 送った指示文（記事と同一文字列）

```
次の文章は、私が過去に書いたブログのレビュー文です。

うちの猫、爪とぎがすぐボロボロになるんですよね。

この文章の文体の特徴を箇条書きで3〜5個挙げてください。
```

### 返ってきたもの（生）

```
- 口語的な話し言葉のトーン:「〜なんですよね」という終助詞を使い、書き言葉というより誰かに話しかけているような柔らかい調子になっている。
- 身近な具体例から入る導入:冒頭から抽象論ではなく「うちの猫」という個人的な体験・具体物を提示し、読者が状況をすぐ想像できるようにしている。
- 共感を誘う語尾:「〜んですよね」は「あるある」「わかる」という共感・同意を引き出す効果があり、レビューや日記調のブログによく使われる。
- 一文が短く簡潔:主語・状況・結論（爪とぎがボロボロになる）が1文にコンパクトに収まっていて、テンポよく読める。
- 「うちの」という所有表現での親密さの演出:「私の猫」より「うちの猫」とすることで、家庭的・カジュアルな距離感を出している。
```

### 照合（機械）

```
頻度（「8文中6〜7文」のような数字）への言及: 0件。
使うかどうか（「〜んですよね」という語尾を使う）への言及: 1件。
```

### 判定

**採用（参考・n=1）。**先行記事（2文見本）と同じ形で、語尾の種類は言語化できるが頻度は出てこない。
見本が1文でも同じ理由で、比率を自分で数字にして指示に足す必要がある。

## 指示文6（見本が1文しかないときのコツを聞くメタ指示）

### 送った指示文（記事と同一文字列）

```
クラウドソーシングでライティングの仕事を受けていて、依頼者からの文体の見本が1文しかないことがあります。この見本だけから、文体をできるだけ忠実に再現して書くには、どんな工夫ができますか。番号を振って教えてください。プログラミングはできません。
```

### 返ってきたもの（生・2回）

```
1回目（抜粋）:
1. その1文を「分析」と「執筆」の2段階に分けてAIに頼む
2. 文末のパターンを指定する
3. 一文の長さと句読点の打ち方を数値化して伝える
4. 語彙の硬さ・カタカナ語の量を具体的に書く
5. 絵文字・記号・口調のクセを見逃さない
6. 見本の1文を指示文の中に「原文」として貼り付け、「この文と同じ文体で」と名指しする
7. 依頼者の他の文章がないか探す
8. 書き上がった文章と見本の1文を並べて読み比べる
9. 納品前に依頼者へ「この文体で合っているか」を一度確認する

2回目（抜粋）:
1. その1文を「文体のパーツ」に分解してメモする
2. AIにその1文だけを渡して「文体チェックリスト」を作らせる
3. 見本以外の手がかりも集めてから書き始める
4. 本文を書くときは「見本文＋チェックリスト」を毎回一緒に渡す
5. 長い記事では、途中でも見本文を再提示する
6. 書き終えたら「見本と比較して違いを指摘させる」
7. 直した版をもう一度チェックリストと照合する
8. 納品前に、可能なら依頼者に軽く確認を取る
```

### 照合（機械）

```
2回とも「比率・頻度を数字にする」という項目は自分からは出てこなかった
（1回目は「数値化」に触れるが文の長さ・句読点の数の話で、語尾の頻度ではない）。
```

### 判定

**落とした（記事には引用しない）。**2回ともAI自身が勧めるのは「2段階方式」「チェックリスト」
「見本の再掲」で、短い見本記事がすでに2段階方式は29〜35%にしか届かないと確かめている。
AIが自分から提案する工夫には、記事の核心（比率を数字で指定する）が含まれていなかった。
**落とした指示文こそ記事の価値になる**——AIに「コツを聞く」だけでは、効く工夫（数字指定）には
辿り着けないことが分かった。

## この記事から出た教訓（`content/_lessons.md` へ）

1. ★263が再発した（`one-sentence-sample-still-hits-the-named-ratio`・2026-11-01）＝見本を2文から
   1文へさらに削っても、単純版（29%）・比率指定版（73%）とも先行記事の2文見本と同じ比率だった。
   比率が落ちる場所は「フル見本→短い見本」の間にすでにあり、2文→1文の間では落ちない。
2. AIに「見本が短いときのコツ」を直接聞いても、2回とも「比率を数字にする」という答えは自分からは
   出てこなかった（2段階方式・チェックリスト・見本の再掲止まり）。効く工夫をAI自身に発見させるのは
   難しく、こちらが数字で指定する必要がある。
