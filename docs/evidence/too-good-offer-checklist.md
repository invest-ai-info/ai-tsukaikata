## 指示文1「これは詐欺ですか？」（AとBに別々の新規エージェント）

### 送った指示文（記事と同一文字列）

```
これは詐欺ですか？

```

### 返ってきたもの（生・要点）

- **A（粗い版）**: 「**判定：黒に極めて近い**（典型的な詐欺的勧誘の型に一致）」。
  ただし「『詐欺罪に当たるか』は最終的に司法の判断」と断定は避けた。赤信号8個
  （偽の希少性・収益の断定・出所不明の92%・二重価格＋締切・限定性の演出・検証不能な
  権威付け・条件不明のままリスクゼロ・LINEへの誘導）を挙げ、確認手順と相談窓口
  （188・#9110）まで自発的に付けた
- **B（整えた版）**: 「**グレー（要警戒）**」「申し込みは推奨しません」。危険シグナル6件＋
  「文面に無いこと（特商法表記の欠如）が最大の問題」。
  ⚠️ **「いつもの黒/グレー/白の枠組みで整理します」と述べた＝汚染の証拠**（上記）

### 照合（機械）

```
中身（検証できない主張5件）は A と B で同一（設計）
判定の語: A=「黒に極めて近い」 / B=「グレー（要警戒）」 → 文面を整えただけで一段やわらいだ
どちらの返答も「92%が本当か」「返金されるか」は確かめていない（文面の型の指摘のみ）
```

### 判定

**採用（「効かない側」として）。**判定は立派に見えるが、①見ているのは文面の型で、
事実（92%・返金・実在）はAIにも確かめられない ②同じ中身でも文面で判定が動く
③最良でも「グレー」までで、結局決められない。→ 判定を聞くのをやめ、確認に変える。

```

```

### 返ってきたもの（生・構造）

**「文面に書かれていないことも確認ポイント」として特定商取引法に基づく表記の欠如を指摘**。

### 照合（機械）

```

  誤検知 ②改行をまたぐ引用1件を「不一致」と誤判定（空白正規化で解決）
```

### 判定

**採用（本体）。**「判定して」より役に立つ＝**確かめられないものの一覧**がそのまま
「申し込めない理由」の一覧になる。仕分けは全件引用つきで、読者がその場で照合できる。
