## この記事から出た教訓（`content/_lessons.md` へ）

1. **「分からなければ分からないと書け」という同じ文言は、対象によって効き方が違う。** 前作の教訓4（名前・日付には2/2で効いた）の直接の再検証で、**同じ文言をURL請求に使うと7/10にしか届かない**。対象が変わると効き方も変わるので、「効いた」を他の対象に転用する前に、その対象で測り直す必要がある。
2. **ヒントが減らすのは「出す頻度」で、「出したときの正確さ」ではない。** ヒントの有無に関わらず、実際に出たURLの正確さは3/7(ヒントなし2/4・ヒントあり1/3)で同程度。ヒントは閾値を上げて「自信が無い」と判定される回数を増やすだけで、出てしまった後の中身までは良くしない。
3. **「URLではなく名前を求める」に言い換えると、番号の作り話は完全に止まる（8/8）。**質問の形そのものを変える方が、同じ質問にヒントを足すより効いた。
4. **ただし言い換えても、名前自体の正確さは別問題として残る。**番号の作り話が0件になった6回でも、現行の正式名称を答えた回は0件。「作り話を止める」と「正しい答えを出す」は別の目標で、片方の対策がもう片方に効くとは限らない。
