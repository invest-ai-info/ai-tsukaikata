## この記事から出た教訓（`content/_lessons.md` へ）

1. **★21が再発した（2本目）が、形が違う。**あちらは「短くすると落ちる」。
   こちらは**「形はそろうのに、中身の方針だけが回ごとに割れる」**。
   出す欄と順番を固定すると見出しも列も4回とも一致するので、
   **画面からは毎回同じものが出ているように見える。**割れているのは
   「直すか直さないか」で、要確認の表には**どちらの回も同じ件数が並ぶ。**
2. **★1（禁止は受け皿と対で）が、自動化の形でも効いた（6本目）。**
   「1文字も直さないでください」だけでなく
   「直したい箇所は、直さずに要確認に入れてください」まで書いた版だけが、
   4回とも同じ方針で返った。
3. **同じ指示文でも、入力が違うと出力の形が変わる。**素朴な版では、
   1本目だけ「[時刻] 話者:」の形が丸ごと消えて29行から時刻が無くなり、
   2本目は31行とも残った。**1本で確かめても、2本目で崩れる。**
4. **集計行は「その回の中で合っている」ことしか保証しない。**
   申告した件数は2回とも表と完全一致したのに、2回の件数は10件と8件だった。
5. **拾う条件を細かく書くと、再現性は下がる。**誤検知が0件と3件に割れ、
   件数のブレも大きくなった。そろえたいときに足すのは条件ではなく、突き合わせ。
