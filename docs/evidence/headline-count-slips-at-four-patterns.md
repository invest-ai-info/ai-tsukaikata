⚠️ **最初に作った材料は、この確認で2つとも引っかかった**（★24の再発）。材料Aは19〜22文目が
「ください」4連続・26〜28文目が「ます」3連続、材料Bは20〜22文目が「ください」3連続という、
意図していないパディング部の連続が紛れ込んでいた。語尾を書き換えて（例：「使ってください」→
「使います」）作り直し、上の確認がTrueになってから本番を回した。壊れた版の生の返りは記事・
本稿のどちらにも使っていない。

### 判定用の照合コード（全トライアル共通）

```python
import re

PATTERNS = ["でしょう", "と思います", "のです", "次第です"]

def extract_conclusions(text: str) -> dict:
    """本文に4パターンの語尾が言及されているか、見出し（冒頭260字）で宣言された総数は何か。"""
    mentioned = {p: (p in text) for p in PATTERNS}
    all_mentioned = all(mentioned.values())
    head = text[:260]
    m = re.search(r"(\d)\s*(?:か所|箇所|つ)", head)
    declared = int(m.group(1)) if m else None
    return {
        "全4パターン言及": all_mentioned,
        "見出しの宣言数": declared,
        "宣言数が4と一致": (declared == 4) if declared is not None else None,
    }
```

⚠️ **このスクリプトの限界（台帳★12の手順どおり、先に自分で疑う）**＝「全4パターン言及」は
本文中にその語尾への言及があるかしか見ない。**前作で見つかった「本文には出るが格下げされる」崩れ方
（3つ目が同格のリストから外れ、軽い言葉で追記されるだけ）は、この文字列照合では検出できない。**
そのため「全4パターン言及=True」でも、実際に同格の番号付きリストに4つとも入っているかは目視で
確認し、該当した回（trial_A_3）は本文に個別で記録した。

## この記事から出た教訓（`content/_lessons.md` へ）

1. **文末パターンを3つから4つに増やしても、本文の列挙そのものが崩れる（前作型の格下げ）頻度は
   悪化しなかった**（材料Aで5回中1回・材料Bで5回中0回）。**かわりに、見出しの一文が宣言する数字が、
   直後に同格で並ぶ実際の件数と食い違うという別の崩れ方が、材料Bでだけ新しく出た**（5回中3回）。
   ⚠️ **材料ごとに現れ方が違う**ので「4パターンに増やすと必ず数字がズレる」と一般化しない。
2. 「総数を先または最後に明記してください」の言い直しは、どちらの崩れ方にも効いた
   （材料A+Bの計11回すべてで、見出しの数字と本文の列挙が一致した）。前作の教訓（台帳のこの系列）
   がそのまま拡張して効くことを確認。
