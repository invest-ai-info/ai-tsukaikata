### 返ってきたもの（生）— A1

```
noteで有料記事(有料note)を販売した際にプラットフォーム側に引かれる手数料は、決済方法によって異なります。

クレジットカード決済の場合
- 販売価格に応じたシステム利用料が5%(消費税別)
- 決済手数料が売上金額に応じて変動(小計に対して概ね5%程度)
- 両方合わせると、実質的に売上の約10〜15%程度が差し引かれるイメージです(価格帯によって決済手数料側の率が変わります)

携帯キャリア決済の場合
- システム利用料は同じく5%
- 決済手数料はクレジットカードより高めに設定されており、合計すると手取りが売上の6割前後になることもあります(価格が低いほど手数料の比率が高くなる傾向)

振込手数料
- 売上を実際に銀行口座へ振り込んでもらう際に、別途振込手数料(数百円程度)がかかります

ポイントとして重要な点
- 手数料率は価格帯によって変動し、特に低価格帯(数百円程度)の記事だと決済手数料の比率が相対的に高くなり、手取りがかなり減ります
- 逆にある程度の価格帯(1,000円以上など)になると、手数料率は落ち着き、手取り率が上がっていきます
- noteは手数料の料率を改定することがあるため、正確な最新の数値は、note公式のヘルプページ(「クリエイター向け:販売手数料について」等のページ)で確認するのが確実です

大まかな目安としては、「クレジットカード決済ならおよそ売上の85〜90%程度が手取りになる」「携帯決済はそれよりだいぶ手取りが減る」という理解をしておくと良いかと思います。正確な料率は変更される可能性があるため、実際に販売する前にnote公式の最新情報を確認することをおすすめします。
```

```
noteで有料記事(有料マガジンや有料コンテンツ)を販売した場合、著者の手元に入る金額は主に以下の2段階で手数料が引かれます。

## 1. note運営への「販売手数料」
- クレジットカード決済: 販売価格の5%
- キャリア決済(携帯電話料金合算払い): 販売価格の15%

## 2. 決済代行への「決済手数料」
- 目安としてクレジットカードで約5%程度(カード決済手数料)
- キャリア決済の場合はキャリア決済手数料が別途かかる

## 合計の目安
- クレジットカード決済の場合: 合計で約10%程度(販売手数料5%+決済手数料5%前後)
- キャリア決済の場合: 合計で約20%前後(販売手数料15%+決済手数料分)

つまり、たとえば1,000円の有料記事が売れた場合、クレジットカード決済であれば概ね900円前後が著者の取り分になる、というイメージです。

## 注意点
- 手数料率はnoteの規約改定で変わることがあるため、実際に販売する前には必ずnote公式のヘルプページ(「note収益化」「販売手数料」などのページ)で最新の料率を確認することを強くおすすめします。
- 振込時に別途振込手数料(数百円程度)が発生する場合があります。
- サークル(月額制のコミュニティ機能)など、コンテンツの種類によって手数料体系が異なる場合があります。

正確な最新の数字は変更される可能性があるので、実際に販売設定をする前にnote公式の「よくある質問」や「クリエイターへのお金の還元について」といったヘルプページで確認してください。
```

## この記事から出た教訓（`content/_lessons.md` へ）

1. 「原文の名称そのままのものと言い換えを分けて」という受け皿を作っても、分ける基準そのものがAIの自己申告なので、原文に無い語を「公式の名称そのまま」だと言い切ることがある（2回中2回）。分けさせる指示は、原文との突き合わせを省略させない。
2. 「書かれていなければ書かれていないと言って」の受け皿は、書かれていないと言う**形**を守っても、その手前で挙げる**対象名**（この場合は決済手段の名前）までは検証しない。対象名が架空でも形式的には成立してしまう。

⚠️ 既に台帳にある教訓と重なる部分がある（★16「書かれていないものは、指させる文が無いので話題にならない」・★36「盛りが入ったぶんだけ、事実のほうが落ちている」）。上の2点はその**新しい亜種**として記す（対象名の作り話・自己申告の検証不能性）。次に近い型が出たら、台帳側で番号を振って昇格を検討する。
