# 試した証拠 — weekly-report-loop-without-drift

2026-08-14 実施。**架空の走り書きメモ3週ぶん**（第2〜4週）を、
**前の週の出来上がりを次の週に渡す形で連鎖させ**、各週を**2回ずつ**走らせた。
さらに**メモが0行の週**を1週ぶん足した。

2つの形を比べている。
- **条件A**＝先週の出来上がった週報を「型」として渡すループ（毎週の連鎖がある）
- **条件B**＝先週の出来上がりを渡さず、中身を消した見出しだけを渡す（連鎖が無い）

⚠️ 実測用のセッションは、このリポジトリのファイルを読まないよう指示したうえで走らせた。
ただし**「事前知識なし」とは言えない**（台帳★20）。判定はすべて**機械照合できるもの**だけ
＝語の有無・箇条書きの数え上げ・集合の差。判定コード＝`check.py`。

🚨 **手動版（`weekly-report-from-memo`）と結果が違う点を先に書いておく。**
あちらでは**メモの事実9件のうち2件しか残らなかった**。今回の条件Aでは
**事実はほとんど落ちなかった**（語で照合して 8/9・8/8・8/8）。
かわりに**膨らむ**ほうが起きた。**症状は入れ替わりうる**ので、
「前回を型に渡すと事実が落ちる」と一般化しないこと（★20の系列）。

### 仕込み（先に宣言する）

- **第1週の週報**（人が書いたもの。ここから連鎖が始まる）＝「4. 相談したいこと」は**1件**
- **第2〜4週のメモ**＝9行・8行・8行。**行数は減っていく**
- **メモにも第1週の週報にも1度も出てこない語** 4つを、あとから返りの中で探す

## 指示文6 — メモが0行の週に、何を出すかを先に決めておく（2回）

### 送った指示文（記事と同一文字列）

```
毎週金曜の朝に自動で走らせています。下の見出しだけを使って、今週のメモから週報を作ってください。他の見出しを足さないでください。

・メモに書いていないことは書かないでください。進み具合・割合・見通しを補わないでください。
・材料が無い見出しは「なし」とだけ書いてください。
・メモが1行も無い週も、見出しは全部そのまま出してください。断り文や説明文に置き換えないでください。
・いちばん最後に「今週のメモは◯行でした」の1行を必ず書いてください。0行のときも書いてください。

前置き・感想は書かないでください。
```

このあとに、続けて次を貼って送った。

## 2. 進んでいないこと
## 3. 来週やること
## 4. 相談したいこと

と、空のメモ欄。

```

### 照合（機械）

```
照合: 2つの返りは1文字も違わなかった（diff で0行）。
  見出し1〜4がそのまま出て、中身は4つとも「なし」。
  最後の行は 2回とも「今週のメモは0行でした」。

比べる先:
  条件A（指示文1）のメモ0行 = 2回とも週報の形をしていない散文で、
    「今週の週報は作成できません。」「今週のメモが空のため、週報を作成できません。」

### 判定

**採用。**2回とも同じ形で、**0行だったことが出力の中に1行で残る**。🔑 **「何も無かった週」と「走らなかった週」が、出力の上で見分けられる**——走らなければ、この1行を含むファイル自体が出来ない。⚠️ **見張りそのものはこの記事の範囲外**（自動実行が止まっていないかは別の話）。

## この記事から出た教訓（`content/_lessons.md` へ）

1. **前回の出力を次回の入力にすると、AIが1度足した文が世代を越えて残る。**
   「窓口」「働きかけ」は第2週の1回目に生まれ（同じ週の2回目は0件）、
   その回を第3週に渡したので第3週は2回とも出た。
   **生まれるかどうかは回によるが、残すかどうかは渡す側が決めている。**
2. **落ちるとは限らない。膨らむこともある。**手動版では事実が9件中2件になったが、
   今回は事実はほぼ落ちず、箇条書きが16→18→23件に増えた。
   **症状は入れ替わりうるので、「型を渡すと消える」と一般化しない**（★20の系列）。
3. **メモに無いものがいちばん増えるのは「相談したいこと」**＝1→3→3→5件。
   材料が無い欄ほど、AIが埋める余地がある。
4. **自分の体調・残業のような私的な行は、名指しで受け皿を作らないと報告書に載る。**
   条件Aは2回とも「業務量の配分についてご相談させてください」として上司への相談事項にした。
   「どの見出しにも入れないでください。出すかどうかは私が決めます」＋
   「5. 私が決める行」で2回とも外に出た（★1の系列）。
5. **材料が0行の週に、断り文を返されると出力の形が壊れる。**
   判断としては正しい（推測で埋めなかった）が、
   自動で保存する形では「週報」の中身が断り文になる。
   **見出しはそのまま出させ、0行だったことを1行で書かせる**と、
   2回とも1文字も違わない同じ形で返った。
