## 教材（架空データ）

毎月の請求書発行作業の説明文。本人の視点で、4つの「本文には理由が書かれていないルール」
（H1初回ログイン承認／H2 20万円超の確認／H3 Slack投稿／H4件名統一）と、
1つの「本文に理由が明記されているルール」（H5 月末15時メンテナンス）をさりげなく埋め込んだ。

```
毎月25日に、取引先ごとの請求書を発行しています。やることはだいたい決まっていて、まず会計システムの「請求書発行」画面を開いて、先月の出荷実績を取引先ごとに集計します。集計が終わったら、請求書のテンプレートに金額と品目を入れて、PDFで出力します。出力したPDFは先方の担当者宛にメールで送ります。送るときの件名は「御請求書_(会社名)_(年月)」という形に統一しています。送り終わったら、発行した請求書の控えをフォルダに保存して、その月の分はおしまいです。ちなみにシステムへのログインは、初めて使うときだけ上長に申請して承認コードをもらう必要があって、私はもう何年も前にもらったので毎回は意識していません。あと、金額が大きい請求（20万円を超えるもの）は、送る前に経理部長の確認メールをもらってからにしています。普段は小さい額が多いので忘れがちですが、たまに大きい請求が来ると慌てます。控えは本当はフォルダ保存だけでなく、社内のSlackの#keiri-logというチャンネルにも貼るルールがあるんですが、これも最初に教わってから特に意識せずにやっています。あと月の最終営業日だけ、15時以降は会計システムがメンテナンスで使えなくなるので、その日は早めに済ませるようにしています。
```

仕込みの確認：H1〜H4は「そういうルールがある／教わってやっている」とだけ書かれ、
**理由（なぜそのルールがあるか）は本文のどこにも書いていない**。H5だけ
「15時以降はメンテナンスで使えなくなる」という理由が明記されている。この違いが実測の軸。
