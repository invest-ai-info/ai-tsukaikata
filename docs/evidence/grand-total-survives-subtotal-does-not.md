````
**カテゴリ別合計（13〜15行目、C列）**

```
=SUMIF($A$2:$A$12,A13,$C$2:$C$12)
```

これをC13、C14、C15にそれぞれ入力（A13〜A15にはカテゴリ名が入っている前提）。範囲はデータ行（2〜12行目）だけを参照し、集計欄自体は含まれません。データが増えて範囲を広げたくない場合は、列全体参照にしておくとさらに安心です。

```
=SUMIF(A:A,A13,C:C)
```

**総合計（16行目、C16）**

各カテゴリ合計を足すだけなので、集計欄自体を参照します。

```
=SUM(C13:C15)
```

もしくはデータから直接合計したいなら

```
=SUM(C2:C12)
```

でも問題ありません（こちらもデータ行のみで集計欄を含まない）。

**まとめて入力する場合**

| セル | 数式 |
|---|---|
| C13 | `=SUMIF(A:A,A13,C:C)` |
| C14 | `=SUMIF(A:A,A14,C:C)` |
| C15 | `=SUMIF(A:A,A15,C:C)` |
| C16 | `=SUM(C13:C15)` |

`A:A`/`C:C`の列全体参照を使えば、後でデータ行が2行目〜12行目より増減しても数式を書き直す必要はありません。
````
