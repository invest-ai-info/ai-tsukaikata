反証条件（凍結済み・研究パックの定義どおり。5回基準を1回に比例縮小して解釈）＝
**1個条件の漏れが、0個条件と同じかそれより少ない、または2個条件と同じかそれより多いなら

### 照合（機械）＝指示文1・2をまとめて

```
0個条件: 材料A 漏れなし／材料B 漏れなし → 0／2（0%）
1個条件: 材料A 漏れなし／材料B 漏れ    → 1／2（50%）
2個条件: 材料A 漏れ  ／材料B 漏れ      → 2／2（100%）
```

反証条件＝「1個条件の漏れが、0個条件と同じかそれより少ない、または2個条件と同じか
それより多いなら棄却」。1個条件（1／2）は0個条件（0／2）より多く、2個条件（2／2）
より少ない＝**どちらの棄却条件にも当たらず、仮説は生存**（0→1→2の段階的な増加）。

⚠️ **この照合結果はn=1（材料2本×各条件1回）に基づく。**次に同じ実験をするときは、
最低でも材料2本×各条件3回以上に増やし、この段階的な形が再現するかを確かめること。

### 判定

**採用**。指示文1・2を記事の指示文1・2にそのまま使う。

## この記事から出た教訓（`content/_lessons.md` へ）

1. **新規＝★179候補。**`estimate-leak-follows-missing-number`（H15）は「数値ゼロ」対
   「部分数値あり（2/3埋まっている）」の2水準だけで、漏れ率が12.5%対75%と大きく
   割れることを示した。今回、埋まっている個数を0個→1個→2個と3段階に分けて試すと
   （n=1と小さいが）、漏れが0／2→1／2→2／2と**段階的に増える形**になった。
   「ゼロか部分的か」の二値ではなく、**埋まっている個数そのものが働いている**
   可能性があるという、★159の系列に続く材料。次に確かめる担当は、最低n=3以上に
   増やして段階性が再現するかを見ること。
