## 判定コード（照合に使ったPython・要約）

```python
def flagged_freeze(text):
    keywords = ["完全に一致", "完全に同一", "変化なし", "同じ数値", "同じ値", "固定", "フリーズ",
                "凍結", "一致しています", "変わっていない", "一切変わっていない", "動いていない"]
    return any(k in text for k in keywords)

def z_flagged(text):
    return "商品Z" in text and flagged_freeze(text)
```

⚠️ **この判定コードは否定文を扱えない。**「変わっていない項目はありません」もキーワード
一致で True になる（指示文4の`control_compare`で実際に発生）。この2件だけは目視で
読み直し、内容が「凍結していないと明示している」ことを確認したうえで判定を確定した。
機械判定を鵜呑みにせず、判定コード自体を疑うという台帳12番の型が、この記事でも1件発生した。

## この記事から出た教訓（`content/_lessons.md` へ）

1. 毎日の一覧が凍結（前日と完全一致）しても、「気になる点があれば教えて」という素朴な
   受け皿さえあれば、凍結2日目という早い段階からAIは自分から指摘する。8品中1品だけが
   凍結する紛らわしい材料でも同様（新規の教訓＝★149として追加）。
2. 「凍結の有無」を判定する機械照合は、キーワードの単純一致だと否定文（「変わっていない
   ものはありません」）を誤って「指摘あり」と数えてしまう。今回は目視で確認して判定し
   直した（台帳12番の再発）。
3. 同じ凍結データでも、指示文が「気になる点があれば」という受け皿を含まず、欲しい情報
   だけに範囲を絞ると、AIは凍結に一切触れない。受け皿の一文を足すだけで戻る（新規の
   教訓＝★150として追加）。
