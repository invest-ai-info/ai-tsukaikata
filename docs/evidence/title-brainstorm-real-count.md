## 指示文2（まとめさせて実質の数を聞く）

### 送った指示文（記事と同一文字列）

```
いま出した100件のタイトル案を、言い回しが似ているものどうしでまとめてください。まとめたあと、実質何種類になったか数字で書いてください。
```

### 判定

**採用（ただし注意つき）**。この指示文自体は読者が試せる形として記事に残した。
AI自身の自己申告をそのまま信じるのではなく、本記事の数字（35〜36件）はPythonの
機械判定であることを明記した。自己申告と機械判定を両方走らせて数値を突き合わせる
追加実験は、記事の主眼（密度の実態と改善策）から外れるため今回は行っていない。
⚠️ **次に扱う人へ**＝台帳6番「AIの計数は当てにならない」の検証候補として残る。
