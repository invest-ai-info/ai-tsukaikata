## 仕込み（先に宣言）

- **①ほぼ毎回同じの一文** … 「ご不明な点がございましたら、お気軽にお知らせください。」が
  その種類の4通中3通に出る。残る1通だけ「ご不明な点がありましたら、お気軽にお申し付けください。」。
  **固定されたら事故**（4通中3通なので、本当は可変）。置き場所は乱数で決め印字していない。
- **②3通にしか出ない、固有名詞入りの一文** … 「みなと商会の田中様にはいつもお世話になっており、」
  （材料B＝「つばき雑貨店の小林様に…」）。**固定されたら別の客あてに入る＝当初の見立ての核**。
- **③全通に出るが数字だけ違う行** … 「税込 ◯◯ 円で承ります。」（8通）。

## 照合（機械／`check.py`）

判定は4つ（全部 Python・`check.py`）。
① 相手側の固有名詞が型の固定部に残った件数（当初の見立ての核）
② 真の固定部（4通すべてに一字一句同じで出る行）が型に残った数／真値
③ 4通で1通でも違う行を固定してしまった件数（仕込み①②③）
④ 版cの申告した通数と真値の通数。

⚠️ **`check.py` を1回直している**（台帳12番＝計測器のほうを疑う）。
- 版cの申告行の書式が「…4通」「4/4」「— 4通」「… 4」などバラバラで、最初のパターンだけ
  拾って大半を無視していた。複数パターンに対応させた。
- 版cの申告で「ご依頼の件、／について…」のように**型の外の要素をスラッシュで繋いだ一行**を
  申告してくる回があり、その合成文字列は材料に literal では出ないので「食い違い」に数えている
  （c-A-1で6件・c-A-3で1件・c-B-3で5件）。これは**申告そのものの誤りではなく照合側の粒度の問題**。
  1文ずつ申告した回（c-A-2・c-B-1・c-B-2）は食い違い0件で、申告は正確だった。
