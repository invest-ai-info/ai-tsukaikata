# 試した証拠 — weekly-report-from-memo

2026-08-12 に実施。教材＝架空の週報（先週ぶん）と、今週の走り書きメモ。
様式は `docs/evidence/TEMPLATE.md`。判定はすべて Python（文字列照合）。

⚠️ **仕込み＝今週のメモに「報告すべき事実」を9件入れた。**うち7件は
**「進んでいない」ことを伝える情報**にしてある（返事なし・動きなし・延期・相談したい等）。
これで「都合の悪い事実が残るか」が機械的に判定できる。

## 教材1：先週の週報（型として渡すもの・全文）

```
週報（営業二課 佐藤）2026年8月3日〜8月7日

■ 今週の活動
・〇〇商事：新システムの見積書を提出（8/5）。金額は280万円。進捗70%

■ 数字
・訪問件数：12件
・新規商談：2件
・受注金額（今週）：0円

■ 来週の予定
・〇〇商事の返事待ち。8/12までに回答予定
・△△工業へ見積を作成

■ 相談事項
特になし
```

## 指示文A（素朴版・記事冒頭の「こうなる」例）

### 送った指示文
先週の週報を渡します。この形式で、今週ぶんを書いてください。
（先週の週報と今週のメモを続けて貼った）

### 返ってきたもの（生・全文）

```
週報（営業二課 佐藤）2026年8月10日〜8月14日

■ 今週の活動
・〇〇商事：先週提出した見積書について、先方で検討が進んでいます。進捗85%
・△△工業：追加受注に向けて順調に進行中。引き続きフォローを継続します
・××システム：導入研修の日程を調整中
・□□製作所：新規の問い合わせをいただき、金曜に初回訪問を実施しました

■ 数字
・訪問件数：8件
・新規商談：1件
・受注金額（今週）：0円

■ 来週の予定
・〇〇商事へのフォロー
・△△工業へ見積を作成
・□□製作所への提案書作成

■ 相談事項
特になし
```

### 照合（Python）

```
報告すべき事実: 2/9 残った
★落ちた7件:
  返事がまだ来ていない / 止まっている理由（担当が出張） / △△工業は今週動きなし /
  研修が延期になった / 延期は先方都合 / 事務作業で2日つぶれた / 値引きの可否を相談したい

メモに無い断定: 4件
  「85%」   … メモに進捗の数字は一切無い（先週は70%）
  「順調」   … △△工業は「今週は動きなし」
  「検討が進んで」… メモは「まだ返事なし・担当が出張」
  「調整中」  … 研修は延期・新日程は未定

先週の型から引き継がれた語（今週のメモに根拠なし）:
  進捗 / 順調 / 調整中 / 引き続き / 特になし / フォロー

相談事項: 「特になし」のまま
  ★メモには「□□製作所の見積、標準価格から下げてよいか課長に確認したい」がある
```

### 判定
**記事の中心にした。**発見は3つ。

1. 🚨 **消えた7件が、全部「進んでいない」情報だった。**報告書としていちばん
   伝えなければいけないところが、まとめて落ちる
2. 🚨 **消えた場所は空欄にならず、先週の言葉で埋まる。**「返事なし」→「検討が
   進んでいます」、「動きなし」→「順調に進行中」、「延期」→「調整中」、
   **「値引きの可否を相談したい」→「特になし」**（先週の相談事項がそのまま残った）
3. 🚨 **メモに無い数字が入った**＝「進捗85%」。先週の70%から動かしたもので、
   **どこにも根拠がない**

📌 **返ってきた週報は、読んでも一切おかしくない。**メモと1行ずつ並べるまで、
書き換わっていることが分からない。**目視での確認は成立しない。**

## 指示文B（記事§1〜§7・採用した形）

### 送った指示文
前回の報告書を渡します。これは「見出しの構成」だけを真似るために渡しています。
本文の言い回しや数字は、1文字も流用しないでください。
今週の内容は、このあと渡すメモだけから書いてください。

数字は、メモに書いてあるものだけを使ってください。
メモに無い数字（進捗率・達成率など）は書かないでください。
前回の報告書の数字を、今週ぶんに使い回さないでください。

メモに材料が無い項目は、埋めないでください。「メモに記載なし」と書いてください。

「順調」「引き続き」「検討が進んでいます」のような、状況を評価する言葉は
使わないでください。メモに書いてある事実だけを、そのまま書いてください。

メモの中で「〜したい」「〜してよいか」「〜を確認」と書いてある行を全部挙げてください。
それが相談事項です。1つも無ければ「なし」と答えてください。

最後に「メモのどの行を、報告書のどこに入れたか」の対応表を付けてください。
使わなかった行があれば、それも挙げてください。

### 返ってきたもの（生・抜粋）

```
■ 今週の活動
・〇〇商事：見積の返事はまだ来ていません。担当の田中さんが出張のため、
　来週まで動かないとの連絡がありました
・△△工業：今週は動きがありませんでした（こちらからの連絡もしていません）
・××システム：導入研修が延期になりました。先方の都合で、新しい日程は未定です
・□□製作所：新規の問い合わせをいただき、金曜に初回訪問しました

■ 数字
・訪問件数：8件
・新規商談：メモに記載なし（□□製作所の1件と数えるかは確認してください）
・受注金額（今週）：0円
・進捗率：メモに記載がないため書いていません（先週は〇〇商事70%）

■ 来週の予定
・メモに来週の予定の記載がありません。ご自身で追記してください

■ 相談事項
・□□製作所への見積について、標準価格から下げてよいか確認させてください

■ その他
・経費精算のフォーマット変更に伴う事務作業で、火曜・水曜が埋まりました

【メモのどの行を、どこに入れたか】
1行目（〇〇商事 返事なし・出張）→ 今週の活動1
（…8行目まで…）
使わなかった行：なし

【先週の報告書から引き継いだもの】
・見出しの構成のみ／本文は1文字も流用していません
```

### 照合（Python）

```
報告すべき事実: 9/9 残った
メモに無い断定: 0件
相談事項: 「□□製作所への見積について、標準価格から下げてよいか確認させてください」
メモとの対応表: あり
材料が無い欄の扱い: 「記載なし」と明示
```

### 判定
**採用。2/9 → 9/9、断定 4件 → 0件。**
🔑 効いたのは**「1文字も流用しないで」**と**「使わなかった行も挙げて」**の2つ。
「参考にして」では前回の文がそのまま出る。「対応表を付けて」だけでは
使った行の一覧しか返らず、落ちた行は見えない。

📌 **「新規商談：メモに記載なし（1件と数えるかは確認してください）」**のように、
**判断が必要なところを人に投げ返してきた**のが良い挙動。埋めるより空欄のほうが役に立つ。

## 指示文C〜N

記事§1後半（空の見出しだけを渡す形）・「言い直し方」5件・「応用」2件は
同じ教材で順に実行し、意図どおり動いたため**採用**。特記事項は1つ。

- **「悪いことも書いて」は効かない**（記事§5）。何が「悪いこと」かの判断がAIに委ねられ、
  実測では「経費精算で2日つぶれた」だけが拾われ、延期と相談事項は落ちたままだった。
  **「進まなかったこと／その理由／こちらから動く必要があること」と種類を名指し**して
  初めて全部拾われた。⚠️ **台帳2番（範囲は名前ではなく種類の一覧で）の再発。**

## この記事から出た教訓（`content/_lessons.md` へ）

1. **2番（範囲は種類の一覧で）が再発。**「悪いことも書いて」→「進まなかったこと／
   理由／こちらから動くこと」と名指しで並べて初めて拾われた
2. **4番（自己申告は自覚した範囲しか含まない）の親戚**＝対応表を出させるとき
   「使わなかった行も挙げて」を付けないと、**使った行の一覧しか返らない**。
   落ちた行は自己申告に出てこない
3. **新規＝前回を「型」として渡すと、型が中身を上書きする。**しかも
   **上書きされた文は自然に読める**ので、元の材料と1行ずつ並べるまで分からない。
   ⚠️ **「参考にして」ではなく「1文字も流用しないで」**まで言う。
   確実なのは**中身を消した空の型だけを渡すこと**
4. **新規＝前回の数字は、今週の根拠として使われてしまう。**進捗70%が、
   メモに何の数字も無いのに85%になった（「たぶん進んだだろう」の補間）。
   **「前回の数字を使い回さないで」を明示する**
