## 教材（架空データ）

[前作](../../content/recipes/per-cadence-threshold-clears-the-misfire.md)と同じ生成方法を、
頻度の種類を2（P1〜P5）から3（P1〜P6）に増やして作り直した（`gen.py`）。

```python
import random
from datetime import date, timedelta

START = date(2026, 7, 1)
END = date(2026, 10, 31)  # inclusive

def daterange():
    d = START
    while d <= END:
        yield d
        d += timedelta(days=1)

ALL_DAYS = list(daterange())
MONDAYS = [d for d in ALL_DAYS if d.weekday() == 0]

def first_business_day(year, month):
    d = date(year, month, 1)
    while d.weekday() >= 5:
        d += timedelta(days=1)
    return d

MONTHLY_DAYS_ALL = [first_business_day(2026, m) for m in (7, 8, 9, 10)]

def gen_daily_process(name, lo, hi, seed):
    rng = random.Random(seed)
    lines = []
    for d in ALL_DAYS:
        n = rng.randint(lo, hi)
        minutes = sorted(rng.sample(range(0, 24 * 60), n))
        for m in minutes:
            hh, mm = divmod(m, 60)
            lines.append((d, f"{hh:02d}:{mm:02d}", name))
    return lines

def gen_weekly_process(name, run_days, lo, hi, seed):
    rng = random.Random(seed)
    lines = []
    for d in run_days:
        n = rng.randint(lo, hi)
        minutes = sorted(rng.sample(range(6 * 60, 9 * 60), n))
        for m in minutes:
            hh, mm = divmod(m, 60)
            lines.append((d, f"{hh:02d}:{mm:02d}", name))
    return lines

def gen_monthly_process(name, run_days, lo, hi, seed):
    rng = random.Random(seed)
    lines = []
    for d in run_days:
        n = rng.randint(lo, hi)
        minutes = sorted(rng.sample(range(1 * 60, 5 * 60), n))
        for m in minutes:
            hh, mm = divmod(m, 60)
            lines.append((d, f"{hh:02d}:{mm:02d}", name))
    return lines

def build(variant):
    lines = []
    lines += gen_daily_process("P1", 1, 2, seed=301)
    lines += gen_daily_process("P2", 4, 8, seed=302)
    lines += gen_daily_process("P3", 10, 15, seed=303)
    lines += gen_daily_process("P4", 20, 30, seed=304)

    if variant == "normal":
        p5_days = MONDAYS
        p6_days = MONTHLY_DAYS_ALL
    elif variant == "stop":
        skip5 = {MONDAYS[6], MONDAYS[7]}  # 2026-08-17, 2026-08-24
        p5_days = [d for d in MONDAYS if d not in skip5]
        p6_days = [d for d in MONTHLY_DAYS_ALL if d.month != 9]  # skip September cycle
    else:
        raise ValueError(variant)

    lines += gen_weekly_process("P5", p5_days, 3, 6, seed=405)
    lines += gen_monthly_process("P6", p6_days, 2, 4, seed=506)
    lines.sort(key=lambda t: (t[0], t[1]))
    return [f"{d.isoformat()} {hhmm} process={proc}" for d, hhmm, proc in lines], p5_days, p6_days
```

### 照合（機械）

判定は「0件/0回」という語が、否定マーカー（すべて実行・当たりません・続いたことはない 等）を
伴わずに各処理名と同じ行に現れるか、または「該当は」「当たります」「該当あり」という結論の
行で名指しされているかを見た。ナイーブな日付の部分文字列一致（例：正常版でも全曜日の列挙に
「8/17」が出現する）は誤検知するため使わなかった（台帳12番の系列）。

```python
import re

EXPECT = {
    "normal_1": set(), "normal_2": set(),
    "stop_1": {"P5", "P6"}, "stop_2": {"P5", "P6"},
}

def flagged_processes(text):
    hit = set()
    for line in text.splitlines():
        if re.search(r"当たります|該当(あり|は|します)", line):
            for p in ["P1", "P2", "P3", "P4", "P5", "P6"]:
                if re.search(rf"\b{p}\b", line) or f"**{p}**" in line:
                    hit.add(p)
    return hit

for key, text in outputs.items():
    assert flagged_processes(text) == EXPECT[key]
```

| 回 | 該当として挙げたもの | 真値と一致 |
|---|---|---|
| 正常版・1回目 | 該当なし | ✅ |
| 正常版・2回目 | 該当なし | ✅ |
| 停止版・1回目 | P5・P6の2件のみ | ✅ |
| 停止版・2回目 | 同上 | ✅ |

P1〜P4を誤って該当に挙げた回は、4回を通じて0件だった（各出力の「該当なし」セクションで
明示的に否定されていることも目視で確認済み）。

### 判定

**採用**。[前作](per-cadence-threshold-clears-the-misfire.md)が「まだ確かめていない」としていた
頻度の種類の拡張（毎日・週1回の2段階→月1回を加えた3段階）を実際に試し、正常版の誤報なし・

## この記事から出た教訓（`content/_lessons.md` へ）

1. 新しい教訓。ナイーブな日付の部分文字列一致で機械判定を書くと、「全曜日を列挙して問題なしと
   結論する行」にまで異常日の日付（8/17など）がたまたま含まれ、誤って「異常として検出した」と
   判定してしまう（台帳12番の再発）。判定は「0件/0回」という語と処理名が否定マーカーを伴わずに
   同じ行にあるか、または「該当あり」「当たります」という結論の語で名指しされているかで見るほうが
   安定した。
