### ログの生成方法

Python（`random.Random`。構成ごとに異なる固定シード）で、60日分（2026-08-15〜10-13）の
日別実行回数を生成し、HH:MM形式の時刻を1日の中でだいたい等間隔にずらして割り振り、処理名
（process=P1〜process=P4）付きの行として日付・時刻順に並べた。日別回数の範囲は先行記事と同じ。

```
P1（1日1〜2回想定）
P2（1日4〜8回想定）
P3（1日10〜15回想定）
P4（1日20〜30回想定）
```

5つの構成を作った。

```
=== mixedA ===

  P2: total=337 stop=(2026-09-12, 4日)
  P3: total=620 stop=(2026-09-25, 10日)
  P4: total=1518 stop=なし（正常）
=== mixedB ===
  P1: total=83  stop=なし（正常）
  P2: total=348 stop=(2026-09-08, 2日)
  P3: total=701 stop=(2026-09-16, 4日)
  P4: total=1239 stop=(2026-09-27, 10日)
=== allnormal（全処理が正常） ===
  P1: total=89, P2: total=365, P3: total=747, P4: total=1502
=== soloP1（P1だけ2日間停止） ===
  P1: total=89  stop=(2026-09-10, 2日)
  P2: total=368, P3: total=746, P4: total=1499（いずれも正常）
=== soloP2（P2だけ2日間停止） ===
  P1: total=98, P2: total=363 stop=(2026-09-10, 2日), P3: total=761, P4: total=1513
```

