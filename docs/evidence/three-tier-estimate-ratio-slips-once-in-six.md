# 試した証拠 — three-tier-estimate-ratio-slips-once-in-six

記事「見積もりは3段階で出せる——比率が崩れたのは6回に1回」の指示文6個すべてについて、
送った指示文・返ってきたもの（生）・判定を残す。

実行方法＝Claudeの汎用エージェント（ツール未使用・単発の会話1回ごとに1トライアル）に、
記事に載せた指示文と1文字も違わない文面を送り、返ってきた文章をそのまま貼った。
各トライアルは記憶を共有しない独立の会話（1回ごとに新規）。

## 教材（架空データ）

### 材料A（記事執筆代行）

```
ブログ記事の執筆代行（1本・3,000字程度・指定キーワード1つを含める・初稿提出後に修正1回まで・納期5日）
```

### 材料B（名刺デザイン）

```
名刺デザイン（データ納品のみ・両面・ロゴ画像は支給・修正2回まで・納期3日）
```

仕込み＝材料・指示文とも全トライアルで1文字も変えない。振るのは「材料（A/B）」と
「指示文の版（素朴／比率指定）」の2つだけ。比率（標準÷安い、高い÷標準）は
送った指示文・返ってきた金額から機械（四則演算）で計算する。金額が範囲で返った場合は
中央値（(下限+上限)÷2）を使う。

## 指示文5（金額から比率を自分で計算させる）

### 送った指示文（記事と同一文字列）

```
以下の見積もり金額について、標準は安いの何倍か、高いは標準の何倍かを、それぞれ計算してください。

安い：6,000円
標準：12,000円
高い：20,000円
```

### 返ってきたもの（生）

```
標準は安いの2倍(12,000÷6,000=2)、高いは標準の約1.67倍(20,000÷12,000≈1.67、分数では6/4=1.5ではなく16/12=4/3…念のため正確な分数は5/3)。

正確な結果:
- 標準/安い = 12,000/6,000 = 2倍
- 高い/標準 = 20,000/12,000 = 5/3 ≈ 1.67倍
```

### 照合（機械）

```
真値: 標準/安い = 12000/6000 = 2.0000  高い/標準 = 20000/12000 = 1.6667(=5/3)
AIの最終回答: 標準/安い = 2倍（一致） 高い/標準 = 5/3≈1.67倍（一致）
```

### 判定

**採用**。最終的な数字は2件とも真値と一致（1/1）。ただし回答の途中に
「分数では6/4=1.5ではなく16/12=4/3…念のため正確な分数は5/3」という、
本題と無関係な分数の書き違いらしき記述が挟まっていた（最終結論とは矛盾しない）。
⚠️ **この1回だけの結果**。計算が割り切れない回でどうなるかは未検証。

## 指示文6（4段階への拡張）

### 送った指示文（記事と同一文字列）

```
次の案件について、「安い」「標準」「高い」「特急」の4段階の見積もりプランを考えてください。それぞれ具体的な金額（円）と、含まれる作業内容の違いを明記してください。

案件：ブログ記事の執筆代行（1本・3,000字程度・指定キーワード1つを含める・初稿提出後に修正1回まで・納期5日）
```

### 返ってきたもの（生）

```
① 安いプラン：8,000円（納期5日・基準どおり）
② 標準プラン：15,000円（納期5日・基準どおり）
③ 高いプラン：28,000円（納期5日・基準どおり）
④ 特急プラン：27,000円（標準プラン15,000円＋特急料金12,000円・納期2日）
  作業範囲は標準プランと同一。納期のみ5日→2日に短縮。
```

### 照合（機械）

```
安い=8000  標準=15000  高い=28000  特急=27000
標準/安い = 15000/8000 = 1.8750
高い/標準 = 28000/15000 = 1.8667
特急 (27000) < 高い (28000) ＝価格の並びが「安い<標準<高い<特急」の順になっていない
```

### 判定

**採用**。安い→標準→高いの比率（1.875倍・1.867倍）は指示文1・2のクラスター
（1.875〜2.000倍・1.667〜1.867倍）とほぼ重なった。ただし4段目の「特急」は
比率ではなく「標準プラン＋固定の特急料金」という足し算で決まり、3段目の「高い」より
金額が低くなった。段を増やす指示は、既存の比率をそのまま延長するとは限らない。

## この記事から出た教訓（`content/_lessons.md` へ）

1. 同じ指示文・同じ材料で3回ずつ試すと、6回中5回は狭い範囲（標準/安いが1.875〜2.000倍）に
   収まったが、6回目は1回だけ3.000倍まで跳ねた。少ない回数（2〜3回）の実測で
   「比率は安定する」と言い切るのは早い。比率そのものを数値で指定すれば、
   材料が違っても指定どおりに揃った（2/2）。
2. 段階の数を増やす指示（3段階→4段階）は、既存の段の比率をそのまま延長しない。
   新しい段が「標準＋固定料金」のような別の論理で決まり、価格の並び順を守らないことがある。
