## 2. 今回の案件は、記録に1件も含まれていないタイプ

## 1. 記録から出る「素の数字」

字数あたりの所要時間を出すと、3件ともかなり揃っています。

| | 字数 | 合計 | 1字あたり |
|---|---|---|---|
| 記録1（K社） | 3,200字 | 445分 | 0.139分 |
| 記録2（K社） | 3,000字 | 430分 | 0.143分 |
| 記録3（M社） | 2,600字 | 345分 | 0.133分 |

ばらつきが小さいので、字数からの換算はかなり信頼できます。3,000字なら **約400〜430分（7時間前後）**。記録2がちょうど同じ3,000字で430分なので、ほぼそのまま当てはまります。

ここまでは素直な計算です。問題はこの先です。

## 2. その数字をそのまま使えない理由

3件の記録には、**共通する見えない条件**があります。

- 記録1 = K社から**4件目**
- 記録2 = K社から**5件目**
- 記録3 = M社から**3件目**

つまり**3件とも「勝手が分かっている相手」の仕事**です。レギュレーションは頭に入っていて、好みのトーンも分かっていて、どこを直されるかも読める。下調べ80分・修正1回で終わるのは、その状態だからこその数字です。

一方、今回のN社は**初めての発注元**。今回の案件でいちばん効きそうな条件が、まさに手元の記録に1件も入っていない条件です。

字数（2,600〜3,200字）はほぼ横並びなので「字数の効果」は測れていますが、「初回かどうかの効果」はゼロ件で、**測れていません**。ここを埋めずに430分と答えると、たぶん外します。

ついでに言うと、K社の4件目→5件目で1字あたりの時間がほぼ変わっていない（0.139→0.143）のも示唆的です。**3〜5件目の時点ではもう学習が終わって平ら**になっている。ということは、慣れによる時間の差は1件目〜2件目あたりに集中していたはずで、その一番大事な部分が記録に残っていません。

## 3. どれくらい上乗せするか

初回で余分にかかるのは、だいたいこのあたりです。

- レギュレーション／マニュアル、既存記事の読み込み　**30〜60分**
- 下調べの上乗せ（どこまで depth を求められるか分からないので広めに調べる）　**20〜30分**
- **修正がもう1回増える**可能性　**30〜45分**（記録でも1回30〜45分。記録2は2回入っている）
- 初回特有のやり取り（確認メール、初稿前のすり合わせ、フォーマット直し）　**20〜30分**

合計で **+100〜165分**。ベースの420分に足すと **520〜585分**、およそ **9〜10時間**。

- 楽観シナリオ（レギュレーションが薄く、修正1回で通る）　**約7時間**
- 標準　**8.5〜10時間**
- 悪いシナリオ（修正3回、初稿の方向性がずれる）　**11時間超**

## 4. 見積もりの精度を上げる方法

推測の幅を狭めたいなら、いちばん効くのはこれです。

**K社とM社の「1件目」の記録を探してください。** どちらも今は常連ですが、過去に必ず1件目があったはずです。その2件が見つかれば、「初回は常連時の何倍か」が実データで出ます。1.2倍なのか1.5倍なのかで、今回の答えは500分にも630分にも変わります。今の3件から推測するより、はるかに確かです。

記録が残っていないなら、**今回のN社案件をその1件目のデータとして取ってください**。次にまた新規が来たときに効きます。

あわせて、着手前にN社へ確認しておくと幅が縮みます。

- レギュレーション／執筆マニュアルの有無とボリューム
- **修正の回数上限**（無制限だと見積もりが立ちません）
- 参考にすべき既存記事があるか
- 構成案の事前提出が必要か（必要なら承認待ちの分、日程も延びます）

## なぜその数字になるか

今回はラッキーなことに、**記録2がほぼ同条件**です。K社・3,000字・同じ進め方。つまり430分という実測値がそのまま答えの候補になります。

| | 記録1（K社3,200字） | 記録2（K社3,000字） | 記録3（M社2,600字） |

| 下調べ〜見直し（修正前） | 400分 | 360分 | 310分 |
| 修正 | 45分（1回） | 70分（2回） | 35分（1回） |
| 合計 | 445分 | 430分 | 345分 |

修正前の作業は、今回と字数が同じ記録2で**360分**。ここは条件がそろっているので、かなり信用できます。

そこに修正を足します。過去3件の修正は 45分・70分・35分。**1回なら40分前後、2回なら70分前後**。

- 修正1回 → 360＋40＝**400分（6時間40分）**
- 修正2回 → 360＋70＝**430分（7時間10分）**

## 特に自信を持って言える部分

**執筆時間はほぼブレていません。**3件を字数で割ると、15.2字/分・15.4字/分・15.8字/分。誤差4%以内です。3,000字なら執筆は195分と見て、ほぼ外しません。

逆に**下調べは一番ブレます**（95分・80分・70分）。字数の差だけでは説明がつかない揺れ方をしているので、ここはテーマの馴染み具合で±15分くらい動くと思っておいてください。

## 「だんだん速くなっている」は、たぶん錯覚です

445分 → 430分 → 345分 と並ぶと慣れてきたように見えますが、**字数が違うので、そのまま比べられません。**1字あたりに直すと（修正前の作業で）0.125分 → 0.120分 → 0.119分。ほとんど横ばいです。

記録1と記録2の15分差は、慣れではなく**200字の差でほぼ説明がついてしまいます。**M社の記録3が短いのも、単に2,600字だからです。

なので「6件目だからもっと速いはず」と見込んで短く見積もるのは、やめておいたほうがいいです。**学習効果は、この記録からは検出できていません。**（無いとまでは言えませんが、あるとも言えません。）

## 見積もりを出すときの使い分け

- **クライアントに伝える／締切を約束する** → 修正2回のほうを採用して**7時間強**。修正が1回で終われば早く上がるだけなので、事故りません。
- **自分のスケジュールを埋める** → **7時間半**を確保しておく。下調べの揺れ（＋15分）と、経験上どこかで発生する細かいロス分です。

## 一点だけ、注意しておきたいこと

判断材料が**K社2件・M社1件の合計3件**しかありません。特に「修正が何回来るか」は、K社の2件が1回と2回で割れていて、実質コインの裏表です。これは記録が足りないのではなく、**そもそも相手都合なので予測しきれない**種類の数字だと思います。

なので、次から記録を取るときに1行だけ足すとしたら、修正回数ではなく**「修正がどこから来たか」**をおすすめします。構成段階の認識ズレなのか、事実確認の指摘なのか、語調の好みなのか。もしK社の2回目の修正が語調の好みだったなら、それは執筆前に潰せる可能性があって、次の見積もりが「430分か400分か」ではなく「400分で確定」に変わります。

まとめると、**今回は7時間前後、伝えるなら7時間強**で見てください。
```

```
