   材料Aでしか確かめていなかった。走り書きの材料Bに同じ条件を当てると0/2で外れ、**「渡せば当たる」
   の成立条件が、材料に「これが種類です」と宣言する列見出しの有無だったこと**が分かった。
2. 崩れの原因を切り分けるときは、**「まとめたこと」「項目数」「材料の形式」の3つの候補を、1つずつ
   固定して確かめる**必要があった。まとめても単独でも4/4とも外れ、項目数を1つに絞ってもA材料では
   当たった（★のとおり材料Aは1項目でも2/2で正解）ので、残った変数（材料の形式）だけが崩れの原因だった。
3. 一つの崩れを直す言い直しが、別の項目を壊すことがある（「1件ずつ数えて」が0件警告を直したが、
   件数の内訳を消した）。**言い直しを採用する前に、直したい項目だけでなく、同じ指示文の他の項目も
   毎回読み直す**必要がある。
