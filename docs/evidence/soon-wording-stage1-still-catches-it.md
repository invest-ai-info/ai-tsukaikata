```
v3_1: ['HD-4401'..'HD-4407']（7件）  tp=7/7  fp=[]
v3_2: ['HD-4401'..'HD-4407']（7件）  tp=7/7  fp=[]
```

### 判定

**採用**。「開始の近さ」の名指しに「今日より先は除く」を足すと、そろそろ型4件の回収
（2回とも7件中7件）と巻き添えの排除（2回とも0件）が両方揃った。

---

## 判定のまとめ

```
[指示文1・現行の一文のみ]
 1回目: 7/7（そろそろ型4件を含む）  2回目: 3/7（そろそろ型4件を含まない）
 → そろそろ型4件の回収は2回分8機会中4機会。巻き添えは2回とも0件。

[指示文2・開始の近さを名指し]
 1回目・2回目とも9件（真値7件＋巻き添え2件）
 → そろそろ型4件の回収は2回分8機会中8機会（100%）。巻き添えは2回分4機会中4機会（100%）。

[指示文3・②＋「今日より先は除く」]
 1回目・2回目とも7件（真値のみ）
 → そろそろ型4件の回収は8/8。巻き添えは0/4。
```

**この記事の値打ちは2つ。**①前作が「試していない」と明記していた案（開始の近さを別枠で
名指し）を実際に試し、「そろそろ」型の回収率が上がることを確かめた。②同時に、語を名指しする
だけでは来月・契約更新のような今日の話ではない予定まで誤って含める新しい巻き添えが生まれる
ことを発見し、「今日より先は除く」という範囲の指定で両方が揃うことを確かめた。②が無いと、
「名指しすれば直る」という一般化した結論になってしまう。

## この記事から出た教訓（`content/_lessons.md` へ）

1. ★37が再発した。「そろそろ」「まもなく」のような語を許可する一覧として名指しすると、AIは
   その語の存在だけで判定するようになり、その語が指す出来事が「今日」かどうかまでは確認しなく
   なった（来月の研修・契約更新の話にまで2回とも反応）。禁止語の一覧だけでなく、許可語の一覧に
   も同じ穴がある。効いたのは語を削ることではなく、語の一覧はそのまま残し「それが今日中である
   かどうか」という範囲を別に指定すること。
