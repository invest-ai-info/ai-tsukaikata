## この記事から出た教訓（`content/_lessons.md` へ）

1. 似た名前・似た文言の項目を『まとめて』と素朴に頼んでも、区別できる手がかり（店舗コード・住所など）が材料のどこかにありさえすれば、指示していなくても誤って1つに畳まれることはなかった（38回中0回）。一覧を28行に増やし、罠のペアを離して配置しても崩れなかった。
2. 区別する手がかりが本当に材料の中に無いときも、多くの回は勝手に『同じ』と決めつけず『不明』に倒れた。ただし2回に1回は、確実に区別できる部分（法人格が分かる行）まで、本当に決められない行と一緒くたに『要確認』1グループへまとめてしまい、粒度が粗くなった。『確定できるものと、本当に決められないものを分けて』と一文足すと、2回とも粒度のブレが消えた。
