# 試した証拠 — listing-only-what-you-checked

フリマ・ハンドメイドの商品説明文を、メモにある事実だけで書かせられるかを実測した記録。

⚠️ 判定はすべて Python の文字列照合。計測コードは `check.py`（本文中に全文を貼ってある）。
⚠️ 台帳★20 のとおり、実測した環境はこのサイトの文脈から切り離されていない。
だから根拠は**機械照合できるものだけ**にした＝先に決めた語の有無・メモの項目が残った数・
引用が原文に実在するか。

## この記事から出た教訓（`content/_lessons.md` へ）

1. **★36（新規）**＝盛られるのは形容だけではない。**盛りが入った量だけ、事実が落ちる。**
   素朴な説明文は盛り語14件と引き換えに、メモ23項目のうち9項目を落とした。

2. **★1が再発した（6本目）**＝「メモに書いていないことは一切書かないでください」は
   盛り語を14→0にするが、**不明と不利も一緒に消える**（17/23）。
