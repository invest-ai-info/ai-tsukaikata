# 試した証拠 — pr-disclosure-judgment-holds-across-x-and-note

記事に載せる指示文すべてについて、この形式で残す。

実測方法: 同一セッション内で起動した独立のサブエージェント（Claudeのgeneral-purposeエージェント、
仮説を伝えずにユーザー発言のみを渡す方式）に、記事と同一の文字列を1回ずつ投げて応答を得た。
各回は新規会話として独立に起動している。

出典: 消費者庁「一般消費者が事業者の表示であることを判別することが困難である表示」の運用基準
（令和5年3月28日　消費者庁長官決定・
<https://www.caa.go.jp/policies/policy/representation/fair_labeling/guideline/assets/representation_cms216_230328_03.pdf>・
2026-11-01確認）。PDFをダウンロードし、本文を読んで該当箇所を確認した（WebFetchはPDFのバイナリを
そのまま読めなかったため、Readツールでページ画像として開いて確認した）。

- 先行記事が引用した箇所＝第3-2-(2)-ク「事業者の表示であることを他の情報に紛れ込ませる場合
  （例えば、ＳＮＳの投稿において、大量のハッシュタグ（……）を付した文章の記載の中に当該事業者の
  表示である旨の表示を埋もれさせる場合）。」（PDF 8〜9ページ）
- この記事で新しく使う箇所＝同じ第3-2-(2)のキ「事業者の表示である旨を、文章で表示しているものの、
  一般消費者が認識しにくいような表示（例えば、長文による表示、周囲の文字の大きさよりも小さい表示、
  他の文字より薄い色を使用した結果、一般消費者が認識しにくい表示）となる場合。」（PDF 8ページ）。
  **「長文による表示」という文言が、ハッシュタグとは別の独立した例として明記されている。**

## 指示文1（X埋没版の判定）

### 送った指示文（記事と同一文字列）

```
次のX(旧Twitter)投稿文について、消費者庁の「一般消費者が事業者の表示であることを判別することが困難である表示」の運用基準に基づいて、PR表記の位置が十分に分かりやすいかどうかを判定してください。運用基準の該当箇所はこちらです:「事業者の表示であることを他の情報に紛れ込ませる場合(例えば、SNSの投稿において、大量のハッシュタグを付した文章の記載の中に当該事業者の表示である旨の表示を埋もれさせる場合)。」
```

（上に続けてX埋没版の投稿文を貼った。）

### 返ってきたもの（生・2回）

```
1回目（抜粋）:
## 判定:不十分である可能性が高い
#PR は6個中4番目に置かれ、前後をすべて商品・季節・価格訴求のハッシュタグに挟まれています。
……本件は6個中4番目=両側に複数タグが並ぶ位置であり、紛れ込みに該当しやすい。
……現状の投稿は……「事業者の表示であることを他の情報に紛れ込ませる場合」に該当するリスクが高く、
PR表記の位置は十分に分かりやすいとは言えません。

2回目（抜粋）:
【結論】このケースは「直ちに違反」と言い切れるほど悪質ではありませんが、改善の余地がある
「グレーゾーン」です。……ハッシュタグの総数は6個。運用基準が問題視しているのは「大量の
ハッシュタグ」の中に埋没させる行為です。……6個であれば「大量」とは言いにくく、この点だけでは
違反性は高くありません。ただし「#PR」の位置が……「紛れ込ませ」の方向性と一致する要素です。
……実務的には「セーフとは言い切れないグレー」と評価するのが妥当。
```

### 照合（機械）

```
正解（仕込みの意図）＝「判別困難（不十分）」寄りの判定が出るべき。
1回目: 「不十分である可能性が高い」＝明確に正しい向き。
2回目: 「グレーゾーン」＝方向性は正しい（セーフとは言わなかった）が、「大量」の文言解釈で
       明確な「不十分」とまでは言い切らなかった。
```

### 判定

**採用。**2回とも「セーフ」とは判定しなかったが、判定の強さに差が出た。2回目は運用基準の
「大量の」という文言に字義どおり反応し、ハッシュタグが6個では「大量」と言えるか迷っていた。

## この記事から出た教訓（`content/_lessons.md` へ）

1. 判定基準の文言を新しい媒体（X・note/ブログ）に広げても、8回中7回は正しい向きで判定できた。
   特にnote・ブログの「長文による表示」（運用基準キ）は2回とも揺れなく正しく、ハッシュタグの例
   （運用基準ク）より判定が安定していた。
2. Xのハッシュタグ埋没版だけ、2回中1回は「大量のハッシュタグ」という**運用基準の字句そのもの**に
   引きずられ、ハッシュタグが6個（先行記事の5個と近い数）でも「大量と言えるか微妙」とグレー判定に
   傾いた。判定基準の文言をそのまま渡すと、具体的な数量語（「大量の」）に字義どおり反応し、
   構造的には同じ「紛れ込み」でも判定の強さが変わることがある。
