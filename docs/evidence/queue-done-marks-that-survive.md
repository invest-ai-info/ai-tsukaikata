# 試した証拠 — queue-done-marks-that-survive

2026-08-19 実施。**架空の待ち行列ファイルを2本**（A＝調べて1行にまとめる待ち行列、
B＝問い合わせの返信下書き 待ち行列）作り、4つの指示文を
**材料2本 × 各2回 ＝ 16系列、各系列を2回転させて全32回**通した。

🔑 **2回転の作り方＝1回転目に返ってきた「更新後の待ち行列の全文」を、
そのまま2回転目の入力にした。**自動実行では、返事の文章は捨てられてファイルだけが残る。
その形をそのまま再現している（台帳★12c／★34の形）。

| 指示文 | 何を足したか | 回数 |
|---|---|---|
| 1 | そのまま「未処理を1件だけ処理して、済の印を付けて」 | 材料2本 × 各2回 × 2回転 ＝ **8回** |
| 2 | 1＋「印は `- [x] ` に固定。ほかの行は1文字も変えないで」 | **8回** |
| 3 | 2＋「処理できなかった行は `- [!] ` にして理由を次の行に」 | **8回** |
| 4 | 2＋「処理できなかった行は、待ち行列のいちばん下に移して」 | **8回** |

判定はすべて Python。判定コード＝`gen.py`（待ち行列を作り、仕込みの成立を検算する）、
`mk.py`（貼るメッセージの組み立てと、返りからの待ち行列の取り出し）、
`check.py`（もとの12行との突き合わせ）、`split.py`（処理できない行の印がどうなったかを数える）、
`pos.py`（その行がどこへ動いたかを見る）。
🚨 **`split.py` だけでは足りなかった**＝印しか見ていないので、指示文4の「いちばん下に移す」が
「印を変えずに飛ばしただけ」と区別できず、**受け皿が働いているのに働いていないように見えていた**
（台帳12番。`pos.py` を足して直した）。

🚨 **書き始める前の見立て（「失敗した行にも済が付いて、その行は永久に飛ばされる」）は、
32回とも起きなかった。**題を実測に合わせて変えてある。

⚠️ 実測用のセッションは、このリポジトリのファイルを読まないよう指示したうえで走らせた。
ただし**「事前知識なし」とは言えない**（台帳★20）。判定は機械照合できるものだけにしてある。

### 仕込み（先に宣言する）

待ち行列は材料ごとに**12行**。内訳は **`- [x]` 済み4行／`- [!]` 前回できなかった2行／
`- [ ]` 未処理6行**。各行の下に、その仕事に使う資料が1行ぶらさがる。

🚨 **未処理6行のうち2行は、どう頑張っても処理できない**（資料が「（取得できませんでした）」
「（文字化けしていて読めません）」になっている）。
🚨 **並び順を固定してある**＝未処理の1番目は処理でき、**2番目は処理できない**。
**だから1回転目は必ず成功し、2回転目で必ず「できない行」が未処理の先頭に来る。**

⚠️ この並びが成立していることは、材料を配る前に `gen.py` が確かめている（台帳★24）。実行結果:

## この記事から出た教訓（`content/_lessons.md` へ）

1. 🚨 **見立てが外れた**＝「失敗した行にも済が付く」は**32回とも0件**。
   AIは32回とも、処理できない行に済の印を付けなかった。
   **勧めていたこと（済の印を付けさせる）は、この形では正しかった。**
2. 🔑 **壊れたのは、縛りを足したほう**＝「印は `- [x] ` に固定」「ほかの行は1文字も変えないで」を
   足した4系列のうち**3系列で、できない行が `- [ ]` のまま残った**。
   素朴に頼んだ4系列は**4系列とも `- [!]` を付けている**。★1（禁止は受け皿と対で渡す）そのもの。
3. 🔑 **★48が、いちばんきれいな形で再現した**＝縛った回でも、AIは
   **返事の文章のほうには**「本文が文字化けしていて読めないので飛ばしました」と書いている。
   **自動実行ではその文章は捨てられ、ファイルだけが明日に渡る。**
   だから**情報は出ているのに、明日には届かない。**
4. 🔑 **受け皿は「印」より「置き場所」のほうが確実に働いた**＝`- [!]` を頼んだ指示文3は4/4、
   「いちばん下に移して」と頼んだ指示文4も4/4。ただし**指示文4は印を変えなくても位置で効く**ので、
   縛り（1文字も変えるな）と衝突しない。★37（受け皿は置き場所まで指定する）の再現。
5. 🔑 **素朴な回が正しく動いたのは、材料に前例があったから**＝待ち行列にもとから
   `- [!]` の行が2件あり、返り自身が「内田様・松本様に `- [!]` が付いているので、
   高橋様も本来はその仲間だと思います」と書いた。
   → **書式を指示文で教えるより、ファイルの中に1行お手本を置くほうが効く場合がある。**
