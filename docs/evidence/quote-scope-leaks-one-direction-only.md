## 指示文1（パターンa「含まれる作業を挙げてください」・材料A/B各3回＝計6回。H7の凍結値）

### 送った指示文（記事と同一文字列）

```
副業で受けた見積書です。

（見積書を貼る）

含まれる作業を挙げてください。
```

### 返ってきたもの（生）— 要点

```
材料A・3回: 3回とも含む作業5件を正しく列挙したうえで、「なお、以下は除外事項として
  明記されているため」等の一文を添え、除外事項5件をすべて列挙した。3/3が聞かれていない
  側（除外事項）に触れた。

材料B・3回: 1回目・2回目は含む作業5件のあと「一方、画像選定・作成、CMSへの入稿…は
  除外事項に明記されており、含まれません」と5件全部に触れた。3回目は含む作業5件のみで、
  除外事項への言及は無し。2/3が聞かれていない側に触れた。
```

### 照合（機械）

```
パターンa・6回のうち、聞かれていない側（除外事項）に1件以上触れた回: 5/6（83%）
```

### 判定

**採用。**反証条件（3回以上）を満たすため、**パターンaの方向ではH7は棄却**——
「含まれる作業を挙げて」と聞くと、5/6が自分から除外事項まで書いた。

## 指示文6（応用・対照＝範囲を中立に聞く・材料A/B各1回）

### 送った指示文（記事と同一文字列）

```
副業で受けた見積書です。

（見積書を貼る）

この見積もりの範囲を教えてください。
```

### 返ってきたもの（生）

```
材料A: 「含まれるもの」「含まれないもの（別料金・別対応）」の両方を、見積書の全10項目と
  一致する形で列挙。金額・納期にも言及したうえで、確認しておくとよい点を添えた。
材料B: 「含まれる作業」「含まれない作業（別料金・対応対象外）」の両方を全10項目と一致する
  形で列挙。単価換算や、追加料金になりやすい項目への注意も添えた。
```

### 照合（機械）

```
含む作業・除外事項の両方（各5件）が明記された回: 2/2
```

### 判定

**採用。**「範囲を教えて」という中立な聞き方でも、2/2とも両方が自分から出てきた。
パターンa（「含まれる作業」を聞く）と同じ向きの挙動。

## この記事から出た教訓（`content/_lessons.md` へ）

1. **H7は方向によって結果が割れた。**「含まれる作業を挙げて」と聞くと5/6が自分から除外事項
   まで書いたが（パターンaでは棄却）、「除外事項を挙げて」と聞くと含む作業にはほぼ触れなかった
   （1/6・パターンbでは生存）。`conflicting-conditions-first`の「聞かれた側だけが返る」は、
   矛盾/欠落という対では両方向とも成立していたが、含む/含まないという対では**一方向だけ**
   成立した。「対になった条件は両方とも聞かれた側だけが返る」と一般化しない。
2. **新規＝見積書のような『含む』が先に立つ場面では、範囲を答えるときに除外もセットで
   出す傾向がある。**指示文6（中立に「範囲を教えて」）でも2/2が両方を返しており、パターンa
   と同じ向き。おそらく「含む作業だけを答えると、書いていない依頼が来たときの線引きが
   曖昧になる」という実務上の配慮が、素朴な質問でも働いている可能性がある（仮説。機械では
   確認できない）。
