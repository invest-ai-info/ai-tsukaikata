## 教材（架空データ）

### ログの生成方法

Python（`random.Random`。処理ごとに固定シード）で、60日分（2026-08-15〜10-13）の実行時刻ログを
生成した。

- **P1**（1日1〜2回）・**P2**（1日4〜8回）・**P3**（1日10〜15回）・**P4**（1日20〜30回）は、
  [先行記事](../../content/recipes/short-stop-slips-through-on-the-quiet-process.md)と同じ生成方法
  （seed=101/102/103/104）。60日間すべてで1件以上になり、停止は仕込んでいない
- **P5**（新規）＝週1回（毎週月曜の06:00〜09:00台）だけ動くバッチ処理。実行する月曜は3〜6回
  （seed=205）

2つの版を作った。

```
=== normal（正常版） ===
  P5の実行日（9回・すべて月曜）:
  2026-08-17, 2026-08-24, 2026-08-31, 2026-09-07, 2026-09-14,
  2026-09-21, 2026-09-28, 2026-10-05, 2026-10-12
  本当の停止は無い

=== stop（停止版） ===
  P5の実行日（7回）:
  2026-08-17, 2026-08-24, 2026-08-31, 2026-09-07,
  2026-09-28, 2026-10-05, 2026-10-12
  09-14・09-21の2回ぶんが欠落。直前の実行(09-07)から次の実行(09-28)まで21日間記録が無い
```

生成スクリプト（`gen.py`、再現用に全文）：

```python
import random
from datetime import date, timedelta

START = date(2026, 8, 15)
END = date(2026, 10, 13)  # inclusive, 60 days

def daterange():
    d = START
    while d <= END:
        yield d
        d += timedelta(days=1)

ALL_DAYS = list(daterange())
assert len(ALL_DAYS) == 60, len(ALL_DAYS)

MONDAYS = [d for d in ALL_DAYS if d.weekday() == 0]  # Monday=0

def gen_daily_process(name, lo, hi, seed):
    rng = random.Random(seed)
    lines = []
    for d in ALL_DAYS:
        n = rng.randint(lo, hi)
        if n == 0:
            continue
        minutes = sorted(rng.sample(range(0, 24 * 60), n))
        for m in minutes:
            hh, mm = divmod(m, 60)
            lines.append((d, f"{hh:02d}:{mm:02d}", name))
    return lines

def gen_weekly_process(name, run_days, lo, hi, seed):
    rng = random.Random(seed)
    lines = []
    for d in run_days:
        n = rng.randint(lo, hi)
        minutes = sorted(rng.sample(range(6 * 60, 9 * 60), n))
        for m in minutes:
            hh, mm = divmod(m, 60)
            lines.append((d, f"{hh:02d}:{mm:02d}", name))
    return lines

def build(variant):
    lines = []
    lines += gen_daily_process("P1", 1, 2, seed=101)
    lines += gen_daily_process("P2", 4, 8, seed=102)
    lines += gen_daily_process("P3", 10, 15, seed=103)
    lines += gen_daily_process("P4", 20, 30, seed=104)

    if variant == "normal":
        run_days = MONDAYS
    elif variant == "stop":
        skip = {MONDAYS[4], MONDAYS[5]}  # 09-14, 09-21
        run_days = [d for d in MONDAYS if d not in skip]
    else:
        raise ValueError(variant)

    lines += gen_weekly_process("P5", run_days, 3, 6, seed=205)
    lines.sort(key=lambda t: (t[0], t[1]))
    return [f"{d.isoformat()} {hhmm} process={proc}" for d, hhmm, proc in lines]
```
