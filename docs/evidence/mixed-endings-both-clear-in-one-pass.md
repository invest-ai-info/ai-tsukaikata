# 試した証拠 — mixed-endings-both-clear-in-one-pass

記事に載せる指示文すべてについて、この形式で残す。

実測方法: 同一セッション内で起動した独立のサブエージェント（Claudeのgeneral-purposeエージェント、
仮説を伝えずにユーザー発言のみを渡す方式）に、記事と同一の文字列を1回ずつ投げて応答を得た。
各回は新規会話として独立に起動している。判定は「。」分割＋対象文末の連続回数の数え上げ（機械）。

## 教材（架空データ）

[前の記事](/recipes/other-endings-and-longer-runs-still-clear/)が残した宿題
「複数の文末表現が別々に3回以上連続する場合は試していません」に答える。2種類の文末パターンを
別々の箇所に仕込んだ、新しい架空の下書き2本を用意した。

```
材料A（新商品説明会の案内文）＝「〜のです」4回連続＋「〜でしょう」3回連続:
来月から新商品説明会を社内で開催することになったのです。説明会は毎週水曜の午後に行うのです。
参加者は事前に希望日を申請するのです。資料は説明会の前日までに配布するのです。
質問がある方は当日に直接聞いていただいて構いません。説明会の内容は後日録画でも確認できるでしょう。
参加できなかった方も内容を把握できるでしょう。録画の視聴期限は2週間程度になるでしょう。

材料B（在宅勤務ルールの連絡文）＝「〜ください」4回連続＋「〜と思います」3回連続:
来月から在宅勤務の申請方法が変わります。申請は前日までに部署フォルダへ提出してください。
承認が下りるまでは出社予定で動いてください。機材の不具合があれば総務へ連絡してください。
在宅勤務の日も朝会には必ず参加してください。新しいルールは来月から試験的に運用されると思います。
問題があれば随時見直していくと思います。半年後には正式な制度にする予定だと思います。
```

仕込みの宣言: 材料Aは文2〜5が「のです」4回連続、文6〜8が「でしょう」3回連続。
材料Bは文2〜5が「ください」4回連続、文6〜8が「と思います」3回連続。どちらも2種類のパターンは
文の位置として別々の箇所にある（間に1文の「地の文」を挟んでいる）。

### 照合（機械）

```
各回を「。」で分割し、文末が「のです」「でしょう」で3回以上連続する箇所を数える。
1回目: のです0回連続・でしょう0回連続（両方解消）
2回目: のです0回連続・でしょう0回連続（両方解消）
3回目: のです0回連続・でしょう0回連続（両方解消）
合計: 3/3回で両方のパターンが同時に解消した。
```

### 判定

**採用。**前の記事は1本の下書きに1種類しか仕込んでいなかったが、2種類を別々の箇所に仕込んでも、
素朴な指示だけで3回とも両方解消した。
