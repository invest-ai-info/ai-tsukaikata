## この記事から出た教訓（`content/_lessons.md` へ）


1. 新規追加。「初期化してください」という動詞は、主語（対象名）を伴わないと、AIが「今回取得できた分をそのまま報告する」（過去分を計上）と「既存分も含めて全部リセットする」のどちらにも倒れうる。対象名を主語にするか、対象を明示的に限定する一文を添えれば、詳しい書き方でも短い一言でも安定した（このファイルの指示文1・3・4・5・6）。
2. 新規追加。実測の相手にClaude Code CLI（`claude --safe-mode --tools ""`）を使うとき、「初期化」「登録」など状態変更を連想させる語を含む指示文では、`--tools ""` で実行できないはずのツール呼び出しを文章として書き出す壊れ方が起きることがある（同一指示文・同一環境でも再現したりしなかったりする）。`--system-prompt` で汎用アシスタント人格に固定すると解消した。次にこの方法で実測する担当は、最初の1回で同じ壊れ方が出ないか確認し、出たら人格を固定してから測り直すこと。
