# 文末表現が連続している箇所

この文章は、同じ文末の文がほぼすべて3〜4文ずつまとまっています。特に不自然に感じやすい順に挙げます。

## 目立つもの(優先して直したい箇所)

| # | 文末 | 該当文 |
|---|---|---|
| ① | **〜てください** ×3 | 「先輩に聞いてください。」「当番リーダーに連絡してください。」「元の場所に戻してください。」 |
| ② | **〜です** ×3 | 「目的は作業時間の短縮です。」「対象は〜全員です。」「開始日は来週の月曜日です。」 |
| ③ | **〜でしょう** ×3 | 「戸惑うこともあるでしょう。」「短くなるでしょう。」「楽でしょう。」 |
| ④ | **〜そうです** ×3 | 「使っているそうです。」「変更するそうです。」「貼られるそうです。」 |
| ⑤ | **〜ましょう** ×3 | 「均等にしましょう。」「相談しましょう。」「保ちましょう。」 |

②は文末だけでなく「〇〇は〜です」という文型も3回続いているため、箇条書きのような印象が強くなっています。

## 「〜ます」の連続(①〜⑤ほどではないが単調)

- 「担当します。/なっています。/繰り越します。/まとめてあります。」(4文)
- 「干しておきます。/一声かけます。/借ります。/片付けます。」(4文)
- 「交換します。/使います。/換気をします。/使います。」(4文。「使います」が2回)
- 「付けます。/しまいます。/確認します。/補充します。」(4文)

「〜ます」は連続しても違和感が出にくい文末です。ただ、短い文が同じ調子で並ぶと読みにくくなります。

- **文をつなげる**:「〜し、〜」「〜ので、〜」「〜たら、〜」を使って2文を1文にする。
- **文末を混ぜる**:「〜てください」「〜ましょう」「〜です」「〜ことになっています」などを交互に使う。
- **内容ごとに並べ直す**:今は文末の種類ごとに文がまとまっています。「概要 → 担当の決め方 → 作業手順 → 他部署の状況 → お願い」のように内容で並べると、文末は自然に分散します。

業務連絡の文が「〜します。〜します。〜します。」と続くと、それ自体が文末の連続になります。挟み込みの文は、語尾を1文ずつ変えて書きます。

## 照合（機械）

判定コードは `judge.py`（下に全文）。各出力について、(a) `総数/合計/全部で` に紐づく数字（冒頭・末尾どちらの位置でも拾う）、(b) 5つの目標パターン（してください・です・でしょう・そうです・ましょう）が応答のどこかにすべて現れているか、(c) 見出し・表見出しなど短い『ラベル行』の中で、目標パターンが2つ以上一緒に名指しされている（＝パターンどうしが1つの項目にまとめられた）行が無いか、を見る。

```python
import re
import sys
import glob

TARGET_STRS = ["てください", "でしょう", "そうです", "ましょう"]

LABEL_LINE_RE = re.compile(r"^(#+\s|\*\*[0-9①②③④⑤⑥⑦⑧⑨⑩]|[①②③④⑤⑥⑦⑧⑨⑩]|\d+[\.\)]|\|)")

def hits_in(text):
    hits = set()
    if "てください" in text:
        hits.add("てください")
    if "でしょう" in text:
        hits.add("でしょう")
    if "そうです" in text:
        hits.add("そうです")
    if "ましょう" in text:
        hits.add("ましょう")
    text_no_sou = text.replace("そうです", "")
    if "です" in text_no_sou:
        hits.add("です")
    return hits

def extract_total(text):
    """Prefer a number explicitly bound to 総数/合計/全部で, wherever it occurs
    (declaring it can be asked for at the start OR the end of the response)."""
    labeled = re.findall(r"(?:総数|合計|全部で)[^\d]{0,12}(\d+)\s*(?:か所|箇所|つ)", text)
    if labeled:
        return int(labeled[-1])
    # fall back: a count near the very start of the response (naive prompt, no explicit label)
    head = text[:200]
    nums = re.findall(r"(\d+)\s*(?:か所|箇所|つ)", head)
    return int(nums[0]) if nums else None

def label_merges(text):
    """Only check short 'label' lines (headings / table rows / numbered markers),
    where the LABEL portion (before any long quoted example) names 2+ target patterns.
    A long quoted/rewritten sentence naturally mixing endings is excluded by the length cap."""
    merges = []
    for line in text.split("\n"):
        line = line.strip()
        if not line or not LABEL_LINE_RE.match(line):
            continue
        # look only at text before the first quoted example marker, and cap length
        # to the 'label' zone (heading / first table cell), not full example sentences.
        label_part = re.split(r"[>「]", line)[0]
        if len(label_part) > 40:
            continue
        hits = hits_in(label_part)
        if len(hits) >= 2:
            merges.append((line[:140], hits))
    return merges

def analyze(path):
    text = open(path, encoding="utf-8").read()
    total = extract_total(text)
    merges = label_merges(text)
    all5 = {"てください", "です", "でしょう", "そうです", "ましょう"}
    covered = hits_in(text)
    missing = all5 - covered
    return total, merges, missing

if __name__ == "__main__":
    files = sys.argv[1:] if len(sys.argv) > 1 else sorted(glob.glob("runs/*.txt"))
    for f in files:
        total, merges, missing = analyze(f)
        print(f"{f}: declared_total={total} missing_targets={missing or 'none'} label_merges={len(merges)}")
        for line, hits in merges:
            print("   MERGE:", hits, line)
```
