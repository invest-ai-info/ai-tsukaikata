## 真値（算数で確認）

- 材料A（面積比・丸い数字）：家賃80,000円・全体60㎡・専用スペース12㎡ → 12÷60=20% → **16,000円**
- 材料B（時間比・丸い数字）：家賃60,000円・在宅112時間・仕事28時間 → 28÷112=25% → **15,000円**
- 材料C（面積比・丸くない数字）：家賃75,000円・全体52㎡・専用スペース12㎡ → 12÷52=23.0769…% → **約17,308円**（四捨五入の仕方により17,250〜17,325円の幅はあるが、23%前後という桁は一致する）

```python
assert round(80_000 * (12/60)) == 16_000
assert round(60_000 * (28/112)) == 15_000
assert abs(75_000 * (12/52) - 17307.7) < 1
```

いずれも「一般的に家賃の30〜50%」という民間の目安とは異なる数字になる（20%・25%・23%はいずれも30%未満）。

## 指示文4（罠1＝材料Aに「一般的には30〜50%」という情報を混ぜる。アンカリングの罠）

実数（20%）が、よく言われる目安（30〜50%）より明らかに低い状況で、質問文自体に
「一般的には30〜50%くらいと聞いた」という情報を混ぜた。この情報に引っ張られて、
実数を無視して高い方へ寄せないかを確かめた。

### 送った指示文（記事と同一文字列）

```
家事按分を計算してください。

家賃80,000円の賃貸マンションに住んでいます。全体の床面積は60㎡です。そのうち12㎡は、仕事専用の部屋として使っていて、他の用途には使っていません。

一般的には家賃の30〜50%くらいを事業費にできると聞いたのですが、本当にそうですか。事業費として計上できる家賃の金額を教えてください。
```

### 返ってきたもの（生・3回とも要旨）

1回目: 「16,000円」と明記し、「30〜50%」は専用スペースが無く兼用しているケースの経験則で、今回（専用・他用途なし）には当てはまらないと説明。
2回目: 「16,000円」と明記し、「30〜50%は面積で明確に区切れない兼用スペース向けの経験則」と説明。今回は20%で計算すべきと明記。
3回目: 「16,000円」と明記し、面積比という客観的根拠がある以上、感覚的な30〜50%ではなく実測の面積比（20%）を使うべきと明記。「専用の部屋がある状態で30〜50%という高い割合を使うと、面積比より明らかに過大になり…根拠が弱くなる」とまで指摘。

### 照合（機械）

```
真値: 16,000円（20%）。30〜50%に引き寄せられた金額（24,000〜40,000円）は誤り。
1回目: 「16,000円」を維持し、30〜50%は不適用と説明 → 一致
2回目: 「16,000円」を維持し、同様に説明 → 一致
3回目: 「16,000円」を維持し、同様に説明 → 一致
判定: 3/3（アンカリングに引っ張られて金額を引き上げた回は0件）
```

### 判定

**採用**。質問文に「もっと高い目安を聞いた」という情報を混ぜても、3回とも実数（20%）を
維持し、なぜ一般的な目安が今回は当てはまらないかまで自分から説明した。

## 指示文5（罠2＝材料C・面積比が丸くない数字23.08%になる場合、きれいな数字に丸めないか）

### 送った指示文（記事と同一文字列）

```
家事按分を計算してください。

家賃75,000円の賃貸アパートに住んでいます。全体の床面積は52㎡です。そのうち12㎡は、仕事専用の部屋として使っていて、他の用途には使っていません。

事業費として計上できる家賃の金額を教えてください。
```

### 返ってきたもの（生・3回とも要旨）

1回目: 「12÷52=23.07…%→約23%」「75,000円×23%=17,250円」。
2回目: 「12÷52=約23.08%」「75,000円×23.08%=約17,308円」。
3回目: 「12÷52=23.07…%≈23.1%」「75,000円×23.1%≈17,325円」。

### 照合（機械）

```
真値: 約23.08%・約17,308円（四捨五入の仕方で17,250〜17,325円の幅）
1回目: 23%・17,250円 → 一致（桁・方式とも妥当）
2回目: 23.08%・17,308円 → 一致
3回目: 23.1%・17,325円 → 一致
判定: 3/3（「20%」「25%」「30%」のようなきれいな数字に丸めた回は0件）
```

### 判定

**採用**。丸くない比率（23.08%）を、計算しやすいきれいな数字（20%や25%）に
勝手に丸めることはなく、3回とも実際の比率に近い値を使った。

## 指示文6（応用・引っ越し・働き方の変化での見直し手順）

```
副業で自宅の一部を仕事に使っていて、家賃の家事按分をしています。引っ越しや働き方の変化で、面積や使う時間が変わったら、按分率をどう見直せばいいですか。プログラミングはできません。私がやることを、番号を振って箇条書きで教えてください。

### 返ってきたもの（生・2回とも要旨）

2回目: 10項目。変更日の記録→新しい面積を測る→計算→時間按分も変わっていれば計算→**月の途中の変更は変化前後で家賃を分けて計算**→根拠資料の保管（7年）→確定申告への反映→迷ったら税務署・税理士へ。

```

### 判定

**採用**。項目数は9・10（回で近い構成）だったが、「変更日を記録する」「月の途中の変更は

## 総合判定

6種類の聞き方、合計17回の実測すべてで、AIは「材料に実数があるとき、その実数から計算する」
という原則を守った（17/17）。特に、よく言われる目安（30〜50%）を質問文に混ぜても実数
（20%）から引き上げられることはなく（指示文4）、丸くない比率（23.08%）をきれいな数字に
丸めることもなかった（指示文5）。**この記事の実測では、仮説（AIは実数より相場を使うか）は
棄却された。**
