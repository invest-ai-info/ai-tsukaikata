## 実測のやり方

- 指示文は**すべて別々の新しいセッション**に渡した。各セッションには
  「架空の発注書＋架空の原稿＋指示文」だけを渡し、**仕込み（どの項目に違反しているか）は渡していない。**
- 各セッションには「答えを全文そのままファイルに書き出してください」という**運搬のための一文**を足してある。
  これは記事に載せる指示文の一部ではない。⚠️ 台帳★20 のとおり、実測用のセッションは
  「事前知識なし」ではない。**判定は機械照合できるものだけに限った**＝
  項目ごとの判定と真値の一致・引用が原稿に実在するか・申告した数字と実測値の差・原文の文の残存数。

### 原稿（架空・違反を仕込んである）

```
## オフィスチェア 選び方の基本

在宅で働く時間が長くなり、椅子を買い替える人が増えています。結論から言うと、選ぶときに見るところは座面の高さと奥行き、そして背もたれの支え方の3つです。この3つが体に合っていれば、値段の高さは決め手になりません。

まず座面の高さです。足の裏が床にしっかり付き、ひざが90度くらいになる高さが目安になります。高さを変えられない椅子だと、机との差を埋めるのが難しくなります。

次に座面の奥行きです。深く座ったときに、ひざの裏と座面の先に指が2本ほど入るくらいが目安です。奥行きが合わないと、浅く座る癖がついてしまいます。

## 背もたれで見るところ

背もたれは、腰のあたりが前に出ている形のものを選んでください。ここが支えられていると、長く座っても姿勢がくずれにくくなります。オカムラのような専門メーカーの椅子は、この部分の作りが丁寧です。

背もたれの高さも見ておきましょう。頭まで支えるタイプは、後ろに倒して休むときに楽になります。ただし場所を取るので、部屋の広さと相談してください。

腰まわりがしっかり支えられる椅子に変えると、腰痛が改善します。座り方を変えるより効果があります。

## 買う前に確かめること

お店で座れるなら、必ず座ってから決めてください。同じサイズと書いてあっても、座り心地は製品ごとに違います。

確かめておきたいのは次の3つです。

- 座面の高さを変えられるか
- ひじ掛けの高さを変えられるか
- キャスターが床の材質に合っているか

通販で買う場合は、返品の条件を先に読んでおくと安心です。組み立てが必要かどうかも確認しておきましょう。

オフィスチェア 選び方で迷ったときは、まず今使っている椅子の不満を書き出してみてください。高さが合わないのか、背中が痛いのか、それとも動かしにくいのか。不満がはっきりすると、見るところも決まります。

長く使うものなので、あせらずに選んでください。予算。それも大事ですが、体に合うかどうかが先です。
```
