2026年8月20日、弊社が配送を委託している運送会社の遅延により、ご注文商品のお届けが3日遅れる事態が発生いたしました。対象となったご注文は47件です。

遅延が判明したのは8月21日午前9時で、同日中に該当のお客様全員へメールでご連絡いたしました。

お詫びとして、対象のお客様には500円分のクーポンを発行いたしました。

【今後の対応】
再発防止に努めてまいります。お客様に安心してご利用いただけるよう、体制を見直してまいります。

今後とも変わらぬご愛顧を賜りますよう、よろしくお願い申し上げます。
```

### 判定

**採用**。今後の対応欄は2回とも原文と一字一句同一（「配送」等の語句補いも今回は無し）。数字6/6は2回とも残った。**ただし2回とも、経緯欄より前に新規のあいさつ文（「お客様各位」＋お詫びの前置き）、今後の対応欄より後に新規の結びの一文が足された**——これは事実欄でも約束欄でもない「書類の外側」の付加で、10回の基本実験のB-run5と同じ位置に出ている。指示文は「約束」を名指ししたが、あいさつ・結びは約束とはラベル付けされていない領域なので、この指示文の対象外に出た可能性がある。

## 指示文4 — 約束欄を「指示するまで触らせない」

### 送った指示文（記事と同一文字列）

```

```

上に続けて教材②を貼って、新規のAgent呼び出しで2回実行。

### 返ってきたもの（生・1回目）

```

・お客様に安心してご利用いただけるよう体制を見直す

```

### 返ってきたもの（生・2回目）

```

## 指示文5 — 約束欄だけ短くする、と向きを指定する

### 送った指示文（記事と同一文字列）

```
事実欄はそのまま残し、約束欄だけ短くまとめてください。
```

上に続けて教材②を貼って、新規のAgent呼び出しで1回実行。

### 返ってきたもの（生）

```
お客様各位

【経緯】
・2026年8月20日、弊社が配送を委託している運送会社の遅延により、ご注文商品のお届けが3日遅れました。

```

### 判定

**採用**。経緯欄（事実欄）は箇条書きのまま一字一句原文と同一。今後の対応欄は「再発防止に努めてまいります。お客様に安心してご利用いただけるよう、体制を見直してまいります。」の2文が「今後は再発防止と体制の見直しに努めてまいります。」の1文にまとまった——新しい約束の追加ではなく要約。**ただし、経緯欄より前にあいさつ＋お詫びの前置き、末尾に結びの一文が新規に足された**（指示文3・基本実験B-run5と同じ位置）。1回のみの実行（この節の主眼は「事実欄を明示的に保護すれば事実欄は動かない」の確認で、これは基本実験と指示文4でも繰り返し確認済みのため）。

## 指示文6 — まず事実欄だけを整えさせる

### 送った指示文（記事と同一文字列）

```
まず事実欄だけを読みやすく整えてください。約束欄には触れないでください。
```

上に続けて教材②を貼って、新規のAgent呼び出しで1回実行。

### 返ってきたもの（生）

```
【事実】

2026年8月20日、弊社が配送を委託している運送会社の遅延により、ご注文商品のお届けが3日遅れました。

・対象となったご注文:47件
・遅延判明:8月21日午前9時
・お客様への連絡:同日中に該当のお客様全員へメールでご連絡
・お詫び対応:対象のお客様へ500円分のクーポンを発行
```

### 判定

**採用**。約束欄（今後の対応）には一切触れず、出力にも含まれていない（指示どおり完全に無視）。事実欄の数字6/6は残った。あいさつ・結びの付加も無し——**約束欄そのものを聞かないと、外側の付加も出ない**ことが分かる（指示文3・5との対比材料）。1回のみの実行。

## この記事から出た教訓（`content/_lessons.md` へ）

1. 「読みやすく整えて」だけの単純な指示では、10回中6回は事実欄にも約束欄にも何も足されない。
   誇張は「毎回起こる」ものではなく「まれに、起こるときは決まった場所に出る」現象として測るべき
   （★109「役割を与える」定説が体裁以外を動かさなかった、と同じ形＝定説は方向としては正しいが
   頻度は思ったより低い）。
2. 語句レベルの補い（「体制」→「配送体制」）と、文まるごとの追加（「このたびの事態を重く受け止め」）は
   性質が違う。前者は既存文脈からの妥当な補完で害が少なく、後者は原文に無い姿勢の断定なので、
   記事では2つを混ぜて数えない（この記事で新設した区分）。
