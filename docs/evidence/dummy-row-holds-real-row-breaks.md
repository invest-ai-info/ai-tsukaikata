## 🔒 切り分け（なぜ材料によって割れたかは特定できていない）

- 副業（WA）・家計（MA）どちらの実データ版初期ファイルも、日付以外はほぼ同一内容の行が
  1行しかない状態から始まっており、構造上の違いは無い
- 2日目の走り書きの文型が違う（副業＝「〜メモ起こし。45分。」＝動詞を欠く体言止め、
  家計＝「〜買った。1500円。」＝動詞がある）。この文型の違いが引き金になった可能性はあるが、
  ダミー版（副業）は同じ走り書きで4/4崩れなかったため、文型だけでは説明できない
- 🔑 **言えるのは「実データ見本＋この走り書きの組み合わせでは崩れることがある」という
  事実までで、「実データ見本は危険」と一般化はできない**（★20と同じ理由）

## この記事から出た教訓（`content/_lessons.md` へ）

1. ダミーの見本行は、書式を保つ役目では実データの見本行と同じか、それ以上に安定した
   （新規）
2. 見本行だけに書式を委ねると、走り書きの言い回しによっては何の変換もされずそのまま
   貼られることがある。指示文に一文（「追記する行もそろえてください」）を足すと防げた（新規）
3. 崩れた行を「どれが違うか」と機械的に聞く点検は、書式としては正しいダミーの見本行を
   誤って名指しすることがある（新規）
