# 試した証拠 — fifth-pattern-merges-with-a-lookalike

[headline-count-slips-at-four-patterns](../../content/recipes/headline-count-slips-at-four-patterns.md) の続き。文末パターンを4つから5つに増やし、
5つ目「〜ということになります」を足したときに、見出しの数字の食い違いがさらに増えるかを実測した。

⚠️ この記事の実測には、このサイト（ai-tsukaikata）のプロジェクトを動かしている環境の文脈が一部伝わっている。
「素のAIは必ずこう返す」と一般化せず、ここに書いた回数（n回中n回）だけを根拠にする。

---

## 教材（架空データ）

**仕込み**＝文末パターン5種類（「〜でしょう」「〜と思います」「〜のです」「〜という次第です」「〜ということになります」）を
それぞれ3文連続で、間に4文ずつ無関係な業務連絡を挟んで仕込んだ。材料は2本（清掃当番メモ＝材料A、備品発注引き継ぎメモ＝材料B）、
どちらも35文。前作（4パターン・28文）と同じ構成を保ったまま1グループ分（3文の仕込み＋周辺の filler）を増やしている。

5つ目のパターン「〜ということになります」は、既存の4つ目「〜次第です」と意味が近い（どちらも「これから〜することが決まっている」という
告知の言い回し）。この近さが崩れ方に関係するかどうかも、この実測の対象にした。

### 材料A（清掃当番メモ・35文）

```

```

## 判定コード（`judge.py`）

```python
import re

PATTERNS = ["でしょう", "と思います", "のです", "次第です", "ということになります"]


def headline_count(text: str):
    m = re.search(r"([0-9〇一二三四五六七八九十]+)\s*(?:か所|箇所|つ(?:あり|あります|見つか|です))", text)
    if not m:
        return None
    digit_map = {"一": 1, "二": 2, "三": 3, "四": 4, "五": 5}
    g = m.group(1)
    return int(g) if g.isdigit() else digit_map.get(g)


def boundaries(text: str):
    """項目の境切り(丸数字・改行・「／」)が来る位置の集合。行頭形式に依存しない。"""
    marks = set()
    for m in re.finditer(r"[①②③④⑤⑥]|\n|／", text):
        marks.add(m.start())
    return sorted(marks)


def merged_pair(text: str) -> bool:
    """「次第です」と「ということになります」が、項目境界を挟まずに同じ項目内に出ているか。"""
    p1 = text.find("次第です")
    p2 = text.find("ということになります")
    if p1 == -1 or p2 == -1:
        return False
    lo, hi = min(p1, p2), max(p1, p2)
    return not any(lo < b < hi for b in boundaries(text))


def coverage_ok(text: str) -> bool:
    return all(p in text for p in PATTERNS)
```

⚠️ **この判定コード自体に、最初に書いた版ではバグがあった**（台帳12番の再発）。最初は行頭が丸数字・「N.」で
始まる行だけを「項目」とみなしていたため、①本文と同じ行に見出し文が乗っている回（4回目のような「5か所あります。でしょう…」の
書き方）②「「」で始まる行（「次第です」「ということになります」系…）の2パターンで項目を取りこぼし、統合の判定が
誤って`True`になったり項目数が合わなくなったりした。**行頭の書式に依存せず、2語の間に境界があるかだけを見る**書き方に
直して、15回すべてを目で見た結果と一致することを確認したうえで上の表を作った。
