# 試した証拠 — paraphrase-drops-match-keeps-facts（紹介文の丸写しを言い換えて消す）

架空の紹介資料**3本**（革小物工房・会計事務所・パン屋、いずれも実在しない社名・地名・数字）に、
「この資料をもとに紹介文を書いて」という同じ依頼を**3版**（そのまま／＋自分の言葉で書き直して／
＋20字以上つながらないように・固有名詞と数字はそのまま）で送った。**3本×3版×2試行＝18回**、
さらに言い直し方2種（自己チェック2回・先に列挙2回）・応用（自動化アップセル1回）の**計23回**、
すべて**独立した新しいエージェント**（Agentツール `general-purpose`。会話の文脈を一切引き継がない。
`reply-template-only-exact-matches` と同一の外枠で「このリポジトリのファイルは読まない・
ツールは使わない」と指定）に送った。

⚠️ **判定は機械でやる。**20字以上の一致は Python の `difflib.SequenceMatcher` で判定した
（自己申告や目視ではない）。事実の保持は正規表現で照合した（順序が変わっても同じ事実として
数えられるよう、後述のとおり一度作り直した）。

```

**あなたがやること**
1. 資料（PDF・Webページ・テキストなど）を私に渡す
2. 私が書いた紹介文を確認する
```

## この記事から出た教訓（`content/_lessons.md` へ）

1. **計測コードの語順依存に注意（12番の再発）。**「職人3人」のような固有名詞＋数字の文字列を
   そのまま完全一致で判定すると、AIが語順を入れ替えただけ（「3人の職人」）を「欠落」と
   誤判定する。正規表現で語順を許容する形に作り直す必要があった。
2. **自己チェックは検出率100%ではない（新しい教訓）。**「資料と照らし合わせて確認して」と
   頼んでも、2回に1回は「ずれはありません」と誤って報告した。機械照合の代わりにはならない。
