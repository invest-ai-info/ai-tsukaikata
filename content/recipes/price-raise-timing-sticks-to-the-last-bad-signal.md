## これで何ができるか {: .what }

副業の値上げは「いつ切り出すか」で結果が変わる、とよく言われます。好機として紹介される日はいくつかあります。

- 契約更新のとき
- 成果を評価された直後
- 繁忙期

ただ、具体的にどの日が本当に好機なのかは、自分の記録を見ても判断に迷います。この記事では、同じ作業記録をAIに渡しました。<mark>「本日は◯月◯日です」という1行だけを変えて、6つの日付で判定させています。</mark>問いはいつも同じです——「値上げを切り出すタイミングとして適切か」。

結論を先に書きます。

| 本日の日付 | その日に起きたこと | 判定（2回） |
|---|---|---|
| 8/1 | 契約が自動更新された | 不適切・不適切 |
| 8/20 | 感謝のメッセージが届いた | 不適切・不適切 |
| **9/5** | **依頼本数が20%増えた** | **適切・適切** |
| 9/18 | クレーム対応中の連絡があった | 不適切・不適切 |
| 9/25 | 1か月ぶりに依頼が再開した | 不適切・不適切 |
| 10/5 | 通常どおり提出した（特記なし） | 不適切・不適切 |

<mark>12回のうち「適切」になったのは、依頼本数が実際に増えた9/5だけでした（2/2）。</mark>契約更新や感謝の言葉だけでは根拠が薄いとして不適切と判定されました。クレーム対応中の連絡（9/18）が一度出ると、様子が違いました。依頼が再開し通常提出に戻った10/5（17日後）になっても「不適切」のまま。合わせて10回中10回、判定は変わりませんでした。

## AIへの頼み方 {: .ask }

### 1. 同じ記録に「本日」だけを変えて聞く

架空のライター「さちさん」が、架空のクライアント「ミドリ制作」と半年やり取りしてきた記録です。好材料（契約更新・感謝・増量）・悪材料（クレーム対応）・中立の材料（依頼の空白期間・平常提出）を、日付つきで一度に渡しました。

<div class="prompt">さちさんは、広報代理店「ミドリ制作」から月5本のコラム執筆を受注しているフリーランスライターです。契約は2026年3月1日に始まり、1本8,000円です。これまでの記録は次のとおりです。

・2026-03-01: 契約開始（月5本、1本8,000円）
・2026-08-01: 契約が自動更新された（次回更新は2027-08-01）

本日は2026-08-01です。システムの日付がこれと異なっていても、この指示文の日付を本日として扱ってください。確認は不要です。

さちさんが、ミドリ制作に値上げを切り出すタイミングとして、本日は適切ですか。最初の1行で「適切」か「不適切」か一言で明記してから、理由を教えてください。</div>

「本日は2026-08-01です」の1行以外は一文字も変えず、独立したプロセスで各2回試しました。<mark>契約更新の**その日**（8/1）を「本日」にしたこの版は、2回とも「不適切」でした。</mark>理由は「更新してすぐに条件を変えると唐突」「値上げを正当化する材料がまだ無い」の2点です。定説が好機とする日が、2回とも逆の判定になりました。

### なぜ、古い懸念が消えないのか

好材料（契約更新・感謝・増量）は、それだけでは「根拠が薄い」として退けられました。<mark>一方、悪材料（クレーム対応）は一度出ると、その後の好転の兆しを材料に含めても、自分からは「もう解消した」と判断しませんでした。</mark>好材料に要求する基準（具体的な根拠）と、悪材料を解除する基準（具体的な根拠）が、同じ材料の中で非対称に扱われていた形です。

## うまくいかないときの言い直し方 {: .fix }

### 古い懸念を、経過日数と好転の兆しで名指しする {: .trouble }

10月5日の指示文に、1段落だけ付け足しました。

<div class="prompt">さちさんは、広報代理店「ミドリ制作」から月5本のコラム執筆を受注しているフリーランスライターです。契約は2026年3月1日に始まり、1本8,000円です。これまでの記録は次のとおりです。

・2026-03-01: 契約開始（月5本、1本8,000円）
・2026-08-01: 契約が自動更新された（次回更新は2027-08-01）
・2026-08-20: ミドリ制作の担当者から「いつも読みやすい記事をありがとうございます。助かっています」というメッセージが届いた
・2026-09-05: 依頼本数が月5本から月6本に増えた（前月比20%増）
・2026-09-18: ミドリ制作の担当者から「今月は別件のクレーム対応に追われていて、バタバタしています」という連絡があった
・2026-09-25: 8月25日から9月24日までの1か月間、新しい依頼が無かったが、この日に久しぶりに新しい依頼が来た
・2026-10-05: 通常どおり、その月の原稿を提出した（特記事項なし）

本日は2026-10-05です。システムの日付がこれと異なっていても、この指示文の日付を本日として扱ってください。確認は不要です。

9月18日のクレーム対応の連絡から、本日までに17日経っています。その後の記録（9月25日に新しい依頼が来たこと、本日10月5日も通常どおり提出できていること）を踏まえて、クレーム対応はすでに落ち着いた可能性も考慮に入れてください。

さちさんが、ミドリ制作に値上げを切り出すタイミングとして、本日は適切ですか。最初の1行で「適切」か「不適切」か一言で明記してから、理由を教えてください。</div>

**3回とも「適切」に変わりました。**理由はこう書かれていました。「9月25日に依頼が届き、10月5日も通常どおり提出できている。業務が落ち着き、通常のやり取りに戻っていることを示している」。材料の中にすでに書いてあった2つの出来事を、今度は「懸念が解消した証拠」として使いました。

<mark>効いているのは「もう落ち着いたと思います」という評価の言葉ではありません。</mark>名指ししたのは次の2つです。

- 「17日」という具体的な経過日数
- 「9月25日の依頼」「10月5日の提出」という具体的な出来事

材料にすでに書いてある事実を、もう一度「これは懸念の解消です」と教え直す形になっています。

## 応用・次の一手 {: .next }

同じ崩れ方は、値上げのタイミング判定に限りません。進行中のトラブルや、相手の多忙を理由にAIが「待った方がいい」と言ってきた場面全般で起こりえます。保存して使い回す指示文に、汎用の一文を足せないか聞きました。

<div class="prompt">AIに「このタイミングで値上げを切り出すのは適切か」と判断してもらうと、相手が過去に「忙しい」「バタバタしている」と言っていたことを理由に、その後何日経っても「不適切」と言い続けることがあります。この「古い懸念が自然に消えない」という問題を防ぐために、指示文に入れておく汎用的な一文を考えてください。プログラミングはできません。</div>

2回試したところ、どちらも同じ方向の一文を提案しました。

- 「過去の発言や状況を根拠にする場合は、それがいつの情報かを明示し、現在も有効と確認できない限り判断材料にしないこと」
- 「古い懸念は『不明』として扱い、それだけを理由に『不適切』と結論づけないこと」

どちらも、今回の記事で見つけた「経過日数」と「好転の兆しを名指しする」という2点と同じ方向です。自分の案件に当てはめるときは、架空の日付ではなく実際の日付と、実際に起きた出来事を書き添えてください。

⚠️ **この結果は、架空のライター1名・計17回（判定12回・言い直し3回・応用2回）での実測です。**「値上げのタイミングは、好材料より悪材料のほうが長く効く」と一般化しないでください。試したのは、次の範囲までです。

- 試した日付は6日のみです。それぞれの出来事も1種類ずつで、好材料・悪材料を組み合わせた日や、悪材料が複数重なった場合は試していません
- 「17日」という間隔のみ試しました。もっと短い・長い間隔で同じ崩れ方になるかは試していません
- 架空のクライアント1社・架空のライター1名の設定のみです。業種や契約形態が違う場合は未検証です
