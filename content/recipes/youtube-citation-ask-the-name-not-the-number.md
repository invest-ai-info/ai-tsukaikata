## これで何ができるか {: .what }

[前作](/recipes/youtube-citation-one-of-five-correct/)は、「出典のURLも書いて」と頼むと、返ってきた5件のうち内容まで合っていたのは1件だけだったことを確かめました。この記事で確かめたのは、その作り話を止める言い方です。結論から書きます。

- **ヒントなしで聞く**——2回とも出典URLを出し、4件中2件は**存在しないページ（404）**でした
- **名前・日付には完全に効いた「自信が持てなければ確認できませんと書いて」を、そのままURL請求に使う**——作り話をやめたのは**10回中7回**。3回はまだ番号を作りました
- **言い方を強める、またはURLではなくページ名だけを求める**——番号の作り話は、合計**10回とも0件**になりました
- **ただし名前だけ求めても**——規定の現行名「量産型のコンテンツ」を答えた回は、**8回中0回**でした

<mark class="warn">同じ「分からなければ分からないと書け」という文言でも、名前・日付には完全に効いたのに、URLには7割しか効きません。</mark>対象が変わると、同じヒントの効き方も変わります。

架空のチャンネル2種（S2・S4。前作と同一）に、合計22回聞きました。ヒントの言葉や聞き方を6条件に分けて比べています。[範囲を聞く質問には効かない「確認できません」](/recipes/no-line-stops-range-either/)が示したのと同じく、**「分からなければ分からないと書け」は、何にでも同じ強さで効く魔法の一文ではありません。**[範囲では0/6・金額の計算では4/4のままだった実測](/recipes/safety-line-stops-range-not-calculation/)も同じ向きです。

## うまくいかないときの言い直し方 {: .fix }

### 3. ヒントの言葉を強める {: .trouble }

同じ「確認できません」でも、作り話の実害を具体的に書き添えると変わるかを確かめます。

<div class="prompt">次のチャンネルは、YouTubeパートナープログラムで収益化できますか。理由も教えてください。判断の根拠にしたページのURLも書いてください。ただし、URLは正確に分かる場合だけ書いてください。存在するかどうか自信が持てないURLを作ることは、読者を存在しないページや無関係なページに案内することになります。自信が持てない場合は、URLの代わりに「URLは確認できません」とだけ書いてください。

(ここにチャンネルの説明を貼る)</div>

S4に2回試すと、**2回とも「URLは確認できません」で止まりました。**指示文2のS4側は5回中2回URLを出していたので、回数は少ないものの、作り話が読者にどう害を与えるかを書き添えるだけで、止まりやすくなる手がかりになりました。

### 4. URLではなく、ページ名だけを求める {: .trouble }

聞き方そのものを変えます。番号を当てさせず、名前だけを求めます。

<div class="prompt">次のチャンネルは、YouTubeパートナープログラムで収益化できますか。理由も教えてください。また、判断の根拠にしたYouTubeヘルプのページ名(タイトル)も書いてください。ただし、URLの具体的な番号(answer/の後の数字など)は、正確に覚えていない場合は書かないでください。

(ここにチャンネルの説明を貼る)</div>

S4に2回試すと、**2回とも番号は0件でした。**「書かないでください」と言われた番号は、2回とも本当に出てきませんでした。

### 5. URLではなく、検索語を求める {: .trouble }

もう1つ、作り話の土台ごと無くす言い方があります。URLそのものを要求せず、読者が自分で確認するための検索語だけを求めます。

<div class="prompt">次のチャンネルは、YouTubeパートナープログラムで収益化できますか。理由も教えてください。また、私が自分でYouTubeヘルプを検索して確認するための検索語も1つ書いてください。URLは書かないでください。

(ここにチャンネルの説明を貼る)</div>

S4に2回試すと、**2回とも「反復性のあるコンテンツ」という検索語を返し、URLは0件でした。**「URLは書かないでください」と頼むと、URLという形そのものが出てこなくなります。

### 6. 名前と条件付きURLを組み合わせる {: .trouble }

最後に、名前を求めつつURLも許可し、番号の推測だけを明示的に禁止する言い方を試します。

## 応用・次の一手 {: .next }

出典を確かめたいとき、聞き方を目的ごとに分けます。

- **自分で開いて確認する時間があるとき**——AIに聞かず、[前提](#前提)に書いたYouTubeヘルプの現行ページを直接開いてください
- **AIに聞かざるを得ないとき**——「出典URLも書いて」ではなく、**「判断の根拠にしたページ名を書いて。URLの番号は、正確に覚えていない場合は書かないで」**、または**「確認するための検索語を1つ書いて。URLは書かないで」**と頼んでください。番号の作り話は、この聞き方に変えた合計10回とも0件でした
- **名前そのものの正確さまで要るとき**——AIに聞かず、原文を貼ってから聞いてください。前作の指示文2・4・6はいずれも、原文を見せると現行名に正しく触れました

副業でAIの判定を人に伝えるときの実務としては、**「結論は伝えてよいが、出典の名前とURLは自分で開いて確かめてから伝える」**のがいちばん安全です。前作が確かめたとおり、**判定そのものは今回も22回中22回正解**でした。崩れるのは判定ではなく、その裏付けとして挙げる名前とURLのほうです。

⚠️ **この結果は、架空のチャンネル2種・合計22回、この1つのAIでの実測です。**別のAIサービスでは違う結果になるかもしれません。YouTubeでの収益の仕組み自体は[YouTubeパートナープログラムの門と入金](/recipes/youtube-payout-thresholds/)にまとめています。

今回の生の返り22回ぶんは `docs/evidence/youtube-citation-ask-the-name-not-the-number.md` に全文置いてあります。URLの実際のHTTPステータスの確認結果も、同じファイルにあります。
