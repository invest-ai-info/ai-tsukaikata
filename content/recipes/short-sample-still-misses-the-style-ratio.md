## これで何ができるか {: .what }

[見本の文章を渡すと文体は再現できる記事](/recipes/writing-style-sample-matches-the-ratio/)は、7〜9文の見本をそのまま渡すと、AIは文末パターンの比率まで実物に近い値（犬78%・万年筆100%）で再現できると確かめました。<mark>ただし、あの記事の見本はどちらも7文以上ありました。</mark>

依頼者から渡される見本が、1〜2文しかないこともあります。<mark>この記事は、同じ見本を1〜2文に短縮し、同じ条件で再現できるかを実測しました。</mark>

- 短縮した見本をそのまま渡して書かせると、比率は**29〜30%**にしか届きませんでした
- 先に「文体の特徴を箇条書きで挙げて」から書かせる**2段階方式にしても、29〜35%**とほぼ変わりませんでした
- <mark class="warn">フル見本（7〜9文）を渡した先行記事の77〜100%から、大きく下がっています</mark>
- ただし、比率を「8文中6〜7文」のように**数字で指定**すると、短い見本のままでも**71〜75%**まで戻りました

## 前提 {: .need }

| | |
|---|---|
| かかる時間 | 15分 |
| 費用 | 無料。ブラウザのチャットAIで足ります |
| 必要なもの | 自分（または過去のクライアント案件）が書いた、公開してよい過去の原稿 |
| プログラミング | **不要**。この記事の指示文をコピーして貼るだけです |

<mark class="warn">この記事が測ったのは「文体の特徴がどれだけの比率で出力に出たか」という機械で数えられる範囲だけです。</mark>見本に使う文章は、自分自身が過去に書いた原稿だけにしてください。

[見本の文章を渡すと文体は再現できる記事](/recipes/writing-style-sample-matches-the-ratio/)が使ったフル見本（くだけた猫レビュー9文・硬いシャープペンシルレビュー7文）を、それぞれ先頭2文に短縮して使いました。新しい話題（犬の散歩バッグ・万年筆）も先行記事と同じです。副業のライティング全般は[AI原稿の直しを受ける記事](/recipes/fix-ai-drafts-for-pay/)も参考にしてください。

## AIへの頼み方 {: .ask }

### 1. 短い見本を、そのまま渡す

くだけた文体の見本を、先頭2文だけに短縮して渡しました。

<div class="prompt">次の文章は、私が過去に書いたブログのレビュー文です。

うちの猫、爪とぎがすぐボロボロになるんですよね。段ボール製のタイプを試したら、思ったより長持ちしたんです。

この文体で、新商品の「犬の散歩バッグ」のレビュー文を200字程度で書いてください。</div>

4回試した結果、**どの回も対象の文末（「〜んですよね」「〜んです」）が使われたのは最初の1〜2文だけ**で、残りはふつうの「です・ます」調に戻りました。

| 回 | 文数 | 対象の文末 |
|---|---|---|
| 1回目 | 7文 | 2文（29%） |
| 2回目 | 7文 | 2文（29%） |
| 3回目 | 6文 | 2文（33%） |
| 4回目 | 7文 | 2文（29%） |

**合計8/27文（30%）。**フル見本（9文）を渡した先行記事の77%から、大きく下がりました。

### 2. 先に特徴を箇条書きで出させる2段階方式を試す

次に、同じ短い見本から特徴を抽出させ、その特徴どおりに書かせる2段階方式を試しました。

<div class="prompt">次の文章は、私が過去に書いたブログのレビュー文です。

うちの猫、爪とぎがすぐボロボロになるんですよね。段ボール製のタイプを試したら、思ったより長持ちしたんです。

この文章の文体の特徴を箇条書きで3〜5個挙げてください。</div>

4回とも、「話し言葉に近いくだけた口調」「〜なんですよね、〜たんです」「個人的な体験から入る構成」等の特徴が返りました。続けて、同じ会話で2手目を送ります。

<div class="prompt">この特徴どおりに、新商品の「犬の散歩バッグ」のレビュー文を200字程度で書いてください。</div>

| 回 | 文数 | 対象の文末 |
|---|---|---|
| 1回目 | 9文 | 2文（22%） |
| 2回目 | 7文 | 2文（29%） |
| 3回目 | 6文 | 2文（33%） |
| 4回目 | 6文 | 2文（33%） |

**合計8/28文（29%）。**単純に書かせた場合（30%）と、ほとんど差がありません。

### 3. 硬い文体（万年筆）でも、同じ傾向になるか

硬い「である」調の見本でも、同じ2条件を試しました。見本はこちらです。

<div class="prompt">次の文章は、私が過去に書いたブログのレビュー文です。

このシャープペンシルを選んだ理由は、グリップ部分の素材にある。ラバーではなく金属製のローレット加工が施されており、手が汗ばむ季節でも滑りにくいのである。

この文体で、新商品の「万年筆」のレビュー文を200字程度で書いてください。</div>

単純に書かせた4回は、合計6/21文（29%）。2段階方式の指示文はこちらです。

<div class="prompt">次の文章は、私が過去に書いたブログのレビュー文です。

このシャープペンシルを選んだ理由は、グリップ部分の素材にある。ラバーではなく金属製のローレット加工が施されており、手が汗ばむ季節でも滑りにくいのである。

この文章の文体の特徴を箇条書きで3〜5個挙げてください。</div>

続けて「この特徴どおりに、新商品の『万年筆』のレビュー文を200字程度で書いてください。」と2手目を送ると、4回の合計は9/26文（35%）。<mark>単純版（29%）より少し高いものの、フル見本を渡した先行記事の100%には遠く及びません。</mark>

### なぜ、2段階にしても戻らなかったのか

2段階方式の1手目（特徴の抽出）を見ると、「話し言葉に近いくだけた口調」「〜なんですよね、〜たんです」のように、**使うかどうか**は正しく言語化されていました。<mark>ところが、どの回も「8文中6〜7文程度」のような頻度の情報は出てきませんでした。</mark>見本がもともと2文しかないので、頻度を数える材料自体が無いのです。2段階方式は「見本から特徴を言葉にして、その言葉どおりに書く」という構造なので、**言葉にできなかった頻度は、2段階目にも引き継がれません。**

## うまくいかないときの言い直し方 {: .fix }

### 比率を数字で指定すると、短い見本でも戻るか {: .trouble }

[先行記事](/recipes/writing-style-sample-matches-the-ratio/)で効いた「8文中6〜7文」という数字指定を、短い見本と組み合わせて試しました。

<div class="prompt">次の文章は、私が過去に書いたブログのレビュー文です。

うちの猫、爪とぎがすぐボロボロになるんですよね。段ボール製のタイプを試したら、思ったより長持ちしたんです。

この文体で、新商品の「犬の散歩バッグ」のレビュー文を200字程度で書いてください。ただし、文末が「〜んですよね」「〜んです」になるのは8文中6〜7文程度にとどめ、残りは別の言い方にしてください。</div>

2回試したところ、2回とも実際の本文は8文で、6文が対象の文末（75%）。**合計12/16文（75%）**です。フル見本を渡した先行記事の数字指定版（74%）とほぼ同じ比率まで戻りました。

硬い文体（万年筆）でも同じ言い方を試しました。

<div class="prompt">次の文章は、私が過去に書いたブログのレビュー文です。

このシャープペンシルを選んだ理由は、グリップ部分の素材にある。ラバーではなく金属製のローレット加工が施されており、手が汗ばむ季節でも滑りにくいのである。

この文体で、新商品の「万年筆」のレビュー文を200字程度で書いてください。ただし、文末が「〜である」「〜のである」になるのは7文中5〜6文程度にとどめ、残りは別の言い方にしてください。</div>

2回とも本文は7文で、5文が対象の文末（71%）。**合計10/14文（71%）**です。2条件を合わせると、**22/30文（73%）**まで戻りました。

<figure class="figure">
<img src="/static/images/short-sample-connector-missing.svg" alt="短い見本に含まれていなかった接続詞は、どちらの頼み方でも0回のままだったことを示す横棒グラフ。犬「ちなみに」はフル見本の実物（先行記事）が2回、短い見本・単純は0回、短い見本・2段階も0回。万年筆「そもそも」もフル見本の実物が2回、短い見本・単純は0回、短い見本・2段階も0回。縦の点線はフル見本の実物の回数（2回）を示す。下の枠には、短い見本（1〜2文）には「ちなみに」「そもそも」が含まれていなかったこと、結果、単純版・2段階版とも4回中4回この接続詞を1回も使わなかったことが書かれている。">
<figcaption>見本に無い特徴は、方式を変えても出てきません。</figcaption>
</figure>

→ **比率は数字で指定すれば戻りますが、見本に無い特徴そのものは戻りません。**先行記事のフル見本には「ちなみに」「そもそも」という接続詞が2回ずつ入っていましたが、1〜2文に短縮した見本にはどちらも入っていません。<mark>結果、単純版・2段階版とも4回中4回、「ちなみに」「そもそも」を1回も使いませんでした。</mark>数字で指定できるのは、見本の中にすでにある特徴の「頻度」だけです。見本に無い特徴は、指定する数字そのものを立てられません。

## 応用・次の一手 {: .next }

| 条件 | 犬（対象の文末） | 万年筆（対象の文末） |
|---|---|---|
| フル見本（7〜9文・先行記事） | 77%（27/35） | 100%（28/28） |
| 短い見本（1〜2文）・単純 | 30%（8/27） | 29%（6/21） |
| 短い見本（1〜2文）・2段階 | 29%（8/28） | 35%（9/26） |
| 短い見本（1〜2文）＋比率を数字で指定 | 75%（12/16） | 71%（10/14） |

見本が短いときは、2段階方式より**比率の数字指定**のほうが効きます。短い見本しか手に入らない場合は、次の順番がおすすめです。

1. 短い見本から、使われている文末・接続詞の**種類**だけを確認する（頻度は見本からは分からないと割り切る）
2. 頻度は「8文中6〜7文」のように、**自分で決めた数字**を指示文に足す
3. 本当にその頻度が自然かどうかは、依頼者に過去の長めの原稿を1本もらえないか聞くのが一番確実です

副業のライティングで文体を扱う他の記事として、[誤字と冗長さだけ直させて言い回しには触らせない記事](/recipes/fix-typos-not-voice/)も参考にしてください。

⚠️ **この結果は、架空のブログレビュー2種・計26回の実測です。**「短い見本では必ず再現できない」と一般化しないでください。試したのは、次の範囲までです。

- 見本は2文に短縮した版のみ。1文だけに短縮した場合は試していません
- 新しい話題は先行記事と同じ2つ（犬の散歩バッグ・万年筆）だけです
- 比率の数字指定は、短い見本と組み合わせた場合のみ。見本なし・言葉だけの説明との組み合わせは試していません
