## これで何ができるか {: .what }

AIが便利だという話は聞くのに、いざ開くと<mark>何を頼めばいいか思いつかない</mark>——ここで止まっている人はとても多いです。使い方の問題ではありません。**自分の仕事のどこが渡せるのかを、まだ棚卸ししていない**だけです。

この記事は、特定の作業のやり方ではなく、<mark>「あなたの仕事の中から、渡せるものを見つける」ための頼み方</mark>を載せます。15分で、時短の大きい順に並んだ候補リストが手に入ります。

渡せる作業は、業種が違ってもだいたい4つの型に入ります。

## 前提 {: .need }

| | |
|---|---|
| かかる時間 | 15分 |
| 費用 | 無料。無料のチャットAIで足ります |
| 必要なもの | ブラウザで使えるAI（ChatGPT・Claude・Geminiなど）だけ |
| プログラミング | **不要**。この記事の指示文をコピーして貼るだけです |

道具を増やす必要はありません。<mark>この記事でやるのは、AIに作業させることではなく、AIと一緒に自分の仕事を棚卸しすること</mark>です。

## AIへの頼み方 {: .ask }

### 1. 自分の1週間を、そのまま渡す

きれいにまとめようとしなくて大丈夫です。思いつく順に並べるだけで足ります。

<div class="prompt">私の仕事の中で、AIに任せられそうな作業を一緒に探してください。

まず私の1週間をそのまま書きます。整理はしていません。

（月曜の朝に週次報告を作る、問い合わせメールに返信、Excelの集計を部長に送る……のように、思いつくまま10行くらい書く）

この中から、AIに任せられそうなものを選んで、理由も添えてください。</div>

**整理してから渡さないでください。**整理する過程で「これはAIには無理だろう」と自分で候補を消してしまいます。<mark>無理かどうかの判断は、渡してからで間に合います</mark>。

### 2. 時短の大きい順に並べさせる

候補が出たら、次はどれから手を付けるかです。これも聞けます。

<div class="prompt">いま挙げてもらった候補を、次の3つで採点して、順番に並べてください。

1. 1回あたり何分の作業か
2. 月に何回やるか
3. 失敗したときの困り具合（小さいほど始めやすい）

そのうえで「最初に手を付けるならこれ」を1つだけ選んで、理由を書いてください。</div>

<mark>最初の1つは、時短が最大のものではなく「失敗しても困らないもの」から始めてください</mark>。慣れる前に重要な作業を任せると、一度の失敗でAI自体を使わなくなります。

### 3. 頼み方まで書かせる

候補が決まったら、そのまま指示文を作らせられます。

<div class="prompt">その作業をAIに頼むための指示文を書いてください。私がコピーしてそのまま使える形でお願いします。

指示文には次を含めてください。

・何を渡すか（私が用意するもの）
・何を返してほしいか（形式も）
・やってほしくないこと</div>

3つ目の「やってほしくないこと」が効きます。これが無いと<mark class="warn">頼んでいない範囲まで気を利かせて触られます</mark>。範囲の区切り方は[「ついでに整理しておきました」と言わせない頼み方](/recipes/limit-what-ai-touches/)に詳しく書きました。

### 4. 同じことを何度もやるなら、まとめて頼む

ここが一番の時短ポイントです。同じ指示を10回コピペしているなら、<mark>1回で10件ぶん頼めます</mark>。

<div class="prompt">同じ作業を複数の対象にまとめてやってほしいです。

対象を下に並べます。それぞれに同じ処理をして、結果を表にまとめて返してください。処理できなかったものは、飛ばさずに理由を書いてください。

（対象を1行ずつ並べる）</div>

最後の一文が肝心です。これが無いと、<mark class="warn">処理できなかったものが黙って結果から消えます</mark>。10件頼んで8件返ってきたのに、それに気づかない、が起こります。

### 5. 毎週やっているなら、決まった時刻に動かす

繰り返しの型に当てはまった作業は、自分が思い出すこと自体をやめられます。

<div class="prompt">この作業を、毎週決まった時刻に自動で実行できるようにしたいです。

私はプログラムを書けません。何が必要になるか、私がやる作業を番号を振って書いてください。作れるものはあなたが作ってください。</div>

ここから先は[「毎日決まった時刻に自動でやっておいて」をAIに作らせる](/recipes/github-actions-daily-cron/)がそのまま続きになります。

## うまくいかないときの言い直し方 {: .fix }

### 候補が出てこない・ありきたりなものしか出ない {: .trouble }

抽象的に聞くと抽象的に返ってきます。具体を足してください。

<div class="prompt">一般論ではなく、私の状況に合わせて考えてください。

私の職種は◯◯で、よく使うソフトは△△です。1日のうち一番時間を取られているのは□□です。この前提で、もう一度候補を出してください。</div>

### 「それはAIには難しいです」と言われた {: .trouble }

まるごと渡せなくても、<mark>途中まで渡せることがほとんど</mark>です。

<div class="prompt">まるごとは無理でも、途中まで手伝える部分はありませんか。

その作業を工程に分解して、AIができる工程と、人がやるべき工程に分けてください。</div>

作業の分担を出させる言い方は[「あとはご自分で」と言われないための頼み方](/recipes/who-does-what/)にまとめてあります。

### 提案どおりにやったのに、思ったほど時短にならない {: .trouble }

<div class="prompt">実際にやってみたら、思ったほど楽になりませんでした。

どこで時間がかかったかを書きます。（例：渡すデータを整えるのに時間がかかった／返ってきたものの確認に時間がかかった）

この部分も含めて短くする方法はありますか。</div>

<mark>時短が出ない原因は、たいてい作業そのものではなく前後の準備と確認です</mark>。そこを言えば、そこを削る案が返ってきます。

### 提案が本当か確かめたい {: .trouble }

<div class="prompt">いまの提案は、実際に動かして確かめたものですか。それとも一般論ですか。

確かめていないなら、そう書いてください。私が自分で試せるように、最小の手順を教えてください。</div>

<mark class="warn">AIは、動かしていないことも自信を持って書きます</mark>。確認の頼み方は[「たぶん動きます」と言わせないための頼み方](/recipes/verify-before-report/)にまとめました。

## 応用・次の一手 {: .next }

棚卸しは1回で終わりにしないでください。**仕事は変わるので、渡せるものも変わります**。

<div class="prompt">3か月前に洗い出した候補リストを見直したいです。

いまの私の状況を書きます。（変わったことを数行）この前提で、リストに足すもの・外すものを教えてください。</div>

もう1つ、慣れてきたら効く問いがあります。

<div class="prompt">私が「これは自分でやるしかない」と思い込んでいそうな作業を、逆に指摘してください。

私の1週間をもう一度見て、渡せるのに渡していないものを探してください。</div>

<mark>渡せるものを見つける力は、指示文を書く力より先に効きます</mark>。良い指示文でも、渡す作業を間違えていれば時短にはなりません。

まず1つ選んで、今週やってみてください。うまくいかない感じがしたら、[「なんか違う」と思ったときの対処](/recipes/something-feels-off/)が次の一手です。
