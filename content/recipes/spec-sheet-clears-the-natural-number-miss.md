## これで何ができるか {: .what }

[先行記事](/recipes/natural-number-swap-hides-from-naive-check/)は、動画の自動字幕を「聞き取りミスがないか確認して」と素朴に頼むだけでは、文脈上は自然に見える数字の誤りを<mark class="warn">80回中23回（28.75%）しか拾えない</mark>と確かめました。

<mark>この記事は、同じキャプション・同じ仕込み誤りに、メーカー公式の仕様書を添えて「1件ずつ照合して」と頼み直しました。</mark>結果は次のとおりです。

- ブレンダー・掃除機とも、仕込んだ8件の誤りを**5回とも全件**拾いました（40/40・40/40）
- 合計**80件中80件（100%）**。先行記事の28.75%から大きく上がりました
- 仕様書に載っていない項目（価格・重さなど）は、間違っているとも正しいとも判定せず、**「照合不可」として保留**しました

<figure class="figure">
<img src="/static/images/spec-sheet-detection-vs-naive.svg" alt="動画の自動字幕キャプションの検品で、素朴な指示文と公式仕様書を添えた指示文を比べる横棒グラフ。先行記事の素朴な指示文（同じ80件の仕込み誤り）は23/80で28.75%。この記事の仕様書照合（ブレンダー40件・掃除機40件、合計80件）は80/80で100%。下の枠には、違いは指示文に公式仕様書を添えたことだけであること、結果が28.75%から100%に上がったことが書かれている。">
<figcaption>添えたのは公式仕様書1枚だけ。指示文の構造は先行記事と同じです。</figcaption>
</figure>

良いことばかりではありません。仕様書から項目を2つ外すテストもしました。その2項目は、**間違っているのに「問題なし」と誤って太鼓判を押されることはなく**、代わりに「仕様書に記載がない」として保留されました。<mark>仕様書に載っていない項目は、見つからないままです。</mark>

## 前提 {: .need }

| | |
|---|---|
| かかる時間 | 15分 |
| 費用 | 無料。ブラウザのチャットAIで足ります |
| 必要なもの | 動画編集ソフトから書き出した自動生成キャプションと、メーカー公式の仕様書（製品ページ・取扱説明書など） |
| プログラミング | **不要**。この記事の指示文をコピーして貼るだけです |

架空のブレンダー「ミックスマイスター」、架空の掃除機「クリーンエース」という設定を使っています。実在の企業・商品とは関係ありません。キャプションと仕込み誤りは[先行記事](/recipes/natural-number-swap-hides-from-naive-check/)とまったく同じものを使い、公式仕様書だけを新しく添えました。

副業の検品全般は[発注書どおりに検品する記事](/recipes/writing-check-against-spec/)、動画編集のほかの工程は[台本と構成案の記事](/recipes/video-script-by-the-clock/)も参考にしてください。

## AIへの頼み方 {: .ask }

### 1. ブレンダーのキャプションを、公式仕様書と1件ずつ照合する

キャプションのあとに、公式仕様書をそのまま続けて貼ります。

<div class="prompt">このキャプションに出てくる数字が、添付した仕様書の値と一致するか、1件ずつ確認してください。食い違いがあれば指摘してください。</div>

上に先行記事と同じキャプション14行、続けて次の仕様書を貼りました。

```
製品名: ミックスマイスター パワーブレンドV3
- 容量: 1.5リットル（家族3人分の目安）
- 刃の枚数: 6枚刃
- モーター冷却の推奨時間: 使用後1分
- バッテリー連続使用時間: 満充電で約20分
- 洗浄にかかる時間の目安: 約60秒
- 保証期間: 購入から1年間
- レシピブック収録数: 30種類
- 付属パーツ数: 全部で5点
```

5回試した結果です。

| 仕込んだ誤り | 拾われた回数 |
|---|---|
| 8枚刃（正しくは6枚刃） | 5/5 |
| 家族4人分（正しくは3人分） | 5/5 |
| モーター冷却「約3分」（正しくは1分） | 5/5 |
| バッテリー「約40分」（正しくは20分） | 5/5 |
| 洗浄「30秒ほど」（正しくは60秒） | 5/5 |
| 保証期間「2年間」（正しくは1年間） | 5/5 |
| レシピ「50種類」（正しくは30種類） | 5/5 |
| パーツ「全部で7点」（正しくは5点） | 5/5 |

**8件とも5回とも拾われました。合計40/40（100%）。**先行記事の素朴な指示文では、この8件のうち4件（家族4人分・洗浄30秒・レシピ50種類・パーツ7点）が5回とも一度も拾われていませんでした。

### 2. 掃除機のキャプションでも、同じ指示文で試す

新しく作った掃除機のキャプションでも、仕様書を添えて同じ指示文を5回試しました。

<div class="prompt">このキャプションに出てくる数字が、添付した仕様書の値と一致するか、1件ずつ確認してください。食い違いがあれば指摘してください。</div>

| 仕込んだ誤り | 拾われた回数 |
|---|---|
| 掃除回数「2回」（正しくは3回） | 5/5 |
| バッテリー「約35分」（正しくは25分） | 5/5 |
| 充電時間「約4時間」（正しくは3時間） | 5/5 |
| 吸引力「6段階」（正しくは4段階） | 5/5 |
| ヘッド幅「2人分」（正しくは1人分） | 5/5 |
| フィルター掃除「月に1回」（正しくは週に1回） | 5/5 |
| 保証期間「3年間」（正しくは2年間） | 5/5 |
| ノズル「4種類」（正しくは3種類） | 5/5 |

**こちらも8件とも5回とも拾われました。合計40/40（100%）。**2つの材料を合わせると、80回中80回（100%）です。

### なぜ、先行記事と結果が逆になったのか

先行記事の誤り（「家族4人分」「レシピ50種類」など）は、<mark>値だけ見れば普通にありえる数字でした。</mark>AIが気づくには、文章としての自然さではなく、製品としての正しい仕様値を**知っている**必要がありました。ところが、知らない数字は記憶から呼び出せません。

<mark>仕様書を添えると、「知っている必要がある」状態が「見比べるだけでよい」状態に変わります。</mark>5回とも返りには、キャプションの値と仕様書の値を並べた表が自分から出てきました。推測ではなく、照合という作業に変わったからです。

## うまくいかないときの言い直し方 {: .fix }

### 仕様書に項目が漏れていたら、どうなるか {: .trouble }

公式仕様書がいつも全項目を載せているとは限りません。掃除機の仕様書から、仕込み誤りのある2項目（吸引力・保証期間）をわざと外して、同じ指示文を3回試しました。

<div class="prompt">このキャプションに出てくる数字が、添付した仕様書の値と一致するか、1件ずつ確認してください。食い違いがあれば指摘してください。</div>

結果です。

| 項目 | 仕様書に載っているか | 拾われた回数 |
|---|---|---|
| 掃除回数・バッテリー・充電時間・ヘッド幅・フィルター・ノズル（6件） | 載っている | 18/18（3回×6件） |
| 吸引力「6段階」（正しくは4段階） | **外した** | 0/3 |
| 保証期間「3年間」（正しくは2年間） | **外した** | 0/3 |

<mark class="warn">外した2項目は、3回とも「仕様書に記載がないため照合できません」と明記されました。</mark>間違っているのに「問題ありません」と誤って太鼓判を押された回は0件です。<mark>その代わり、見つけることもできませんでした。</mark>仕様書に載っている6件は、3回とも全件そのまま拾われています（18/18）。

<figure class="figure">
<img src="/static/images/spec-sheet-partial-coverage.svg" alt="掃除機の仕様書から、仕込み誤りのある吸引力と保証期間の2項目をわざと外して、同じ指示文を3回試した結果を示す図。仕様書に残した6項目（掃除回数・バッテリー・充電時間・ヘッド幅・フィルター・ノズル）は3回×6件=18件中18件が正しく不一致として拾われた。仕様書から外した吸引力と保証期間の2項目は、3回とも「照合不可」として保留され、間違っているのに一致と誤判定された回も、正しく不一致と判定された回も0件だった。下の枠には、仕様書に載っている項目は見逃しゼロだが、外した項目は保留されるだけで見つからないことが書かれている。">
<figcaption>外した2項目は「分からない」で止まり、間違ったまま通ることはありませんでした。</figcaption>
</figure>

→ **この頼み方の見逃しゼロは、仕様書が全項目を載せていることが前提です。**仕様書を用意するときは、キャプションに出てくる数字の種類（容量・時間・個数・人数など）が、全部仕様書にも載っているかを先に確かめてください。漏れがあれば、その項目だけ元の素朴な検品（28.75%の精度）に戻ります。

## 応用・次の一手 {: .next }

納品用の記録に残すなら、表の形式を決めて頼むと毎回同じ見た目になります。

<div class="prompt">照合結果を、1項目1行の表で、項目名・キャプションの値・仕様書の値・判定（一致／不一致／照合不可）の4列にまとめてください。</div>

2回試したところ、2回とも同じ4列の表が返り、仕込んだ8件は2回とも全件「不一致」、仕様書に無い3項目（価格・重さ・収納スタンド）は2回とも「照合不可」に正しく分かれました。感想（「女性でも片手で持てる軽さ」など）は、2回とも自分から表の対象外として注記しています。

食い違いが見つかったら、そのまま直させられます。

<div class="prompt">見つかった食い違いをもとに、キャプションの数字を仕様書の値に直した完成版を書いてください。</div>

2回試したところ、2回とも8件すべてを仕様書の値に直し、**仕様書に無かった3項目（価格・充電時間・ブラシの付属）はそのまま残しました。**さらに2回とも、「これは字幕の文字だけの修正で、動画の音声は元の数字のままです」という注意を自分から添えました。字幕だけ直して公開すると、音声と字幕が食い違う動画になってしまうということです。

仕様書が手に入らない動画もあります。そのときの工夫も聞きました。

<div class="prompt">動画編集の副業で、レビュー動画の自動字幕を検品しています。メーカー公式の仕様書があるときは、キャプションの数字を仕様書と1件ずつ照合すれば、文脈上は自然に見える数字の誤りもほぼ確実に見つけられると分かりました。ただし、公式の仕様書が手に入らない動画もあります。仕様書が無いとき、検品の精度を上げるにはどんな工夫ができますか。番号を振って教えてください。</div>

返ってきた11項目のうち、すぐ使えそうなのは次の3点でした。

1. **販売ページ・取扱説明書PDF・FAQなど、仕様書以外の一次情報を探す**。仕様書という形でなくても、同じ数字が載っていることがあります
2. **動画内の映像（箱の刻印・画面に出る設定値）を一次証拠にする**。音声認識の誤りとは独立した根拠になります
3. **確度を「確認済み・概ね確認・未確認」の3段階で記録し、未確認の数字は依頼主にそう伝える**。見つけられなかったことを隠さないほうが、品質と信頼の両方を守れます

同じ検品の副業について、字幕以外の内容確認は[AI原稿の直しを受ける記事](/recipes/fix-ai-drafts-for-pay/)も参考にしてください。

⚠️ **この結果は、架空の動画2本・仕込み誤り16件・計104回（仕様書あり80回＋部分仕様書24回）の実測です。**「仕様書があれば必ず100%拾える」と一般化しないでください。試したのは、次の範囲までです。

- 仕様書に載っている項目は8件まで。数十項目に及ぶ長い仕様書は試していません
- 仕様書の値は、この記事では常に正しいという前提です。仕様書そのものが古い・誤っている場合は試していません
- 材料は2本・各14行まで。10分を超える長尺動画は試していません

今回の生の返りと判定の詳細は `docs/evidence/spec-sheet-clears-the-natural-number-miss.md` に全文置いてあります。
