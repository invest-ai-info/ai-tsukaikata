## これで何ができるか {: .what }

まだ返信の来ていない相手に、いつ催促するか。<mark>基準の日数を渡さずに判定させると、AIは自分で決めた日数を最後まで一貫して使いました。</mark>ただし、その日数がこちらの望む基準と同じとは限りません。プログラミングは要りません。

<mark class="warn">この記事の材料では、5日ルールで「催促する」に入る18件中3件が、AIが自分で決めた基準（7日）では「まだ早い」として取りこぼされました。</mark>取りこぼしはいつも同じ向きで、早すぎる催促は1件も出ませんでした。

| 頼み方 | 5日ルールとの一致率 |
|---|---|
| 基準を渡さず、AIに決めさせる | 材料1（18件）: 15／18件（83%・4回とも同じ判定）<br>材料2（12件）: 10〜11／12件（83〜92%・2回で1件ぶれた） |
| 「最後にやりとりした日から5日以上」と基準を渡す | 材料1・材料2とも、暦日・営業日を含めて6回すべて満点 |

**この記事は、AIに実際に判定させた実測の記録です。**架空の送付記録を使っており、特定の会社・相手の実例ではありません。

## 前提 {: .need }

- 毎朝または毎週、「まだ返信の来ていない相手」の一覧をAIに渡し、催促すべきかを判定させている（受信箱の見張り・営業リストの棚卸しなど）
- 「何日空いたら催促するか」を指示文に書かず、AIの判断に任せている
- [返事が来ているかどうかを判定させる記事](/recipes/who-has-not-replied-yet/)は、著者自身が「何日空いたら催促するかは一度も測っていません」と明記していた。この記事はその続きです

この記事は、催促する基準そのものを作る話ではありません。**基準の日数を書かなかったとき、AIが実際にどう判定するのか**、その1点だけを試しています。

## うまくいかないときの言い直し方 {: .fix }

### 基準を渡さないと、AIは自分の基準を勝手に決めて押し通す {: .trouble }

「基準は自分で決めてください」と丸投げすると、AIは範囲や日によって答えを変えるのではなく、<mark>最初に決めた1つの日数を、最後まで押し通しました。</mark>今回は6回中5回が「7日」を選びました。**ここが誤解しやすい点です。**「一貫している」ことと「あなたの会社の基準と一致する」ことは別の話です。5日ルールで運用しているつもりなら、AIの自己基準（7日）はそれより甘く、境界の数件を取りこぼします。

### 材料が変わると、その「安定」はそこまで固くない {: .trouble }

同じ材料（18件）だけを見ていたら、「AIの自己基準は完全に安定している」と書いてしまうところでした。<mark class="warn">件数も構成も違う別材料（12件）に差し替えると、2回のうち1回だけ、境界の1件の判定が変わりました。</mark>**1本の材料だけで「毎回同じ形で出る」と言い切らないでください。**

### 「営業日で」と言えば正しく数えるが、判定が変わる場面はまだ未確認 {: .trouble }

「営業日で」と指定すると、土日を除く日数計算は2回とも間違えませんでした（28個の個別の日数すべてが正解と一致）。ただし今回の材料では、暦日で数えても営業日で数えても、最終的な判定は1件も変わりませんでした。**「営業日にすると判定そのものが変わる場面」は、この記事ではまだ確認できていません。**必要なら、5日の境界を土日がまたぐ材料を別に作って試してください。

### 正しい判定を並べたのに、まとめの件数だけ言い間違える {: .trouble }

判定の表そのものは正しいのに、<mark class="warn">最後のまとめの一文だけ件数を言い間違えることが2回ありました</mark>（「8件」と書いた直後に9個列挙・「5件」と書いた直後に6個列挙）。個別の判定行は両方とも正しかったので、**件数を数えるならAIのまとめの一文ではなく、表の行を自分で数えてください。**自動化するなら、行数を数えるのはPythonなどのコードに任せるほうが確実です。

## 応用・次の一手 {: .next }

**基準の日数は、必ず指示文に数字で書いてください。**「何日空いたら催促するか」を書かないと、AIは自分で決めた数字（この記事では多くの場合7日）を使います。5日で運用しているなら「5日以上」と明記するだけで、一致率は83%前後から100%に上がりました。

これは[更新が止まった相手への異常閾値を決めさせる記事](/recipes/flat-threshold-misfires/)とは軸が違います。あちらは自動監視が「何日空いたら壊れたとみなすか」を扱い、こちらは人へのメールを「何日空いたら催促するか」を扱います。**どちらも「基準の日数を書くかどうか」で結果が動く点は共通していました。**

毎朝や毎週の自動実行にするなら、[毎日決まった時刻にAIを動かす仕掛けを作らせる記事](/recipes/github-actions-daily-cron/)を参考に、送信日・前回の催促日の一覧を毎回渡す形にしてください。渡す指示文には、必ず日数を数字で書くことと、催促の対象になった件数を自分で数えることの2つを忘れないでください。
