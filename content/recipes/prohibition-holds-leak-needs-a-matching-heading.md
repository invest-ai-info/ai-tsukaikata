## これで何ができるか {: .what }

[禁止の一文だけで3週間守れる](/recipes/bare-prohibition-holds-but-erases-the-row/)は、週報ループの3週連鎖（週2→週4）を確かめた記事です。禁止の一文はこれだけでした。「自分の体調・残業にあたる行は、どの見出しにも入れないでください」。この一文だけで、3週とも本文への漏れは止まりました。

ただし著者自身が、こう書き残していました。

- 3週より長い連鎖は試していない
- 禁止対象が3つ以上に増えた場合は試していない
- 禁止の一文を削った影響が、週を追うごとに悪化するかどうかは試していない

測りました。やったことは2つです。

- 同じ禁止の一文を、**週2→週5の4週連鎖**に伸ばした
- 仕込む話題を、体調・残業に加えて**待遇（ボーナスの査定）**まで3つに増やした

同じ4週連鎖を、禁止あり・禁止なしの2条件でそれぞれ**2回ずつ**試しました。

1. **禁止の一文は、4週・3つの話題に増えても、本文への漏れを6回中0回に抑えました。**週3の体調不良も、週4の残業も、週5の待遇の話も、2回ずつ試して一度も本文に現れませんでした
2. <mark>禁止を外すと、結果は話題によって割れました。</mark>体調（頭痛で半休）は禁止が無くても2回とも漏れませんでした。ところが残業と待遇は、禁止が無いと2回とも「4. 相談したいこと」にそのまま書かれました
3. <mark class="warn">禁止ありの週5だけ、禁句（ボーナスの話）と一緒に、無関係な「評価面談の日程」まで1行、2回とも本文から消えていました。</mark>禁止していない話題まで巻き込んで消えることがあります

📌 **前作が残した3つめの問いへの答えです。**3つめは、禁止を外した影響が週を追うごとに悪化するかという問いでした。この記事の実測の範囲では「悪化」ではなく「話題による」という形で答えが出ました。体調は週3でも漏れず、残業と待遇は週4・週5のどちらで試しても即座に漏れました。**週を追うごとに緩むのではなく、その話題が「相談したいこと」に当てはまるかどうかで、最初から決まっていました。**

## うまくいかないときの言い直し方 {: .fix }

### 「禁止すれば安心」と思っていたら、関係ない予定まで消えていた {: .trouble }

対象の話題と近い言葉（評価・査定・面談など）を含む行は、禁止と一緒に消える可能性があります。<mark class="warn">公開前に、禁止した話題の周辺の行だけ、週報と元のメモを見比べてください。</mark>この記事の指示文4（下の「応用・次の一手」内の診断プロンプト）がそのまま使えます。

### 体調や私用の話は、禁止しなくても大丈夫だと思ってよいか {: .trouble }

この実測の範囲（体調＝頭痛・半休）では、禁止が無くても漏れませんでした。ただし<mark>これは「体調の話は常に安全」という意味ではありません。</mark>今回たまたま、4つの見出しのどれにも当てはまらなかったから消えただけです。見出しの構成を変えれば（たとえば「5. その他」を足せば）、同じ体調の話が書く場所を持つことになり、結果は変わるはずです。**安全かどうかは話題の種類ではなく、見出しとの相性で決まります。**

### 「人への不満」はまだ試していない {: .trouble }

前作の禁止の一文には「人への不満」も名指しされていますが、この記事でも体調・残業・待遇の3つまでしか試していません。人への不満は「3. 来週やること」「4. 相談したいこと」のどちらにも当てはまりそうな話題です。そのため、残業・待遇と同じ側（禁止が無いと漏れる側）になると見ていますが、確かめてはいません。

## 応用・次の一手 {: .next }

**この記事の結論は3つです。**①禁止の一文は、4週・3つの話題に増えても崩れませんでした。②禁止を外した影響は週を追うごとに悪化するのではなく、話題が既存の見出しに当てはまるかどうかで最初から決まっていました。③禁止ありでも、話題圏が近い無関係な行まで巻き込んで消えることがありました。

📌 **禁止の一文を書くときは、対象の話題だけでなく「その話題と同じ引き出しに入っている言葉」まで考えてください。**待遇を禁止するなら、評価・査定・面談といった隣接語が一緒に消えても困らないかを確認してください。困るなら、[禁止は受け皿と対で渡す](/recipes/bare-prohibition-holds-but-erases-the-row/)の「5. 私が決める行」のような受け皿を必ず添えてください。

🔒 **ここで扱った軸は「話題が見出しに当てはまるかどうか」です。**[除外の書き方で来年また鳴るか決まる](/recipes/exclusion-wording-decides-the-repeat/)が扱った「除外ルールの一般化」とは別の軸です。あちらは条ごとに積み重ねた除外ルールが他の条へ巻き添えになるかを調べ、巻き添えは0件でした。こちらは単発の禁止の一文が、意図しない隣接語まで消すかどうかを調べています。
