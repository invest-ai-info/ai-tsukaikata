## これで何ができるか {: .what }

<mark>KDP原文を会話の最初の1ターン目だけで貼って引用させても、引用の正確さは変わりませんでした。</mark>独立した新規の会話にそれぞれ試した結果です。

- **資料を全部貼って、1ターン目だけで引用させる**——4回とも正しい引用・正しい4か国
- **関連部分だけ貼って、1ターン目だけで引用させる**——4回とも正しい引用・正しい4か国
- **無関係な情報を混ぜても、1ターン目だけで引用させる**——3回とも正しい引用・正しい4か国
- **引用を求めずに、1ターン目だけで聞く**——<mark class="warn">引用を求めずに聞いた3回は、3回中2回が、資料が触れていない範囲を断定で広げました</mark>

[Kindleの印税を式から出す記事](/recipes/kindle-royalty-formula/)があります。この記事は「資料の該当箇所をそのまま引用してから答えてください」という指示文を試していました。送った先は、資料を貼った会話の**3ターン目**（前提を積んだ後）です。3回とも原文どおりの引用を得ていました。ただし本文には「これは上の指示文のさらに後（同じ会話の3ターン目）で送っています。単独で送った場合は測っていません」という宿題が残っていました。その宿題を、実際に試したのが今回です。

## 前提 {: .need }

| | |
|---|---|
| かかる時間 | 15分 |
| 費用 | 無料。ブラウザのチャットAIで足ります |
| 必要なもの | 資料（規約・ヘルプページなど）の原文 |
| プログラミング | **不要**。この記事の指示文をコピーして貼るだけです |

この記事が引用の正しさを判定する基準にしたのは、KDPヘルプの次の一文です（<a href="https://kdp.amazon.co.jp/ja_JP/help/topic/G200634500">電子書籍の希望小売価格</a>・2026-08-26確認）。「日本、インド、メキシコ、およびブラジルの読者への販売において 70% のロイヤリティが適用されるには、電子書籍が KDP セレクトに登録されていることが必要です。」正解は、この4か国です。

## AIへの頼み方 {: .ask }

### 1. 資料を全部貼って、1ターン目だけで引用させる

既出記事が3ターン目までに積み上げていた資料（35%と70%の選択制・販売地域外の扱い・両方の式・配信コスト・日本の70%条件、計6か所）を、**会話の最初の1ターン目だけ**で貼りました。

<div class="prompt">次の資料を読んだうえで、質問に答えてください。

（ここにKDPヘルプの該当箇所6か所を貼る）

質問: KDPセレクトへの登録は、どの国の読者への販売で70%を受け取るための条件ですか。資料の該当箇所をそのまま引用してから答えてください。</div>

**4回とも、原文と一字一句一致する引用から、日本・インド・メキシコ・ブラジルの4か国に正しく到達しました。**既出記事の3ターン目（3回とも原文どおり）と、同じ正確さです。

### 2. 関連部分だけ貼って、1ターン目だけで引用させる

今度は6か所のうち、答えに直接関係する1か所だけを貼りました。

<div class="prompt">次の資料を読んだうえで、質問に答えてください。

（ここにKDPヘルプの該当箇所1か所だけを貼る）

質問: KDPセレクトへの登録は、どの国の読者への販売で70%を受け取るための条件ですか。資料の該当箇所をそのまま引用してから答えてください。</div>

**こちらも4回とも正しい引用・4か国でした。**ただし引用の範囲は回によって割れ、3文すべてを引用したのは1回、残り3回は該当する1文だけを引用しました。<mark>3文すべてを引用した回も、該当する1文だけを引用した回も、原文と一致するので、正確さそのものは崩れていません。</mark>

## うまくいかないときの言い直し方 {: .fix }

### 「そのまま引用してから答えて」を外すと {: .trouble }

引用の指示を外し、同じ資料で質問だけを聞きました。

<div class="prompt">次の資料を読んだうえで、質問に答えてください。

（ここにKDPヘルプの該当箇所6か所を貼る）

質問: KDPセレクトへの登録は、どの国の読者への販売で70%を受け取るための条件ですか。</div>

**4か国の答え自体は3回とも正しいままでした。**変わったのは別のところです。<mark class="warn">3回中2回は、資料が触れていない範囲（4か国以外では条件になるのか）について、「含まれていない」「条件になっていない」と断定で広げました。</mark>残る1回は「資料の記載からは…述べられていません」と、書かれている範囲だけに留めました。引用を求めた3つの聞き方（資料を全部貼る・関連部分だけ貼る・無関係な情報を混ぜる。合計11回）で、この広げすぎが起きたのは2回だけです。<mark>引用を求める指示には、答えの範囲を広げすぎない副作用もあるようです。</mark>

### 無関係な情報を混ぜても引用は崩れないか {: .trouble }

資料に、質問とは関係のない一文（Kindle Unlimitedの分配の説明）を混ぜて試しました。

<div class="prompt">次の資料を読んだうえで、質問に答えてください。

（ここにKDPヘルプの該当箇所6か所＋無関係な1文を貼る）

質問: KDPセレクトへの登録は、どの国の読者への販売で70%を受け取るための条件ですか。資料の該当箇所をそのまま引用してから答えてください。</div>

**3回とも、無関係な一文が引用や回答に混ざることはなく、正しい引用・4か国のままでした。**無関係な情報があっても、引用先を見失う様子はありませんでした。

## 応用・次の一手 {: .next }

**資料を貼って質問する頼み方は、テンプレートにしておくと毎回楽です。**

<div class="prompt">資料を貼って質問するとき、資料に書かれていないことまで答えが広がらないようにする頼み方を教えてください。プログラミングはできません。番号を振って箇条書きで教えてください。</div>

2回試したところ、共通していた骨格は次のとおりです。

- 「資料の中だけで答えてください」と最初に書く
- 「資料に無ければ『書かれていません』と答えてください」と断り方を指定する
- 資料の言葉そのまま、または該当箇所を引用して答えるよう求める
- 質問自体も、資料の範囲に合わせて狭く書く
- 答えの根拠にした場所を示すよう求める

毎回コピーして使えるテンプレートも作らせられます。

<div class="prompt">資料を貼ってすぐ質問するときに、毎回コピーして使える指示文のテンプレートを作ってください。資料の範囲外のことは答えず、該当箇所を引用してから答えてほしいです。</div>

1回試したところ、「資料だけを根拠に」「引用→結論の順」「書かれていない場合の断り方」まで含むテンプレートができました。これは[Kindleの印税を式から出す記事](/recipes/kindle-royalty-formula/)が実際に使った「資料に書かれていることだけで答えてください」という受け皿と同じ型です。資料を貼ったら、まずこの形で聞いてください。会話を何ターンも重ねる必要はありません。

⚠️ **この結果は、KDPヘルプの1か所・合計17回（応用2回を含む）の実測です。**「資料を貼れば1ターン目でも必ず正確」と一般化しないでください。試したのは、次の範囲までです。

- 判定したのは「国名を答えられるか」「引用が原文と一致するか」の2点だけです。価格帯など、この記事で貼っていない数字は試していません
- 資料は1種類（KDPロイヤリティの該当箇所）のみです。もっと長い資料や、複数の論点が絡む資料では未検証です
- 「書かれていない範囲を広げる」傾向は、この1つの質問・この材料だけの観察です。他の資料・他の質問では確かめていません
