## これで何ができるか {: .what }

「AIを使って作った動画は、YouTubeで収益化できますか」——<mark>聞けばAIはすぐ答えてくれます。この記事で確かめたのは、その答えの「どこまでが当てになるか」です。</mark>結論だけ先に書くと、次の3つがはっきり分かれました。

- **収益化できるかどうかの判定**——原文を見せなくても見せても、**全26回とも正しい方向**でした
- **規定の正式名称**——原文を見せなかった4回は、**4回とも改称前の古い名前**のままでした
- **出典のURL**——求めた2回で返ってきた5件のうち、**内容まで合っていたのは1件だけ**でした

<mark class="warn">「AIの答えが当たっていたかどうか」は、判定・名前・出典の3つを別々に確かめないと分かりません。</mark>判定が当たっていることは、名前や出典が正しいことの証拠にはなりません。

架空のチャンネル4パターン(AIを使っているか・独自性があるかの組み合わせ)を用意し、YouTubeの実際の収益化ポリシーと突き合わせて、AIに26回聞きました。既存記事[案件のAI利用ルールを確かめる](/recipes/job-ai-policy-check/)と[案件のAI利用ルールを、別サイト名でも確かめる](/recipes/platform-name-guesses-the-rule-backwards/)は「募集文に書いてあることをAIが正しく拾えるか」を扱いました。この記事は逆に、**募集文ではなく、規定そのものの中身と名前を正しく扱えるか**を確かめています。

## 前提 {: .need }

| | |
|---|---|
| かかる時間 | 20分 |
| 費用 | 無料。ブラウザのチャットAIで足ります |
| 必要なもの | 特にありません |
| プログラミング | **不要**。この記事の指示文をコピーして貼るだけです |

実測に使った架空のチャンネル4パターンと、YouTubeヘルプ「YouTube のチャンネル収益化ポリシー」
（<https://support.google.com/youtube/answer/1311392?hl=ja>・2026-09-29確認）に基づく正解です。

| パターン | 説明 | 正解 |
|---|---|---|
| S1（AI＋独自性あり） | 独自考案のキャラクター・物語をAIで映像化。展開やテーマが動画ごとに変わる | 収益化の対象 |
| S2（AI＋テンプレ） | AI音声のニュース読み上げスライドショーを、同じテンプレートで大量投稿 | 収益化の対象外 |
| S3（人間＋独自性あり） | 本人が出演し、毎回違う商品を実演レビュー。AI不使用 | 収益化の対象 |
| S4（人間＋テンプレ） | 本人は出演しているが、毎回ほぼ同じ展開・オチをテンプレートで大量投稿。AI不使用 | 収益化の対象外 |

<mark class="warn">この表の分かれ目は「AIを使ったかどうか」ではありません。使ったのが人間かAIかに関わらず、**独自性があるかどうか**で分かれています。</mark>YouTubeヘルプ本文にも次のようにあります。

> クリエイターならではの、率直な洞察や視点が追加されておらず、汎用的または独創性のないテンプレートを使用して作成され、大量生産されたような印象を与える AI 生成コンテンツ

このポリシーは以前「繰り返しの多いコンテンツ」という名称でした。大量生産されたコンテンツも含むことを明確にするため、現在は**「量産型のコンテンツ」**という名称に変わっています。

## AIへの頼み方 {: .ask }

### 1. まず、原文を見せずにそのまま聞く

<div class="prompt">次のチャンネルは、YouTubeパートナープログラムで収益化できますか。理由も教えてください。

(ここにチャンネルの説明を貼る)</div>

4パターンそれぞれに2回ずつ、独立した新規の会話で試しました(全8回)。**8回とも、判定は正解の方向と一致しました。**S1・S3(独自性あり)は「収益化できる」、S2・S4(テンプレ)は「収益化できない」で、取り違えは0件です。

<figure class="figure">
<img src="/static/images/yt-policy-name-hit-and-miss.svg" alt="YouTubeの収益化ポリシーの正式名称を尋ねた実測結果を示す表。原文を見せずに聞いた4回(架空のチャンネル2種を2回ずつ)は、4回とも現行の正式名称「量産型のコンテンツ」を言い当てられず、「反復コンテンツ」「reused content」など改称前の古い名前を答えた。原文を貼ってから聞いた2回は、2回とも現行の正式名称を正しく答えた。下の枠には、収益化できるかどうかの判定そのものは原文の有無に関わらず今回の全26回とも正しい方向だったこと、当たっているのは結論であって規定の名前は別に確かめないと古いままであることが書かれている。">
<figcaption>判定は当たっていた。ただし規定の名前を挙げた回は、7回とも改称前の名前だった。</figcaption>
</figure>

判定は正しかったものの、理由の中で規定の名前に触れた回は7回ありました(S3-rep1を除く全回)。**その7回とも「反復(性の)コンテンツ」「reused content」「repetitious content」「二次利用コンテンツ」という、改称前の名前**でした。現行の正式名称「量産型のコンテンツ」を使った回は0回です。

### 2. 原文を貼ってから、同じ質問をする

<div class="prompt">次の文章は、YouTubeヘルプ「収益化ポリシー」の一部です(2026-09-29確認)。

(ここに原文抜粋を貼る)

これをふまえて、次のチャンネルは収益化できますか。理由も教えてください。

(ここにチャンネルの説明を貼る)</div>

原文抜粋には、前提の節に引用した「許可される例」「許可されない例」と、改称の説明を貼りました。同じ4パターンに2回ずつ試すと、**こちらも8回とも判定は正解の方向と一致しました。**判定の正しさは、原文の有無で変わりませんでした。

一方、規定の中身に踏み込んだ回では違いが出ました。S4(人間・テンプレ)の2回はどちらも「『量産型のコンテンツ』という名称に変更されています」と、**改称の事実に正しく触れています。**原文を見せると、少なくとも名前が古いままにはなりません。

### 3. 規定の正式名称と、改定時期も聞いてみる

判定だけでなく、名前そのものを聞いたらどうなるかを確かめます。原文はまだ見せません。

<div class="prompt">次のチャンネルは、YouTubeパートナープログラムで収益化できますか。理由も教えてください。あわせて、判断の根拠にした規定の正式名称と、その規定が最後にいつ改定されたかも書いてください。

(ここにチャンネルの説明を貼る)</div>

S2・S4に2回ずつ、計4回試しました。**判定は4回とも正解。名前は4回とも改称前の古い名前でした。**面白いのは改定時期です。

- 1回は「2025年7月ごろ」、もう1回は「2025年7月9日発表・7月15日適用」——**どちらも真値(2025-07-15)にほぼ一致**
- 残る1回は「2024年7月上旬(2024年7月9日前後)」——**年をまるごと1年、間違えました**

<mark class="warn">正しい日付と間違った日付が、まったく同じ自信満々な言い方で出てきます。</mark>「◯月◯日前後」という具体的な言い方そのものは、正しさの目印になりません。

### 4. 原文を貼って、名前も聞く

<div class="prompt">次の文章は、YouTubeヘルプ「収益化ポリシー」の一部です(2026-09-29確認)。

(ここに原文抜粋を貼る)

これをふまえて、次のチャンネルは収益化できますか。理由と、この規定の正式名称も書いてください。

(ここにチャンネルの説明を貼る)</div>

S4に2回試すと、**2回とも「量産型のコンテンツ(旧称『繰り返しの多いコンテンツ』)」と、現行の正式名称を正しく答えました。**指示文3と条件をそろえると、原文の有無だけで結果が変わったことが分かります。

| 条件 | 回数 | 現行の正式名称を正しく答えた回数 |
|---|---|---|
| 原文なし(指示文3) | 4回 | 0/4 |
| 原文あり(指示文4) | 2回 | 2/2 |

⚠️ **回数が少ない実測です(4回・2回)。**この2つの条件・この材料での結果として読んでください。

### 5. 出典のURLも聞いてみる

規定の名前だけでなく、根拠のページそのものを求めたらどうなるかを確かめます。原文は見せません。

<div class="prompt">次のチャンネルは、YouTubeパートナープログラムで収益化できますか。理由と、判断の根拠にしたページのURLも書いてください。

(ここにチャンネルの説明を貼る)</div>

S2に2回試すと、判定は2回とも正解でしたが、URLは合わせて5件返ってきました。**すべて自分でcurlを実行してHTTPステータスと実際のページ内容を確認しました。**

<figure class="figure">
<img src="/static/images/yt-citation-url-breakdown.svg" alt="「判断の根拠にしたページのURLも書いて」と頼んだ2回の返りで出てきた、計5件のURLの内訳を示す図。①answer/72851(1回目)は実在するがYPP資格要件の概要ページで反復コンテンツの規定ではない。②answer/6162278(1回目)は実在するが広告掲載ガイドラインのページで無関係。③answer/9997383(2回目)はURLが存在せず404で、回答は「本件の直接の根拠」と説明していた。④answer/1311392(2回目)は実在し、実際に量産型のコンテンツの規定が書かれている正しいページ。⑤answer/6162278(2回目)は実在するが①②と同じ広告掲載ガイドラインのページで無関係。下の枠には、5件のうち実在してかつ内容も一致していたのは④の1件だけで、③は存在しないURL、①②⑤は実在するが別の話題のページだったことが書かれている。">
<figcaption>実在するURLでも、書いてある内容が違うことがある。開いて読むまで分からない。</figcaption>

<mark class="warn">5件のうち、内容まで一致していたのは1件だけでした。</mark>1件(answer/9997383)は**404で、そもそも存在しません**。「本件の直接の根拠」と説明されていたページです。残る3件のうち2件(answer/6162278が2回登場)は、**実在はするものの「広告掲載に適したコンテンツのガイドライン」という別の話題のページ**でした。量産型コンテンツの規定はそこには書かれていません。「スライドショー」「読み上げ」「反復」「量産」という語は、そのページに0件でした。

## うまくいかないときの言い直し方 {: .fix }

### 名前や日付に自信が持てないなら、そう書かせる {: .trouble }

規定の名前や日付を自分で確かめられない場面では、**AIに無理な断定をさせない一文が効くか**を確かめます。

<div class="prompt">次のチャンネルは、YouTubeパートナープログラムで収益化できますか。理由も教えてください。規定の正式名称や最後に改定された時期について自信が持てない場合は、無理に断定せず「確認できません」とだけ書いてください。

(ここにチャンネルの説明を貼る)</div>

S2に2回試すと、**判定は2回とも正解のまま、名前・日付は2回とも「確認できません」でした。**指示文3では毎回、古い名前や不正確な日付が自信満々に出てきましたが、この一文を足すだけで、誤った名前・誤った日付は1件も出なくなりました。

<mark>「分からなければ分からないと書け」は、規定の名前や改定日のような固有の事実には効きました。</mark>[逃げ道の一文は範囲でも効かない](/recipes/no-line-stops-range-either/)は、同じ言い回しが数字の計算には効かなかったことを実測しています。**効くかどうかは、何を聞いているかで変わります。**判定の理由づけには効かなくても、固有名詞や日付のような「知っているか、知らないかがはっきりする」対象には効きやすいようです。

## 応用・次の一手 {: .next }

**AIに「収益化できるか」を聞くこと自体は、今回の実測の範囲では止める理由がありません。**判定は26回とも正しい方向でした。<mark class="warn">止めてほしいのは、その理由に出てくる規定の名前・改定日・出典URLを、確かめずにそのまま人に伝えることです。</mark>

- **判定だけ知りたいとき**——指示文1のようにそのまま聞いて構いません
- **規定の名前や日付を引用したいとき**——指示文3のように聞かず、まず自分でYouTubeヘルプの現行ページを開いて確認するか、原文を貼ってから聞いてください(指示文2・4)
- **確認する時間が無いとき**——「言い直し方」の節の「自信が持てなければ確認できませんと書いて」を足すと、誤った名前・日付が出てくる代わりに、正直に保留してくれます

⚠️ **この結果は、架空のチャンネル4パターン・のべ26回、この1つのAIでの実測です。**別のAIサービスや、実在のチャンネルではまた違う答えが返るかもしれません。実際に自分のチャンネルで収益化を判断する前には、必ずYouTubeヘルプの現行ページ
（<https://support.google.com/youtube/answer/1311392?hl=ja>）をご自身で開いて確認してください。

この崩れ方は、[案件のAI利用ルールを確かめる](/recipes/job-ai-policy-check/)が確かめた崩れ方とは別物です。あちらは「聞かれてもいない規約を作り話しない」、つまり**知らないことを正直に断った**回でした。今回は逆で、**規定の中身には自信があるまま、引用元だけが的を外した**回でした。YouTubeでの収益の仕組みそのものは[YouTubeパートナープログラムの門と入金](/recipes/youtube-payout-thresholds/)にまとめています。

今回の生の返り26回ぶんは `docs/evidence/youtube-citation-one-of-five-correct.md` に全文置いてあります。URLの実際のHTTPステータスとページ内容の確認結果も、同じファイルにあります。
