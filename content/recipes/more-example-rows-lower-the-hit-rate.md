## これで何ができるか {: .what }

[毎日の追記を同じ形にそろえる](/recipes/daily-append-same-shape/)は、ファイルの1行目に
お手本を1行だけ置けば、書式を指示文に書かなくても追記が規定の形にそろうことを確かめました。
ただし、その記事はこう締めていました——「次に測るなら＝ファイルが100行を超えたあとで走らせた
場合です。この80回では触っていません」。

毎日1行ずつ積み上がっていくファイルは、1週間後には7行、半年後には180行になります。
**お手本が1行だけだったときの結果が、見本が100行になったあとも続くのか。**これを測りました。

結論は3つです。

1. **見本を1行から100行に増やしても、的中は上がりません。むしろ下がります。**書式を1文字も
   書かない指示文のまま、お手本1行の元記事は12回中12回そろいましたが、クリーンな100行では
   **4回中3回**でした
2. **100行のうち1行だけ、区切り記号の違う行が混ざっていると、的中はさらに下がります。**
   同じ無指示の指示文で**4回中1回**にまで落ちました
3. **「ファイルに合わせて」と指示文に一言添えるだけなら、100行でも1行乱れていても関係ありません。**
   この版だけは常に4回中4回です

| 条件 | 書式の指示 | 的中（規定の書式になった回数） |
|---|---|---|
| お手本1行（元記事） | なし | 12/12 |
| クリーンな100行 | なし | **3/4** |
| クリーンな100行 | 「ファイルに合わせて」と明示 | 4/4 |
| 1行だけ乱れた100行（1日目） | なし | **1/4** |
| 同じ系列（2日目） | なし | 1/4（1日目と同じ内訳） |

📌 **この記事の数字は、すべて架空データでの実測です。**走り書きにも、100行の記録にも、
半角スラッシュと半角カンマは1文字も入れていません（入れると、それ自体がお手本になるため）。
架空の記録ファイル2本（副業の作業記録／家計の買い物メモ）に100行ぶんの履歴を機械で積み、
独立した新規会話（毎回ゼロから起動・前の会話の記憶なし）で試しました。**合計27回**
（クリーンな100行8回＋1行乱れた100行16回＋点検3回）の生の返りと機械照合は
`docs/evidence/more-example-rows-lower-the-hit-rate.md` に置いてあります。

この記事は[毎日の追記を同じ形にそろえる](/recipes/daily-append-same-shape/)の続きです。
指示文は元記事の指示文1（書式を書かない）・指示文6（「ファイルに合わせて」）・指示文7
（点検）を一字一句同じ文字列で使い、変えたのは**ファイルの行数（1行→100行）と、
その100行の中身（クリーン／1行だけ乱れ）**だけです。

## AIへの頼み方 {: .ask }

### 1. 100行まで育てたファイルに、書式を書かずに頼んでみる

ファイルは見出し1行＋規定の書式どおりの行100行（2026-04-23〜2026-07-31の毎日1行）。
指示文には書式を1文字も書きません。

<div class="prompt">下の「記録ファイル」の末尾に、【今日ぶん】を1行だけ追記してください。すでにある行は1文字も変えないでください。更新後のファイル全体を、コードブロックで出してください。</div>

このあとに走り書き「2026年8月1日 C社 記事の下書き 90分」と、100行の記録ファイルをそのまま貼ります。
材料2本（副業の作業記録・家計の買い物メモ）×各2回＝**4回**。

<mark>元記事では、この指示文に「お手本1行」を添えると12回中12回そろいました。見本を100行に
増やしたこの実測では、4回中3回です。</mark>崩れた1回は、走り書きがそのまま最後の行に貼られました
（`2026年8月1日 C社 記事の下書き 90分`）。**指示文・ファイルとも、そろった回と1字1句同じです。**

🔑 **崩れたのは材料A（副業の作業記録）の2回目だけでした。**同じ材料・同じ指示文の1回目は
規定の書式（`2026-08-01 / C社 / 記事の下書き / 90分`）にそろっています。
[ダミーの見本行でも書式はそろう](/recipes/dummy-row-holds-real-row-breaks/)でも、
**同じ材料（副業の作業記録）で、走り書きがそのまま貼られる崩れ方**が4回中4回で出ていました
（あちらは見本1行、こちらは見本100行）。材料Aだけが、この崩れ方に弱いようです。

### 2. 「ファイルに合わせて」なら100行でも崩れない

指示文は1番と同じ文章に、「すでにファイルにある行と同じ形にそろえてください」の一文だけを足します。

<div class="prompt">下の「記録ファイル」の末尾に、【今日ぶん】を1行だけ追記してください。すでにある行は1文字も変えないでください。更新後のファイル全体を、コードブロックで出してください。すでにファイルにある行と同じ形にそろえてください。</div>

材料2本×各2回＝**4回**。<mark>「ファイルに合わせて」を足したこの版は、4回とも規定の書式でした。</mark>100行という量も、材料Aの弱さも、
この一文を足すだけで関係なくなります。

### 3. 100行のうち1行だけ区切りの違う行を混ぜると、的中はさらに下がる

末尾から2行目（2026-07-30付け）だけを、カンマ区切りの壊れた形
（`2026-07-30,D社,会議メモ,30分`）に差し替えました。他の99行は規定の書式のままです。
指示文は1番とまったく同じ（書式を1文字も書かない）ものを使います。

<div class="prompt">下の「記録ファイル」の末尾に、【今日ぶん】を1行だけ追記してください。すでにある行は1文字も変えないでください。更新後のファイル全体を、コードブロックで出してください。</div>

材料2本×各2回＝**4回**。<mark class="warn">1行だけ乱れた100行では、的中は4回中1回まで下がりました。</mark>クリーンな
100行（1番）の4回中3回より、さらに悪くなっています。

<img src="/static/images/grown-file-sticky-pattern.svg" alt="そろった系列はそろったまま、崩れた系列は崩れたまま続いたことを示す図。材料Aの独立した2つの会話を比べている。系列A-rep2は1日目に「2026-08-01 / C社 / 記事の下書き / 90分」という規定の書式で追記し、2日目も「2026-08-02 / D社 / 打ち合わせメモ起こし / 45分」という同じ規定の書式のままだった。系列A-rep1は1日目に「2026年8月1日 C社 記事の下書き 90分」という走り書きのまま追記し、2日目も「2026年8月2日。D社の打ち合わせメモ起こし。45分。」という走り書きのままだった。指示文はどちらの系列も2日間とも一字一句同じだった。">

🔑 **乱れた1行の形（カンマ区切り）が、新しい行にコピーされたことは1回もありません。**
崩れた3回は、カンマ区切りではなく**走り書きがそのまま**（`2026年8月1日 C社 記事の下書き 90分`）
貼られました。乱れた1行は「真似される」のではなく、「規定の書式に従う確率を下げる」ように
働いたようです（4回という少ない回数での観察なので、言い切りはしません）。

### 4. 崩れた系列は、2日目も自分から直らない

1日目の出力をそのまま2日目の入力にして、2日目の走り書き「2026年8月2日。D社の打ち合わせメモ
起こし。45分。」を追記させました。指示文は3番と同じ（書式を書かない）ものです。

<div class="prompt">下の「記録ファイル」の末尾に、【今日ぶん】を1行だけ追記してください。すでにある行は1文字も変えないでください。更新後のファイル全体を、コードブロックで出してください。</div>

材料2本×各2回＝**4回**。<mark>4系列とも、1日目の結果（そろう／そろわない）が2日目へそのまま
続きました。</mark>1日目にそろった1系列は2日目も規定の書式、1日目に崩れた3系列は2日目も走り書き
のままです。**的中は2日目も4回中1回で、1日目と内訳まで完全に同じでした。**

## うまくいかないときの言い直し方 {: .fix }

### 100行もあるのに、今日の追記だけ走り書きのまま残った {: .trouble }

<mark class="warn">育ったファイルを見るだけでは、今日の1行がそろっているかは分かりません。</mark>
99行が規定の書式でも、今日の1行だけ走り書きのまま貼られることがあります
（実測の4回中1回）。確実にそろえたいなら、2番の「ファイルに合わせて」の一文を指示文に
足してください。**100行の実績があっても、この一文を省略する理由にはなりません。**

### 1行だけ乱れているのに、何日も気づかなかった {: .trouble }

乱れた行は自分からは直りません。見つけるには、**点検専用の別の新しい会話**に「形がそろって
いない行」を挙げさせます（元記事の言い直し方と同じ型）。

<div class="prompt">下のファイルは、毎日1行ずつAIに追記しているものです。行の形（区切り記号・日付の書き方・末尾の単位）がそろっていない行があれば、その行をそのままコピーして挙げてください。1行もなければ「ありません」とだけ書いてください。</div>

102行（見出し＋101行）になったファイルを3系列に渡したところ、**3系列とも、乱れた行を
一字一句そのままコピーして挙げました。**乱れが1件だけの系列も、乱れに走り書きの追記が
重なった系列も、**誤検知は0件**です。元記事は3日目・29〜31行のファイルでこの点検を試して
いましたが、**102行に増えても同じ精度でした。**

⚠️ **この点検は月に1回ぶんの手間です。**毎日走らせる自動化の中に混ぜる必要はありません。

## 応用・次の一手 {: .next }

**「見本が増えれば増えるほど安定する」は外れでした。**むしろ逆です。お手本1行のときの
12回中12回は、見本を100行に増やすと4回中3回に、1行乱れると4回中1回に下がりました。
**唯一、行数も乱れも関係なかったのは、指示文に「ファイルに合わせて」と一言添えた版だけ**です。

- 書式を1文字も書かない：お手本1行で12/12 → クリーンな100行で3/4 → 1行乱れた100行で1/4
- 「ファイルに合わせて」と明示：クリーンな100行で4/4（**1行乱れた100行への指示文は、この実測では試していません**）

<div class="prompt">下の「記録ファイル」の末尾に、【今日ぶん】を1行だけ追記してください。すでにある行は1文字も変えないでください。更新後のファイル全体を、コードブロックで出してください。すでにファイルにある行と同じ形にそろえてください。</div>

[毎日決まった時刻にAIを動かす仕掛けを作らせる](/recipes/github-actions-daily-cron/)に
この指示文を組み込むなら、**ファイルが何行になっても、この一文だけは外さないでください。**
行数が増えたから書式の指示を削ってよい、という理屈は今回の実測では支持されませんでした。

**月に1回は点検も**。[毎日の追記を同じ形にそろえる](/recipes/daily-append-same-shape/)の
点検（4番）を、ファイルが育ったあとも同じ頻度で続けてください。102行でも精度は変わりません。

⚠️ **この記事が実測していないこと**＝乱れた行が2行以上になった場合、ファイルが500行・
1000行まで育った場合、「ファイルに合わせて」版に乱れた行を混ぜた場合の3つです。
特に3つ目は、2番と3番を両方やって初めて分かることなので、次に測るならここからです。
