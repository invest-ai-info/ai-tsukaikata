## これで何ができるか {: .what }

<mark>副業でAIに請求書の下書きを作らせるとき、適格請求書（インボイス）として必要な項目のうち、どれが抜けやすいかを実測しました。</mark>発行者・宛先・取引内容・金額だけを渡し、登録番号を渡さずに「請求書を作ってください」と頼んだ結果です。

- **登録番号は、渡さなければ3回中0〜1回しか欄に残りません**
- <mark>架空の番号をでっち上げた回は、6回とも0件でした</mark>
- **税率が2種類（10%・8%）混ざる材料のほうが、単一税率より登録番号も税率の内訳も残りやすい**という、意外な結果になりました

<figcaption>登録番号は渡さないと消える回が多く、税率が混ざると残りやすくなりました。</figcaption>
</figure>

<mark class="warn">単一税率の材料では、税率ごとの消費税額（必須項目の1つ）も3回中2回省略され、税込の合計額だけが書かれました。</mark>税率が混ざる材料では3回とも明記されています。「複雑な条件のほうが崩れる」という見立ては、今回は逆向きに外れました。

## 前提 {: .need }

| | |
|---|---|
| かかる時間 | 15分 |
| 費用 | 無料。ブラウザのチャットAIで足ります |
| 必要なもの | 発行者の情報（氏名・名称・登録番号）、取引の内容・金額・日付 |
| プログラミング | **不要**。この記事の指示文をコピーして貼るだけです |

<mark class="warn">実在の取引先名・実在の登録番号は貼らないでください。</mark>この記事は架空の社名・金額を使っています。実在の人物・団体とは関係ありません。

適格請求書に必要な記載事項は、国税庁の質疑応答事例「[４ 適格請求書の記載事項](https://www.nta.go.jp/taxes/shiraberu/zeimokubetsu/shohi/keigenzeiritsu/pdf/qa/54.pdf)」（2026-10-23確認）によると次の6つです。

1. 適格請求書発行事業者の氏名または名称**および登録番号**
2. 課税資産の譲渡等を行った年月日
3. 取引内容（軽減税率対象品目なら、その旨も）
4. 税率ごとに区分した金額の合計と適用税率
5. 税率ごとに区分した消費税額
6. 交付を受ける事業者（取引先）の氏名または名称

この記事は「下書きが何個欠けるか」という実測に絞っています。実際の請求書は、発行前に自分で6項目を目で確認してください。[副業の手取りを契約額から出す記事](/recipes/take-home-from-the-contract-amount/)と合わせて読むと、受け取る側の計算にも役立ちます。

## AIへの頼み方 {: .ask }

### 1. 登録番号を渡さず、単一税率の取引を頼む

発行者名・宛先・取引内容・金額（税込）だけを渡し、登録番号は書きません。

<div class="prompt">次の内容で請求書を作ってください。発行者は合同会社ヒカリデザイン、宛先は株式会社みどり商事です。11月20日に行ったウェブサイト制作の代金55万円（税込）を請求します。</div>

3回試しました。**3回とも、登録番号の欄そのものが出てきませんでした**（0/3）。<mark class="warn">架空の番号を作文した回は1回もありません。</mark>静かに欄ごと消えるだけでした。さらに3回中2回は、税率ごとの消費税額も書かれず、「55万円（税込）」という合計額だけで終わっています。

### 2. 登録番号を渡さず、税率が2種類混ざる取引を頼む

次は、標準税率10%の品目と、軽減税率8%の品目が1枚の請求書に混ざる場合です。登録番号は同じく渡しません。

<div class="prompt">次の内容で請求書を作ってください。発行者は合同会社ヒカリデザイン、宛先は株式会社みどり商事です。11月25日の取引で、事務用品22,000円（税込）と、軽減税率対象の飲食料品3,240円（税込）を、まとめて請求します。</div>

3回試すと、**登録番号の欄は1回だけ残りました**（1/3）。残った1回は、実際の番号は書かず「T（記入してください）」という空欄にして、備考で「登録番号を追記してください」と案内しています。<mark>一方、税率ごとの消費税額（10%対象・8%対象の内訳）は、3回とも正しく明記されました。</mark>単一税率の材料より良い結果です。

### 3. 登録番号を渡して頼む（基準）

比較のため、登録番号を含むすべての情報を渡した場合も確認しておきます。

<div class="prompt">次の情報から、請求書を作ってください。

発行者：合同会社ヒカリデザイン（登録番号T1234567890123）
交付先：株式会社みどり商事
取引年月日：2026年11月20日
取引内容：コーポレートサイト制作一式
金額：550,000円（税込、消費税率10%）</div>

3回とも、6項目すべてが請求書に転記されました。**材料に書いてあれば、確実に写されます。**消えるのは「渡していない情報」だけです。

## うまくいかないときの言い直し方 {: .fix }

### 登録番号が静かに消える {: .trouble }

指示文1・2と同じ条件に、「分からなければ分からないと明記して」の一文を足します。

<div class="prompt">次の内容で請求書を作ってください。発行者は合同会社ヒカリデザイン、宛先は株式会社みどり商事です。11月20日に行ったウェブサイト制作の代金55万円（税込）を請求します。

適格請求書として必要な項目（発行者の登録番号・取引年月日・取引内容・税率ごとの金額と消費税額・交付先名）をすべて書いてください。登録番号が分からない場合は、分からないと明記してください。</div>

単一税率・税率混在の両方の材料で2回ずつ、**合計4回とも「登録番号：不明（ご確認ください）」という形で欄が残りました。**架空の番号は4回とも書かれていません。<mark>欄ごと消える事故は、材料に書くか、この一文を足すかのどちらかで防げます。</mark>

## 応用・次の一手 {: .next }

**分割請求（着手金・残金のように2回に分けて発行する場合）でも、情報を渡せば同じように正しく記載されるか**も確認しました。

<div class="prompt">次の情報から、2回に分けて発行する請求書を、それぞれ作ってください。

発行者：合同会社ヒカリデザイン（登録番号T1234567890123）
交付先：株式会社みどり商事
取引内容：ロゴデザイン制作一式（契約金額330,000円・税込、消費税率10%）
支払い：
・1回目（着手金）：2026年11月5日発行、165,000円（税込）
・2回目（残金）：2026年12月10日発行、165,000円（税込）</div>

2回試すと、**4枚の請求書すべてで6項目が独立して正しく記載されました。**金額（165,000円の税抜150,000円・消費税15,000円）も2回とも一致しています。登録番号を情報として渡しておけば、請求書が複数枚に分かれても抜けません。

**請求書を毎回AIに作らせているなら、渡す情報をテンプレート化しておくのが確実です。**

<div class="prompt">今後、私が請求書を頼むときに毎回渡す情報（発行者名・登録番号・取引先名など）をテンプレートにしてください。私が空欄を埋めるだけで、6項目（登録番号・取引年月日・取引内容・税率ごとの金額・消費税額・交付先名）が必ず揃う形にしてください。</div>

2回試すと、2回とも6項目すべてに対応する空欄を持つテンプレートが返り、税率ごと（10%対象・8%対象）の金額欄もあらかじめ分かれていました。**渡す情報を固定書式にしてしまえば、「渡し忘れる」という人間側の抜けごと防げます**——これが今回の実測から見えた、いちばん確実な予防線です。

[士業・出演料でも源泉徴収の式を実測した記事](/recipes/withholding-formula-crosses-lawyers-and-performers/)も、同じ「必要な情報を渡せば正しく処理される・渡さなければ抜ける」という構図でした。

⚠️ **この結果は、単一税率・税率混在の2材料・計20回（分割請求2回・テンプレート化2回を含む）の実測です。**「税率が多いほど必ず正確になる」と一般化しないでください。試したのは、次の範囲までです。

- 税率は10%と8%の2種類のみです。複数の軽減税率品目が多数混ざる場合は未検証です
- 登録番号を「渡さない」パターンは2材料のみ。社名や業種が変わった場合は未検証です
- 判定は「項目が本文に出たか」の機械的な確認です。記載された日付・金額が実際に正しいかは別途、本文で個別に照合しています
