## これで何ができるか {: .what }

[緊急語が入っても仕分けは崩れない](/recipes/synonym-wording-empties-the-collateral/)という前作は、最後にこう書いて終わっていました。「今回の紛らわしい語は『急ぎではない』『来週』という否定の言葉を自分から含んでいました。否定の言葉すら含まない、もっと巧妙な紛らわしさは試していません。例えば、緊急に見える言葉と緊急でない言葉が同じ文に混ざる依頼です」。この記事はその先です。プログラミングは要りません。

結論は3つです。

1. 除外の基準を「至急」「今すぐ」「本日中」という**語そのもの**の有無で固定した、古い指示文があります。そこに「至急対応をお願いしたい件ですが、来週分の定期メンテナンスでまとめて直していただければ結構です」という依頼を混ぜました。<mark class="warn">8回中7回、一覧に残ってしまいました。</mark>除外の根拠を引用させる指定を足しても、7回中3回は同じように残りました。
2. 前作で確立した指示文に差し替えました。除外の基準を「類義語・言い換えも含める」と**広げた**ものです。6件条件・既存の誤りと同時に混ぜた7件条件、引用の有無の4通り×各4回＝16回を試しました。<mark>16回すべてで、この依頼だけを正しく除外できました。</mark>
3. 健全な5件への巻き添えは、古い指示文・新しい指示文を合わせた24回すべてで0件でした。

## うまくいかないときの言い直し方 {: .fix }

### 「語の有無」で基準を書いている指示文が、まだ残っている {: .trouble }

<mark class="warn">「至急」「今すぐ」「本日中」のように、具体的な語を例示する書き方そのものが危険です。</mark>指示文3・4のように「〜に限らず、同じ意味を持つ表現（類義語・言い換え）も含めて」と、範囲を明示的に広げる言い方に直してください。[前作](/recipes/synonym-wording-empties-the-collateral/)が確立した言い換えです。

### 引用させているのに、まだ崩れることがある {: .trouble }

指示文2の結果が示すとおり、<mark>引用の指定は基準の狭さを補いません。</mark>根拠の引用は「除外した判断が信用できるか」を事後に確かめる手段であって、判断そのものを広げる手段ではないと考えてください。基準を直す（指示文3・4）ほうが先です。

### この紛れ語を、もっと難しくしたらどうなるか {: .trouble }

📌 **この記事が確かめたのは、否定の言葉を含まない紛れ語1種類だけです。**今回の紛れ語は「来週分の定期メンテナンスで」「月末の定例報告に」という具体的な先送り先を自分から書いていました。<mark>先送り先を書かず、単に優先度だけを下げる言い方（「他の作業が立て込んでいればそちらを先で構いません」など）は試していません。</mark>次に測るなら、そこから始めてください。
