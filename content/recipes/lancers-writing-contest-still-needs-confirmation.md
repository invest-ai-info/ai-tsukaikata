## これで何ができるか {: .what }

<mark>ランサーズでライティングの案件を募集するとき、AI利用の可否をAIに聞いても、答えは一枚岩ではありませんでした。</mark>架空のSEOブログ記事の募集文を、コンペ方式とプロジェクト方式の2パターンで用意しました。AI利用についての記載は一切入れていません。それぞれ5回ずつ、計10回聞きました。

- **素朴に聞いて、最初の結論文で「使ってOK」と言い切った回**——10回中**1回**（コンペ方式のみ）
- **「結局、一言で」と答えを迫った回（同じコンペ方式の募集文・5回）**——**5回とも「使ってOK」**
- **ランサーズの実際の「選べる」制度に自分から触れた回**——10回中**0回**
- **「原文のまま抜き出して」と言い直した回**——3回とも規約への言及自体が消えました

<mark class="warn">「要確認」という答えは、強く迫られると崩れることがあります。</mark>最初の答えでは9割が慎重だったのに、決断だけを求めると全部が肯定側に変わりました。**慎重な答えが、どのくらい強いかは別問題です。**

既存記事[ランサーズのAI可否は「要確認」](/recipes/lancers-ai-policy-needs-confirmation/)はロゴデザインの依頼で実測し、末尾に「業務はロゴデザインのみ（デザイン・ライティング以外は試していません）」という宿題を残していました。この記事はその宿題のライティング版です。**おおむね同じ結果を再現しましたが、完全に同じではありませんでした。**理由と、新しく見つけたことを、このあとに書きます。

## AIへの頼み方 {: .ask }

### 1. コンペ方式の募集文で、素朴に聞く

架空のSEOブログ記事の募集文（依頼形式＝コンペ方式）を用意しました。AI利用についての記載は一切入れていません。

<div class="prompt">この募集文でAIを使って作業してよいか教えてください。</div>

上に続けて、募集文を貼ります。

**5回のうち4回は「記載が無いので確認を」という結論でした。**「文面だけでは判断できません」「確定はできません」のように、確認を促す形です。**残り1回だけ、最初の結論文が「この募集文にはAI利用を禁止する記載はなく、文面上は使っても問題ない状況です」という、断定に近い形になりました。**どの回も、ランサーズが実際に持つ「使用許可・制限を選べる」機能や【AIで生成】ラベルには、5回とも1件も触れていません。

### 2. 同じ聞き方を、プロジェクト方式の募集文でも試す

契約形式の1行だけを「プロジェクト方式」に差し替えた募集文で、同じ実験をしました。

<div class="prompt">この募集文でAIを使って作業してよいか教えてください。</div>

**こちらは5回とも「要確認・避けるのが安全」という結論でした。**断定に寄った回は0回です。コンペ方式版との違いは、断定に寄った1回があったかどうかだけです。実際の仕組みを示す語は、コンペ方式・プロジェクト方式を合わせた10回中0回でした。

### 3. 結局どちらか、一言で答えさせる

最初の結論は9割が慎重でした。では、迷いの余地を与えずに決断だけを迫るとどうなるでしょうか。同じコンペ方式の募集文で、新しい会話として5回試しました。

<div class="prompt">結局、使ってよいかダメか、一言で教えてください。</div>

**5回とも「使ってOK」でした。**「結論：使ってOKです。ただし条件付きです」「一言で言うと『使ってよい』です」のように、最初の一言はすべて肯定側です。素朴に聞いた指示文1では1/5だった肯定が、同じ材料・同じ募集文のまま5/5まで増えました。

### なぜこの言い方が変わるのか

**「要確認」という結論は、クライアントに確認するまで保留するという「決めない」側の姿勢です。**この姿勢は、別の判断を強く求める指示が重なると崩れます。素朴に聞くと「書かれていないので確認してください」という、人に判断を預ける答えが返りますが、「一言で」と決断そのものを求められると、もう一度よく読んでも募集文に禁止の記載は無いので、肯定側に倒れると考えられます。**慎重な答えの9割は、決断を迫られるとその場では崩れることがあります。**

## うまくいかないときの言い直し方 {: .fix }

### 原文だけを聞きたいとき {: .trouble }

「コンペ方式」という募集文自身の語を繰り返した回がありました。原文だけを答えさせる言い直しでも、同じように止まるかを確かめました。

<div class="prompt">この募集文に書かれている文を、原文のまま抜き出してください。規約の一般的な内容や可否の判断は書かないでください。

この募集文でAIを使って作業してよいか教えてください。</div>

**3回とも「AI利用に触れている文は募集文の中にありません」と答えました。**募集文自身の項目名への言い換えも含めて、規約への言及が消えています。既存記事で確かめた「原文のまま抜き出して」という言い直しは、業務をライティングに変えても効きました。

### 制度そのものを直接尋ねてみると {: .trouble }

「自分からは言及しない」ことは「知らない」ことと同じでしょうか。募集文を見せず、業務をライティングに限定して、制度の有無だけを直接尋ねました。

<div class="prompt">ランサーズには、コンペ方式のライティング依頼で、発注者が生成AIの「使用許可・制限」を選べる制度がありますか。知っていることを教えてください。</div>

<mark>制度の有無を直接尋ねると、3回とも「選べる」「選択」という実際の仕組みに近い語を自分から出しました。</mark>ただし、既存記事（ロゴデザインで同じ質問をした回）とは様子が違います。「コンペ形式のライティングでも同じ選択肢があるのか…はっきり言えません」「ライティング依頼で…専用の制度や項目があるとは、私の知識では断定できません」のように、**3回とも「ライティングに限った適用」には確信を持てていませんでした。**募集文の可否を聞かれた場面では10回中0回だった同じ知識が、制度の有無を直接尋ねると言葉としては出てきますが、ライティングという業務に限定した確信度は、デザインのときより低いことが分かります。

## 応用・次の一手 {: .next }

複数の回が「応募前に発注者へ確認を」と自分から提案していました。その確認文をAIに作らせられるかも試しました。

<div class="prompt">この募集文の発注者に、AI利用の可否を確認するための質問文を1つ作ってください。</div>

2回とも、そのまま送れる丁寧な質問文ができました。1回は「1. 生成AIの利用は一切不可 2. 構成案やアイデア出しのみ可 3. 下書きに利用してもよいが加筆・修正は自分で行う 4. 特に制限はない」という選択肢まで自分から作り、発注者が一度の返信で答えやすい形にしていました。

**「一言で」と迫ると答えが変わることを知っておくと、確認の聞き方そのものにも応用できます。**たとえばAIに案件の下調べをさせるとき、「結局どちらですか」と決断だけを求めると、材料が薄いまま片方に倒れた答えが返ってくることがあります。[傾向を語らせない記事](/recipes/too-few-records-no-trend/)や[見積もりの前提を埋めさせない記事](/recipes/estimate-leak-follows-missing-number/)にも近い注意があります。**自分が「決めてほしい」と思って一言を求めるときほど、AIは無理にでも一言を作ってくる**ことを覚えておいてください。

⚠️ **この結果は、この1種類の業務（ライティング・SEOブログ記事）・合計23回の実測です。**「ランサーズのAI可否は一言で迫れば必ず崩れる」と一般化しないでください。試したのは、次の範囲までです。

- 業務はSEOブログ記事の執筆のみ（他のライティング区分・デザイン以外のカテゴリは試していません）
- 募集文にAI利用の記載が無い場合だけ（明記がある場合は既存記事の型に戻ります）
- 「一言で」の言い直しはコンペ方式のみで試しました（プロジェクト方式では未検証です）
- 制度の有無を直接尋ねた3回も、正確さまでは検証していません

ランサーズの制度そのものが今も同じ内容かは、応募のたびに公式ヘルプで確認してください
（制度は2024年3月時点のプレスリリースが根拠で、更新されている可能性があります）。
