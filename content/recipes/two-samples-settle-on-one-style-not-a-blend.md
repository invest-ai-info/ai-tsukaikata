## これで何ができるか {: .what }

副業のライティングで、クライアントから過去原稿を2本渡され「この文体で書いて」と頼まれることがあります。<mark>2本の見本の文体が違うとき、AIがどちらの文体で書くかは、あらかじめ見分けられます。</mark>

[見本の文章を渡すと文体は再現できる記事](/recipes/writing-style-sample-matches-the-ratio/)は、7〜9文の短い見本で、文末パターンの比率が実物に近い値まで再現されることを確かめました。今回は2つを広げて実測しました。

- 見本を**約850字の長い記事**に広げても、再現の比率は短い見本のときと同程度でした
- 文体が違う**2本の見本を同時に渡す**と、出力は両方の中間ではなく、常に**一方だけ**になりました

<img src="/static/images/mixed-style-sample-lean.svg" alt="長い見本を使った6つの条件で、硬い（のである調）の文末比率を示す表。見本1本（くだけた）だけで書かせた場合は22文中0文（0%）、見本1本（硬い）だけで書かせた場合は20文中17文（85%）、2本同時・くだけた→硬いの順で曖昧に依頼した場合は19文中14文（74%）、2本同時・硬い→くだけたの順で曖昧に依頼した場合は21文中17文（81%）、2本同時で明示的に1つ目（くだけた）だけを使うよう指示した場合は13文中0文（0%）、2本同時で明示的に2つ目（硬い）だけを使うよう指示した場合は14文中11文（79%）。下の枠には、曖昧に頼んだ2条件（74%・81%）は順番を入れ替えても硬い側に近いままであること、くだけた側に寄った回は0回で半分ずつ混ざることは6条件・計112文のどこにも起きなかったこと、見本1本だけの条件どうしでも対称な結果になったことが書かれている。">

<mark class="warn">2本の見本を「この文体で」と曖昧なまま渡すと、くだけた側の文末は3回・3回・計6回とも1文も出ませんでした。</mark>半分ずつ混ざる、という結果は一度も起きていません。見本の順番を入れ替えても（先にくだけた・先に硬いのどちらでも）、硬い側に偏る結果は変わりませんでした。

## 前提 {: .need }

| | |
|---|---|
| かかる時間 | 15分 |
| 費用 | 無料。ブラウザのチャットAIで足ります |
| 必要なもの | 自分（または過去のクライアント案件）が書いた、公開してよい過去の原稿2本以上 |
| プログラミング | **不要**。この記事の指示文をコピーして貼るだけです |

<mark class="warn">この記事が測ったのは「文体の特徴が出力にどれだけ出たか」という機械で数えられる範囲だけです。</mark>見本に使う文章は、自分自身が過去に書いた原稿だけにしてください。他人の文章や著名な書き手の文体の模倣には使わないでください。

副業のライティング全般は[AI原稿の直しを受ける記事](/recipes/fix-ai-drafts-for-pay/)、短い見本での結果は[短い見本ではAIの文体再現が弱まる記事](/recipes/short-sample-still-misses-the-style-ratio/)も参考にしてください。

## AIへの頼み方 {: .ask }

### 1. 長い見本（くだけた調）を1本だけ渡す

約850字・22文の、くだけた「〜んですよね」調のブログ記事を見本にしました。新しい話題は「コーヒーメーカー」です。

<div class="prompt">次の文章は、私が過去に書いたブログ記事です。

うちの近所に新しくできた水族館に行ってきたんですよね。入ってすぐのところにクラゲの大きな水槽があって、ライトの色が変わるたびに雰囲気が違って見えるんですよね。思っていたより空いていて、ゆっくり見られたんです。いちばん気に入ったのはペンギンのコーナーで、ガラスがすごく低いところまであるので、しゃがむと目線が合うんですよね。ちなみに、ペンギンのえさやりは午後2時からと決まっていて、整理券が要るんです。整理券は午前中に無くなることもあるらしいので、早めに行くのがいいんですよね。お土産屋さんでは、ラッコのぬいぐるみが一番人気らしいんです。ちなみに、カフェのメニューにも水族館らしい青いソーダがあって、見た目がきれいなんですよね。出口のところに写真コーナーがあって、無料で撮ってもらえるのもよかったんです。駐車場は少し離れたところにしかないので、電車で行くほうが楽だと思うんですよね。館内はベビーカーでも通れる広さで、段差もほとんど無くて助かったんですよね。途中に休憩用のベンチがいくつもあって、歩き疲れても座れるのがありがたいんです。夏休み期間は激込みになるという話を聞いたので、平日の午前中を選んだんですよね。ちなみに、音声ガイドのアプリを入れておくと、展示の説明が詳しく聞けるんです。イルカのショーは屋外席だと日差しが強いので、屋根のある後方の席がいいんですよね。グッズの価格はそこまで高くなくて、学生でも買いやすい値段だったんです。入り口近くのロッカーは100円で使えて、帰りに返金されるのも地味に助かるんですよね。ちなみに、館内のトイレは思っていたよりきれいで、おむつ替えのスペースもあるんです。スタッフさんがみんな親切で、分からないことを聞くとすぐ丁寧に教えてくれました。一番奥のコーナーには深海生物のエリアがあって、照明が暗めで雰囲気があるんです。滞在時間は3時間くらいが目安で、全部じっくり見るとそれくらいかかります。次に行くときは、夜の特別営業の時間帯を狙ってみたいと思っているんですよね。

この文体で、新商品の「コーヒーメーカー」のレビュー文を200字程度で書いてください。</div>

3回試しました。**3回とも、文末が「んですよね」「んです」で終わる比率は100%**（22文中22文）でした。短い見本（200〜400字）で確かめた前作の77〜100%と、同じ水準です。<mark>見本を長くしても、再現の精度は落ちませんでした。</mark>

## 応用・次の一手 {: .next }

**見本を2本以上渡す場面では、曖昧なまま「この文体で」とだけ頼まないでください。**今回の実測では、常に硬い側に偏りましたが、見本の組み合わせや話題が変われば、どちらに偏るかは変わる可能性があります。偏る方向そのものより、**「中間で混ざらない」「自己申告を信じない」の2点**を持ち帰ってください。

- 使いたい見本を**番号か名前で名指し**する（「1つ目だけ」「◯◯のほうの文体で」）
- 使わない見本は**「参考にしないでください」と明示的に外す**
- どちらを使ったか心配なときは、**出力そのもの**（文末の語尾など）を見て確かめる。AIへの質問では確かめない

[見本の文章を渡すと文体は再現できる記事](/recipes/writing-style-sample-matches-the-ratio/)と[短い見本ではAIの文体再現が弱まる記事](/recipes/short-sample-still-misses-the-style-ratio/)も、同じ文体模倣シリーズの実測です。見本の長さ・本数が変わるたびに、挙動が変わりうることが分かります。

⚠️ **この結果は、くだけた調・硬い調の長い見本2本・計18回の実測です。**「2本渡すと必ず一方に偏る」「硬い側が常に勝つ」と一般化しないでください。試したのは、次の範囲までです。

- 見本はどちらも約850字・20〜22文のみです。もっと短い・もっと長い見本の組み合わせは試していません
- 文体の種類は「くだけた調」と「硬い調」の1組だけです。他の組み合わせ（敬語とぞんざい等）では、どちらに偏るかを含めて未検証です
- 測ったのは文末パターンの比率のみです。語彙の選び方や段落構成までは数えていません
