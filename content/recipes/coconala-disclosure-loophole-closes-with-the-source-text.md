## これで何ができるか {: .what }

[クラウドワークスの著作権は納品しても渡らない](/recipes/crowdworks-copyright-stays-with-you/)は、規約第18条を貼ると、素朴に聞いたときの逆方向の誤りが直ることを確かめました。<mark>今回は別のプラットフォーム（ココナラ）・別のカテゴリ（AIイラスト出品の禁止）で、同じ効き目が出るかを試しました。</mark>

架空の案件文2本（SNSアイコン制作・VTuber立ち絵制作。どちらもAI利用の記載なし）を用意し、「この案件で、AIが生成したイラストをそのまま納品物として出品してよいか」を尋ねました。

<mark class="warn">結論だけを見ると、素朴に聞いた6回もすべて「正解」に見えます。</mark>6回とも「出品は避けるべき」と答えていたからです。ただし理由を読むと、6回とも規約原文を引用していませんでした。そして6回とも「発注者に開示して合意を得れば問題ない」という、規約のどこにも書かれていない救済策を提案していました。規約原文を貼って聞いた10回では、この救済策は10回中1回まで減りました。

実測の根拠は、ココナラ公式ニュース「[ココナラ通信12月号](https://coconala.com/news/917)」の生成AIガイドライン原文です。掲載は2023年12月5日で、2026-10-21に確認しています。

| 原文（抜粋） |
|---|
| 各カテゴリにおけるサービスの信頼性、適正価格を損なう行為につながることは出品者保護の観点から回避したく、**一部カテゴリにおいてAIによる生成イラストそのものを納品物とするサービスの出品を禁止させていただいています。** |

<mark class="warn">この原文には「開示すれば出品してよい」という例外は書かれていません。</mark>一部カテゴリでの出品そのものの禁止であり、発注者への開示や事前合意で解除される規定ではありません。

<mark class="warn">実在の案件文・実在の発注者名は貼らないでください。</mark>この記事は架空の場面を使っています。実在の人物・団体とは関係ありません。

## AIへの頼み方 {: .ask }

### 1. プラットフォーム名を出し、素朴に聞く

架空のSNSアイコン制作案件（ココナラで募集している体裁。AI利用の記載なし）を使いました。

<div class="prompt">この案件で、AIが生成したイラストをそのまま納品物として出品してよいですか。理由も教えてください。</div>

上に続けて、募集文を貼ります。**3回とも、結論は「避けるべき」で正しかったものの、理由には規約原文が一度も出てきませんでした。**代わりに3回とも、「発注者に開示して許可を取れば、リスクが減る・問題が小さくなる」という救済策が含まれていました。

### 2. 同じ聞き方を、別の案件文でも試す

業種が変わっても同じ結果になるかを見るため、VTuberの立ち絵イラスト制作案件でも試しました。

<div class="prompt">この案件で、AIが生成したイラストをそのまま納品物として出品してよいですか。理由も教えてください。</div>

**こちらも3回とも、結論は「避けるべき」で正しかったものの、規約原文は引用されませんでした。**1回は「AIイラスト出品自体がすべて禁止というわけではない」と、はっきり明言していました。2案件・合計6回を通じて、規約原文を引用した回は0回です。「開示すれば足りる」という救済策が出た回は6回でした。

### 3. 規約原文を貼って、同じ質問をする

同じSNSアイコン案件に、ココナラ通信12月号の抜粋を添えます。

<div class="prompt">以下はココナラ公式ニュース「ココナラ通信12月号」の抜粋です。

「各カテゴリにおけるサービスの信頼性、適正価格を損なう行為につながることは出品者保護の観点から回避したく、一部カテゴリにおいてAIによる生成イラストそのものを納品物とするサービスの出品を禁止させていただいています。」

質問: この案件で、AIが生成したイラストをそのまま納品物として出品してよいですか。理由も教えてください。</div>

上に続けて、募集文を貼ります。**5回とも、規約原文を引用して「避けるべき」と答えました。**「開示すれば足りる」という救済策が出た回は0/5でした。

### 4. 規約原文を貼って、VTuber立ち絵案件でも試す

<div class="prompt">以下はココナラ公式ニュース「ココナラ通信12月号」の抜粋です。

「各カテゴリにおけるサービスの信頼性、適正価格を損なう行為につながることは出品者保護の観点から回避したく、一部カテゴリにおいてAIによる生成イラストそのものを納品物とするサービスの出品を禁止させていただいています。」

質問: この案件で、AIが生成したイラストをそのまま納品物として出品してよいですか。理由も教えてください。</div>

**5回とも規約原文を引用して「避けるべき」と答えましたが、1回だけ「発注者に開示すれば最も安全」という救済策が残りました。**2案件×5回＝10回を通じて、規約原文を引用した回は10/10、「開示すれば足りる」という救済策が出た回は1/10でした。

### なぜこの言い方が効くのか

規約原文を貼ると、AIの判断の起点が「一般的なリスク論」から「この規約が何を禁じているか」に変わったと考えられます。実際、原文を貼った回の多くは「出品しようとしているカテゴリが禁止対象かどうかを確認してください」という条件分岐をしていました。原文が示すのは「一部カテゴリ」という範囲の限定で、個別の案件がその対象かどうかまでは書かれていません。この限定を踏まえた言い方になっていたことが、結論の方向だけでなく理由の正確さにもつながったようです。

## うまくいかないときの言い直し方 {: .fix }

### 原文を貼っても、「開示すれば足りる」が1回だけ残った {: .trouble }

10回のうち1回（VTuber立ち絵案件の3回目）は、規約原文を引用したうえで、なお次のように答えました。

> 依頼者に事前開示する。AI生成を一部または全部使う場合は、応募時・受注時にクライアントへその旨を伝え、合意を得るのが最も安全です。

<mark class="warn">規約原文は引用していても、「開示すれば足りる」という結論に戻る回が完全には消えませんでした。</mark>他の9回は「禁止対象であれば…できません」「今回のカテゴリでは不可」のように、カテゴリの禁止を開示とは無関係に扱っていました。規約原文を貼ることは誤りを大きく減らしますが、0にはしません。

まず、規約原文を貼らずに「開示・合意で解除できるか」を名指しで聞くとどうなるかを確かめました。

<div class="prompt">この案件で、AIが生成したイラストをそのまま納品物として出品してよいですか。理由も教えてください。発注者への開示や合意で解除できる規定かどうかにも触れてください。</div>

**2回とも、「発注者への事前開示と同意があれば問題は基本的に解消します」と、はっきり断定しました。**規約原文を貼っていないのに、「開示・合意で解除できるか」という聞き方自体では誤りは直りませんでした。

次に、規約原文を貼ったうえで、同じ質問をしました。指示文2で1/10に残っていた誤りが直るかを確かめるためです。

<div class="prompt">以下はココナラ公式ニュース「ココナラ通信12月号」の抜粋です。

「各カテゴリにおけるサービスの信頼性、適正価格を損なう行為につながることは出品者保護の観点から回避したく、一部カテゴリにおいてAIによる生成イラストそのものを納品物とするサービスの出品を禁止させていただいています。」

質問: この案件で、AIが生成したイラストをそのまま納品物として出品してよいですか。理由も教えてください。発注者への開示や合意で解除できる規定かどうかにも触れてください。</div>

**2回とも、「発注者が合意しても、ココナラの規約違反状態は解消されない」とはっきり書きました。**「開示すれば足りる」という救済策は、この2回には出ませんでした。**毎回の答えを、思い込みで信じないほうが安全です。**

## 応用・次の一手 {: .next }

**結論だけでなく、理由に規約原文が引用されているかまで確認してください。**今回の実測では、結論（避けるべき）だけを見ると素朴な聞き方でも全問正解に見えました。理由を読まなければ、6回とも作り話の救済策が混ざっていたことに気づけません。

[クラウドワークスの著作権は納品しても渡らない](/recipes/crowdworks-copyright-stays-with-you/)という記事があります。あちらで「さっきの回答は規約を確認したうえでのものか、それとも推測か」と聞き直すと、AIが「未確認の推測でした」と自分から認めています。規約の中身を確かめたいときは、AIの記憶に頼らず、自分でそのプラットフォームの公開ガイドラインページを開いて確認してください。

⚠️ **この結果は、ココナラという1つのプラットフォーム・この1つの規約文・合計16回の実測です。**他のプラットフォームや他の規約文で同じ比率になるとは限りません。試したのは、次の範囲までです。

- 質問文は「そのまま納品物として出品してよいか」の1種類のみ（別の聞き方は試していません）
- 誤りの型は「開示すれば足りる」のみを数えました。「禁止されていない」という逆方向の誤りは、今回の2材料・この質問文では出ませんでした
- 原文は1文のみ貼りました。原文をもっと長く（前後の文脈つきで）貼った場合は試していません

今回の生の返り16回ぶんは `docs/evidence/coconala-disclosure-loophole-closes-with-the-source-text.md` に全文置いてあります。
