## これで何ができるか {: .what }

<mark>法人から個人へ原稿料・デザイン料を直接支払う契約では、プラットフォームの手数料とは別に、所得税の源泉徴収が発生します。</mark>これまでの手取り計算の記事は、クラウドワークス・ランサーズなどのプラットフォーム経由でした。天引きの対象は、システム利用料と消費税だけでした。この記事は、プラットフォームを使わずに法人から直接受け取る場面を試します。

架空の業務委託契約4種を用意し、「この契約の手取り額を計算してください」と試しました。

- **原稿料30万円・源泉徴収義務の明記あり**——5回とも正解269,370円
- **デザイン料130万円・100万円の段階を跨ぐ**——5回とも正解1,136,640円
- **原稿料30万円・源泉徴収義務の明記なし**——それでも5回とも正解269,370円
- **デザイン料100万円ちょうど（税率の境界値）**——3回とも正解897,900円

<mark class="warn">「明記しないと見落とすのでは」という心配は、この5回では当たりませんでした。</mark>原稿料という業務の性質と「法人から個人への直接支払い」という状況だけで、AIは自分から根拠の法律を挙げて源泉徴収を適用しました。

[プラットフォームの段階制手数料から手取りを出す記事](/recipes/take-home-from-the-contract-amount/)は、クラウドワークス型・ランサーズ型の計算を確かめています。どちらも「源泉」という語は一度も出てきません。この記事はその外側にある、もう一段の天引きを試します。

## 前提 {: .need }

| | |
|---|---|
| かかる時間 | 20分 |
| 費用 | 無料。ブラウザのチャットAIで足ります |
| 必要なもの | 業務委託契約書（支払金額・直接契約の旨） |
| プログラミング | **不要**。この記事の指示文をコピーして貼るだけです |

<mark class="warn">実在の取引先名・実在の金額は貼らないでください。</mark>この記事は架空の社名・金額を使っています。実在の人物・団体とは関係ありません。

この記事は「手取り額を計算できるか」という実測に絞っています。確定申告のやり方（源泉徴収された分の精算・還付）や、インボイス制度の免税事業者としての是非には踏み込みません。消費税をどちらに当てはめるかで段階制の計算が揺れるかは[別の記事](/recipes/pick-where-tax-applies-and-it-holds/)で確かめています。

## AIへの頼み方 {: .ask }

### 1. 原稿料30万円、源泉徴収義務を明記した契約で聞く

法人が個人のライターへ、原稿料30万円を直接支払う架空の契約です。契約書の備考欄に、源泉徴収義務がある旨を明記しています。

<div class="prompt">この契約の手取り額を計算してください。</div>

上に続けて、契約書を貼ります。

**5回とも「手取りは269,370円」と正しく計算しました。**式は300,000円×10.21%＝30,630円。300,000−30,630＝269,370円です。5回とも、この式を明示しています。契約書に税込・税抜の記載が無いことにも自分から気づき、税抜だった場合の金額（299,370円）まで併記していました。

### 2. デザイン料130万円、100万円の段階を跨ぐ契約で聞く

次はデザイン料130万円という、源泉徴収の税率が途中で変わる金額です。100万円以下の部分は10.21%、100万円を超える部分は20.42%という2段階の税率が適用されます。

<div class="prompt">この契約の手取り額を計算してください。</div>

**5回とも「手取りは1,136,640円」と正しく計算しました。**100万円以下の部分は102,100円、超える30万円の部分は61,260円です。5回とも、この2つを分けて計算し、合計163,360円を源泉徴収する式を示しています。

### 3. 源泉徴収義務を明記しない契約でも聞く

ここまでは契約書に「源泉徴収義務があります」と明記していました。この一文を削除し、「法人が個人へ原稿料を直接支払う」という事実だけを残した契約で、同じ指示文を試しました。

<div class="prompt">この契約の手取り額を計算してください。</div>

**こちらも5回とも「手取りは269,370円」と、明記ありの版とまったく同じ結果になりました。**5回とも「原稿料は所得税法204条1項1号の報酬・料金にあたる」と、自分から法律名を挙げました。そのうえで、源泉徴収を適用しています。<mark>明記が無くても、業務の性質（原稿料・デザイン料）と支払いの形（法人から個人への直接支払い）だけで、見落としは起きませんでした。</mark>

### 4. 100万円ちょうどの境界値で聞く

税率が10.21%から20.42%に変わる境目は、ちょうど100万円です。境目そのものの金額（1,000,000円）で試すと、誤って高い税率側に踏み込まないかを確かめました。

<div class="prompt">この契約の手取り額を計算してください。</div>

**3回とも「100万円ちょうどなので、すべて10.21%が適用されます」と明示し、正しく897,900円に到達しました。**100万円を1円でも超えた場合だけ超過分に20.42%がかかることも、3回とも自分から補足していました。

## うまくいかないときの言い直し方 {: .fix }

### 税込か税抜かが分からないとき {: .trouble }

4回の実測すべてで、契約書の金額が税込か税抜かの記載が無いことが共通の課題になりました。AIはこの不明点を無視せず、毎回両方のケースを計算して見せていました。「税込です」と先に伝えると、どうなるかを試しました。

<div class="prompt">この契約の金額は税込です。この前提で、手取り額を計算してください。</div>

**2回とも、269,370円という同じ結論にまず到達しました。**ただし2回とも、もう一歩先まで補足しています。請求書で消費税額を区分して書けば、源泉徴収の対象が税抜部分だけになり、手取りが2,785円多くなる（272,155円）という計算です。<mark>「税込」と伝えても、請求書の書き方という別の変数が残っていることまで教えてくれました。</mark>

## 応用・次の一手 {: .next }

**直接契約が増えてきたら、契約のたびに同じ手順で確認できるようにしておくと安心です。**

<div class="prompt">法人から直接、原稿料やデザイン料を受け取る契約が増えてきました。契約ごとに源泉徴収の対象かどうかと、正しい手取り額を毎回確認したいです。プログラミングはできません。私が契約のたびに確認することを、番号を振って箇条書きで教えてください。</div>

2回試したところ、手順の数（11個と10個）は違いましたが、次の骨格は共通していました。

- まず、報酬の種類が源泉徴収の対象業務かどうかを確認する（原稿料・デザイン料・講演料などは対象、システム開発などは対象外になりやすい）
- 請求書で、報酬額・消費税・実費（交通費など）を区分して記載してもらう
- 100万円以下の部分と超える部分で税率を分けて（10.21%／20.42%）源泉徴収税額を計算する
- 入金された金額と、計算した手取り額が一致するか照合する
- 年明けに支払調書を受け取り、確定申告の記録として残す

**源泉徴収された分は所得税の前払いです。**確定申告で、その年の所得税額と精算されます。[副業の手取りを契約額から出す記事](/recipes/take-home-from-the-contract-amount/)と合わせて読むと、プラットフォーム経由か直接契約かで天引きの種類が違うことが分かります。思ったより少ない入金にも慌てずに済みます。

⚠️ **この結果は、この4種類の架空契約・合計22回（言い直し2回・応用2回を含む）の実測です。**「どんな報酬でも源泉徴収は必ず正しく計算される」と一般化しないでください。試したのは、次の範囲までです。

- 報酬の種類は原稿料・デザイン料のみ（講演料・翻訳料・著作権の使用料など、他の対象業務は試していません）
- 1回の支払い単位で計算（分割払いや、複数月の報酬をまとめて支払う場合は未検証です）
- 消費税の課税事業者・インボイス登録の有無による違いは、本文中の補足以上には踏み込んでいません

税率や源泉徴収の対象範囲は制度が変わることがあるため、実際の契約では国税庁の最新情報で確認してください。
