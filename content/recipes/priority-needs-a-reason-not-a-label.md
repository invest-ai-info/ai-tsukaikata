## これで何ができるか {: .what }

AIにタスクの並べ替えを頼むと、締切ばかりが優先されて重要度は軽く扱われる、とよく言われます。<mark>実際に試すと、答えは「材料の書き方しだい」でした。</mark>プログラミングは要りません。

<mark class="warn">重要度を「高・中・低」のラベルだけで渡すと、締切が近い軽い仕事4件が、締切は先でも重大な仕事4件に必ず勝ちました。4回ともです。</mark>タスクの説明文に「遅れると何が起きるか」を一文添えるだけで、この結果は完全に逆転しました。

|---|---|---|
| 理由の一文あり（なぜ重要か・なぜ軽微か） | 「優先順位をつけて並べ替えて」だけ | **64／64組（100%）** |
| 理由の一文あり | 「重要度も踏まえて」と一言追加 | **64／64組（100%）・変化なし** |
| 「重要度：高・中・低」のラベルだけ | 「優先順位をつけて並べ替えて」だけ | **0／32組（0%）** |
| 「重要度：高・中・低」のラベルだけ | 「重要度も踏まえて」と一言追加 | **0／32組（0%）・変化なし** |

**この記事は、AIに実際にタスクを並べ替えさせた実測の記録です。**架空のタスク一覧を使っており、特定の会社の実例ではありません。

## 前提 {: .need }

- 毎回AIに、締切のあるタスクの一覧を優先順位づけさせている（受信箱の仕分け・日々のToDo整理など）
- 「重要度も踏まえて並べ替えて」のような一言を足せば安全、と思っている
- タスクの説明を「重要度：高」「重要度：低」のようなラベルだけで渡していることがある

この記事は、優先順位づけの基準そのものを作る話ではありません。**「重要度も踏まえて」という指示の一言が、実際に締切より重要度を優先させるのか**、その1点だけを試しています。

- 1回目: TB1〜TB4は1〜5位・TA1〜TA4は17〜20位
- 2回目: TB1〜TB4は1・2・5・10位・TA1〜TA4は12〜15位

### 「重要度も踏まえて」と言っても、締切の近さに負ける {: .trouble }

この記事の実測では、材料に「なぜ重要か」の理由が書かれていないかぎり、指示文をどれだけ強めても直りませんでした。**効いたのは指示文ではなく、タスクの説明そのものに理由の一文を足すことです。**指示文4・5を、理由つきの指示文1・2の書き方に戻すと、16組×8回で逆転ゼロという結果に戻りました。

自分の受信箱やToDoリストをAIに渡すときも同じです。**「重要度：高」とだけ書いたタスクより、「これが遅れると何が起きるか」を一言添えたタスクのほうが、正しく優先されます。**

### 理由の一文を、全部のタスクに書くのは大変 {: .trouble }

<mark class="warn">これは、この記事では試していません。重要度が高いタスクにだけ理由を書き、低いタスクはラベルのままにしたらどうなるかは未確認です。</mark>「高」だけに理由を足せば十分なのかも分かりません。**確かめずに「一部だけでよい」とは書けないので、次に試すことの1つとして残します。**

## 応用・次の一手 {: .next }

**この記事は、「AIに優先順位を任せると締切に引っ張られる」という定説を、実際に試しに行った記録です。**この材料・この回数では、答えは「引っ張られるかどうかは材料しだい」でした。
