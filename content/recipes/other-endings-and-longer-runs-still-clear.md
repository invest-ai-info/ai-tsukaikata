## これで何ができるか {: .what }

<mark>クラウドソーシングで「AI感をなくして人間らしく」と求められたとき、文末表現の不自然な繰り返しが素朴な頼み方だけで直るか実測しました。</mark>条件は[前の記事](/recipes/rewrite-clears-sentence-ending-repeats/)より強くしています。前の記事は文末表現2種（「〜のです」「〜ください」）・連続4回までしか試していないと、自分で宿題として残していました。今回は、**新しい文末表現2種**（「〜でしょう」「〜と思います」）と、**既出の文末表現を5回・6回に増やした版**の、合計4種類の下書きで試しました。

**架空の下書き4本に、文末表現の連続を仕込みました。**素朴に「人間らしく書き直して」と頼んだ計12回（4本×3回）は、<mark>12回とも文末の3回以上連続が解消しました。</mark>「3回以上連続で使わないでください」という一文を足した3回（6回連続の下書きのみ）も、結果は同じでした。

## AIへの頼み方 {: .ask }

### 1. 新しい文末表現「〜でしょう」が4回連続する下書きで試す

新人研修の挨拶文を想定し、「〜でしょう」で終わる文を4回連続させました。

<div class="prompt">次の文章を、AIが書いたような文章ではなく人間らしい文章に書き直してください。</div>

上に続けて、下書きを貼ります。

```
来週から新しい部署に配属されることになりました。初めての業務にはきっと戸惑うことも多いでしょう。
周りの先輩方も最初は同じように苦労されたでしょう。わからないことがあれば、遠慮なく質問するのがよいでしょう。
少しずつ慣れていけば、仕事の流れも見えてくるでしょう。
```

**3回とも、文末の3回以上連続は解消しました。**文末の変え方は回ごとに違いました。

- 1回目：「異動します」「多いと思います」「聞いていこうと思います」「見えてくるはずです」と変化
- 2回目：「異動します」「あります」「聞いていこうと思います」「見えてくるはずです」と変化
- 3回目：「異動します」「多いと思います」「苦労してきたはずです」「聞こうと思います」「見えてくるはずです」と変化

### 2. 新しい文末表現「〜と思います」が4回連続する下書きで試す

出張報告の所感を想定し、「〜と思います」で終わる文を4回連続させました。

<div class="prompt">次の文章を、AIが書いたような文章ではなく人間らしい文章に書き直してください。</div>

```
今回の出張では、新しい取引先との関係を築けたと思います。先方の要望を直接伺えたのは有意義だったと思います。
今後の提案に活かせる情報も得られたと思います。次回はもう少し準備期間を長く取るべきだと思います。
```

<mark>こちらも3回とも、文末の3回以上連続が解消しました。</mark>文末表現2種（「〜でしょう」「〜と思います」）×3回＝6回とも、素朴な指示だけで3回以上連続が残った回は0件です。

### 3. 既出の文末表現を5回連続に増やした下書きで試す

前の記事は「〜のです」を4回連続までしか試していません。清掃当番の引き継ぎメモを想定し、5回連続に増やしました。

<div class="prompt">次の文章を、AIが書いたような文章ではなく人間らしい文章に書き直してください。</div>

```
今月から清掃当番のやり方を少し変更するのです。まず入口付近から掃き始めるのです。
次に机の上を乾いた布で拭くのです。ゴミ袋は毎回新しいものに交換するのです。
最後に換気のため窓を少し開けておくのです。
```

**3回とも解消しました。**2回は「ます」で終わる文末に統一し、1回は文末をそれぞれ違う形に散らしました。5回連続に増やしても、4回連続のときと同じ結果です。

### 4. 既出の文末表現を6回連続に増やした下書きで試す

忘年会の案内文を想定し、「〜ください」を6回連続させました。前の記事で試した最大（4回）より2回多い、この記事で最も極端な仕込みです。

<div class="prompt">次の文章を、AIが書いたような文章ではなく人間らしい文章に書き直してください。</div>

```
忘年会の出欠は今週中に回答してください。会場の変更があれば必ず確認してください。
アレルギーがある方は事前に伝えてください。遅刻する場合は幹事に連絡してください。
会費は当日受付で渡してください。写真撮影が苦手な方は一声かけてください。
```

<mark>6回連続という、この記事で最も極端な仕込みでも、3回とも文末の3回以上連続は解消しました。</mark>文末表現2種・連続回数2種（5回・6回）を合わせた12回すべてで、3回以上連続が残った回は0件です。

### なぜ、新しい文末表現・長い連続でも消えるのか

**「人間らしく書き直して」という指示は、特定の文末表現や連続回数を名指ししていません。**文の構造そのものを組み替える指示だと考えられます。前の記事は文末表現2種・連続4回までの検証でした。今回は文末表現を変えても、連続回数を6回まで増やしても、同じ天井（3回以上連続0件）に達しました。**狭い範囲でしか試していない結果が、もっと広い範囲でも成立していた**という形です。

## うまくいかないときの言い直し方 {: .fix }

### 「3回以上禁止」を明記すると、6回連続でも違いが出るか {: .trouble }

最も極端な材料（6回連続）で、機械的なルールを明記した場合と比べました。

<div class="prompt">次の文章を、AIが書いたような文章ではなく人間らしい文章に書き直してください。同じ文末表現（「〜でしょう」「〜ます」など）を3回以上連続で使わないでください。</div>

```
忘年会の出欠は今週中に回答してください。会場の変更があれば必ず確認してください。
アレルギーがある方は事前に伝えてください。遅刻する場合は幹事に連絡してください。
会費は当日受付で渡してください。写真撮影が苦手な方は一声かけてください。
```

**3回とも文末の3回以上連続は解消し、素朴な指示と同じ結果でした。**

<figcaption>6回連続でも、禁止の一文を足すかどうかで結果は変わりませんでした。</figcaption>

<mark class="warn">連続回数を前の記事の1.5倍（4回→6回）に増やしても、「3回以上連続を禁じる」という機械的ルールの上乗せ効果は確認できませんでした。</mark>前の記事は「連続回数が多いと禁止の一文が効いてくるかもしれない」という可能性を残していました。6回連続という最も極端な条件でも、素朴な指示と同じ天井に達しています。

## 応用・次の一手 {: .next }

この実測の範囲では、**文末の繰り返しだけが心配なら、文末表現の種類や連続回数を気にして指示文を調整する必要はなさそうです。**「人間らしく書き直して」という素朴な一言で、新しい文末表現でも、6回連続でも解消しました。

毎回同じ下調べをするのが面倒なら、確認の手順そのものを聞いておくと役に立ちます。

<div class="prompt">クラウドソーシングで「AI感をなくして人間らしく書き直してください」という納品前の検品をするとき、文末表現の不自然な繰り返しが残っていないかを確認する手順を、番号を振って教えてください。プログラミングはできません。</div>

2回試したところ、どちらも前の記事と同じ2つのコツを含んでいました。

- 「文末だけを縦に並べて目で確認する」
- 「音読して引っかかる箇所を探す」

加えて、「最初に書き直しを依頼し、そのあとに確認する」という順番も自分から含めていました。

同じ検品の副業で、禁止語リストそのものの効き方は[先行記事](/recipes/ai-smell-clears-before-the-list/)に、発注前の内容確認は[発注書どおりに検品する記事](/recipes/writing-check-against-spec/)にまとめています。

⚠️ **この結果は、架空の下書き4本・計15回（素朴な指示12回・禁止を明記した指示3回）での実測です。**「文末の繰り返しは、どんな条件でも必ず消える」と一般化しないでください。試したのは、次の範囲までです。

- 文末表現は「〜でしょう」「〜と思います」「〜のです」「〜ください」の4種のみです。他の文末表現は試していません
- 連続回数は4回・5回・6回のみです。7回以上の極端な繰り返しは試していません
- 1本の下書きに仕込んだ連続は1種類のみです。複数の文末表現が別々に3回以上連続する場合は試していません
