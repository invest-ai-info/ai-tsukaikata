## これで何ができるか {: .what }

noteの記事やKindle本のタイトルを決めるとき、AIに「案を100個出して」と頼んだことはありませんか。並んだ100行を見ると、選び放題に見えます。<mark>しかし実際に選べる案は、見た目ほど多くありません</mark>。

架空のnote記事テーマ（在宅勤務の集中力）とKindle本テーマ（スマホで撮る料理写真）の2本で、「タイトル案を100個出してください」を1回ずつ試しました。返ってきた200件は、言い回しの近さをdifflibで測り、似たものを同じ組にまとめてPythonで機械的に判定しました。結果は3行で言えます。

1. **件数はいつも頼んだとおり。**2本とも100件ちょうど返ってきました
2. **しかし実質の種類数は35〜36件です。**似た言い回しをまとめると、<mark class="warn">100件のうち6割以上が同じ発想の言い換えでした</mark>
3. **減り方は一様ではありません。**前半50件は新しい発想が30件前後出るのに、<mark>後半50件になると新しい発想は3〜5件しか出ません</mark>。残りは全部、前半で出た発想の言い回し違いです

この記事では、まず素朴な頼み方の実態を見せます。そのあと、**件数を減らす代わりに密度を上げる頼み方**と、**件数を保ったまま密度も上げる頼み方**の2つを試した結果を載せます。どちらも、読んで試せる指示文の形にしてあります。

この記事はタイトルを**選ぶ**前の下ごしらえです。選んだタイトルをそのまま使うかどうかは、[「それはAIには難しいです」と言われた](/recipes/find-what-to-delegate/)と同じく、最後は自分で決めてください。実測に使った架空テーマと、判定コードの全文は `docs/evidence/title-brainstorm-real-count.md` にあります。

## AIへの頼み方 {: .ask }

### 1. 素朴に「100個出して」——件数は合うが、中身の密度は見えない

まずは、ありがちな頼み方そのままです。

<div class="prompt">在宅勤務で集中力を保つ工夫について書いたnote記事の、売れるタイトル案を100個出してください。1行に1案ずつ書いてください。</div>

100件ちょうど返ってきました。ただし先頭と末尾を見比べると、違いがはっきりします。

> 1件目: 在宅勤務でも集中力が切れない7つの習慣
> 100件目: 集中力を保つ在宅勤務のための工夫、まとめてみました

<mark class="warn">末尾のほうは「集中力を保つ」「在宅勤務」「工夫」という同じ単語の並び替えです</mark>。Kindle本テーマ（スマホで撮る料理写真）でも、1回試して同じ崩れ方をしました。**件数を見ているだけでは、この崩れには気づきません**。

### 2. 言い換えをまとめさせて、実質の数を聞く

数える前に、AI自身にもまとめさせてみます。

<div class="prompt">いま出した100件のタイトル案を、言い回しが似ているものどうしでまとめてください。まとめたあと、実質何種類になったか数字で書いてください。</div>

この頼み方は読者も今すぐ試せます。<mark class="warn">ただし、本人の数え方を鵜呑みにしないでください。</mark>本記事の実質の種類数（35〜36件）はPythonで機械的に数えた数で、AI自身への自己申告だけに頼っていません。人が読み直して数えても、AIが数えても、最後はコードで裏取りするのが確実です。

### 3. 「言い換え禁止・無理に埋めない」——密度はほぼ100%、件数は減る

次に、件数より中身の濃さを優先する頼み方です。

<div class="prompt">在宅勤務で集中力を保つ工夫について書いたnote記事の、売れるタイトル案を出してください。ただし、結び方(「〜のコツ」「〜のまとめ」「〜入門」など語尾のパターン)を2回以上使わないでください。新しい切り口が思いつかなくなったら、数を埋めるために言い換えを足さず、「ここから先は言い換えになります」と正直に書いて、そこで止めてください。</div>

note記事テーマは**23件で自分から打ち切り**ました。Kindle本テーマ(スマホ料理写真)も**22件で打ち切り**ました。Pythonで判定すると、実質の種類数はnote記事テーマが23件中20件(87%)、Kindle本テーマが22件中22件(100%)です。

<figure class="figure">
<img src="/static/images/title-honest-stop-density.svg" alt="「100個出して」と「言い換え禁止・無理に埋めないで」を比べた図。「100個出して」は出てきた件数100件に対し実質の種類数は35〜36件(密度35〜36%)。「言い換え禁止・正直に打ち切ってよい」は出てきた件数が22〜23件に減る代わりに、実質の種類数は20〜22件(密度87〜100%)に上がる。数を求めると埋め草が増え、正直さを求めると出てくる件数そのものは減るというのが、この記事の比較の軸。note記事テーマは23件中20件(87%)、Kindle本テーマは22件中22件(100%)が実質の種類数だった。">
<figcaption>件数を求めると埋め草が増え、正直さを求めると件数そのものが減ります。</figcaption>
</figure>

<mark>100件欲しいのか、本物の候補が欲しいのかで、頼み方は変わります</mark>。選ぶ作業だけを考えるなら、23件で全部本物のほうが、100件のうち65件が言い換えより選びやすいです。

### 4. それでも件数が欲しいなら、切り口を先に割り振る

件数と密度の両方が欲しいときの頼み方です。先に「どんな角度で書くか」を決めてから、角度ごとに数を割り振ります。

<div class="prompt">在宅勤務で集中力を保つ工夫について書いたnote記事のタイトル案がほしいです。まず次の5つの切り口で、1つずつ案を考えてください。

1. 数字訴求(「3つの」「7つの」のように具体的な数を見せる)
2. 疑問形(「〜なのか」で終わる)
3. 体験談(「私が」で始める)
4. 警告・逆説(常識と違うことを言う)
5. 比較(2つのものを比べる)

切り口が決まったら、それぞれの切り口で10案ずつ、合計50案出してください。どの案がどの切り口か、見出しを付けて分けてください。</div>

note記事テーマで1回試しました。50件中、Pythonの判定で**実質43件(86%)**が別物でした。しかも<mark>前半25件・後半25件で新しい発想の出方がほぼ同じ</mark>(21件・22件)です。素朴に100個出させたときの「後半は言い換えばかり」という崩れが、起きませんでした。

⚠️ この4番だけは、note記事テーマ1本・1回の実測です。Kindle本テーマでは試していません。**切り口を先に割ると密度が上がる、という傾向として読んでください**。

## うまくいかないときの言い直し方 {: .fix }

### 100件のうち、どれが本物でどれが言い換えか分からない {: .trouble }

全部を読み比べるのは大変です。先頭と末尾だけでなく、通しで聞いてみます。

<div class="prompt">いま出した100件を、出てきた順のまま1件ずつ見ていってください。直前までに出た案と発想が重なるものには「※言い換え」と印をつけてください。重ならない、新しい発想のものだけ、そのまま残してください。</div>

この頼み方自体は読者も試せます。<mark class="warn">印をつける作業もAI自身の判断なので、結果を鵜呑みにせず、残った案の数が実際に少ないかをざっと見てください。</mark>件数が怪しいと感じたら、2番の「まとめさせる」頼み方と両方試して、数字が近いかを確かめてください。

### 50案・100案と頼むと、途中から案ではなく感想が混ざる {: .trouble }

件数を多く頼むと、まれに「〜という案もありますが、やや弱いかもしれません」のような感想が本文に混ざります。

<div class="prompt">案だけを1行に1つ、番号を振って出してください。説明や感想は書かず、タイトルの文字列だけにしてください。</div>

### 切り口を割り振っても、切り口の中で似た案が出る {: .trouble }

4番の頼み方でも、同じ切り口の中で近い案が出ることがあります(実測でも「在宅勤務の集中力を保つ7つの習慣」と「在宅勤務の集中力、朝の3分習慣が効く」が、どちらも数字訴求の切り口の中で同じ組になりました)。

<div class="prompt">いま出た数字訴求の切り口の10案を見てください。このうち、言い回しが近いものを教えてください。近いものがあれば、その案を別の数字・別の事実に差し替えてください。</div>

**切り口を割っても、切り口の中は別にチェックしてください**。角度を分けるのは全体の密度を上げる工夫であって、個々の重なりまで消すわけではありません。

## 応用・次の一手 {: .next }

**同じ案件が続くなら、この頼み方を型にして保存します。**

<div class="prompt">いまのやり取り(切り口を5つ決めてから、各切り口で案を出す)を、次のテーマでもそのまま使える手順にしてください。テーマを差し替える場所だけを空欄にしてください。</div>

この型は、タイトルだけでなく[同じ処理を複数の対象にまとめて頼む](/recipes/batch-instead-of-repeat/)の考え方とも相性が良いです。切り口を先に決めるのは、対象を先に並べてから同じ処理をかけるのと同じ発想です。

**案の数そのものの数え方は、コピー案でも同じ崩れ方をします。**「30案出して」のあとに「もう30案」と頼んだときの重なり方は、[コピー案を30から60に増やす](/recipes/second-thirty-not-new/)に実測があります。あちらは**2回に分けて頼む**崩れ方、この記事は**1回で大量に頼む**崩れ方です。どちらも、AIが新しい発想を使い切ったあとは言い換えで埋める、という同じ性質から来ています。

<mark>「何個出た」ではなく「何種類出た」を見てください</mark>。見る軸を変えるだけで、選ぶ時間は短くなります。
