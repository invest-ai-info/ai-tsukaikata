## これで何ができるか {: .what }

[毎日の追記を同じ形にそろえる](/recipes/daily-append-same-shape/)は、ファイルに書式のお手本を1行置けば、追記が3日とも規定の形にそろうことを確かめました。ただし末尾でこう書いて止まっていました——「この実測は3回転までしか測っていません。4日目・10日目・50日目にどうなるかは、この記事は何も言っていません」。

<mark>この記事で10回転・50回転まで測りました。</mark>結論は2つです。

1. **形（区切り記号・日付のケタ・末尾の単位）は、10回でも50回でも崩れません。**試し方は次の3つです。
   - 架空の記録2本（副業の作業記録／家計の買い物メモ）
   - それぞれ2回ずつ、同じ指示文のまま50回転（合計200回）
   - 前の日の返りを、そのまま次の日の入力にする
   <mark>**結果は200回中200回、規定の形のままでした。**</mark>
2. <mark class="warn">ただし走り書きが「本日◯◯でした」のように日付を書かない日だけ、追記された日付の値がファイルの続きの日ではなく、呼び出した実際の日（2026-10-09）に化けました。</mark>これは**46回中46回**で起きています。しかも区切り記号も日付のケタ数も他の行と同じなので、1番の「形」の検査では一度も引っかかりません。

## 前提 {: .need }

| | |
|---|---|
| かかる時間 | 20分。指示文に1行足すだけです |
| 費用 | 無料。無料のチャットAIで足ります |
| 必要なもの | ブラウザで使えるAI（ChatGPT・Claude・Geminiなど）と、毎日1行ずつ追記しているテキストファイル |
| プログラミング | **不要**。ファイルはメモ帳で作れるただのテキストです |

⚠️ **[毎日の追記を同じ形にそろえる](/recipes/daily-append-same-shape/)を先に読んでください。**そちらは「指示文で書式を説明するか、ファイルにお手本を1行置くか、どちらでも3日とも12回中12回そろう」ことを確かめています。この記事は、その先に残った**回数（時間軸）という1つの未測定事項**だけに答えます。

📌 **この記事の数字は、すべて架空データでの実測です。**走り書きにも、日付にも、半角スラッシュと半角カンマは1文字も入れていません。**2026-10-09という日付だけは本物**です。実測を回した日（2026年10月9日）そのものが、この記事の核心になっています。

## AIへの頼み方 {: .ask }

### 1. 同じ指示文のまま、50回転させる

[毎日の追記を同じ形にそろえる](/recipes/daily-append-same-shape/)の3番（ファイルにお手本を1行だけ置き、指示文には書式を1文字も書かない版）を、そのまま50回続けました。指示文は一度も変えていません。

<div class="prompt">下の「記録ファイル」の末尾に、【今日ぶん】を1行だけ追記してください。すでにある行は1文字も変えないでください。更新後のファイル全体を、コードブロックで出してください。</div>

このあとに `【今日ぶん】` として、その日の走り書きを1行、`【記録ファイル】` としてファイルの中身をそのまま貼ります。ファイルの初日は見出し1行とお手本1行だけです。走り書きは5つの書き方を順番に回し、実際の記入にありうる揺れを持たせました。

- 「。」で区切る書き方
- 「2026年8月2日」のような和暦ふうの書き方
- 「8/3」のような短い書き方
- 「本日◯◯でした」のように日付を書かない書き方
- 読点で区切る書き方

**材料は2本（副業の作業記録／家計の買い物メモ）。**それぞれ2回ずつ、独立した新規プロセス（`claude --safe-mode --tools ""`）で50回転させました（4系列×50回＝合計200回）。前の日の返り（コードブロックの中身）を、そのまま次の日の入力にしています。自動実行では返事の文章は捨てられ、ファイルだけが翌日に渡るためです。

### 2. 10回目・50回目でも、形は崩れていません

<div class="prompt">下の「記録ファイル」の末尾に、【今日ぶん】を1行だけ追記してください。すでにある行は1文字も変えないでください。更新後のファイル全体を、コードブロックで出してください。</div>

50回目まで、**指示文はこの1文字も変えていません。**それでも、次の3つは200回中200回、規定どおりでした。

- 区切り記号（半角スラッシュ）
- 日付の書き方（西暦4桁-月2桁-日2桁）
- 末尾の単位（「分」「円」）

すでにある行が1文字でも変わった回も200回中0回です。[見本は100行あっても的中は4分の3](/recipes/more-example-rows-lower-the-hit-rate/)は「ファイルが大きくなったとき」を測った記事です。あちらは一度に100行へ増やして測りましたが、この記事は**1行ずつ自然に増えていく実際の連鎖**で測った点が違います。形についての結論は同じでした——**崩れない**、です。

### 3. 「本日」とだけ書いた日だけ、日付の値が壁時計の実日付に化ける

ここがこの記事の芯です。走り書きの5パターンのうち1つは、日付を書かずに「本日」で済ませる形にしました。

> 本日F社向けに記事の下書き、所要50分でした。

ファイルの続きとしては、この行の日付は前の行の翌日（たとえば2026-08-04）になるはずです。ところが、**4系列・のべ40回ぶんの「本日」の走り書きは、40回とも日付が2026-10-09になりました。**これは、この記事を実測した日そのものです。

<mark class="warn">さらに、ファイルが1行しかない最初の状態（連鎖の長さと無関係）でも、同じことが起きます。</mark>見本1行だけのファイルに「本日」の走り書きを渡す単発の呼び出しを6回試したところ、**6回とも2026-10-09になりました。**合わせて**46回中46回**です。

🔑 **AIは間違えて日付を忘れたわけではありません。**「本日」を、ファイルの続きの日付ではなく、**自分が呼び出された本物の今日**だと正しく認識して書いています。問題は、その「本物の今日」が、架空の記録ファイルが進んでいる「物語の中の今日」とは違うことです。

### 4. 「形がそろっているか」と聞く点検は、この事故に気づきません

[毎日の追記を同じ形にそろえる](/recipes/daily-append-same-shape/)の「言い直し方」は、別の新しい会話にファイルを渡して、形がそろっていない行を探す点検を提案していました。

<div class="prompt">下のファイルは、毎日1行ずつAIに追記しているものです。行の形（区切り記号・日付の書き方・末尾の単位）がそろっていない行があれば、その行をそのままコピーして挙げてください。1行もなければ「ありません」とだけ書いてください。</div>

10回目・50回目のファイル（4系列×2つの時点＝8回）をこの点検にかけたところ、**8回とも「ありません」でした。**2026-10-09の行は、区切り記号も日付のケタ数も他の行とまったく同じなので、「形」の点検では異常に見えないためです。

**同じ8回を、わざと1行だけ区切り記号をカンマに変えた版で試すと、8回とも正しくその1行を見つけました。**つまり点検そのものが壊れているわけではありません。**聞いた形（区切り記号）には効くが、聞いていない日付の値のズレには答えない**、というだけです。

### 5. 聞き方を「日付の順番」に変えると、同じ8回で見つかる

<div class="prompt">下のファイルは、毎日1行ずつAIに追記しているものです。各行の日付が、前後の行と比べて順番から外れていないか確認してください。おかしい行があれば、その行をそのままコピーして挙げてください。おかしな行が無ければ「ありません」とだけ書いてください。</div>

まったく同じ8つのファイルに、聞き方だけをこう変えて渡したところ、**8回とも2026-10-09の行を一字一句コピーして正しく名指ししました。**50回目のファイル（10行の「本日」が混ざっている）でも、**10行すべてを一度に挙げました。**点検の値打ちは「何を聞くか」で決まります。「形」ではなく「日付の順番」を聞けば、この事故は見つかります。

## うまくいかないときの言い直し方 {: .fix }

### 「本日」とだけ書いてしまい、日付が実際の今日になった {: .trouble }

生成する指示文に、1行だけ足します。

<div class="prompt">下の「記録ファイル」の末尾に、【今日ぶん】を1行だけ追記してください。すでにある行は1文字も変えないでください。【今日ぶん】の中に日付の表記が無く「本日」「今日」としか書かれていない場合は、実際のシステム上の今日の日付ではなく、記録ファイルの最後の行の次の日を使ってください。更新後のファイル全体を、コードブロックで出してください。</div>

材料2本（副業の作業記録／家計の買い物メモ）× 各3回＝6回試したところ、**6回とも正しい日付（ファイルの続きの日）になりました。**直す前は46回中46回が実際の今日でしたが、この1行で6回中6回に反転しています。

### 点検をかけても、日付のズレに気づけない {: .trouble }

上の4番のとおり、「形がそろっているか」という聞き方では気づけません。聞き方を変えてください。

<div class="prompt">下のファイルは、毎日1行ずつAIに追記しているものです。各行の日付が、前後の行と比べて順番から外れていないか確認してください。おかしい行があれば、その行をそのままコピーして挙げてください。おかしな行が無ければ「ありません」とだけ書いてください。</div>

月に1回、このファイルを別の新しい会話に渡して走らせるくらいの使い方が合っています。

## 応用・次の一手 {: .next }

**この記事が答えたのは「回数（時間軸）」という1つの軸だけです。**[毎日の追記を同じ形にそろえる](/recipes/daily-append-same-shape/)が残した未測定事項は、もともと3つありました。

- お手本の行数 → [見本は100行あっても的中は4分の3](/recipes/more-example-rows-lower-the-hit-rate/)が答えた
- お手本の種類 → [ダミーの見本行でも書式はそろう](/recipes/dummy-row-holds-real-row-breaks/)が答えた
- 回数（時間軸） → この記事が答えた

**「本日」の事故は、[引き継ぎメモの日付を直す](/recipes/convert-dates-keep-comparison-words/)とは逆方向の問題です。**あちらはAIに相対日付（「先週」「来月まで」）をわざと絶対日付へ変換させる記事です。変換の基準に「本物の今日」を使うのは、あちらでは正しい動きでした。この記事の自動追記は、そもそも日付の変換を頼んでいません。頼んでいないのに、走り書きの言葉だけで「本物の今日」が紛れ込んでくる、という違いです。

**自分の記録ファイルが、本物の今日とは違う日付の世界を進んでいるときは注意してください。**過去の埋め直し・架空データ・テスト環境がそれにあたります。「本日」という書き方そのものを避け、**日付は自分で書いてから渡すのがもっとも確実です。**

**次に測るなら**＝走り書きの言い方を「今日」「昨日」「さっき」などに増やしたとき、同じ事故が同じ形で起きるかです。この記事で仕込んだのは「本日」の1語だけで、そこは触っていません。手でうまくいったら、時刻を決めて自動にする仕掛けは[毎日決まった時刻にAIを動かす仕掛けを作らせる](/recipes/github-actions-daily-cron/)にあります。
