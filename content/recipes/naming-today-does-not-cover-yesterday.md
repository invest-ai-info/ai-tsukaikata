## これで何ができるか {: .what }

[追記の形は50回でも崩れない——「本日」は壁時計の日付に化ける](/recipes/append-rounds-date-drift/)は、ある事故を確かめた記事です。毎日の追記で走り書きが「本日◯◯でした」と日付を書かない日だけ、追記された日付が呼び出した実際の日に化けるという事故です。末尾の宿題はこうでした。

> 次に測るなら＝走り書きの言い方を「今日」「昨日」「さっき」などに増やしたとき、同じ事故が同じ形で起きるかです。

<mark>この記事で「今日」「昨日」「さっき」の3語を測りました。</mark>結論は3つです。

1. **3語とも、「本日」と同じ壁時計化けが起きました。**架空の記録2本に3語ずつ、2回ずつ渡した**12回**すべてで日付が化けました。正しくはファイルの続き（2026-08-04）のはずが、実行した実際の日（2026-10-22。「昨日」は前日の2026-10-21）になりました
2. <mark class="warn">先行記事の直し方（「本日」「今日」としか書かれていない場合は〜の1行）は、名指ししていない「さっき」には2回とも効きました。</mark>ところが<mark class="warn">同じく名指ししていない「昨日」には、**4回中1回**、壁時計の日付に戻りました。</mark>名指ししていない語への効き方は、語によって当たり外れがあります
3. **「昨日」を名指しに加えた最終版は、2回とも正しく直りました。**確実にするには、効くかもしれない語に賭けず、語を列挙します

## AIへの頼み方 {: .ask }

### 1. 「今日」「昨日」「さっき」で、同じ指示文を試す

[追記の形は50回でも崩れない](/recipes/append-rounds-date-drift/)が使った、日付の扱いに何も触れていない指示文をそのまま使いました。

<div class="prompt">下の「記録ファイル」の末尾に、【今日ぶん】を1行だけ追記してください。すでにある行は1文字も変えないでください。更新後のファイル全体を、コードブロックで出してください。</div>

材料は2本（副業の作業記録／家計の買い物メモ）。どちらも最後の行が2026-08-03で、ファイルの続きとしては次の行が2026-08-04になるはずです。この指示文に、日付を書かない3つの走り書きを渡しました。

- 「今日D社向けに資料を修正、所要40分でした。」
- 「昨日E社と電話で打ち合わせ、所要25分でした。」
- 「さっきF社とチャットで相談、所要10分でした。」

**材料2本×3語×2回＝12回。**それぞれ独立した新規のエージェント（前の回の結果を共有しない別プロセス）に、同じ依頼を送りました。

### 2. 12回とも、続きの日付ではなく実行した実際の日になった

結果は次のとおりです（続きとして正しいのは2026-08-04、「昨日」はその前日の2026-08-03）。

| 走り書き | 材料・1回目 | 材料・2回目 |
|---|---|---|
| 「今日」（作業記録） | 2026-10-22 | 2026-10-22 |
| 「今日」（買い物メモ） | 2026-10-22 | 2026-10-22 |
| 「昨日」（作業記録） | 2026-10-21 | 2026-10-21 |
| 「昨日」（買い物メモ） | 2026-10-21 | 2026-10-21 |
| 「さっき」（作業記録） | 2026-10-22 | 2026-10-22 |
| 「さっき」（買い物メモ） | 2026-10-22 | 2026-10-22 |

<mark class="warn">12回とも、ファイルの続きの日付（2026-08-04）にはならず、実行した実際の日（2026-10-22）になりました。「昨日」だけは実際の前日（2026-10-21）でしたが、これも壁時計基準であることに変わりません。</mark>🔑 **「本日」1語だけの事故ではなかった。**日付を書かず、現在時刻からの相対語で済ませる走り書きは、言い方を変えても同じ事故を起こします。

先行記事が見つけた直し方を、そのまま（1文字も変えずに）当てました。この指示文は「本日」「今日」の2語しか名指ししていません。

「今日」と「さっき」に当てました（それぞれ材料2本×1回＝計4回）。**4回とも2026-08-04（続きの日付）に正しく直りました。**「さっき」は指示文のどこにも名指しされていません。それでも「今日」と同じ扱いで一般化されています。

### 4. 「昨日」だけは、4回に1回、壁時計の日付に戻る

同じ指示文を、名指しされていない「昨日」に当てました（材料2本×2回＝4回）。

4回のうち**3回は、2026-08-03（続きの前日）になりました。**これは最後の行（C社・2026-08-03）と同じ日付です。それでも「今日＝続きの2026-08-04」の前日という意味では**正しい日付**です。日付が重複しているように見えても、1日に複数の仕事があっただけで、事故ではありません。

<mark class="warn">ところが残りの1回は、2026-10-21（壁時計の実日付の前日）に戻りました。</mark>この回は「昨日」が指示文の名指しの対象外だと判断し、通常どおり実際のシステム日付を基準に計算しています。🔑 **「名指ししていない語への一般化」は、保証ではありません。**「さっき」は4回とも一般化されましたが、「昨日」は4回に1回、一般化が外れました。

「昨日」の扱いを指示文の中で明文化しました。

材料2本に1回ずつ当てたところ、**2回とも2026-08-03（続きの前日）になりました。**「昨日」の扱いを運に任せず、指示文の中で定義したことで、4回中1回の取りこぼしが消えています。

## うまくいかないときの言い直し方 {: .fix }

### 「昨日」「さっき」など、言い方を増やすたびに同じ検証が要るのか不安 {: .trouble }

**この記事が答えたのは「今日」「昨日」「さっき」の3語だけです。**「先ほど」「ついさっき」「午前中に」のような、さらに別の言い方は試していません。<mark class="warn">試していない言い方を、この記事の結果だけで「大丈夫」と決めないでください</mark>。

安全な考え方は次の順です。

1. 走り書きに出てきそうな相対語を、まず自分で書き出す（「今日」「昨日」「さっき」「先ほど」など）
2. それぞれについて、「実際のシステム日付」ではなく「ファイルの続きの日付を基準にした日」を1語ずつ指示文の中で定義する
3. 定義していない語が出てきたときの振る舞いは保証されない、と割り切る

<div class="prompt">下の「記録ファイル」の末尾に、【今日ぶん】を1行だけ追記してください。すでにある行は1文字も変えないでください。【今日ぶん】の中に日付の表記が無く「本日」「今日」「さっき」としか書かれていない場合は、実際のシステム上の今日の日付ではなく、記録ファイルの最後の行の次の日を使ってください。「昨日」としか書かれていない場合は、記録ファイルの最後の行と同じ日付を使ってください。更新後のファイル全体を、コードブロックで出してください。</div>

### 走り書きの言い方そのものを、自分では制御できない {: .trouble }

自動化の入力が自分の手入力でない場合（他の人のメモ、別のアプリからの転記など）、走り書きの言い方を事前に全部挙げきることはできません。

- **確実な対策は1つだけです。**[先行記事](/recipes/append-rounds-date-drift/)の結論どおり、**日付は自分で書いてから渡す**こと。「本日」「今日」「昨日」「さっき」のような言葉そのものを、入力の時点で避けます
- どうしても相対語が残るなら、追記のたびに点検を走らせてください。使うのは[毎日の追記が同じ形かを点検する記事](/recipes/daily-append-same-shape/)の点検です。**聞き方は「形」ではなく「日付の順番」に向けます**（[先行記事](/recipes/append-rounds-date-drift/)の4〜5番）

## 応用・次の一手 {: .next }

**「本日」1語で見つかった事故は、「今日」「さっき」にも同じ形で再発しました。**そして「名指しした語の外側」への一般化は、語によって信頼度が違うことも分かりました。

| 語 | 名指し無しでの一般化 |
|---|---|
| 今日 | （名指しされている） |
| さっき | 2/2で一般化された |
| 昨日 | 4回中3回は一般化・4回中1回は外れた |

この表は、[追記の形は50回でも崩れない](/recipes/append-rounds-date-drift/)の末尾に残っていた宿題のうち1つを埋めました。まだ試していないことは2つです。

- 「先ほど」「午前中に」のような、3語以外の相対語
- 相対語が2つ以上、同じ走り書きの中に混ざる場合（「さっき」と「昨日分の追加」が同じ行に出るなど）

次に測るなら、相対語を自分で全部挙げる代わりに別の言い方を試します。**「日付を書かない走り書きは、すべてファイルの続きの日付を使ってください」**のように、個別の語を名指ししない言い方です。これが安定するかを確かめます。[毎日決まった時刻にAIを動かす仕掛けを作らせる](/recipes/github-actions-daily-cron/)で自動化する前に、この指示文をそのまま使ってください。
