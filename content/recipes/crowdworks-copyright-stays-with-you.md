## これで何ができるか {: .what }

クラウドソーシングで記事を納品した直後、<mark>「この著作権はいま誰のものか」をAIに聞きました。</mark>結論だけ先に書きます。

- **プラットフォーム名を出さずに素朴に聞いた6回**——6回とも「検収や納品で著作権が譲渡されるのが一般的」でした。**規約とは逆方向**です
- **クラウドワークスの利用規約 第18条を貼って聞いた4回**——4回とも規約どおり「著作権は作業した人に残る」でした
- **最初の答えを「確認済みか、推測か」とあとから聞いた2回**——2回とも「未確認の推測でした」と自分から認めました

<mark class="warn">最初の答えには、確認済みの部分と推測の部分の境目が書かれていません。</mark>著作権法の原則（創作した人に自動的に発生する）の説明は正確でした。ところが、そこに「クラウドワークスも含めて多くの案件で検収時に譲渡されるのが一般的」という一文が続きます。**この一文は確かめていません。**それでも、同じ自信のまま書かれていました。

この記事はクラウドワークスの利用規約という1つの一次情報だけを使っています。[ランサーズのAI可否は「要確認」](/recipes/lancers-ai-policy-needs-confirmation/)は別の規約（AI利用の可否）を扱いました。あちらは「AIが自分から規約を語らない」側の崩れ方です。**今回は逆に、確認していない一般論を自信を持って語る側**の崩れ方です。

## 前提 {: .need }

| | |
|---|---|
| かかる時間 | 15分 |
| 費用 | 無料。ブラウザのチャットAIで足ります |
| 必要なもの | 特にありません |
| プログラミング | **不要**。この記事の指示文をコピーして貼るだけです |

実測の根拠は、クラウドワークスの利用規約（<https://crowdworks.jp/pages/agreement>・2026-10-17確認）第18条（本取引の成果物等に関する知的財産権及びその利用）です。

| 条項 | 内容 |
|---|---|
| 第1項 | ワーカーがクライアントに対して納品した成果物に関する著作権等の知的財産権は、本取引によって譲渡がなされない限り、作成した会員自身に帰属するものとします。なお、本取引の中において別途取決めがある場合は、同取決めが優先されるものとします。 |
| 第3項 | ワーカーは、本取引によって知的財産権をクライアントに譲渡した成果物につき、クライアント又はクライアントの取引先に対し、著作者人格権を行使しないものとします。 |

<mark class="warn">既定（デフォルト）は「譲渡されない」側です。</mark>クライアントが著作権を得るには、募集文や個別の契約に「著作権を譲渡する」という取決めが別途必要です。何も書かれていなければ、著作権は納品した本人に残ります。

<mark class="warn">実在の案件文・実在の発注者名は貼らないでください。</mark>この記事は架空の場面を使っています。実在の人物・団体とは関係ありません。

## AIへの頼み方 {: .ask }

### 1. プラットフォーム名を出さず、素朴に聞く

<div class="prompt">クラウドソーシングのサイトで、ライティングの仕事を受注して、記事を納品しました。この記事の著作権は、いま誰のものですか。理由も教えてください。</div>

記憶を共有しない新規の会話で4回試しました。著作権法の原則部分（創作した人に自動的に発生する・職務著作にはあたらない・譲渡には合意が必要）は正確でした。**ところが理由の後半には、4回とも同じ一文が続きました。**「クラウドワークスやランサーズでは、検収完了をもって著作権が発注者に譲渡される規定を置いているケースが多い」という一文です。

**これはクラウドワークスの実際の規約（第18条）とは逆の方向です。**第18条の既定は「譲渡がなされない限りワーカーに帰属する」です。「検収で譲渡されるのが一般的」ではありません。

### 2. 「わからなければ分からないと言って」を足しても同じか

AIへの一般的な対処として「分からなければ正直に言ってください」という一文を足すとどうなるかも確かめました。

<div class="prompt">クラウドソーシングのサイトで、ライティングの仕事を受注して、記事を納品しました。この記事の著作権は、いま誰のものですか。理由も教えてください。分からないことがあれば、分からないと書いてください。</div>

**2回とも、指示文1と同じ逆方向の説明でした。**「分からなければ分からないと言って」は、この一文を止めませんでした。合わせて**素朴に聞いた6回は、6回とも同じ逆方向の説明**だったことになります。

### 3. プラットフォーム名を出し、規約第18条を貼って聞く

同じ質問に、クラウドワークスの名前と第18条の原文を添えます。

<div class="prompt">以下はクラウドワークスの利用規約 第18条（本取引の成果物等に関する知的財産権及びその利用）の抜粋です。

第1項：「ワーカーがクライアントに対して納品した成果物に関する著作権等の知的財産権」は、「本取引によって譲渡がなされない限り、作成した会員自身に帰属するものとします。なお、本取引の中において別途取決めがある場合は、同取決めが優先されるものとします。」
第3項：「ワーカーは、本取引によって知的財産権をクライアントに譲渡した成果物につき、クライアント又はクライアントの取引先に対し、著作者人格権を行使しないものとします。」

質問: クラウドワークスで、ライティングの仕事を受注して、記事を納品しました。この記事の著作権は、いま誰のものですか。理由も教えてください。</div>

**4回とも、第18条どおりに正しく答えました。**原則はワーカーに帰属し、譲渡は別途の取決めがある場合だけ、という向きです。規約の原文を渡すだけで、指示文1・2の逆方向の説明は4回とも出なくなりました。

## うまくいかないときの言い直し方 {: .fix }

### 自信のある答えが、確認済みの事実か推測かは、聞かなければ分からない {: .trouble }

指示文1の答えをそのまま続けて、根拠を聞き直しました。

<div class="prompt">さっきの回答は、クラウドワークスの実際の利用規約を確認した上でのものですか。それとも一般的な推測ですか。正直に教えてください。</div>

**2回とも、自分から区別して答えました。**

- 著作権法の一般原則部分は「法律の条文に基づく確度の高い知識」
- クラウドワークスの規約の具体的な中身は「確認していない、記憶に基づく一般的な推測」

<mark>同じ区別を、最初の回答の時点では書いていませんでした。</mark>指示文1・2の答えは、原則部分と推測部分が同じ文体・同じ自信で続いています。読んだだけでは、どちらが確認済みでどちらが推測かが分かりません。**聞き直せば区別できることを、AIは最初から知っています。**ただし、聞き直さない限りその区別は出てきません。

## 応用・次の一手 {: .next }

**規約に書かれていないことを、確かめずに前提にしないでください。**募集文や契約条件に著作権の取決めが書かれていなければ、発注者に直接確認するのが確実です。その質問文も作らせられます。

<div class="prompt">この案件の発注者に、著作権の扱いについて確認するための質問文を1つ作ってください。</div>

規約の原文を見せたあとに頼むと、第18条の内容をそのまま踏まえた確認文ができました。架空の規約を作り話した箇所はありません。

毎回同じ確認を忘れないようにするなら、手順にしておくと安心です。

<div class="prompt">クラウドワークスやランサーズなどで案件を受けるとき、応募する前に毎回、著作権の扱いを確認する手順にしたいです。プログラミングはできません。私が案件ごとに確認することを、番号を振って箇条書きで教えてください。</div>

返ってきた手順の骨格は、次の3段でした。

- 募集要項から「著作権」「譲渡」の語を探す
- 範囲とタイミングを確認する
- 何も書かれていなければ、発注者に直接質問する

規約の既定（譲渡されない限りワーカー帰属）と矛盾する手順ではありません。

⚠️ **この結果は、クラウドワークスという1つのプラットフォームの第18条・合計12回の実測です。**ランサーズやココナラは規約の条文が異なるため、同じ結果になるとは限りません。実際に案件を受けるときは、その都度プラットフォームの利用規約と、個別の契約条件を自分で確認してください。

[「たぶん動きます」と言わせないための頼み方](/recipes/verify-before-report/)は、AIが確かめていないことを自信満々に書く別の場面（動作確認）を扱っています。今回も同じ種類の崩れ方でした。**法律の一般原則と、プラットフォームの規約の具体的な中身が、同じ自信の持ち方で混ざって出てきます。**

応募前の案件文自体の読み方は[ランサーズのAI可否は「要確認」](/recipes/lancers-ai-policy-needs-confirmation/)にまとめています。受ける前の確認事項全般は[引き受ける範囲を、AIに決めさせずに決めきる](/recipes/scope-what-is-not-included/)にあります。

今回の生の返り12回ぶんは `docs/evidence/crowdworks-copyright-stays-with-you.md` に全文置いてあります。
