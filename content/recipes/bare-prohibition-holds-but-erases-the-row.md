## これで何ができるか {: .what }

[週報を毎週金曜に自動で作らせる](/recipes/weekly-report-loop-without-drift/)で分かったのは、
「自分の残業、先月より増えている」のような自分用のメモが、何もしないと上司への相談事項として
報告書に書かれてしまうことでした。対策は「禁止の一文」と「行き先（5. 私が決める行）」の両方
でしたが、著者自身がこう書き残していました。「禁止だけを渡した形は、今回は試していません。
ここで言えるのは、行き先を作った側では、その行が残った、ということまでです」。

測りました。**行き先を作らず、禁止の一文だけ**を足した指示文で、同じ3週連鎖（週2→週3→週4）
を2回試しました。

| 条件 | 週3「体調不良で半休」 | 週4「残業が増えている」 |
|---|---|---|
| 禁止なし（元の指示文） | 本文にそのまま書かれた | 本文にそのまま書かれた |
| **禁止だけ・行き先なし** | **跡形もなく消えた** | **跡形もなく消えた** |
| 禁止＋行き先あり | 「5.」に残った | 「5.」に残った |

<mark>禁止の一文だけでも、週をまたいで3週とも本文への漏れは止まりました。</mark>仕込んだ禁句2件
×2回＝4件は、4件とも本文の見出しに現れませんでした。<mark class="warn">ただし行き先が無いぶん、
その行自体が週報のどこにも残らず、跡形もなく消えました。</mark>

## 前提 {: .need }

| | |
|---|---|
| かかる時間 | 25分 |
| 費用 | 無料 |
| 必要なもの | 走り書きのメモを1か所に書き溜めていること |
| プログラミング | **不要** |

📌 **この記事は[前作](/recipes/weekly-report-loop-without-drift/)の未測定事項への回答です。**
材料（週1の人の週報・週2〜4のメモ）はすべて前作からそのまま流用しています。
前作の指示文2・3（禁止＋行き先あり）、手動版の作り方は[週報を前回のぶんを型にして書かせる](/recipes/weekly-report-from-memo/)
にあります。

## AIへの頼み方 {: .ask }

### 1. 禁止の一文だけを足し、行き先は作らない

前作の指示文3から、最後の「5. 私が決める行」を作る一文だけを抜きました。他は1文字も変えて
いません。

<div class="prompt">毎週金曜の朝に自動で走らせています。下の見出しだけを使って、今週のメモから週報を作ってください。他の見出しを足さないでください。

・メモに書いていないことは書かないでください。進み具合・割合・見通しを補わないでください。
・メモの行が「まだ終わっていない」「返事がない」「決まっていない」と読めるものは、進んだように書き換えないでください。
・自分の体調・残業・待遇・人への不満にあたる行は、どの見出しにも入れないでください。出すかどうかは私が決めます。
・材料が無い見出しは「なし」とだけ書いてください。

前置き・感想は書かないでください。</div>

このあとに「見出し」（1〜4の空の見出し）と「先週の週報」「今週のメモ」を貼ります。週2は
第1週（人が書いた週報）を型にします。中身の短い週2はそのまま載せます。

<div class="prompt">=== 見出し ===
## 1. 今週やったこと
## 2. 進んでいないこと
## 3. 来週やること
## 4. 相談したいこと

=== 先週の週報 ===
## 1. 今週やったこと
- A社向けの見積書を作成し、部長の確認を受けたうえで送付しました。
- 在庫システムの入替について、情報システム部と初回の打ち合わせを実施しました。
- 月次の請求処理を予定どおり完了しました。

## 2. 進んでいないこと
- B社の値引き要請について、社内の判断を待っている状況です。

## 3. 来週やること
- A社からの返答を確認します。
- 入替の日程案を作成します。

## 4. 相談したいこと
- B社の値引きをどこまで受けるか、方針をご相談させてください。

=== 今週のメモ ===
・A社 返事なし 先方の担当が出張らしい
・B社 値引きの件 まだ返事もらえてない こちらから催促した
・入替の日程案 11月4日の週で出した
・棚卸しと重なるかも 総務に確認中
・研修 2回だと足りない 3回にするか未定
・見積の版が古かった 240万で出してたが最新は280万 差し替えた
・情シスの担当が誰か確定してない
・請求書のフォーマット変更 来月から 周知まだ
・月曜の会議 資料は自分が作る</div>

週3・週4は、前の週の**実際の返り**を型にします（モデルの出力は回によって多少違うため、
ここだけプレースホルダで示します）。

<div class="prompt">=== 見出し ===
## 1. 今週やったこと
## 2. 進んでいないこと
## 3. 来週やること
## 4. 相談したいこと

=== 先週の週報 ===
（ここに、前の週の実際の返りをそのまま貼ります）

=== 今週のメモ ===
（ここに、今週のメモをそのまま貼ります）</div>

2回の連鎖（各3週）で、週3のメモにある「木曜 体調不良で半日休んだ」も、週4のメモにある
「自分の残業 先月より増えている」も、本文の1〜4のどこにも現れませんでした。<mark>仕込んだ
禁句2件×2回＝4件は、4件とも本文への漏れが0件でした。</mark>

### 2. ただし、消えた行は週報のどこにも残らない

ここが前作の指示文3と違うところです。行き先（5.）を作っていないので、禁止された行は
**本文からも、どこからも消えます。**

<div class="prompt">毎週金曜の朝に自動で走らせています。下の見出しだけを使って、今週のメモから週報を作ってください。他の見出しを足さないでください。

・メモに書いていないことは書かないでください。進み具合・割合・見通しを補わないでください。
・メモの行が「まだ終わっていない」「返事がない」「決まっていない」と読めるものは、進んだように書き換えないでください。
・自分の体調・残業・待遇・人への不満にあたる行は、どの見出しにも入れないでください。出すかどうかは私が決めます。
・材料が無い見出しは「なし」とだけ書いてください。

前置き・感想は書かないでください。

=== 見出し ===
## 1. 今週やったこと
## 2. 進んでいないこと
## 3. 来週やること
## 4. 相談したいこと

=== 先週の週報 ===
（ここに、週3の実際の返りをそのまま貼ります）

=== 今週のメモ ===
（ここに、週4のメモをそのまま貼ります）</div>

返ってきた週報を最後まで読んでも、「残業」にあたる記述は1文字もありません。本文の見出し
1〜4のどこにも入らず、本文の外にも注記は付きません。**ファイルを開くだけでは、禁止された
行があったこと自体に気づけません。**

### 3. 比べるために、行き先ありの指示文もこの晩にあらためて試す

同じ週3の実返りを型にして、今度は行き先（5. 私が決める行）を復活させた指示文を試しました。

<div class="prompt">毎週金曜の朝に自動で走らせています。下の見出しだけを使って、今週のメモから週報を作ってください。他の見出しを足さないでください。

・メモに書いていないことは書かないでください。進み具合・割合・見通しを補わないでください。
・メモの行が「まだ終わっていない」「返事がない」「決まっていない」と読めるものは、進んだように書き換えないでください。
・自分の体調・残業・待遇・人への不満にあたる行は、どの見出しにも入れないでください。出すかどうかは私が決めます。
・材料が無い見出しは「なし」とだけ書いてください。
・最後に「## 5. 私が決める行」を作り、どの見出しにも入れなかった行を、メモの言葉のまま1行ずつ全部並べてください。1行も無ければ「なし」と書いてください。

前置き・感想は書かないでください。</div>

<mark>同じ上流（週3の実返り）・同じ週4のメモで、行き先ありの版は2回とも「5. 私が決める行」に
「自分の残業 先月より増えている」をそのまま残しました。</mark>週3の「体調不良」も、同じやり方
で2回とも「5.」に残りました。**違いは行き先の一文があるかどうかだけです。**

### 4. 消えた行を、別の会話で見つけ出す

週報とメモを並べて、どこにも入っていない行を挙げさせます。

<div class="prompt">下に「今週のメモ」と「出来上がった週報」を並べます。メモにある行のうち、週報のどの見出しにも入っていない行を、メモの言葉のまま1行ずつそのまま挙げてください。1件も無ければ「なし」とだけ書いてください。

=== 今週のメモ ===
（ここに、その週のメモをそのまま貼ります）

=== 出来上がった週報 ===
（ここに、出来上がった週報をそのまま貼ります）</div>

週3・週4それぞれ2回、計4回試しました。<mark>4回とも、消えていた禁句1件だけを過不足なく
挙げました。</mark>他のメモの行を誤って「無い」と言った回は0件です。**消えたことに気づく
手段はあります。使うかどうかは別です。**

## うまくいかないときの言い直し方 {: .fix }

### 禁止だけで十分だと思っていたら、大事な行が消えていた {: .trouble }

この実測の範囲では、禁止の一文は本文への漏れを止めるには十分でした。問題は「止まったこと」
ではなく「止めた行の記録が残らないこと」です。<mark class="warn">自分で読み返すつもりの行
（体調・残業など）を禁止するなら、行き先も必ず一緒に作ってください。</mark>[前作の指示文3](/recipes/weekly-report-loop-without-drift/)
がその形です。

### もう何週か、行き先なしで回してしまった {: .trouble }

過去の週報を直す必要はありません。この記事の指示文4を、気になる週のメモと週報のペアに
当ててください。消えていた行があれば、1行ずつそのまま返ってきます。**来週からは行き先
入りの指示文に切り替えてください。**

### 行き先を作ると、本文の見出しまで変わってしまわないか心配 {: .trouble }

心配いりません。今回の実測では、行き先の有無で1〜4の中身が変わることはなく、違いは
「5.」が存在するかどうかだけでした。1〜4に書かれた文は、行き先ありと行き先なしで実質
同じでした。

## 応用・次の一手 {: .next }

**この記事の結論は2つです。**①禁止の一文だけでも、3週をまたいで本文への漏れは止まります。
②ただし行き先が無いと、禁止された行はどこにも残らず消えます。消えたことに自分で気づく
仕組みが別に要ります。

📌 **「禁止だけでよいか、行き先も要るか」の分かれ目は、その行を後で読み返したいかどうかです。**
読み返す必要が無い雑音（例: 挨拶文、定型句）なら禁止だけで十分です。[前作](/recipes/weekly-report-loop-without-drift/)
の「自分の残業」のように、**自分で見る場所が要るもの**には行き先を作ってください。

📌 **消えたことへの気づき方は**[自動化が静かに壊れたのを、AIに見つけさせる](/recipes/auto-health-check/)
と同じ発想です。あちらは仕組みが止まったことに気づく話、こちらは**仕組みは動いているのに、
特定の行だけが静かに消える**話です。

⚠️ **この記事が実測していないこと**＝3週より長い連鎖、禁止対象が3つ以上に増えた場合、
禁止の一文を削った影響が週を追うごとに悪化するかどうかの3つです。今回は4件とも1週目
から消えており、進行の有無を観察できる材料がありませんでした。
