## これで何ができるか {: .what }

<mark>受注者の屋号に「法人」という文字列が入っているだけで、AIが源泉徴収の判定を間違えないかを実測しました。</mark>[士業・出演料の手取りを実測した記事](/recipes/withholding-formula-crosses-lawyers-and-performers/)が、末尾で「個人なのに社名に『法人』を含む紛らわしい表記は未検証」と残した宿題の続きです。

結果はこうなりました。

- **講演料150,000円・原稿料200,000円の2契約を用意**
- **屋号を紛らわしくした版・紛らわしくない対照版を、各2回**
- **合計8回とも、個人事業主として正しい手取り額に到達**
- **屋号は「◯◯法人工房」のように個人名と一緒に書かれていて、「株式会社」「合同会社」のような法人格の語尾が無いことが判断の決め手だった**
- **依頼者が「法人なので源泉徴収は不要ですよね」と誤った前提をつけて聞いても、2回とも正しい側の金額にたどりついた**

## 前提 {: .need }

| | |
|---|---|
| かかる時間 | 20分 |
| 費用 | 無料。ブラウザのチャットAIで足ります |
| 必要なもの | 業務委託契約書（受注者の屋号・業務内容・契約金額が分かるもの） |
| プログラミング | **不要**。この記事の指示文をコピーして貼るだけです |

<mark class="warn">実在の取引先名・実在の金額は貼らないでください。</mark>この記事は架空の屋号・氏名・金額を使っています。実在の人物・団体とは関係ありません。

この記事は「手取り額を計算できるか」という実測に絞っています。確定申告のやり方には踏み込みません。源泉徴収の税率は、100万円以下の部分が10.21%です。根拠は[No.2792 源泉徴収が必要な報酬・料金等とは](https://www.nta.go.jp/taxes/shiraberu/taxanswer/gensen/2792.htm)（2026-10-29確認）のとおりです。源泉徴収は、支払先が個人の場合に適用される制度で、法人への支払いは原則対象外です。

[原稿料・デザイン料の源泉徴収を実測した記事](/recipes/direct-contract-withholding-survives-the-million-yen-line/)と[士業・出演料に広げた記事](/recipes/withholding-formula-crosses-lawyers-and-performers/)も、同じ手取り計算シリーズです。後者の記事では、正式な法人格の表記（「◯◯税理士法人」）を確かめています。表記があれば、3回とも「源泉徴収なし」と正しく判定できました。今回はその逆側を試します。**個人なのに屋号だけが法人っぽい**場合です。

## AIへの頼み方 {: .ask }

### 1. 講演料契約・屋号「法人企画社」で聞く

架空の講演料契約です。受注者欄は「法人企画社　佐藤一郎」とだけ書き、個人事業主か法人かは明記していません。専門職の肩書も付けていません。

<div class="prompt">この契約の手取り額（源泉徴収後）を計算してください。</div>

上に続けて、契約書を貼ります。

**2回とも「手取りは134,685円」と正しく計算しました。**式は150,000円×10.21%=15,315円の源泉徴収。150,000円から引いて134,685円です。2回とも、受注者名を「屋号＋個人名」という書き方だと自分で読みました。個人事業主の典型的な書き方で、法人格を示す語尾が無いことを根拠に挙げています。

### 2. 同じ契約で、屋号だけを「法人」の文字列を含まない形に変えて聞く

指示文1とまったく同じ契約・同じ指示文です。受注者の屋号だけを「佐藤企画社」に変えました。

<div class="prompt">この契約の手取り額（源泉徴収後）を計算してください。</div>

**こちらも2回とも「手取りは134,685円」と、屋号を変える前とまったく同じ結果になりました。**屋号に「法人」という文字列が入っていても入っていなくても、結論は揃いました。

業務の種類を変えた2本目の材料です。架空のウェブ記事原稿執筆の契約で、受注者欄は「蒼空法人工房　鈴木次郎」とだけ書きました。

### 4. 同じ契約で、屋号だけを「法人」の文字列を含まない形に変えて聞く

受注者の屋号だけを「蒼空工房」に変えました。他はすべて指示文3と同じです。

<div class="prompt">この契約の手取り額（源泉徴収後）を計算してください。</div>

## うまくいかないときの言い直し方 {: .fix }

### 「法人なので不要ですよね」と誤った前提をつけて聞くと {: .trouble }

ここまでは、こちらは何も決めつけずに聞いていました。今度は依頼者側が先に間違った思い込みを言ってしまう場面を試します。指示文1と同じ講演料契約で、質問の言い方を変えました。

<div class="prompt">受注者は「法人企画社」という名前なので、法人への支払いとして源泉徴収は不要だと思います。その前提でこの契約の手取り額を計算してください。</div>

<mark>「その前提で」と頼んでも、前提の誤りをそのまま認めず、まず訂正しました。</mark>「屋号に『法人』という文字列を含めること自体は何の法的効力も持たない」と説明しています。結論は134,685円（源泉徴収あり）に正しく到達しました。

同じ言い方を、原稿料契約（屋号「蒼空法人工房」）でも試しました。

<div class="prompt">受注者は「蒼空法人工房」という名前なので、法人への支払いとして源泉徴収は不要だと思います。その前提でこの契約の手取り額を計算してください。</div>

<mark class="warn">結論の金額は正しかったものの、書き方は1回目より迷っていました。</mark>**2つの場合を並べて**提示しています。

- 個人事業主の場合: 179,580円
- 本当に法人である場合: 200,000円

最後に「法人番号や登記簿で確認するまでは、個人事業主の可能性が高く179,580円が妥当」とまとめました。金額そのものは外していません。ただ、言い切る代わりに条件分岐の形になっています。

→ 依頼者が誤った前提を口にしたときの答え方は、1回ごとに多少揺れます。**計算結果をそのまま受け取る前に、「個人か法人か、どちらだと判断したか」を一言で聞き直す**のが安全です。

<div class="prompt">個人事業主と法人、どちらだと判断してその金額を出しましたか。判断の根拠も教えてください。</div>

この聞き方を添えれば、どちらの書き方であっても、判断の根拠（屋号に法人格の語尾が無いこと）を明示させられます。

## 応用・次の一手 {: .next }

**屋号に紛らわしい文字列を含む取引先が増えてきたら、契約のたびに同じ手順で確認できるようにしておくと安心です。**

<div class="prompt">副業で請け負う相手の屋号や社名に「法人」などの紛らわしい文字列が含まれることが増えてきました。屋号の見た目だけで源泉徴収が必要かどうかを決めず、契約のたびに正しく確認したいです。プログラミングはできません。私が契約のたびに確認することを、番号を振って箇条書きで教えてください。</div>

2回試したところ、どちらも次の骨格が共通していました。

- 屋号の文字列（「法人」「コーポレーション」等）だけで法人だと判断しない
- 国税庁の「法人番号公表サイト」で、実際に法人登記されているかを確認する
- 支払う業務が源泉徴収の対象業務（204条1項に列挙される業務）かどうかを確認する
- 判断に迷う場合は、税務署や契約している税理士に確認する
- 確認した内容と根拠を、契約ごとに記録・保存する

⚠️ **この結果は、架空の契約2種（講演料150,000円・原稿料200,000円）・計10回（応用2回を含む）の実測です。**「屋号がどんなに紛らわしくても絶対に間違えない」と一般化しないでください。試したのは、次の範囲までです。

- 紛らわしい屋号は「◯◯法人△△」という1つの型のみです。「株式会社」の一部だけを切り取った表記など、他の紛らわしさは未検証です
- 業務の種類は講演料（204条1項1号）・原稿料（同号）のみです
- 契約金額はいずれも100万円以下の1段階の税率で収まる額です。100万円を跨ぐ金額での紛らわしい屋号は未検証です
