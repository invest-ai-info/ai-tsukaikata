## これで何ができるか {: .what }

<mark>消費税を「込み」として総額だけを書いた契約（消費税額を区分して記載しない契約）で、AIが手取り額（源泉徴収後）を正しく計算できるかを実測しました。</mark>[士業・出演料の手取りを実測した記事](/recipes/withholding-formula-crosses-lawyers-and-performers/)の続きです。

結果は3つに分かれました。

- **消費税を区分して記載した契約は、2回とも正しく計算できた**
- **消費税「込み」で総額しか書かない契約は、3回中2回、消費税分を逆算して除いてから源泉徴収をかけ、本来より多い手取り額を出した**
- **国税庁の通達の文言を先に示すと、2回とも正しく計算できた**

<img src="/static/images/tax-included-withholding-hit-and-miss.svg" alt="4つの条件で、手取り額が国税庁の通達どおりの正解と一致した回数を示す表。①消費税を区分記載した契約は2回中2回正解、②消費税込みで総額のみ・通達を示さずに依頼は3回中1回正解、③消費税込みで総額のみ・通達の文言を先に示して依頼は2回中2回正解、④区分の有無をまず確認させる汎用プロンプトを契約①②の両方に適用は2回中2回正解。下の枠には、②で誤った2回はどちらも消費税込みの金額を税抜へ逆算してから源泉徴収をかけ、本来より2,907円多い手取り額（302,092円、正解は299,001円）を出したこと、通達の文言か区分確認の指示があれば4回とも正解したことが書かれている。">
<figcaption>区分記載の無い契約は、3回中2回、源泉徴収が少なく計算されました。</figcaption>
</figure>

<mark class="warn">手取りが多く計算されたのではなく、源泉徴収が少なく計算された点に注意してください。</mark>源泉徴収が本来より少ないということは、支払う側の源泉徴収義務が不足する方向の誤りです。

## 前提 {: .need }

| | |
|---|---|
| かかる時間 | 20分 |
| 費用 | 無料。ブラウザのチャットAIで足ります |
| 必要なもの | 業務委託契約書（報酬の額・消費税の書き方・支払金額が分かるもの） |
| プログラミング | **不要**。この記事の指示文をコピーして貼るだけです |

<mark class="warn">実在の取引先名・実在の金額は貼らないでください。</mark>この記事は架空の社名・金額を使っています。実在の人物・団体とは関係ありません。

この記事は「手取り額を計算できるか」という実測に絞っています。確定申告のやり方には踏み込みません。源泉徴収の税率（100万円以下の部分10.21%）は[No.2792 源泉徴収が必要な報酬・料金等とは](https://www.nta.go.jp/taxes/shiraberu/taxanswer/gensen/2792.htm)（2026-10-26確認）のとおりです。消費税の扱いは制度が変わることがあるので、契約では必ず国税庁の最新情報（[インボイス制度開始後の報酬・料金等に対する源泉徴収](https://www.nta.go.jp/law/tsutatsu/kobetsu/shotoku/gensen/111209/01.htm)、2026-10-26確認）で確認してください。この通達には、こう書かれています。

> 原稿料や弁護士報酬などの源泉徴収の対象となる報酬・料金等（所得税法第204条第１項）の中に消費税及び地方消費税の額（以下「消費税等の額」といいます。）が含まれている場合は、原則として、消費税等の額を含めた金額が源泉徴収の対象となります。ただし、報酬・料金等の支払を受ける者からの『請求書等』において、報酬・料金等の額と消費税等の額が明確に区分されている場合には、その報酬・料金等の額のみを源泉徴収の対象とする金額として差し支えありません。

**原則は消費税込みの金額全体。区分して記載されているときだけ、報酬額のみでよい**、という順番です。プラットフォーム経由の段階制手数料に消費税をどちらへ当てはめるかは、[別の記事](/recipes/pick-where-tax-applies-and-it-holds/)で確かめています。

## AIへの頼み方 {: .ask }

### 1. 消費税を区分して記載した契約で聞く

まずは従来どおり、消費税額を区分して書いた契約です。月額原稿料300,000円（消費税別）に、消費税33,000円を加算して請求総額333,000円としています。

<div class="prompt">この契約の手取り額（源泉徴収後）を計算してください。</div>

上に続けて、契約書を貼ります。

**2回とも「手取りは302,370円」と正しく計算しました。**式は300,000円×10.21%=30,630円の源泉徴収。消費税込みの請求総額333,000円から引いて302,370円です。

### 2. 消費税「込み」で総額しか書かない契約で、同じ指示文で聞く

同じ請求総額333,000円ですが、契約書には「月額業務委託料333,000円（消費税込み）」とだけ書き、消費税額の内訳は書きません。指示文は指示文1とまったく同じです。

<div class="prompt">この契約の手取り額（源泉徴収後）を計算してください。</div>

3回中2回、こう計算しました。

```
消費税込みの金額なので、まず税抜の報酬額を算出します。333,000円÷1.1=302,727円（1円未満四捨五入）。
この302,727円に10.21%を掛けると30,908円。手取り額は333,000円−30,908円=302,092円です。
```

**正解は299,001円なのに、302,092円と、2,907円多く計算しました。**消費税込みの金額を税抜へ逆算してから源泉徴収をかけたためです。この契約書には消費税額の区分記載が無いので、国税庁の通達に従えば333,000円全体が源泉徴収の対象になります。<mark>1回だけ、区分記載が無いことに自分で気づいて、正しく299,001円を出しました。</mark>

### 3. 国税庁の通達の文言を先に示して聞く

同じ契約②に、前提の節で引用した通達の文言をそのまま添えて頼みます。

<div class="prompt">国税庁の通達（令和3年12月9日付「インボイス制度開始後の報酬・料金等に対する源泉徴収」）によれば、報酬・料金等に消費税等の額が含まれている場合、原則として消費税等を含めた金額が源泉徴収の対象になりますが、請求書等で報酬の額と消費税等の額が明確に区分されている場合は、報酬の額のみを対象にできるとされています。これを踏まえて、次の契約の手取り額（源泉徴収後）を計算してください。</div>

上に続けて、契約②の契約書を貼ります。

**2回とも「手取りは299,001円」と正しく計算しました。**通達の文言を先に渡すと、区分記載が無い契約でも正しい側に揃いました。

## うまくいかないときの言い直し方 {: .fix }

### 「合っていますか」と漠然と聞いても、逆算の誤りには気づかない {: .trouble }

指示文2で302,092円と計算した投稿を、新しい会話で見せて漠然と点検だけ頼みました。

<div class="prompt">この計算、合っていますか？</div>

```
はい、計算の流れを確認しました。消費税込みの金額から税抜額を算出し、その金額に源泉徴収税率10.21%を
掛けて、請求総額から差し引くという手順は一般的な計算方法です。数値も正しく計算されています。
```

<mark class="warn">漠然とした点検依頼は、計算の手順の一貫性だけを確認し、「そもそも税抜へ逆算してよいか」という前提には触れませんでした。</mark>間違った手順を「一般的な計算方法」と誤って追認しています。

→ 点検してほしい観点を名指しして頼み直します。

<div class="prompt">契約書に消費税額の区分記載があるかどうかを確認し、区分記載が無い場合は国税庁の取扱い（区分記載が無ければ消費税込みの金額全体が源泉徴収の対象になる）に従って計算をやり直してください。</div>

**2回とも、区分記載が無いことに気づき、正しく299,001円に直しました。**

```
契約書を確認したところ、消費税額の区分記載はありませんでした。ご指摘のとおり、この場合は消費税込みの
金額全体333,000円が源泉徴収の対象になります。計算をやり直すと、源泉徴収税額は333,000円×10.21%=
33,999円、手取り額は333,000円−33,999円=299,001円です。先ほどの302,092円という計算は誤りで、
正しくは299,001円です。
```

<mark>点検してほしい観点（区分記載の有無）を名指しすれば、誤りに気づいて直させられます。</mark>

## 応用・次の一手 {: .next }

**通達を毎回引用しなくても、判断の条件そのものをプロンプトに埋め込めば、どちらの契約でも正しく計算できるかを試しました。**

<img src="/static/images/tax-included-withholding-calc-chain.svg" alt="同じ請求総額333,000円という条件だけを揃え、消費税の書き方だけを変えた2契約の計算の分かれ道を示す図。上段＝消費税を区分記載した契約。報酬額300,000円×10.21%=30,630円を源泉徴収し、333,000円から引いて手取りは302,370円。下段＝消費税込みで総額333,000円のみ記載した契約の、ありがちな誤りの手順。333,000円を1.1で割って税抜額302,727円へ逆算し、その302,727円×10.21%=30,908円を源泉徴収、333,000円から引いて手取りは302,092円。正しくは、区分記載が無いので333,000円全体×10.21%=33,999円を源泉徴収し、手取りは299,001円。下の枠には、誤りの手順は源泉徴収が2,907円少なくなる方向であること、国税庁の通達第1項が原則は消費税込みの金額全体を対象とし区分記載があるときだけ報酬額のみでよいとしていることが書かれている。">
<figcaption>税抜へ逆算する手順だと、源泉徴収が2,907円少なくなりました。</figcaption>
</figure>

<div class="prompt">次の契約書で、まず消費税額が報酬額と明確に区分して書かれているかどうかを確認してください。区分されていれば報酬額のみを、区分されていなければ消費税込みの金額全体を源泉徴収の対象とし、手取り額を計算してください。</div>

契約①（区分記載あり）・契約②（区分記載なし）の両方に適用したところ、<mark>2回とも正しく、302,370円・299,001円にそれぞれ到達しました。</mark>通達の条文を毎回貼らなくても、「まず区分記載を確認する」という手順をプロンプト自体に組み込んでおけば、両方の契約形式に対応できます。

[士業・出演料の手取りを実測した記事](/recipes/withholding-formula-crosses-lawyers-and-performers/)と合わせて使うと、業務の種類・消費税の書き方が増えても、同じ手順で確認できます。

⚠️ **この結果は、架空の契約1組（請求総額333,000円）・計9回の実測です。**「消費税込みの契約は必ず少なく計算される」と一般化しないでください。試したのは、次の範囲までです。

- 請求総額は333,000円の1パターンのみです。100万円を跨ぐ金額・税率が10%以外の場合は未検証です
- 業務の種類は原稿料（204条1項1号）のみです。弁護士報酬・出演料など他の業務は[既存の記事](/recipes/withholding-formula-crosses-lawyers-and-performers/)で別途確認しています
- 1円未満の端数処理（切り捨て）は国税庁の一般的な取扱いに沿って計算しています。四捨五入を採用している契約では結果が変わる可能性があります

今回の生の返りと正解値の計算は `docs/evidence/no-tax-breakdown-means-withholding-on-the-full-amount.md` に全文置いてあります。
