## これで何ができるか {: .what }

クラウドソーシングには「リスト作成」という仕事の区分があります。条件を渡されて、当てはまる会社や店を何十件か集める仕事です。AIに条件を渡せば一瞬で終わりそうに見えます。

実際にやってみると、そうはなりませんでした。架空の条件（関東の中小の印刷会社を20件・連絡先つき）で頼んだところ、<mark class="warn">4回とも、社名は1件も返ってきませんでした</mark>。断られたのです。

この記事は、その先の話です。**AIが作れるのは納品物ではなく、<mark>自分が確かめるための作業リスト</mark>**でした。自分で集めた候補25件を渡して条件で絞らせた3回は、3回とも同じ形に割れています。

## 前提 {: .need }

| | |
|---|---|
| かかる時間 | 30分（候補を集める時間は別） |
| 費用 | 無料。無料のチャットAIで足ります |
| 必要なもの | 自分で集めた候補の一覧（会社名・所在地・業種などが1行に並んだもの） |
| プログラミング | **不要**。この記事の指示文をコピーして貼るだけです |

<mark class="warn">この記事では、自動で集める手口（スクレイピングなど）は扱いません。</mark>集め方はサイトの規約に触れることがあるためです。扱うのは、**集めたあとに何をAIにやらせるか**だけです。

## AIへの頼み方 {: .ask }

以下は架空の発注条件（関東・印刷会社・従業員100人以下）と、架空の候補25行での実測です。**候補の会社はすべて架空**で、こちらが作りました。

### 1. まず、AIに集めさせようとするとどうなるか

<div class="prompt">副業でリスト作成の仕事を受けました。次の条件で20件挙げてください。

・関東（東京・神奈川・埼玉・千葉）にある印刷会社
・従業員100人以下の中小企業
・会社名／所在地（市区町村まで）／電話番号／ウェブサイトのURL を1行にまとめる</div>

**4回試して4回とも、社名は1件も返りませんでした。**断られた理由も4回ともほぼ同じで、返ってきた文をそのまま引くとこうです。

> それらしい形式の番号やドメインを出すことはできますが、それは事実上の捏造です。

> たちが悪いのは実在する無関係な会社の番号が紛れ込むケースです。

⚠️ **これは「どのAIでも必ず断られる」という意味ではありません。**検索機能が動く状態なら別の返りになりますし、この結果は試した環境での4回ぶんです。

🔑 **大事なのは断られたことではなく、断り文の中身でした。**4回とも、集め方（組合の名簿・法人番号公表サイト・タウンページ）と確認手順、そして所要時間まで書いてあります。<mark>断り文が、そのままこの仕事の手順書になっています。</mark>そして4回とも、同じ申し出をしました——集めたものを貼れば、絞り込みと整形はできます、と。

### 3. 判定は「○／×／確かめていない」の3つで書かせる

2択にすると、決まらないものがどちらかに寄ります。行き先を3つ作ります。

<div class="prompt">一覧の各行が、発注条件のどれを満たしているかを行ごとに書いてください。

「関東にある」「印刷会社である」「従業員100人以下」の3つを、それぞれ ○ ／ × ／ 確かめていない の3つで書いてください。私が渡した25行に書いていないことは、すべて「確かめていない」にしてください。あなたの知識で補わないでください。</div>

**2回試して、25行×3条件＝75マスすべてが真値と一致しました。**「確かめていない」に入るべき12マスも、2回とも12マスちょうどです。

⚠️ <mark class="warn">効いているのは「推測するな」ではなく、「確かめていない」という行き先を作ったこと</mark>です。禁止だけを渡すと、行き先が無いので推測が別の欄に混ざります。

2回とも、こちらが聞いていないのに範囲まで断りました——「業種欄の記載をそのまま採用しました。実際の事業内容までは確かめていません」。<mark>○の意味が「記載がそうなっている」に限定されます。</mark>

### 4. 「1件2分で確かめられる形」に変えさせる

ここで単価が決まります。確認に1件5分かかるか2分で済むかで、時給が倍以上変わります。

<div class="prompt">この一覧を、私が1件2分で確かめられる形にしてください。

行ごとに、私が最初に開くページを1つだけ書いてください。2つ以上書かないでください。どこを見れば分かるか見当がつかない行は、開く先を書かずに「見当がつかない」と書いてください。</div>

**2回試しました。2回とも、「見当がつかない」に置いたのは同じ4行**で、これは確認が要る12行のうち、こちらが「サイト不明」と書いておいた行と完全に一致します（25行全体では「サイト不明」は6行です）。存在しないURLを埋めた回は0回でした。1回目は理由まで書いています。

> 適当に検索結果ページを指定することもできますが、それは「どこを見れば分かるか」の答えにはなっていないので書きませんでした。

⚠️ **2回で違ったところもあります。**1回目は確認が要る12行だけを表にし、2回目は25行すべてに「開かなくてよい」まで書きました。**同じ指示文でも、表に出す範囲は割れます。**2回目は所要時間まで出しました（開くのは8行・2分×8＝約16分）。

## うまくいかないときの言い直し方 {: .fix }

### 発注元が「20件そろえてほしい」と言って譲らない {: .trouble }

<div class="prompt">発注元が「20件そろえてほしい」と言っています。

いま何件足りないかを書いたうえで、条件のどれをどこまで緩めると何件になるかを、条件ごとに分けて出してください。どれを緩めるべきかは決めないでください。決めるのは私です。</div>

**1回だけの結果です。**不足13件と書いたうえで、条件ごとに増える件数が出ました。真値と全部一致しています——従業員150人以下まで許すと＋1件、人数条件を外しても＋3件、業種を広げても**最大＋2件**、地域を外しても最大＋1件。

🔑 いちばん効いたのは、返り自身が書いたこの一行でした。

> B単独（最大9件）とC単独（最大8件）では20件に届きません。

<mark>「緩められる余地がどこにも無い」ことが、数で言えるようになります。</mark>これは発注元に持っていける材料です。「集まりませんでした」と言うのと、「地域条件を全部外しても8件です」と言うのは別のことです。

⚠️ **どれを緩めるかは決めさせないでください。**条件を動かすのは発注元との約束の話で、こちらが決めることではありません。約束をどう伝えるかは[発注者への返事](/recipes/client-reply-without-softening/)にあります（丁寧に書かせると、決めた条件のほうが消えます）。

### 一覧の見た目が整っていて、確かめたくなくなる {: .trouble }

これがこの仕事のいちばんの罠です。表になった瞬間、全部の行が同じ顔になります。

今回の実測では、AIの側が3回とも欄を分けてくれました。ただし<mark class="warn">分けさせる指示文を書かなければ、同じ表に並びます</mark>。同じ型の事故は[出品文を事実だけで書かせる](/recipes/listing-only-what-you-checked/)でも出ています（あちらは1件の商品、こちらは何十件の一覧です）。

→ **「そのまま出せる行」と「私が確かめる行」を、別の表に分けて出してください。**1つの表に印を付ける形だと、コピーしたときに印が落ちます。

## 応用・次の一手 {: .next }

### 確かめた結果を書き戻す欄を、先に作らせる

確認は自分の作業なので、書き込む場所が要ります。**1回だけ試した結果です。**

<div class="prompt">確かめた結果を私が書き足したいので、書き込む欄を作ってください。

欄は「確かめた日」「確かめた場所」「結果（合っていた／違っていた／たどり着けなかった）」の3つにしてください。あなたはこの3つを埋めないでください。空欄のまま出してください。</div>

**12行×3欄＝36マスが、すべて空欄で返りました。**埋める代わりに書き方の目安だけが添えられ、貼り付け用のTSVまで付いてきます。

<mark>「確かめた場所」の欄が、この仕事の成果物そのものです。</mark>納品するときに「どこを見て確かめたか」が1行ずつ残っていれば、それは確かめずに出したリストとは別の商品になります。

### 毎回同じ条件で集めるなら、自動にする

同じ発注元から似た条件で繰り返し受けるなら、条件文と絞り込みの指示文をファイルに置いて、[決まった時刻に自動で動かす](/recipes/github-actions-daily-cron/)形にできます。⚠️ そのときも<mark class="warn">「確かめていない」という行き先を、指示文から落とさないでください</mark>——短くする工程で真っ先に削られるのは、出力の見た目に効かない一文です。

### この記事の外に置いたもの

**AIが出した実在の会社名は、この記事に1件も載せていません。**確かめていないものを載せれば、この記事自身が「確かめずに納品する」ことになるからです。教材の25件はすべて架空です。

自分の中にある売り物を掘り出す話は[売れるものの棚卸し](/recipes/sell-what-you-already-do/)にあります。この記事は逆で、**外から集めたものをどう受け取るか**の話でした。<mark>確かめる工程は消えません。消えるのは、確かめる場所を探す時間のほうです。</mark>
