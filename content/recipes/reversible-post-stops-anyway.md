## これで何ができるか {: .what }

AIエージェントを自動で動かすとき、「重要な操作の前には必ず確認を取ること」という1行だけを守らせれば、危ないところで止まってくれる——そう言われます。<mark>実際に試すと、取り消せない操作を見逃すことは1件もありませんでした。</mark>ただし、取り消せる操作の一部を、余計に止めることがありました。プログラミングは要りません。

<mark class="warn">「戻せる」「バックアップは無い」といった可逆性の事実を本文から消すと、公式アカウントやLINEの主要な掲示を丸ごと差し替える操作だけ、8回中6回、余計に確認を挟みました。</mark>受領確認の定型返信や、自動返信文の1行修正は、同じ条件でもほとんど素通りしました。

| 条件 | 結果（取り消せない操作8種／戻せる操作4種） |
|---|---|
| 「戻せる」「バックアップなし」等の事実を本文に書く | 取り消せない操作は96回中96回、確認対象に入った。戻せる操作を余計に止めた回数はゼロ |
| 事実を消して、AI任せにする | 取り消せない操作は変わらず見逃しゼロ。ただし「公式発信の差し替え」だけ8回中6回、余計に止めた |
| 事実の代わりに「取り消せないか踏まえて」と1文だけ足す | 過剰確認は8回中6回→4回に減ったが、ゼロにはならなかった |

**この記事は、AIに実際に判定させた実測の記録です。**架空の秘書エージェントの設定を使っており、特定の会社の実例ではありません。

## 前提 {: .need }

- 定期実行や自動処理をAIエージェントに任せていて、「重要な操作の前には必ず確認を取ること」のような1行だけのガードレールを敷いている、または敷こうとしている
- 「AIエージェントを自由に動かすのではなく、重要な操作の前には許可を求めさせることが大切」という助言を、AIエージェントの運用を解説する記事でよく見かける
- 本文中に何が取り消せて何が取り消せないかを、いちいち書くのは手間だと感じている

この記事は、確認の仕組みそのものを設計する話ではありません。**AI自身に「これは重要か」を判断させたとき、その判断がどこまで当てになるか**、その1点だけを試しています。

## うまくいかないときの言い直し方 {: .fix }

### 「戻せる」操作まで、余計に止められる {: .trouble }

本文に可逆性の事実を書かないと、<mark class="warn">公式アカウントやLINEの主要な掲示を丸ごと
差し替える操作は、材料を変えても8回中6回、余計に確認を挟まれました。</mark>「重要な操作かどうか」を
「戻せるかどうか」ではなく「見える範囲の広さ」で判断していると考えられます。

この記事の結果どおりなら、直し方は指示文を強めることではありません。**タスクの説明そのものに、
戻せるかどうかの一言を足すこと**です。指示文2「「取り消せないか踏まえて」を1文足す」までは、
過剰確認を半分近くまでしか減らせませんでした。

### 念を押しても、直りきらない {: .trouble }

<mark class="warn">念押しそのものが効いたのかどうかは、この記事の材料では
確かめきれていません。</mark>「取り消せないか踏まえて」の
1文で過剰確認が7件から4件へ減った理由——念押しそのものが効いたのか、単なる回によるばらつきなのか——は
切り分けられていません。**確かめずに「念押しは半分だけ効く」とは言い切れないので、次に試すことの
1つとして残します。**確実なのは、事実（「戻せる」の一言）を書いたときだけ0件になった、という点です。

## 応用・次の一手 {: .next }

**この記事は、「AIエージェントの運用では、重要な操作の前に必ず確認を求めることが大切」という
定説を、実際に試しに行った記録です。**この材料・この回数では、答えは「見逃しは起きないが、
戻せる操作の一部を余計に止めることがある」でした。

[理由を上位のタスクだけに書いても、順位は保てるか](/recipes/priority-needs-a-reason-not-a-label/)と
同じ構図です。あちらは「理由の一文があるかどうか」で優先順位の結果がまるごと入れ替わりました。
この記事も、**指示文の言葉ではなく、材料に何を書くかが結果を左右**しました。

[止まった自動処理を頼み直す](/recipes/stuck-flag-proceed-verdict/)とは軸が逆です。あちらは
「進めるべきか判断して」という開いた聞き方が、自動化の中では「止まったまま」の同義語になる
（進めてよい条件を明示しないと、AIは異常を正確に見抜いても「待つ」から動かない）という話でした。
この記事は逆に、止めてほしい場面（重要な操作）を自己判断させたときの話です。**「開いた聞き方は
動かない側に倒れる」「自己判断は止める側に倒れる」——どちらも、こちらが条件を決めて渡さないと
安全側に振れる、という共通点があります。**

**毎朝の自動処理や、定期実行のAIエージェントに「重要な操作の前は確認して」とだけ伝えているなら、
確認することが2つあります。**

- 取り消せない操作（削除・確定・送金・一斉送信など）は、名前を挙げなくても見逃されにくい
- ただし「公式のSNS・LINEの主要な告知を丸ごと差し替える」のように**見た目が大きい対外的な操作**は、
  実際は戻せても、AIが自分から確認を挟みに来ることがある。頻繁に自動で回したい操作なら、
  タスクの説明に「戻せます」と一言添えておくと、余計な足止めを避けられます
