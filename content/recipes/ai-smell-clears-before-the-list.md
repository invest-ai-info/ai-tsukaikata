## これで何ができるか {: .what }

<mark>クラウドソーシングで「AI感をなくして人間らしく」と求められたとき、禁止語リストを渡すだけで十分かを実測しました。</mark>「禁止語リストを渡すと体感8割のAI臭が消える」という実践的な言い方がネット上にあります。ただし**何と比べて8割なのか**は確かめられていません。リストが無い場合と比べてなのかが、書かれていないのです。

典型的なAI臭い表現を13種、架空のブログ下書き2本に仕込みました。

- 表現の例：「〜と言えるでしょう」「いかがでしたか」「要するに」など
- 下書きの題材：リモートワークのコツ・観葉植物の水やり

**素朴に「人間らしく書き直して」とだけ頼んだ6回のうち、仕込んだ禁止語13種が全部消えたのは5回でした。**残り1回だけ、「今日からぜひ試してみてください」という形で「ぜひ」が1語だけ本文に残りました。<mark>禁止語リストを渡さなかった6回で、本文のどこかに1回でも残った禁止語は「ぜひ」ただ1種だけです。</mark>残り12種（「と言えるでしょう」「いかがでしたか」「要するに」など）は、リストを渡さなくても6回とも一度も出ませんでした。

禁止語リストを明示した6回は、6回とも13種全部が消えました。さらに機械的ルールを足した6回も結果は同じでした。

- 足したルール：「同じ文末表現を3回以上連続で使わないでください」
- 結果：6回とも全部消え、文末の3回以上連続は0回（リスト明示だけの版と同じ）

この記事はこの実測の生の返り（全18回）と、見逃していないかを確かめた過程をそのまま載せています。

## AIへの頼み方 {: .ask }

### 1. リモートワーク記事で、禁止語リストを明示して頼む

<div class="prompt">次の文章を、AIが書いたような文章ではなく人間らしい文章に書き直してください。次の語句は使わないでください：と言えるでしょう／いかがでしたか／要するに／つまり／することができます／かもしれません／ぜひ／と言っても過言ではありません／さまざまな／について解説します／となっています／このように／していきましょう</div>

上に続けて、禁止語13種のうち10種を仕込んだ架空の下書き（リモートワークのコツ・298字）を貼ります。

**3回とも、13種すべてが本文から消えました。**

> リモートワークを続けていると、「快適に働くには何が要るか」が少しずつ見えてきます。自分の経験で言えば、効いたのは次の3つです。
>
> 1つ目は作業場所。いちばん大きかったのは、静かな部屋を確保したことでした。（中略）3つ目は休憩です。在宅だと、気づけば何時間も座りっぱなしになりがちです。体にもよくないので、1時間に1回は立ち上がって水を飲むくらいの軽いルールをおすすめします。

### 2. 観葉植物記事でも、同じ指示文を試す

<div class="prompt">次の文章を、AIが書いたような文章ではなく人間らしい文章に書き直してください。次の語句は使わないでください：と言えるでしょう／いかがでしたか／要するに／つまり／することができます／かもしれません／ぜひ／と言っても過言ではありません／さまざまな／について解説します／となっています／このように／していきましょう</div>

<mark>禁止語リストを明示した版は、観葉植物の下書きでも3回とも、禁止語13種が全部消えました。</mark>材料2種×3回＝6回とも、禁止語リストを明示した版で禁止語が残った回は0回です。

### なぜこの言い方が効くのか

**禁止語を具体的な語句の列挙で渡すと、AIは「置き換えるべき語」を機械的に認識できます。**抽象的に「AI臭さを消して」とだけ頼むより、何を消すべきかが明確なぶん、確実に守らせやすいと考えられます。

ただし、下の実測が示すのは、**この明示自体は裏切りませんが、明示しなくても大半は同じ結果になっていた**という点です。リストの価値は「0から9割」ではなく「9割強から10割」を埋めることにありました。

## うまくいかないときの言い直し方 {: .fix }

### 禁止語リストを渡さずに「人間らしく」とだけ頼むとどうなるか {: .trouble }

禁止語リストを渡さず、指示文を短くしてみました。指示文はこれだけです。

<div class="prompt">次の文章を、AIが書いたような文章ではなく人間らしい文章に書き直してください。</div>

リモートワーク記事で3回試しました。

**3回とも、禁止語13種が本文から全部消えました。**うち2回は、書き直した本文のあとに「直したポイント」という自己解説を自分から付け足しました。解説の中では禁止語そのものを引用していましたが、肝心の本文には残っていませんでした。

同じ指示文を観葉植物記事でも試します。

<div class="prompt">次の文章を、AIが書いたような文章ではなく人間らしい文章に書き直してください。</div>

**3回中2回は全部消えましたが、1回だけ「今日からぜひ試してみてください」という形で「ぜひ」が本文に残りました。**禁止語リストを渡していないので、AIは「ぜひ」がAI臭いと見なされる語だという情報自体を持っていません。

<mark>材料2種×3回＝6回を通じて、禁止語13種のうち12種はリストが無くても6回とも一度も出ませんでした。</mark>リストが実際に消したのは、残った「ぜひ」という最後の1語だけです。

### さらに「同じ文末を3回以上連続させない」という機械的ルールを足すとどうなるか {: .trouble }

仕込んだ下書きは、もともと「〜と言えるでしょう」「〜でしょう」のように、同じ語尾で終わる文が4つ連続する作りでした。禁止語リストに加えて、文末の繰り返しそのものを禁じる一文を足しました。

<div class="prompt">次の文章を、AIが書いたような文章ではなく人間らしい文章に書き直してください。次の語句は使わないでください：と言えるでしょう／いかがでしたか／要するに／つまり／することができます／かもしれません／ぜひ／と言っても過言ではありません／さまざまな／について解説します／となっています／このように／していきましょう。さらに、同じ文末表現（「〜でしょう」「〜ます」など）を3回以上連続で使わないでください。</div>

リモートワーク記事で3回試しました。**3回とも禁止語13種が全部消え、文末が3回以上連続した回も0回でした。**

同じ指示文を観葉植物記事でも試します。

<div class="prompt">次の文章を、AIが書いたような文章ではなく人間らしい文章に書き直してください。次の語句は使わないでください：と言えるでしょう／いかがでしたか／要するに／つまり／することができます／かもしれません／ぜひ／と言っても過言ではありません／さまざまな／について解説します／となっています／このように／していきましょう。さらに、同じ文末表現（「〜でしょう」「〜ます」など）を3回以上連続で使わないでください。</div>

**こちらも3回とも、禁止語13種が全部消え、文末が3回以上連続した回も0回でした。**材料2種×3回＝6回とも、ここまではリスト明示だけの版（指示文1・2）と同じ結果です。

<mark class="warn">文末の3回以上連続を禁じる機械的ルールを足しても、リスト明示だけの版からの「上乗せ」は観測されませんでした。</mark>理由は、文末の3回以上連続という問題自体が、素朴な版の時点ですでに一度も起きていなかったからです。

- 仕込んだ「でしょう」で終わる文は、本文を見直す段階でほとんどの回に自然に消えていました
- 18回を通じて「でしょう」という語尾が残ったのは1回・1件だけでした
- 機械的ルールの効果を検出するには、文末の繰り返しがリスト明示だけでは解消しない材料が別に必要です

## 応用・次の一手 {: .next }

発注者から「AI感をなくして」とだけ言われた場合でも、この実測の範囲では次の順番が効率的でした。

1. まずは素朴に「人間らしく書き直して」と頼む
2. 残った語だけを、その場で個別に名指しして禁止する

最初から長い禁止語リストを作り込む必要は無さそうです。素のまま1回試して、実際に残った語を追加で禁止するほうが手間が少なく済みます。

同じ原稿を何度も直す仕事なら、[毎回の作業を自動化した記事](/recipes/github-actions-daily-cron/)の型も使えます。禁止語チェックの部分だけをスクリプト化しておけば、毎回AIに頼らず確認できます。

⚠️ **この結果は、この2つの架空の下書き・のべ18回での実測です。**次の範囲は確かめていません。

- 禁止語が13種よりずっと多い場合、またはこの13種以外の表現
- 文末の繰り返しが、禁止語の除去だけでは解消しない構造の下書き（機械的ルールの効果はまだ検出できていません）
- 発注者が実際に使う「AI検出ツール」による判定（この記事が測ったのは、こちらが決めた禁止語リストとの一致だけです）

今回の生の返り18回ぶんと判定コードは `docs/evidence/ai-smell-clears-before-the-list.md` に全文置いてあります。
