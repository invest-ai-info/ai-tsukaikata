## これで何ができるか {: .what }

クラウドソーシングの提案文づくりで、「募集文の表現から依頼主の本当の課題を読み取って提案する」と採用率が上がる、という話をよく見かけます。<mark>この記事は、AIに提案文を書かせたとき、募集文に書かれている本当の狙いを、頼まなくても拾うかを実測したものです。</mark>

架空の募集文を2種類（①サイトのリニューアル②展示会用の動画ナレーション）用意し、それぞれに「依頼主が本当に困っていそうなこと」を1行だけ仕込みました。同じ狙いの一文を、**①地の文（背景説明の一文として自然に混ぜる）②本題と無関係な追記として切り離す（「話は変わりますが」と前置きして末尾に添える）**、の2通りの置き方で試しています。

- 材料1（サイトリニューアル）＝表向きの依頼は「スマホで見にくいので直してほしい」。仕込んだ本当の狙いは「最終面接後の入社辞退が増えている」（採用ページの印象が関係するかもしれない、という一段の推論を要する）
- 材料2（動画ナレーション）＝表向きの依頼は「展示会用の会社紹介動画の原稿を書いてほしい」。仕込んだ本当の狙いは「前回の展示会で、隣のブースの動画のほうが分かりやすいと言われた」

「この募集に応募する提案文を書いてください」とだけ素朴に頼んだ場合、この狙いに提案文の本体が触れるかどうかを、狙いを表す語（「辞退」「隣のブース」など）が本文にあるかで機械判定しました。

<figure class="figure">
<img src="/static/images/proposal-hidden-want-hit-and-miss.svg" alt="提案文が募集文に書かれた本当の狙いを拾うかどうかを、狙いの置き方（地の文に織り込む／本題と無関係な追記として切り離す）で比べた表。すべて提案文の本体で本音の語に触れた回数で、多いほど拾えている。材料1（サイトリニューアル）は、狙いが無い対照で0/4、地の文に織り込むと6/6、切り離した追記にすると0/6、切り離した追記に「依頼主が本当に困っていそうなことも考えて」を足すと6/6に戻った。材料2（動画ナレーション）は、対照で0/4、織り込みで4/4、切り離しで3/4、一文を足すと4/4だった。下の枠には、地の文に織り込むと素朴に頼むだけで2つの材料とも満点で拾ったこと、本題と無関係な追記に切り離すと材料1は0/6まで落ちたが材料2は3/4で落ち方は材料によること、一文を足すと切り離した版でも両方とも満点に戻ったことが書かれている。">
<figcaption>拾うか拾わないかは、狙いが分かりにくいかどうかではなく、置き場所で決まった。</figcaption>
</figure>

<mark>結論から言うと、「行間を読む」かどうかは、狙いが読み取りにくいかどうかでは決まりませんでした。</mark>地の文に混ぜると2つの材料とも6/6・4/4で拾いましたが、本題と無関係な追記として切り離すと、材料1は0/6まで落ちました（材料2は3/4で、落ち方は材料によって違いました）。

## 前提 {: .need }

| | |
|---|---|
| かかる時間 | 15分 |
| 費用 | 無料。ブラウザのチャットAIで足ります |
| 必要なもの | 特にありません。募集文を読んで提案文を書かせる場面の話です |

<mark class="warn">この記事は「採用率が上がるか」を測ったものではありません。</mark>測ったのは「AIが募集文の本文中の情報を拾うかどうか」だけです。実際に提案文を送るときは、拾われた内容が事実として正しいか、相手にとって失礼にならないかを必ず自分で確認してください。応募文づくり全般は[実績を盛らずに提案文を組む記事](/recipes/proposal-without-inflating/)も参考にしてください。

## AIへの頼み方 {: .ask }

### 1. まず、狙いが書かれていない募集文で素朴に頼む（対照）

<div class="prompt">次の募集文を読み、この募集に応募する提案文を書いてください。

【募集文】
（ここに募集文を貼る）</div>

材料1のヒントなし版（サイトのリニューアル依頼のみで、辞退の話は一切無い）を4回試しました。**当然ながら4回とも「辞退」に類する話は一切出てきません。**この0/4を基準にします。

### 2. 同じ頼み方で、狙いを地の文に混ぜた募集文を渡す

<div class="prompt">次の募集文を読み、この募集に応募する提案文を書いてください。

【募集文】
（ここに募集文を貼る）</div>

指示文1と1文字も違いません。材料だけを、背景説明の一文に「最近は最終面接まで進んだ方が入社を辞退するケースが増えていて、人事担当は悩んでいます」を混ぜた版に差し替えて6回試しました。**6回とも提案文の本体で「辞退」に触れました。**「募集文を拝見し、『スマホでの見づらさ』と『採用辞退の増加』という2つの課題は、実はつながっている可能性があると感じました」のように、自分から2つの情報を結びつけた回もありました。

### 3. 同じ頼み方で、狙いを本題と無関係な追記に切り離した募集文を渡す

<div class="prompt">次の募集文を読み、この募集に応募する提案文を書いてください。

【募集文】
（ここに募集文を貼る）</div>

指示文1・2とまったく同じ指示文です。材料だけ、同じ「辞退」の一文を、本文の末尾に「（追記：話は変わりますが、最近は最終面接まで進んだ方が入社を辞退するケースが増えていて、人事担当が悩んでいます。）」という形で切り離した版に差し替えて6回試しました。

<mark class="warn">**6回とも提案文の本体は「辞退」に一切触れませんでした。**</mark>しかも6回中5回は、提案文の前に「追記部分の採用辞退のお悩みは今回のご依頼とは直接関係のない内容のようですので、提案文には含めず……」と、**除外することを自分から宣言してから**書いていました。見落としではなく、意図的な線引きでした。

### 4. 別の題材（動画ナレーション）で、地の文に混ぜた版を試す

材料を変えても同じ形になるかを確かめます。

<div class="prompt">次の募集文を読み、この募集に応募する提案文を書いてください。

【募集文】
（ここに募集文を貼る）</div>

材料2の織り込み版（「前回の展示会では、隣のブースの会社の紹介動画のほうが分かりやすいと言われてしまったことがありました」を背景説明に混ぜた版）を4回試しました。**4回とも提案文の本体で「隣のブース」に触れました。**材料1と同じ形が、業種を変えても再現しました。

### 5. 同じ題材で、切り離した版を試す

<div class="prompt">次の募集文を読み、この募集に応募する提案文を書いてください。

【募集文】
（ここに募集文を貼る）</div>

同じ「隣のブース」の一文を、末尾に切り離した版を4回試しました。**材料1とは違い、4回中3回は提案文の本体でそのまま言及しました。**残る1回は本体では触れず、「トーンだけでさりげなく示す」という婉曲な対応を選び、その判断自体を自分から末尾の補足に書いていました。<mark>切り離すという同じ操作でも、材料1（0/6）ほど強くは効きませんでした。</mark>

## うまくいかないときの言い直し方 {: .fix }

### 大事な情報が、募集文の本題と離れた場所にあるとき {: .trouble }

<mark>効いたのは「依頼主が本当に困っていそうなことも考えてください」と1文足すことでした。</mark>指示文3（材料1の切り離し版）に、この一文を足します。

<div class="prompt">次の募集文を読み、この募集に応募する提案文を書いてください。依頼主が本当に困っていそうなことも考えてください。

【募集文】
（ここに募集文を貼る）</div>

**6回試して、6回とも「辞退」に触れるようになりました。**「募集文の本題はコーポレートサイトのリニューアルですが、あわせて記載のあった『最終面接後の内定辞退が増えている』というお悩みも、実はサイトのリニューアルと無関係ではないと考えます」のように、自分で関連づけて提案に組み込みました。同じ一文を材料2の切り離し版（3/4だったもの）に足すと、こちらも4回中4回に上がりました。

### 「切り離せば無視される」と決めつけない {: .trouble }

<mark class="warn">材料1では切り離すと0/6でしたが、材料2では切り離しても3/4が拾いました。</mark>「本題と無関係な場所に置けば、AIは触れない」と一般化しないでください。材料2の狙い（前回の展示会で比較されて評価が低かった）は、今回の依頼（分かりやすい動画にする）と話題として近く、切り離した書き方でも自然につながって見えたのだと考えられます。**狙いが今回の依頼とどれだけ近い話題かによって、切り離しの効き目は変わります。**確実に拾わせたいなら、置き場所を工夫するより、指示文4のように名指しで頼むほうが安定します。

## 応用・次の一手 {: .next }

**自分が書く募集文・依頼文の側でも、応用できます。**本当に伝えたいこと（予算の上限、譲れない条件など）を、本題から浮いた場所に書くと、AIによる要約や下書きから抜け落ちるかもしれません。[材料に無い情報を先に挙げさせる記事](/recipes/ask-what-is-missing-first/)や、[見積もりの前提を先に言うか後に言うかで漏れが変わる記事](/recipes/estimate-gap-leaks-on-money-ask/)も、情報の「置き場所」が結果を左右するという同じ性質を、別の場面で確かめています。

⚠️ **この結果は、この2つの架空の募集文・のべ40回での実測です。**「地の文なら必ず拾う」「切り離せば必ず無視される」と一般化せず、大事な情報は指示文で名指しして確認するか、今回の④のように「本当に困っていそうなことも考えて」と一文添えてください。

今回の生の返り40回ぶんと判定コードは `docs/evidence/proposal-reads-between-lines-if-woven-in.md` に全文置いてあります。
