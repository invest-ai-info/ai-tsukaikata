## これで何ができるか {: .what }

<mark>分割払いの1件で、2回分（非連続）が同時に未入金になっていても、AIはそれを見落としませんでした。</mark>用意したのは次の2種類です。

- 架空の内装リフォーム工事12件（6分割）
- 動画制作費の受託契約12件（8分割）

どちらも1件だけ、「両端ではない・隣り合ってもいない」2回分を入金明細から抜きました。材料2種×5回＝10回試しましたが、2回分の両方・正しい不足額を言い当てられなかった回は0回でした。

ただし、<mark class="warn">別の契約と一緒に24件を1つのメッセージへ混ぜて聞くと、3回のうち1回は、実在する入金まで「未入金」に数えてしまいました。</mark>この結果は、この2種類の架空データ・合計21回の実測です。本文の最後に、確かめていないことも書いておきます。

[3回の分割](/recipes/three-way-split-does-not-break-the-match/)と[4分割・5分割](/recipes/four-and-five-way-split-does-not-break-the-match/)を実測した先行記事は、どちらも「仕込みは1回分だけ」という前提でした。2回以上が同時に抜けるケースは試していません。この記事はその続きです。

## 前提 {: .need }

| | |
|---|---|
| かかる時間 | 20分 |
| 費用 | 無料。ブラウザのチャットAIで足ります |
| 必要なもの | 契約（請求）一覧と、入金明細の2つの表 |
| プログラミング | **不要**。この記事の指示文をコピーして貼るだけです |

<mark class="warn">口座番号や実在の取引先名は貼らないでください。</mark>この記事は架空の氏名・社名・金額を使っています。実在の人物・団体とは関係ありません。

分割払いの入金照合そのものの基本的な挙動は[分割払いの入金照合を実測した記事](/recipes/installment-payments-add-up-correctly/)にあります。1つの入金が2件ぶんの合算だったケースは[入金が合算されて未入金に見える記事](/recipes/combined-payment-missed-as-unpaid/)で確かめています。この記事が見ているのは、そのどちらとも違う軸——「1件の契約の中で、2回分が同時に未入金になっている」ケースです。

## AIへの頼み方 {: .ask }

### 1. 内装リフォーム（6分割）で、2回同時の未入金を素朴に聞く

架空の内装リフォーム工事12件（6回払い＝着手金+中間金1〜4+残金）を用意しました。山本様（2階増築部分改装）だけ、2回分（計780,000円）を入金明細から抜いています。抜いたのは中間金1（2回目）と中間金4（5回目）で、両端でも隣り合ってもいません。

<div class="prompt">まだ入金されていない工事はどれですか。1件が複数回に分けて入金されることがあります。合計額が工事金額と一致するかどうかも確認してください。</div>

上に続けて、契約一覧と入金明細を貼ります。

**5回とも、山本様の中間金1・中間金4の両方と、不足額780,000円を正しく指摘しました。**「1回だけ足りない」と数え間違えた回や、他11件を誤って未入金扱いした回は0回です。

### 2. 動画制作費（8分割）でも同じ聞き方を試す

業種・分割回数が変わっても同じ結果になるかを見るため、動画制作費の受託契約12社（8回払い＝企画料+制作1〜6+納品金）でも同じ実験をしました。ミナト広報社だけ、2回分（計480,000円）を抜いています。抜いたのは制作2（3回目）と制作6（7回目）です。

<div class="prompt">まだ入金されていない案件はどれですか。1件が複数回に分けて入金されることがあります。合計額が契約金額と一致するかどうかも確認してください。</div>

**こちらも5回とも、制作2・制作6の両方と不足額480,000円を正しく指摘しました。**内装リフォームの実験と合わせて、2種類の材料・合計10回を通じて、2回同時の未入金を見落とした回はありません。

### 3. 内装リフォームで、どの回が抜けているかまで書かせる

根拠まで書かせる言い方も試しました。

<div class="prompt">まだ入金されていない工事はどれですか。どの回（着手金・中間金・残金のうち）が抜けているかを、工事ごとに全部書いてください。</div>

**3回とも、中間金1・中間金4の両方を名指しで「未入金」と書きました。**着手金・中間金2・中間金3・残金を誤って抜けと書いた回は0回です。

### 4. 動画制作費でも、どの回が抜けているかまで書かせる

<div class="prompt">まだ入金されていない案件はどれですか。どの回（企画料・制作・納品金のうち）が抜けているかを、案件ごとに全部書いてください。</div>

**こちらも3回とも、制作2・制作6の両方を名指しで「未入金」と書きました。**材料①・②の詳細版を合わせて、2回同時の未入金をどちらも正しく名指しした回は合計6回です。

### なぜこの言い方が効くのか

「1件が複数回に分けて入金されることがあります」という一文が、1回分だけ見つけて安心する動きを止めていると考えられます。「どの回が抜けているか」まで書かせると、AIは着手金から残金まで（または企画料から納品金まで）を1回ずつ順番に照合する形になります。2回目を見つけたあとも、最後の回まで照合を続けていました。

## うまくいかないときの言い直し方 {: .fix }

### 24件を1つのメッセージに混ぜると、どうなるか {: .trouble }

ここまでは、1種類の材料（12件）だけを渡していました。今度は、内装リフォーム12件と動画制作費12件、合わせて24件・入金明細164行を1つのメッセージにまとめて聞きました。指示文は、分割回数が契約ごとに違うことを補っただけです。

<div class="prompt">まだ入金されていない契約はどれですか。契約によって分割回数（6回・8回）が違います。1件が複数回に分けて入金されることがあります。合計額が契約金額と一致するかどうかも確認してください。</div>

**3回のうち2回は、山本様（中間金1・中間金4）とミナト広報社（制作2・制作6）の2件・4回分だけを正しく指摘しました。**残り1回は違いました。ミナト広報社について、実際には2026-06-22に入金済みの「制作1」（240,000円）まで未入金に加えたのです。存在しない3つ目の欠落を作り、不足額も720,000円（正しくは480,000円）と誤って計算しました。<mark class="warn">単独の材料では16回とも崩れなかった判定が、材料を24件・164行にまとめた途端に崩れました。</mark>分割方式そのもの（6回・8回）を取り違えたのではなく、1社ぶんの行数を数え間違えたと考えられます。

## 応用・次の一手 {: .next }

**毎月やるなら、分割回数が契約ごとに違っても、2回分が同時に抜ける可能性まで含めて同じ手順で回せる形にしておくと安心です。**

<div class="prompt">毎月、着手金・中間金数回・残金のように分割回数が契約ごとに違う入金を、入金明細と契約一覧から突き合わせたいです。1件につき2回分が同時に未入金になっていることもあります。件数は月によって10件のときも40件のときもあります。プログラミングはできません。私が毎月やることを、番号を振って箇条書きで教えてください。</div>

2回試したところ、手順の数（13個と12個）は違いました。それでも、次の骨格は共通していました。

- 契約ごとに、回次と金額の予定を表にしておく
- 入金明細を、毎月同じ形で並べる
- 1行ずつ照合してチェックを付ける
- 2回分がまとめて1本の入金になっている可能性も見て、合算した金額とも照合する
- 対応づけられなかった入金・チェックの付かなかった回次を、両方向から洗い出す
- 月をまたいで、未入金を次月に引き継ぐ

両回とも「1件につき2回分が同時に未入金」という条件に自分から触れ、合算一致を試す手順を含めていました。⚠️ **ただし、この記事の実測では「24件を1通に混ぜると、1社ぶんの行数を数え間違える」ことも分かっています。**毎月の件数が多い月（40件など）は、分割方式ごとにグループを分けてから照合すると、取りこぼしを減らせるかもしれません。

⚠️ **この結果は、この2種類の架空データ・合計21回の実測です。**「AIは2回同時の未入金を絶対に見落とさない」と一般化しないでください。試したのは、次の範囲までです。

- 仕込んだ2回分はどちらも「両端ではない・隣り合っていない」組み合わせのみ（連続する2回や、最初と最後の組み合わせは試していません）
- 1件の契約での同時未入金は2回分まで（3回分以上は試していません）
- 24件を混ぜた実測は3回のみ（もっと多く試すと、誤りの頻度が変わる可能性があります）
