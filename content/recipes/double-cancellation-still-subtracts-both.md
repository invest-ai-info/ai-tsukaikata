## これで何ができるか {: .what }

[キャンセルの説明を検算する記事](/recipes/cancellation-note-half-goes-unchecked/)では、キャンセル額だけが書かれ確定額が書かれていない契約（1件分）を仕込みました。計算手順を明示する言い方なら、10回とも正しく見つけています。<mark>今回は、同じ備考に2件分のキャンセル額が同時に書かれている契約を仕込み、同じ言い方が同じ精度を保つかを確かめました。</mark>

用意したのは次の2種類です。

- 架空のWebサイト保守契約12社
- 架空のSNS運用代行契約12社

どちらにも、3種類の契約を1件ずつ仕込みました。

- **真の未入金**：備考なし。入金が0円
- **正当なキャンセル**：備考に確定した請求額まで明記。入金はその確定額どおり
- **2件同時の曖昧なキャンセル**：備考に「2件分のキャンセル額」だけ書かれ、確定額は書かれていない。実際の入金は、基本月額から2件分を引いた額より**さらに少ない**

**計算手順を明示する言い方は、2件同時でも10回とも隠れた不足を見つけ、正当なキャンセルを誤って疑った回は0回でした。**<mark>この結果は、1件分のキャンセルだけを仕込んだ前の記事と同じ精度です。</mark>

比較のために、計算手順を明示しない素朴な聞き方も同じ材料で10回試しました。<mark class="warn">9回は正しく見つけましたが、残り1回は「不足額3,500円」という見出しの直後に、計算の説明として「差は2,500円不足」という**別の数字**を書いていました。</mark>正解は2,500円です。見出しだけ読むと誤った額を信じてしまう崩れ方で、前の記事には出ていなかった形です。

## AIへの頼み方 {: .ask }

### 1. Webサイト保守契約で、計算手順を明示して聞く

架空のWebサイト保守契約12社を用意しました。3件だけ、ふつうと違う行を混ぜています。

- **たんぽぽ保育園**：入金が0円（真の未入金）
- **北斎自動車**：備考に「オプションの多言語対応（13,000円）をキャンセルされたため、請求額を40,000円に修正済みです」と確定額まで明記。入金もその40,000円どおり（正当なキャンセル）
- **満月印刷**：備考に「オプションA（年末休業対応・3,000円）とオプションB（深夜対応・2,000円）の両方をキャンセルされたとの連絡があり、返金対応済みです」とだけ書かれ、確定額は書かれていない（2件同時の曖昧なキャンセル）
  - 本来の確定額＝基本月額49,000円 − 2件分（合計5,000円）＝44,000円のはず
  - 実際の入金は40,000円。4,000円が説明のつかない不足のまま残っている

<div class="prompt">まだ入金に不足がある契約はどれですか。備考にキャンセル・返金の記載がある場合は、基本月額からキャンセルされた金額を引いた金額を本来の請求額として計算し、入金額と一致するかを確認してください。一致しない場合は不足として挙げてください。会社名と不足額を挙げてください。</div>

上に続けて、契約一覧（社名・基本月額・備考・今月の入金額）を貼ります。

**5回試したところ、5回とも満月印刷の不足4,000円を正しく見つけました。**備考は「2件分」としか書いておらず、「合計」という言葉もありませんが、5回とも3,000円と2,000円の両方を引いています。北斎自動車を誤って不足扱いした回は0回です。

### 2. SNS運用代行契約でも、計算手順を明示して聞き直す

同じ構造を、別の業種でも確かめました。

- **朝日整体院**：入金0円（真の未入金）
- **緑風工務店**：確定額36,000円まで明記され、入金も一致（正当なキャンセル）
- **星空クリニック**：備考に「ストーリーズ投稿オプション（4,000円）と、ハイライト編集オプション（1,500円）の両方をキャンセルされたとの連絡があり、返金対応済みです」とだけ書かれる（2件同時の曖昧なキャンセル）
  - 本来の確定額は45,500円。実際の入金は43,000円だった

<div class="prompt">まだ入金に不足がある契約はどれですか。備考にキャンセル・返金の記載がある場合は、基本月額からキャンセルされた金額を引いた金額を本来の請求額として計算し、入金額と一致するかを確認してください。一致しない場合は不足として挙げてください。会社名と不足額を挙げてください。</div>

**こちらも5回とも、星空クリニックの不足2,500円を正しく見つけました。**緑風工務店を誤って不足扱いした回は0回です。2種類の材料を合わせると、**10回とも**2件同時の曖昧なキャンセルの隠れた不足を見つけました。

### なぜこの言い方が効くのか

指示文は「キャンセルされた金額」としか言っていません。「2件分」「合計」という言葉は入れていません。<mark>それでも、備考に2つの金額が書かれていれば、両方を基本月額から引く動きになりました。</mark>この言い方が指定しているのは、金額の個数ではなく計算の手順そのものです。「基本月額から引いて入金額と一致するか確認する」という手順なら、キャンセルが何件あっても同じように繰り返されます。

## うまくいかないときの言い直し方 {: .fix }

### 計算手順を省くとどうなるか {: .trouble }

比較のため、計算手順を書かない素朴な聞き方も同じ材料で試しました。

<div class="prompt">まだ入金に不足がある契約はどれですか。会社名と不足額を挙げてください。問題がなければ「不足はありません」と書いてください。</div>

Webサイト保守契約で5回、運用代行契約で5回、合計10回試したところ、**9回は正しく満月印刷・星空クリニックの不足を見つけました。**正当なキャンセル（北斎自動車・緑風工務店）を誤って不足扱いした回は10回とも0回です。1件分のキャンセルだけを仕込んだ前の記事では、素朴な聞き方は10回中5回しか見つけられませんでした。<mark>今回の2件同時のケースでは、素朴な聞き方でも9回見つかりました。</mark>

ただし、残り1回は違う崩れ方をしました。星空クリニックについて、同じ回答の中に**2つの違う不足額**が出てきたのです。

- 回答の見出し：「不足額 **3,500円**」
- 直後の説明：「正しくは51,000−5,500＝45,500円のはずで、入金43,000円との差は**2,500円**不足」

正解は2,500円です。計算の過程は正しいのに、見出しの数字だけが違っています。

```
【1回だけ出た崩れ方（該当箇所のみ抜粋）】
不足額 3,500円（キャンセルはストーリーズ4,000円＋ハイライト1,500円＝5,500円分のはずなのに、
請求は51,000円→43,000円へ8,000円引かれている。正しくは51,000−5,500＝45,500円のはずで、
入金43,000円との差は2,500円不足）
```

<mark>見出しの数字だけを読むと、間違った額を信じてしまいます。</mark>計算手順を明示した言い方では、この崩れ方は10回とも起きていません。

### 「説明が合っているか確認して」では足りるか {: .trouble }

[前の記事](/recipes/cancellation-note-half-goes-unchecked/)で試した、計算の手順を書かない軽い言い方も、同じ材料で試しました。

<div class="prompt">まだ入金に不足がある契約はどれですか。備考にキャンセル・返金の記載がある場合は、その説明が入金額と合っているか確認してください。会社名と不足額を挙げてください。</div>

Webサイト保守契約で3回試したところ、1回目と3回目は満月印刷の不足4,000円を正しく見つけました。ところが2回目は、計算そのものを間違えました。

- 書いていた式：「基本月額49,000円 − 3,000円 − 2,000円 = 46,000円」
- 正しい答え：49,000から3,000円と2,000円を引けば44,000円

この計算違いのまま「まとめ」の表には**満月印刷の不足額を6,000円**と書いていました（正解は4,000円）。

<div class="prompt">まだ入金に不足がある契約はどれですか。備考にキャンセル・返金の記載がある場合は、その説明が入金額と合っているか確認してください。会社名と不足額を挙げてください。</div>

運用代行契約では3回とも星空クリニックの不足2,500円を正しく見つけ、計算違いは起きませんでした。6回を合わせると、<mark>軽い言い方では5回は正しく、1回は2件分の引き算そのものを間違えました。</mark>

計算手順を明示した言い方（本文のAIへの頼み方）では、10回の実測を通じてこの種の計算違いは1件も起きていません。**見出しの数字だけでなく、計算の根拠（基本月額・引いた2つの金額・結果）まで読む習慣が、素朴な言い方・軽い言い方を使うときの保険になります。**

## 応用・次の一手 {: .next }

キャンセルが何件重なっても同じ手順で確かめたいなら、この指示文を毎月の確認に組み込めます。

<div class="prompt">毎月、顧客ごとの基本月額と入金額を突き合わせて、不足がある契約を見つけたいです。1社の中で複数のキャンセル・返金が重なる場合もあります。プログラミングはできません。私が毎月やることを、番号を振って箇条書きで教えてください。</div>

2回試したところ、どちらも「備考にある金額をすべて拾って合計してから引く」という手順を自分から含めていました。1件のキャンセルだけを前提にせず、複数ある場合を言葉で足しておくと、手順の案にも反映されます。

⚠️ **この結果は、この2種類の架空データ・合計28回（計算手順を明示した版10回・素朴な版10回・軽い言い方の版6回・応用の自動化プロンプト2回）の実測です。**「AIは何件分のキャンセルでも必ず正しく処理する」と一般化しないでください。試したのは、次の範囲までです。

- 1社の中で仕込んだ曖昧なキャンセルは2件分のみです。3件以上が同時に重なる場合は試していません
- 2件分のキャンセル額は、どちらも備考の同じ文の中に書きました。別々の文・別の段に分けて書かれる場合は試していません
- 素朴な聞き方・軽い言い方は材料ごと3〜5回のみです。もっと多く試すと、数字が食い違う頻度が変わる可能性があります
