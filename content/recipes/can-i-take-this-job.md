## これで何ができるか {: .what }

副業をしていると、いちばん判断に困るのがこれです。<mark>いま3件抱えている。そこへ新しい依頼が来た。受けられるのか</mark>。

計算そのものは、引き算1本です。**使える時間 − いま抱えている案件 − 新しい依頼 = 差**。難しいのは計算ではなく、材料を集めて並べるところです。AIに任せられるのは、まさにそこです。

架空の材料（2週間ぶんの予定表・抱えている案件3件・幅つきの見積もりが付いた新規の依頼1件）を、**きつい側と余裕がある側の2本**作り、7個の指示文を**合わせて20回**通しました。

- **計算は毎回正しかった。**使える合計・既存の残り・差・新規の下限と上限は、どの頼み方でも材料から計算した真値どおりでした
- **そのまま聞くと、判断が付いてくる。**「受けられます」「対応できます」「見送り」といった言い切りが、4回で **2語・3語・1語・3語**
- **「計算だけしてください」にすると、言い切りは4回とも0語**になり、返りは3,241字から338字まで縮みました

</figure>

<mark class="warn">受けるか断るかを決めるのは、あなたです</mark>。AIに渡してよいのは引き算までで、そこから先は渡さないほうがいい、というのがこの記事の結論です。

## 前提 {: .need }

| | |
|---|---|
| かかる時間 | 15分 |
| 費用 | 無料。ブラウザのチャットAIで足ります |
| 必要なもの | 2週間ぶんの空き時間の枠・抱えている案件の残り分数と締切・新しい依頼の見積もり |
| プログラミング | **不要**。3つを貼って、指示文をコピーするだけです |

1件が何時間かかるかは、この記事では扱いません。そこは[案件にかかる時間を、AIに当てさせず自分の記録から出す](/recipes/estimate-hours-from-your-own-log/)にあります。<mark>この記事は、その見積もりが出たあと——それが「自分の予定表に入るのか」を見るところ</mark>です。

**見積もりは幅で持ってきてください**。今回の材料は下限800分・上限1,120分にしてあり、**下限なら入り、上限なら入りません**。どちらを使ったかで答えが逆になる、というのがこの題材の芯です。

## AIへの頼み方 {: .ask }

### 1. まず、そのまま聞いてみる

<div class="prompt">副業の話です。新しい依頼が来ました。

（使える時間の枠・抱えている案件の残り分数と締切・新しく来た依頼を、そのまま貼る）

この依頼、受けられますか。</div>

4回とも、引き算は正確でした。真値の7つの数（使える合計2,160分・既存1,140分・差1,020分・下限800分・上限1,120分・220分あまる・100分たりない）が、ほぼ全部そろって出ます。

**そのうえで、判断が付いてきます。**

> # 結論：条件を付ければ受けられます。無条件なら断ったほうがいいです

<mark class="warn">この判断には、あなたの事情が1つも入っていません</mark>。単価も、その取引先と続けたいかも、来月の予定も、材料には書いていないからです。それでも文の形は結論なので、読むとそこで決まった気になります。

返りはどれも長く、**1,974字から3,241字**ありました。読むほうも、どこが計算でどこが意見かを分けながら読むことになります。

### 2. 判断をやめさせて、引き算の4つの数だけ出させる

これがこの記事でいちばん効いた形です。

<div class="prompt">副業の話です。新しい依頼が来ました。

（使える時間の枠・抱えている案件の残り分数と締切・新しく来た依頼を、そのまま貼る）

受けるかどうかは私が決めます。計算だけしてください。

次の4つを、分の数字で1行ずつ書いてください。
・この2週間に使える時間の合計
・いま抱えている案件に残っている時間の合計
・新しい依頼に要る時間（見積もりの下限と上限の2通り）
・その差（下限で見た場合と、上限で見た場合の2通り）

受ける・断る・おすすめは書かないでください。</div>

**4回とも、受ける・断るの言い切りは0語**でした。長さも **338字〜612字**まで落ちています。数字は4回とも真値どおりです。

<figure class="figure">
<img src="/static/images/job-ask-shape-vs-verdict.svg" alt="頼み方を3通りに変えて、返りの長さと、受ける・断るの言い切りの語数を並べた図。材料は2本、それぞれ2回ずつ通した。そのまま「この依頼、受けられますか」と聞くと、材料Aの1回目が2,520字で言い切り2語、2回目が3,241字で3語、材料Bの1回目が2,308字で1語、2回目が1,974字で3語だった。「受けるかどうかは私が決めます。計算だけしてください」にすると、612字・521字・338字・349字となり、言い切りは4回とも0語になった。出す形を6行に固定した保存版では、103字・103字・259字・276字で、言い切りはやはり4回とも0語。材料Aの2回は1文字も違わなかった。引き算の4つの数は、どの頼み方でも材料から計算した真値どおりだった。変わったのは判断が付くかどうかと、返りの長さだけである。ただし保存版の材料Bでは、こちらが決めた最後の行の様式が事実と合わず、2回とも様式のほうを変えて注記が付いた。">
<figcaption>計算の質は変わりません。落ちたのは判断と、読む量だけです。</figcaption>
</figure>

<mark>「私が決めます」を先に置くのが効いています</mark>。禁止だけを渡すのではなく、決める人が誰かを書いてから禁止しています。同じ形は[引き受ける範囲を決めきる](/recipes/scope-what-is-not-included/)の〔私が決める〕欄にも出てきます。

### 3. 材料に無い前提を、〔前提〕として別の行に出させる

引き算が成り立つには、実は前提がいくつも要ります。それを本文に混ぜさせず、名前で出させます。

<div class="prompt">副業の話です。新しい依頼が来ました。

（使える時間の枠・抱えている案件の残り分数と締切・新しく来た依頼を、そのまま貼る）

上の材料に書いていないことを、前提にしないでください。

計算に前提が要るときは、その前提を〔前提〕と書いて別の行に並べてください。
たとえば「作業に集中できる」「体調を崩さない」なども、置いたなら〔前提〕に書いてください。
そのうえで、使える時間・抱えている案件・新しい依頼の差を分で出してください。</div>

各材料1回ずつ。前提が行として並びました。

> 〔前提〕枠（平日夜120分×10日、土日午前240分×4日）が、2週間ぜんぶ欠けずに使える。体調を崩さない、残業で夜の枠が潰れる日が無い。
> 〔前提〕枠の時間はまるごと作業に充てられる。移動・打ち合わせ・食事は枠の外にある。

<mark>これらは全部、材料には1文字も書いていないことです</mark>。指示文1では同じ内容が本文の途中に散らばっていて、名前が付いていませんでした。名前が付くと、**そのうち何個が自分にとって本当かを、1行ずつ判定できます**。

### 4. 締切ごとに区切らせる

合計だけの引き算には、抜けがあります。締切が違えば、使える時間も違うからです。

<div class="prompt">副業の話です。新しい依頼が来ました。

（使える時間の枠・抱えている案件の残り分数と締切・新しく来た依頼を、そのまま貼る）

締切ごとに区切って計算してください。

締切の早い順に、その締切までに使える時間と、その時点までに終わらせる必要がある作業の
合計を、分の数字で並べてください。締切をまたいで先送りできる作業があれば、
それも分けて書いてください。
受ける・断るの判断は書かないでください。</div>

これで、合計の引き算では見えない形が出ました。<mark class="warn">新しい依頼に回せるのは合計で1,020分あるのに、いちばん最後の区間（既存3件の締切がすべて過ぎたあと）には360分しか残っていません</mark>。つまり**前倒しできるかどうかが、この案件の実際の分かれ目**です。

「合計では入る」と「締切ごとに見ても入る」は別の話です。片方だけを見て決めないでください。

### 5. 「◯分余る／◯分足りない」だけを出させる

判断も理由も要らず、数だけほしいときの形です。

<div class="prompt">副業の話です。新しい依頼が来ました。

（使える時間の枠・抱えている案件の残り分数と締切・新しく来た依頼を、そのまま貼る）

足りないかどうかだけを、分の数字で答えてください。

足りている場合は「◯分余る」、足りない場合は「◯分足りない」と書いてください。
見積もりの下限で見た場合と、上限で見た場合の両方を書いてください。
足りない場合に何を削ればよいかは書かないでください。私が決めます。</div>

各材料1回ずつ。「下限で220分余る／上限で100分足りない」が真値どおり返りました。<mark>頼んでいないのに、答えを変える前提を自分から書いた回もあります</mark>——「8月31日の120分を計算に入れています。締切当日に作業できないなら、下限で100分余る／上限で220分足りないに変わります」。これは自分で決めるべき条件です。

### 6. 計算に使った数字の出どころを、先に並べさせる

<div class="prompt">副業の話です。新しい依頼が来ました。

（使える時間の枠・抱えている案件の残り分数と締切・新しく来た依頼を、そのまま貼る）

先に、この計算に使った数字をすべて並べてください。

どの数字を材料のどの行から取ったのかが分かるように、1つずつ書いてください。
材料のどの行にも書かれていない数字を使った場合は、その行の末尾に
〔材料に無い〕と付けてください。
数字を並べ終わるまで、受けられるかどうかは書かないでください。</div>

各材料1回ずつ。この形は**引き算の答えより手前で止まります**（差を書かなかった回があります）。使いどころは、上の指示文2で出た数が疑わしいときの確かめ用です。数を出す工程と、出どころを確かめる工程を分ける、という形は[副業の本当の時給を、自分の作業記録から出す](/recipes/hourly-rate-from-your-own-log/)と同じです。

## うまくいかないときの言い直し方 {: .fix }

### 「受けられます」と言われて、そのまま受けてしまった {: .trouble }

言い直し方は指示文2です。<mark>「受けるかどうかは私が決めます。計算だけしてください」を先頭に置く</mark>と、4回とも言い切りが0語になりました。

<mark class="warn">禁止だけを足しても足りません</mark>。「おすすめは書かないで」だけだと、代わりに何を書けばよいかが決まっていないので、別の言い方で判断が戻ってきます。**決める人を先に名指ししてから、書かないものを列挙してください。**

### 数字は合っているのに、なんとなく不安 {: .trouble }

合っています。今回20回のうち、引き算の数が真値と食い違った回は**ありませんでした**。不安の正体はたいてい**前提**のほうです。

指示文3で〔前提〕を並べさせて、1行ずつ「これは自分に当てはまるか」を見てください。今回出てきた前提は「2週間ぜんぶ枠が欠けない」「体調を崩さない」「移動と食事は枠の外」。**枠が3回飛ぶだけで360分消えます**。

### 余裕がある案件だと、途中の数が出てこない {: .trouble }

これは実際に起きました。余裕がある側の材料では、**使える合計から既存を引いた途中の数（2,000分）を書かず、最終の差だけを書く**回があります。

計算としては正しいのですが、途中の数が無いと**次に依頼が来たときに使い回せません**。指示文2は4つの数を1行ずつ指定してあるので、そのまま使ってください。

## 応用・次の一手 {: .next }

### 毎週おなじ6行で出す保存版にする

毎週やるなら、出す形まで決めてしまうのが早いです。

<div class="prompt">副業の話です。新しい依頼が来ました。

（使える時間の枠・抱えている案件の残り分数と締切・新しく来た依頼を、そのまま貼る）

毎週この形で出したいので、出す形をそろえてください。

1行目に「今週の空き時間（◯月◯日〜◯月◯日）」とだけ書いてください。
次の4行に、順に「使える合計 ◯分」「抱えている案件 ◯分」「差し引き ◯分」
「新しい依頼 下限◯分／上限◯分」と書いてください。
最後の1行に「下限なら◯分余る／上限なら◯分足りない」の形で書いてください。
それ以外は何も書かないでください。あいさつも判断も理由も要りません。</div>

材料2本で2回ずつ（計4回）。**きつい側の材料では、2回の返りが1文字も違いませんでした**（どちらも103字）。数字も真値どおりです。

<mark>ここまで短くなると、毎週決まった時刻に自動で出すところまで持っていけます</mark>（[「毎日決まった時刻に自動でやっておいて」をAIに作らせる](/recipes/github-actions-daily-cron/)）。

<mark class="warn">ただし、様式のほうが壊れる場合があります</mark>。余裕がある側の材料では、こちらが決めた最後の行（「上限なら◯分足りない」）が事実と合いませんでした。返りは2回とも様式を変えて、理由を添えています。

> 最後の1行だけ、指定の形（「上限なら◯分足りない」）に当てはめられませんでした。上限900分でも差し引き2000分の中に収まり、1100分余るためです。「足りない」と書くと事実と逆になるので「余る」にしています。

<mark>様式を決めるときは、想定していない結果になった週のことも書いておいてください</mark>。「足りるときは『◯分余る』、足りないときは『◯分足りない』と書いてください」と両方の形を渡せば、毎週おなじ行数で出ます。

### 断ると決めたあと

引き算で「入らない」と分かっても、それは断ると決めたことではありません。締切をずらしてもらう、本数を減らす、といった相談もできます。決めた条件を相手に伝える工程は[取引先への返事をAIに整えさせると、自分が決めた条件のほうが緩む](/recipes/client-reply-without-softening/)にまとめてあります。

⚠️ この記事の数字は、すべて架空の材料から出したものです。実際に受けるかどうかは、単価・取引先との関係・来月以降の予定など、予定表に書いていないことも含めて自分で決めてください。
