## これで何ができるか {: .what }

副業の確定申告でよく聞く「青色申告なら65万円の控除」——この数字だけが先に広まっています。<mark>複式簿記で記帳すれば誰でも65万円になる、と思い込んでいる人は少なくありません</mark>。実際には、複式簿記で記帳して決算書を添付して期限内に出しても、**もう1つの条件が無いと55万円で止まります**。

この記事は、AIにこの制度を聞くと、その「もう1つの条件」が答えから抜け落ちないかを実際に試した結果です。聞き方を6種類変えて、計17回試しました。

<mark class="warn">結論を先に書くと、この実測では「AIが要件を1つ飛ばす」という予想は外れました。</mark>17回とも、65万円に必要な4つめの条件（e-Taxによる電子申告、または優良な電子帳簿保存のどちらか一方）を自分から挙げました。確かめた事実として、そのまま載せます。

## AIへの頼み方 {: .ask }

### 1. まず素直に、控除額そのものを聞く

<div class="prompt">副業の所得を青色申告するといくら控除が受けられますか</div>

**3回とも、65万円・55万円・10万円の3段階を説明しました。**しかも3回とも、65万円の条件に「e-Taxでの電子申告または優良な電子帳簿保存」を自分から明記しました。<mark>聞いていないのに、65万円と55万円を分ける条件まで先に教えてくれた形です。</mark>

### 2. 「何をすればいいか」という手順の形で聞く

質問の向きを、制度の説明から作業の指示に変えます。手順ベースだと、細かい条件が削られて抜けることがあります。

<div class="prompt">65万円控除を受けるには何をすればいいですか</div>

**こちらも3回とも、手順の中にe-Tax電子申告または優良な電子帳簿保存の項目が入っていました。**3回のうち2回は「55万円の土台」と「65万円に上げる追加条件」を分けて説明する構成でした。

### 3. 「違いは何か」という比較の形で聞く

<div class="prompt">55万円控除と65万円控除の違いを教えてください</div>

**3回とも、差の核心を1文で要約しました。**

- 1回目：「差は、紙で出すか電子で出すか（または電子帳簿保存をしているか）という1点だけ」
- 3回目：「55万円と65万円の差はe-Tax（電子申告）または電子帳簿保存を行っているかどうかの1点のみ」

## うまくいかないときの言い直し方 {: .fix }

### 「複式簿記で記帳していれば大丈夫」と思い込んでいないか、具体的な条件で判定させる {: .trouble }

ここまでは制度の説明を聞いていました。説明できることと、自分の具体的な条件に当てはめて間違えないことは別です。<mark>具体的な条件を渡して「はい／いいえ」を判定させます</mark>。

<div class="prompt">複式簿記で記帳して、確定申告書は紙で税務署の窓口に提出する予定です。この条件で青色申告特別控除は65万円になりますか</div>

**3回とも「いいえ、55万円になります」と正しく判定しました。**<mark>「複式簿記で記帳していれば大丈夫」という早合点は起きず、紙提出だけでは条件が1つ欠けていると説明しました。</mark>

### 「パソコンに保存＝電子化している」と早合点していないか、もう一段意地悪な条件で確かめる {: .trouble }

「紙で提出」だけだと分かりやすすぎます。「データをパソコンに保存している」という、電子化しているように聞こえる記述を足しました。<mark>本物の電子帳簿保存の要件と取り違えないかを確かめました</mark>。

<div class="prompt">会計ソフトで複式簿記をつけていて、データは全部パソコンに保存しています。確定申告書は紙に印刷して税務署の窓口に提出する予定です。この条件で青色申告特別控除は65万円になりますか</div>

**3回とも「55万円になります」と正しく判定し、「単にパソコンに保存しているだけでは不十分」と理由まで説明しました。**優良な電子帳簿保存には、事前の届出書の提出や、訂正・削除の履歴が残る仕組みなどの要件があります。<mark>「データが電子である」ことと「優良な電子帳簿保存の要件を満たしている」ことは別物だと、3回とも区別しました。</mark>

## 応用・次の一手 {: .next }

**毎年の確定申告のたびに同じ条件を確認したいなら、チェックリストにしてもらえます。**

<div class="prompt">副業を青色申告しています。毎年の確定申告のたびに、65万円の控除の条件をすべて満たしているか自分でチェックしたいです。プログラミングはできません。私が確認することを、番号を振って箇条書きで教えてください。</div>

2回試したところ、項目数は11・11で、骨格は共通していました。

- 事業所得として認められる実態があるか（副業が「雑所得」止まりでないか）
- 青色申告承認申請書を期限内に提出しているか
- 複式簿記で記帳しているか
- 損益計算書・貸借対照表の両方を添付しているか
- 法定期限内に提出しているか
- **e-Taxでの電子申告、または優良な電子帳簿保存のどちらかを満たしているか**（2回とも、この項目で65万円と55万円を分けていた）

[原稿料・デザイン料の源泉徴収を実測した記事](/recipes/direct-contract-withholding-survives-the-million-yen-line/)や[講演料・翻訳料でも源泉徴収の式が崩れないかを確かめた記事](/recipes/withholding-formula-holds-for-other-fee-types/)でも同じ型でした。**制度の条件は「説明させる」だけで終わらせないことです。**<mark>「自分の具体的な条件を当てはめて判定させる」ところまでやると、思い込みに気づきやすくなります。</mark>

<mark class="warn">この結果は、この6種類の聞き方・計17回の実測です。</mark>「どんな聞き方でも制度の条件は必ず正しく答えられる」と一般化しないでください。試したのは、次の範囲までです。

- 試したのは青色申告特別控除（65万円・55万円・10万円）の条件だけです。事業所得と雑所得の区分そのものの判定は試していません
- 「会計ソフトで保存」という1種類の紛らわしい記述だけを試しました。他の紛らわしい記述（例えば「クラウドに保存している」「バックアップを取っている」）は未検証です
- 制度は今後変わることがあります。実際の申告では国税庁の最新情報を確認してください
