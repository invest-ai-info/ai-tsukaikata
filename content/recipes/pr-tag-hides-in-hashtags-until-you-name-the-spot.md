## これで何ができるか {: .what }

<mark>AIにアフィリエイトの紹介文を書かせるとき、「広告だとわかるようにPR表記も入れて」と頼むだけで、読者が気づける場所にPR表記が来るかを実測しました。</mark>架空の商品2種・計18回試した結果は、3つに分かれました。

- **「PR表記も入れて」とだけ頼むと、表記は4回とも入りましたが、4回とも末尾のハッシュタグの列に埋もれました**
- **「目立つように」と強調だけ足しても、位置は変わらず2回とも末尾のままでした**
- **「本文の最初の1行に、独立して書いて」と場所まで指定すると、4回とも冒頭に置かれました**

<figure class="figure">
<img src="/static/images/pr-disclosure-hit-and-miss.svg" alt="5つの条件で、PR表記が投稿の最初の1行に来た回数を示す表。①PR表記に触れずに依頼は0回中0回（表記自体が無い）、②『PR表記も入れて』とだけ依頼は0回中4回、③『目立つように』と強調を追加は0回中2回、④本文の最初の1行に独立して書くよう位置を指定は4回中4回、⑤埋もれた投稿文をPR表記の位置で自己点検・修正させるは2回中2回。下の枠には、位置を名指しした④と埋もれを指摘させた⑤だけが毎回1行目に来たこと、『PRを入れて』『目立たせて』だけでは8回中0回も1行目に来なかったことが書かれている。">
<figcaption>位置を名指しした条件だけが、毎回1行目に来ました。</figcaption>
</figure>

そもそも何も頼まなければ、PR表記は2回とも自然には現れませんでした。<mark>「アフィリエイト投稿文」という言葉自体には、PR表記を促す力はありません。</mark>明示的に頼む必要があります。

## 前提 {: .need }

| | |
|---|---|
| かかる時間 | 15分 |
| 費用 | 無料。ブラウザのチャットAIで足ります |
| 必要なもの | 紹介したい商品の特徴（架空でも実在でも）だけ |
| プログラミング | **不要**。この記事の指示文をコピーして貼るだけです |

<mark class="warn">この記事はアフィリエイトリンクを実際に貼りません。</mark>架空の商品名で実測しています。実際に投稿するときは、ご自身のアフィリエイトリンク・実在の商品名に置き換えてください。

この記事は「PR表記が読者に気づける場所に来るか」という表示の作り方の実測です。景品表示法・ステルスマーケティング規制に該当するかどうかの法的な判断は行いません。最新の制度は必ず[消費者庁「一般消費者が事業者の表示であることを判別することが困難である表示」の運用基準](https://www.caa.go.jp/policies/policy/representation/fair_labeling/guideline/assets/representation_cms216_230328_03.pdf)（2026-10-26確認）でご確認ください。この運用基準の第3-1-(2)-クには、こう書かれています。

> 事業者の表示であることを他の情報に紛れ込ませる場合（例えば、ＳＮＳの投稿において、大量のハッシュタグ（ＳＮＳにおいて特定の話題を示すための記号をいう。「＃」が用いられる。）を付した文章の記載の中に当該事業者の表示である旨の表示を埋もれさせる場合）。

今回の実測で4回とも起きたのは、まさにこの形でした。

副業でAIに文章を書かせたら検品する、という考え方は[副業ライティングの納品前検品をAIにやらせる記事](/recipes/writing-check-against-spec/)と同じ軸です。フリマ出品文の事実の誇張を防ぐ記事は[事実だけで書かせる記事](/recipes/listing-only-what-you-checked/)にあります。

## AIへの頼み方 {: .ask }

### 1. まずPR表記に触れずに頼んでみる（対照）

何も言わずに頼むと何が起きるかを、先に確かめておきます。

<div class="prompt">次の商品を紹介する、Instagramに投稿する想定のアフィリエイト投稿文を書いてください。

商品名: USB給電ネッククーラー「クールネックS」
特徴: 保冷剤2個を交換しながら使う首掛け扇風機。重さ320g。USB-Cで本体を充電。連続使用4時間。カバーは取り外して洗える。価格2,980円。</div>

**2回とも、PR表記は現れませんでした。**「アフィリエイト投稿文を書いて」という言葉だけでは、読者への表示は何も変わりません。頼まなければ始まらない、という当たり前の前提がまず確認できました。

### 2. 「広告だとわかるようにPR表記も入れて」と頼む

次に、サイトでよく見かける頼み方をそのまま試します。

<div class="prompt">次の商品を紹介する、Instagramに投稿する想定のアフィリエイト投稿文を書いてください。広告だとわかるようにPR表記も入れてください。

商品名: USB給電ネッククーラー「クールネックS」
特徴: 保冷剤2個を交換しながら使う首掛け扇風機。重さ320g。USB-Cで本体を充電。連続使用4時間。カバーは取り外して洗える。価格2,980円。</div>

返ってきた投稿文の末尾はこうなりました。

```
夏のお出かけ・通勤・アウトドアに1台あると本当に助かります。

#ネッククーラー #暑さ対策グッズ #夏の必需品 #クールネックS #便利グッズ #PR
```

<mark class="warn">PR表記は商品を変えても4回とも入りましたが、4回とも本文の最後、ハッシュタグの列の中に混ざりました。</mark>1回は「#PR」が5つのタグの先頭に来ましたが、それでも列の内部であることに変わりはありません。本文を読んでいる間は、どこにも広告だと分かる言葉が出てきません。

### 3. 「目立つように」と強調だけ足してみる

位置を直接は言わず、「目立たせて」と足すだけで変わるかを試しました。

<div class="prompt">次の商品を紹介する、Instagramに投稿する想定のアフィリエイト投稿文を書いてください。広告だとわかるように、PR表記を目立つように入れてください。

商品名: USB給電ネッククーラー「クールネックS」
特徴: 保冷剤2個を交換しながら使う首掛け扇風機。重さ320g。USB-Cで本体を充電。連続使用4時間。カバーは取り外して洗える。価格2,980円。</div>

**「【PR】」と装飾は付きましたが、2回とも投稿の末尾のままでした。**<mark class="warn">強調の指示は見た目を変えるだけで、位置までは動かしませんでした。</mark>

### 4. 本文の最初の1行に、独立して書くよう位置を指定する

最後に、「どこに」まで具体的に書きます。

<div class="prompt">次の商品を紹介する、Instagramに投稿する想定のアフィリエイト投稿文を書いてください。PR表記は、本文の最初の1行に、他の文章と同じ大きさの文字で、最初に目に入るように書いてください。ハッシュタグの中に埋め込むのではなく、本文の冒頭に独立して書いてください。

商品名: USB給電ネッククーラー「クールネックS」
特徴: 保冷剤2個を交換しながら使う首掛け扇風機。重さ320g。USB-Cで本体を充電。連続使用4時間。カバーは取り外して洗える。価格2,980円。</div>

返ってきた投稿文の冒頭はこうなりました。

```
【PR】USB給電のネッククーラー『クールネックS』のご紹介です。

保冷剤を2個入れ替えながら使えるので、暑い屋外でもずっと涼しい!
```

<mark>4回とも「【PR】」が最初の1行に来て、ハッシュタグの列とは完全に分離しました。</mark>違いは「目立たせて」ではなく「本文の最初の1行に」「ハッシュタグの中に埋め込むのではなく」という**場所そのものの指定**でした。

## うまくいかないときの言い直し方 {: .fix }

### 「大丈夫ですか」と漠然と聞いても、埋もれには気づかない {: .trouble }

指示文2で作った、PR表記が末尾のハッシュタグに埋もれた投稿文を、新しい会話で見せて漠然と点検だけ頼みました。

<div class="prompt">この投稿文、このまま使っても大丈夫ですか？</div>

返ってきたのはこうでした。

```
文章は読みやすく、商品の特徴も簡潔にまとまっています。絵文字の使用量も適度で、
Instagramの投稿としては自然な印象です。強いて言えば、もう少し使用シーンを具体的に
描写すると、より読み手の想像を掻き立てられるかもしれません。
```

<mark class="warn">2回とも、文章の読みやすさやトーンにしか触れず、PR表記がハッシュタグに埋もれている問題には一度も触れませんでした。</mark>何を点検してほしいかを言わないと、別の観点のフィードバックが返ってきます。

→ 点検してほしい観点を名指しして頼み直します。

<div class="prompt">この投稿文は、PR表記がハッシュタグの中に埋もれていませんか。本文を読んだだけでは広告だと分からない場合は、どこに問題があるか指摘し、直してください。</div>

**2回とも、埋もれを正しく指摘し、本文の冒頭へ【PR】を移して直しました。**<mark>すでに埋もれた投稿文があっても、点検の観点を名指しすれば直させられます。</mark>

## 応用・次の一手 {: .next }

**位置の違いを、投稿の構造として見ておきます。**

<figcaption>同じ投稿でも、PR表記の位置で「読む前」か「読んだ後」かが変わります。</figcaption>

**次からは、投稿のたびに消費者庁の運用基準の文言を基準として渡し、AIに判定させる使い方ができます。**良い例・悪い例の両方で試しました。

<div class="prompt">次のInstagram投稿文について、消費者庁の「一般消費者が事業者の表示であることを判別することが困難である表示」の運用基準（「大量のハッシュタグを付した文章の記載の中に、事業者の表示である旨の表示を埋もれさせる場合」は判別困難な表示にあたる、とされています）に基づいて、PR表記の位置が十分に分かりやすいかどうかを判定してください。</div>

指示文4で作った冒頭【PR】の投稿文には「読者は本文を読み始める前に広告だと認識できます」、指示文2で作った末尾埋没の投稿文には「本文を読んでいる間は広告だと気づけません」と、<mark>2回とも正しい向きで判定しました。</mark>投稿する前に、この1文で検品に使えます。

[副業ライティングの納品前検品をAIにやらせる記事](/recipes/writing-check-against-spec/)と合わせて使うと、文章の質とPR表記の両方を、投稿前にAIへ検品させる流れになります。

⚠️ **この結果は、商品2種・計18回（指示文7の2回を含む）の実測です。**「どんなAIでも必ず埋もれる」「位置さえ指定すれば必ず守られる」と一般化しないでください。試したのは、次の範囲までです。

- 投稿形式はInstagram想定の短文＋ハッシュタグのみです。note・ブログ記事形式の長文、X（旧Twitter）の文字数制限がある形式は未検証です
- 商品は架空の2種のみです。実在の商品名・実在のブランド名を使った場合は未検証です
- 「目立つように」という強調の指示は1種類だけ試しました。文字の色・絵文字での強調など、他の言い方は未検証です
- 判定は文字列照合によるものです。実際にSNSへ投稿したときの見え方（折りたたみ・文字数制限による省略）そのものは確認していません
