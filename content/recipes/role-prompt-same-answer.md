## これで何ができるか {: .what }

「AIには役割を与えよ（あなたは◯◯の専門家です、と書く）」——検定教材や仕事術の本で、いちばんよく見かける定説です。<mark>このサイトの記事にも、これまで役割を与えた指示文は1つも載せていませんでした</mark>。

そこで実際に試しました。架空の会社の経費精算規程（7条）と、6件の問い合わせを用意し、①役割なし ②「あなたは担当者です」 ③「あなたは20年の専門家です」の3版に加えて、念押しの一文を外した版・引用を求めた版も合わせて<mark>6版×各2回＝12回、合計72問</mark>を通しました。

先に結果を書きます。

- 🔑 <mark>答えられる3問（宿泊費・備品の承認・在宅勤務手当）の正答も、規程に無い3問を「記載がありません」と言い切る検出も、**72問中72問で満点**でした</mark>。役割の有無で1問も動きませんでした
- **記載の無い問いに、実在する条文番号をでっちあげて答えた回数は0件**（12回×3問＝36問すべてで確認）
- 一字一句そのままの引用を求めた4回（12引用）は、<mark>12引用とも規程の原文と完全一致</mark>。作り話の引用はありませんでした
- 🚨 <mark class="warn">揺れたのは、聞いていないのに条文名を書き添えるという体裁だけ</mark>でした。「20年の専門家です」を付けた回は2回とも書き添えましたが、同じ役割に「一字一句引用して」を足した回は2回とも書き添えず、**役割だけで再現する効果ではありませんでした**

**この記事は「役割を与えるな」とは言いません。**測ったのはこの1つの材料・この12回だけです。ただ、少なくともこの実測では、<mark>役割を付けても答えの正しさは1つも変わりませんでした</mark>。

## 前提 {: .need }

| | |
|---|---|
| かかる時間 | 15分 |
| 費用 | 無料。ブラウザのチャットAIで足ります |
| 必要なもの | 社内規程のような「根拠が条文単位で決まる資料」 |
| プログラミング | **不要**。指示文をコピーして貼るだけです |

この記事でやるのは、規程そのものを検品する作業ではありません。**規程を守って答えているか**を、AIに聞いて確かめる場面の話です。実際の社内規程や契約書で試すときは、社外秘の情報を貼らないよう気をつけてください。

## AIへの頼み方 {: .ask }

材料は架空の「経費精算規程」（7条）と、6件の問い合わせです。3件（宿泊費・備品購入・在宅勤務手当）は規程に答えがあり、残り3件（資格試験の受験料・駐輪場代・クリーニング代）は規程のどこにも書かれていません。**答えが実在するか・実在しないかを先に自分で決めてから**試すのがポイントです（決めずに試すと、AIの答えが合っているかどうか自分にも判定できません）。

3. 在宅勤務手当は月にいくらもらえますか。
4. 業務に関連する資格試験の受験料は、経費として申請できますか。
5. 電車通勤ですが、駅から会社までのあいだの駐輪場代は申請できますか。
6. 出張中にスーツをクリーニングに出しました。クリーニング代は経費になりますか。</div>

2回とも、答えられる3問は条文番号つきで正しく、答えられない3問は「該当条文なし」と明言しました。**役割を付けていないのに、この時点で満点**です。

「規程に書かれていないことは、想像で答えず『記載がありません』と書いてください」の一文が効いています。これが無い版がどうなるかは§4で試します。

本規程は、従業員が業務上支出した費用の精算方法を定める。

第2条（出張旅費）
出張時の交通費は実費を精算する。宿泊費は1泊あたり8,000円を上限とし、上限を超える分は自己負担とする。

第3条（会議費）
社外での打ち合わせにともなう飲食費は、1人あたり3,000円までを会社負担とする。

第4条（備品購入）
5,000円未満の業務用品は、購入後に申請すればよい。5,000円以上の業務用品は、購入前に所属長の承認を得ること。

第5条（在宅勤務手当）
在宅勤務を行う従業員には、月額3,000円を給与とあわせて支給する。

第6条（残業時の食事）
22時以降まで残業した場合、1食あたり1,000円までの食事代を実費精算する。

第7条（申請期限）
費用が発生した日から30日以内に申請すること。期限を過ぎた申請は原則として受け付けない。

## うまくいかないときの言い直し方 {: .fix }

### 「専門家として振る舞ってください」と役割を強めても変わらない {: .trouble }

強めても、規程の中身は増えません。中身を増やしたいなら、役割ではなく資料そのものを増やす必要があります。

<div class="prompt">いまの規程には、資格試験の受験料・駐輪場代・クリーニング代についての定めがありませんでした。

これらを規程に追加するなら、どんな条文が必要か、たたき台を考えてください。私が最終的に内容を決めます。</div>

これは「規程が答えを持っているか確かめる」作業とは別の、**規程を作る作業**です。混ぜないでください。

### 役割を与えたら、口調だけが変わった {: .trouble }

中身ではなく話し方が変わることはあります。読み手に合わせたいときは、話し手ではなく読み手を名指しするほうが効きます。実測は[人に見せる前の下書きは、AIに直させずに「どこが伝わらないか」だけ言わせる](/recipes/critique-not-rewrite/)にあります。

### そもそも自分の頼み方が足りているか分からない {: .trouble }

役割を足す前に、頼み方自体に抜けがないかをAIに聞き返させる手があります。

<div class="prompt">いまの私の頼み方（指示文）を見て、曖昧なところや、あなたが自分で決めてしまいそうな部分があれば、答える前に質問してください。</div>

この頼み方の実測は[AIに聞く前に、足りない情報を聞き返してもらう](/recipes/ask-what-is-missing-first/)にあります。⚠️ あちらの実測では、この頼み方によってAIが自分で決める設定が増えることも分かっています。
