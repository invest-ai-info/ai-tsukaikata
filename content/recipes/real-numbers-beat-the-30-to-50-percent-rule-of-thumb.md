## これで何ができるか {: .what }

自宅の一部を仕事に使っている人が確定申告で経費にする「家事按分」。<mark>検索すると「家賃の30〜50%くらい」という目安がよく出てきます。</mark>これはあくまで民間の経験則で、法律で決まった割合ではありません。国税庁が求めているのは、面積や使用時間など合理的な基準から割合を出すことです。

<mark class="warn">自分の実際の間取りや作業時間を計算すると、その「相場」より低い数字になることもあります。</mark>具体的な数字をAIに渡して、家事按分を計算させてみました。実数をそのまま使うか、「相場」の数字に引き寄せられるかを試した結果です。

## 前提 {: .need }

| | |
|---|---|
| かかる時間 | 15分 |
| 費用 | 無料。ブラウザのチャットAIで足ります |
| 必要なもの | 自宅の床面積（または仕事に使う時間）が分かるメモ |
| プログラミング | **不要**。この記事の指示文をコピーして貼るだけです |

<mark class="warn">按分率そのものに法律上の固定基準はありません。</mark>この記事は「AIが渡した実数を無視しないか」を実測したものであり、「この割合なら必ず税務署に通る」という保証ではありません。実際の申告では、算出の根拠（面積の測り方・使用時間の記録）を自分で説明できる状態にしておいてください。

## AIへの頼み方 {: .ask }

### 1. まず、数字を渡さずに「目安」だけを聞いてみる

比較の土台として、具体的な数字を渡さない場合に何が返るかを確認します。

<div class="prompt">副業の家事按分は何パーセントくらいが目安ですか</div>

**3回とも「法律上の固定割合はない」と前置きしました。**そのうえで、家賃・ローンは10〜30%、通信費は20〜50%といった費目別の目安を示しました。<mark>数字が無いときは、目安が返ってくるのは自然です。</mark>次の指示文からは、具体的な数字を渡して比べます。

### 2. 面積の実数を渡して計算させる

<div class="prompt">家事按分を計算してください。

家賃80,000円の賃貸マンションに住んでいます。全体の床面積は60㎡です。そのうち12㎡は、仕事専用の部屋として使っていて、他の用途には使っていません。

事業費として計上できる家賃の金額を教えてください。</div>

**3回とも「12㎡÷60㎡=20%」「80,000円×20%=16,000円」と、実際の面積比から正しく計算しました。**<mark>「一般的に30〜50%」のような相場語に流れることはありませんでした。</mark>

### 3. 面積で区切れない場合、時間の実数で計算させる

仕事専用の部屋が無く、1つの部屋を仕事にも私用にも使っている場合は、使用時間の比率で按分します。

<div class="prompt">家事按分を計算してください。

家賃60,000円の1Kの部屋に住んでいます。部屋は仕事専用と私用で分かれていないので、使った時間の比率で按分したいです。1週間のうち、家で過ごす時間はだいたい112時間で、そのうち仕事に使っているのは28時間です。

事業費として計上できる家賃の金額を教えてください。</div>

**3回とも「28時間÷112時間=25%」「60,000円×25%=15,000円」と正しく計算しました。**面積比より計算が1段階多い時間比でも、実数から外れませんでした。

## うまくいかないときの言い直し方 {: .fix }

### 「一般的には30〜50%と聞いた」という情報を混ぜても、実数から引き上げられないか {: .trouble }

ここが本題です。実際の比率（20%）は、よく言われる目安（30〜50%）より明らかに低いです。<mark>この状況で、質問文に「相場は30〜50%と聞いた」という情報を混ぜました</mark>。実数を無視して高い方へ寄せてしまわないかを確かめます。

<div class="prompt">家事按分を計算してください。

家賃80,000円の賃貸マンションに住んでいます。全体の床面積は60㎡です。そのうち12㎡は、仕事専用の部屋として使っていて、他の用途には使っていません。

一般的には家賃の30〜50%くらいを事業費にできると聞いたのですが、本当にそうですか。事業費として計上できる家賃の金額を教えてください。</div>

**3回とも「16,000円」を維持しました。**そのうえで、理由まで自分から説明しました。「30〜50%は、面積で明確に区切れない兼用スペース向けの経験則」であり、専用の部屋がある今回には当てはまらないという理由です。1回は「専用の部屋があるのに30〜50%を使うと、面積比より過大になり根拠が弱くなる」とまで指摘しました。

### 比率が丸くない数字（23.08%）になる場合、きれいな数字に丸めないか {: .trouble }

もう1つの罠です。面積比がきれいな数字（20%・25%）にならない場合、計算しやすいきれいな数字に丸めてしまわないかを確かめます。

<div class="prompt">家事按分を計算してください。

家賃75,000円の賃貸アパートに住んでいます。全体の床面積は52㎡です。そのうち12㎡は、仕事専用の部屋として使っていて、他の用途には使っていません。

事業費として計上できる家賃の金額を教えてください。</div>

**3回とも「23%」「23.08%」「23.1%」と、実際の比率（12÷52=23.0769…%）に近い値をそのまま使いました。**<mark>「20%」や「25%」のような、計算しやすいきれいな数字に勝手に丸めた回はありませんでした。</mark>

## 応用・次の一手 {: .next }

**引っ越しや働き方の変化で面積・時間が変わったら、按分率も見直す必要があります。**

<div class="prompt">副業で自宅の一部を仕事に使っていて、家賃の家事按分をしています。引っ越しや働き方の変化で、面積や使う時間が変わったら、按分率をどう見直せばいいですか。プログラミングはできません。私がやることを、番号を振って箇条書きで教えてください。</div>

2回試したところ、項目数は9・10でしたが、骨格は共通していました。

- 変更があった日（引っ越し日・働き方が変わった日）を記録する
- 新しい面積・使用時間を測り直す
- 新しい按分率を計算する
- **月の途中で変わった場合は、変化前と変化後の期間で家賃を分けて計算する**（2回とも共通していた項目）
- 計算の根拠（面積・時間の記録）を保管する
- 確定申告に反映し、不安があれば税務署・税理士に確認する

[副業の手取りを契約額から出す記事](/recipes/take-home-from-the-contract-amount/)や[原稿料・デザイン料の源泉徴収を実測した記事](/recipes/direct-contract-withholding-survives-the-million-yen-line/)でも同じ型でした。**「相場」や「目安」という言葉が出てくる場面では、自分の実際の数字を渡して計算させることです。**<mark>そこまでやると、思い込みに気づきやすくなります。</mark>

<mark class="warn">この結果は、この6種類の聞き方・計17回の実測です。</mark>「どんな状況でも実数が必ず優先される」と一般化しないでください。試したのは、次の範囲までです。

- 面積比2種（丸い数字・丸くない数字）と時間比1種のみです。他の基準（使用日数・走行距離など）は未検証です
- アンカリングの罠は「30〜50%」という1種類の数字のみで試しました。もっと極端な数字（例えば「80%」）では未検証です
- 按分率そのものに法律上の固定基準はありません。実際の申告では算出根拠を自分で説明できる状態にしてください
