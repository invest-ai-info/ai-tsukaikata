## これで何ができるか {: .what }

<mark>原稿料・デザイン料で確かめた源泉徴収の式は、講演料・翻訳料・著作権使用料にも、ラベルを書かなくても正しく一般化しました。</mark>架空の業務委託契約5種で「この契約の手取り額を計算してください」と試した結果です。

- **講演料45万円・明記あり**——3回とも正解404,055円
- **翻訳料120万円・100万円の段階を跨ぐ**——3回とも正解1,057,060円
- **著作権使用料28万円・明記あり**——3回とも正解251,412円
- **講演料45万円・「講演料」という語も204条も書かない**——<mark>「講演料」という語も204条も書かない契約でも3回とも正解404,055円</mark>
- **システム開発45万円・204条の対象外（負例）**——<mark>204条の対象外のシステム開発では3回とも「源泉徴収は不要」と正しく判定</mark>

[原稿料・デザイン料の源泉徴収を実測した記事](/recipes/direct-contract-withholding-survives-the-million-yen-line/)は、本文の最後で宿題を残していました。「報酬の種類は原稿料・デザイン料のみ（講演料・翻訳料・著作権の使用料など、他の対象業務は試していません）」という一文です。その宿題を、実際に試したのが今回です。

<mark class="warn">「個人への業務委託だから源泉徴収される」という思い込みは、今回のシステム開発の負例では当たりませんでした。</mark>所得税法204条1項1号は、原稿料・デザイン料・講演料・著作権等の使用料・通訳翻訳の報酬などを列挙しています。この列挙に当たらない仕事には、源泉徴収の義務そのものが発生しません。

## 前提 {: .need }

| | |
|---|---|
| かかる時間 | 20分 |
| 費用 | 無料。ブラウザのチャットAIで足ります |
| 必要なもの | 業務委託契約書（報酬の種類・支払金額が分かるもの） |
| プログラミング | **不要**。この記事の指示文をコピーして貼るだけです |

<mark class="warn">実在の取引先名・実在の金額は貼らないでください。</mark>この記事は架空の社名・金額を使っています。実在の人物・団体とは関係ありません。

この記事は「手取り額を計算できるか」という実測に絞っています。確定申告のやり方（源泉徴収された分の精算・還付）や、インボイス制度の免税事業者としての是非には踏み込みません。税率や源泉徴収の対象範囲は制度が変わることがあるため、実際の契約では国税庁の最新情報で確認してください。

## AIへの頼み方 {: .ask }

### 1. 講演料45万円、明記ありの契約で聞く

法人が個人の講師へ、社内研修セミナーの講演料を直接支払う架空の契約です。契約書の備考欄に、所得税法204条1項1号に該当する旨と源泉徴収義務があることを明記しています。

<div class="prompt">この契約の手取り額を計算してください。</div>

上に続けて、契約書を貼ります。

**3回とも「手取りは404,055円」と正しく計算しました。**式は450,000円×10.21%＝45,945円。450,000−45,945＝404,055円です。3回とも、講演料が204条1項1号の「講演料」に該当することを自分から言及しています。

### 2. 翻訳料120万円、100万円の段階を跨ぐ契約で聞く

次は翻訳料120万円という、源泉徴収の税率が途中で変わる金額です。100万円以下の部分は10.21%、超える部分は20.42%という2段階の税率が適用されます。

<div class="prompt">この契約の手取り額を計算してください。</div>

**3回とも「手取りは1,057,060円」と正しく計算しました。**100万円以下の部分は102,100円、超える20万円の部分は40,840円です。3回とも、この2つを分けて計算し、合計142,940円を源泉徴収する式を示しています。<mark>原稿料・デザイン料で確かめた「100万円の段差」は、翻訳料でも同じ形で崩れませんでした。</mark>

### 3. 著作権使用料28万円の契約で聞く

受注者が制作したイラストの、商品パッケージへの使用を許諾する架空の契約です。

<div class="prompt">この契約の手取り額を計算してください。</div>

**3回とも「手取りは251,412円」と正しく計算しました。**280,000円×10.21%＝28,588円。280,000−28,588＝251,412円です。

### 4. 講演料45万円、「講演料」という語も204条も書かない契約で聞く

ここまでは契約書に「講演料」という名目と、204条1項1号に該当するという備考を書いていました。この2つを両方削除しました。残したのは「2026年11月14日開催の社内研修セミナーにて、90分間の講演を行う」という業務内容の説明と、「報酬：450,000円」だけです。この契約で、同じ指示文を試しました。

<div class="prompt">この契約の手取り額を計算してください。</div>

**こちらも3回とも「手取りは404,055円」と、明記ありの版とまったく同じ結果になりました。**3回とも「この契約は講演料にあたる」と自分から判定しました。204条という条文番号も自分で挙げたうえで、源泉徴収を適用しています。<mark>ラベルも条文番号も書かなくても、業務内容（講演を行う）だけで見落としは起きませんでした。</mark>

## うまくいかないときの言い直し方 {: .fix }

### 204条の対象外の仕事でも同じように聞いてみる {: .trouble }

ここまでの4パターンはすべて、源泉徴収の対象になる業務でした。<mark class="warn">「個人への業務委託だから、源泉徴収されるに違いない」と思い込んでいないか</mark>——これを確かめます。204条1項1号の列挙に入っていない業務（社内システムの機能追加開発）で、まったく同じ指示文を試しました。

<div class="prompt">この契約の手取り額を計算してください。</div>

**3回とも「源泉徴収は不要で、450,000円が全額そのまま支払われる」と正しく判定しました。**3回とも、理由を自分から説明しています。所得税法204条が列挙する業務には原稿料・デザイン料・講演料・著作権等の使用料・通訳翻訳の報酬などが入りますが、システム開発・プログラミングは含まれていません。<mark>「個人への支払いだから源泉徴収が必要」という過剰な一般化は、3回とも起きませんでした。</mark>

## 応用・次の一手 {: .next }

**報酬の種類が増えてきたら、契約のたびに同じ手順で確認できるようにしておくと安心です。**

<div class="prompt">法人から直接、講演料・翻訳料・著作権使用料などを受け取る契約が増えてきました。契約ごとに源泉徴収の対象かどうかと、正しい手取り額を毎回確認したいです。プログラミングはできません。私が契約のたびに確認することを、番号を振って箇条書きで教えてください。</div>

2回試したところ、項目の数（10個と11個）は違いましたが、次の骨格は共通していました。

- まず、報酬の名目が源泉徴収の対象業務（204条1項1号の列挙）に当たるかどうかを確認する
- 契約書・請求書で、消費税が本体価格と区分して記載されているかを確認する
- 1回の支払金額が100万円を超えるかどうかで、税率（10.21%／20.42%）を自分でも計算してみる
- 実際の入金額と、自分で計算した手取り額が一致するか照合する
- 契約・支払いの記録と支払調書を一覧で残し、確定申告の材料にする

**源泉徴収された分は所得税の前払いです。**確定申告で、その年の所得税額と精算されます。[副業の手取りを契約額から出す記事](/recipes/take-home-from-the-contract-amount/)と合わせて読むと、プラットフォーム経由・直接契約・204条の対象外業務で、天引きの有無がどう変わるかが分かります。

⚠️ **この結果は、この5種類の架空契約・合計17回（応用2回を含む）の実測です。**「どんな報酬でも204条の当てはめは必ず正しい」と一般化しないでください。試したのは、次の範囲までです。

- 報酬の種類は講演料・翻訳料・著作権使用料・（対照として）システム開発のみです。士業報酬や芸能・スポーツの指導料など、204条の他の号・他の列挙業務は試していません
- 1回の支払い単位で計算（分割払いや、複数の報酬種別が1枚の契約書に混在する場合は未検証です）
- ラベルを外した版は講演料のみで試しました（翻訳料・著作権使用料でラベルを外した場合は未検証です）

今回の生の返りと、真値を計算したコードは `docs/evidence/withholding-formula-holds-for-other-fee-types.md` に全文置いてあります。
