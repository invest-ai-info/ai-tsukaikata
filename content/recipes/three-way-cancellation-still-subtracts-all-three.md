## これで何ができるか {: .what }

[2件同時のキャンセルを実測した記事](/recipes/double-cancellation-still-subtracts-both/)では、同じ備考に2件分のキャンセル額だけが書かれた契約を仕込みました。計算手順を明示する言い方なら、10回とも正しく見つけています。<mark>今回は、同じ備考に3件分のキャンセル額が同時に書かれている契約を仕込み、同じ言い方が同じ精度を保つかを確かめました。</mark>

用意したのは次の2種類です。

- 架空のWebサイト保守契約12社
- 架空のSNS運用代行契約12社

どちらにも、3種類の契約を1件ずつ仕込みました。

- **真の未入金**：備考なし。入金が0円
- **正当なキャンセル**：備考に確定した請求額まで明記。入金はその確定額どおり
- **3件同時の曖昧なキャンセル**：備考に「3件分のキャンセル額」だけ同じ1文の中に書かれ、確定額は書かれていない。実際の入金は、基本月額から3件分を引いた額より**さらに少ない**

**計算手順を明示する言い方は、3件同時でも10回とも隠れた不足を見つけ、正当なキャンセルを誤って疑った回は0回でした。**<mark>この結果は、2件分のキャンセルだけを仕込んだ前の記事と同じ精度です。</mark>

比較のために、計算手順を明示しない素朴な聞き方も同じ材料で10回試しました。<mark class="warn">10回中7回は正しく見つけましたが、残り3回は3種類の違う崩れ方をしました。</mark>3件目のキャンセル額を見落として不足額を過大計算した回、計算の本文は正しいのに結論の数字だけが食い違った回、確定額と入金額の引き算そのものを間違えた回です。2件同時のときの前の記事では、素朴な聞き方は10回中1回しか崩れませんでした。

## AIへの頼み方 {: .ask }

### 1. Webサイト保守契約で、計算手順を明示して聞く

架空のWebサイト保守契約12社を用意しました。3件だけ、ふつうと違う行を混ぜています。

- **ひまわり薬局**：入金が0円（真の未入金）
- **青葉自動車**：備考に確定額44,000円まで明記。入金もその44,000円どおり（正当なキャンセル）
- **三日月印刷**：3件同時の曖昧なキャンセル。確定額は書かれていない
  - 備考の文面：「オプションA（年末休業対応・2,000円）とオプションB（深夜対応・1,500円）とオプションC（出張対応・2,500円）の3件をキャンセルされたとの連絡があり、返金対応済みです」
  - 本来の確定額＝基本月額52,000円 − 3件分（合計6,000円）＝46,000円のはず
  - 実際の入金は42,000円。4,000円が説明のつかない不足のまま残っている

<div class="prompt">まだ入金に不足がある契約はどれですか。備考にキャンセル・返金の記載がある場合は、基本月額からキャンセルされた金額を引いた金額を本来の請求額として計算し、入金額と一致するかを確認してください。一致しない場合は不足として挙げてください。会社名と不足額を挙げてください。</div>

上に続けて、契約一覧（社名・基本月額・備考・今月の入金額）を貼ります。

**5回試したところ、5回とも三日月印刷の不足4,000円を正しく見つけました。**備考には「3件」としか書いておらず「合計」という言葉もありませんが、5回とも2,000円・1,500円・2,500円の3件すべてを引いています。青葉自動車を誤って不足扱いした回は0回です。

### 2. SNS運用代行契約でも、計算手順を明示して聞き直す

同じ構造を、別の業種でも確かめました。

- **ほたる接骨院**：入金0円（真の未入金）
- **大地工務店**：確定額50,000円まで明記され、入金も一致（正当なキャンセル）
- **白樺クリニック**：3件同時の曖昧なキャンセル
  - 備考の文面：「ストーリーズ投稿オプション（3,000円）と、ハイライト編集オプション（1,500円）と、リール制作オプション（2,500円）の3件をキャンセルされたとの連絡があり、返金対応済みです」
  - 本来の確定額は47,000円。実際の入金は44,500円だった

<div class="prompt">まだ入金に不足がある契約はどれですか。備考にキャンセル・返金の記載がある場合は、基本月額からキャンセルされた金額を引いた金額を本来の請求額として計算し、入金額と一致するかを確認してください。一致しない場合は不足として挙げてください。会社名と不足額を挙げてください。</div>

**こちらも5回とも、白樺クリニックの不足2,500円を正しく見つけました。**大地工務店を誤って不足扱いした回は0回です。2種類の材料を合わせると、**10回とも**3件同時の曖昧なキャンセルの隠れた不足を見つけました。

### なぜこの言い方が効くのか

指示文は「キャンセルされた金額」としか言っていません。「3件分」「合計」という言葉は入れていません。<mark>それでも、備考に3つの金額が書かれていれば、3つとも基本月額から引く動きになりました。</mark>この言い方が指定しているのは、金額の個数ではなく計算の手順そのものです。「基本月額から引いて入金額と一致するか確認する」という手順なら、キャンセルが2件でも3件でも同じように繰り返されます。

## うまくいかないときの言い直し方 {: .fix }

### 計算手順を省くとどうなるか {: .trouble }

比較のため、計算手順を書かない素朴な聞き方も同じ材料で試しました。

<div class="prompt">まだ入金に不足がある契約はどれですか。会社名と不足額を挙げてください。問題がなければ「不足はありません」と書いてください。</div>

Webサイト保守契約で5回、運用代行契約で5回、合計10回試したところ、**7回は正しく三日月印刷・白樺クリニックの不足を見つけました。**正当なキャンセル（青葉自動車・大地工務店）を誤って不足扱いした回は10回とも0回です。しかし残り3回は、3種類の違う崩れ方をしました。

```
【崩れ方①　3件目を見落として過大計算（三日月印刷）】
三日月印刷に不足があります。基本月額52,000円から2,000円とオプションB1,500円を引くと
48,500円。入金42,000円との差額です（オプションCの2,500円を見落としている）。
結論: 三日月印刷 6,500円
```

```
【崩れ方②　本文は正しいのに結論の数字だけ食い違う（三日月印刷）】
三日月印刷。基本月額52,000円から3件のキャンセル分を引くと46,000円のはずで、入金
42,000円との差は4,000円不足のはずですが、見出しではまとめ違いが起きました。
結論: 三日月印刷 6,000円
```

```
【崩れ方③　確定額と入金額の引き算そのものを間違える（白樺クリニック）】
白樺クリニックの不足額を確認しました（確定額47,000円、入金44,500円の差）。
結論: 白樺クリニック 3,500円
```

<mark class="warn">正解はそれぞれ三日月印刷4,000円・白樺クリニック2,500円です。</mark>①は3件あるキャンセルのうち1件を見落とし、②は計算の説明は合っているのに最後にまとめた数字だけが違い、③は確定額から入金額を引く最後の一歩を間違えています。<mark>計算手順を明示した言い方では、この3種類の崩れ方は10回とも起きていません。</mark>

→ キャンセルが何件になっても、**基本月額から1件ずつ引いて入金額と一致するか確認する**という手順を指示文に書いておくのが、件数が増えるほど効いてきます。

### 「説明が合っているか確認して」では足りるか {: .trouble }

[前の記事](/recipes/double-cancellation-still-subtracts-both/)で試した、計算の手順を書かない軽い言い方も、同じ材料で試しました。

<div class="prompt">まだ入金に不足がある契約はどれですか。備考にキャンセル・返金の記載がある場合は、その説明が入金額と合っているか確認してください。会社名と不足額を挙げてください。</div>

Webサイト保守契約で3回試したところ、1回は3件の合計を6,000円ではなく5,000円と足し間違え、三日月印刷の不足額を5,000円と誤りました（正解は4,000円）。

<div class="prompt">まだ入金に不足がある契約はどれですか。備考にキャンセル・返金の記載がある場合は、その説明が入金額と合っているか確認してください。会社名と不足額を挙げてください。</div>

運用代行契約では3回のうち1回、白樺クリニックの不足を**完全に見逃し**「不足はありません」と結論づけました。6回を合わせると、<mark class="warn">軽い言い方では4回は正しく、2回は違う崩れ方（足し算の間違い・見逃し）をしました。</mark>

計算手順を明示した言い方（本文のAIへの頼み方）では、10回の実測を通じてこの種の誤りは1件も起きていません。**件数が増えるほど、「確認して」とだけ頼む軽い言い方は不安定になります。**

キャンセルが何件重なっても同じ手順で確かめたいなら、この指示文を毎月の確認に組み込めます。

<div class="prompt">毎月、顧客ごとの基本月額と入金額を突き合わせて、不足がある契約を見つけたいです。1社の中で複数のキャンセル・返金が重なる場合もあります。プログラミングはできません。私が毎月やることを、番号を振って箇条書きで教えてください。</div>

試したところ、「備考にある金額をすべて拾って合計してから引く」という手順を自分から含めていました。件数を決め打ちせず、複数ある場合を言葉で足しておくと、手順の案にも反映されます。

[2件同時のキャンセルを実測した記事](/recipes/double-cancellation-still-subtracts-both/)、[分割払いの入金照合を実測した記事](/recipes/installment-payments-add-up-correctly/)と合わせて読むと、入金照合のパターンが広がります。

⚠️ **この結果は、この2種類の架空データ・合計28回（計算手順を明示した版10回・素朴な版10回・軽い言い方の版6回・応用の自動化プロンプト2回）の実測です。**「AIは何件分のキャンセルでも必ず正しく処理する」と一般化しないでください。試したのは、次の範囲までです。

- 1社の中で仕込んだ曖昧なキャンセルは3件分のみです。4件以上が同時に重なる場合は未検証です
- 3件分のキャンセル額は、すべて備考の同じ文の中に書きました。別々の文・別の段に分けて書かれる場合は[前の記事](/recipes/double-cancellation-still-subtracts-both/)と同じく未検証です
- 素朴な聞き方・軽い言い方は材料ごと3〜5回のみです。もっと多く試すと、崩れる頻度が変わる可能性があります
