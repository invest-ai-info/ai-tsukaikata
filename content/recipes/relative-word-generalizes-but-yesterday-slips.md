## これで何ができるか {: .what }

[追記の日付ズレ、3語でも防げる](/recipes/naming-today-does-not-cover-yesterday/)は、「今日」「昨日」「さっき」の3語を名指しして直す方法を確かめた記事です。末尾にこう書いて終わっていました。

> 次に測るなら、相対語を自分で全部挙げる代わりに別の言い方を試します。個別の語を名指ししない言い方です。これが安定するかを確かめます。

この記事はそこを測ります。**語を列挙せず「相対的な言葉なら続きの日付を使う」と一般化した指示文**を、前作が試していない2語（「先ほど」「午前中に」）も含めた5語で試しました。

<img src="/static/images/relative-word-generalize-hit-and-miss.svg" alt="素朴な一般化と、意味で分けた一般化の正答率を比べた表。素朴な一般化で今日・さっき・先ほど・午前中にの4語を合わせて数えると8回中8回で緑、同じ素朴な一般化で昨日だけを数えると2回中1回で黄色。意味で分けた一般化に変えると、昨日を含む5語とも8回中8回で緑。下の枠には、素朴な一般化は今日型の4語には効くが昨日だけ2回中1回しか直らなかったこと、意味で区別する言い方に変えると5語とも8回とも正しくなったことが書かれている。">
<figcaption>素朴な一般化は、「昨日」だけ半分しか直りませんでした。</figcaption>
</figure>

分かったことは2つです。

**① 一般化は、名指ししていない新しい語にも効きました。**「先ほど」「午前中に」は指示文のどこにも出てきませんが、<mark>素朴な一般化だけで8回とも正しい日付になりました</mark>。

**② ただし「昨日」だけは、一般化しても安定しませんでした。**<mark class="warn">同じ素朴な一般化で「昨日」を試すと、2回中1回は前日ではなく今日と同じ日付に紛れ込みました</mark>。原因は「名指ししていないこと」ではなく、**「今日にあたる語」と「前日にあたる語」を区別していないこと**でした。

## AIへの頼み方 {: .ask }

### 1. 語を列挙せず、素朴に一般化して試す

<div class="prompt">下の「記録ファイル」の末尾に、【今日ぶん】を1行だけ追記してください。すでにある行は1文字も変えないでください。【今日ぶん】の中に日付の表記が無く、相対的な言葉だけで時点が書かれている場合は、実際のシステム上の今日の日付ではなく、記録ファイルの続きの日付を使ってください。更新後のファイル全体を、コードブロックで出してください。</div>

架空の「副業の作業記録」（最後の行が2026-08-03で、続きとして正しい次の行は2026-08-04）に、5つの相対語の走り書きを渡しました。「今日」「さっき」は前作で名指し済み、「先ほど」「午前中に」は前作が「試していない」と明記した語です。それぞれ**新規プロセスに2回ずつ＝10回**試しました。

| 走り書き | 1回目 | 2回目 |
|---|---|---|
| 今日 | 2026-08-04 | 2026-08-04 |
| さっき | 2026-08-04 | 2026-08-04 |
| 先ほど | 2026-08-04 | 2026-08-04 |
| 午前中に | 2026-08-04 | 2026-08-04 |
| 昨日（正しくは2026-08-03） | **2026-08-04** | 2026-08-03 |

<mark>「今日」「さっき」「先ほど」「午前中に」の4語は、8回とも続きの日付（2026-08-04）に正しくなりました。</mark>名指ししていない「先ほど」「午前中に」にも、一般化がそのまま効いています。

<mark class="warn">ところが「昨日」だけは、2回中1回、前日（2026-08-03）ではなく今日と同じ2026-08-04になりました。</mark>

### 2. なぜ「昨日」だけ崩れるのか

<div class="prompt">下の「記録ファイル」の末尾に、【今日ぶん】を1行だけ追記してください。すでにある行は1文字も変えないでください。【今日ぶん】の中に日付の表記が無く「本日」「今日」「さっき」としか書かれていない場合は、実際のシステム上の今日の日付ではなく、記録ファイルの最後の行の次の日を使ってください。「昨日」としか書かれていない場合は、記録ファイルの最後の行と同じ日付を使ってください。更新後のファイル全体を、コードブロックで出してください。</div>

これは前作の直し方（語を名指しする版）です。前作の実測では、名指しした「昨日」ですら**4回中1回**、同じ崩れ方をしました。今回、名指ししていない新しい語（「先ほど」「午前中に」）に**同じ指示文**を当てたところ、こちらは**4回中4回**正しくなりました。

<figure class="figure">
<img src="/static/images/relative-word-yesterday-across-versions.svg" alt="「前日を指す語」（昨日）だけの正答率を、3つの指示文で比べた表。前作が名指しした指示文は4回中3回で黄色、今回の素朴な一般化は2回中1回で黄色、意味で分けた一般化は2回中2回で緑。下の枠には、名指しても素朴に一般化しても昨日は安定しなかったこと、今日型と前日型を意味で分けると名指しせずに2回とも正しくなったこと、不安定の原因は名指しの有無ではなく今日型と前日型を区別していないことだったと書かれている。">
<figcaption>名指ししても一般化しても、「前日を指す語」だけが崩れました。</figcaption>
</figure>

🔑 **ここで分かるのは、不安定の原因が「名指ししていないこと」ではないという点です。**名指しした「昨日」（前作）も、素朴に一般化した「昨日」（今回）も、同じように崩れました。崩れなかったのは、名指しされていない**「今日型」の語**（さっき・先ほど・午前中に）だけです。**「前日を指す語」という種類そのものが、今日と区別されにくいのです。**

### 3. 意味で区別すると、名指しせずに安定する

語を列挙する代わりに、「今日にあたる語」と「前日にあたる語」を**意味で**分けました。

<div class="prompt">下の「記録ファイル」の末尾に、【今日ぶん】を1行だけ追記してください。すでにある行は1文字も変えないでください。【今日ぶん】の中に日付の表記が無く、相対的な言葉だけで時点が書かれている場合は、実際のシステム上の今日の日付を使わないでください。その言葉が指す時点を、記録ファイルの最後の行を基準に判断してください。前の行からの続きとして今日にあたる言葉なら、記録ファイルの最後の行の次の日を使い、前の行と同じ日を指す言葉（前日を指す言葉など）なら、記録ファイルの最後の行と同じ日付を使ってください。更新後のファイル全体を、コードブロックで出してください。</div>

5語すべてに試しました（今日・さっきは1回、昨日・先ほど・午前中には2回ずつ＝計8回）。

<mark>8回とも真値どおりになりました。</mark>「昨日」は2回とも正しく前日（2026-08-03）、残りの4語は正しく続き（2026-08-04）です。**語を1つも名指ししていないのに、新しい語にも「前日を指す語」にも、両方正しく効きました。**

## うまくいかないときの言い直し方 {: .fix }

### 列挙した語のリストを、増やし続けるのがつらい {: .trouble }

3番の指示文に切り替えてください。語を列挙する代わりに、**「今日にあたる語」と「前日にあたる語」という2つの意味**だけを区別します。走り書きに出てくる語を自分で全部書き出す必要がなくなります。

<div class="prompt">下の「記録ファイル」の末尾に、【今日ぶん】を1行だけ追記してください。すでにある行は1文字も変えないでください。【今日ぶん】の中に日付の表記が無く、相対的な言葉だけで時点が書かれている場合は、実際のシステム上の今日の日付を使わないでください。その言葉が指す時点を、記録ファイルの最後の行を基準に判断してください。前の行からの続きとして今日にあたる言葉なら、記録ファイルの最後の行の次の日を使い、前の行と同じ日を指す言葉（前日を指す言葉など）なら、記録ファイルの最後の行と同じ日付を使ってください。更新後のファイル全体を、コードブロックで出してください。</div>

### 「相対的な言葉なら続きの日付」とだけ書いてしまう {: .trouble }

1番の壊れ方です。

<div class="prompt">下の「記録ファイル」の末尾に、【今日ぶん】を1行だけ追記してください。すでにある行は1文字も変えないでください。【今日ぶん】の中に日付の表記が無く、相対的な言葉だけで時点が書かれている場合は、実際のシステム上の今日の日付ではなく、記録ファイルの続きの日付を使ってください。更新後のファイル全体を、コードブロックで出してください。</div>

<mark class="warn">この言い方は「前日を指す語」を区別しないため、「昨日」だけ2回に1回、今日と同じ日付に紛れ込みます</mark>。「前の行と同じ日を指す言葉なら、最後の行と同じ日付を使う」という一文を必ず足してください。

### 前作の「名指しする版」を、まだそのまま使っている {: .trouble }

<div class="prompt">下の「記録ファイル」の末尾に、【今日ぶん】を1行だけ追記してください。すでにある行は1文字も変えないでください。【今日ぶん】の中に日付の表記が無く「本日」「今日」「さっき」としか書かれていない場合は、実際のシステム上の今日の日付ではなく、記録ファイルの最後の行の次の日を使ってください。「昨日」としか書かれていない場合は、記録ファイルの最後の行と同じ日付を使ってください。更新後のファイル全体を、コードブロックで出してください。</div>

名指しする版そのものは間違いではありません。ただし、走り書きに出てくる語が増えるたびに、この指示文を書き直す手間が発生します。語を列挙する手間を減らしたいなら、3番の指示文に乗り換えてください。

### 「一昨日」「おととい」のような、もっと前を指す語も出てくる {: .trouble }

この記事が試したのは「今日にあたる語」と「前日にあたる語」の2種類だけです。**2日前・3日前を指す語は試していません。**同じ理屈（意味のカテゴリで分ける）が通用するかは別の実測が必要です。出てくる可能性があるなら、「前日より前を指す語が出た場合は、作業を止めて人に確認してください」という受け皿を先に足してください。
