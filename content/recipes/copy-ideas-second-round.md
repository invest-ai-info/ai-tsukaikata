## これで何ができるか {: .what }

コピーの案出しは、30案もらったところで終わりません。読み返すと使えるのは数案で、<mark>「もう30案ください」ともう一度頼むことになります</mark>。

このとき、頼み方の選択肢は2つあります。**同じ会話の続きで追加を頼む**か、**会話を新しくして同じ指示文をもう一度通す**かです。当サイトの[使えるコピー案だけを数える](/recipes/count-copy-ideas-that-pass/)は後者を勧めていました——「同じ指示文をもう一度そのまま通してください」。<mark class="warn">その勧めは、二巡目を1回も測らずに書かれています。</mark>

そこで、架空の商品を**2件**（町のパン屋の冷凍パン定期便／会計事務所向けの領収書の読み取り）と、**○×が機械で決まる4条件だけ**の架空の発注書を作り、**一巡目は5通りとも同じ指示文**にして、**二巡目の言い方だけ**を振りました。1つの頼み方につき4回（材料2本 × 各2回）、**全20回**です。

- **二巡目に返った案は、20回とも30案ちょうど**でした。「もっと案をください」と数を言わなかった回も30案です
- **4条件は、20回とも30案すべてが通りました**（機械判定）。二巡目だから緩む、ということは起きていません
- **二巡目の中で完全に重複した案は、20回とも0件**でした
- 🚨 <mark>一巡目と文字が七割以上重なる案は、会話を切ってやり直した4回だけ 4〜7件</mark>。同じ会話で追加した回は0〜3件です
- 🚨 **一字一句そのまま同じ案も、やり直した回だけ 0〜3件**出ました

<mark class="warn">商標や既存のコピーと衝突しないかは、AIに判定させないでください。</mark>この記事でAIにやらせるのは、案を並べるところまでです。出てきた60案は納品物ではなく、[「20件のリスト」は自分が確かめる作業リストとして受け取る](/recipes/list-as-work-not-delivery/)と同じで、**自分が確かめる作業リスト**として受け取ります。

|---|---|

| 費用 | 無料。ブラウザのチャットAIで足ります |

実測に使った材料は、次の架空の商品説明です。指示文の「下の商品」はこれを指します。

```
【商品】
町のパン屋が始めた、冷凍パンの定期便。
・毎月1回、店で焼いたパンを冷凍して自宅へ送る
・6種類12個入り。前月に注文した種類は自動で外れる
・解凍はトースターで4分。前の晩の準備は要らない
・配送は全国。北海道と沖縄は追加の送料がかかる
・申し込みも停止も、店のサイトの同じ画面からできる
```

もう1件は「小さな会計事務所向けの、領収書の読み取りサービス」で、必ず入れる語を「領収書」、使わない3語を「完全／万能／究極」にしてあります。

<mark class="warn">発注元がAIの利用を禁じている場合があります</mark>。規約や指示書を先に確かめ、禁じられているなら使わないでください。案件ごとのルールの確かめ方は[案件のAI利用ルールを、募集要項の原文で確かめる](/recipes/job-ai-policy-check/)にあります。

## AIへの頼み方 {: .ask }

### 1. 一巡目は、条件を渡して30案（ここは5通りとも同じ）

まず発注書の条件と商品説明を貼って、こう頼みます。

<div class="prompt">【発注書の条件】
1. 全角20字以内
2. 「冷凍」を必ず入れる
3. 次の3語は使わない: 絶品／極上／感動
4. 英数字（半角・全角とも）を使わない

下の商品のキャッチコピーを30案出してください。1行に1案ずつ書いてください。</div>

**20回とも30案が返り、4条件も30案すべてが通りました。**ここは既存記事の実測どおりで、二巡目を測るための土台です。<mark>振ったのは、このあとの一文だけです。</mark>

### 2. 「もっと案をください」でも、30案返ってくる

いちばん短い頼み方です。件数を1文字も指定していません。

<div class="prompt">もっと案をください。</div>

**4回とも30案でした。**「もっと」に数の意味はないのに、一巡目の30という数がそのまま引き継がれます。4条件も4回とも30案すべて通りました。

<mark>一巡目と一字一句そのまま同じ案は、4回とも0件</mark>です。ただし文字が七割以上重なる案が0〜3件あります。たとえば「トースターで焼きたて冷凍パン」に対して「トースターだけで、焼きたて冷凍パン」。**読むと別の案に見えますが、選ぶ側から見れば同じ一手です。**

### 3. 「あと30案出してください」——数を言っても、結果はほぼ同じ

<div class="prompt">あと30案出してください。</div>

**4回とも30案・4条件は30/30**で、§2と数字が変わりませんでした。似た案は0〜2件、一字一句同じ案は1回だけ1件です。

📌 **数を指定してもしなくても、返る数は30**でした。この材料・この回数では、「あと30案」と書く手間の見返りは見つかりませんでした。

### 4. 「一つも重ならない案を」と書いた4回だけ、似た案が0件

重なりを止める一文を、二巡目の中に入れます。

<div class="prompt">いま出た30案と一つも重ならない案を、30案出してください。</div>

<mark>この4回だけ、似た案も一字一句同じ案も0件でした。</mark>他の4通りが1件以上出しているのと、はっきり分かれます。

🔑 **効いているのは「重ならない」という言葉ではなく、比べる相手を名指ししたこと**です。「いま出た30案と」と書いてあるので、AIは手元の30案を見に行ってから書きます。4回のうち3回は、前置きで「先ほどの30案とは異なる」「前回の30案と重複しない」と自分から宣言してから案を並べました（残り1回は前置きなしで案だけを返しています）。

### 5. 同じ指示文をもう一度——会話を切ると、いちばん重なる

§1の指示文を、そのままもう一度通します。ここで**同じ会話の続きで通すか、新しい会話で通すか**が分かれます。

| 二巡目 | 似た案（4回ぶん） | 一字一句同じ案 |
|---|---|---|
| 同じ会話でもう一度 | **2・3・3・3件** | 4回とも0件 |
| 新しい会話でもう一度 | **7・7・4・7件** | **0・3・0・1件** |

🚨 **新しい会話でやり直すと、いちばん重なります。**同じ商品・同じ条件を渡しているのだから当然で、AIには前の30案が見えていません。実際に出た組はこうです。

- 一巡目「毎月変わる冷凍パン、六種十二個」／二巡目「毎月変わる冷凍パン、六種十二個」（**完全に同じ**）
- 一巡目「冷凍だから、いつでも焼きたてに」／二巡目「冷凍だから、いつでも焼きたての香り」

⚠️ **既存記事が勧めていた「もう一度そのまま通す」は、いちばん重なる形でした。**ただし重なったのは4〜7件で、**残り23〜26案は新しい案**です。「やり直しても無駄」ではありません。

### 6. 毎回この形なら、前置きを書かせない

案件が続くなら、二巡目の形を固定します。

<div class="prompt">先ほどの30案は1案も使わないでください。
同じ4条件のまま、新しく30案だけを返してください。1行に1案。
前置きも説明も書かないでください。</div>

**4回とも、前置きの行が0行の案の一覧だけが返りました。**表計算ソフトへそのまま貼れる形です。

## うまくいかないときの言い直し方 {: .fix }

### 似た案が混ざっている気がする {: .trouble }

数えるのは人には向きません。**同じ会話の中で、そのまま聞き直せます。**

<div class="prompt">いま出した60案の中に、言い回しがほとんど同じで中身も同じ組があれば、
その2案をそのまま並べてください。1組も無ければ「ありません」とだけ書いてください。</div>

<mark>「1組も無ければ『ありません』」まで書くのが要点</mark>です。これが無いと、無理に候補を作る側へ倒れます（[頼む範囲を先に区切る型](/recipes/limit-what-ai-touches/)と同じ形）。4回とも組が返り、「ありません」と答えた回は0回でした。

**同じ会話ではなく、別の新しい会話に一覧を2つ貼って聞く形**も試しました。

<div class="prompt">下に、同じ商品で別々に作ったキャッチコピーの一覧を2つ貼ります。
【一覧1】と【一覧2】に、言い回しがほとんど同じで中身も同じ組があれば、
その2案をそのまま並べてください。1組も無ければ「ありません」とだけ書いてください。</div>

⚠️ **返ってきた組の数は、こちらの機械判定と合ったり合わなかったりします。**この形を4回通して、AIが挙げたのは 3組・3組・4組・3組。同じ一覧をこちらのコードで数えると 7組・7組・4組・7組で、**合ったのは1回だけ**でした。AIは「中身が同じか」で数え、こちらのコードは「文字が七割以上重なるか」で数えています。<mark>数を合わせにいかず、挙がってきた組を目で見て捨てるかどうかだけ決めてください。</mark>

📌 一致しなかった回では、AIのほうが**自分から補足**しています——「これら以外にも『表現は近いが完全一致ではない』組もありましたので、参考までに挙げておきます」。<mark class="warn">その参考の5組は、正式な回答の外に置かれます。</mark>返りの上のほうだけをコピーすると、そこは丸ごと落ちます。

### 60案になって、選べない {: .trouble }

案を増やす前に、落とす条件を先に決めます。

📌 **条件の○×はAIで足ります**（4条件は20回とも30案すべて正しく通りました）。足りないのは、確かめようがないことのほうです。商標、既存コピーとの衝突、その言い方を発注元が言えるかどうか——ここは[使えるコピー案だけを数える](/recipes/count-copy-ideas-that-pass/)の§5にある「私が確かめること」を添えさせる形へ渡してください。

### 二巡目だけ条件が緩んでいないか心配 {: .trouble }

この実測では緩みませんでした（20回とも30/30）。それでも毎回確かめたいなら、二巡目にも条件を貼り直します。

⚠️ ただし<mark class="warn">貼り直しは「条件を書いていない場所」には届きません</mark>。条件を渡していない項目（言い回しの重複など）は、貼り直しても変わらないというのが[渡した縛りが会話を重ねても残るか](/recipes/list-survives-many-turns/)の実測です。

## 応用・次の一手 {: .next }

**案を貯めるなら、会話を切らずに足していく。**この実測では、同じ会話で追加した12回の似た案が0〜3件、会話を切った4回が4〜7件でした。<mark>30＋30＝60案にいちばん近づくのは、同じ会話の続きで頼んだときです。</mark>

**60案を1つのファイルに落として、条件の○×を毎回同じコードで当てる。**字数・必須語・禁止語・文字種は、表計算ソフトの数式でも判定できます。行が増えても壊れない書き方は[行が増えても壊れない数式を書かせる](/recipes/formula-that-survives-new-rows/)にあります。

**直前に何を聞いたかで、答えの数え方が変わることがあります。**この記事は「同じ会話を続ける」ことを勧めていますが、続けた会話が別の質問を引きずる例は[見積もりの根拠を件数で出させる](/recipes/count-the-estimate-basis/)にあります。**案出しでは効きましたが、集計では逆に働きます。**

**今回の数字はすべて架空データでの実測**（材料2本 × 5通り × 各2回 ＝ 全20回、1回につき一巡目と二巡目の2ターン。後半の指示文は材料2本 × 各2回）です。生の返りと判定コードは `docs/evidence/copy-ideas-second-round.md` に全文置いてあります。
