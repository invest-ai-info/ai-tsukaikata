## これで何ができるか {: .what }

<mark>提案文の末尾に切り離した追記を仕込んだとき、AIが拾うかどうかは、話題が本題とどれだけ近いかで大きく変わりました。</mark>架空の募集文2種（①サイトのリニューアル②動画ナレーション）を用意しました。それぞれの末尾に「話は変わりますが」と本題から切り離した追記を仕込みます。追記の内容は次の2水準です。

- **本題に近い話題**：サイトのフォーム不具合／動画の字幕の不具合
- **本題と遠い話題**：展示会での対応が分かりにくい（両材料でそろえた）

近い話題は2つの材料とも6/6で拾いました。遠い話題は材料1（サイトリニューアル）が0/6、材料2（動画ナレーション）が3/6にとどまりました。近い条件の合計は12/12、遠い条件の合計は3/12で、差は9です。

<mark class="warn">「切り離せば必ず無視される」わけでも「近ければ必ず拾う」わけでもありません。</mark>この2つの架空の募集文・のべ36回での実測です。確かめていないことは、記事の最後にまとめます。

## 前提 {: .need }

| | |
|---|---|
| かかる時間 | 15分 |
| 費用 | 無料。ブラウザのチャットAIで足ります |
| 必要なもの | 特にありません。募集文を読んで提案文を書かせる場面の話です |
| プログラミング | **不要**。この記事の指示文をコピーして貼るだけです |

<mark class="warn">この記事は「採用率が上がるか」を測ったものではありません。</mark>測ったのは「AIが募集文の追記を拾うかどうか」だけです。実際に提案文を送るときは、拾われた内容が事実として正しいか、相手に失礼にならないかを必ず自分で確認してください。

[本題と無関係な追記に切り離すと、地の文と違って拾われないことがある](/recipes/proposal-reads-between-lines-if-woven-in/)という記事をすでに書きました。ただしその記事では、材料2（動画ナレーション）だけ切り離しても3/4が拾いました。**落ち方は材料によって強さが違う**という結果が残っていたのです。本文はこう推測していました。「材料2の狙いは今回の依頼と話題として近く、切り離しても自然につながって見えた可能性がある」。今回はその推測を、話題の近さを意図的に振って確かめました。応募文づくり全般は[実績を盛らずに提案文を組む記事](/recipes/proposal-without-inflating/)も参考にしてください。

## 応用・次の一手 {: .next }

**自分が募集文・依頼文を書く側でも応用できます。**本当に伝えたい前提（予算の上限、譲れない条件など）があるとします。それを本題と無関係に見える場所に切り離して書くと、話題が遠いほど抜け落ちるかもしれません。

情報の「置き場所」が結果を左右するという同じ性質を、別の場面でも確かめています。[材料に無い情報を先に挙げさせる記事](/recipes/ask-what-is-missing-first/)と、[見積もりの前提を先に言うか後に言うかで漏れが変わる記事](/recipes/estimate-gap-leaks-on-money-ask/)です。

⚠️ **この結果は、この2つの架空の募集文・のべ36回での実測です。**次の範囲は確かめていません。

- 追記が2つ以上ある場合（今回は1つだけ）
- 話題の近さを3水準以上に分けた場合（今回は近い・遠いの2水準だけ）
- 「近い」「遠い」の判定は担当が用意した2つの話題ペアによるもので、近さそのものを数値化してはいません

「話題を近づければ必ず拾う」「遠ければ必ず無視される」と一般化せず、大事な情報は指示文4のように名指しで頼むほうが安定します。

今回の生の返り36回ぶんと判定コードは `docs/evidence/postscript-lands-only-if-topic-is-close.md` に全文置いてあります。
