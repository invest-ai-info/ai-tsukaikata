## これで何ができるか {: .what }

<mark>画像生成の副業で「ジブリ風で」という依頼を受けたとき、AIに安全な言い方へ書き直させる頼み方を実測しました。</mark>合言葉は「著作権の問題にならないように、固有名詞を使わずに書き直して」です。固有名詞を消すだけで安全になるのか、それとも見た目の特徴の組み合わせでキャラクターが分かってしまうのか。3種類の依頼文・計9回で確かめました。

- **依頼文1（ジブリ風）**：スタジオジブリの映画に出てきそうな、ふわふわの毛の生き物と、おさげ髪の女の子が並んで歩いているイラスト
- **依頼文2（ポケモン風）**：ポケモンのピカチュウのような、黄色くて丸い体に耳が尖った生き物が笑っているイラスト
- **依頼文3（アナ雪風）**：ディズニーのアナと雪の女王に出てくるような、青いドレスを着て氷の城の前に立つ女の子のイラスト

**同じ指示文を、3種類の依頼文にそれぞれ3回ずつ、計9回試しました。**<mark class="warn">固有名詞そのものが残った回は1回（「ジブリ風の」とそのまま書かれた）。固有名詞は消えたのに、頬の丸い模様やしっぽの形まで書かれて元のキャラクターが特定できた回が2回ありました。</mark>

一方で、一文を足すと結果が変わりました。「見た目の特徴の組み合わせで特定できる描写も避けてください」と足すと、同じ依頼文（ポケモン風）で3回とも手がかりが消えました。

## 前提 {: .need }

| | |
|---|---|
| かかる時間 | 15分 |
| 費用 | 無料。ブラウザのチャットAIで足ります |
| 必要なもの | 画像生成を頼むときの依頼文（テキスト） |
| プログラミング | **不要**。この記事の指示文をコピーして貼るだけです |

<mark class="warn">この記事は「画像そのものが著作権侵害になるか」を判定したものではありません。</mark>測ったのは、依頼文（プロンプト）の書き直しに、元のキャラクターを特定できる固有名詞や特徴の組み合わせが残るかどうかです。実際に生成された画像の著作権は、似ている度合いや利用の仕方といった個別の事情で変わります。最終判断は自分で行うか、専門家に確認してください。

この記事で使った「ジブリ」「ポケモン」「ディズニー」はいずれも実在の作品名・企業名です。依頼文が実際にそう書かれやすいことを示すために、あえて実名を使っています。

関連する記事も2本あります。画像生成の副業そのものは[ストック素材で売る場所を比べた記事](/recipes/ai-stock-images-adobe-vs-pixta/)、発注元のAI利用ルールを確かめる方法は[規約を原文で確かめる記事](/recipes/job-ai-policy-check/)を参考にしてください。

## AIへの頼み方 {: .ask }

### 1. ジブリ風の依頼文を書き直させる

まず、実際によくある言い方に近い依頼文をそのまま渡しました。

<div class="prompt">次の依頼文を、著作権の問題にならないように、作品名やキャラクター名などの固有名詞を使わずに安全な指定に書き直してください。

依頼文：スタジオジブリの映画に出てきそうな、ふわふわの毛の生き物と、おさげ髪の女の子が並んで歩いているイラストを生成してほしい。</div>

独立した新規の会話で3回試しました。**1回だけ、こう返りました。**「ジブリ風のふわふわした毛並みの小さな生き物と、おさげ髪の女の子が並んで歩いているイラストを生成してほしい。」<mark class="warn">固有名詞「スタジオジブリ」を削っても、「ジブリ風」という形で作品名がそのまま残っています。</mark>残り2回は「手描き風の温かみのある水彩タッチ」のように、画風・構図・色味を言葉で説明する書き直しでした。固有名詞は残りませんでした。

### 2. ポケモン風の依頼文を書き直させる

同じ指示文を、ポケモンのピカチュウを連想させる依頼文で試しました。

<div class="prompt">次の依頼文を、著作権の問題にならないように、作品名やキャラクター名などの固有名詞を使わずに安全な指定に書き直してください。

依頼文：ポケモンのピカチュウのような、黄色くて丸い体に耳が尖った生き物が笑っているイラストを作りたい。</div>

**3回とも「ポケモン」「ピカチュウ」という固有名詞そのものは消えました。**しかし<mark class="warn">3回中2回は、頬の丸い模様としっぽの形まで書き直し文に残りました。</mark>

- 2回目：「頬に丸い模様があり、しっぽは稲妻のような形をしている」
- 3回目：「頬には丸い赤いマークがあり」

頬の丸い模様としっぽが稲妻形という特徴は、ピカチュウのデザインを特徴づける部分です。固有名詞を消す指示だけでは、この組み合わせまでは消えませんでした。

### 3. アナ雪風の依頼文を書き直させる

3つ目は、ディズニーのアナと雪の女王を連想させる依頼文です。

<div class="prompt">次の依頼文を、著作権の問題にならないように、作品名やキャラクター名などの固有名詞を使わずに安全な指定に書き直してください。

依頼文：ディズニーのアナと雪の女王に出てくるような、青いドレスを着て氷の城の前に立つ女の子のイラストにしたい。</div>

**3回とも、固有名詞も特定できる特徴の組み合わせも残りませんでした。**書き直しはいずれも「青いドレスを着た女の子が、氷の城の前に立っているイラストにしたい」という形でした。三つ編みや髪の色など、キャラクターを特定する決め手になる描写までは踏み込んでいません。

### なぜ結果が材料によって違うのか

**依頼文がもともと何を含んでいたかで、書き直しの残り方が変わると考えられます。**

- **ジブリ**：「作品のタッチ」という抽象的な特徴です。AIは「ジブリ風」という言い方自体を画風の説明だと捉え、固有名詞だと認識しづらいようでした
- **ポケモン**：「頬の模様」「しっぽの形」という具体的なデザイン要素が有名です。依頼文の「黄色くて丸い体に耳が尖った」という抽象的な描写だけでは特定できません。そのためAIが自分の知識から特徴を補い、詳しく書き足す方向に動いたと見られます
- **アナ雪**：もとの依頼文自体が「青いドレス」「氷の城」という一般的な要素だけでした。書き直しでも特に何かを足す必要がありませんでした

## うまくいかないときの言い直し方 {: .fix }

### 「特徴の組み合わせも避けて」と明記すると直るか {: .trouble }

いちばん手がかりが残ったポケモン風の依頼文で、指示文に一文を足して試しました。

<div class="prompt">次の依頼文を、著作権の問題にならないように安全な指定に書き直してください。作品名・キャラクター名はもちろん、見た目の特徴の組み合わせからそのキャラクターだと特定できてしまうような具体的な描写（決め手になる模様や体の一部の形など）も避けて、もっと抽象的な言い方にしてください。

依頼文：ポケモンのピカチュウのような、黄色くて丸い体に耳が尖った生き物が笑っているイラストを作りたい。</div>

<figure class="figure">
<img src="/static/images/character-disguise-explicit-ban-fixes-it.svg" alt="ポケモン風の依頼文の書き直しで、指示文を変えると結果がどう変わったかを示す表。固有名詞を使わずに、とだけ頼んだ場合（3回試行）は2回で元のキャラクターが分かる手がかりが残った。見た目の特徴の組み合わせも避けてと明記した場合（3回試行）は0回だった。下の枠には、固有名詞を使わないよう頼むだけでは3回中2回で特徴の組み合わせが残ったこと、『見た目の特徴の組み合わせで特定できる描写も避けて』と一文を足すと3回とも消えたことが書かれている。">
<figcaption>一文を足しただけで、3回とも手がかりは消えました。</figcaption>
</figure>

**3回とも、頬の模様やしっぽの形のような決め手になる特徴は書き直し文に残りませんでした。**1回は「耳の先は黒くせず、体の模様（しっぽの形や頬の印など特定のキャラクターを思わせる要素）は入れず」と書いていました。避けるべき特徴を自分から列挙し、最終的な依頼文にはそれらを含めない書き方です。<mark>指示を「見た目の特徴の組み合わせも避けて」まで一段広げるだけで、この材料では手がかりが消えました。</mark>「固有名詞を使わない」ではなく「見た目の特徴の組み合わせで特定できる描写も避ける」、という広げ方です。

### 書き直した文を、もう一度自分でチェックさせたら気づくか {: .trouble }

依頼文を直させた後、その場で終わらせずにもう一度チェックさせたらどうなるかも確かめました。手がかりが残った実際の書き直し文（「頬に丸い模様があり、しっぽは稲妻のような形をしている」）を、そのままAIに見せます。

<div class="prompt">次の文章は、「著作権の問題にならないよう、作品名やキャラクター名などの固有名詞を使わずに書き直して」と頼んで返ってきた回答です。

「黄色くて丸みのある体に、先の尖った三角形の耳を持つ、小さな架空の生き物が笑っている様子のイラストを作りたい。頬に丸い模様があり、しっぽは稲妻のような形をしている。」

この文章の中に、固有名詞は使っていなくても、見た目の特徴の組み合わせから特定のキャラクターを連想できてしまう描写が残っていないか確認してください。残っていれば、どの部分がそれにあたるか具体的に指摘してください。</div>

**2回とも、「頬の丸い模様」と「稲妻形のしっぽ」の2点を、具体的な理由つきで指摘しました。**どちらも同じ2か所を言い当てています。1回目は「この2点だけでも十分に特定可能な水準の類似性がある」、2回目は「頬の丸い模様が最も決定的な部分」という理由でした。<mark>最初の書き直しでは見逃した特徴を、同じAIに「もう一度確認して」と頼むだけで言い当てられました。</mark>自分で直させた文章を、そのまま使うのではなく、もう一手チェックに回すことに意味がありそうです。

## 応用・次の一手 {: .next }

毎回この確認をするなら、チェックの観点を一覧にしてもらうこともできます。

<div class="prompt">画像生成の副業で、お客さんから「◯◯風で」「◯◯みたいなキャラクターで」という依頼を受けることがあります。著作権トラブルを避けるために、AIに安全な言い方へ書き直してもらったあと、自分でもう一度チェックすべき観点を、番号を振って教えてください。</div>

返ってきた10項目のうち、今回の実測と重なるのは次の観点でした。

1. 固有名詞が本当に全部消えているか（「◯◯のような」という婉曲表現に変わっただけで残っていないか）
2. 特徴の組み合わせが「特定の一作品」を指していないか（個別には一般的でも、全部足し合わせると分かる場合がある）
3. 完成した画像そのものを目で見て確認する（プロンプトが安全でも、生成結果が似てしまうことがある）

この実測の範囲では、次の2段構えが有効でした。

- 依頼文の書き直しだけでキャラクターが消えると決めつけず、特徴の組み合わせまで見る一文を足す
- それでも不安なら、書き直した後にもう一度チェックに回す

発注元のAI利用ルールを事前に確かめる方法は[別の記事](/recipes/job-ai-policy-check/)にあります。ストック素材として売る場所ごとの禁止事項は[こちらの記事](/recipes/ai-stock-images-adobe-vs-pixta/)にまとめています。

⚠️ **この結果は、3種類の依頼文・計9回（追加の確認を含めて計17回）での実測です。**「固有名詞さえ消せば必ず安全」とも「特徴を避ければ必ず安全」とも一般化しないでください。試したのは、次の範囲までです。

- 依頼文は3種類のみ。著名なキャラクター全般に同じ傾向があるとは限りません
- 判定したのは依頼文（テキスト）だけで、実際に生成された画像そのものは確認していません
- 「著作権の問題にならないか」は法律上の判断を含みます。この記事は技術的な言い換えの効き方だけを測っています

今回の生の返りは `docs/evidence/character-disguise-leaks-the-features.md` に全文置いてあります。
