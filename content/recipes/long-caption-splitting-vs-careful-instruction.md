## これで何ができるか {: .what }

<mark>動画編集の副業で自動字幕を検品するとき、10分を超える長尺動画でも検品の精度は同じか実測しました。</mark>[先行する3本の記事](/recipes/naive-caption-check-drops-the-warm-time-number/)はいずれも「材料は最長47行（約4分半ぶん）まで。10分・20分を超える長尺動画は試していません」と宿題を残していました。今回は、架空の空気清浄機レビュー動画（10分23秒・88行）を使い、同じ種類の誤りを前半8件・後半8件、計16件仕込んで試しました。

**素朴に通しで聞いた5回では、前半8件の隠れた誤りを見つけたのは10/40（25%）。後半8件は12/40（30%）でした。**<mark class="warn">前半のほうが見逃されやすい結果になりましたが、原因を確かめると「前半だから」ではありませんでした。</mark>

**前半だけを切り出して別に聞くと、13/24（54%）まで上がりました。**動画を分けずに「数値に注意して確認してください」と頼むだけでも、**15/24（62.5%）**まで上がり、分割よりも効きました。一方、後半8件は分割でも強調指示でもほとんど変わりませんでした（30%→33%・50%）。

## 前提 {: .need }

| | |
|---|---|
| かかる時間 | 15分 |
| 費用 | 無料。ブラウザのチャットAIで足ります |
| 必要なもの | 動画編集ソフトやYouTubeから書き出した自動生成キャプションのテキスト |
| プログラミング | **不要**。この記事の指示文をコピーして貼るだけです |

<mark class="warn">この記事は「音声を正しく直せるか」を測ったものではありません。</mark>測ったのは「キャプションのテキストだけを読んで、文脈上は自然だが値が違う数字に気づけるか」です。最終的な正しさは必ず元の音声か製品の仕様書で確認してください。

架空の空気清浄機「クリアウィンド Z1」という設定で作ったキャプションを使っています。実在の企業・商品とは関係ありません。素朴な指示文での検品そのものは[先行記事](/recipes/naive-caption-check-drops-the-warm-time-number/)、文脈上自然な数字の誤りは[字幕検品の盲点を見つけた記事](/recipes/natural-number-swap-hides-from-naive-check/)で確かめています。

## AIへの頼み方 {: .ask }

### 1. 10分の動画を、通しで素朴に聞く

架空のレビュー動画（10分23秒・88行）を用意しました。仕込んだのは16件の「文脈上どちらでも成立する」誤り（製品のスペック値が少し違う数字になっている）です。前半・後半に8件ずつ、均等に仕込んでいます。

<div class="prompt">これは動画の自動生成キャプションです。聞き取りミスで誤って変換されている可能性がある箇所があれば、指摘してください。</div>

上に続けて、タイムスタンプつきのキャプション全文（88行）を貼ります。5回試した結果です。

| | 見つかった回数 |
|---|---|
| 前半8件（0:00〜5:43） | 10/40（25%） |
| 後半8件（5:50〜10:23） | 12/40（30%） |

前半・後半ともに8件中、5回とも1回も見つからなかった項目が複数あります。

- 前半：対応畳数・フィルター交換周期・コード長
- 後半：保証期間・お手入れ頻度・価格帯

これらは「よくある範囲に収まる数字」で、値だけ見ても不自然ではありません。

### 2. 前半・後半を切り分けて、同じ指示文で聞く

同じ16件を、前半だけ（0:00〜5:43・50行）・後半だけ（5:50〜10:23・38行）に切り分けて、同じ指示文を3回ずつ試しました。まず前半だけです。

<div class="prompt">これは動画の自動生成キャプションです。聞き取りミスで誤って変換されている可能性がある箇所があれば、指摘してください。</div>

後半だけでも、同じ指示文を3回試しました。

<div class="prompt">これは動画の自動生成キャプションです。聞き取りミスで誤って変換されている可能性がある箇所があれば、指摘してください。</div>

| | 通しで聞いたとき | 分けて聞いたとき |
|---|---|---|
| 前半8件 | 10/40（25%） | 13/24（**54%**） |
| 後半8件 | 12/40（30%） | 8/24（33%） |

**前半だけを切り出すと、見つかる割合が2倍以上になりました。**ところが後半は、分けても30%→33%とほとんど変わりません。<mark>同じ「分ける」という工夫が、前半と後半で効き方が違いました。</mark>

### 3. 分けずに「数値に注意して」と頼む

今度は10分の動画を分けずに、指示文だけを変えて試しました。

<div class="prompt">これは動画の自動生成キャプションです。文章としては自然に読めても、具体的な数値（時間・個数・人数など）が前後の文脈や一般的な製品の仕様と比べて不自然でないか、特に注意して確認してください。聞き取りミスで誤って変換されている可能性がある箇所があれば、指摘してください。</div>

3回試した結果です。

| | 素朴に聞いたとき | 「数値に注意して」と頼んだとき |
|---|---|---|
| 前半8件 | 10/40（25%） | 15/24（**62.5%**） |
| 後半8件 | 12/40（30%） | 12/24（50%） |

**動画を分けなくても、指示文を変えるだけで前半8件の検出は62.5%まで上がりました。**切り分けて聞いた54%よりも高い結果です。後半8件も30%→50%まで上がりましたが、前半ほどの伸びではありません。

### なぜ、前半と後半で効き方が違うのか

**通しで読むと、前半の内容は後半の内容より先に読まれています。**AIが答えを作る時点では、後半の内容のほうが「直前に読んだばかりの情報」です。前半の数字は、同じ会話の中でも相対的に古い情報として扱われやすく、見直されにくいと考えられます。

<mark>動画を2つに分けて渡すと、前半の内容が「直前に読んだばかりの情報」になるので、通しで読んだときより見直されやすくなります。</mark>一方、後半はもともと「直前に読んだばかりの情報」の位置にあるので、分けても大きくは変わりません。「数値に注意して」という一文は、分割と似た効果を、分けずに実現する言い方だと考えられます。

## うまくいかないときの言い直し方 {: .fix }

### 「見つからない」と「自信を持って問題なしと言う」は違う {: .trouble }

素朴に通しで聞いた5回のうち1回は、他の4回と違う崩れ方をしました。

```
【5回のうち1回だけ出た崩れ方（要点）】
明らかな誤変換(聞き取りミス)は見当たりませんでした。製品名「クリアウィンド Z1」や
数値・仕様の記述も文脈上一貫しており、不自然な単語の混入もありません。
```

この回は、前半・後半とも1件も指摘しませんでした。<mark class="warn">単に見つからなかった他の回と違い、この回は「一貫している」と明言しています。</mark>見つからないことと、確認済みだと言い切ることは違います。「不足はありません」という言い切りを、そのまま信じてよいとは限らないことは、[キャンセルの検算を試した記事](/recipes/cancellation-note-half-goes-unchecked/)でも確かめています。

### 「数値に注意して」でも、動かない項目がある {: .trouble }

「数値に注意して確認してください」と頼んだ3回とも、1件も指摘されなかった項目が2つありました。

- 保証期間「3年間」（正しくは1年間）
- 価格帯「3万円前後」（正しくは2万円前後）

<mark class="warn">この2件は、素朴に聞いた5回・分けて聞いた3回・「数値に注意して」と頼んだ3回、合計11回を通じて一度も指摘されませんでした。</mark>どちらも、保証や価格として「よくある範囲」に収まる数字です。[先行記事](/recipes/natural-number-swap-hides-from-naive-check/)で確かめたとおり、**「よくある範囲に収まる誤り」は、分けても・注意を促しても見つかりにくいまま残ります。**どの工夫も万能ではありません。保証・価格のような項目は、原文の仕様書と突き合わせる検品（[仕様書を使った検品の記事](/recipes/spec-sheet-clears-the-natural-number-miss/)）を別に用意したほうが確実です。

### 2つの工夫を重ねても、足し算にはならない {: .trouble }

分けて、さらに「数値に注意して」も頼むとどうなるかも試しました。前半だけを切り出した材料に、強調した指示文を使います。

<div class="prompt">これは動画の自動生成キャプションです。文章としては自然に読めても、具体的な数値（時間・個数・人数など）が前後の文脈や一般的な製品の仕様と比べて不自然でないか、特に注意して確認してください。聞き取りミスで誤って変換されている可能性がある箇所があれば、指摘してください。</div>

| | 前半8件を見つけた回数 |
|---|---|
| 通しで「数値に注意して」 | 15/24（62.5%） |
| 分けて、さらに「数値に注意して」 | 12/24（50%） |

**2つの工夫を重ねても、通しで「数値に注意して」と頼んだときより下がりました。**<mark class="warn">分けて渡すと、後半の内容（比較クラスや消費電力など）と見比べる手がかりが失われます。</mark>前半の数字の中には、後半の別の数字と比べて初めて「おかしい」と気づくものも含まれていました。分けたことで、その手がかりが使えなくなったと考えられます。**工夫は重ねるほど良いとは限りません。**

## 応用・次の一手 {: .next }

長い動画を検品する手順そのものも聞いてみました。

<div class="prompt">動画編集の副業で、10分を超えるレビュー動画の自動字幕を検品しています。通しで「聞き取りミスがないか確認して」と頼むと、動画の前半に出てくる数値の誤りを見逃しやすいと分かりました。検品の進め方そのものを見直すなら、どんな工夫ができるか、番号を振って教えてください。</div>

2回試したところ、どちらも「動画を2〜3分割し、それぞれ別に確認する」という本文の工夫を自分から含めていました。もう1つ共通して出てきたのは、「数値だけを先に全部抜き出してリスト化し、あとから1件ずつ照合する」という2段階の進め方です。こちらは本文では試していません。

本文の実測から言えるのは、**提案の1つ（分割）よりも、本文で確かめた「数値に注意して確認して」という一言のほうが、手間なしで同等以上の効果があった**ということです。もう1つの提案（数値を先にリスト化する2段階方式）は、[字幕検品の盲点を見つけた記事](/recipes/natural-number-swap-hides-from-naive-check/)でも「次に試す人への宿題」として残っており、この記事でも試していません。

同じ検品の副業について、参考になる記事が2本あります。文脈上自然な数字の誤りは[字幕検品の盲点を見つけた記事](/recipes/natural-number-swap-hides-from-naive-check/)、外部の仕様書と突き合わせる検品は[仕様書を使った検品の記事](/recipes/spec-sheet-clears-the-natural-number-miss/)です。

⚠️ **この結果は、架空のレビュー動画1本（10分23秒・仕込み16件）・計19回の実測です。**「長い動画ほど前半が見逃される」と一般化しないでください。試したのは、次の範囲までです。

- 動画は1本・10分23秒のみです。20分・30分とさらに長い動画は試していません
- 前半・後半の区切りは1か所のみです。3分割・4分割は試していません
- 「数値に注意して」と「分割」を両方使う組み合わせは、前半だけで3回試しました。後半での組み合わせは試していません
