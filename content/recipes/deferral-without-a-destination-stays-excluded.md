## これで何ができるか {: .what }

[緊急語が入っても仕分けは崩れない](/recipes/urgent-word-itself-does-not-slip-through/)という前作があります。緊急語を含みながら先送り先を書いた依頼（「来週分の定期メンテナンスで」等）を、広い基準の指示文で正しく除外できることを確かめた記事です。末尾にはこう書き残していました。

- 先送り先を書かず、優先度だけを下げる言い方は試していない
- 社内ヘルプデスク以外の題材への横展開も試していない

測ったのは1つめです。先送り先を**一切書かない**依頼を新しく仕込みました。「至急対応をお願いしたい件ですが、**他の作業が立て込んでいればそちらを先で構いません**」のような言い方です。これを、前作で確立した広い基準の指示文に通しました。

1. 材料A（丁寧な長文）・B（口語）×健全5件のみ・既存の誤りも混在の2条件×各2回＝**8回**試しました
2. <mark>8回すべてで、該当する1〜2件だけが正しく除外され、健全な5件は一度も巻き込まれませんでした。</mark>

## うまくいかないときの言い直し方 {: .fix }

### 「先送り先を書いていないから見抜けないのでは」と心配になる {: .trouble }

この実測の範囲では、心配は当たりませんでした。広い基準（「〜に限らず、同じ意味を持つ表現も含めて」）は、具体的な先送り先の有無を見ていません。<mark>文全体が指す対応時期という1点だけで判断していました。</mark>基準を語の例示に戻さない限り、この結果は保たれるはずです。

### 古い基準（語の有無だけで固定）に戻したらどうなるか {: .trouble }

[前作](/recipes/urgent-word-itself-does-not-slip-through/)が既に確かめています。<mark class="warn">語の有無だけで固定した古い基準は、先送り先を書いた依頼で8回中7回すり抜けました。</mark>この記事では古い基準を再検証していません。ただし先送り先を書かない依頼は「至急」という語自体が本文にそのまま残ります。古い基準ではさらに見抜きにくくなると考えられます。

### 誤りと新しい依頼が同時に来たら、どちらかを見逃さないか {: .trouble }

指示文2・3がこの心配に答えています。<mark>性質の異なる2つの崩し方（解決済みの誤り・先送り依頼）が同じ一覧に同居しても、8回中8回、両方とも正しく見分けられました。</mark>片方だけ見逃す、健全な行を巻き添えにする、といった崩れ方はこの実測では起きていません。

## 応用・次の一手 {: .next }

**[「AIには工程を分けて頼め」から始まった連作](/recipes/split-into-stages-what-breaks/)に、5本目が加わりました。**

1. 工程を分けると、上流の誤りは下流で直るか。答え＝「確認は効くが、健全なときほど巻き添えを生む」（[doubt-fixes-added-not-dropped](/recipes/doubt-fixes-added-not-dropped/)）
2. 基準を固定すれば直るか。答え＝「誤りには効くが、健全な巻き添えは消えない」（[narrowed-criteria-fixes-dirty-not-clean](/recipes/narrowed-criteria-fixes-dirty-not-clean/)）
3. 基準を緩めて類義語も含めれば直るか。答え＝「24回中24回、直った」（[synonym-wording-empties-the-collateral](/recipes/synonym-wording-empties-the-collateral/)）
4. 緊急語そのものが入った、先送り先ありの紛れ語でも直るか。答え＝「16回中16回、直った」（[urgent-word-itself-does-not-slip-through](/recipes/urgent-word-itself-does-not-slip-through/)）
5. **この記事。**先送り先を書かない、優先度だけを下げる依頼でも直るか。答え＝「8回中8回、直った」

📌 **広い基準の指示文は、連作を通じて一度も書き換えられていません。**4本目・5本目とも、紛れ語の作り方だけを変えて同じ指示文に通しています。自動仕分けの除外基準は、個別の紛れ語に合わせてその都度直すより、最初から範囲を広げておくほうが保守の手間が少なくなります。

- 社内ヘルプデスク以外の題材（経費・在庫・商品カテゴリなど）への横展開
- 古い基準（語の有無だけで固定）に先送り先を書かない依頼を通した場合の崩れ方
