## これで何ができるか {: .what }

毎朝の受入検品を、AIに任せる形です。**やり方によって、見つかる不良の数がまったく変わります。**プログラミングは要りません。

| やり方 | 結果 |
|---|---|
| **20件全部**を1件ずつ確認させる | 境界線上の不良5件を、4回とも全部正しく不合格にした |
| **抜き取りで3件・6件**をAIに選ばせる | 選んだ項目の判定は外れなかったが、AIは怪しい項目を狙って選んでいた |
| **1件目・10件目・20件目**と、人が位置を指定する | 5件の不良を1つも拾えなかった（指定した3件がたまたま良品だったため） |

<mark>1g・1日・英数字1文字という際どい差でも、20件全部を見せれば12回とも見逃しませんでした。危ないのは判定の精度ではなく、そもそも何件を見せるかです。</mark>

<mark class="warn">「抜き取り」をAIに任せると、無作為ではなく怪しい項目を狙って選んできます。人が思う「抜き取り」とは中身が違います。</mark>

この記事は、架空の納品データを使った実測です。実際の検品現場の記録ではありません。

## 前提 {: .need }

| | |
|---|---|
| かかる時間 | 20分。検品の頼み方を決めるときに1回だけやります |
| 費用 | 無料。無料のチャットAIで足ります |
| 必要なもの | ブラウザで使えるAI（ChatGPT・Claude・Geminiなど）と、検品の基準（数値・日付・型番） |
| プログラミング | 不要。基準と一覧をそのまま貼るだけです |

📌 **数字はすべて架空データでの実測です。**納品記録20件それぞれに、重複しない識別子（`D-01` の形）・重量・使用期限・型番を1つずつ付けました。

⚠️ **仕込んだ5件は、どれも際どい差です。**重量は下限480gに対して479g（1g不足）と、上限520gに対して522g（2g超過）。使用期限は基準日2026-11-25に対して2026-11-24（1日不足）と2026-11-19（6日不足）。型番は `ASSY-118-B` に対して `ASSY-118-8`（末尾1文字違い）。目視ならすべて見落としうる差です。

## AIへの頼み方 {: .ask }

### 1. まず、いつもどおり「抜き取り3件」を頼む

多くの現場でやっている検品の形です。20件全部は見ず、3件だけ抜き取って確認します。

<div class="prompt">毎朝の受入検品です。今日届いた20個から、抜き取りで3個だけ選んで確認してください。基準は次のとおりです。①重量480〜520g（両端含む） ②使用期限は本日（2026-09-26）から60日以上先であること ③型番はASSY-118-Bであること。選んだ3個について、基準を満たしているかどうかを教えてください。</div>

このあとに、20件の記録（識別子・重量・使用期限・型番）を貼ります。

**2回とも、選んだ3件の判定そのものは外れませんでした。**1回目は `D-01`・`D-08`・`D-16` を選び、重量超過の `D-08` と型番違いの `D-16` を正しく不合格にしています。

> 【D-08】522g / 期限2026-12-05 / ASSY-118-B
> → 重量×(520gを超過)、期限○、型番○ ⇒ **不合格(重量超過)**

🚨 **問題は判定ではなく、選ばれなかった残り17件です。**1回目は不良5件のうち2件しか選ばれず、2回目（`D-02`・`D-07`・`D-16`）は1件しか選ばれませんでした。残る3件・4件は、良いとも悪いとも一度も判定されていません。

### 2. 抜き取りを6件に増やす

3件で不安なら、件数を増やせば直るように思えます。

<div class="prompt">毎朝の受入検品です。今日届いた20個から、抜き取りで6個だけ選んで確認してください。基準は次のとおりです。①重量480〜520g（両端含む） ②使用期限は本日（2026-09-26）から60日以上先であること ③型番はASSY-118-Bであること。選んだ6個について、基準を満たしているかどうかを教えてください。</div>

**2回とも、まったく同じ6件（`D-01`・`D-05`・`D-08`・`D-11`・`D-16`・`D-19`）が選ばれました。**うち4件が本物の不良で、4件とも正しく不合格にしています。2回目はなぜその6件を選んだかまで書いていました。

> 抜き取り6個として、リストの中から重量超過・期限ギリギリ・型番違いなど「基準に触れそうなもの」を含めてバランスよく次の6件を選び、確認しました

<mark class="warn">「抜き取り」を頼んでも、AIは無作為に選んでいません。全件に先に目を通し、怪しく見えるものを混ぜて選んでいます。</mark>件数を増やせば拾える不良は増えますが、それは「たまたま当たった」のではなく「怪しいものを狙われた」結果です。**人が想像する無作為な抜き取りとは、中身が別物です。**

### 3. 位置をこちらで指定する

AIに選ばせたくないなら、位置を固定する手があります。

<div class="prompt">毎朝の受入検品です。今日届いた20個のうち、1件目・10件目・20件目の3個を確認してください。基準は次のとおりです。①重量480〜520g（両端含む） ②使用期限は本日（2026-09-26）から60日以上先であること ③型番はASSY-118-Bであること。基準を満たしているかどうかを教えてください。</div>

**2回とも、指定どおりの3件（`D-01`・`D-10`・`D-20`）が返り、3件とも合格でした。**5件の不良は1つも見つかりません。**この3件が、たまたま全部良品だったからです。**

🚨 **ただし2回とも、頼んでいない「参考」情報が付いてきました。**

> （参考：全20件をざっと目視すると、D-08は522gで①を外れ、D-16は型番がASSY-118-8で③を外れているように見えますが、これらは今回確認対象外の3件・10件・20件目には含まれていません。念のため申し添えます。）

2回合わせると、この「参考」欄は重量違反(`D-08`)と型番違反(`D-16`)には触れましたが、日付を数え直さないと分からない期限違反(`D-05`・`D-11`)には一度も触れませんでした。<mark>見た目で分かる異常は「ついで」に拾いますが、計算がいる異常は拾いません。</mark>

### 4. 抜き取りをやめて、20件全部を確認させる

対象外を作らない、いちばん単純な直し方です。

<div class="prompt">毎朝の受入検品です。今日届いた20個全部について、基準を満たしているかどうかを1件ずつ確認してください。基準は次のとおりです。①重量480〜520g（両端含む） ②使用期限は本日（2026-09-26）から60日以上先であること ③型番はASSY-118-Bであること。基準外のものがあれば、識別子とどの基準に違反しているかを教えてください。</div>

**2回とも、20件中の不良5件を全部正しく不合格にし、良品15件を誤って不合格にした回はゼロでした。**

> 20件のうち、基準を満たさないものは5件です（残り15件は①〜③すべて満たしています)。
>
> - **D-03**：重量 479g → ①重量違反（480g未満、下限を1g下回る）
> - **D-05**：使用期限 2026-11-24 → ②期限違反(本日2026-09-26から59日後で、60日基準に1日足りない)

<figure class="figure">

⚠️ **1点だけ、内部の計算がずれた回がありました。**2回目の返りは、60日後の基準日を「2026-11-26」と書いています（正しくは2026-11-25）。

> 毎朝の受入検品、20件を基準①重量480〜520g(両端含む)・②使用期限が本日(2026-09-26)から60日以上先(=2026-11-26以降)・③型番ASSY-118-Bで確認しました。

**それでも判定結果は5件とも正しいままでした。**基準日を1日間違えても、境界の1日不足（`D-05`）はもともと2日以上の差でアウト側に落ちるため、結論は動きません。ただし、もし本物の納品が2026-11-25ちょうどだったら、この回だけ間違った判定を返していたはずです。

### 5. 判定の前に、差を書き出させる

内部の計算ミスが心配なら、計算過程を先に書かせます。

<div class="prompt">毎朝の受入検品です。今日届いた20個全部について、基準を満たしているかどうかを1件ずつ確認してください。基準は次のとおりです。①重量480〜520g（両端含む） ②使用期限は本日（2026-09-26）から60日以上先であること ③型番はASSY-118-Bであること。判定の前に、3つの基準それぞれについて実際の値と基準値の差を書き出してから、合格か不合格かを判定してください。基準外のものがあれば、識別子とどの基準に違反しているかを教えてください。</div>

**2回とも、5件全部を正しく不合格にし、基準日も2回とも「2026-11-25」と正しく計算していました。**

> | D-03 | 479g（**下限-1g＝1g不足**） | 2026-12-20（+25日） | 一致 | **不合格（重量）** |

差を書き出す手間は増えますが、**前の版で起きた基準日のずれは、この2回では起きませんでした。**材料はこの1組・この2回だけなので、「差を書き出せば必ずずれない」とまでは言えません。ただし、途中式が答えに残るぶん、あとから人が検算しやすくなります。

### 6. 「小さな差でも見逃さないで」と念を押す

念押しの一言で、精度が変わるかも試しました。

<div class="prompt">毎朝の受入検品です。今日届いた20個全部について、基準を満たしているかどうかを1件ずつ確認してください。基準は次のとおりです。①重量480〜520g（両端含む） ②使用期限は本日（2026-09-26）から60日以上先であること ③型番はASSY-118-Bであること。小さな差でも見逃さないでください。基準外のものがあれば、識別子とどの基準に違反しているかを教えてください。</div>

**2回とも結果は変わらず、5件を正しく不合格にしました。**すでに全数確認そのものが5/5で見逃しゼロだったため、念押しで伸びしろがありませんでした。天井（見逃しゼロ）に達している版に念押しを足しても、それ以上は上がりません。この記事と同じ結論は、[「重要です」を足しても見逃しは減らない](/recipes/urgent-wording-does-not-catch-more/)にもあります。

## うまくいかないときの言い直し方 {: .fix }

### 「抜き取り」を頼んだのに、無作為に選ばれていない気がする {: .trouble }

その勘は正しいです。この実測では、3件・6件のどちらでも、AIは怪しく見える項目（重量が極端・型番が違う）を狙って選んでいました。⚠️ **本当に無作為な抜き取りが必要なら、AIに選ばせず、乱数で行番号を決めてから渡してください。**AIに「抜き取って」と頼む形は、無作為抽出ではなく「AIなりの一次スクリーニング」になります。

### 全数確認の返りに、基準日の計算が1日ずれていた {: .trouble }

4回中1回、60日後の基準日を「2026-11-26」（正しくは2026-11-25）と書いた回がありました。この回でも最終判定は5件とも正しいままでしたが、**境界ちょうどの日付が来たら判定を間違えていたはずです。**⚠️ <mark class="warn">**日付や数量の基準を渡すときは、境界の値そのもの（この記事なら「2026-11-25以降」）も一緒に書き、判定の前にその値を復唱させてください。**</mark>セクション5の「差を書き出させる」版は、この復唱を強制する形です。

### 「参考」として教えてくれる情報を、正式な検品結果だと思ってしまう {: .trouble }

位置を指定した版では、頼んでいないのに「ついでに気づいた」不良を教えてくれました。ただし2回とも、見た目で分かる重量・型番の異常には触れましたが、**日数を数えないと分からない期限の異常には触れませんでした。**🚨 **この「参考」欄をあてにして自動化を組まないでください。**出るかどうかも、何を拾うかも安定しません。検品として使うなら、返りの形式を固定できる「4. 全数確認」の指示文を使ってください。

## 応用・次の一手 {: .next }

**「抜き取り3件」の弱点は、判定の精度ではなく母数でした。**20件中5件が不良のとき、無作為に3件を抜き取っても不良を1つも含まない確率は、組み合わせの計算で約40%あります。

<figure class="figure">
<img src="/static/images/sample-size-miss-probability.svg" alt="抜き取り件数を1件から10件まで増やしたときに、20件中5件の不良を1つも拾わない確率を示した横棒グラフ。組み合わせの計算による理論値で、実験ではない。1件は75.0%、2件は55.3%、3件（今回の記事の運用・濃い色）は39.9%、4件は28.2%、5件は19.4%、6件は12.9%、7件は8.3%、8件は5.1%、9件は3.0%、10件は1.6%。下の枠には、抜き取りが少ないと拾えないのは判定が甘いからではなくそもそも母数が足りないから、この記事の全数確認（20件全部）ならこの確率は0%になるという結論が書かれている。">
<figcaption>抜き取りを増やしても、拾えない確率はすぐには下がりません。</figcaption>
</figure>

**AIに検品を任せるなら、件数を絞る理由がありません。**人が目でやるなら3件が現実的でも、AIに渡す一覧の行数が20行から200行に増えても、頼み方は変わりません。**抜き取りではなく全数確認を、毎朝の自動実行に組み込んでください。**

同じ「定説を実測する」型で、抜き取りの見せ方を6通り試したのが[毎朝ひとりでにAIが作った要約、3件だけ見て不良に気づけるか](/recipes/three-samples-and-the-pass-line/)です。あちらは「AIが選ぶ3件に不良が入るか」を試して16回とも入っていましたが、この記事は「入らなかった残りは、そもそも判定すらされない」という一段先を確かめています。

閾値そのものの誤検知を扱った[更新の間隔がバラつく相手に、異常の閾値を決めさせる](/recipes/flat-threshold-misfires/)とは、扱う異常のタイプが違います。あちらは「正常でも鳴る」誤報の話、この記事は「異常なのに鳴らない」見逃しの話です。

📌 **この記事で測っていないこと**＝5件の不良はどれも1種類の基準にしか違反していません。**複数の基準に同時に違反する項目**（重量も期限も外れている、など）や、**本当に無作為な乱数で選んだ抜き取り**は試していません。また、材料はこの1組の納品記録だけなので、別の商品・別の基準でも同じ結果になるとは言えません。
