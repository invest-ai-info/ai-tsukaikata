## これで何ができるか {: .what }

家に届く紙は、たいてい**読むのが面倒で、書くのはもっと面倒**です。役所の通知、保険の更新、学校のプリント、レシートの山。<mark>この「読む」と「下書き」は、まるごとAIに渡せます</mark>。

仕事で使うより、むしろ暮らしのほうが向いています。締切がゆるく、失敗しても取り返しがつくからです。<mark>AIに慣れる練習として、家の紙仕事から始めるのは合理的です</mark>。

ただし1点だけ、渡してはいけないところがあります。

## 前提 {: .need }

| | |
|---|---|
| かかる時間 | 15分 |
| 費用 | 無料。スマホの無料アプリで足ります |
| 必要なもの | 写真を渡せるAI（ChatGPT・Claude・Geminiのアプリ版） |
| プログラミング | **不要**。写真を送って、この記事の指示文を貼るだけです |

<mark class="warn">マイナンバー・口座番号・カード番号が写っている書類は、そのまま渡さないでください。</mark>指で隠して撮るか、その部分を塗りつぶしてから渡します。AIに送った内容は、送った先の会社のサーバーを通ります。

## AIへの頼み方 {: .ask }

### 1. 難しい通知を、自分向けに言い直させる

役所や保険の文書は、わざと厳密に書いてあるので読みにくいです。

<div class="prompt">この書類の写真を送ります。中身を、次の3つに分けて教えてください。

1. これは何の書類か（1行で）
2. 私は何をすればいいか（やることが無いなら「無し」と書いてください）
3. 期限はいつか

書いていないことは推測せず「書かれていません」としてください。</div>

3つ目の但し書きが効きます。これが無いと、<mark class="warn">よくある一般的な手続きの話を、その書類に書いてあるかのように混ぜてきます</mark>。

### 2. レシートを家計の表にする

1枚ずつ入力する作業は、まとめて渡せば1回で終わります。

<div class="prompt">レシートの写真を何枚か送ります。次の形の表にまとめてください。

日付／店名／金額／分類（食費・日用品・交通費など）

読み取れなかった項目は、空欄にせず「読めません」と書いてください。合計金額も最後に出してください。</div>

<mark>「読めなかったものを空欄にしない」が大事です</mark>。空欄だと、あとで見たときに「0円だった」のか「読めなかった」のか分かりません。読めない部分は自分で入れれば済みます。

### 3. 面倒な文章を、型どおりに書かせる

問い合わせ・申請・お断り。書き出しで止まる文章こそ、下書きを作らせる価値があります。

<div class="prompt">次の内容で、問い合わせの文章を書いてください。

・相手：（どこに出すか）
・伝えたいこと：（箇条書きで3つくらい）
・希望：（どうしてほしいか）

丁寧すぎず、短くしてください。私が読んで直せるように、埋めるべき箇所は（　）にしておいてください。</div>

**「短くして」を必ず付けてください。**放っておくと<mark>やたら丁寧で長い文になり、直すのに時間がかかります</mark>。

### 4. 選択肢を、条件つきで比べさせる

保険・料金プラン・引っ越し先。比較は得意分野です。ただし条件を渡さないと一般論が返ってきます。

<div class="prompt">次の選択肢を比べたいです。私の条件を書きます。

・条件：（家族構成、譲れない点、予算など）
・選択肢：（AとB、または資料の写真）

条件に照らして、それぞれの向き・不向きを表にしてください。書類に書かれていない点は「記載なし」としてください。最後に、私が確認すべき点を3つ挙げてください。</div>

最後の「確認すべき点」が効きます。<mark>AIの比較を鵜呑みにせず、自分で確かめる場所を先に教えてもらう</mark>という使い方です。

## うまくいかないときの言い直し方 {: .fix }

### 写真の文字を読み間違えている {: .trouble }

<div class="prompt">読み取った内容を、加工せずそのまま書き出してください。

読みにくかった箇所は、勝手に補わず「（不明）」と書いてください。そのうえで、私が確認すべき箇所を指摘してください。</div>

<mark class="warn">数字の読み間違いは、それらしく見えるので気づきません。</mark>金額・日付・期限は、必ず原本と1回見比べてください。この「そのまま出させる」考え方は[AIに数字を「それっぽく」埋めさせない頼み方](/recipes/numbers-not-in-the-source/)と同じです。

### 一般論ばかりで、私の書類の話になっていない {: .trouble }

<div class="prompt">一般的な説明は要りません。送った書類に実際に書いてあることだけで答えてください。

書類に書かれていない項目は「この書類には書かれていません」としてください。</div>

### 個人情報を送ってしまった気がする {: .trouble }

<mark class="warn">送ってしまったものは、こちらの操作では取り消せません。</mark>あわてず、次を確認してください。

- そのサービスの設定で、会話の履歴の保存や学習利用を止められることが多いです（サービスごとに場所が違います）
- 会話そのものを削除できる場合もありますが、<mark>削除しても「送った事実」は消えません</mark>
- 口座番号やカード番号を送ってしまった場合は、AI側の設定より先に、**金融機関に相談するほうが確実**です

次からは、渡す前に隠す癖をつけてください。指で隠して撮るだけで十分です。

### 家族に見せたら「これ違うよ」と言われた {: .trouble }

<div class="prompt">この部分が違うと指摘されました。（どこがどう違うか）

なぜそう読み取ったのか、書類のどこを見たのかを教えてください。私が原本のどこを確認すればいいかも書いてください。</div>

## 応用・次の一手 {: .next }

慣れてきたら、毎月くり返す紙仕事をまとめて渡せます。

<div class="prompt">毎月やっている家の作業を書きます。（家計の集計、光熱費の確認、など）

このうち、写真や画面のコピーを渡せば任せられるものはどれですか。渡し方も教えてください。</div>

もう1つ、家族と共有すると効きます。

<div class="prompt">いまの内容を、家族に共有できる短いメモにしてください。専門用語は使わず、やることと期限だけにしてください。</div>

書類は毎年ほぼ同じ形で届きます。<mark>一度うまくいった頼み方を保存しておくと、来年そのまま使えます</mark>。指示文を覚えさせる方法は[AIに「記憶」を持たせる](/recipes/claude-code-memory/)に書きました。

自分の暮らしの中でほかに渡せるものを探すなら、[渡せる作業の見つけ方](/recipes/find-what-to-delegate/)がそのまま使えます。
