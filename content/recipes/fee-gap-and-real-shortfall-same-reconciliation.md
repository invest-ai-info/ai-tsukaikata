## これで何ができるか {: .what }

<mark>振込手数料ぶんの小さな差額と、本当の未入金が同じ月の入金照合に同時に存在しても、AIはこの2種類を取り違えませんでした。</mark>[前作](/recipes/find-the-500-yen-gap-in-a-split-payment/)は、分割入金に埋もれた手数料ぶんの差額を単独で検出できることを確かめました。ただし「同じ請求の中に、手数料による差額と、本当の入金漏れが同時に混ざっている場合」は宿題として残していました。この記事はその宿題に答えます。

架空の月額契約10社の一覧（デザイン制作・翻訳の2種）に、次の2件を同時に仕込みました。

- **手数料型**：契約額より220円（または440円）だけ少なく着金している1件
- **本当の未入金**：入金記録そのものが無く、差額が契約額の全額に一致する1件
- 残り8社は、契約額どおりに着金しています

**材料2種×5回＝10回とも、手数料型の差額は「推測」として軽く扱い、本当の未入金は「要対応」として区別しました。**<mark class="warn">「推測として書いて」という指示を削った6回でも、手数料額を典型的でない85円に変えた6回でも、この区別は崩れませんでした。</mark>健全な8社を誤って指摘した回は、22回を通じて0回です。

## 前提 {: .need }

| | |
|---|---|
| かかる時間 | 20分 |
| 費用 | 無料。ブラウザのチャットAIで足ります |
| 必要なもの | 契約（請求）一覧と、入金明細の2つの表 |
| プログラミング | **不要**。この記事の指示文をコピーして貼るだけです |

<mark class="warn">口座番号や実在の取引先名は貼らないでください。</mark>この記事は架空の社名・金額を使っています。実在の人物・団体とは関係ありません。

手数料ぶんの差額を単独で検出できることは[前作](/recipes/find-the-500-yen-gap-in-a-split-payment/)で、分割の端数があっても崩れないことは[端数の実測記事](/recipes/odd-split-still-catches-the-real-shortfall/)で確かめています。この記事が見ているのは、**2種類の原因が異なる差額が同じ月に両方とも存在するとき、どちらがどちらか取り違えないか**という点です。

## AIへの頼み方 {: .ask }

### 1. デザイン制作10社の月額契約で、手数料型と未入金を同時に試す

D社（契約額65,000円）だけ220円少なく着金し、F社（契約額150,000円）は入金記録そのものがない状態です。他の8社は契約額どおりです。

<div class="prompt">入金明細と契約一覧を突き合わせて、差額がある契約を挙げてください。差額が振込手数料の可能性がある場合はその旨を推測として書いてください。</div>

上に続けて、契約一覧10社・入金明細9社（F社は記載なし）を貼ります。

**5回とも、D社を「推測」、F社を「未入金・要対応」として正しく区別しました。**

> **D社**：差額220円。推測：振込手数料を差し引いて入金された可能性があります。（中略）
>
> **F社**：契約額150,000円に対し、入金明細に記載がありません。これは振込手数料のような小さな差額ではなく、入金そのものがない状態です。

### 2. 翻訳10社の月額契約でも、同じ指示文を試す

今度はO社が440円少なく着金し、N社（契約額200,000円）が入金記録そのものがない状態です。

<div class="prompt">入金明細と契約一覧を突き合わせて、差額がある契約を挙げてください。差額が振込手数料の可能性がある場合はその旨を推測として書いてください。</div>

**こちらも5回とも、O社を「推測」、N社を「未入金・要対応」として正しく区別しました。**健全な8社を誤って指摘した回は、材料2種×5回＝10回を通じて0回です。

### なぜこの言い方が効くのか

**「差額が振込手数料の可能性がある場合はその旨を推測として書いてください」という一言が効いています。**断定を避けながらも、2種類を書き分ける余地を作っているのです。この一言が無くても、下の実測が示すとおり同じ区別は自然に起きました。それでも明示したほうが、どちらが確定情報でどちらが推測かが、読む側にも伝わりやすくなります。

## うまくいかないときの言い直し方 {: .fix }

### 「推測として書け」という指示を削るとどうなるか {: .trouble }

「差額が振込手数料の可能性がある場合はその旨を推測として書いてください」という一文を削り、指示文を短くしました。

<div class="prompt">入金明細と契約一覧を突き合わせて、差額がある契約を挙げてください。</div>

デザイン制作の材料で3回試しました。

**3回とも、D社には「可能性があります」という推測表現が自発的に付き、F社には付きませんでした。**指示していないのに、両者の扱いを自分から分けています。

同じ短い指示文を、翻訳の材料でも試します。

<div class="prompt">入金明細と契約一覧を突き合わせて、差額がある契約を挙げてください。</div>

**こちらも3回とも、O社とN社の扱いを自発的に分けました。**材料2種×3回＝6回を通じて、推測の指示が無くても区別は崩れませんでした。

### 手数料額を、典型的でない85円に変えるとどうなるか {: .trouble }

ここまでの手数料ぶんの差額（220円・440円）は、振込手数料として見慣れた金額です。もっと小さく、銀行手数料としては典型的でない85円に変えて試しました。指示文は指示文1・2と同一です。

<div class="prompt">入金明細と契約一覧を突き合わせて、差額がある契約を挙げてください。差額が振込手数料の可能性がある場合はその旨を推測として書いてください。</div>

デザイン制作の材料（D社の差額を85円に変更）で3回試しました。

**3回とも、D社とF社の区別は崩れませんでした。**ただし、85円という金額には確信度を下げる言い方が付きました。

> 推測：差額85円は、振込手数料を差し引いて入金された可能性があります。ただし、銀行や振込方法による手数料としてはやや少額で、85円という金額が実際の手数料と一致するかは、この資料だけでは確認できません。

同じ変更を翻訳の材料（O社の差額を85円に変更）でも試します。

<div class="prompt">入金明細と契約一覧を突き合わせて、差額がある契約を挙げてください。差額が振込手数料の可能性がある場合はその旨を推測として書いてください。</div>

**こちらも3回とも区別は崩れませんでした。**材料2種×3回＝6回を通じて、典型的でない金額でも、手数料型と本当の未入金を取り違えた回はありません。

<mark>金額が典型的かどうかで変わったのは「どれだけ確信を持って推測と書くか」であって、「2種類を区別できるかどうか」ではありませんでした。</mark>

## 応用・次の一手 {: .next }

**毎月の入金照合を自動にするなら、見分ける工程を追加で足す必要は無さそうです。**手数料ぶんの差額と本当の未入金が同じ月に混ざっても、この記事の範囲では取り違えが起きませんでした。推測の指示を省いても、差額の金額が見慣れないものでも同じです。定期実行の置き方は[「毎日決まった時刻に自動でやっておいて」をAIに作らせる記事](/recipes/github-actions-daily-cron/)にあります。

**それでも、検出した後の扱いまでは自動化しないでください。**手数料型の判定は22回を通じて常に「推測」にとどまり、断定はしていません。先方に確認する・手数料負担の約束を確かめるといった判断は、人間が行う必要があります。

⚠️ **この結果は、この2つの架空の材料・のべ22回での実測です。**次の範囲は確かめていません。

- 手数料型・本当の未入金が、それぞれ2件以上に増えた場合
- 契約額どうしが近い金額で、健全な契約と手数料型の差額が紛らわしい場合
- 3か月以上の連続した月で、同じ会社に手数料ぶんの差額が繰り返し出る場合

今回の生の返り22回ぶんと判定コードは `docs/evidence/fee-gap-and-real-shortfall-same-reconciliation.md` に全文置いてあります。
