## これで何ができるか {: .what }

会議の議事録づくりは、AIに渡す価値が特に大きい作業です。<mark>聞き直しながら書き起こす時間が、まるごと消えます</mark>。

ただし「議事録にして」とだけ頼むと、読める文章は返ってくるのに<mark class="warn">肝心の宿題が本文に埋もれて、結局だれも動きません</mark>。議事録の目的は記録ではなく、次の行動が決まることです。

## 前提 {: .need }

| | |
|---|---|
| かかる時間 | 20分（会議1時間ぶん） |
| 費用 | 無料〜。無料の範囲でできることが多いです |
| 必要なもの | 録音、または文字起こし。音声を渡せるAIだと一段楽になります |
| プログラミング | **不要**。録音を渡して指示文を貼るだけです |

<mark class="warn">録音を渡す前に、社外秘や第三者の個人情報が含まれていないかを確認してください。</mark>会社によっては、外部サービスへの持ち出しが禁止されています。まず自分の職場の規則を確認してください。

## AIへの頼み方 {: .ask }

### 1. 3つを別々に出させる

これがこの記事の本体です。1つの文章にまとめさせないでください。

<div class="prompt">会議の録音（または文字起こし）を渡します。次の3つを、別々の見出しで出してください。

【決まったこと】結論だけ。理由は1行まで
【宿題】誰が・何を・いつまでに。表にしてください
【持ち帰り】決まらなかったこと、次回に回したこと

3つを1つの文章にまとめないでください。</div>

<mark>宿題を表にすると、担当が空欄の行が目で見て分かります</mark>。文章の中に混ぜると、この空欄が見えません。

### 2. 決まらなかったことを消させない

AIは、きれいにまとまった文章を作ろうとします。放っておくと<mark class="warn">結論が出なかった話題が、なかったことになります</mark>。

<div class="prompt">結論が出なかった話題も必ず残してください。

「議論したが決まらなかった」ことは、書かないのではなく、そう書いてください。何が対立点だったかも1行で添えてください。</div>

<mark>会議で一番重要な情報は、決まったことではなく「決まらなかったこと」であることが多い</mark>です。ここが消えると、次の会議で同じ議論をやり直します。

### 3. 埋められない項目を、勝手に埋めさせない

<div class="prompt">担当者や期限が会議で言われていない場合は、推測で埋めないでください。

「（担当者の指定なし）」「（期限の指定なし）」と書いてください。私があとで埋めます。</div>

もっともらしい担当者名を入れられると、<mark class="warn">本人が知らないまま宿題を持たされます</mark>。書かれていないことを書かせない考え方は[AIに数字を「それっぽく」埋めさせない頼み方](/recipes/numbers-not-in-the-source/)と同じです。

### 4. 共有用の短い版も作らせる

出席していない人向けの文面は、議事録とは別物です。

<div class="prompt">いまの議事録から、出席していない人に送る短い連絡文を作ってください。

3行以内。相手が知りたいのは「自分に関係があるか」だけなので、宿題がある人の名前を先頭に書いてください。</div>

### 5. 発言者が分からないときは、分からないままにする

<div class="prompt">誰の発言か特定できない部分は、話者を推測しないでください。

「発言者不明」としてください。声で区別がつかない場合は、その旨を最初に書いてください。</div>

## うまくいかないときの言い直し方 {: .fix }

### 話し言葉のまま書き起こされて読みにくい {: .trouble }

<div class="prompt">話し言葉のままではなく、書き言葉に直してください。

ただし、意味を変えたり要約しすぎたりしないでください。「えー」「あの」のような言い淀みと、繰り返しだけを取り除いてください。</div>

### 長い会議で、後半が薄くなった {: .trouble }

<div class="prompt">会議を前半・後半に分けて、それぞれ別に処理してください。

まず前半だけ渡します。終わったら後半を渡すので、そのときに全体をつなげてください。</div>

<mark>1時間を超える録音は、分けたほうが結果が安定します</mark>。まとめて渡す限界の話は[まとめて1回で頼む](/recipes/batch-instead-of-repeat/)にも書きました。

### 専門用語や社内用語を、別の言葉に変えられた {: .trouble }

<div class="prompt">社内用語はそのまま残してください。一般的な言葉に置き換えないでください。

聞き取れなかった用語は、置き換えずに「（聞き取れず）」としてください。</div>

よく出る用語は、先に渡しておくと精度が上がります。

<div class="prompt">この会議でよく出る用語を先に渡します。（用語を列挙）

これらは正確にこの表記で書いてください。</div>

### 内容が本当か確かめたい {: .trouble }

<div class="prompt">議事録の各項目について、録音のどのあたりの発言に基づいているかを添えてください。

（冒頭・中盤・終盤、または時間の目安）

推測で書いた項目があれば、正直に「これは推測です」と書いてください。</div>

<mark>要約は、書いていないことを書くだけでなく、書いてあることを消すこともあります</mark>。重要な項目は元の録音で確かめてください。

## 応用・次の一手 {: .next }

宿題の表は、そのまま次の会議の材料になります。

<div class="prompt">前回の宿題の表を渡します。今回の録音から、それぞれが「完了・進行中・手つかず」のどれかを判定してください。

言及がなかったものは「今回言及なし」としてください。</div>

<mark>これをやると、会議の冒頭で前回の宿題を追う時間が消えます</mark>。

定例会議なら、書式を固定してしまうのが最終形です。

<div class="prompt">この議事録の書式を、次回以降も同じ形で使いたいです。書式のテンプレートと、私が毎回貼る指示文を作ってください。</div>

覚えさせて毎回同じ形にする方法は[AIに「記憶」を持たせる](/recipes/claude-code-memory/)に書きました。
