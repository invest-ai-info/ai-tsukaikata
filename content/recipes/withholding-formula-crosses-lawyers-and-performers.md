## これで何ができるか {: .what }

<mark>弁護士やタレントなど、原稿料・講演料とは別の業務でも、源泉徴収の正しい手取り額をAIに
計算させられるかを実測しました。</mark>[講演料・翻訳料・著作権使用料で確かめた記事](/recipes/withholding-formula-holds-for-other-fee-types/)の続きです。

結果は3つに分かれました。

- **204条の明記がある契約は、弁護士（204条2号）もタレントの出演料（204条5号）も、3回中3回で正解**
- **204条の明記を外すと、タレントの出演料は1/3まで落ちる**（1回は計算ミス、1回は源泉徴収を適用せず）
- **弁護士の肩書「弁護士」の語だけ残せば明記が無くても3/3のままだが、肩書まで外すと0/3まで落ちる**

<mark class="warn">もう1つ、意図していなかった発見があります。</mark>支払先を弁護士個人から**税理士法人（法人）**に変えた負例です。「法人だから源泉徴収は不要です」という条項はどこにも書いていません。<mark>それでも3回とも、受注者名「◯◯税理士法人」という表記だけから自分から法人格に気づき、正しく除外しました</mark>（3/3）。

この記事は「手取り額を計算できるか」という実測に絞っています。確定申告のやり方には踏み込みません。実際の税率・適用条件は制度が変わることがあります。契約では必ず国税庁の最新情報（[No.2798 弁護士や税理士等に支払う报酬・料金](https://www.nta.go.jp/taxes/shiraberu/taxanswer/gensen/2798.htm)・[No.2792 源泉徴収が必要な报酬・料金等とは](https://www.nta.go.jp/taxes/shiraberu/taxanswer/gensen/2792.htm)、2026-10-23確認）で確認してください。

## AIへの頼み方 {: .ask }

### 1. 弁護士個人の顧問料（204条の明記あり）で聞く

法人が個人の弁護士へ、月額顧問料を直接支払う架空の契約です。契約書に、所得税法204条1項2号に該当する旨と源泉徴収義務があることを明記しています。消費税は「別」（契約の金額に消費税が加算される）としました。

<div class="prompt">この契約の手取り額を計算してください。</div>

上に続けて、契約書を貼ります。

**3回とも「手取りは598,740円」と正しく計算しました。**式は600,000円×10.21%＝61,260円の源泉徴収。消費税別なので請求総額は600,000円＋消費税60,000円＝660,000円、そこから源泉徴収61,260円を引いて598,740円です。204条1項2号（士業）でも、原稿料・講演料（1号）と**同じ式**が正しく適用されました。

### 2. タレントの出演料（204条の明記あり・100万円の段階を跨ぐ）で聞く

次は、法人が個人のタレントへCM出演料を支払う契約です。150万円という、源泉徴収の税率が途中で変わる金額です。204条1項5号に該当する旨を契約書に明記しています。

<div class="prompt">この契約の手取り額を計算してください。</div>

**3回とも「手取りは1,445,800円」と正しく計算しました。**源泉徴収は100万円以下の部分が102,100円、100万円を超える50万円の部分が102,100円、合計204,200円。消費税別の請求総額1,650,000円から、この204,200円を引いた金額です。<mark>出演料（5号）でも、弁護士報酬・原稿料等と同じ2段階の式が崩れませんでした。</mark>

### 3. 204条の明記を外し、弁護士の肩書だけを残して聞く

指示文1の契約から、「所得税法204条1項2号に該当し、源泉徴収を行う」という条項を削除しました。業務内容も「弁護士業務に関する顧問サービス」から「毎月定例の顧問サービス」という一般的な言い方に変えました。ただし受注者名には「桜井法律事務所　桜井　健一（個人事業主・弁護士）」という**肩書だけ**を残しています。

<div class="prompt">この契約の手取り額を計算してください。</div>

**こちらも3回とも「手取りは598,740円」と、明記ありの版とまったく同じ結果になりました。**204条の条文番号は書いていませんが、3回とも「弁護士」という肩書から自分で「源泉徴収の対象業務」と判定しています。

## うまくいかないときの言い直し方 {: .fix }

### 肩書まで外すと、判定に自信を持てなくなる {: .trouble }

指示文3からさらに、受注者名の「弁護士」という肩書も削除し、「桜井　健一（個人事業主）」という名前だけに変えました。業務内容は指示文3と同じです。

<div class="prompt">この契約の手取り額を計算してください。</div>

<mark class="warn">3回とも、単一の正しい答えに到達できませんでした。</mark>2回は「源泉徴収なし・660,000円」を主結論にしました。それでも「もし資格保有者なら598,740円」と条件付きで併記しています。残り1回は、正答（598,740円）への言及が一度もありませんでした。<mark>肩書も明記も両方外すと、業務内容が「顧問サービス」という一般的な言い方のままでは、正しい判定に確信が持てなくなります。</mark>

→ 業務委託契約で源泉徴収の判定をAIに任せるなら、**受注者の肩書・資格名（弁護士・税理士等）を契約書に残しておく**のが安全です。明記を省くときも、**資格名だけは必ず書いておいてください**。

### 出演料は、明記を外すとさらに不安定になる {: .trouble }

指示文2の出演契約から、204条の明記を外しました（受注者の肩書「タレント」はそのまま残しています）。

<div class="prompt">この契約の手取り額を計算してください。</div>

3回試すと、**正しい最終金額（1,445,800円）に到達したのは1回だけでした。**1回は源泉徴収の式も手順も正しかったのに、最後の引き算を1,445,600円と誤りました（200円差）。もう1回は「契約書に源泉徴収に関する記載がないため」と、源泉徴収そのものを適用しませんでした。<mark>弁護士は肩書だけで3/3のままでしたが、タレントは肩書（「タレント」）があっても明記を外すと1/3まで落ちました。</mark>

→ 204条の明記を外した状態での正答率は、業務の種類によって違います。**明記を省いて一般化する前に、その業務ごとに実測し直してください。**明記そのものを残すのが、いちばん確実な直し方です（指示文2の版なら3/3）。

## 応用・次の一手 {: .next }

**支払先が法人のときは、何も教えなくても正しく気づくかを試しました。**指示文1と同じ月額60万円の顧問料を、弁護士個人ではなく**税理士法人（法人）**に支払う契約に変え、204条の明記も「法人だから対象外」という注記も、どちらも書きませんでした。

<div class="prompt">この契約の手取り額を計算してください。</div>

**3回とも「法人への支払いなので源泉徴収は不要。手取りは660,000円（全額）」と正しく判定しました。**3回とも、自分から「源泉徴収は支払先が個人の場合に限られる」という条文の仕組みを説明しています。気づいた根拠は、受注者名「まつば税理士法人」の法人格の表記だけです。

**報酬の種類・受注者の形態が増えてきたら、契約のたびに同じ手順で確認できるようにしておくと安心です。**

<div class="prompt">士業・出演料・法人など、さまざまな相手から報酬を受け取る（または支払う）契約が増えてきました。契約ごとに源泉徴収の対象かどうかと、正しい手取り額を毎回確認したいです。プログラミングはできません。私が契約のたびに確認することを、番号を振って箇条書きで教えてください。</div>

試したところ、次の骨格が共通していました。

- まず、報酬の名目が**源泉徴収の対象業務**（204条1項に列挙される業務）に当たるかどうかを確認する
- 受注者が**個人か法人か**を確認する。法人（弁護士法人・税理士法人等）なら、原則として源泉徴収は不要
- 契約書・請求書で、消費税が本体価格と区分して記載されているかを確認する
- 1回の支払金額が100万円を超えるかどうかで、税率（10.21%／20.42%）を自分でも計算してみる
- 実際の入金額と、自分で計算した手取り額が一致するか照合する

[副業の手取りを契約額から出す記事](/recipes/take-home-from-the-contract-amount/)と合わせて読むと、プラットフォーム経由・直接契約で天引きの有無がどう変わるかが分かります。

⚠️ **この結果は、弁護士個人・タレント出演料・税理士法人の3種・計18回（応用3回を含む）の実測です。**「どの士業でも必ず正しい」「法人なら必ず気づく」と一般化しないでください。試したのは、次の範囲までです。

- 業務の種類は弁護士（204条1項2号）・タレントの出演料（204条1項5号）・税理士法人（負例）のみです。スポーツ選手・モデル・外交員など、204条の他の列挙業務（4号等）は未検証です
- 消費税は「別」（契約額に加算）のみ試しました。消費税が「込み」の契約は未検証です
- 1回の支払い単位で計算しました（分割払いは未検証です）
- 法人の負例は税理士法人1種のみです。別の士業法人や、個人なのに社名に「法人」を含む紛らわしい表記などは未検証です
